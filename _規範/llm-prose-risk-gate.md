# LLM 慣用不良修辭 Gate

## 目的

防止課程大綱、教案與學員講義出現高度模板化、空泛、說教或缺乏具體判準的 LLM 文風。

本 Gate 是文案品質規範，不是 AI 作者偵測器。單一句型不能證明文字由 AI 產生；判斷依據是句型密度、上下文必要性、是否提供具體資訊，以及是否讓讀者感到文字可被任何主題直接替換。

研究與編輯觀察指出，LLM 文字常使用較窄且重複的語篇資源，容易產生模板化轉折、過度 hedging 與缺乏情境校準的修辭；模型、提示詞與文類仍會影響結果，因此所有命中項都要人工判斷，不可只靠字串掃描放行。

## 適用範圍

- `_outlines/`：課程定位、學習成果、單元說明與申請表文案。
- `_lessons/`：教案中的學員視角正文、案例、練習與檢核題。
- `courses/**/*.html`：學員實際看到的文字。
- 講師備註也應遵守，但可在分析句型時保留必要的規範示例或引用。

## 高風險模式

### BLOCKER：預設改寫

以下模式在學員正文中預設改寫：

- `不是 X，而是 Y`
- `並非 X，而是 Y`
- `不只是 X，而是 Y`
- `不是為了 X，而是為了 Y`
- `這不是……，這是……`
- `與其 X，不如 Y`

優先改成「行動 → 目的 → 可觀察結果」的正向句。必要限制另起一句，不要用否定句包住主旨。

### MAJOR：密度過高時改寫

- 「首先／其次／最後」反覆排列，但沒有真正的程序依賴。
- 「值得注意的是／需要強調的是／重要的是」作為空泛加重語氣。
- 「在現今快速變動的時代／隨著科技演進」等可套用到任何主題的開場。
- 「總而言之／綜合來看／換句話說」重述上一段而沒有新增判斷。
- 「許多專家認為／研究顯示／業界普遍認為」沒有來源、範圍或日期。
- `可能、可以、往往、通常、某種程度` 等 hedging 疊加，讓句子沒有明確判斷。
- `全面、深度、完整、無縫、高效、強大、賦能、創造價值` 等沒有驗收標準的詞。
- 三項並列只為製造節奏，例如「清楚、有效、可執行」；每一項都必須對應不同產出或判準。

### MINOR：整體閱讀時檢查

- 破折號或括號連續插入補充條件。
- 每段都使用相同句長與相同三句結構。
- 為避免重複而反覆更換同一角色的稱呼。
- 反問句只負責轉場，沒有要求讀者做判斷。
- `Great question`、`這是一個很好的問題`、`希望這有幫助` 等客服式套語。

## 例外條件

下列情況可以保留否定句，但仍要確認它提供了具體資訊：

- 課程限制：「本課程不要求學員支付真實廣告預算。」
- 安全或權限邊界：「LocalWP 網站不提供公開索引驗證。」
- 正反例標示：「非例」作為分類標籤。
- 學員必須辨認的錯誤句或原始引用；應明確標示為例句，不要讓它成為作者敘述。

例外句不要再接固定的「而是」轉折。需要說明替代方案時，另起一句：

> 本課程不要求學員支付真實廣告預算。練習使用模擬資料完成投放判斷。

## 改寫程序

### 1. 掃描

先掃描 `不是`、`並非`、`不只是`、`而是`、`不是為了`、`值得注意的是`、`總而言之`、`賦能`、`全面` 等詞。

### 2. 分類

每個命中項標記為：

- `CONTRAST`：公式化否定—轉正。
- `BOUNDARY`：必要限制或安全邊界，可保留。
- `EXAMPLE`：學員要辨認的錯例或引用，可保留並加標籤。
- `FILLER`：刪除後資訊不減的語氣填充。
- `EVIDENCE_GAP`：需要來源、數據或具體產出的空泛主張。

### 3. 改寫

依下列順序處理：

1. 把主語改成角色、學員或本單元任務。
2. 直接說動作、對象、成果與判斷條件。
3. 將必要限制拆成獨立句。
4. 將抽象詞改成檔案、欄位、數量、行動或可觀察結果。
5. 保留原本的教學事實、案例、工具、限制與驗收要求。

### 4. 冷讀

朗讀修正版，確認：

- 第一個句子直接交代情境、任務或判準。
- 沒有先替讀者創造一個錯誤立場，再由作者宣布正解。
- 刪除轉折詞後，前後句仍然有因果關係。
- 讀者能指出要做什麼、留下什麼、如何判斷完成。

## 修正版示例

| 高風險寫法 | 建議寫法 |
|---|---|
| 本單元的任務不是替學員決定職涯出口，而是建立一個共同主題。 | 本單元先建立一個供後續五科共同使用的主題。學員再依自己的目標延伸到不同應用情境。 |
| 核心不是寫漂亮標語，而是說明對象與問題。 | 本單元要寫出一組可檢查的價值主張，內容包括對象、問題、證據與下一步。 |
| 這不是一篇品牌介紹文，而是一份工作文件。 | Brief 是用來記錄任務邊界與判斷條件的工作文件。品牌介紹文屬於另一種文件。 |
| 這不是為了湊數，而是避免單一印象成為結論。 | 至少需要兩筆線索，才能避免把單一印象寫成結論。 |

## 放行標準

- 學員正文中不得留下未審查的高風險對比句。
- 每個保留的否定句都要標明功能：限制、錯例、引用或必要分類。
- 空泛詞若保留，附近必須有具體定義、產出或驗收條件。
- 修辭掃描通過後，仍要做一次人工朗讀與零基礎冷讀。
- `PASS` 代表命中項已分類、必要句已保留、其餘句已改成具體敘述；不是代表全文沒有任何「不」字。


## 句意、指涉與段落推進

核對誰在做什麼、處理的資料或對象、必要條件與結果是否明確。中文上下文已明確時可以省略主詞、受詞或副詞；不要求每句具備所有文法成分。只有「設定、完成、確認」而沒有可定位的對象或判準，才補成學員能執行與判斷的敘述。

代詞「它、這個、上述」須能唯一指向對象。資料、角色與術語前後一致；換案例、條件或視角時交代理由。段落應由問題、解釋與示範推進到練習、變化及使用條件，不要求固定四標題，也不為每個標題補固定句數。

「所以」等連接詞只能表達已成立的推論。例：「平均數是 8，所以每個人都是 8」仍是錯誤推理；應解釋平均分配的代表值與實際個別值的差別。掃描只能提供候選，必須閱讀內容並引用理由後才下語意結論。
