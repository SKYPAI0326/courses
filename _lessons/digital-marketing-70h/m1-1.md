# 快思慢想：顧客什麼時候憑直覺、什麼時候停下來比較
用雙歷程理論讀懂顧客如何在快速印象與仔細比較之間切換。
學習目標：能說明 System 1 與 System 2 的定義、特徵與合作方式｜能判斷一個購買時刻較偏直覺、比較或兩者都有，並寫出要再確認的問題｜能依判讀安排注意線索、比較資訊與下一步
本節完成物：山徑咖啡三個購買時刻的判讀（直覺／比較／兩者都有）

## 開始之前

> 數位行銷人才培訓｜第一模組「消費者心理學」｜單元 1-1｜1.5 小時
> 本模組不使用 AI 工具，全部用紙筆或試算表完成。

## 1. 兩種想事情的方式：System 1 和 System 2

### 1.1 先做一個小測驗

請在 3 秒內回答，不要拿紙筆：

> 一支球拍加一顆球，合計 110 元。球拍比球貴 100 元。球多少錢？

多數人腦中第一個冒出來的答案是「10 元」。但如果球是 10 元，球拍就是 110 元，合計 120 元，不對。正確答案是 **5 元**（球 5 元，球拍 105 元，合計 110 元）。

這題改編自心理學家 Daniel Kahneman 在《快思慢想》（英文原書 *Thinking, Fast and Slow*，2011 年出版；繁體中文版由天下文化出版、洪蘭翻譯）裡用來說明兩種思考的例子。剛剛發生了兩件事：

- 「10 元」是**自動冒出來**的，你沒有刻意去算。這是 **System 1**。
- 如果你停下來，用「球 + 球拍 = 110」去驗算，發現不對，再重新算出 5 元。這是 **System 2**。

### 1.2 定義與特徵

Kahneman 用兩個「角色」來描述大腦處理事情的兩種方式。這兩個名稱他是沿用心理學家 Keith Stanovich 與 Richard West 提出的說法。

| | System 1（快思） | System 2（慢想） |
|---|---|---|
| 一句話定義 | 自動、快速運作，幾乎不費力，也感覺不到自己在控制 | 把注意力分配給需要費力的思考，例如計算、比較、檢查 |
| 速度 | 快，常在幾秒內就有結論 | 慢，要花時間 |
| 費不費力 | 幾乎不費力，可以同時做別的事 | 費力，分心或累了就做不好 |
| 你感覺到的 | 「直覺就覺得是這樣」，常說不出理由 | 「我在想」「我在比」，能說出理由 |
| 生活例子 | 看到熟悉的品牌標誌、一眼覺得這張照片好看、讀出看板上的字 | 比較兩支手機的規格、填一份很長的表單、算哪個方案比較划算 |

### 1.3 兩者怎麼合作

這是最容易誤會的地方：**System 1 和 System 2 不是輪流上班，而是一直同時在運作**，分工如下：

1. **System 1 一直開著**，不斷產生印象、感覺和想做的衝動，例如「這支壺看起來很專業」「這則貼文好像不錯」。
2. **System 2 平常是省電模式**。大多數時候它直接接受 System 1 的印象，不另外檢查。Kahneman 用「懶惰」來形容 System 2：能不費力，就不費力。
3. **遇到卡住或意外時，System 2 才被叫出來**。例如 System 1 給不出答案（「17 × 24 是多少？」）、事情和預期不一樣（「怎麼會這麼貴？」）、或後果很重要（「這筆錢花下去會不會後悔？」）。
4. **System 2 能做的事有限**。注意力是有限的，事情太多、太累、太趕時，System 2 會放棄，又交回 System 1。

用山徑咖啡的顧客來想：滑 IG 時看到一支手沖影片，System 1 先覺得「好療癒」。這個印象讓她停下來，點進商品頁後，看到三款價格從 1,680 到 3,280 元，差了快一倍，System 2 被叫出來：「差在哪裡？我需要哪一款？」如果這時網頁看不出差別，比較變得很費力，她可能就先離開了。

### 1.4 三個常見誤會

| 誤會 | 正確理解 |
|---|---|
| System 1 是大腦的某個部位 | 不是。Kahneman 明說這兩個「系統」是方便說明的角色，不是腦中的兩個區域。 |
| System 1 是感性、不好的；System 2 是理性、好的 | 不是。System 1 常常是對的，熟手的直覺（例如老店員一看就知道顧客要什麼）就是 System 1。System 2 也會算錯。 |
| 有些顧客是「直覺型」，有些是「比較型」 | 不是。**同一個人**在不同時刻會切換。所以本課判讀的對象是「購買時刻」，不是「哪種顧客」。 |

> **記住這一句就夠**：System 1 先給印象，System 2 在需要時才出來比較和檢查；行銷要做的，是在每個時刻給對的東西。


## 2. 怎麼判讀一個購買時刻

### 2.1 什麼叫「購買時刻」

購買時刻是顧客從「注意到」到「買下或預約」途中，**一個具體、看得到的場景**。例如「在 IG 滑到沖煮影片」「在商品頁比較三款」「在 LINE 問問題」。寫的時候用「顧客正在做什麼」來描述，不要寫成「品牌認知階段」這種抽象名稱。

### 2.2 判讀訊號表（判斷依據）

你擔心「直覺／比較沒有標準答案」，這是對的，**判讀結果本身沒有唯一答案**。但判讀有沒有寫好，有標準：**你的判讀要對得上你寫的事實**。下面這張表就是對照用的訊號。

| 偏 System 1 的訊號 | 偏 System 2 的訊號 |
|---|---|
| 時間很短（幾秒內決定要不要停下、點下去） | 時間拉長（願意花幾分鐘、甚至等一天） |
| 顧客同時在做別的事（滑手機、通勤、趕時間） | 顧客主動投入（主動提問、主動搜尋、填資料） |
| 反應來自畫面、聲音、熟悉感、第一印象 | 反應來自規格、價格、條件、比較 |
| 顧客說不太出理由（「就覺得不錯」） | 顧客能說出理由，或問出具體問題 |
| 下一步是「點一下」就能完成 | 下一步需要輸入、計算、選擇 |

判讀規則：

- 事實大多落在左欄 → **System 1**
- 事實大多落在右欄 → **System 2**
- 兩欄都有明確事實，且都影響顧客下一步 → **兩者都有**

「兩者都有」不是不知道時的安全牌。選它時，判讀理由要分別寫出哪個事實是 System 1、哪個事實是 System 2。

### 2.3 「可觀察事實」和「判讀」要分開

這是本表最重要的一條規矩，下一單元 1-2 會拿這張表檢查「說服訊號有沒有真實依據」，所以事實欄必須是**任何人去看資料都會同意的內容**。

| 可觀察事實（可以放） | 判讀或推測（不能放進事實欄） |
|---|---|
| 沖煮影片平均互動 118，規格貼文平均互動 42 | 顧客比較喜歡影片 |
| 表單有 9 個欄位 | 表單太長 |
| 一則評論說「預約表單填到一半放棄，問題太多。」 | 顧客都覺得表單很煩 |

右欄的句子不是錯，而是屬於「判讀理由」或「還要確認的問題」那一欄。

### 2.4 「還要確認的問題」怎麼寫

好的問題有兩個條件：

1. **答案可能改變你的判讀或內容安排**。如果不管答案是什麼，你都不會改，這個問題就不必寫。
2. **有辦法查到答案**。寫出去哪裡查或問誰，例如「看預約表單每個欄位的放棄率」「訪談 5 位到店試握的顧客」。

本課的資料有幾個先天限制，寫問題時可以從這裡找：

- 這是課堂模擬資料，不是真實成效。
- 樣本很小，例如沖煮影片只有 3 則、評論只有幾則。
- 「互動」＝按讚＋留言＋分享，**不等於想買**，也看不出顧客看了多久。

### 2.5 「內容安排」怎麼寫

內容安排要回答三件事，依判讀調整比重：

| | 注意線索 | 比較資訊 | 下一步 |
|---|---|---|---|
| 意思 | 讓顧客停下來、注意到的東西 | 幫顧客比較、做決定的資料 | 顧客接下來要做的一個動作 |
| System 1 為主時 | **重點**：一個清楚的畫面或一句話 | 少量，放在點進去之後 | 一點就到，不用輸入 |
| System 2 為主時 | 讓顧客找得到比較資料 | **重點**：用同一標準並排呈現 | 降低費力程度，例如少填欄位、給確認通知 |
| 兩者都有時 | 先抓住注意 | 緊接著提供比較 | 兩條路都要通 |

寫的時候要具體到「放什麼、放在哪」，例如「每支沖煮影片結尾放預約連結」，不要只寫「加強行銷」。


## 3. 完整範例：在商品頁比較三款手沖壺

這一列不是你要交的三個時刻之一，是示範用。請看每一欄是怎麼從前一欄推出來的。

**先把相關材料挑出來**（只挑和這個時刻有關的）：

- 三款商品頁都有容量、材質與價格，價格區間 NT$1,680–3,280。
- 只有一款提供出水影片。
- 商品頁沒有「適合哪種沖煮習慣」的比較表。
- 評論：「店員講得很清楚，但網頁看不出三款差別。」
- 評論：「影片有幫助，希望每款都用一樣方式測。」
- 評論：「如果有新手比較表，我會比較快決定。」
- 行動版產品頁平均要滑三個畫面才看到預約入口。

**對照訊號表**：顧客在看規格和價格、想知道差別、評論能說出具體需求（比較表、同樣方式測），主要落在右欄。左欄的訊號（出水影片的畫面）只出現在一款，評論提到它，是因為它「有幫助比較」，而不是因為它好看。

**範例這一列：**

| 欄位 | 內容 |
|---|---|
| 購買時刻 | 在商品頁比較三款手沖壺 |
| 可觀察事實 | 三款頁面都有容量、材質、價格（1,680–3,280 元），只有一款有出水影片，沒有沖煮習慣比較表；評論說「網頁看不出三款差別」「希望每款都用一樣方式測」「如果有新手比較表，我會比較快決定」；行動版要滑三個畫面才看到預約入口 |
| 判讀 | System 2 |
| 判讀理由 | 顧客在這個時刻是主動比較規格與價格，評論能說出具體的比較需求（比較表、同一測法），屬於費力的比較。目前資料不齊，三款資訊標準不一致，讓比較更費力。 |
| 還要確認的問題 | ①顧客比較時最在意哪幾項？是容量、材質、價格，還是「適不適合我的沖法」？（訪談到店試握的顧客）②沒有影片的兩款，顧客停留和離開的情形和有影片的那款有沒有差？（之後用 GA4 查） |
| 內容安排 | 注意線索：頁面上方放一句「三款怎麼選？看比較表」。比較資訊：做一張新手比較表，依沖煮習慣（例如一次沖幾人份）並排三款；三款都補上同一方式拍的出水影片。下一步：比較表下方直接放「還不確定？預約 20 分鐘試握」，行動版不用滑三個畫面就看得到。 |

**這一列為什麼算寫得好**：事實欄每一句都能在材料裡找到；判讀理由引用了事實；兩個問題的答案都可能改變比較表要放哪些項目；內容安排分別寫了注意線索、比較資訊、下一步，而且具體到放在哪裡。

**對照：如果判讀是 System 1，會寫成什麼樣？** 以「打開首頁的第一眼」為例：顧客幾秒內就決定要不要往下看，靠的是標題「找到你的下一把手沖壺。」和畫面給的第一印象，這偏 System 1。這時的內容安排重點就變成「注意線索」：例如評論說「門市可以試握這件事我到結帳後才知道」，那首頁第一眼就該看得到「可預約 20 分鐘試握」，而不是只放在導覽列和頁面底部。


## 4. 動手做：山徑咖啡三個購買時刻

請開一份 Google 試算表或 Excel，第一列打上六個欄位名稱，再填三列。下面每個時刻給你「該看的事實」和「判讀時問自己的問題」，**沒有給答案**，因為判讀要由你根據訊號表做出來。

### 時刻 A：在社群看到沖煮影片

**該看的事實**

- Instagram 近四週 12 則貼文：8 則規格介紹、3 則沖煮影片、1 則門市活動。
- 平均互動（按讚＋留言＋分享）：規格貼文 42、沖煮影片 118、門市活動 96。
- 只有門市活動貼文附預約連結。

**問自己**

- 顧客在 IG 上是什麼狀態？在滑、還是在找？決定要不要停下來需要多久？
- 互動 118 能告訴你顧客「喜歡」，能告訴你顧客「想買」嗎？留言裡可能有什麼，而你現在看不到？
- 看完影片想進一步了解的人，下一步可以點哪裡？
- 只有 3 則影片，數字夠不夠讓你下結論？

### 時刻 B：填預約表單

**該看的事實**

- 表單有 9 個欄位。
- 送出後顯示成功訊息，但沒有 Email 或 LINE 確認。
- 一則評論：「預約表單填到一半放棄，問題太多。」

**問自己**

- 填表單需要輸入和選擇，是費力的事還是不費力的事？
- 願意打開表單的人，原本想不想預約？他放棄，是因為不想要，還是因為太費力？
- 送出後沒有確認通知，顧客心裡可能會出現什麼疑問？
- 9 個欄位中，哪些是預約當下真的需要的？你要怎麼查到顧客在哪一欄放棄？

> 小心陷阱：「顧客放棄了」不代表這個時刻就是 System 1。請回到訊號表，看事實落在哪一欄。

### 時刻 C：在 LINE 問器具問題

**該看的事實**

- LINE 官方帳號由人工回覆器具問題，沒有標準化的比較資料。
- 一則評論：「LINE 問問題隔天才回，但答案有用。」

**問自己**

- 主動打字問問題的人，是在滑過去，還是在想清楚？
- 「隔天才回」對這位顧客的影響是什麼？他願意等，代表什麼？會不會也有不願意等就走掉的人，而你看不到？
- 人工回覆沒有標準資料，不同店員回答會不會不一樣？顧客問的問題，和商品頁缺的資料有沒有關係？
- 回覆裡可以接什麼「下一步」？

### 填完之後

- 判讀欄三列不一定要三種都不同，重點是每一列的理由對得上事實。
- 內容安排可以互相呼應。例如你為某個時刻設計的比較資料，也可能用在另一個時刻。


## 5. 自我檢查：我寫得對不對？

交出前逐列檢查。七項都打勾，這一列就合格。

- [ ] **購買時刻**寫的是顧客正在做的具體行為。
- [ ] **可觀察事實**每一句都能在材料裡找到原文或數字，沒有「太長」「比較喜歡」這類判斷字眼。
- [ ] **判讀**只填 System 1、System 2、兩者都有其中之一。
- [ ] **判讀理由**至少引用一個事實，並說出它對應訊號表的哪一項；選「兩者都有」時，兩邊各有事實。
- [ ] **還要確認的問題**至少一個，答案可能改變判讀或內容安排，並寫出去哪裡查或問誰。
- [ ] **內容安排**分別寫了注意線索、比較資訊、下一步，比重和判讀一致。
- [ ] **內容安排**具體到「放什麼、放在哪」。

如果兩個同學判讀不同，不代表有人錯。請比的是：誰的理由對得上事實、誰的問題比較能查出答案。


## 6. 補充：顧客開始請 AI 幫忙「比較」

本模組不用 AI，但你在後面的模組會一直遇到這個趨勢，先知道就好。

**已查證的事實**

- OpenAI 在 2025 年 11 月 24 日宣布 ChatGPT 的「購物研究」（shopping research）功能：使用者描述需求後，ChatGPT 會反問預算、用途等問題，再整理成購買指南。OpenAI 也提醒這個功能可能出錯，使用者應自行確認商家頁面的資訊。
- Adobe 在 2026 年 1 月 7 日發布的資料指出，2025 年 11 月 1 日至 12 月 31 日的美國假期購物季，從生成式 AI 工具點擊進入美國零售網站的流量，比前一年同期增加 693.4%。Adobe 同時說明，使用這類工具的人數基數仍然不大。

**要注意的限制**

- 這是**美國**資料，不能直接套用到台灣。
- 693.4% 是「成長率」，基數小時，成長率看起來會很大，不代表多數顧客都這樣買東西。

**和本課的關係（分析推論，不是研究結論）**：如果有一部分顧客把 System 2 的比較工作交給 AI，那麼品牌的比較資訊是否清楚、標準一致、公開在網頁上，就更重要。山徑咖啡缺少的那張新手比較表，不只顧客需要，AI 整理資訊時也用得到。


## 7. 帶回你的小組：巷口晨光早餐預訂

你的組選了「巷口晨光早餐預訂」。模組作業要畫「購買心理地圖」時，可以先用今天的方法讀卡片上的三句顧客原話：

| 顧客原話 | 可以怎麼想 |
|---|---|
| 「我想前一天選好，早上不用在櫃前想太久。」 | 顧客主動把費力的選擇（System 2）移到前一天晚上，讓早上趕時間時不用再想。這正好是兩個系統合作的例子。 |
| 「如果能看見隔天有哪些口味，我才會先預訂。」 | 前一天預訂時需要比較資訊：有哪些口味、還有沒有。 |
| 「我最怕到店才知道想吃的賣完。」 | 這是顧客在意的風險。1-3 單元會學到「損失趨避」，到時候可以回來接這一句。 |

這只是起點，判讀還要等你們在 1-4 單元訪談後，用真實顧客的事實來確認。


## 8. 複習小卡（考前或下次上課前看這張就好）

- **System 1（快思）**：自動、快、不費力，給出印象和感覺。
- **System 2（慢想）**：費力、慢，負責比較、計算、檢查；平常偷懶，遇到卡住、意外或重要的事才出來。
- **合作方式**：System 1 一直在給印象，System 2 多半直接接受，必要時才介入；太累太趕時，System 2 會放棄。
- **判讀對象**：購買時刻，不是顧客類型。同一個人會切換。
- **判讀依據**：看事實落在訊號表哪一欄（時間長短、是否主動投入、靠畫面還是靠規格、說不說得出理由、下一步費不費力）。
- **內容安排**：注意線索、比較資訊、下一步，依判讀決定比重。
- **下一課 1-2**：會用你這張表，檢查山徑咖啡的說服訊號有沒有真實依據，所以事實欄一定要寫準。
