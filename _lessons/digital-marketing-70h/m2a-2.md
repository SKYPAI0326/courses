## 一、先認得六種產品形態

上一節你做了「AI 錯誤對照表」，知道 AI 會說錯。這一節要處理的是另一個問題：**同一個 AI 品牌裡，其實有好幾種用法，適合的工作完全不同。** 選錯用法，不是做不出來，就是做出來要花更多時間修。

這裡說的「產品形態」，就是這些用法的分類。先記一句話就好：

> **形態看的是「工作怎麼進行」，不是「哪個品牌」。** ChatGPT、Claude、Gemini 各自都有好幾種形態。

### 六種形態一覽

| 形態 | 一句話說明 | 適合的任務 | 使用前提（用之前要先確定的事） |
|---|---|---|---|
| **聊天** | 你問一句、它回一段，來回修改。可以貼文字或上傳檔案。 | 改寫、摘要、整理你已經有的資料、起草 | 資料要你自己給；它說的事實要自己核對 |
| **深度研究** | 你給一個研究題目，它先擬研究計畫，再自己去搜尋很多網頁，花幾分鐘寫成一份附出處的報告。 | 需要從多個外部網站蒐集、整理公開資訊 | 等得起（通常幾分鐘到十幾分鐘）；**每一條出處都要點開核對**；免費方案通常有次數限制 |
| **代理** | 它不只回答，還會「實際去做」：開網頁、點按鈕、填表單、處理檔案，一步一步完成一件較長的工作。 | 跨好幾個網站或系統的多步驟操作 | 它的動作會真的發生，所以要有**人工核准點**；先在測試環境或測試名單上跑；多數需要付費方案 |
| **專案與記憶** | 「專案」是一個資料夾，把同一件工作的檔案、指示、對話放在一起；「記憶」是 AI 記住你說過的偏好，下次自動帶入。 | 同一件事要反覆做（每週報告、固定格式文案） | 放進去的資料會被反覆使用，**敏感資料不要放**；記憶記錯了要會去刪 |
| **生圖** | 用文字描述或上傳圖片，產生或修改圖片。 | 社群配圖、示意圖、草圖 | 商用前確認方案的使用條款；圖裡的文字和產品細節常出錯 |
| **生影片** | 用文字、圖片或影片產生短片，或用對話修改影片。 | 短影音素材、概念展示 | 服務變動很快（見後面 Sora 的例子），**用之前先確認服務還在、你的方案能不能用** |

### 還有一個不是形態、但常一起出現的東西：連接器

**連接器**（Connector）是讓 AI 讀取或寫入你其他服務的「授權通道」，例如讓 AI 讀你的 Gmail、Google 雲端硬碟、行事曆。

- 聊天加上連接器，AI 就能直接讀你雲端的檔案，不用你一份份上傳。
- 代理加上連接器，AI 就可能**代替你寄信、改檔案**。

所以開連接器前要問自己：「我允許它讀什麼？允許它改什麼？」公司帳號的連接器，通常要先問主管或資訊人員能不能開。本節只要你**知道有這個東西**；實際串接留到後面的自動化專節（2D-2）。

### 怕名詞記不住？用這張對照

| 你聽到 | 想成 |
|---|---|
| 聊天 | 一位你問什麼就答什麼的助理，資料要你給 |
| 深度研究 | 一位會自己上網找資料、交報告的研究助理，但報告要你驗收 |
| 代理 | 一位會動手幫你操作電腦的助理，所以重要動作要你點頭 |
| 專案 | 一個放固定工作資料的資料夾 |
| 記憶 | 助理記在小本子上的「你的習慣」 |
| 連接器 | 你給助理的一把鑰匙，決定它能開哪幾扇門 |

### 能力類別：當成「查表索引」用

有時候你不是從形態想起，而是從「我要產出什麼東西」想起。這時用下面這張表反查：

| 我要處理的是…… | 先看哪種形態 | 備註 |
|---|---|---|
| **文字**（文案、摘要、比較表、信件） | 聊天；要外部資料時看深度研究 | 最常用、免費版大多可用 |
| **圖像**（配圖、示意圖） | 生圖 | 單元提到的工具：ChatGPT 圖像生成、Midjourney、Canva AI（本節不操作，2C-2 會用到） |
| **影片**（短影音、影片修改） | 生影片 | 單元提到 Gemini Omni（本節不操作，2C-3 會用到） |
| **語音**（逐字稿、語音對話、配音） | 聊天的語音模式，或專門的語音工具 | 錄音內容常含個資，先想清楚再上傳 |
| **數據分析**（試算表統計、做圖表） | 聊天上傳檔案 | 數字一定要回原檔抽查，算錯不會自己告訴你 |


## 二、用「三問」選形態

認得形態之後，遇到一件工作要怎麼選？不要從「哪個工具最紅」開始，而是先問這件工作本身的三個問題：

### 三問

1. **輸入從哪裡來？**
   - 你手上已經有（檔案、表格、文字）→ 偏向**聊天**
   - 要從很多外部網站找 → 偏向**深度研究**
   - 每次都是同一批資料、同一個格式 → 考慮**專案與記憶**
2. **輸出要變成什麼？**
   - 一段文字、一張表，你看完再用 → **聊天**就夠
   - 附出處的研究底稿 → **深度研究**
   - 要真的寫進、寄到、發布到外部系統（網站、LINE、Email）→ 這是**代理**或自動化的範圍
   - 圖片、影片 → **生圖、生影片**
3. **錯了的代價是什麼？誰要核准？**
   - 錯了你自己看得到、改得掉 → 可以讓 AI 多做一點
   - 錯了會被很多人看到、寄出去收不回來、牽涉錢 → AI 只做到「草稿」，**最後一步留給人**，並寫下核准者是誰

第三問最重要。它決定的不是「能不能用 AI」，而是「AI 做到哪一步要停下來給人看」。

### 示範：山徑咖啡的三個任務

山徑咖啡是課程的模擬品牌（台北的咖啡器具選品店），這次產品線是「新手升級手沖壺」三款，價格 NT$1,680–3,280，主推門市 20 分鐘試握體驗。以下三個任務都用同一組欄位判斷，你等一下的表也是這八欄。

> 下表的「核准者」與「試用紀錄」數字是示範用的假設，課程資料沒有指定。

**任務 1：整理三款手沖壺比較表**

| 欄位 | 內容 |
|---|---|
| 任務 | 把三款商品頁摘要整理成一張比較表 |
| 輸入 | 三款商品頁摘要（已經在手上：杉影 600、溪線 700、稜峰 600 銅製） |
| 輸出 | 一張表，只列：商品、容量、材質、價格、出水影片有無 |
| 錯了的代價與核准者 | 價格或容量抄錯，上架後會誤導顧客；上架前由店長逐格對回商品頁 |
| 選用形態 | 聊天 |
| 選用理由 | 資料全部在手上，只是重新排列；聊天幾秒就能出表，人工逐格核對五欄也很快 |
| 不選的形態與理由 | 深度研究：不需要外部資料，叫它上網找反而可能混進別家規格；代理：不需要操作任何系統 |
| 試用紀錄 | 工具：手上的聊天工具；人工修正：逐格核對約 3 分鐘（示範數字） |

做出來應該長這樣，你可以拿來檢查 AI 有沒有亂加：

| 商品 | 容量 | 材質 | 價格 | 出水影片 |
|---|---|---|---|---|
| 杉影 600 手沖壺 | 600 ml | 不鏽鋼 | NT$1,680 | 無 |
| 溪線 700 手沖壺 | 700 ml | 不鏽鋼 | NT$2,380 | 有 |
| 稜峰 600 銅製手沖壺 | 600 ml | 銅 | NT$3,280 | 無 |

如果 AI 自己多寫了「適合新手」「重量輕」這類欄位，就是它補了商品頁沒寫的東西，要刪掉。這正是上一節錯誤對照表裡的那種錯。

**任務 2：蒐集台灣手沖器具市場公開資訊並附出處**

| 欄位 | 內容 |
|---|---|
| 任務 | 找台灣手沖器具市場的公開資訊 |
| 輸入 | 來自多個外部網站 |
| 輸出 | 研究底稿，每一條都附連結與查核日期 |
| 錯了的代價與核准者 | 引用錯誤數據會讓後面的定位判斷整個歪掉；由行銷負責人抽查出處後才能放進企劃 |
| 選用形態 | 深度研究 |
| 選用理由 | 輸入分散在很多網站，深度研究會先擬計畫、再一次搜尋整理並附出處，比一問一答省力 |
| 不選的形態與理由 | 聊天：要自己一題一題問、一個個網站找，容易漏；代理：不需要在網站上操作或填表 |
| 試用紀錄 | **本節只判斷形態，不實際做。** 實際研究留到 2D-1 深度研究 |

**任務 3：把核准過的比較表同步到網站、LINE 與 Email**

| 欄位 | 內容 |
|---|---|
| 任務 | 已核准的比較表，要更新到網站、LINE 官方帳號、Email |
| 輸入 | 已核准的表格 |
| 輸出 | 三個外部系統上的內容 |
| 錯了的代價與核准者 | 發出去的訊息收不回來，三個管道同時出錯影響最大；每個管道發布前都要店長確認 |
| 選用形態 | 現階段：聊天起草三個管道的版本，人工貼上發布 |
| 選用理由 | 輸出涉及外部系統、錯了收不回，先讓 AI 只做草稿 |
| 不選的形態與理由 | 代理全自動發布：等有測試環境、能設定「發布前停下來讓人核准」再評估；串接方法留到 2D-2 |
| 試用紀錄 | 本節不實測 |

看出來了嗎？三個任務的選擇，**決定因素都在三問裡，不在工具名氣。**


## 三、選好形態之後：評估具體工具

形態決定了「哪一類」，接下來才挑「哪一個」。同樣是聊天，ChatGPT、Claude、Gemini 都有；同樣是生圖，也有好幾家。用下面四問評估：

### 四問

1. **瓶頸在哪？** 你現在做這件事，卡在哪一步？打字慢、找資料慢、格式整理慢，還是要反覆做？工具要解決的是那一步，不是全部。
2. **真實任務品質如何？** 用**你自己的真實任務**測一次，不要看官方示範影片。看它有沒有亂補、有沒有漏、格式對不對。
3. **能不能匯出、接到下一步？** 結果能不能複製成表格、下載成檔案、匯出到 Google 文件？還是只能截圖？你下一步要用 Excel，它就要能給你可以貼進 Excel 的東西。
4. **方案、費用與資料條款？** 你要的功能在免費版有沒有？有沒有次數限制？你的對話會不會被拿去訓練模型、能不能關掉、能不能刪除？

### 排除條件：碰到任何一條就先不用

- 任務含公司內部或個人資料，但這個工具的訓練設定**關不掉**，或你找不到資料條款。
- 你需要的功能在台灣、或在你的方案**不能用**。
- 結果**無法匯出**成你下一步需要的格式。
- 要開的連接器權限超過任務需要，或公司沒有核准。

### 試用紀錄：六個欄位

每次實測，都記下這六項。這是你的表裡「試用紀錄」那一格要寫的內容：

| 欄位 | 寫什麼 | 範例寫法 |
|---|---|---|
| 工具 | 工具名稱與方案 | ChatGPT 免費版 |
| 官方方案連結 | 你實際打開的官方方案頁網址 | （貼你開過的網址） |
| 查核日期 | 你打開那天 | 2026-11-12 |
| 資料設定 | 對話會不會用來訓練、你有沒有關、能不能刪 | 訓練：預設開啟，已關閉；可刪除單則對話 |
| 能否匯出 | 用什麼方式拿出結果 | 可複製表格貼到試算表 |
| 人工修正時間 | 從拿到結果到可以交出去，你花了幾分鐘修改與核對 | 12 分鐘 |

### 省時淨值：判斷到底有沒有比較快

很多人覺得「AI 幾秒就出來，一定比較快」，但要把核對時間算進去：

> **省時淨值 ＝ 原本自己做的時間 －（下指令與等待的時間 ＋ 人工修正與核對的時間）**

示範：任務 1 自己做要 20 分鐘；用聊天下指令加等待 2 分鐘、核對 3 分鐘，省時淨值 = 20 −（2 + 3）= 15 分鐘。

如果算出來接近 0 或是負的，代表這件事目前**不值得**交給 AI，或是指令要改。這個數字也是你之後跟主管說明「為什麼用／不用 AI」最有說服力的依據。

### 工具組合：先一個用熟，卡住再補

不要一次註冊五個工具。原則是：

1. **先選一個主力工具用熟。** 你目前有 ChatGPT 免費版，就先用它把聊天、上傳檔案、找設定都摸熟。
2. **遇到明確的瓶頸，再補一個。** 例如：主力工具的深度研究免費次數用完、或生圖不好用，這時才去試第二個，而且用**同一個任務**比較，才比得出差別。

## 四、動手做：填你的工具選用表

### 步驟 1：建表

在試算表第一列貼上這八個欄位：

```text
任務	輸入	輸出	錯了的代價與核准者	選用形態	選用理由	不選的形態與理由	試用紀錄
```

（從上面這行複製，貼到 A1 儲存格，通常會自動分成八欄。）

第二、三、四列分別放下面三件交辦。

### 練習資料：三個工作交辦

> 以下是課堂模擬資料，不是真實組織或人物。

**交辦一：** 我手上有一份 30 頁的內部請假規章 PDF，內容包含假別、申請期限、附件與例外處理。請在本週五 17:00 前整理成一頁重點，保留原規章的章節位置，不能自行補公司沒有寫的規則。這份資料先給全體同仁閱讀，再由人資主管核對後發布。

**交辦二：** 下週三中午前，請比較三家公開的線上會議軟體方案。我目前只有三個產品名稱，其他資料要從各產品的官方方案頁找，並附上實際開啟過的官方連結與查核日期。交付一張比較表給資訊主管，若價格、參與人數或錄影條件找不到就留白，不要引用部落格轉述。

**交辦三：** 每週一上午要把報名表單上一週的新回覆整理成名單，再寄出確認信。我可以提供表單欄位、核准過的信件範本與收件人清單格式；寄出前要先排除重複地址，並交給活動負責人確認人數。希望下個月開始固定執行，第一次先在下週一 10:00 前完成測試名單，不要直接寄給報名者。

### 步驟 2：三件都先填前七欄

每一件，照順序問自己：

1. 輸入從哪裡來？（內部檔案？外部網站？表單？）
2. 輸出要給誰、變成什麼？會不會進到外部系統？
3. 錯了會怎樣？交辦裡寫的核准者是誰？
4. 根據上面三題，選一種形態，寫一句理由。
5. 至少寫一種「不選」的形態和原因。

小提示：**核准者其實都寫在交辦裡了**，找「由誰核對」「交給誰」「給誰確認」這幾句。

### 步驟 3：查你手上工具的資料設定與方案

介面常是英文、選單很深，以下是三家的大致路徑。**找不到的時候，直接在該工具的說明中心搜尋括號裡的英文名稱。**

**ChatGPT**

- 資料設定：點左下角（或右上角）你的頭像 →「設定」（Settings）→「資料控制」（Data controls）→ 找「協助改善所有人的模型體驗」（Improve the model for everyone）。開著代表你的對話可能被用來訓練模型。
- 匯出：同一頁有「匯出資料」（Export data）。單一回答可以直接複製。
- 刪除：對話列表每則對話旁的「⋯」可以刪除。
- 方案頁：chatgpt.com/pricing

**記到你的試用紀錄：** 方案頁網址、今天日期、訓練設定是開或關（你有沒有改）、能不能刪、能怎麼匯出。

### 步驟 4：實測其中一件

只有一個免費工具，就測一件。依你的工具有沒有深度研究，二選一：

**選項 A：測交辦二（工具有深度研究時）**

1. 自己挑三個線上會議軟體（例如 Zoom、Google Meet、Microsoft Teams，你也可以換）。
2. 按下計時器，貼上這段指令：

```
請比較以下三個線上會議軟體的公開方案：Zoom、Google Meet、Microsoft Teams。
只能使用各產品官方網站的方案頁，不要引用部落格、新聞或比較網站。
請做成一張表，欄位：產品、方案名稱、價格、參與人數上限、錄影條件、官方方案頁連結。
找不到的格子留白，不要推測。
```

3. 停錶，記下「下指令與等待時間」。
4. **重新按錶，自己逐一點開它給的連結**，確認網址是官方網站、數字對得上。改完停錶，這就是「人工修正時間」。
5. 看能不能把表複製貼到試算表，記下「能否匯出」。

如果它引用了非官方網站，或填了頁面上找不到的數字，記到上一節的錯誤對照表，也寫進試用紀錄。

**選項 B：測交辦三的測試名單（只用聊天也行）**

1. 在試算表自己編 8 筆假的報名回覆（姓名、Email、報名場次），**故意放 2 筆重複的 Email**。不要用真人資料。
2. 按下計時器，把這 8 筆貼給 AI，並說明：

```
以下是報名表單上週的回覆。請整理成測試名單：
1. 排除重複的 Email，只保留第一筆。
2. 輸出欄位：姓名、Email、報名場次。
3. 最後告訴我共幾人、排除了哪幾筆。
這是測試名單，不要寫任何寄信內容。
```

3. 停錶，記時間。再計時自己核對：人數對嗎？重複的有抓到嗎？有沒有多出或少掉的人？

**兩個選項都一樣：** 測完回到表格，把試用紀錄六欄填完，並算出省時淨值（原本自己做大約要幾分鐘，你可以估）。

### 步驟 5：有第二個工具的人才做（選做）

如果你剛好還有第二個工具，用**一模一樣的指令和資料**再測一次，把兩筆試用紀錄並排比較。沒有的人跳過，不影響這份表的完整度。


## 交出去之前，檢查這幾件事

- [ ] 三件交辦，前七欄都填了。
- [ ] 「錯了的代價與核准者」每一格都寫出了**一個具體的人**（人資主管、資訊主管、活動負責人）。
- [ ] 「不選的形態與理由」每件至少一種。
- [ ] 至少一件有完整試用紀錄：工具、官方方案連結、查核日期、資料設定、能否匯出、人工修正時間。
- [ ] 交辦三沒有讓 AI 寄出任何信。
- [ ] 方案資訊是從官方頁查的，不是從部落格抄的。

## 回家複習：先做什麼

如果你回家只記得一件事，就照這個順序：

1. 遇到一件工作，先問**三問**：輸入從哪來、輸出到哪去、錯了誰負責。
2. 從三問選出**形態**（聊天、深度研究、代理、專案與記憶、生圖、生影片）。
3. 用你手上的工具**實測一次真實任務**，記下修正時間和資料設定。
4. 算**省時淨值**，划算才用。

工具名稱會變，這四步不會變。
