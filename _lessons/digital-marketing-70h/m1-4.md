## 開始之前

> 用具體購買經驗辨認顧客追求的進展，並把原話轉成待驗證的行銷切入點。

## 這一節你要做出什麼

前三節你看的是顧客「怎麼想」：哪個時刻在快思、哪個時刻在慢想，頁面用了哪些說服訊號，試握體驗的開頭、高峰、結尾怎麼安排。這一節往前再問一層：**顧客到底想靠這次購買，讓自己的生活往哪裡前進？**

這一節結束時，你手上會有兩樣東西：

| 要交的東西 | 用什麼資料 | 個人／小組 |
|---|---|---|
| 1. 柏翰的分析（情境、原話、要完成的工作、切入點、為什麼這樣寫），加上三人的共同工作，原話與推論分開標示 | 山徑咖啡品牌包：柏翰訪談、一則評論，再對照阿傑與麗芬 | 個人 |
| 2. 模組作業「我們的產品，顧客為什麼買」：你的一份訪談，以及小組的購買心理地圖 | 你們組的主題產品（巷口晨光早餐預訂） | 先個人訪談，再小組合併 |

**開始前先做一件事：** 用瀏覽器打開課程的山徑咖啡品牌包（單元頁連結 `assets/datasets/simulated-brand-pack.html`），找到阿傑、麗芬、柏翰三份訪談。下面會一直用到。這些都是課堂模擬資料，不是真實品牌的成效。

這一節只有四個新東西要記，其他都是操作：

1. **工作**：顧客在某個情況下「雇用」產品，想取得的進展。
2. **三個面向**：功能、情感、社會。
3. **工作句**：「在＿＿情況下，我想＿＿，以便＿＿」。
4. **原話和推論分開放**：一兩個人說的話，是待驗證的假設。


## 一、待完成的工作（JTBD）：顧客買的不是產品，是「進展」

### 1. 從一句話開始

「待完成的工作」英文是 Jobs to Be Done，簡稱 JTBD。這個說法由 Clayton Christensen 等人提出並推廣；本節主要依據 Christensen、Taddy Hall、Karen Dillon、David S. Duncan 在 2016 年 9 月《哈佛商業評論》（HBR）的文章〈Know Your Customers' "Jobs to Be Done"〉。

核心想法只有一句：**顧客在某個情境下，「雇用」一個產品，幫自己完成一件事、取得想要的進展。** 產品做得好，下次會再被雇用；做不好，就被「開除」，顧客改雇別的東西。

三個關鍵字拆開看：

- **情境**：什麼時候、在哪裡、手上有什麼限制。同一個人在不同情境下，要完成的工作可能完全不同。
- **雇用**：顧客不是「需要一把手沖壺」，而是「需要某件事被解決」，手沖壺只是被找來做這件事的其中一個人選。
- **進展**：顧客想從現在的狀態，走到一個更好的狀態。例如從「注水忽大忽小」走到「每次都倒得穩」。

### 2. 最有名的例子：早上的奶昔

哈佛商學院 Working Knowledge 在 2011 年刊出一篇文章（作者 Carmen Nobel），轉述 Christensen 常講的奶昔案例。一家速食連鎖想多賣奶昔，原本的做法是問顧客「奶昔要怎麼改，你會買更多」，改了口味、濃度，銷量沒有變化。

後來研究者換個做法：整天待在店裡，看誰在什麼時間、什麼情況下買奶昔。結果發現約 40% 的奶昔是在一大早賣出，買的多是要開車通勤、外帶就走的人。他們要的東西是：能單手拿、不弄髒上班衣服、能撐到中午不餓，還能讓又長又無聊的車程好過一點。奶昔剛好比貝果或甜甜圈更適合這件事。

這個例子要你記住兩件事：

1. **問「產品要怎麼改」，常常問不出真正原因；觀察和詢問「當時的情況」才問得出來。**
2. **競爭對手不只是同類產品。** 早上的奶昔，對手是貝果、甜甜圈。能在同一個情境完成同一件工作的東西，都是對手。

文章也提到，奶昔還能做另一份工作：讓爸媽買給小孩當點心。但這份工作要的是比較稀、很快喝完的奶昔，和通勤族要的濃稠奶昔相反。**同一類產品，工作不同，要做的改良也不同。**

### 3. 放到山徑咖啡

如果只問「顧客要什麼手沖壺」，答案會是規格：容量、材質、價格。但阿傑的訪談說的是另一件事：他用了兩年入門壺，想讓注水更穩，可是「看規格不知道差在哪」。他要完成的工作不是「買一把貴的壺」，而是「升級時不要買錯」。

這時山徑咖啡真正的對手，也不只是別家的壺，還包括阿傑現在的做法：看 YouTube 評測、到大型電商比價。

> **為什麼行銷人要懂這個？** 後面的社群開場、搜尋關鍵字、廣告文案、Email 主旨，都要說「顧客在意的那件事」。只講規格，顧客要自己把規格翻譯成「這對我有什麼用」；講對工作，顧客一看就知道這是在說他。


## 二、一個工作的三個面向：功能、情感、社會

Christensen 等人在文章中強調，工作不只是功能上的事，還有情感和社會的一面，而且這兩面有時比功能更有力。一份工作可以從三個面向看：

| 面向 | 問自己 | 山徑咖啡的例子 |
|---|---|---|
| **功能** | 顧客要「做到」什麼？ | 注水穩定、控制水流 |
| **情感** | 顧客想有什麼「感受」？ | 花錢升級不後悔、買得安心 |
| **社會** | 顧客想被別人「怎麼看」？ | 在社群推薦時，別人覺得他懂、說得有道理 |

**怕記不住？用一句話記：做到什麼、感覺怎樣、別人怎麼看。**

兩個提醒：

- **不是每份訪談都三面向齊全。** 找不到某一面向，就寫「這份訪談沒有出現」，不要硬湊。硬湊出來的，就是你的推論，不是顧客說的。
- **情感和社會通常藏在原話的語氣裡。** 阿傑說「我才敢買」，「敢」就是情感線索：他怕買錯。麗芬的訪談整理寫到她未來可能在社區教手沖，這是社會線索：她選的壺，以後可能要在別人面前用、推薦給別人。


## 三、工作句：在＿＿情況下，我想＿＿，以便＿＿

把一份工作寫成一句話，用這個句型：

> **在＿＿＿情況下，我想＿＿＿，以便＿＿＿。**

三格各填什麼：

| 格子 | 填什麼 | 常見錯誤 |
|---|---|---|
| 在＿＿情況下 | 具體情境：誰、什麼階段、有什麼限制 | 只寫「想買壺時」，太空泛 |
| 我想＿＿ | 顧客想完成的事（動作或判斷） | 寫成產品，例如「我想買山徑的 B 款」 |
| 以便＿＿ | 完成後得到的進展、狀態 | 寫成規格，例如「以便有 600ml 容量」 |

**檢查方法：把句子裡的「山徑咖啡」和任何產品名稱遮住，句子還成立嗎？** 成立，才是在寫工作；不成立，你寫的是產品。

對照一下：

- 不好：「在想買手沖壺時，我想買一把好壺，以便沖出好咖啡。」→ 情境太空泛，誰都可以套。
- 不好：「在逛山徑咖啡官網時，我想看到 B 款的規格，以便下單。」→ 寫的是品牌和產品，不是顧客的進展。
- 好：「在已用入門壺兩年、想讓注水更穩的情況下，我想在多花錢前親手確認哪把壺的重量和壺嘴適合我，以便升級時不買錯。」→ 有情境、有想做的事、有進展。


## 四、原話和推論：最容易混在一起的地方

這一節最重要的習慣是：**顧客說的，和你想的，分開放。**

### 1. 怎麼分？用一個問題判斷

> **這句話，我能在訪談紀錄裡逐字找到嗎？**

- 找得到，一字不差 → **原話**。用引號標起來。
- 找不到，是你根據原話想出來的 → **推論**。
- 還沒有人說過、但你需要知道的 → **待確認**。

例如阿傑：

- 【原話】「能先拿在手上試，我才敢買。」
- 【推論】阿傑怕買錯，試握能降低他的不安。（他沒有說「怕」，是品牌包「決策障礙」欄寫了怕買錯壺嘴與重量，加上「才敢」兩字推出來的。）
- 【待確認】試握要不要付費？品牌包沒有寫。阿傑自己也不確定，這正是他的決策障礙之一。

你可以直接在每一行前面加上【原話】【推論】【待確認】三種標籤，這樣交作業或小組合併時，一眼就看得出來。

> **品牌包裡的「情境」「目前替代方案」「決策障礙」算什麼？** 這些是訪談整理者寫的摘要，不是顧客逐字說的話。引用時寫「訪談整理寫到……」，不要加引號當成原話。只有「原話」欄和評論，才是顧客的話。

### 2. 一兩個人說過的話，是假設，不是結論

阿傑說想先試握，不代表所有顧客都想試握。只有一兩個人說過的話，都要當成**待驗證的假設**。寫切入點時，就寫成「待驗證」，並說明之後要怎麼確認（例如多訪談幾位、看更多評論、之後的模組用數據檢查）。

這不是不相信顧客，而是避免行銷團隊把一個人的意見，當成所有人的需求，花錢做錯方向。


## 五、痛點轉換：原話 → 工作 → 切入點

找到痛點後，不是直接寫「我們的壺很穩」。要走三步：

1. **原話的痛點**：顧客用自己的話說出卡住的地方。
2. **要完成的工作**：把痛點放回情境，問「他卡住，是因為想完成什麼？」寫成工作句。
3. **行銷切入點**：品牌可以從哪個角度，幫他完成這份工作。

切入點的三個要求：

- **用顧客的語言**：顧客說「看規格不知道差在哪」，切入點就從「看規格看不出差別」講起，不要改成「多項專業參數全面升級」。
- **對應工作，不是產品規格**：講「讓你升級不買錯」，不是講「304 不鏽鋼」。
- **真實、不誤導**：品牌沒有的東西不能說有。例如試握收不收費，品牌包沒寫，切入點就不能寫「免費試握」，要列為待確認。


## 六、示範：阿傑與麗芬

下面用課程指定的兩份訪談，示範完整寫法。每人一小段，欄位固定是：**情境、原話、要完成的工作、切入點、為什麼這樣寫**。

### 阿傑

**情境：** 訪談整理寫到：32 歲，行銷企劃，已使用入門壺兩年，想改善注水穩定度；目前看 YouTube 評測、再到大型電商比價；怕買錯壺嘴與重量，不確定門市試握是否要付費。

**原話：** 「我知道貴的壺可能比較穩，但看規格不知道差在哪。能先拿在手上試，我才敢買。」

**要完成的工作：** 在已用入門壺兩年、想讓注水更穩的情況下，我想在多花錢前親手確認哪把壺的重量和壺嘴適合我，以便升級時不買錯。

**切入點（待驗證）：** 「規格看不出差別？先拿在手上倒一次，再決定。」把 20 分鐘試握與注水體驗，說成「升級前的確認」，而不是門市服務清單上的一項。前提是品牌先把試握是否收費寫清楚（待確認）。

**為什麼這樣寫：** 工作句的情境來自訪談整理，「確認重量和壺嘴」來自他的決策障礙，「不買錯」是從「才敢買」推論出來的情感面。切入點直接借用他的話「看規格」「拿在手上」，對應的是「確認適不適合」這份工作，不是壺的材質。試握收費沒寫清楚，本身就是他的障礙，所以列為待確認，不自己補上「免費」。

### 麗芬

**情境：** 訪談整理寫到：45 歲，咖啡興趣社群成員，想買第二把壺，未來可能在社區教手沖；目前在 Facebook 社團問其他使用者；怕商品介紹偏專業，希望有人直接比較三款的使用難度。

**原話：** 「我想知道新手用哪一把最不容易失手，不想只聽材質多高級。」

**要完成的工作：** 在想買第二把壺、未來可能在社區教新手手沖的情況下，我想知道哪一把讓新手最不容易失手，以便選得安心，日後推薦給別人時也說得出理由。

**切入點（待驗證）：** 「新手用哪一把最不容易失手？」做一份三款的使用難度比較，用「失手」「好不好上手」這種說法，而不是材質等級。品牌包寫到目前商品頁沒有「適合哪種沖煮習慣」的比較表，這正是缺口。

**為什麼這樣寫：** 「最不容易失手」「不想只聽材質多高級」是她的原話，切入點直接沿用。「推薦給別人時說得出理由」是推論：她沒說這句，但訪談整理寫到她未來可能在社區教手沖、目前在 Facebook 社團問其他使用者，這兩條線索指向社會面向。這一點只有她一人出現，要標成推論。

### 兩人的暫定共同工作

**共同工作（推論）：** 在要換一把更合用的手沖壺、但看規格或材質介紹看不出差別的情況下，我想用自己看得懂的方式，確認哪一把適合我的程度，以便花錢不後悔。

**三個面向各在哪裡：**

- **功能**：確認哪一把適合（阿傑看重量和壺嘴，麗芬看新手好不好上手）。兩人都有。
- **情感**：不後悔、安心（阿傑的「才敢買」、麗芬的訪談整理：怕商品介紹偏專業）。兩人都有，但「不後悔」是推論。
- **社會**：只在麗芬出現（可能在社區教手沖）。阿傑沒有，所以共同工作句不放社會面。

**為什麼是「暫定」：** 只有兩個人。等加上柏翰，再看這句話還站不站得住。


## 七、練習：柏翰的分析與三人共同工作（要交）

**練習個人完成。** 先不要看本節最後的參考寫法。

### 練習資料（品牌包）

- 訪談整理：柏翰，28 歲，產品設計師。第一次從細口壺升級控流壺。目前收藏多支評測影片，自己做筆記。不信任只呈現最好一次的示範，在意比較方法是否一致。
- 原話：「我會看實測影片，但如果沒有標注同一個人、同一個水量，影片也很難比較。」
- 評論：「影片有幫助，希望每款都用一樣方式測。」
- 對照用的品牌事實：三款商品頁都有容量、材質與價格，但**只有一款提供出水影片**；沒有「適合哪種沖煮習慣」的比較表。

### 步驟

**第 1 步：寫情境。**
從訪談整理抄出柏翰的處境，寫成一兩句。記得寫「訪談整理寫到」，不要加引號。

**第 2 步：寫原話，兩句都要。**
同時引用訪談「同一個人、同一個水量」那句，和評論「影片有幫助，希望每款都用一樣方式測」。這兩句都可以逐字找到，所以加引號、標【原話】。注意：評論不一定是柏翰寫的，要寫明「一則評論」，不要說成柏翰說的。

**第 3 步：寫工作句。**
用「在＿＿情況下，我想＿＿，以便＿＿」。卡住時問自己：

- 情況：他是第一次升級什麼？他現在靠什麼做判斷？
- 我想：他看影片時想做到什麼？（提示：不是「看影片」本身）
- 以便：比較清楚之後，他得到什麼？他不信任什麼？

寫完做遮名檢查：拿掉任何品牌和產品名，句子還成立嗎？

**第 4 步：把「測試不一致」的痛點轉成一個待驗證的方向。**
寫一項內容或體驗方向，要用柏翰的語言、對應他的工作，並寫出「這是待驗證的」以及「之後要怎麼確認」。可以想想：品牌目前只有一款有出水影片，這和他的痛點有什麼關係？

**第 5 步：寫「為什麼這樣寫」。**
說明工作句每一格從哪來：哪些是原話、哪些是訪談整理、哪些是你推論的。

**第 6 步：比較三份訪談，寫三人的共同工作。**
先在紙上列三行：

| | 阿傑 | 麗芬 | 柏翰 |
|---|---|---|---|
| 他想比較什麼？ | | | |
| 現在用什麼方法比較？ | | | |
| 卡在哪裡？ | | | |

找出三人都有的地方（共同點），和只有一兩人有的地方（差異）。共同點寫進共同工作句；差異另外列出來，不要硬塞進句子。最後，每一句都標上【原話】【推論】或【待確認】。

### 交件前自我檢查

- [ ] 兩句原話都有引用，且一字不差、加了引號
- [ ] 評論沒有被寫成柏翰本人說的
- [ ] 工作句有情境、想做的事、進展三格；遮掉產品名仍成立
- [ ] 切入點用顧客的話，對應工作，不是規格
- [ ] 切入點寫明「待驗證」，並寫出之後怎麼確認
- [ ] 沒有寫品牌包裡沒有的事實（例如試握收不收費）
- [ ] 共同工作句有分開標示原話與推論
- [ ] 有寫出三人的差異，不只寫共同點

### 參考寫法（自己寫完再對照）

這只是一種寫法。你的句子不必一樣，只要每一格都講得出依據就可以。

> **柏翰**
>
> **情境：** 訪談整理寫到：28 歲產品設計師，第一次從細口壺升級控流壺；目前收藏多支評測影片、自己做筆記；不信任只呈現最好一次的示範，在意比較方法是否一致。
>
> **原話：** 訪談：「我會看實測影片，但如果沒有標注同一個人、同一個水量，影片也很難比較。」一則評論：「影片有幫助，希望每款都用一樣方式測。」
>
> **要完成的工作：** 在第一次從細口壺升級控流壺、只能靠評測影片比較的情況下，我想看到三款用同一套方法測出來的差異，以便自己判斷哪一把真的比較好控流，而不是被最好看的一次示範說服。
>
> **切入點（待驗證）：** 「同一個人、同一個水量，三款一起倒給你看。」做三款同條件的出水對照：畫面標注沖煮者與水量，呈現不只一次的注水。品牌包寫到目前只有一款有出水影片，三款之間無法比較，這是缺口。驗證方式：這只來自一份訪談加一則評論，之後要多問幾位正在考慮升級的人，「比較方法一致」對他們重不重要。
>
> **為什麼這樣寫：** 「同一個人、同一個水量」「一樣方式測」直接沿用原話，切入點也用他的詞。工作句的「只能靠評測影片」來自訪談整理的替代方案；「不被最好看的一次示範說服」來自決策障礙。「自己判斷」是我的推論：他收藏影片、自己做筆記，看得出他想自己下判斷，而不是聽別人的結論。

> **三人的共同工作**
>
> **共同點：**
> - 三人都想在買之前比較不同壺之間的差別，但手上的資訊無法直接比較。阿傑：【原話】「看規格不知道差在哪」；麗芬：【原話】「不想只聽材質多高級」；柏翰：【原話】「影片也很難比較」。
> - 三人都在用品牌以外的方法自己比較：YouTube 加電商比價、FB 社團、收藏影片做筆記（訪談整理）。
>
> **差異：**
> - 想比較的東西不同：阿傑要親手確認重量和壺嘴；麗芬要新手好不好上手；柏翰要測試方法一致。
> - 社會面只在麗芬出現（可能在社區教手沖）。
>
> **共同工作句（推論）：** 在要換一把更合用的手沖壺、但規格、評測與他人意見都無法直接比較的情況下，我想用一致、看得懂的方式比較不同壺在實際使用時的差別，以便選到適合自己程度的那一把，花錢不後悔。
>
> **待確認：** 三人共同在意「比較」，但這只來自三份訪談。是不是多數考慮升級的顧客都卡在這裡，還要更多訪談或資料確認。試握是否收費，品牌包沒有寫。


## 八、怎麼訪談：問「上一次」，不問「為什麼」

模組作業要你自己找人訪談。這一段教你問出**具體事件**，而不是空泛意見。

### 1. 為什麼不問「你為什麼買」

問「你為什麼買」，對方會給你一個整理過、聽起來合理的答案，例如「因為方便」「因為品質好」。這些話很難用，因為每個品牌都可以說自己方便、品質好。

改成問**最後一次購買的具體經驗**，對方會回想當時的時間、地點、在煩惱什麼、比較了什麼。真正的工作，就藏在這些細節裡。奶昔案例也是這樣：問「奶昔要怎麼改」問不出來，看「當時的情況」才看得出來。

### 2. 核心三題（模組作業也用這三題）

1. **上一次決定買這類產品時，發生了什麼事？**
2. **當時考慮過哪些替代做法？**
3. **最後讓你決定的是什麼？**

### 3. 兩個追問（回答太概括時用）

- **當時想解決什麼問題、想達到什麼狀態？**
- **如果沒買，你會怎麼辦？**

第二個追問特別有用：答案常常就是你真正的競爭對手。例如阿傑沒買的話，會繼續看 YouTube 和比價；麗芬會繼續在社團問人。

### 4. 對方回答太空泛時，怎麼拉回具體事件

| 對方說 | 你可以接著問 |
|---|---|
| 「就方便啊。」 | 「那一次是哪一天？那天早上本來打算怎麼處理？」 |
| 「通常都會……」 | 「我們先只聊最近那一次，好嗎？那次是什麼情況？」 |
| 「品質比較好。」 | 「你那時候是怎麼看出品質比較好的？當時在看什麼？」 |
| 「不知道，就買了。」 | 「買之前那一兩天，有發生什麼事讓你想到要買嗎？」 |
| 「我覺得大家應該都會想要……」 | 「先不管大家，你自己那一次是怎樣？」 |

訪談時記得：

- **不推銷、不糾正**。對方說的不合你的預期，正是你要記下來的地方。
- **不提示答案**。不要問「你是不是因為怕賣完才預訂？」，改問「最後讓你決定預訂的是什麼？」
- **先徵求同意**。說明是課堂作業，問對方可不可以記筆記或錄音；不要記下對方不想公開的個人資料。

### 5. 現場怎麼記

準備一張紙或一個文件，分三欄：

| 原話（逐字，加引號） | 我的推論 | 待確認 |
|---|---|---|
| | | |

訪談當下只要盡量把原話寫進第一欄，寫不完就先記關鍵詞，訪談後馬上補。推論和待確認，可以訪談結束後再填。這樣小組合併時，就不會分不清哪句是對方說的、哪句是你想的。


## 九、模組作業：我們的產品，顧客為什麼買

你們組的主題產品是課程備用產品卡 1「巷口晨光早餐預訂」：社區烘焙坊的早餐麵包盒，單盒 NT$80～180，前一天預訂、隔日上午取貨，主要轉換是完成隔日早餐預訂。

### 1. 個人準備：訪談一位

**找誰：** 買過、或認真考慮過「預訂早餐」這類服務的人。不一定要是巷口晨光的顧客，可以是用過連鎖早餐店預點、社區麵包店預訂，或認真考慮過但最後沒訂的人。同事、朋友、家人都可以，只要他有具體的一次經驗。只是「覺得聽起來不錯」、從來沒有實際考慮過的人，不算。

**用什麼問：** 核心三題，換成早餐的說法：

1. 「上一次你決定先預訂早餐（或認真考慮要不要預訂）的時候，發生了什麼事？」
2. 「那時候你還考慮過哪些做法？例如當天早上再買、去哪一家、乾脆不吃？」
3. 「最後讓你決定（訂或不訂）的是什麼？」

回答太概括時，追問：「那時候想解決什麼問題？希望早上變成什麼樣子？」「如果沒有預訂，你那天早上會怎麼辦？」

**記得帶：** 前三節的成果：購買時刻判讀表、說服訊號清單、峰終草案。訪談後對照看：對方描述的哪個時刻，符合你判讀表裡的快思或慢想？對方提到的哪個東西，是你清單上的說服訊號？

> **卡上的顧客原話不是你的訪談。** 產品卡寫了「我最怕到店才知道想吃的賣完」等句子，那是卡片提供的線索。你可以拿它當訪談前的猜想（例如：「也許有人怕賣完」），但**不要問對方是不是怕賣完**，也不要把卡上的話寫成你的訪談原話。如果對方自己說出類似的話，那才是你的原話。

### 2. 小組討論：合併訪談、畫購買心理地圖（25 分鐘）

課程沒有規定地圖要畫在紙上還是簡報上，你們組可以直接畫在小組的 Google 簡報或 Canva 簡報（之後本來就要放進企劃書），或先用紙畫再拍照放進去。

**地圖怎麼排：** 橫向放關鍵購買時刻，逐格往下填。

| | 時刻 1 | 時刻 2 | 時刻 3 | 時刻 4 |
|---|---|---|---|---|
| 這個時刻顧客在做什麼 | | | | |
| 偏 System 1、System 2，或兩者都有 | | | | |
| 有真實依據的影響力原則或偏誤 | | | | |
| 依據（哪份訪談、原話或訪談整理） | | | | |

下面是用山徑咖啡做的一格示範，讓你看填法（巷口晨光的地圖要用你們自己的訪談填）：

| | 決定要不要升級前，先找人問 |
|---|---|
| 這個時刻顧客在做什麼 | 麗芬在 Facebook 社團問其他使用者（訪談整理） |
| 偏 System 1、System 2，或兩者都有 | 兩者都有：主動比較是慢想，但把判斷交給其他使用者是省力的捷徑（推論） |
| 有真實依據的影響力原則或偏誤 | 社會認同（推論） |
| 依據 | 訪談整理的「目前替代方案：在 Facebook 社團問其他使用者」 |

填「影響力原則或偏誤」時，**只填有訪談依據的**。訪談沒提到稀缺，就不要因為「早餐會賣完」聽起來像稀缺，就自己填上去，那是紙上作業。

**地圖下方，再寫：**

- **共同 JTBD 句子**：用「在＿＿情況下，我想＿＿，以便＿＿」。
- **三欄分開**：原話／推論／仍缺的證據。

**最後 10 分鐘：** 選出一個最值得測試的心理槓桿或行銷切入點。選的標準：訪談裡有依據、對應你們的共同工作、說了不會誤導顧客。

### 3. 上台分享（每組 3～5 分鐘）

展示一張購買心理地圖，講四樣東西：

1. 一個關鍵時刻
2. 一句顧客原話
3. 一個待完成的工作
4. 最值得測試的切入點

並指出哪些來自訪談、哪些是小組推論。

### 4. 講師的四項判準（上台前自己先對一次）

- [ ] 訪談是否來自**具體購買事件**（有時間、有情況，不是「通常」「大家」）
- [ ] 是否**保留顧客原話**（逐字、加引號）
- [ ] 工作句是否**包含情境與進展**
- [ ] 心理槓桿或切入點是否**真實且不誤導**（有依據，品牌做得到）

### 5. 放進小組企劃書

把購買心理地圖、JTBD 句子、最值得測試的切入點，放進小組企劃書第 1 段「顧客心理」，這次加 1～2 頁。保留訪談來源、原話、推論和待確認事項，不要整理到只剩結論。之後第二模組會拿這張購買心理地圖當輸入，第三模組做「我們的產品往哪個方向推」時也要帶著它，所以原話和推論分得越清楚，後面越好用。


## 十、常見錯誤對照

| 錯誤 | 為什麼不行 | 改成 |
|---|---|---|
| 工作句寫成「我想買巷口晨光的麵包盒」 | 寫的是產品，不是工作 | 遮掉品牌名，寫顧客想完成的事 |
| 把自己的猜測加上引號 | 小組會以為顧客真的這樣說 | 只有逐字找得到的才加引號 |
| 訪談問「你為什麼會預訂？」 | 得到整理過的漂亮答案 | 問「上一次預訂那天發生了什麼事？」 |
| 一個人說了，就寫成「顧客都……」 | 一兩人說的是假設 | 寫「待驗證」並說明怎麼確認 |
| 切入點寫「多種口味任你選」 | 是產品特色，沒對應工作 | 用顧客原話，對應他想要的進展 |
| 地圖每格都填滿原則 | 沒依據的原則是紙上作業 | 沒依據就空著，寫在「仍缺的證據」 |


## 十一、回家複習：照這個順序做

1. **先讀第一、三節**（約 10 分鐘）：記住「雇用產品取得進展」和工作句三格。
2. **讀第四節**，練習給阿傑的三句話各貼一個標籤：【原話】【推論】【待確認】。
3. **自己寫柏翰的分析**（第七節步驟 1～6），寫完才對照參考寫法。
4. **準備訪談**：把第九節的早餐版核心三題抄在紙上，旁邊抄第八節的「拉回具體事件」問法。
5. **約一位受訪者**，訪談後當天把原話補齊。
6. **帶著訪談紀錄和前三節成果**，去和組員合併、畫地圖。


## 一頁速記卡

- **JTBD**：顧客在某個情境下「雇用」產品，取得想要的進展。
- **三面向**：做到什麼（功能）、感覺怎樣（情感）、別人怎麼看（社會）。
- **工作句**：在＿＿情況下，我想＿＿，以便＿＿。遮掉產品名仍成立。
- **訪談三題**：上一次發生什麼事？考慮過哪些替代做法？最後讓你決定的是什麼？
- **兩個追問**：想解決什麼、想達到什麼狀態？沒買的話會怎麼辦？
- **痛點轉換**：原話 → 工作 → 切入點（用顧客的話、對應工作、不誤導）。
- **判斷原話**：逐字找得到才是原話。一兩人說的，都是待驗證的假設。
