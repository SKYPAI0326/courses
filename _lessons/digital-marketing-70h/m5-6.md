## 2. 先記住四個觀念

### 觀念一：E-E-A-T 是「檢查可信度的四個角度」，不是分數

E-E-A-T 出自 Google《搜尋品質評估指南》（Search Quality Rater Guidelines，本講義查證的是 2025-09-11 版）。這份指南是給 Google 的「搜尋品質評估員」用的：Google 請人實際看搜尋結果、評估頁面品質，用來檢查搜尋系統表現好不好。

四個字母分別是：

| 面向 | 英文 | 白話問題 | 例子 |
|---|---|---|---|
| 經驗 | Experience | 寫的人**親自用過、做過**嗎？ | 親手用過手沖壺的人寫的心得，比沒用過的人寫的「評測」可信 |
| 專業 | Expertise | 寫的人有沒有這個主題需要的**知識或技能**？ | 電路配線建議，電工寫的比單純的老房子愛好者可信 |
| 權威 | Authoritativeness | 寫的人或網站是不是這個主題**大家會去找的來源**？ | 店家自己的社群頁，可能就是「現在有什麼在賣」的權威來源 |
| 可信 | Trust | 這一頁**正確、誠實、安全、可靠**嗎？ | 網路商店要有安全的付款與可靠的客服 |

**記法：可信（Trust）在正中間，另外三個是用來支撐可信的。** 指南原文說，可信是 E-E-A-T 裡最重要的一項，因為不可信的頁面無論看起來多有經驗、多專業、多權威，E-E-A-T 都是低的。

三件很多人誤會的事，一定要分清楚：

1. **E-E-A-T 本身不是一個特定的排名因素。** Google「有用內容指南」寫明，E-E-A-T 不是特定排名因素；Google 的系統是用多種訊號去找出看起來有好 E-E-A-T 的內容。
2. **評估員不控制排名。** 評估員的評分用來檢查系統是否運作良好，不會直接放進排名演算法。
3. **沒有可以自己算的總分。** 網路上看到「E-E-A-T 分數 85 分」之類的說法，都不是 Google 的東西。這一節做的四列檢查，是幫你找出「頁面已經有什麼、還缺什麼」，不是打分數。

**最重要的禁忌：不能虛構。** 為了「看起來有專業」而編一個資深咖啡師的名字、編證照、編「上百位顧客體驗過」，會直接破壞可信。Google 的有用內容指南也把捏造的作者身分（例如 AI 生成的大頭照、編造的名字、不實資歷）列為欺騙。所有「可補的做法」都必須是**店家真的有、真的做得到**的事。

### 觀念二：YMYL 決定「需要多高的可信度」

YMYL 是 Your Money or Your Life（你的錢或你的命）的縮寫，指可能大幅影響人的**健康、財務、安全，或社會福祉**的主題，例如醫療、投資、貸款。Google 對這類主題會更重視 E-E-A-T。

手沖壺商品頁和門市體驗頁不是明顯的 YMYL 主題，不需要像醫療文章那樣嚴格。但它仍然是賣東西、收預約的頁面，所以「誰在經營、怎麼聯絡、資料怎麼處理」這些可信訊號還是要有。

### 觀念三：誰、怎麼、為什麼（Who, How, Why）

Google 有用內容指南提供一個簡單的自我檢查：

- **誰（Who）**：讀者看得出是誰做的嗎？讀者會期待看到作者時，有沒有標出來？
- **怎麼（How）**：讀者看得出這份內容是怎麼產生的嗎？例如影片怎麼拍、體驗流程怎麼進行。如果用了 AI 或自動化，而讀者合理會問「這是怎麼做出來的」，就應該說明 AI 用在哪裡、為什麼有幫助。
- **為什麼（Why）**：這份內容主要是為了幫助讀者，還是為了在搜尋排名上取巧？

你做四列檢查時，「缺少訊號」常常就落在「誰」和「怎麼」這兩題。

### 觀念四：反向連結要看「怎麼來的」，不是看「有幾條」

**反向連結（Backlink）**：別的網站上，連到你網站的連結。
**錨點文字（anchor text）**：連結上那串可以點的文字。例如一篇文章寫「推薦你看[台北手沖壺試握](https://example.com)」，「台北手沖壺試握」就是錨點文字。

反向連結常被當成「別人推薦你」的證據，所以有人會用錢或交換去「製造」推薦。判斷一條連結或一個合作好不好，用這四項：

| 品質判斷 | 要問的問題 |
|---|---|
| ① 主題相關 | 對方網站的主題、讀者，跟我們的內容有關嗎？ |
| ② 編輯理由 | 對方是因為內容有用而**自己決定**提到我們，還是因為收了錢或被要求？ |
| ③ 對對方讀者有用 | 對方的讀者看到這份資料，會得到幫助嗎？ |
| ④ 取得方式正當 | 有沒有用錢、商品、服務或互換連結去「換」連結？ |

連結數量、第三方網域分數，只是**線索**，不是答案。

**記法：四項都說得通，才是好的站外信任。** 只要④出問題（用錢或交換換連結），其他三項再好也不行。


## 3. Google 不允許的做法：一次看懂

接下來會遇到很多政策名詞。你不用背英文，只要能把情境對到下面這張表。

### 3.1 連結垃圾（link spam）

Google「垃圾內容政策」把**主要目的是操縱搜尋排名**而建立的連結，叫做連結垃圾。和本節有關的例子：

| 做法 | 白話 | 本節情境裡的樣子 |
|---|---|---|
| 買賣連結 | 付錢買連結、或用商品／服務換連結 | 付 NT$9,000 在別人舊文章加連結 |
| 過度交換連結 | 「你連我、我連你」，或只為互連而做的合作頁 | 「兩邊一起上線」的互放連結 |
| 自動化建連結 | 用程式或服務大量產生連到自己的連結 | — |
| 文章或新聞稿塞最佳化錨點文字 | 在客座文章、新聞稿、業配文裡，放刻意挑選關鍵字當錨點的連結 | 「可自訂錨點文字的連結」 |
| 低品質目錄 | 以收錄連結為主、對讀者沒幫助的名錄或書籤網站 | 付年費刊登、附三個自訂錨點連結的名錄 |

**付費連結不是一律違規。** 政策也說，用於廣告或贊助的買賣連結是網路的正常經濟活動，只要那條連結有加上標示：

- `rel="sponsored"`：標示這是廣告或付費刊登的連結（Google 偏好用這個）。
- `rel="nofollow"`：備用的標示，表示網站不希望 Google 把這條連結當成一般的推薦。過去付費連結建議用它，現在仍可接受。

你不會寫程式也沒關係。這兩個標示是**對方網站**寫在連結程式碼裡的，長這樣：

```html
<a href="https://example.com/products/riverline-700" rel="sponsored">溪線 700 手沖壺</a>
```

### 3.2 客座文章（guest post）

在別人的網站或專欄發表文章。**客座文章本身不違規**；若內容是為了服務對方的讀者、由對方編輯審核，就是正常的內容合作。會出問題的是：文章的主要目的是塞進帶最佳化錨點文字、會傳遞排名的連結。

### 3.3 網站聲譽濫用（site reputation abuse）

在一個已經很有名的網站上，放第三方內容，**主要是想借那個網站的排名訊號**，讓這份內容排得比自己放還前面。Google 的例子是：教育網站放第三方的發薪日貸款贊助評論、醫療網站放和主題無關的「最佳賭場」廣告頁。

套到咖啡：如果一個寵物用品網站願意收錢，替你放一整頁「台北手沖壺推薦」，那一頁和它的讀者、主題都無關，只是借它的名氣，就落在這個範圍。

### 3.4 大量內容濫用（scaled content abuse）

為了操縱排名而大量產生對讀者沒有價值的頁面，**不論是用什麼方法做的**。Google 明列的例子包括用生成式 AI 產出大量頁面卻沒有替讀者增加價值。

套到咖啡：用 AI 一口氣產出「大安區手沖壺推薦」「信義區手沖壺推薦」……幾十頁內容幾乎一樣的頁面，就是這種情況。

### 3.5 第三方網域分數（DA、DR）

DA（Domain Authority）、DR（Domain Rating）這類分數，是 SEO 工具公司自己估算的數字，**不是 Google 的指標**。不同工具、不同日期的數字也不一樣。

本課的處理方式：對方給你一個分數時，只把它當線索；**沒有寫明是哪個工具、哪一天測的，就標「待查」**。就算分數很高，主題不相關、要付錢買連結，判斷照樣是不接觸。


## 4. 步驟一：E-E-A-T 四列檢查

### 4.1 做法

1. 把頁面觀察紀錄（練習資料的「頁面信任訊號現況」）每一項，放進最適合的面向。一個觀察可以支撐不只一個面向，放在最直接的那一列即可。
2. 「已有訊號」只寫**資料裡真的看到的東西**。
3. 「缺少訊號」寫讀者會想知道、但頁面沒有的資訊。用「誰、怎麼、為什麼」去想。
4. 「可補的真實做法」寫店家**真的做得到、而且是事實**的補法。不確定店家有沒有這項資料時，寫「先確認門市是否有……，有才補」。

### 4.2 本講義的示範：溪線 700 商品頁（第 2 部分）

> 以下是本講義用第 2 部分資料做的示範，課堂示範的寫法可能略有不同，重點是看「怎麼想」。

| 面向 | 已有訊號 | 缺少訊號 | 可補的真實做法 |
|---|---|---|---|
| 經驗 | 有一支出水影片，影片文字寫明「700 ml 壺、500 ml 水量」 | 影片沒有拍攝日期與操作者；看不出是誰實際用過、在什麼情況下拍的 | 向門市確認實際拍攝日期與操作者；經本人同意後，補上「拍攝日期、操作者職稱」 |
| 專業 | 有基本規格（不鏽鋼、700 ml、價格） | 頁面沒有具名作者或內容負責人；沒有和另外兩款用同一組欄位比較，也沒有說明適合的沖煮習慣 | 標示真實的內容負責人（個人或團隊名稱）；用材質、容量、價格同一組欄位做三款比較表 |
| 權威 | 頁尾連到「關於山徑咖啡」，寫明為台北在地咖啡器具選品店 | 頁面上看不到外部來源對這款商品的提及或引用 | 先做出可被引用的資料（三款比較表），再接觸相關的教學網站或社群，由對方決定是否引用 |
| 可信 | HTTPS；客服 Email 與門市電話；隱私政策；更新日期 2026-10-20 | 沒有合作揭露說明（需先確認是否真的有合作） | 先確認此頁是否含任何贊助或聯盟連結；有的話補揭露，沒有就不用加 |

注意「可補的真實做法」裡沒有任何一句是「新增一位咖啡師推薦」「加上顧客好評」——因為資料裡沒有這些事實。

### 4.3 換你做：門市體驗頁（第 3 部分）

**對象**：`https://example.com/store-experience` 門市體驗頁（資料整理日期 2026-11-05）

| 觀察項目 | 頁面或網站上看到的內容 |
|---|---|
| 內容負責人 | 頁面標示「門市服務團隊整理」，沒有個人姓名。 |
| 更新日期 | 頁面未顯示更新日期。 |
| 關於頁 | 頁尾有「關於山徑咖啡」連結。 |
| 聯絡資訊 | 頁面顯示門市電話、客服 Email 與營業時間。 |
| 隱私政策 | 預約表單下方有隱私政策連結。 |
| HTTPS | 網址列顯示 `https://`。 |
| 合作揭露 | 頁面未出現合作或贊助內容。 |
| 體驗流程 | 頁面寫「20 分鐘試握與注水體驗」，沒有列出使用水量、器具清單或現場紀錄方式。 |

填這張表：

| 面向 | 已有訊號 | 缺少訊號 | 可補的真實做法 |
|---|---|---|---|
| 經驗 | | | |
| 專業 | | | |
| 權威 | | | |
| 可信 | | | |

卡住時，問自己這幾題：

- 經驗：一個想預約的人，看得出「現場實際會發生什麼」嗎？流程寫到多細？
- 專業：「門市服務團隊整理」回答了「誰」嗎？還缺什麼才回答得完整？
- 可信：預約表單會收個資，這頁有哪些訊號讓人敢填？哪一項跟商品頁不同、這頁沒有？
- 權威：頁面上有沒有任何外部來源提到這個體驗？

**自我檢查**

- [ ] 「已有訊號」每一格都能在上面的觀察表找到原文。
- [ ] 「可補的真實做法」沒有編造人名、資歷、體驗人數或評價。
- [ ] 不確定店家有沒有的資料，寫成「先確認……，有才補」。
- [ ] 沒有寫任何分數。


## 5. 步驟二：外部信任來源清單

### 5.1 八個欄位怎麼填

| 欄位 | 填什麼 |
|---|---|
| 情境 | 一句話描述收到什麼 |
| 對方與讀者 | 對方是誰、讀者是誰；資料沒寫就寫「未提供」 |
| 相關性 | 對方主題與讀者，和我們的內容有多相關（對應品質判斷①③） |
| 編輯理由 | 對方提到我們，是自己判斷內容有用，還是收錢或被要求？（對應②） |
| 付費或交換 | 照資料寫：有沒有付費、商品、名額、互換連結（對應④） |
| 判斷與判準 | 可接觸／不接觸／待查，加上**依據哪一條判準** |
| 既有資產 | 我們手上真的有、而且適合這個對象的資料 |
| 下一步 | 具體要做的事；**待查就寫出要核對的頁面、規則或合作條件** |

我們手上的既有資產只有三項，不能多寫：

1. 20 分鐘試握流程
2. 三款材質、容量、價格（杉影 600：不鏽鋼、600 ml、NT$1,680；溪線 700：不鏽鋼、700 ml、NT$2,380；稜峰 600：銅製、600 ml、NT$3,280）
3. 溪線 700 出水影片（700 ml 壺、500 ml 水量；只有這一款有影片）

### 5.2 三種判斷怎麼選

照順序問，問到哪一題就停在哪裡：

1. **對方要求用錢、商品、名額或互換連結，去換連結嗎？** → 是：**不接觸**（判準：取得方式不正當）。
2. **對方要求隱藏合作關係嗎？** → 是：**不接觸**。就算沒有收錢也一樣：只要我們提供商品、名額等任何好處，雙方就有利益關係，讀者有權知道。要求不揭露，等於請你一起對讀者隱瞞，直接破壞「可信」，也違反第四模組學過的合作揭露原則。
3. **主題相關、對對方讀者有用、由對方編輯決定，而且我們有適合的既有資產嗎？** → 都是：**可接觸**。
4. **有一項資料不足，無法判斷**（不知道讀者是誰、不知道規則、不知道對方是否真的存在、不知道分數怎麼來）→ **待查**，並寫出要核對什麼。

> **對方沒收錢但要求不揭露，怎麼判？**
> 看第 2 題。重點不在對方有沒有向你收錢，而在讀者會不會被誤導。可以在「下一步」加一句：「若對方改為願意清楚標示合作，再重新評估」，但以目前收到的條件，判斷是不接觸。

## 6. 步驟三：一封不要求回連的接觸稿

### 6.1 為什麼不要求回連

接觸稿（outreach）的目的，是讓對方知道「有一份資料可能對你的讀者有用」。要不要用、怎麼用、要不要放連結，是對方編輯的決定。只要信裡出現「請附上我們的連結」「刊登後請連回官網」，你就把「編輯理由」變成了「被要求」。

### 6.2 四個部分

| 部分 | 寫什麼 | 一句話檢查 |
|---|---|---|
| 相關內容 | 你在對方那裡看到什麼、為什麼聯絡 | 有沒有引用對方真的說過的話？ |
| 既有資產 | 你能提供的資料，只限已存在的三項；寫清楚範圍與限制 | 有沒有提到不存在的資料？ |
| 讀者用途 | 這份資料能幫對方讀者解決什麼問題 | 主詞是「讀者」還是「我們的商品」？ |
| 由對方決定 | 明說是否使用、怎麼使用、是否放連結都由對方決定 | 有沒有任何要求回連的字？ |

另外加兩件事：**表明身分與關係**（我們是賣這些商品的店），以及**誠實寫出資產限制**（例如只有一款有影片）。

## 8. 模組作業：顧客在搜尋什麼（你這週的個人準備）

### 8.2 小組討論時，本節學到的東西用在哪

小組討論的最後一行要寫「待查技術與站外事項」。用本節的眼光看巷口晨光，可能會寫到這類項目（請依你們的搜尋觀察調整，不要照抄）：

- **信任／體驗**：預訂頁沒有列出每日品項的更新時間，也沒說明售完時的替代方式（對應顧客原話「最怕到店才知道想吃的賣完」）。
- **站外**：地圖服務上的店家資訊（營業時間、取貨時間）是否和預訂頁一致。
- **站外**：公開評論有沒有店家回覆。
- **技術**：預訂頁能不能被搜尋到（5-5 的索引檢查）。

巷口晨光是社區烘焙坊，搜尋時常會出現地圖上的店家清單。Google 商家檔案說明在地排序主要看三個因素：**相關性、距離、知名度**。知名度會參考連到商家的網站數量和評論數，評論數多、評分高的店家有機會排得更前面。所以：

- **回覆評論**：Google 說明回覆顧客評論表示你重視他們的意見。
- **不買評論，也不以優惠換好評**：Google 的地圖內容政策禁止用金錢、折扣、免費商品或服務誘使顧客留評論，也禁止只挑滿意的顧客邀評。可以做的是邀請顧客依真實體驗留下評論，不附任何好處。
- **付費提升在地排名做不到**：Google 說明商家無法透過要求或付費提升自己的在地排名。

小組開新對話，貼上：實際搜尋觀察、產品事實來源、意圖地圖、改寫前後全文，並請 AI：

```
請依三項判準檢查這份成果：符合搜尋意圖、有原創資訊、每個新主張有來源。
每一項各指出一個清楚的地方和一個可以修正的地方，都要引用成果原句。
不要預測排名、流量或轉換。
```

小組自行選一處修正，把 AI 建議、人工修改與採用或不採用的理由，放進企劃書附錄的 AI 使用紀錄。

### 8.4 放進企劃書

第 4 段「搜尋」共 2 頁：

- 第 1 頁：意圖地圖與優先查詢。
- 第 2 頁：重點頁 Title、Meta、H1 改寫前後與來源，並保留「待查技術與站外事項」。

（本節的個人成果：E-E-A-T 檢查、信任清單、接觸稿，不放進企劃書。）


## 9. 面試時怎麼說你做過什麼

你沒有自己的網站，產品也是課堂模擬資料，這不影響你說清楚「你會怎麼判斷」。可以這樣講，記得主動說明是課堂模擬資料：

> 「在課程裡，我用 Google 搜尋品質評估指南的 E-E-A-T 四個面向，檢查一個模擬門市體驗頁，列出已有和缺少的信任訊號，以及店家做得到的補法。接著用主題相關、編輯理由、對讀者有用、取得方式正當這四項，判斷四個外部合作情境和一個自選候選類型：拒絕了付費買連結、要求不揭露合作的邀約，對資料不足的寫出要核對的規則。最後寫了一封不要求回連的接觸稿，只提供已存在的資料，再請 AI 找越界的句子，回到原始資料核對後自己決定怎麼改。」

如果被問「怎麼增加反向連結」，你可以回答：先做出別人願意引用的資料（例如比較表、方法說明、原創資料），再找主題相關的對象接觸，由對方決定是否引用；不買連結、不交換連結。


## 10. 一頁速查

| 看到…… | 想到…… |
|---|---|
| 「付 NT$X 就幫你加連結」 | 買賣連結 → 不接觸 |
| 「你連我、我連你」 | 交換連結，沒有編輯理由 → 不接觸此提議；有真實合作再各自依事實介紹 |
| 「可自訂錨點文字」 | 最佳化錨點文字 → 連結垃圾的訊號 |
| 「不要標示合作」 | 隱瞞利益關係 → 不接觸 |
| 「網域分數 78」 | 工具估計值，不是 Google 指標；沒寫工具與日期 → 待查；主題無關照樣不接觸 |
| 「是否引用由編輯決定」 | 有編輯理由 → 再看相關性與資產 |
| 有人提到你但沒附連結 | 未連結提及 → 看規則能否以品牌身分回覆，不要求對方補連結 |
| 想加一個「資深咖啡師推薦」 | 店裡真的有這個人、本人同意嗎？沒有就不能寫 |
| 想用 AI 一次產幾十頁地區頁 | 大量內容濫用 |
| 想送優惠換五星評論 | 違反地圖內容政策 |


## 11. 卡住時
