## 教學流程（Teaching Flow）

### 熱身 / Warmup（5 min）

<!--
講師備註（不進學員講義）：

本段重點是讓學員 5 分鐘內決定「演練組合」。
3 種組合對應 3 種實際業務情境、學員依自己最常遇到的情境挑——這才真能帶走。
避免學員花 10 分鐘決定「要跑什麼」。
-->

#### 快速決策：選演練組合 + 品牌（5 min）

你是**系列把關者**——這是 M4 最後一輪演練、為自己建立**完整品牌資產**（DNA + 3 張系列）。

**步驟 1｜挑 1 個品牌（2 min）**

三選一：

- **A 自家品牌**：你實際經營或服務的品牌（最有商業價值）
- **B 客戶品牌**：你最近接案的客戶品牌（最接近實戰）
- **C 主線 A 弄一下咖啡工作室**：課程預設範例（若 A/B 不適用）

**步驟 2｜從 3 種演練組合挑 1 組（3 min）**

| 組合 | 情境 | 3 張主題變量 | 適合誰 |
|---|---|---|---|
| **I 跨季節** | 年度行銷規劃 | 春 / 夏 / 秋 新品（同類商品、換季節）| 做快消品 / 餐飲 / 美妝 |
| **II 跨產品線** | 品牌陣列展示 | 主打 A / B / C 3 款不同產品 | 有多產品線品牌 / 手作店 |
| **III 跨活動週期** | 行銷日曆 | 新品上市 / 週年慶 / 會員專屬 3 個活動 | 做電商 / 服務業 / SaaS |

**快速判斷**：

- 你手上業務**一年會跑 4 季行銷** → **組合 I**
- 你品牌**有 3+ 核心產品** → **組合 II**
- 你每月都有**不同行銷主題** → **組合 III**
- 都不太符合 → 預設用**組合 I**（最通用）

**預期差異**：你挑的組合 + 品牌跟同學不會一樣——這是設計、每個人跑自己業務情境才有帶走價值。

### 演練 / Exercise（20 min）

<!--
講師備註（不進學員講義）：

20 分鐘分 3 階段：
- 階段 1 填 DNA（8 min）
- 階段 2 跑 3 張系列（10 min）
- 階段 3 驗收 C（2 min）

巡堂重點：
- DNA 是否具體（色票有 hex / 字族有名稱）——不具體立刻提醒補
- 3 張系列是否共享同 DNA——若看到某張配色偏離立刻提醒
- 驗收 C 的必要項是否全過；任一失敗要回修，不能用平均分數抵銷
-->

#### 階段 1｜填五段 Brand DNA（8 min）

參考 `courses/gen-image/assets/downloads/brand-dna-template.md`，使用同一套五段 schema：

| 段 | 內容 | 硬性要求 |
|---|---|---|
| 1 | 任務與受眾 | 用途、受眾、第一眼、感受與下一步 |
| 2 | 不可變項 | 色彩、光向、材質、構圖、商品／角色、後製字體；每項有驗收方式 |
| 3 | 可變項 | 列出允許範圍，指定本輪唯一主要變因 |
| 4 | 禁止帶入 | 第三方識別、reference 邊界、敏感屬性、正式文字 |
| 5 | 系列檢查 | 工具、來源、並排與第三人證據清單 |

**若真的來不及**：第 1／2／4 段不可省略；第 3 段只寫一個主要變因，第 5 段沿用範本清單。

**自我檢查（填完立刻自查）**：

- [ ] 第 1 段能讓第三人說出用途與受眾
- [ ] 第 2 段每個不可變項都有驗收方式
- [ ] 第 3 段只有一個主要變因
- [ ] 第 4 段已界定權利、reference 與正式文字邊界

---

#### 階段 2｜取得 3 張系列候選（10 min）

依你選的演練組合（I / II / III）、跑 3 張系列：

**組合 I 跨季節範例**：

- 第 1 張：{品牌}春季限定 {新品 A}
- 第 2 張：{品牌}夏季限定 {新品 B}
- 第 3 張：{品牌}秋季限定 {新品 C}

**組合 II 跨產品線範例**：

- 第 1 張：{品牌}主打 {產品 A}
- 第 2 張：{品牌}主打 {產品 B}
- 第 3 張：{品牌}主打 {產品 C}

**組合 III 跨活動週期範例**：

- 第 1 張：{品牌}新品上市
- 第 2 張：{品牌}週年慶優惠
- 第 3 張：{品牌}會員專屬活動

**每張流程**：貼模板 F → 取得候選 → AI 列差異線索 → 人工檢查。記錄實際耗時，不預設平台速度。

**品牌繼承 prompt 模板**（見 `prompt-templates.md` 模板 F）：

```
吃下以下品牌 DNA：
[貼完整 品牌小卡]

---

結構沿用：{固定骨架}
本輪唯一主要變因：{例：商品從抹茶換成柚子}
Reference 角色：{商品／構圖／品牌，各自只負責什麼}
必須保留：{不可變項}
可以改變：{可變項；本輪只啟用一項}
禁止帶入：{第三方識別、未授權元素、正式價格與法規文字}
正式文字：保留乾淨文字區，交由後製加入。

請依以上 DNA + 骨架 + 主題產出 1:1 L4 完稿。

【AI 差異盤點】產完只列待查位置，不要替作品宣告通過：
1. 哪些位置可能偏離「必須保留」？
2. 哪些位置可能超出「可以改變」或違反「禁止帶入」？
3. 哪些資訊無法從像素證明，必須由人或工具確認？
```

**3 張都要用同一份 DNA + 同一個骨架**——每輪只換一個主要變因。

> **預期差異**：3 張每次跑結果不同、AI 對「禁用清單」的遵守程度也會波動。逐張記錄實際違規項目，不預設遵守率；這是為什麼要跑驗收 C。

---

#### 階段 3｜驗收 C 跨張一致性檢核（2 min）

3 張跑完後，使用 `prompt-templates.md` 模板 G 先列差異線索：

```
請對剛才的 3 張系列（A / B / C）做品牌一致性自檢、對照以下 DNA：
[貼 品牌小卡]

逐項跨張比對：
1. 色彩與光向：指出可能偏離 Brand DNA 的區域。
2. 商品／角色：指出外觀、比例或材質可能漂移的位置。
3. 構圖：指出主體占比、留白與視線路徑差異。
4. 禁止清單：逐張列出可能違規的元素。
5. 正式文字：列出必須人工後製與校稿的位置。

最後輸出待查清單；實際通過與否由人類與工具證據決定。另確認 3 張只有指定的主要變因改變，並列出每一項要由取色、reference、來源紀錄、後製檔、並排或第三人盲評補足的證據。
```

**判定**：

- **所有必要項與證據通過** → 本 PRAC 合格、存檔進個人品牌資產庫
- **任一必要項失敗** → 只修缺口並重驗，不用總分平均放行
- **兩輪仍失敗** → 停止、留下陰性紀錄並回階段 1 補規格

---

### 分享 / Share（5 min）

#### 互相展示（3 min）

2-3 人一組、每人快速展示：

- **自家 品牌小卡**（口述 5 段要點、30 秒）
- **3 張系列**（並排展示、30 秒）
- **驗收 C 證據**（AI 線索、人工現象、取色／字型來源／第三人證據，30 秒）
- **挑其中最滿意的 1 張 + 最卡關的 1 張**（30 秒）

**同學回饋（互相給 30 秒）**：

- 你的 3 張看起來**像同品牌**嗎？（外部視角檢驗）
- DNA 有沒有**什麼段落可以更具體**？
- 若要再做第 4 張、**你建議什麼主題**？

#### 老師總結 + M5 預告（2 min）

- 統計全班「五段必要條件全過且有證據」的人數
- 挑 2-3 個**最完整的 DNA 範例**當全班示範
- **CH5-1 預告**：下個單元 30 分鐘跑完一次**完整閉環**——你今天產出的 DNA + 3 張系列就是 CH5-1 的起點。**全部存檔備份**。

## 商業情境案例（Case）

**角色**：主線 A 老闆（弄一下咖啡工作室）或學員自家品牌

**公司**：弄一下咖啡工作室（示範）或學員品牌

**任務**：

老闆在 CH4-3 學會填 DNA + 跑 3 張系列。現在他要為自己建立**第一份完整品牌資產**——作為未來所有行銷物料的基礎。

他挑了**組合 I 跨季節**——因為咖啡店最常做季節限定：

- 春：抹茶提拉米蘇拿鐵
- 夏：柚子氣泡美式
- 秋：焙茶拿鐵

目標：**3 張系列放一起、第三方認出「這是同個咖啡店的 3 個季節新品」**。

本單元教他：
- 填完整五段 Brand DNA
- 用 DNA + 骨架跑 3 張系列
- 驗收 C 跨張檢核
- 存檔為**個人品牌資產庫雛形**

**本單元要他學會**：

- M4 全技能整合應用（跨產業能力、多變體能力、品牌繼承能力合流）
- PM 系列把關者的實戰手感
- 建立長期可反覆使用的品牌資產（不是一次性）
- 與同學比對、讓外部視角檢驗系列感

**POV**：

主要走第二人稱「你」（學員為自家品牌建資產）。老闆示範是參照、你做的是自己的實戰。

## 動手練習題（Hands-on Exercise）

**題目**：

在 30 分鐘內完成**完整品牌系列演練**：

1. **熱身（5 min）**：挑 1 品牌 + 1 組合（跨季節 / 跨產品線 / 跨活動週期）
2. **演練（20 min）**：
   - 填五段 Brand DNA（8 min）
   - 取得 3 張系列候選（10 min，平台等待依實況記錄；不可用時走 OFFLINE-01）

3. **分享（5 min）**：互相展示 + 回饋

**預期成果**：

- 1 份完整五段 Brand DNA
- 3 張系列 L4 完稿（共享同 DNA + 同骨架）
- 1 份驗收 C 紀錄（AI 線索、人工必要項、取色／字型來源／第三人證據）
- 1 個**外部驗證結果**（同學能否辨認為「同品牌」）
- 1 組可進 CH5-1 整合實戰的**品牌資產雛形**

**完成標準**（self-check）：

- [ ] 品牌明確（自家 / 客戶 / 假想皆可）
- [ ] 演練組合明確（I / II / III 選 1）
- [ ] DNA 五段填完，第 2 段每項都有驗收方式
- [ ] 跑出 3 張系列（共享同 DNA + 同骨架、每輪只換一個主要變因）
- [ ] 系列檢查必要條件全過；任一失敗已回修或停止
- [ ] 至少 1 位同學確認「看起來像同品牌」
- [ ] DNA + 3 張系列**獨立備份**（CH5-1 會用）

**預期差異提醒**：

- 你的品牌、組合、DNA、系列跟同學完全不同——這是設計
- **不追求「跑得最漂亮的系列」、追求「放一起能被認出是同品牌」**
- 五段必要條件都不能省略；沒有用總分平均放行
- 今天產出是**個人品牌資產庫的雛形**——未來做新廣告從這份 DNA 開始、不再從零

## 常見錯誤 3 條（Common Pitfalls）

### 錯誤 1｜熱身花 10 分鐘決定演練組合

**錯誤現象**：

學員看到 3 種組合（跨季節 / 跨產品線 / 跨活動週期）、開始糾結「我到底該選哪個？」「跨季節會不會太簡單？」「跨產品線我只有 2 款產品怎麼辦？」——結果 10 分鐘過去了、還沒開始填 DNA。

**原因**：

**選擇癱瘓**。對初學者來說 3 選 1 已經太多。但演練的重點是「跑通流程」、不是「選最完美組合」。

**解法**：

**5 分鐘強制決策**（老師巡堂、超過 5 分鐘提醒）：

- 一年做 4 季行銷 → **選 I 跨季節**
- 品牌有 3+ 產品 → **選 II 跨產品線**
- 每月不同行銷主題 → **選 III 跨活動週期**
- **都不符合或選不定 → 預設 I**（最通用）

**心法**：**選哪個都會有收穫**——重點是跑完完整流程、體驗 M4 所有技能的整合。

---

### 錯誤 2｜跳過第 4 段「禁止帶入」

**錯誤現象**：

學員沒有寫第三方識別、reference 邊界、人物與正式文字限制就開始生成。候選可能帶入未授權 logo、包裝、人物特徵或不可控價格日期，整組不能放行。

**原因**：

第 4 段是權利與正式文字的停止條件。缺少它，就無法證明輸入與交付物可用。

扣 CH4-3 錯誤 3 的 PRAC 實戰版——在時間壓力下最容易被跳過、但跳過代價最高。

**解法**：

第 4 段必填：逐項寫第三方識別、reference 中不得複製的元素、不必要人物與敏感屬性、正式價格日期及法規文字。任何來源或權利不明就停止。

---

### 錯誤 3｜3 張系列主題變量設太多

**錯誤現象**：

學員挑組合 I 跨季節、但 3 張主題是：

- 第 1 張：春季抹茶**拿鐵**（杯裝飲品）
- 第 2 張：夏季柚子**蛋糕**（盤裝甜點）
- 第 3 張：秋季焙茶**禮盒**（包裝盒）

**3 張商品型態完全不同**——杯 / 盤 / 盒。結果：
- 第 1 張符合骨架 4（商品中心 + 道具環繞的杯子結構）
- 第 2 張難以套進骨架 4（盤子平面、道具環繞邏輯不同）
- 第 3 張更不適合骨架 4（盒子是靜物包裝、不是開放式飲品）

**驗收 C 第 4 項「骨架一致性」直接失敗**。

**原因**：

**變量失控**。系列演練的核心是**控制變量、換單一維度**：

- 組合 I 跨季節 → **商品類別保持一致、只換季節主題**（都是飲品類、或都是甜點類）
- 組合 II 跨產品線 → **3 產品結構相近**（都是杯裝、或都是盒裝）
- 組合 III 跨活動週期 → **商品本身一致、只換行銷主題**

**解法**：

**3 張主題的商品型態必須相近**：

- 組合 I 範例（飲品）：春抹茶拿鐵 / 夏柚子拿鐵 / 秋焙茶拿鐵（都是拿鐵類）
- 組合 II 範例（皂類）：玫瑰皂 / 薰衣草皂 / 檜木皂（都是單塊皂）
- 組合 III 範例（App）：notero 新品上市 / notero 週年慶 / notero 會員方案（都是同 App 不同訊息）

**心法**：**演練是控制變量測技能、不是炫技**。變量多 = 看不出 DNA 效果、失去演練意義。

### Q2（反思驗證｜系列資產價值）

請回答：

1. 你今天產出的 **品牌小卡 + 3 張系列**，**未來半年內**可以**重複使用多少次**？
2. 若下個月要做第 4 張，哪些條件允許沿用？哪些品牌、平台或用途變更會觸發重驗？
3. 版本化 DNA 與證據鏈相較於從零製作，實際節省在哪裡？

**預期答案要點**（至少命中 3 點算通過）：

1. **重複使用次數**：依實際行銷計畫計算，不預設固定張數
2. **下個月做第 4 張**：
   - 引用目前核准版本；品牌、平台或用途條件改變時更新並重驗
   - 每輪只換第 3 段指定的一個主要變因
   - 貼同份 DNA + 單一變因 → 取得候選 → 完成單張與系列檢查
3. **時間節省來源**：
   - 過去：記錄一張基準作品從需求到驗收的實際時間
   - 現在：用同一份 DNA 做下一張並記錄實際時間與修正輪數
   - **節省幅度**：用兩次紀錄計算，不先承諾固定百分比
4. **額外價值**（加分項）：
   - 系列一致性有可重複檢查的依據（每張都引用同一 DNA 版本，仍需逐張驗收）
   - 新員工 / 外包設計師可依 DNA 與證據紀錄接手，但仍要完成權限、來源與驗收交接
   - 品牌 **辨識度複利**——每次曝光都強化相同視覺記憶

**不及格的答案**：

- 「看情況」
- 「不確定能不能重複用」
- 沒算出具體使用次數
- 「還是要重畫設計」（違反本單元核心 — DNA 就是為了不用重畫）
