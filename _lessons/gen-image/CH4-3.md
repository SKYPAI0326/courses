## 教學流程（Teaching Flow）

### 看 / Observation（10 min）

<!--

開場用「有 DNA vs 沒 DNA」的對比讓學員立刻感受系列感的差異。
本段不實跑、用文字描述 3 張連續廣告的視覺結果就夠了。
目的是讓學員意識到「沒 DNA 就像僱了 3 個不同設計師、有 DNA 就像同個設計師跑 3 次」。

#### 開場情境（90 秒，純口述）

主線 A 弄一下咖啡工作室老闆準備做**春夏秋冬 4 季 × 3 張新品廣告 = 12 張**的年度行銷系列。

他已經在 CH4-1 學會跨業種套用、CH4-2 學會多變體。他覺得自己準備好了——但跑出 3 張後、發現**老闆自己的朋友問：「這 3 張是 3 個不同品牌嗎？」**

- 春季抹茶拿鐵：鼠尾草綠 + 奶油白 + 抹茶粉盤道具
- 夏季柚子氣泡：黃橘 + 白 + 柚子皮道具
- 秋季焙茶拿鐵：深棕 + 米色 + 乾茶葉道具

3 張結構都對（骨架 4 商品中心 + 道具環繞）、主題都是咖啡、但**看起來像 3 個不同品牌**——因為**配色、字體、道具、語氣**每張都照當季「感覺」跑、沒統一規範。

**缺的是什麼？品牌小卡——你品牌的視覺規格書、給 AI 看的**。

本單元教你：
- 填一份 品牌小卡（5 段）
- 每次跑新廣告都吃這份 DNA
- 跑完用系列檢查 3 問 做跨張一致性檢核

學完後、你跑 3-5-10 張都能**看起來像同一個品牌的 3-5-10 個商品**、不是 3-5-10 個不同品牌。

---

#### 對比展示｜有 DNA vs 沒 DNA（8 min）

> 本段用文字描述讓學員腦內想像 2 組連續廣告的差異。

**情境 A｜沒 DNA（各張自由發揮）**

主線 A 老闆跑春夏秋 3 張廣告、每張都自由選配色字體：

| 張次 | 商品 | 配色 | 字體 | 道具 | 語氣 |
|---|---|---|---|---|---|
| 春 | 抹茶拿鐵 | **鼠尾草綠 + 奶油白 + 白** | 明朝體 | 抹茶粉 + 湯匙 | 療癒、手作 |
| 夏 | 柚子氣泡 | **黃橘 + 白 + 天藍** | 黑體 | 柚子切片 + 冰塊 | 清爽、活力 |
| 秋 | 焙茶拿鐵 | **深棕 + 米 + 咖啡棕** | 手寫感 | 乾茶葉 + 木匙 | 沉穩、職人 |

**視覺感受**：3 張放一起像 **3 個咖啡店的廣告**——綠的、黃的、棕的、每張一個世界。

**情境 B｜有 DNA（所有張共用一份規格）**

主線 A 老闆寫了 品牌小卡：

- 風格 preset：日系職人
- 色票：primary 鼠尾草綠 #5a7a5a / accent 奶茶棕 #8a6a4a / bg 奶油白 #f5efe3
- 字族：主標明朝體 / 內文 Noto Sans JP
- 語氣：手作、職人、季節感、療癒（4 詞固定）
- 禁用：漸層、純黑、霓虹色、快時尚口號

同樣春夏秋 3 張、但**強制吃這份 DNA**：

| 張次 | 商品 | 配色 | 字體 | 道具 | 語氣 |
|---|---|---|---|---|---|
| 春 | 抹茶拿鐵 | **鼠尾草綠 + 奶茶棕 + 奶油白** | 明朝體 + 黑體 | 抹茶粉 + 湯匙 | 手作、職人、季節感 |
| 夏 | 柚子氣泡 | **鼠尾草綠 + 奶茶棕 + 奶油白** | 明朝體 + 黑體 | 柚子切片 + 湯匙 | 手作、職人、季節感 |
| 秋 | 焙茶拿鐵 | **鼠尾草綠 + 奶茶棕 + 奶油白** | 明朝體 + 黑體 | 乾茶葉 + 湯匙 | 手作、職人、季節感 |

**視覺感受**：3 張放一起像**同一個咖啡店 3 個季節新品**——配色字體語氣全一致、只有商品內容換。

**決定性的 3 項一致變量**：**配色 + 字體 + 道具類型**。商品換、但視覺 DNA 不換。

**本段結論**（老師帶 30 秒）：

- **沒 DNA = 每張都重新決定 = 看起來像不同品牌**
- **有 DNA = 每張吃同份規格 = 看起來像同品牌**
- DNA 不是「限制創意」、是**建立長期可辨識的品牌資產**
- 後面 35 分鐘教你填 DNA + 用 DNA 跑 3 張系列 + 跨張一致性驗收

### 學 / Learn（20 min）

#### Brand DNA 五段詳解（10 min，扣 `courses/gen-image/assets/downloads/brand-dna-template.md`）

本單元只使用下載模板的五段 schema：

1. **任務與受眾**：品牌／專案代稱、交付用途、受眾情境、希望觀眾先看到、感受到與下一步。
2. **不可變項**：主色與容差、accent 位置與面積、光向、材質、構圖安全區、商品／角色外觀、正式後製字體與層級。每項都要寫驗收方式。
3. **可變項**：列出允許改變的場景、配件、季節色與鏡位；每輪只指定一個主要變因。
4. **禁止帶入**：第三方 logo、包裝、角色、trade dress、reference 中不得複製的元素、不必要敏感屬性，以及正式價格、日期、法規與合約文字。
5. **系列檢查**：並排檢查主色、光向、材質、商品／角色、用途與安全區；正式文字後製校稿，並保存 reference、prompt、模型／版本、日期與人工修改。

可從 `7-brand-style-system.md` 取用可觀測屬性。不要用知名品牌或在世創作者名稱當風格捷徑。色數與字族數可用課程示例作起點，實際規則以品牌需求與證據為準。

缺少任一必要證據就標記 `REVISE`，不能用其他項目的高分抵銷。

#### 品牌繼承 prompt 模板（5 min）

使用 `prompt-templates.md` 的模板 F「品牌繼承系列」。

```
吃下以下品牌 DNA：

[貼整份 品牌小卡]

---

結構沿用：{骨架代號}

本輪唯一主要變因：{例：商品從抹茶換成柚子}
固定條件：{骨架、場景、徽章、價格、道具與安全區}

請依以上 DNA + 骨架 + 主題產出 L4 完稿。

【AI 差異盤點】
產完只列待查線索：
1. 哪些位置可能偏離不可變項？
2. 哪些位置可能違反禁止帶入？
3. 哪些資訊無法從像素證明，必須由人或工具確認？

不要替我宣告通過，不要猜實際 hex 或字型名稱。
```

**關鍵鎖定**：

- **整份 DNA 貼上**——不是摘要，是完整五段
- **AI 只列線索**——人與工具做最後判定
- **每輪一個主要變因**——其他條件固定並明列

---

#### 系列檢查 3 問｜品牌系列一致性檢核（5 min）

使用 `prompt-templates.md` 的模板 G「系列差異盤點」。**單張驗收用 CH2-1 的驗收 A，系列驗收用本單元的人工證據鏈**。

拿到 3 張系列後、同對話內貼：

```
請對剛才產出的 3 張系列（A / B / C）做品牌一致性自檢、對照以下 DNA：

[貼 品牌小卡]

逐項比對 3 張：

1. 主色、光向與材質有哪些待查差異？
2. 商品／角色不可變項有哪些待查差異？
3. 是否出現禁止帶入元素？
4. 是否只有指定的主要變因改變？
5. 哪些資訊必須由取色、reference、來源紀錄、後製檔或第三人確認？

結論：請只列待查線索與證據缺口，不要替我宣告通過。
```

**PM 判定**：

- **五段檢查全過，且取色／reference／字型來源／第三人盲評有證據** → 收為系列資產
- **任一必要項失敗** → 迭代不符那張，保留已通過項，只修失敗項
- **兩輪仍失敗** → 回去強化 DNA 或停止，不用總分平均放行

> **預期差異**：AI 能協助找跨張差異，但不能從像素證明精確 hex、實際字型或品牌權利。由人工、取色器、後製檔與第三人盲評作最後判定。

### 做 / Hands-on（15 min）

#### 活動｜填 品牌小卡 + 跑 3 張系列 + 驗收 C

**教學意圖**：學員為自家品牌（或假想品牌）建立完整 DNA、跑 3 張系列、做跨張一致性驗收——完成後就有**可長期使用的品牌視覺資產**。

---

**階段 1｜填 Brand DNA（5 min）**

打開 `courses/gen-image/assets/downloads/brand-dna-template.md` 的填空範本、填自家品牌：

- 第 1 段：任務與受眾
- 第 2 段：不可變項及各自驗收方式
- 第 3 段：可變項與本輪唯一主要變因
- 第 4 段：禁止帶入
- 第 5 段：系列檢查與來源紀錄

**若 5 分鐘填不完**：第 1／2／4 段不可省略；第 3 段只寫一個主要變因，第 5 段沿用檢查清單。

---

**階段 2｜跑 3 張系列（7 min）**

用品牌繼承 prompt 模板、跑 3 張系列：

- 3 張共享同骨架 + 同 DNA
- 每輪只換一個主要變因；其他條件固定
- 例：只換商品為春抹茶 / 夏柚子 / 秋焙茶，場景、徽章、價格、道具與安全區固定

記錄實際組 prompt、排隊、生成、後製與驗收時間；平台不可用時使用 OFFLINE-01 實際面板，不預設固定分鐘數。

---

**階段 3｜驗收 C 跨張檢核（3 min）**

3 張都跑完後、貼系列檢查 3 問 給 AI、讓它做跨張一致性自檢。

**判定**：

- **所有必要項與證據通過** → 存檔 3 張系列 + DNA
- **任一必要項失敗** → 只修缺口後重驗，不用總分平均放行
- **兩輪仍失敗** → 停止並記錄，回階段 1 補規格

---

#### 完成標準（self-check）

- [ ] 填完五段 Brand DNA，且名稱與下載模板一致
- [ ] 跑出 3 張系列（同骨架 + 同 DNA + 每輪一個主要變因）
- [ ] 做過驗收 C 跨張一致性自檢
- [ ] 必要條件全過，並附取色／reference／字型來源／第三人證據
- [ ] 存檔 3 張系列 + 品牌小卡（PRAC4 會用）

## 商業情境案例（Case）

**角色**：主線 A 老闆（弄一下咖啡工作室）

**公司**：弄一下咖啡工作室

**任務**：

老闆要做 **春夏秋冬 4 季 × 3 新品 = 12 張**年度系列廣告。他試跑春夏秋 3 張發現問題：

- 3 張結構都對（骨架 4）、主題都是咖啡

- 花 5 分鐘填完 DNA 5 段（風格 / 色票 / 字族 / 語氣 / 禁用 / 骨架）
- 每次新廣告都丟 DNA + 骨架 + 新主題給 AI
- 跑完用驗收 C 做跨張檢核
- **12 張年度廣告看起來像 1 個品牌的 12 個新品**、不是 12 個不同品牌

**本單元要他學會**：

- PM 系列把關者身份——不跑單張、建立長期資產
- 品牌小卡 5 段填寫邏輯
- 品牌繼承 prompt 的「AI 只列差異線索」機制
- 驗收 C 跨張一致性 5 項清單

**POV**：

主要走第二人稱「你」（學員為自家品牌建 DNA）。老闆的 4 季 12 張是案例、你是為自己做同樣的事。

## 動手練習題（Hands-on Exercise）

**題目**：

在 15 分鐘內：

1. **填 Brand DNA**（5 min）：自家 / 客戶 / 假想品牌任選、填完五段
2. **跑 3 張系列**（7 min）：同骨架 + 同 DNA + 每輪只改一個主要變因
3. **跨張檢核**（3 min）：AI 列線索，人工依五段必要條件與可觀測證據判定

**預期成果**：

- 1 份完整五段 Brand DNA
- 3 張系列 L4 完稿
- 1 份驗收 C 記錄（5 項打勾 + 判定）
- 1 張**獨立備份**的 DNA（PRAC4 / CH5-1 會反覆使用）

**完成標準**（self-check）：

- [ ] DNA 五段名稱與下載模板一致，第 2 段每項都有驗收方式
- [ ] 3 張系列都吃同份 DNA（不是每張重填）
- [ ] 五段必要條件與證據全過，沒有用平均分數抵銷失敗項
- [ ] 3 張放一起能被第三人辨識為「同品牌」
- [ ] 能說出「若 DNA 某段沒填、系列會變什麼樣」

**預期差異提醒**：

- 你的 DNA 跟同學完全不同、你的 3 張系列也不同——這是設計
- **5/5 通過不是目標**——3-4/5 已經比沒 DNA 好很多
- DNA 是**迭代品**——第一版不完美、用個 1-2 個月後會想修、這是正常的
- 今天填的 DNA + 3 張系列是**品牌資產雛形**、PRAC4 + CH5-1 會繼續用

## 常見錯誤 3 條（Common Pitfalls）

### 錯誤 1｜DNA 填得太抽象（只寫「日系風」）

**錯誤現象**：

學員填 DNA 時，第 1 段只寫「做廣告」、第 2 段只寫「日系清新」、第 3 段沒有指定唯一變因。填完看似有內容，實際上無法驗收。

**原因**：

**抽象詞 = AI 的猜謎題**。日系風的配色有 10 種可能、字族有 20 種可能——AI 只能猜一個組合。下次跑新系列時 AI 又猜一個、**兩次結果不會一致**。

**解法**：

**每段都要具體到「可執行」的程度**：

| 抽象（錯誤）| 具體（正確）|
|---|---|
| 日系風 | 大面積留白、自然材質、低對比、細線條、物件不超過四件 |
| 清新色調 | primary 鼠尾草綠 #5a7a5a + accent 奶茶棕 #8a6a4a + bg 奶油白 #f5efe3 |
| 好看的字體 | headline: Shippori Mincho (700) / body: Noto Sans JP (400) |
| 親切 | 手作、職人、季節感、療癒（4 詞）+ 示範句「なめらかな抹茶のハーモニー」|

**檢查方法**：填完每段、**換隔壁同學看**——他能不能照你的描述重現同樣的視覺？若他說「我要猜什麼顏色才對」——你的描述不夠具體。

---

### 錯誤 2｜3 張系列跑完沒做驗收 C 跨張檢核

**錯誤現象**：

學員跑 3 張系列、每張個別看都還 OK、存檔。**沒跑驗收 C 跨張檢核**。兩週後要做第 4 張系列、打開前 3 張才發現——第 1 張是鼠尾草綠主導、第 2 張不小心用了橄欖綠（跟鼠尾草綠不同 hex）、第 3 張徽章變矩形（不是 DNA 指定的圓形）——**三張已經偏離 DNA**。

**原因**：

單張驗收用 A、但**系列驗收需要跨張比對**——人肉眼比對跨張偏離容易漏判（特別是色彩相近如鼠尾草綠 vs 橄欖綠）。驗收 C 就是專門為了抓**跨張微偏離**設計的。

**解法**：

**3 張系列跑完後、必跑驗收 C**：

- 讓 AI 逐項比對 3 張的色票 / 字族 / 禁用 / 骨架 / 語氣
- AI 只能指出可能偏色的位置；人用取色器記錄實際色值與容差，再判定是否符合第 2 段。
- 驗收 C 任一必要項失敗 → 立刻迭代那張、不要存檔

**紀律**：**驗收 C 是系列化的最後守門員**——跳過就等於把偏離的資產存進品牌庫、未來每次新廣告都在累積偏離。

---

### 錯誤 3｜DNA 的「禁用清單」沒填

**錯誤現象**：

學員填 DNA 時、第 4 段禁用清單留空或只寫「沒特別禁用」。結果 AI 產系列時、**自己加了漸層背景、多了裝飾邊框、用了額外的亮橘色點綴**——這些 DNA 沒禁、所以 AI 合法加上、但**跟你的品牌調性不符**。

**原因**：

學員以為「可用清單夠了、禁用清單可有可無」。**錯**。AI 預設會從**訓練資料平均值**取用（訓練資料裡充滿漸層、多色、裝飾邊框）、**沒禁用清單 = AI 自由發揮**。

**解法**：

**禁用清單是必填、不是選填**：

至少列 3 類 × 每類 3-5 項：

**視覺禁用**（3-5 項）：
- 漸層（本品牌走平面）
- 純黑 #000（太冷硬）
- 霓虹色、螢光色
- 寫實人像（走靜物路線）
- 玻璃態 glassmorphism

**情境禁用**（3-5 項）：
- 促銷轟炸風（本品牌走價值訴求）
- 網路流行梗
- 假名人代言
- 快速消費感（走慢食）

**字體禁用**（3 項）：
- Comic Sans 類手寫感字體
- 過瘦 Hairline 字體
- 同頁超過 2 種字族

**心法**：AI 是「很會跟你訓練的員工」——你告訴它「不要做 X」比「做 Y」更重要、因為它會自己學會做 Y、但**你不說它就會做 X**。

## 檢核題 2 條（Quiz）

### Q1（概念驗證｜簡答）

請說明 品牌小卡 的 **5 段是什麼**、以及**為什麼每段都重要**（特別是解釋：為什麼禁用清單不是選填、是必填）。

**預期答案要點**（至少命中 5 點算通過）：

1. **5 段**：
   - 第 1 段：任務與受眾
   - 第 2 段：不可變項與驗收方式
   - 第 3 段：可變項與本輪唯一主要變因
   - 第 4 段：禁止帶入
   - 第 5 段：系列檢查與來源紀錄

2. **禁用清單必填的理由**：
   - AI 預設從訓練資料平均值取用（充滿漸層、多色、裝飾）
   - 若只填「可用清單」、AI 會**自由發揮加東西**
   - 禁用清單 = **明確劃出不跨的界線**、AI 才會守
   - 「告訴 AI 不要做什麼」比「告訴 AI 做什麼」更重要

3. **每段重要理由**（加分項）：
   - 色彩：寫角色、容差與驗收方式，不預設通用色數
   - 字體：由後製工具套用並以設計檔、來源與成品證據驗證
   - 語氣：示範句對比給 AI 具體錨點、知道「好 vs 壞」邊界
   - 骨架對應：避免今天用骨架 4、明天跑骨架 5、破壞品牌辨識度

4. **DNA 整體價值**：
   - 給 AI 看的品牌規格書、不是給設計師看的文件
   - **建立後持續版本化**——每次新廣告引用目前核准版本，品牌變更時同步更新
   - 建立長期可辨識的品牌資產

**不及格的答案**：

- 只列 5 段沒說為什麼重要
- 「禁用清單看情況」（錯誤、必填）
- 「DNA 就是品牌風格」（太空泛）

### Q2（應用驗證｜情境題）

**情境**：

請為**弄一下咖啡工作室**（主線 A）填 品牌小卡 的**前 3 段**（風格 preset / 色票 / 字族）、並組成**一個品牌繼承 prompt**（跑「夏季柚子美式」新品廣告）。

品牌背景（你可參考）：
- 台北單店手沖咖啡
- 走職人、手作、季節限定路線
- 客群 25-35 歲女性

**預期答案要點**（至少命中 5 點算通過）：

**品牌小卡 前 3 段**：

1. **風格 preset**：大面積留白、自然材質、低對比、細線條、物件不超過四件

2. **色票**：
   - primary：鼠尾草綠 #5a7a5a
   - accent：奶茶棕 #8a6a4a
   - bg：奶油白 #f5efe3
   - **禁用色**：純黑、霓虹、高飽和紅橘

3. **字族**：
   - headline：Shippori Mincho 700
   - body：Noto Sans JP 400
   - 字階：H1 48-56pt / H2 22-26pt / Body 14-16pt

**品牌繼承 prompt**：

```
吃下以下品牌 DNA：

【風格 preset】日系職人
【色票】primary 鼠尾草綠 #5a7a5a + accent 奶茶棕 #8a6a4a + bg 奶油白 #f5efe3
【禁用色】純黑、霓虹、高飽和紅橘
【字族】headline Shippori Mincho 700 / body Noto Sans JP 400
【語氣】手作、職人、季節感、療癒（參考句：なめらかな抹茶のハーモニー）

結構沿用：骨架 4 商品中心 × 道具環繞

本次主題：

請依以上 DNA + 骨架 + 主題產出 1 張 1:1 L4 完稿。

【AI 差異盤點】產完只列待查位置：
1. 哪些位置可能偏離不可變項？
2. 字族是否符合？
3. 禁用清單是否全遵守？
```

**加分答案**：

- 指出「DNA 應該繼續填第 3 段語氣 + 第 4 段禁用清單 + 第 5 段骨架對應才完整」
- 提醒「跑完後丟驗收 C」
- 建議「這份 DNA 填完、老闆未來所有廣告都從這張開始、不從零開始」

**不及格的答案**：

- 色票寫「鼠尾草綠 + 奶茶棕 + 米白」不寫 hex（扣錯誤 1 抽象）

- prompt 沒貼 DNA（變成一般生圖指令、不是品牌繼承）
