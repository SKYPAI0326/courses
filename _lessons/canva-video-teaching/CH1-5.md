# 換一個主題，用同一套方法再做一次
在複本換掉影片和句子，確認整支作品跟著改對
本節完成物：一份電腦教室練習複本，畫面、位置、活動與提問都指向同一個新主題，原畫面版保持不變。

## 先建立複本，保留畫面版

你現在有一支 36 秒畫面版，答案、活動文字與動態效果都已經對準時間。這一頁要驗證的不是重新剪一支影片，而是能不能沿用原來的結構，把位置、活動、畫面與提問一起換成電腦教室。

在畫面版開啟「檔案」→「建立複本」，把新設計命名為 `姓名_電腦教室_練習`。看到瀏覽器開啟新的設計，而且上方顯示新名稱後，再開始替換內容。原來的畫面版留在專案中，第二場仍會從那一份作品繼續。

複本準備好後，先完成自己的版本，真的卡住再看頁尾的參考做法。這次只給要達成的結果，你要自己判斷哪些物件需要跟著換。

## 先看新作品要達成什麼

複本已經和原作分開，接著依下列結果逐項修改。電腦教室的位置關係設定為「在圖書館對面」，活動是「使用電腦、練習打字」。

- 開場問題詢問電腦教室在哪裡，回答要表達它與圖書館的相對位置。
- 閱讀片段改成能看出電腦教室的畫面，自習片段改成能看出打字動作的畫面。
- 活動文字要對應使用電腦與練習打字，舊的閱讀、自習句不再留在複本中。
- 結尾兩個問題要改問電腦教室的位置，以及能在那裡做什麼。
- 四個片段仍是 10、6、6、14 秒，整支作品維持 36 秒。

目標清楚後，先換兩段活動影片，再用文字工具更新內容。

## 用「取代」換掉活動畫面

新作品的檢查目標已經列好，接著在主軌選取原本的閱讀片段。看到片段亮起後，開啟工具列的「取代」，從圖庫影片搜尋 `computer room`，選一段沒有皇冠付費標示的畫面。新影片會進入原片段的位置，原有的六秒區間則繼續作為活動段落。

再選取原本的自習片段，從工具列「取代」搜尋 `typing`，挑一段能清楚看見打字動作、沒有皇冠的影片。播放第 10–22 秒，確認前六秒呈現電腦教室，後六秒呈現打字活動。

若換入畫面的動作太快，選取該影片，開啟工具列「速度」，暫時改成 0.75x，觀察時間軸上的片長如何改變。看過差別後改回原速，並確認活動片段回到六秒；這次測試用來理解速度會影響片長，成品仍沿用固定時間。

兩段影片都換好後，接著更新活動句、位置問答與最後提問。

## 用魔法文案工具改寫活動句

活動畫面已經換成電腦教室與打字，接著選取原本的活動文字，開啟文字工具列的魔法文案工具，畫面以實際為準。輸入下面的指令，讓工具先提出適合新生閱讀的短句：

```
改寫成兩句給新生看的英文短句，各配一段活動畫面：第一句說可以在這裡使用電腦，第二句說可以在這裡練習打字。
```

產生結果後，挑選意思最直接、能和兩段畫面對上的寫法。把第一句放在電腦教室片段，把第二句放在打字片段；再逐字確認活動沒有被工具改成別的內容。魔法文案工具有免費使用額度，入口與畫面以實際為準。

接著自行更新開場問答與提問段：位置關係「在圖書館對面」寫在開場的答案裡。每改完一組文字，就播放那個片段，確認畫面與句子說的是同一件事。文字全部換好後，再從頭播放四個片段。

## 逐段播放，確認整支作品一起改對

新影片與新文字都已經放好，接著從第 0 秒開始播放。前十秒要看出電腦教室的位置關係；第 10–22 秒要看出使用電腦與練習打字；第 22–36 秒的問題要能由前面內容回答。

播放時若仍看見圖書館的舊句子，先停在那一刻，再選取上方軌對應的文字物件改寫。若位置圖仍只呈現舊關係，就調整圖形或文字標示，讓畫面也能支持「在對面」。最後確認主軌仍在第 36 秒結束，活動片段各為六秒。

這份電腦教室複本用來證明你能換題材，完成後保留在專案列表即可。下一頁會回到原來的畫面版，下載可播放的 MP4，並保存下次能繼續編輯的設計網址。

## 卡住時的參考做法

自己的版本已經先做過一輪後，再用這組文字核對內容：

- `Where is the computer room?`
- `It's across from the library.`
- 電腦教室片段：`You can use computers here.`
- 打字片段：`You can practise typing here.`（案例原句合寫為 `You can use computers and practise typing here.`）
- `Where is the computer room?`
- `What can you do there?`
- 範例回答：`The computer room is across from the library. I can practise typing there.`

可用第一段活動影片呈現電腦教室環境，第二段呈現手部打字。開場用位置文字或簡單圖形表達兩處在對面，提問段則保留讓學生回答的閱讀時間。更多題材對照可查看[案例與腳本](../../courses/canva-video-teaching/resources/案例與腳本.md)。

參考做法的用途是核對位置、活動與提問是否一致。保留完成的練習複本，下一頁仍回到圖書館畫面版，讓第二場有正確的 36 秒起點。

### 講師授課筆記（不進講義）

配時：複製作品 3 分、獨立修改 12 分、核對內容與時間 7 分、選定續作 3 分。新條件同時涉及較長文字、地點關係及活動語句，具有轉移判斷。跟不上者保留圖書館作為續作，在本單元至少獨立修改一個活動句。


本次強化配時以實拍主流程為準；可展開的文字版操作不列第二次必做。新版入口依官方文件，新增平台路徑尚未完成真人冷讀；既有圖例只證明圖中的頁面編輯器。
