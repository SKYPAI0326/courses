# 操作題 28–40：輸出、動畫、色彩與 Matte

最後一組常把多個條件放在同一句話裡。你會先拆條件、安排不破壞既有狀態的順序，再逐步實作 Photoshop Sequence 輸出、Transform + Easy Ease 與光束 Track Matte。

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | `ACP-AE-Lab-PRAC1.aep` 複製檔 `ACP-AE-Q28-40.aep`、本頁 13 張路徑卡 |
| 完成物 | 題 29、38、40 實作證據，題 28、30–37、39 路徑卡，個人錯題與復原清單 |
| 第一個動作 | 另存題組副本，將第 29 題分為 Render Settings、Output Module、Output To 三列 |
| 成功訊號 | 你能先說「要在哪個對話框驗收」，再選輸出格式或動畫屬性 |
| 完成檢查 | 13 張卡皆有安全順序、完成證據與復原位置 |

## Step by Step：替多條件題目排安全順序

1. 把題目拆成一條一條 checkbox，不在腦中同時記全部條件。
2. 標出每一條作用於 Composition、Layer、Effect、Render Settings、Output Module 或 Output To。
3. 先建立題組副本或複製 Composition，保留可回復版本。
4. 先做不會破壞既有狀態的命名、選取與檢查，再做數值修改。
5. 每完成一條就核對並留證，不到最後才一次回想。
6. 完成後重開工程，從題目第一條重新驗收。

**Checkpoint**：如果不確定要在哪個對話框驗收，先不要選格式或修改數值。

## 代表題實作

### 題 29：Photoshop Sequence 輸出

1. **準備**：複製 `PRAC1_Title_6s` 為 `Q29_PS_Sequence`，把 Work Area 設為 0–1 秒，減少測試檔案數。
2. **加入佇列**：將 `Q29_PS_Sequence` 加入 Render Queue。
3. **檢查 Render Settings**：核對 Resolution 與 Time Span，確認只輸出 0–1 秒。
4. **設定 Output Module**：Format 選 Photoshop Sequence，依題目需求設定 Channels。
5. **設定 Output To**：建立並指定 `Exports/Q29-sequence-test` 資料夾，不與其他輸出混放。
6. **應看到**：渲染後資料夾中有多個連續編號 `.psd` 檔，不是單一影片。
7. **卡住時**：格式正確但位置錯誤就回到 Output To；檔案數過多就回到 Render Settings 的 Time Span。

### 題 38：Transform 與 Easy Ease

1. **準備**：複製目標 Composition 為 `Q38_Ease`，在 Timeline 只選取 `Accent_Shape`。
2. **建立 Position**：0 秒放在畫面左外，啟用 Position；1.5 秒移到畫面中央。
3. **建立 Scale**：1.5 秒 Scale = 85%，啟用 Scale；3 秒 Scale = 110%。
4. **套用 Easy Ease**：只選兩個 Position Keyframe，再選 Keyframe Assistant > Easy Ease。
5. **應看到**：Position 有兩個 Ease Keyframe，Scale 有兩個一般 Keyframe，兩組時間不混在一起。
6. **卡住時**：Undo，先收起 Scale，只選 Position 菱形後重做 Easy Ease。

### 題 40：光束 Track Matte

1. **準備**：複製 `FX_Matte` 為 `Q40_Beams_Matte`，建立 `Beam_Fill` 與 `Beam_Matte`。
2. **先單獨檢查 Fill**：只開 `Beam_Fill`，確認它提供可見的光束畫面。
3. **再單獨檢查 Matte**：只開 `Beam_Matte`，確認它提供要保留的透明形狀。
4. **設定 Track Matte**：在 `Beam_Fill` 的 Track Matte 來源選 `Beam_Matte`，先使用 Alpha。
5. **應看到**：光束只留在 Matte 形狀範圍內，Modes 欄顯示正確來源。
6. **處理相反結果**：若保留範圍正好相反，切換 Inverted，不立即重畫 Shape。
7. **卡住時**：全透明就先設回 None，重做 Step 2、3，確認兩層各自可見後再指定來源。

## Step by Step：變式練習

1. 從題 28、30–37、39 選三題。
2. 每題只改名稱、時間或一個數值，不改作用層級。
3. 把新條件拆成 checkbox，先寫安全順序與復原位置。
4. 使用題組副本完成操作，每完成一條就核對。
5. **通過標準**：每題都有數值、開關或檔案證據，不以「看起來差不多」代替。

## 修復

- **輸出格式對但檔案不在指定處**：回到 Output To，別在 Output Module 內找資料夾。
- **更改視圖 Resolution 卻以為改了輸出**：回到 Render Queue > Render Settings 核對該 render item。
- **Preset 套在錯圖層**：Undo，選擇指定 Text Layer，確認 Animator 出現在這一層。
- **Track Matte 結果全透明**：設 None，分別檢查 fill 與 matte 圖層，再檢查來源、Alpha/Luma 與 Inverted。
- **多條件漏做**：把題幹拆成 checkbox，每完成一條就留證，最後重開工程再驗一次。
