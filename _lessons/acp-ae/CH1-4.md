# Mask、Matte、Blending、Effects 與色彩

Mask、Track Matte、Blending Mode 與 Adjustment Layer 都會改變畫面，但控制方式不同。這一課用同一張標題卡做四個版本，讓你直接比較「改哪個圖層」與「影響哪些內容」。

## 本課英文名詞

| 英文介面名稱 | 中文理解 | 實際用途 |
|---|---|---|
| Mask | 遮罩 | 在同一圖層畫出要顯示或隱藏的範圍 |
| Mask Path / Mask Feather | 遮罩路徑／羽化 | 控制遮罩形狀並柔化邊緣 |
| Track Matte | 軌道遮罩 | 用另一圖層的形狀或亮度控制透明範圍 |
| Alpha / Luma | 透明資訊／亮度資訊 | 決定 Track Matte 依透明度還是明暗建立範圍 |
| Blending Mode | 混合模式 | 決定目前圖層如何和下方圖層混合 |
| Adjustment Layer | 調整圖層 | 把效果套用到它下方的多個圖層 |
| Effect | 效果 | 改變圖層的顏色、模糊、扭曲或其他外觀 |
| Effect Controls | 效果控制面板 | 查看並修改目前圖層已套用效果的參數 |
| Ellipse Tool | 橢圓工具 | 在選取圖層時畫 Mask；未選圖層時建立 Shape Layer |
| Alpha Matte | 透明度軌道遮罩 | 用來源圖層的透明區域控制下方圖層是否可見 |
| Mode / Modes | 模式／模式欄 | 顯示 Blending Mode 與 Track Matte 選項 |
| None / Normal | 無／正常 | 取消 Matte 來源／使用一般混合方式 |

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | `ACP-AE-Lab-v03.aep`、`Square_Practice` 內的文字、Shape 與 Solid |
| 完成物 | `FX_Base`、`FX_Mask`、`FX_Matte`、`FX_Blend`、`FX_Adjust` 五個可比較 Composition |
| 第一個動作 | 複製基準 Composition，保留 `FX_Base` 不修改 |
| 成功訊號 | Project 面板可同時找到基準版與四個操作版 |
| 交接 | PRAC1 選擇 Mask 或 Track Matte 完成標題揭露 |

## 方法選擇表

| 任務句型 | 優先方法 | 作用層級 | 完成檢查 |
|---|---|---|---|
| 「只顯示這個圖層的圓形區域」 | Mask | 同一圖層 | 圖層下出現 Masks 與 Mask Path |
| 「使用另一個 Shape 控制文字顯示」 | Track Matte | 填色層參考另一層 | Modes 欄位可看到 Matte 來源 |
| 「讓上層亮部與下層混合」 | Blending Mode | 圖層像素混合 | Mode 不再是 Normal |
| 「讓下方多層一起改色」 | Adjustment Layer + Effect | 調整圖層以下 | 關閉調整層可看到前後差異 |

Adobe 說明中，Track Matte 是讓一個圖層根據另一個圖層的 Alpha 或亮度決定透明度，而新版可在 Modes 欄位指定來源層。詳見 [Track Mattes](https://helpx.adobe.com/after-effects/desktop/work-with-transparency-and-compositing/work-with-track-mattes-and-traveling-mattes/track-mattes-and-traveling-mattes.html)。

## Step by Step：用同一畫面比較四種方法

### Step 1：建立不修改的基準版

- **操作**：在 Project 面板複製 `Square_Practice`，改名 `FX_Base`。再從 `FX_Base` 複製四份，命名 `FX_Mask`、`FX_Matte`、`FX_Blend`、`FX_Adjust`。
- **應看到**：Project 面板共有五個名稱清楚的 Composition，內容一開始相同。
- **如果沒有**：先整理名稱；不要在分不清版本時繼續操作。

### Step 2：在 FX_Mask 建立同圖層遮罩

- **操作**：開啟 `FX_Mask`，選取 `Accent_Shape`，再用 Ellipse Tool 畫一個圓形 Mask。展開 Masks，調整 Mask Feather。
- **應看到**：只有 `Accent_Shape` 的可見範圍改變，Timeline 的該圖層下出現 `Masks > Mask 1`。
- **如果沒有**：若產生新的 Shape Layer，Undo，先選取 `Accent_Shape` 再畫；若整層消失，先檢查 Mask Mode。

### Step 3：在 FX_Matte 用另一層控制文字

- **操作**：開啟 `FX_Matte`，建立圓形 Shape 並改名 `Matte_Circle`。在 `Title_Text` 的 Track Matte 來源選 `Matte_Circle`，類型使用 Alpha。
- **應看到**：文字只在圓形提供的 Alpha 範圍內顯示，Modes 欄可看到 Matte 來源名稱。
- **如果沒有**：先把 Matte 設回 None，分別確認文字與圓形都能單獨看見，再重新指定來源。

### Step 4：在 FX_Blend 比較像素混合

- **操作**：開啟 `FX_Blend`，複製 `Accent_Shape`，改名 `Light_Blend`。在 Timeline 的 Mode 欄選一個能看出差異、但不會讓畫面爆白的 Blending Mode。
- **應看到**：Mode 不再是 Normal，重疊區的亮度或顏色改變。
- **如果沒有**：確認 Modes 欄已顯示；先切回 Normal，再重新選一個差異較明顯的模式。

### Step 5：在 FX_Adjust 同時調整下方圖層

- **操作**：開啟 `FX_Adjust`，選 **Layer > New > Adjustment Layer**，命名 `Color_Adjust`。把它放在要受影響圖層的上方，再套用一個色彩調整 Effect，做小幅修改。
- **應看到**：`Color_Adjust` 下方的圖層一起改變；關閉它的眼睛後可回到未調整畫面。
- **如果沒有**：檢查 Adjustment Layer 的上下順序與時間長度；不要先加第二個 Effect。

### Step 6：逐一比較作用對象

- **操作**：依序開啟 `FX_Base`、`FX_Mask`、`FX_Matte`、`FX_Blend`、`FX_Adjust`。每次只比較一個版本，說出「被改的是哪個圖層」與「控制來源在哪裡」。
- **應看到**：四種方法都有可辨認差異，`FX_Base` 保持原樣。
- **如果沒有**：用圖層眼睛或 Effect 開關做 A/B 比較，不要一次開關多個項目。

### Step 7：另存新版

- **操作**：另存 `ACP-AE-Lab-v04.aep`。
- **應看到**：重開工程後五個 Composition 都存在，名稱與差異不變。
- **如果沒有**：回到存檔步驟確認新檔，再關閉工程。

## Step by Step：同步練習與變式

### 同步練習：調整既有 Mask

1. 開啟 `FX_Mask`，選取 `Accent_Shape`。
2. 展開 `Masks > Mask 1`，不要再畫第二個 Mask。
3. 調整 Mask Path 位置，再小幅增加 Mask Feather。
4. **通過標準**：橘色圖層只顯示於圓形內，邊緣有輕微柔化。
5. **卡住時**：若看見 `Mask 2`，Undo 到只剩 `Mask 1` 再繼續。

### 變式練習：改變 Matte 形狀

1. 開啟 `FX_Matte`，選取 `Matte_Circle`。
2. 將它的 Shape 改成橫向矩形。
3. 不更換 `Title_Text`，也不更改 Alpha Matte 類型。
4. **通過標準**：文字的可見範圍跟著變成橫向矩形，Matte 來源仍是同一層。

## 完成檢查

- 五個 Composition 名稱正確，`FX_Base` 尚未修改。
- Mask 是目標圖層的屬性；Matte 有明確來源圖層。
- Blending Mode 作用於指定層，Adjustment Layer 只影響其下方圖層。
- 關閉目標開關或 Effect 後，可看到基準與處理版差異。

## 修復

| 現象 | 回修位置 | 重跑起點 |
|---|---|---|
| 畫 Shape 時變成 Mask | 目前圖層選取 | Undo；若要新 Shape Layer，先取消所有圖層選取 |
| Matte 後整層不見 | Modes 欄位、Matte 來源與 Alpha/Luma | 先設回 None，確認來源有可見區域再重設 |
| Effect 影響到不該改的圖層 | Adjustment Layer 順序 | 移到需受影響圖層上方，其他圖層上方不可越過 |
| 無法判斷差異 | 效果或圖層眼睛開關 | 關閉／開啟只比較一個變因 |
