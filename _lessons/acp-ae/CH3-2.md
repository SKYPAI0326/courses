# 操作題 14–27：時間、Parenting、素材與效果

這一組先判斷功能應該改 Footage、Layer、時間屬性、Parent 關係還是 Effect，再開始動手。你會逐步實作 Time Remap 停格、Parenting 與 Radial Blur 動畫。

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | `ACP-AE-Lab-PRAC1.aep` 複製檔 `ACP-AE-Q14-27.aep`、本頁 14 張路徑卡 |
| 完成物 | 題 14、17、27 實作證據，題 15–16、18–26 路徑卡 |
| 第一個動作 | 另存題組副本，在每題前寫 P（Project）、C（Composition）、L（Layer）、E（Effect）或 T（Time） |
| 成功訊號 | 你能解釋為何點了正確功能卻沒有結果，往往是作用層級或選取對象錯誤 |
| 完成檢查 | 14 題皆有層級、路徑、證據與復原位置 |

## Step by Step：先判斷作用層級

1. 圈出題目的動詞與完整對象名稱。
2. 在題號旁寫 P（Project）、C（Composition）、L（Layer）、E（Effect）或 T（Time）。
3. 寫出進入點，例如 Project 面板、Timeline、Effect Controls。
4. 抄下數值、時間與不得改動項目。
5. 寫出操作後應看到的屬性、畫面或檔案。
6. 寫出 Undo、Reset、None 或題組副本等復原位置。

**Checkpoint**：若你只能說出功能名稱，卻說不出要先選哪個對象，先不要操作。

## 代表題實作

### 題 14：Time Remap 停格

1. **準備**：複製 `PRAC1_Title_6s` 為 `Q14_Freeze`，再把它放進另一個測試 Composition，選取該圖層。
2. **操作**：選 **Layer > Time > Enable Time Remapping**。
3. **應看到**：Timeline 出現 Time Remap 屬性，以及自動建立的起點與終點 Keyframe。
4. **操作**：CTI 移到 3 秒，建立 Time Remap Keyframe；複製同一時間值到 5 秒。
5. **檢查**：播放 3–5 秒，畫面應保持在同一內容時間，不是整層停在 0 秒。
6. **卡住時**：停用 Time Remapping 或從副本重開；不要在無法辨認時間值時繼續加 Keyframe。

### 題 17：Parenting

1. **準備**：在複製版建立 Shape Layer，命名 `CTRL_Parent`。
2. **記錄原值**：寫下 `Title_Text` 與 `Accent_Shape` 的 Position，暫時不要移動它們。
3. **操作**：在 Parent & Link 欄，將兩個子層的 Parent 都設為 `CTRL_Parent`。
4. **應看到**：兩個子層的 Parent 欄顯示相同父層，畫面位置暫時不變。
5. **檢查**：只移動 `CTRL_Parent`，兩個子層應保持相對距離一起移動。
6. **卡住時**：畫面跳移就 Undo，將 Parent 設回 None，確認父層位置後再重做。

### 題 27：Effect 數值動畫

1. **準備**：複製 `FX_Adjust` 為 `Q27_Blur`，選取指定圖層。
2. **操作**：套用 Radial Blur 或授課版本中的同等效果，在 Effect Controls 找到 Amount。
3. **建立動畫**：0 秒 Amount = 0 並啟用 Stopwatch；2 秒 Amount = 35；4 秒 Amount = 0。
4. **應看到**：Amount 下有三個 Keyframe，2 秒效果最明顯，0 與 4 秒回到 0。
5. **檢查**：關閉 Effect 做 A/B 比較，留下 0、2、4 秒證據。
6. **卡住時**：確認 Keyframe 位於 Effect 屬性下；若加在 Transform，Undo 後回到 Effect Controls。

## Step by Step：變式練習

1. 從題 15–16、18–26 選三題。
2. 每題改一個名稱或數值，先寫下新的要求。
3. 操作前標記 P、C、L、E 或 T，並寫出第一個要選取的對象。
4. 完成後核對實際修改是否落在同一層級。
5. **通過標準**：三題都有層級、路徑、證據與復原位置，且未誤改其他層級。

## 修復

- **Interpret Footage 與 Composition fps 混淆**：回到 Project 面板的 footage；不在 Composition Settings 代替它。
- **Parent 後畫面跳移**：Undo，核對是否選到正確父層；先保持 Parent 在預期位置。
- **Marker 加在圖層上**：刪除 Marker，取消所有圖層選取後在時間軸標尺重加。
- **Effect 動畫沒變化**：檢查是否有兩個以上不同數值、CTI 是否在正確時間、Effect 是否啟用。
