# 3D、Camera、音訊、Render Queue 與輸出

這一課先用短練習看懂 3D Layer 與 Camera，再把六秒動畫加入 Render Queue。你會依序檢查畫布、渲染方式、檔案格式與輸出位置。

## 本課英文名詞

| 英文介面名稱 | 中文理解 | 實際用途 |
|---|---|---|
| 3D Layer | 3D 圖層 | 啟用 Z 軸、方向與材質等立體屬性 |
| Camera | 攝影機 | 控制 3D 圖層的觀看位置與視角 |
| Render Queue | 渲染佇列 | 集中放置等待輸出的 Composition 與設定 |
| Render Settings | 渲染設定 | 決定輸出範圍、品質、解析度與影格率 |
| Output Module | 輸出模組 | 決定檔案格式、通道、壓縮與音訊 |
| Output To | 輸出至 | 指定輸出檔的資料夾與檔名 |
| Time Span | 時間範圍 | 決定這次實際要輸出哪一段時間 |
| Needs Output | 尚未指定輸出位置 | 提醒學員先設定 Output To 才能輸出 |
| Preview | 預覽 | 輸出前播放工作區段並檢查畫面、長度與音訊 |
| File > Export > Add to Render Queue | 加入渲染佇列 | 把目前 Composition 送到 Render Queue |
| Quality / Resolution | 品質／解析度 | 控制渲染品質與輸出尺寸比例 |
| Format / Audio Output | 格式／音訊輸出 | 選擇檔案格式並決定是否輸出聲音 |
| Audio Layer / Audio Meter | 音訊圖層／音量表 | 放置聲音素材並查看播放音量 |
| Summary / Render | 摘要／渲染 | 先核對輸出設定，再開始輸出 |

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | `ACP-AE-Lab-v04.aep`、`Square_Practice`、一段由學員自行可用音訊或無音訊備援路徑 |
| 完成物 | 0–6 秒 Render Queue 項目、設定證據與測試輸出 |
| 第一個動作 | 播放 `Square_Practice`，確認 Work Area = 0–6 秒且畫面完整 |
| 成功訊號 | Render Queue 中出現一個 render item，狀態會因輸出位置是否完成而變化 |
| 交接 | PRAC1 將相同檢查用於六秒成品 |

## 三層輸出模型

| 層級 | 負責什麼 | 不負責什麼 |
|---|---|---|
| Composition Settings | 畫布尺寸、fps、duration | 最後檔案格式與輸出位置 |
| Render Settings | Quality、Resolution、Time Span、frame rate 等渲染方式 | 容器、編碼、音訊開關 |
| Output Module | Format、壓縮、通道、Audio Output 與輸出後處理 | Composition 本身的編輯長度 |

Adobe 官方文件區分 Render Settings 與 Output Module：前者決定渲染影格率、長度、解析度與圖層品質，後者決定格式、壓縮與其他輸出屬性。詳見 [Rendering and exporting basics](https://helpx.adobe.com/after-effects/desktop/render-and-export/basics-of-rendering-and-exporting/basics-rendering-exporting.html)。

## Step by Step：辨識 3D Layer 與 Camera

### Step 1：建立安全副本

- **操作**：複製一個 Composition，改名 `3D_Check`。開啟它，選取 `Title_Text`，打開 Timeline 的 3D Layer 開關。
- **應看到**：`Title_Text` 的 Transform 除了 X、Y，還出現 Z 軸與方向相關屬性。
- **如果沒有**：確認開啟的是立方體圖示，而且選取的是 `Title_Text`。

### Step 2：加入 Camera 並觀察差異

- **操作**：選 **Layer > New > Camera**，建立 Camera，再輕微改變視角。
- **應看到**：3D 圖層會受 Camera 視角影響；沒有開啟 3D 的圖層不會自動獲得深度。
- **如果沒有**：先不要做 Camera 動畫；確認 `Title_Text` 的 3D 開關與目前視圖。

### Step 3：回到正式輸出 Composition

- **操作**：回到 `Square_Practice`。
- **應看到**：正式 Composition 沒有因 `3D_Check` 的操作而被修改。
- **如果沒有**：關閉目前分頁，在 Project 面板重新開啟 `Square_Practice`。

## Step by Step：建立可核對的輸出

### Step 1：確認六秒預覽範圍

- **操作**：在 `Square_Practice` 將 Work Area 設為 0–6 秒，從頭播放一次。
- **應看到**：六秒內畫面完整，沒有意外黑幀或被關閉的必要圖層。
- **如果沒有**：先在 Timeline 修正 Work Area 或圖層眼睛，不要急著加入 Render Queue。

### Step 2：決定是否加入音訊

- **操作**：有合法可用音訊時，把它匯入 Project 的 `Assets` 並放進 Timeline；沒有音訊就明確採用無音訊版本。
- **應看到**：有音訊版本可在 Timeline 看到 Audio Layer；無音訊版本不需要 Audio Meter 證據。
- **如果沒有**：素材無法取得時使用無音訊備援，不要以缺少的音訊繼續設定。

### Step 3：把 Composition 加入 Render Queue

- **操作**：在 Project 面板選取 `Square_Practice`，選 **File > Export > Add to Render Queue**。
- **應看到**：Render Queue 出現一個新的 render item，名稱是 `Square_Practice`。
- **如果沒有**：確認選到的是 Composition，不是資料夾或素材，再重新加入。

### Step 4：檢查 Render Settings

- **操作**：點 render item 的 Render Settings 文字，核對 Quality、Resolution 與 Time Span。Time Span 應對應 0–6 秒 Work Area。
- **應看到**：對話框中的時間範圍與練習要求相同。
- **如果沒有**：取消輸出，回到 Composition 修正 Work Area，再刪除舊 render item 並重新加入。

### Step 5：檢查 Output Module

- **操作**：點 Output Module 文字，選擇授課電腦實測可用的格式；有音訊時開啟 Audio Output。
- **應看到**：Output Module Summary 顯示所選格式、通道與音訊狀態。
- **如果沒有**：先記錄目前設定，不要隨意切換多個格式；本頁格式仍須在授課機驗證。

### Step 6：指定輸出位置

- **操作**：點 Output To，指定 `ACP-AE-Practice/Exports/Square_Practice-test`，使用不會覆蓋舊檔的檔名。
- **應看到**：Render Queue 的 Output To 顯示可寫入的完整路徑，不再是 Needs Output。
- **如果沒有**：建立 `Exports` 資料夾或改選可寫入位置，再重新指定檔名。

### Step 7：留下設定證據並輸出

- **操作**：先擷取 Render Settings、Output Module、Output To 三處證據，再按 Render。
- **應看到**：狀態完成，指定資料夾出現輸出檔。
- **如果沒有**：保留錯誤訊息，先檢查 Output To 與磁碟空間，不要覆蓋原工程。

### Step 8：開啟輸出檔並另存工程

- **操作**：開啟輸出檔，核對長度、畫面、解析度與音訊；接著另存 `ACP-AE-Lab-v05.aep`。
- **應看到**：輸出檔可播放且符合規格，新版工程可重新開啟。
- **如果沒有**：依出錯項目回到 Step 4、5 或 6；不要直接重複 Render 同一個錯誤設定。

## Step by Step：同步練習與變式

### 同步練習：只輸出前三秒

1. 保持 Composition Settings 不變。
2. 建立新的 Render Queue 項目。
3. 在 Render Settings 把 Time Span 設為 0–3 秒。
4. 指定新的輸出檔名後執行測試輸出。
5. **通過標準**：檔案長度為三秒，而且你能指出改的是 Render Settings，不是 Output Module。

### 變式練習：輸出不同 Resolution

1. 再建立一個新的 Render Queue 項目。
2. 只修改該項目的 Render Settings > Resolution。
3. 使用不同檔名輸出，避免覆蓋第一個版本。
4. **通過標準**：兩個輸出項目的 Resolution 不同，但 `Square_Practice` 的 Composition 尺寸沒有改變。

## 完成檢查

- Work Area 範圍與 Render Settings 的 Time Span 相符。
- Output Module 格式與音訊開關符合交付規格。
- Output To 是可寫入路徑，檔名可辨識。
- 輸出檔可開啟，長度與畫面正確；若有音訊規格，實際可聽見。
- 證據圖不只顯示「Done」，還能看到三個設定層級。

## 修復

| 現象 | 回修位置 | 重跑起點 |
|---|---|---|
| Render Queue 顯示 Needs Output | Output To | 指定現有資料夾與新檔名 |
| 只輸出一小段或太長 | Render Settings > Time Span | 回到 Work Area 重設 0–6 秒後再加入佇列 |
| 檔案無聲 | Output Module > Audio Output、Timeline 音訊開關 | 先在 Preview 確認有聲，再重設輸出 |
| 影片清晰度不對 | Render Settings > Resolution | 不先改 Composition，只修正指定輸出項目 |
