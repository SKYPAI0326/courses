# 操作題 1–13：Composition、圖層與介面狀態

這一組先學會把長題目拆成六個小欄位，再開始操作。你會使用 `ACP-AE-Lab-PRAC1.aep` 的副本實作題 1、7、10；其餘十題先完成路徑卡，不在原工程直接試錯。

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | `ACP-AE-Lab-PRAC1.aep` 的複製檔 `ACP-AE-Q01-13.aep`、本頁 13 張路徑卡 |
| 完成物 | 題 1、7、10 的實作證據，題 2–6、8–9、11–13 的路徑與驗收 |
| 第一個動作 | 另存題組副本，在第 1 題下列出對象、層級與四個數值 |
| 成功訊號 | 未進入介面前，已能說出要在 Project、Composition、Timeline、Effect Controls 或 Render Queue 的哪一層操作 |
| 完成檢查 | 13 張卡皆有完成證據與復原位置；三題實作另存復原點 |

## Step by Step：先讀懂每一張操作路徑卡

1. **找動詞**：題目要你建立、修改、刪除、修剪，還是只調整檢視？
2. **找對象**：寫下完整名稱，例如 `Title_Text`，不要只寫「圖層」。
3. **判斷層級**：要在 Project、Composition、Timeline、View 還是 Render Queue 操作？
4. **抄下數值與時間**：寬高、fps、duration、Position 或 Work Area 都要逐項記錄。
5. **圈出不得改動項目**：例如「不改 Composition」「保留原 Keyframe」。
6. **先寫完成證據與復原位置**：知道要拍哪個畫面、出錯回哪裡後，才進 AE。

**Checkpoint**：六欄中有任何一欄不確定時，先停在路徑卡，不要用滑鼠猜功能。

## 十三張操作路徑卡

| 題 | 任務與作用層級 | 建議路徑 | 完成證據 | 復原位置 |
|---:|---|---|---|---|
| 1 | 依規格建新正方形 Composition；Composition | Composition > New Composition | Settings 中名稱、寬高、fps、duration | Composition Settings |
| 2 | 檢查 Action Safe，清除越界元素；視圖與 Layer | 開啟 Safe Margins，再移動或刪除指定層 | 安全區不再有題目指定的越界元素 | Undo／Position／Delete |
| 3 | 用紋理改變下方畫面；Layer Mode | Timeline Modes 欄位設 Blending Mode | 模式名與前後差異 | Mode 設回 Normal |
| 4 | 將指定圖層整段反向播放；Layer Time | Layer > Time > Time-Reverse Layer | 起訖畫面交換，圖層長度不變 | 再執行一次或 Undo |
| 5 | 讓元素依階段上移；Transform Keyframe | Position 起終 Keyframe，核對每階段時點 | 指定時間的 Position 值 | Position Keyframe |
| 6 | 在指定圖層建立椭圓可見區；Mask | 選層後使用 Ellipse Tool | Masks > Mask 1 與畫面範圍 | Mask Path / Feather |
| 7 | 將 Work Area 設到指定區間，並用它修剪 Composition；Composition Time | 先設 Work Area，再 Composition > Trim Comp to Work Area | Composition duration 與原 Work Area 一致 | 立即 Undo，或從前一版重開 |
| 8 | 建立指定的自訂 Render Settings；Render Queue | Add to Render Queue > Render Settings | Quality、Resolution、Time Span 的證據 | 刪除 render item 重加 |
| 9 | 修改現有文字內容；Text Layer | Type Tool 或 Text 屬性編輯 | Timeline 層名不必改，畫面文字正確 | Undo／重輸原文 |
| 10 | 新增、重命名、排序、鎖定指定圖層；Timeline | 依相依先建層、再命名與排序、最後鎖定 | Timeline 全圖 | 另存後再刪錯層 |
| 11 | 改變 Composition 視圖配置與 Resolution；View | Composition 面板下方的 View Layout / Resolution | 介面控制值正確，不必改 Composition Settings | 設回 1 View / Auto |
| 12 | 將雪花或亮部以指定混合模式疊加；Layer Mode | Timeline Modes 指定目標層 | Mode 欄位與畫面亮部效果 | Normal |
| 13 | 建立橫式 Logo Composition；Composition | New Composition 並依題幹輸入寬高、fps、duration | Settings 與 Project 面板名稱 | Composition Settings |

## 代表題實作

### 題 1：從文字規格建立 Composition

1. **準備**：在路徑卡寫下名稱 `Q01_Square`、1080 × 1080、29.97 fps、10 秒。
2. **操作**：選 **Composition > New Composition**，逐欄輸入上述數值。
3. **應看到**：Project 面板出現 `Q01_Square`，畫布為正方形。
4. **檢查**：關閉對話框後重新開啟 Composition Settings，不靠記憶核對五欄。
5. **留下證據**：擷取 Settings 畫面，另存 `Q01-done.aep`。
6. **卡住時**：只修正錯誤欄位；若改到原工程，停止保存並從題組副本重開。

### 題 7：Work Area 與 Trim

1. **準備**：在題組工程複製 `PRAC1_Title_6s`，改名 `Q07_Trim`，確認原版仍存在。
2. **操作**：開啟 `Q07_Trim`，把 Work Area 起點設為 1 秒、終點設為 5 秒。
3. **應看到**：Work Area 只涵蓋 1–5 秒；先留下修剪前證據。
4. **操作**：選 **Composition > Trim Comp to Work Area**。
5. **應看到**：Composition duration 變成 4 秒，內容從原本的 1 秒位置開始。
6. **卡住時**：若操作在原版，立刻 Undo 或關閉不保存；通過後不再用 `Q07_Trim` 做後續題目。

### 題 10：Timeline 圖層管理

1. **準備**：複製 `PRAC1_Title_6s`，改名 `Q10_Layers`。
2. **建立與命名**：建立或複製需要的圖層，依序命名 `Guide_Top`、`Title_Main`、`Accent_Bar`、`BG_Locked`。
3. **排序**：只處理上下順序，先不要改 Label 或 Lock。
4. **設定狀態**：替圖層指定 Label，確認眼睛開關，再鎖定 `BG_Locked`。
5. **應看到**：四個名稱、指定順序、Label、眼睛與 Lock 都在 Timeline 同時可見。
6. **卡住時**：Undo 最近一次修改，一次只重做命名、排序或狀態其中一類；不要刪除不確定的圖層。

## Step by Step：變式練習

1. 從題 2–6、8–9、11–13 選三題。
2. 每題只替換圖層名稱或一個數值，不改作用層級。
3. 操作前先寫下預測的畫面或設定變化。
4. 依六欄路徑卡完成操作與證據。
5. **通過標準**：實際結果與預測一致；若不同，能指出錯在對象、層級或數值。

## 修復

- **改到原始 Composition**：停止操作，不再保存；從題組起點副本重開。
- **選錯層**：Undo 後在 Timeline 大聲點名目標層，再重做單一修改。
- **介面值與工程值混淆**：先問「這是 View，還是 Composition 本身？」再選入口。
- **無法証明完成**：回到題幹的每一條要求，讓數值、開關或畫面狀態同時入鏡。
