# 介面、Project 與 Composition 規格

這一課從 AE 的空白畫面開始。你會先存檔，再建立一個「名稱、寬高、影格率與長度」都符合規格的 Composition，最後重新打開設定畫面逐欄檢查。

## 本課英文名詞

| 英文介面名稱 | 中文理解 | 實際用途 |
|---|---|---|
| Project | 工程檔 | 保存素材、Composition 與設定，副檔名是 `.aep` |
| Project panel | 專案面板 | 管理素材、Composition 與資料夾 |
| Composition | 合成 | 一段動畫的工作畫布，決定尺寸、影格率與長度 |
| Composition panel | 合成預覽面板 | 顯示目前時間點的畫面 |
| Timeline | 時間軸 | 排列 Layer、查看時間並設定動畫 |
| Layer | 圖層 | 放入 Composition 的文字、圖形、圖片、影片或音訊 |
| Composition Settings | 合成設定 | 修改合成名稱、寬高、影格率與總長度 |
| fps / Duration | 每秒影格數／總長度 | 控制每秒畫面張數與合成可使用多久 |
| File > Save As | 檔案 > 另存新檔 | 先替 Project 指定資料夾與檔名 |
| New Composition | 新增合成 | 開啟建立新 Composition 的設定視窗 |
| Name / Width / Height | 名稱／寬度／高度 | 設定合成名稱與畫布尺寸 |
| Frame Rate | 影格率 | 設定每秒播放多少格 |
| Pixel Aspect Ratio | 像素長寬比 | 一般螢幕練習選 Square Pixels |
| Background Color | 背景顏色 | 設定合成預覽底色，不會建立背景 Layer |
| Workspace | 工作區 | 控制面板排列，面板不見時可恢復配置 |

## 任務契約

| 欄位 | 內容 |
|---|---|
| 學員問題 | 題目同時給尺寸、fps 與 duration 時，要到哪裡設定？ |
| 輸入 | 可啟動的 AE、可寫入的 `ACP-AE-Practice` 資料夾、本頁規格卡 |
| 完成物 | `ACP-AE-Lab.aep`，內含 `Square_Practice` Composition |
| 第一個動作 | 建立空白 Project，立即另存為 `ACP-AE-Practice/ACP-AE-Lab.aep` |
| 成功訊號 | 視窗標題顯示檔名，Project 面板可見且工程可重新開啟 |
| 交接 | 保留 `Square_Practice`，CH1-2 在其中建立圖層 |

## Step by Step：建立正方形練習畫布

### Step 1：先建立空白工程並存檔

- **操作**：開啟 AE，選擇建立新的 Project。接著選 **File > Save As > Save As**，存到 `ACP-AE-Practice` 資料夾，檔名輸入 `ACP-AE-Lab.aep`。
- **應看到**：AE 視窗標題出現 `ACP-AE-Lab.aep`，檔案也出現在指定資料夾。
- **如果沒有**：先確認資料夾可寫入；不要繼續建立 Composition，避免工程尚未存檔。

### Step 2：打開 Composition 設定

- **操作**：在最上方選單選 **Composition > New Composition**。
- **應看到**：畫面出現 New Composition Settings 對話框，可以輸入名稱、Width、Height、Frame Rate 與 Duration。
- **如果沒有**：先點一下 AE 視窗，確認目前使用的是 AE 選單，再重新選一次。

### Step 3：輸入畫布名稱與尺寸

- **操作**：Name 輸入 `Square_Practice`；Width 輸入 `1080`；Height 輸入 `1080`；Pixel Aspect Ratio 選 Square Pixels。
- **應看到**：Width 與 Height 都是 1080，畫布比例為正方形。
- **如果沒有**：檢查寬、高是否輸入反了，也不要在數值後加 `px`。

### Step 4：輸入時間規格

- **操作**：Frame Rate 輸入 `29.97`；Duration 輸入 `00:00:10:00`。
- **應看到**：Duration 表示 0 小時、0 分、10 秒、0 個影格。
- **如果沒有**：逐段輸入完整時間碼；不要只輸入 `10` 後直接確認。

### Step 5：完成 Composition

- **操作**：Background Color 設為深灰，按 **OK**。
- **應看到**：Project 面板出現 `Square_Practice`；中央 Composition 面板是深灰正方形；下方 Timeline 暫時沒有圖層。
- **如果沒有**：先在 Project 面板連按兩下 `Square_Practice`。若 Project 面板找不到它，回到 Step 2 重新建立。

### Step 6：重新打開設定並留下證據

- **操作**：選取 `Square_Practice`，再選 **Composition > Composition Settings**。逐欄核對名稱、寬、高、fps 與 duration，然後擷取設定畫面。
- **應看到**：五項規格都和本頁相同，而且截圖能同時辨識 Composition 名稱與設定值。
- **如果沒有**：直接在 Composition Settings 修正錯誤欄位，按 **OK** 後再重新開啟並擷圖。

中間狀態應為：Project 面板有一個 Composition；Composition 面板是深灰正方形；Timeline 尚無圖層。

## Step by Step：同步練習與變式

### 同步練習：建立橫式 Composition

1. 選 **Composition > New Composition**。
2. 名稱輸入 `Wide_Practice`，尺寸輸入 1920 × 1080，Frame Rate 輸入 24，Duration 輸入 8 秒。
3. 按 **OK** 後重新開啟 Composition Settings。
4. **通過標準**：名稱、寬、高、fps、duration 五項都正確，Project 面板可看到 `Wide_Practice`。
5. **卡住時**：回到上面的 Step 2–6，只查看操作入口，不照抄 `Square_Practice` 的數值。

### 變式練習：建立直式 Composition

1. 建立 `Vertical_Check`，尺寸輸入 1080 × 1920，Frame Rate 輸入 30，Duration 輸入 6 秒。
2. 關閉設定對話框，再重新打開。
3. 不看規格卡，依序口述要檢查的五項：名稱、Width、Height、Frame Rate、Duration。
4. **通過標準**：畫布是直式，五項設定皆正確。
5. **卡住時**：若畫面變成橫式，先只檢查 Width 與 Height，不要重建整個工程。

## 完成檢查

- `Square_Practice` = 1080 × 1080、29.97 fps、10 秒。
- `Wide_Practice` = 1920 × 1080、24 fps、8 秒。
- `Vertical_Check` = 1080 × 1920、30 fps、6 秒。
- Project 已儲存，關閉後能重新開啟。
- 證據圖可同時看到 Composition 名稱與全部規格。

## 修復

| 現象 | 回修位置 | 重跑起點 |
|---|---|---|
| 畫面方向風格對，寬高卻相反 | Composition Settings 的 Width / Height | 更正後重新擷圖 |
| 播放太快或太慢 | Composition Settings 的 Frame Rate | 核對數值，不以預覽感覺判定 |
| 面板排列不同 | Window > Workspace，重設目前 Workspace | 找回 Project、Composition、Timeline 三面板 |
| 工程尚未儲存 | Save As | 先存到指定資料夾再繼續 |

**版本備註**：本課使用 Adobe After Effects 2025 的功能與介面名稱。不同版本或語系的選單名稱與位置可能略有差異，請以功能名稱、設定值與完成結果核對。如何修改視圖與 Resolution 可查閱 [Adobe 官方視圖說明](https://helpx.adobe.com/after-effects/desktop/view-and-preview/preview-video-and-audio/modifying-using-views.html)。
