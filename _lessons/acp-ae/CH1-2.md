# 素材、圖層、Timeline 與 Transform

這一課會在上一課的 `Square_Practice` 裡放入背景、橘色強調帶與文字。每次修改前都先在 Timeline 點選正確圖層，再改它的屬性。

## 本課英文名詞

| 英文介面名稱 | 中文理解 | 實際用途 |
|---|---|---|
| Solid | 純色圖層 | 建立滿版背景或單一色塊 |
| Shape Layer | 形狀圖層 | 製作矩形、圓形等向量圖形 |
| Text Layer | 文字圖層 | 輸入並排版標題或內文 |
| Transform | 變形屬性群組 | 集中控制圖層的位置、大小、旋轉與透明度 |
| Position / Scale | 位置／縮放 | 移動、放大或縮小圖層 |
| Rotation / Opacity | 旋轉／不透明度 | 改變角度、顯示程度或淡出 |
| Anchor Point | 錨點 | 圖層縮放與旋轉時使用的中心點 |
| CTI | 目前時間指示器 | 決定 Timeline 正在查看哪一刻 |
| Make Comp Size | 符合合成尺寸 | 建立 Solid 時讓它填滿目前 Composition |
| Rectangle Tool / Type Tool | 矩形工具／文字工具 | 分別用來畫 Shape 與建立文字 |
| Shape Path | 形狀路徑 | 控制 Shape 本身的寬、高與輪廓 |
| Label | 色彩標籤 | 用顏色區分不同用途的圖層 |
| Undo | 復原 | 操作結果不對時退回上一步 |

## 任務契約

| 欄位 | 內容 |
|---|---|
| 輸入 | CH1-1 的 `ACP-AE-Lab.aep`、`Square_Practice` |
| 完成物 | `BG_Solid`、`Accent_Shape`、`Title_Text` 三個圖層的標題卡 |
| 第一個動作 | 在 Project 面板建立 `Comps`、`Assets`、`Exports` 資料夾，將 `Square_Practice` 移入 `Comps` |
| 成功訊號 | Timeline 三層名稱清楚，從上到下是文字、強調形狀、背景 |
| 交接 | CH1-3 動畫化 `Title_Text` 與 `Accent_Shape` |

## 先判斷操作層級

Project 面板中的物件是「可以拿來使用的項目」；放進 Composition 後，才會在 Timeline 變成一列 Layer 圖層。同一個項目可以放進不同 Composition，也可以重複放入同一個 Composition。

Transform 的 Position、Scale、Rotation、Opacity 只會改目前選取的圖層。看到數值不對時，先看 Timeline 哪一列被選取，再看 CTI 在哪個時間。

## Step by Step：建立三層標題卡

### Step 1：整理 Project 面板

- **操作**：在 Project 面板底部按資料夾圖示，依序建立 `Comps`、`Assets`、`Exports`。把 `Square_Practice` 拖進 `Comps`。
- **應看到**：Project 面板有三個資料夾；展開 `Comps` 可以看到 `Square_Practice`。
- **如果沒有**：確認拖曳的是 Project 面板中的 Composition，不是 Timeline 的圖層。

### Step 2：建立背景 Solid

- **操作**：在 Project 面板連按兩下 `Square_Practice` 開啟它。選 **Layer > New > Solid**，名稱輸入 `BG_Solid`，尺寸使用 Make Comp Size，顏色設為深灰。
- **應看到**：Timeline 出現 `BG_Solid`，中央畫面全部變成深灰。
- **如果沒有**：確認目前開啟的是 `Square_Practice`；若 Solid 尺寸不滿版，重新建立並選 Make Comp Size。

### Step 3：建立橘色強調帶

- **操作**：先按 Timeline 空白處，確定沒有圖層被選取。選 Rectangle Tool，在畫面拖出橘色矩形，將新圖層改名 `Accent_Shape`。
- **應看到**：Timeline 多出 `Accent_Shape`；畫面上出現橘色矩形。
- **如果沒有**：如果矩形變成 `BG_Solid` 的 Mask，立刻 Undo，取消圖層選取後重畫。

### Step 4：建立標題文字

- **操作**：選 Type Tool，在畫面點一下並輸入 `MOTION STARTS HERE`。使用電腦現有的無襯線字型，將圖層改名 `Title_Text`。
- **應看到**：Timeline 多出 `Title_Text`，畫面能讀到完整文字。
- **如果沒有**：確認文字顏色和背景不同；若字型顯示缺失，改用電腦已有的無襯線字型。

### Step 5：排好圖層順序並鎖定背景

- **操作**：在 Timeline 拖曳圖層，從上到下排成 `Title_Text`、`Accent_Shape`、`BG_Solid`。開啟 `BG_Solid` 的 Lock，並替三層設定不同 Label 顏色。
- **應看到**：文字在最上方，橘色矩形在文字後方，背景在最下方；`BG_Solid` 顯示鎖頭。
- **如果沒有**：先只調整順序，不要同時改 Position；文字被遮住時，把 `Title_Text` 拖到最上方。

### Step 6：調整文字位置

- **操作**：在 Timeline 點選 `Title_Text`，展開 **Transform**。只修改 Position，讓文字位於畫面中央偏上；Scale 保持 100%。
- **應看到**：只有文字移動，橘色矩形與背景位置不變。
- **如果沒有**：Undo，確認 Timeline 藍色選取列是 `Title_Text`，再修改 Position。

### Step 7：調整強調帶

- **操作**：改選 `Accent_Shape`，展開 Transform，調整 Position 與 Scale，讓矩形位於文字後方。
- **應看到**：只有橘色矩形改變；文字仍在中央偏上。
- **如果沒有**：先把 Scale 還原為 100%，一次只改 Position 或 Scale 其中一項。

### Step 8：另存新版

- **操作**：選 **File > Save As > Save As**，另存為 `ACP-AE-Lab-v02.aep`，不要覆蓋上一課檔案。
- **應看到**：視窗標題顯示新檔名，關閉再重開後三個圖層仍存在。
- **如果沒有**：檢查存檔資料夾與檔名；未確認新檔存在前不要進入下一課。

## 選取快查

| 想改什麼 | 先選哪裡 | 完成證據 |
|---|---|---|
| 文字位置 | Timeline 的 `Title_Text` | Position 值與畫面位置同時變化 |
| 強調帶大小 | `Accent_Shape` | Scale 或 Shape Path 尺寸變化 |
| 背景可見性 | `BG_Solid` 的眼睛開關 | 關閉後出現透明格 |
| 圖層順序 | Timeline 圖層列 | 上層遮住下層重疊區 |

## Step by Step：同步練習與變式

### 同步練習：重新排位置

1. 保留原本三個圖層，不新增素材。
2. 選 `Accent_Shape`，把強調帶移到文字左側。
3. 選 `Title_Text`，把文字移回畫面中央。
4. **通過標準**：圖層名稱與順序不變，只有兩層的 Transform 數值改變。
5. **卡住時**：若整張畫面一起移動，Undo，檢查是否誤選 Composition 或多選圖層。

### 變式練習：建立自己的標題卡

1. 在 Project 面板複製 `Square_Practice`，改名 `Square_Variant`。
2. 開啟複製版，把 `Title_Text` 的文字改成自己的課程名。
3. 把 `Accent_Shape` 調整成細線，但不要改變三層順序。
4. **通過標準**：`Square_Practice` 保持原樣；`Square_Variant` 有新文字與細線強調帶。
5. **口頭檢查**：說明你改了文字內容、Transform，或兩者都有；不能只回答「我改了圖層」。

## 完成檢查

- Project 面板的 Comps、Assets、Exports 資料夾都存在。
- Timeline 沒有 `Shape Layer 1`、`Text 1` 等難以辨識名稱。
- `BG_Solid` 已鎖定；三層順序正確。
- 選取任一圖層時，你能在畫面上指出它的對應物件。
- 工程可從 `ACP-AE-Lab-v02.aep` 重開。

## 修復

| 現象 | 回修位置 | 重跑起點 |
|---|---|---|
| 改到錯的物件 | Timeline 選取列 | Undo，選對圖層再改 |
| 文字被矩形遮住 | Timeline 圖層順序 | 把 `Title_Text` 移到 `Accent_Shape` 上方 |
| 背景跟著被拖移 | `BG_Solid` 鎖定開關 | Undo 後鎖定背景 |
| 不知哪個值被改 | 選取目標圖層後顯示 Transform | 與本頁規格相比，只復原不合格值 |
