# 專案二：直式限時動態廣告

專案一做的 Logo 開場是橫的。成果展還需要一支放在 IG、FB 限時動態的直式廣告，專案二就做這一支，而且直接把專案一的 Logo 拿來用。

專案一裡每一層都各做各的。這次的重點是圖層之間的關係：一層決定另一層哪裡看得到、一層帶著其他幾層一起動、一段做好的動畫整包放進另一個畫面。

## 做完的樣子

一支直式、8 秒的影片：

| 時間 | 畫面 |
|---|---|
| 整段 | 深藍色背景，上面有淡淡的雲霧紋理 |
| 0 到 6 秒 | 畫面上方播專案一的 Logo 開場，6 秒時 Logo 消失 |
| 1 到 2 秒 | 白色大標題「畢業成果展」，一道黃色的光從左到右掃過字裡面 |
| 3 到 3.5 秒 | 一張圓形的作品圖和一行小字，從底部一起彈出來 |
| 5 到 5.5 秒 | 日期、地點、免費入場三行字，從畫面下方一起滑上來 |

## 開始前

- 打開專案一的 `EXPO.aep`，選 **File > Save As > Save As**，存成 `EXPO-02.aep`。做壞了還能回到專案一的版本。
- 每一步一樣分成「做法」和「你會看到」，對得上再往下；對不上看「如果不一樣」。

## 1. 直式畫布

做法：

1. 選 **Composition > New Composition**。
2. 填：
   - Composition Name：`Story_Ad`
   - Width `1080`、Height `1920`（直式是寬 1080、高 1920）
   - Frame Rate：`30`
   - Duration：`0:00:08:00`
3. 按 OK。
4. 在 Project 面板把 `Story_Ad` 拖進 `Comps` 資料夾。

你會看到：Composition 面板是一塊直長的畫布。

如果不一樣：畫布是橫的，表示寬高打反了。選 **Composition > Composition Settings**，把 Width 改 1080、Height 改 1920。

## 2. 把專案一的 Logo 放進來

做法：

1. 從 Project 面板把 `Logo_Open` 拖進 `Story_Ad` 的 Timeline。

你會看到：整段 Logo 動畫變成 Timeline 上的**一列**。畫面上的 Logo 太寬，左右被切掉。

為什麼是一列：Composition 可以像素材一樣放進另一個 Composition，裡面有幾層、幾個 Keyframe，都包在這一列裡。這種放法叫做巢狀（nested）。

2. 展開這一列的 Transform，Scale 改成 `56`。
3. 滑鼠移到 Position 的第二個數字上，按住往左拖，看著 Logo 往上移，移到畫面上方約四分之一處放開。

你會看到：整段 Logo 一起縮小，移到上方，但它是一條深藍色橫帶，因為專案一的深藍背景也一起進來了。

為什麼是 56：直式畫面寬 1080，Logo 原本寬 1920，1080 ÷ 1920 約等於 0.56。

我們只要 Logo，不要它的背景：

4. 在 Timeline 雙擊 `Logo_Open` 這一列，會打開 `Logo_Open` 本身。
5. 點 `BG` 那一列最左邊的眼睛圖示，把它關掉。
6. 點 Timeline 上方的 `Story_Ad` 分頁，回到直式廣告。

你會看到：橫帶不見了，只剩 Logo。

要記住的規則：在 `Logo_Open` 裡改的東西，所有放了它的地方都會跟著變。專案一已經輸出的 `Logo_Open.mp4` 是另一個檔案，不受影響。

另外，播到 6 秒時 Logo 會消失。這是預期的：`Logo_Open` 只有 6 秒，色條在 6 秒結束。這支廣告最後 2 秒本來就留給日期地點。

## 3. 背景加紋理：第一個 Effect 與混合模式

做法：

1. 選 **Layer > New > Solid**，名稱 `BG_Story`，按 **Make Comp Size**，顏色選深藍，按 OK。
2. 把 `BG_Story` 拖到最底層，點它的鎖頭鎖住。
3. 再選 **Layer > New > Solid**，名稱 `Texture`，按 **Make Comp Size**，按 OK。把它放在 `BG_Story` 正上方。
4. 選取 `Texture`，選 **Effect > Noise & Grain > Fractal Noise**。

你會看到：

- 畫面變成整片灰色雲霧，深藍被蓋住了。這是預期的，下一步處理。
- 左上角多了一個 **Effect Controls** 分頁，裡面是 Fractal Noise 的設定。效果套在哪一層，設定就在這裡調。

為什麼按 Make Comp Size 會變成 1080 × 1920：它跟著目前打開的 Composition 尺寸。

要讓雲霧「疊在」深藍上，而不是蓋住，要改圖層的 **Blending Mode**（混合模式）：

5. 在 Timeline 圖層列右側找 **Mode** 欄位。看不到的話，按 Timeline 面板左下方的 **Toggle Switches / Modes** 按鈕，它會在開關欄和 Mode 欄之間切換。
6. 把 `Texture` 的 Mode 從 Normal 改成 **Screen**，看一下畫面；再改成 **Overlay**，看一下畫面。
7. 最後留在 **Overlay**。展開 `Texture` 的 Transform，Opacity 改成 `40`。

你會看到：

- Screen：只有亮的部分疊上去，整體變亮。
- Overlay：深藍回來了，上面多了深淺紋理。
- Opacity 40 之後，紋理變淡。

Mode 欄管的是「這一層的顏色怎麼和下面的圖層混在一起」。

## 4. 大標題加掃光：Track Matte

先打標題：

1. 用 **Type Tool** 打 `畢業成果展`，在 Character 面板選一個中文字型，白色、大小約 150。
2. 點箭頭圖示結束打字，改名 `Headline`。
3. 打開 Align 面板（**Window > Align**），按 **Align Horizontal Center**，再把標題拖到 Logo 下方。

再做一道光：

4. 點 Timeline 空白處取消選取。沒有取消的話，畫的形狀會變成被選取那一層的遮罩。
5. 用 **Rectangle Tool**，Fill 選黃色、Stroke 選 None，畫一條比標題還高的直長條，改名 `Light`。
6. 展開 `Light` 的 Transform，Rotation 輸入 `20`。

你會看到：一條斜斜的黃色長條。

讓光從左掃到右：

7. 時間碼 `0:00:01:00`。用箭頭工具把 `Light` 拖到標題左邊外面，按 Position 的碼錶。
8. 時間碼 `0:00:02:00`。把 `Light` 拖到標題右邊外面。
9. 框選這兩個菱形，選 **Animation > Keyframe Assistant > Easy Ease**。

你會看到：播放時，黃光從左到右掃過整個畫面。

現在要讓光只在字裡面出現。讓一層的可見範圍由另一層的形狀決定，這叫 **Track Matte**（軌道遮罩）。

10. 在 `Light` 那一列找 **Track Matte** 欄位（在 Mode 欄旁邊）。
11. 按住欄位旁的螺旋圖示（pick whip），拖到 `Headline` 那一列放開。
12. 播放。

你會看到：光只在字裡面出現，但白色的字本身也不見了，只有光掃過時看得到。這是預期的：`Headline` 被拿去當形狀之後，AE 會自動把它的顯示關掉。

補一份白字當底：

13. 選 `Headline`，選 **Edit > Duplicate**。
14. 新複製出來的那一份改名 `Headline_White`，拖到 `Light` 的下面，確認它的眼睛是開著的。

你會看到：白字一直都在，黃光在字裡面掃過。

Track Matte 欄位旁邊有兩個小圖示，可以切換用來源層的 **Alpha**（透明度）或 **Luma**（亮度）當形狀，也可以反轉。文字的形狀來自透明度，所以用 Alpha。

## 5. 圓形作品圖：Mask

還沒有作品照片，先用漸層色塊代替。

做法：

1. 選 **Layer > New > Solid**，名稱 `Photo`。這次**不要**按 Make Comp Size，Width、Height 都打 `600`（如果 Lock Aspect Ratio 有勾，先取消），顏色隨意，按 OK。
2. 選取 `Photo`，選 **Effect > Generate > Gradient Ramp**。

你會看到：一塊 600 × 600 的漸層方塊。

接著裁成圓形。這次要**保持 `Photo` 被選取**，因為我們就是要把圓畫在它身上：

3. 確認 Timeline 上 `Photo` 是反白的。
4. 選 **Ellipse Tool**，在方塊上按住 Shift 拖出一個圓。

你會看到：方塊變成圓形。展開 `Photo`，和 Transform 並排多了一組 **Masks > Mask 1**。

5. 展開 Mask 1，**Mask Feather** 設 `10`。

你會看到：圓的邊緣變柔和。Mask 1 底下還有 **Mask Expansion**，可以讓圓往外擴或往內縮。

Mask 和 Track Matte 的差別：Mask 畫在圖層自己身上；Track Matte 是借另一層的形狀。

## 6. 讓作品圖晚一點出現：In Point

作品圖要在 3 秒才出現。

Timeline 右側每一列有一條色條，代表這一層在哪一段時間存在。色條的開頭叫 **In Point**，結尾叫 **Out Point**。

做法：

1. 時間碼 `0:00:03:00`，藍色時間線移到 3 秒。
2. 把 `Photo` 色條的**左端**往右拖，拖到藍色時間線的位置放開。

你會看到：`Photo` 的色條從 3 秒才開始；播放時，作品圖 3 秒才出現。差一兩格沒關係。

拖色條的左端是剪掉開頭，拖右端是剪掉結尾。

## 7. 作品圖和小字一起彈出：Pre-compose

做法：

1. 用 Type Tool 在作品圖下方打 `作品搶先看`，改名 `Caption`。
2. 把 `Caption` 色條的左端也拖到 3 秒。
3. 按住 Ctrl（Mac 是 Command）點 `Photo` 和 `Caption`，兩列同時選取。
4. 選 **Layer > Pre-compose**。
5. 名稱填 `Photo_Card`，選 **Move all attributes into the new composition**，**Open New Composition** 不要勾，按 OK。

你會看到：兩列變成一列 `Photo_Card`；Project 面板多了一個同名的 Composition。`Photo_Card` 的色條可能從 0 秒開始，也可能從 3 秒開始，兩種都可以，裡面的兩層本來就是 3 秒才出現。

為什麼要包起來：如果分別替兩層做縮放，它們會各自朝自己的中心縮，彈出時會分開。包成一層，就會一起動。

這和第 2 步是同一件事，方向相反：第 2 步把現成的 Composition 放進來；這一步把幾層打包成新的 Composition。

做彈出：

6. 在 Timeline 選 `Photo_Card`，點工具列上的 **Pan Behind Tool**，把小十字（錨點）拖到作品圖的底部中央。點回箭頭工具。
7. 展開 `Photo_Card` 的 Transform。
8. 時間碼 `0:00:03:00`：Scale 改 `0`，按碼錶。
9. 時間碼 `0:00:03:10`：Scale 改 `110`。
10. 時間碼 `0:00:03:15`：Scale 改 `100`。
11. 框選三個菱形，選 **Animation > Keyframe Assistant > Easy Ease**。

你會看到：播放時，作品圖連同小字一起從底部彈出，稍微衝過頭再回到原本大小。

## 8. 日期地點：靠近邊緣要看安全框

做法：

1. 用 Type Tool 打三行，每一行各自一層：`12.18 – 12.20`、`教育館 B1 展廳`、`免費入場`。放在畫面下方。
2. Composition 面板下方有一個像井字的按鈕（**Choose grid and guide options**），點開選 **Title/Action Safe**。

你會看到：畫面上出現兩個框。外框是 **Action Safe**，重要的動作要在框內；內框是 **Title Safe**，文字要在框內。

為什麼要看：手機限動的上下邊緣常被介面蓋住，太靠邊的字會看不到。

3. 三行字如果超出內框，往上移。
4. 同時選這三層，在 Align 面板按 **Align Horizontal Center**。
5. 選最下面那一行，展開 Transform，在 Position 的第二個數字直接打 `1620`。
6. 再按一次井字按鈕，選 **Title/Action Safe**，把安全框關掉。

你會看到：三行字左右置中；最下面一行離畫面底部 300 像素（畫面高 1920，1920 − 300 = 1620）。直接打數字比拖曳準。

## 9. 三行一起滑上來：Null 與 Parent

三行字要一起從畫面外滑上來。分別做三組動畫很麻煩，也很難對齊，所以讓一層帶著它們動。

做法：

1. 選 **Layer > New > Null Object**，改名 `Info_CTRL`。

你會看到：Timeline 多一列，畫面上只有一個小方框。**Null** 是看不見的圖層，有位置、縮放、旋轉，專門拿來帶動別的圖層。

2. 在三行字那三列，找 **Parent & Link** 欄位（顯示 None）。按住旁邊的螺旋圖示，拖到 `Info_CTRL` 放開。三行都做一次。

你會看到：三行的 Parent & Link 欄位都顯示 `Info_CTRL`。用箭頭工具拖動 `Info_CTRL` 的小方框，三行字會一起移動。試完選 **Edit > Undo** 放回原位。

子層跟著父層移動、縮放、旋轉，這叫 **Parenting**（父子關係）。

做動畫只動 `Info_CTRL`。三行字現在的位置就是要停的位置，所以先記終點：

3. 展開 `Info_CTRL` 的 Transform。
4. 時間碼 `0:00:05:15`：按 Position 的碼錶。
5. 時間碼 `0:00:05:00`：滑鼠移到 Position 的第二個數字，按住往右拖，直到三行字完全移出畫面下方。
6. 框選兩個菱形，套用 **Easy Ease**。

你會看到：5 秒時三行字從畫面下方一起滑上來，停在原本的位置。

## 10. 先輸出一版低解析度檢查

先輸出一版小的看整體節奏，比一直在 AE 裡預覽快。

做法：

1. 在 Project 面板選 `Story_Ad`，選 **Composition > Add to Render Queue**。
2. 點 **Render Settings** 右邊的藍字：**Resolution** 選 **Half**，確認 **Time Span** 是整段 8 秒，按 OK。
3. **Output Module** 的 Format 選 **H.264**。
4. **Output To** 存到 `EDTECH-EXPO`，檔名 `Story_Ad_draft.mp4`。
5. 按 **Render**，播放這個檔案看一遍。
6. 有要改的就回 Timeline 改。改完再做一次第 1 到 5 步，這次 Resolution 選 **Full**，檔名 `Story_Ad.mp4`。
7. 選 **File > Save**。

你會看到：`Story_Ad_draft.mp4` 畫面較小、較快算完；`Story_Ad.mp4` 是完整尺寸的直式 8 秒影片。

兩個設定的分工：**Render Settings** 管「怎麼算」，例如解析度、要算哪一段時間；**Output Module** 管「存成什麼檔」，例如格式。

## 自己做一次

1. 把 `Texture` 的 Mode 改成 **Screen**、Opacity 改成 `20`，和 Overlay 比較，選你喜歡的。
2. 讓 `Photo_Card` 在 7 秒縮回去：
   - 時間碼 `0:00:06:15`，按 Scale 左邊的菱形按鈕（**Add or remove keyframe at current time**），在這裡加一個 Keyframe。
   - 時間碼 `0:00:07:00`，Scale 改 `0`。
3. 把 `Info_CTRL` 的 Scale 改成 `90`。

完成後檢查：

- 白字一直看得到，黃光只出現在字裡。
- 作品圖和小字一起彈出，7 秒一起縮回。
- 三行字一起變小，Parent & Link 欄位都是 `Info_CTRL`。

## 這次做過的事在哪裡

| 你做過的事 | 在哪裡做 | 題目會稱為 |
|---|---|---|
| 建直式畫布、改寬高 | Composition 選單 | Composition |
| 打開安全框 | Composition 面板下方的井字按鈕 | Composition（Title/Action Safe） |
| 把 Logo 整段放進來、把兩層打包 | Project 面板、Layer > Pre-compose | Project（巢狀 Composition） |
| 手動設尺寸的 Solid、Null、剪色條開頭 | Layer 選單、Timeline 色條 | Layer（In Point／Out Point） |
| 混合模式、光只在字裡、父子關係、眼睛開關 | Timeline 的 Mode、Track Matte、Parent & Link 欄位 | Timeline 欄位 |
| 旋轉、圓形裁切、柔化邊緣、彈出動畫 | Timeline 圖層展開的 Transform、Masks | Timeline 屬性 |
| 雲霧紋理、漸層 | Effect 選單，設定在 Effect Controls | Effect |
| 低解析度與正式版輸出 | Render Queue 的 Render Settings、Output Module | Render Queue |
