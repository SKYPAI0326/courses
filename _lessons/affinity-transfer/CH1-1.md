## 教學流程（Teaching Flow）

### 破題 / Hook

阿凱在弄一下工作室收到一份既有品牌 brief：同一組內容要做成社群主視覺、可縮放的標誌資產，以及後續可修改的多頁宣傳品。他原本用 Illustrator、Photoshop、InDesign 分工完成；今天要把第一個工作環境搬到 Affinity，先確定自己能找到正確工作區、建立可繼續編輯的文件，並知道哪些 Adobe 概念不能直接照搬。

本單元只處理「如何在 Affinity 找到工作位置並建立可工作的文件」，不處理完整 logo 繪製、修圖或排版。完成後，你會留下 `affinity-transfer-ch1.af`（Affinity 原始檔）與一份「Adobe → Affinity 工作區對照表」。這兩份成果會在 CH2、CH3、CH4 重複使用。

開始前先固定五個答案：

1. **我現在在哪裡？** 你正在把一個原本依賴三套 Adobe 軟體的品牌任務搬到 Affinity；若工作區找錯，後面會把向量、像素與版面操作混在一起。
2. **我手上有什麼？** 只有已安裝的 Affinity 3.2.3 與一個空白文件建立規格：寬 1920 px、高 1080 px、RGB／8、sRGB、無出血。CH1 不要求外部 AI、PSD 或 IDML 檔；若要對照參考原始檔，從 `assets/affinity-transfer/reference/CH1-1-reference.af` 取得，當前狀態為 `BLOCK`。
3. **我要留下什麼？** 一份名為 `affinity-transfer-ch1.af` 的可再編輯文件，以及完成 6 列對照的 `Adobe → Affinity 工作區對照表`。
4. **我第一步做什麼？** 開啟 Affinity，使用 `File > New` 建立上述規格的空白文件。
5. **我怎麼知道可以繼續？** 畫布出現 1920 × 1080 的空白文件，文件色彩顯示為 RGB／8、sRGB；若沒有，回到「步驟 1」修正文件設定，不要先建立圖形。

### 概念 / Concepts

- **工作區（Studio）** — 一組針對任務排列的工具與面板；在本課程中，它決定你當下看到哪些工具，不等於另一個獨立軟體。
- **Vector 工作區** — 處理路徑、形狀、文字與可縮放圖形；對照 Illustrator 的主要繪圖工作。
- **Pixel 工作區** — 處理像素畫筆、選取、修圖與點陣影像；對照 Photoshop 的主要編修工作。
- **Layout 工作區** — 處理頁面、文字框、圖片框與多頁結構；對照 InDesign 的主要排版工作。
- **Affinity 原始檔（`.af`）** — 保存文件中的圖層、向量、像素與文字，讓你可以回頭修改；它不是交給印刷廠的最終輸出檔。
- **對照表** — 把「原本在 Adobe 做的任務」記成「Affinity 入口、預期結果、差異限制」；本例用它避免只記住按鈕位置，卻忘記交付條件。

Affinity 將 Vector、Pixel、Layout 工具放在同一個應用程式內，因此同一份文件可以在不同工作區之間切換。切換後工具列與面板會改變，但文件本身不會因此自動變成另一種格式。這是與過去「開另一個 Adobe 應用程式」不同的工作習慣：你要先辨認目前的工作區，再決定下一個工具。

把 Adobe 任務轉成 Affinity 工作區時，先用「物件類型」判斷，不用先背按鈕位置：

| 原本的 Adobe 任務 | Affinity 先切換到 | 第一個要找的物件或面板 | 本課先驗證的結果 |
|---|---|---|---|
| 製作可縮放標誌 | Vector | 形狀、鋼筆、節點、Layers | 形狀仍可縮放與選取 |
| 調整照片色調 | Pixel | 像素圖層、調整、遮色片 | 像素圖層可獨立隱藏 |
| 編排多頁文字 | Layout | 頁面、文字框、文字樣式 | 文字仍可重新輸入 |
| 管理圖層順序 | 三者皆可 | Layers | 每一類物件可單獨控制 |
| 準備輸出檔 | 依內容選擇 | Export／文件資訊 | 輸出設定與原始檔分開 |
| 跨檔案交接 | 先用空白檔驗證 | Import／Open | 不把「開得開」誤認為完整相容 |

完整示範的輸入是三個物件名稱與它們的類型：`V-logo-test`（Vector 形狀）、`P-brush-test`（Pixel 圖層）、`L-text-test`（Layout 文字框）。處理順序是先建立文件，再切換工作區建立物件，接著在 Layers 中命名與隱藏測試。中間結果是每次只隱藏一個前綴時，畫布只少一種內容；完成品是重新開檔後三種物件仍可獨立編輯。錯例是先 Export 成 PNG 再開回來：畫面可能一樣，但 Layers 只剩一張圖片，因此不能算完成。

本課的課堂標籤不是 Affinity 功能，而是學習節奏：**Demo** 是講師先展示一次完整判斷；**Together** 是你跟著完成尚未完成的部分，並做一個自己的選擇；**Solo** 是你獨立套用同一流程，只改一個主要變因；**Check** 是停下來驗收，不另外產生第二份相同成品；**Stage** 是目的相同的一組步驟；**Checkpoint** 是每一小段的停站檢查。看到這些字時，請先看「模式」再動手，不要把它們當成 Vector、Pixel 或 Layout 的工具名稱。

### 操作示範 / Demo

#### Stage A：建立可驗證的起始文件

以下示範使用的原始輸入是「寬 1920 px、高 1080 px、RGB／8、sRGB 的空白畫布」。選這組設定，是因為 CH1 要觀察工作區切換，不讓列印出血或外部檔案匯入干擾第一個結果。

**步驟 1｜建立文件**

- **模式**：Demo
- **操作**：開啟 Affinity，選 `File > New`。輸入寬度 `1920 px`、高度 `1080 px`；色彩格式選 `RGB/8`，色彩設定選 `sRGB`，出血維持 0。按 `Create`。
- **講師提示**：這裡建立的是工作檔，不是從 Adobe 匯入的副本；不要先開啟原始 AI、PSD 或 INDD。
- **預期結果**：畫面中央出現 1920 × 1080 的空白畫布，文件頁籤或文件資訊可看到 RGB／8 與 sRGB。
- **快速檢查**：用文件資訊或新文件設定重新確認三個值：1920 × 1080、RGB／8、sRGB。
- **卡住時**：若單位顯示為 mm，先把寬高欄位後的單位改成 px；若找不到 RGB／8，搜尋 `colour format` 或 `color format`，不要用目前預設值猜測。

建立文件後，你已經有了可以承接三種工作的容器。剛才確認的尺寸與色彩值是後面所有檢查的基準，所以現在要觀察 Affinity 如何把三類工具放在同一個文件上。

**步驟 2｜辨認三個工作區**

- **模式**：Demo
- **操作**：在介面上找到 `Vector`、`Pixel`、`Layout` 的工作區按鈕或對應選單。依序點選一次，每次停留 3 秒觀察工具列、左側工具與右側面板的變化。
- **講師提示**：你要辨認的是「目前任務模式」，不是把三個工作區當成三個檔案。
- **預期結果**：切換到 Vector 時看到路徑與形狀相關工具；切換到 Pixel 時看到像素選取或畫筆工具；切換到 Layout 時看到頁面或文字框相關工具。
- **快速檢查**：在對照表填入三列：`Illustrator → Vector`、`Photoshop → Pixel`、`InDesign → Layout`，並各寫一句「我在這裡會處理什麼」。
- **卡住時**：若看不到按鈕，使用 `View`、`Window` 或 `Studio` 選單搜尋 `Vector`、`Pixel`、`Layout`；不同視窗配置可能把按鈕收進選單，但工作區名稱不變。

**步驟 3｜先用一個具體物件驗證 Vector**

- **模式**：Demo
- **操作**：切換到 `Vector`。選矩形工具，在畫布左上方拖出一個約 420 × 220 px 的矩形；在右側 `Colour` 或 `Fill` 控制中選一個純色，不加陰影。
- **講師提示**：這個矩形只用來驗證「形狀是向量物件」，不是本課的 logo 設計。
- **預期結果**：矩形邊緣在放大時保持銳利；圖層或物件清單出現一個可選取的形狀物件。
- **快速檢查**：放大畫布到 200% 左右，重新選取矩形；若仍可用節點或形狀控制調整，它就是可編輯向量物件。
- **卡住時**：若你畫出的物件變成像素圖，確認目前工作區是 Vector，並重新建立矩形；不要用 `Rasterize` 或任何轉換命令補救。

**Checkpoint 1｜文件與工作區**

**模式**：Check

現在應該看到：一個 1920 × 1080 的 RGB／8 sRGB 文件、一個可選取的向量矩形，以及完成前三列的對照表。若缺少其中任何一項，回到步驟 1 或步驟 2；通過後才能加入 Pixel 與 Layout 的觀察，因為後面的比較要建立在同一個文件上。

#### Stage B：在同一文件上看見 Pixel 與 Layout 的差異

剛才的矩形證明 Vector 工作區可以在本文件留下可縮放物件。現在沿用這份文件，不另開新檔，觀察 Pixel 與 Layout 如何加入不同類型的內容；這一步的目標是建立選擇工作區的判斷，而不是完成修圖或排版。

**步驟 4｜用 Pixel 工作區加入可辨認的像素內容**

- **模式**：Together
- **操作**：切換到 `Pixel`。新增一個像素圖層（若面板提供 `Pixel Layer` 選項就選它），用畫筆在矩形右側畫一條短線，再立即把該圖層隱藏與顯示各一次。
- **講師提示**：Pixel 物件與 Vector 矩形都在同一份文件，但縮放與編修方式不同；先觀察圖層類型，再談工具名稱。
- **預期結果**：圖層面板出現像素圖層；隱藏時短線消失，顯示時短線恢復，矩形不受影響。
- **快速檢查**：只關閉像素圖層的可見性，確認矩形仍在；這表示你沒有把兩者合併成一個不可分的圖像。
- **卡住時**：若找不到新增像素圖層，搜尋 `Pixel Layer`、`New Pixel Layer` 或在 Layers 面板的新增按鈕中找像素圖層；不要直接在向量矩形上塗畫。

**步驟 5｜用 Layout 工作區建立文字框**

- **模式**：Together
- **操作**：切換到 `Layout`。建立一個文字框，輸入 `Affinity workspace test`；將文字框放在畫布下方，保持單行，不調整字體設計。
- **講師提示**：本步不是排版練習；文字框只用來確認 Layout 工作區能留下可編輯文字物件。
- **預期結果**：文字出現在畫布下方，文字框可被重新選取，文字內容仍可修改。
- **快速檢查**：重新點入文字框，把最後一個字改成 `check`，確認修改後仍是文字而非圖片。
- **卡住時**：若文字工具建立的是藝術文字而不是框架文字，搜尋 `Frame Text` 或 `Text Frame`，重新建立一個可輸入多行的文字框；本步只要求文字仍可編輯。

**步驟 6｜整理面板與文件結構**

- **模式**：Together
- **操作**：在 Layers 面板將三個物件命名為 `V-logo-test`、`P-brush-test`、`L-text-test`；將它們放在可看懂的順序。若面板未顯示，從 `View` 或 `Window > Studio` 開啟 `Layers`。
- **講師提示**：命名是跨軟體轉移的共同能力；不要依賴顏色或位置記憶物件用途。
- **預期結果**：Layers 面板能清楚看到三個不同前綴的物件，且每個物件都能單獨選取、隱藏與重新顯示。
- **快速檢查**：依序只隱藏 `V-`、`P-`、`L-` 各一次；畫布應分別只消失一種內容。
- **卡住時**：若文字或畫筆內容被自動包進群組，先展開群組再命名子物件；若無法改名，確認目前選取的是圖層／物件本身而不是畫布空白處。

**Checkpoint 2｜三類內容仍可分開修改**

**模式**：Check

現在應該看到同一個文件中有一個 Vector 形狀、一個 Pixel 圖層與一個可編輯文字框，三者在 Layers 面板中可單獨選取。若隱藏其中一項會連帶消失其他內容，回到步驟 4 或步驟 6 修正圖層結構；通過後才能存檔，因為 CH1 的完成物必須能支持下一堂課的延續修改。

#### Stage C：保存並留下可重複使用的對照

三類內容現在已經分開且可辨認。接著把這個狀態保存成可再開啟的 Affinity 原始檔，並把剛才的判斷寫成表格；這樣下一個單元不需要重新猜測每個工作區的用途。

**步驟 7｜保存原始檔與對照表**

- **模式**：Together
- **操作**：選 `File > Save As`，檔名輸入 `affinity-transfer-ch1`，選擇 Affinity 原生格式（副檔名以目前版本對話框顯示為準），保存到你能找到的課程資料夾。另在筆記中建立 6 列對照表：`Adobe 任務`、`Affinity 工作區`、`入口／工具`、`預期結果`、`目前限制`、`下次要驗證的檔案`。
- **講師提示**：原始檔與輸出檔要分開；CH1 只保存原始檔，不要把 PNG 當成課程完成物。
- **預期結果**：關閉並重新開啟後，矩形、像素短線、文字框與圖層名稱都存在。
- **快速檢查**：重新開檔後逐一隱藏三個前綴圖層；若三者仍能獨立控制，原始檔保存成功。
- **卡住時**：若 Save As 沒有顯示 `.af`，以目前版本列出的 Affinity 原生格式為準；若重開後只有一張扁平圖，回到步驟 6 重新確認沒有先執行合併或匯出。

**步驟 8｜填入對照表的完整一筆**

- **模式**：Together
- **操作**：先完成一筆完整示範：`Illustrator／製作可縮放標誌` → `Vector` → `矩形、鋼筆、節點、布林運算` → `形狀仍可編輯並可輸出 SVG/PDF` → `外觀堆疊與複雜遮色片需另測` → `CH2-1 的品牌資產副本`。再自行補上 Photoshop 與 InDesign 兩列。
- **講師提示**：完整一筆要同時包含原始任務、操作入口、中間判斷與交付結果；只寫「Vector = Illustrator」不算完成。
- **預期結果**：對照表至少有 6 列，且每列都有「預期結果」與「限制」兩欄。
- **快速檢查**：遮住工具名稱，只看任務與預期結果，你仍能說出下一個要驗證的動作。
- **卡住時**：若不知道限制，寫「尚未驗證」並在下一欄指定要用哪一份副本測試；不要把「看起來一樣」寫成已確認。

### 動手 / Hands-on

沿用剛才的空白文件，但只改一個主要變因：把畫布尺寸從 1920 × 1080 改成你平常交付的社群尺寸，例如 1080 × 1080。Vector 矩形、Pixel 短線、Layout 文字框的內容、命名規則與三個工作區不變。

1. **模式**：Solo — 複製 `affinity-transfer-ch1.af`，另存為 `affinity-transfer-ch1-square.af`。
2. **模式**：Solo — 只修改文件尺寸為 1080 × 1080，確認原本三種物件仍在。
3. **模式**：Solo — 重新依序切換 Vector、Pixel、Layout，記錄每個工作區中你會做的 Adobe 任務。
4. **模式**：Solo — 將三個物件重新排列，讓它們在正方形畫布中仍可辨認；不要新增第四種物件。
5. **模式**：Solo — 更新對照表的「預期結果」欄，補上一句尺寸改變後仍保持不變的交付條件。

**變化練習預期成果**：一份 1080 × 1080 的可編輯 Affinity 原始檔、三個可單獨控制的物件，以及一份完成 6 列的對照表。你沒有改變學習目標，只驗證文件尺寸變動不會破壞工作區與圖層判斷。

### 檢核 / Verification

用以下順序自行驗收：

- [ ] 原始檔可重新開啟，且不是只有一張扁平圖片。
- [ ] Vector 形狀、Pixel 圖層、Layout 文字框各自存在並可單獨隱藏。
- [ ] 你能指出目前工作區與下一個 Adobe 任務的對應關係。
- [ ] 對照表至少有 6 列，每列包含入口、預期結果、限制與下一個驗證檔案。
- [ ] 你能說明 CH1 沒有驗證 AI、PSD、IDML 匯入；這些會在 CH5 用副本測試。

驗收成功代表你已建立可延續的 Affinity 工作環境，不代表三套 Adobe 檔案已完全相容。下一次使用這份完成物時，CH2 會保留工作區與文件設定，只把 `V-logo-test` 替換成品牌向量資產。

## 講師授課筆記（不進講義）

- **時間分配（課堂上限 120 分鐘）**：破題與五個起始答案 8 分鐘；概念與介面辨認 15 分鐘；Stage A 示範 25 分鐘；Stage B 示範與跟做 30 分鐘；Stage C 保存與對照表 15 分鐘；動手變化題 20 分鐘；檢核 7 分鐘。
- **調度**：先用同一份空白文件完成完整示範，再讓學員複製文件做正方形變化題。不要在 CH1 臨時匯入學員的 AI、PSD 或 IDML，避免把檔案相容性問題混入工作區教學。
- **課前準備**：確認 Affinity 3.2.3 可啟動、免費 Canva 帳號可登入；準備一張顯示三個工作區名稱的截圖作為介面不同時的備援。若版本不同，以 `Vector`、`Pixel`、`Layout` 搜尋名稱，不要求按鈕位置完全一致。
- **講師話術**：每次切換後要求學員先說「現在處理哪一類物件」，再問「這對照 Adobe 的哪一段工作」。避免把課程變成按鈕記憶。

## 試跑包需求清單（Verification Asset Spec）

**課程類型**：skill-operation

- **核心環境**：Affinity 3.2.3（macOS）；免費 Canva 帳號只用於啟動與登入，不使用 Canva AI。
- **核心素材**：無外部檔案；學員依本教案輸入 1920 × 1080、RGB／8、sRGB 的新文件規格。
- **學員完成檔**：`affinity-transfer-ch1.af` 與變化版 `affinity-transfer-ch1-square.af`；副檔名以 Save As 對話框實際顯示為準。
- **可複製內容**：對照表欄位 `Adobe 任務｜Affinity 工作區｜入口／工具｜預期結果｜目前限制｜下次要驗證的檔案`。
- **備援**：無法登入 Canva 時，使用已啟動的 Affinity 離線完成核心操作；若介面名稱不同，搜尋 `Vector`、`Pixel`、`Layout`、`Studio`、`Layers`。
- **狀態**：`NOT_VERIFIED`（操作規格可建立，但課程專案尚未提供可開啟的參考／備援 `.af` 成品）；AI／PSD／IDML 素材屬 CH5，尚未納入本單元。取得方式與升級條件見 `assets/affinity-transfer/reference/README.md`。

## 動手練習題（Hands-on Exercise）

**題目**：複製 CH1 的完成檔，只把文件尺寸改成你平常使用的社群尺寸；保留三種工作區、三種物件與相同命名規則，重新驗證它們仍可分開修改。

**預期成果**：一份新的可編輯 Affinity 原始檔、三個能獨立隱藏的物件，以及一份包含 6 列的 Adobe → Affinity 對照表。

**完成標準**（self-check）：

- [ ] 尺寸只改變一次，其他物件類型與命名規則沒有被替換。
- [ ] Vector、Pixel、Layout 內容可分別選取、隱藏、顯示。
- [ ] 對照表每列都有下一次要驗證的檔案或明確寫「尚未驗證」。

## 常見錯誤 3 條（Common Pitfalls）

1. **錯誤現象**：矩形在放大後邊緣模糊，或 Layers 面板只剩一張圖片。
   **原因**：在 Pixel 工作區直接塗畫，或把向量物件先轉成像素再繼續操作。
   **解法**：回到 Stage A 的步驟 2，切換到 Vector，重新建立 `V-logo-test`；保留原本文件副本，不用扁平圖覆蓋原始檔。

2. **錯誤現象**：只隱藏文字時，矩形和畫筆短線也一起消失。
   **原因**：三種內容被合併、群組選取層級錯誤，或操作時選到父群組。
   **解法**：回到 Stage B 的步驟 6，展開群組並確認 `V-`、`P-`、`L-` 三個子物件；修正後從 Checkpoint 2 重新驗證。

3. **錯誤現象**：重新開檔後找不到原始圖層，只有 PNG 或 PDF 預覽。
   **原因**：使用 `Export` 取代 `Save As`，或把輸出檔當成工作檔保存。
   **解法**：回到 Stage C 的步驟 7，使用 Affinity 原生格式另存副本；若原始檔已被覆蓋，安全停止並從最後一份未扁平化副本重做，不刪除任何既有檔案。

**Q1（概念驗證）**：你要修改一個可縮放的品牌標誌、修整一張照片、建立多頁文字框，分別應先切換到哪三個工作區？

- [ ] Pixel、Vector、Layout
- [x] Vector、Pixel、Layout
- [ ] Layout、Pixel、Vector
- [ ] 三項都在 Pixel 完成

**Q2（應用驗證）**：你收到一個 AI 檔，但只想先確認 Affinity 的工作區，不想讓匯入相容性影響判斷。你會怎麼做？

- **預期答案要點**：先使用空白文件建立規格完成 CH1；把 AI 檔保留為副本，放到 CH5 的交換檢查；在對照表中寫明「來源格式、匯入後可編輯性、需要重建的項目」，不把「成功開啟」當成「完整相容」。
