# 把提示詞架構帶到圖像與影音任務

你已在 CH1-2 練習用「背景／資料、任務、限制與缺資訊處理、輸出格式」交代需求，也在 CH1-3 把架構套用在生活詢問、比較、摘要、規劃與撰寫。本課沿用同一組欄位，處理兩種新的輸入：描述圖像生成需求，以及整理音訊或影片內容。

本課會留下兩份可複製成果：一則圖像提示詞，以及一則音訊／影片摘要提示詞。若你目前只能使用文字型 LLM，仍可用本課的文字任務簡述和逐字稿練習如何寫提示詞；這種練習不會證明你的工具能讀取圖片、音訊或影片。

先打開你平常存放可複製提示詞的筆記；沒有固定位置時，使用一份純文字文件即可。新增「圖像生成」和「影音摘要」兩個標題，最後把兩份完成版放在標題下。成果就是未來能直接複製的提示詞，不需另外填紙本檢核表。

## 同一組欄位，資料邊界不同

提示詞四欄仍分別回答四件事：模型本次能用哪些資料、要完成什麼、遇到缺漏或衝突時怎麼處理，以及答案要長什麼樣子。媒介改變時，最需要重新說明的是「資料」和「限制」：圖像任務要交代畫面主體與構圖；音訊／影片任務要說清楚工具可讀到的是逐字稿、聲音、畫面，還是其中幾種。

不同應用程式可能先把檔案轉成逐字稿、抽取影片畫面或其他資訊，再交給模型使用。你在提示詞裡要求模型描述某個內容，不能讓工具取得原本沒有提供的資料。模型無法讀取附件時，應要求它明說無法讀取，並請你提供可用的文字或其他輸入。

附件是否送入成功，先看你正在使用的工具介面是否顯示檔案已附加。提示詞要求模型回報讀取狀態只能提供線索，模型說「已讀取」不等於附件確實可用；你無法確認時，改貼逐字稿或其他可見文字再做摘要。

## 圖像生成：把畫面要求說成可見條件

圖像提示詞的資料欄位，先交代圖片用途、主體和已知的場景；任務欄說明要生成或修改什麼；限制欄描述構圖、不要加入的元素，以及缺少資料時要如何處理；輸出欄再指定張數、方向或比例等工具支援的格式。受眾或視覺風格可以補充，但不必每次填寫。

例如，你要在讀書會投影片放一張情境插圖。起始需求只有「做一張讀書會準備的圖」。模型不知道讀書會在哪裡、要畫幾個人、投影片哪一側要留空。把已知條件寫入四欄，提示詞就能讓模型依明確要求作畫，而不必猜測校名或其他未提供的細節。

這次的任務簡述是：為「大學讀書會準備」投影片生成一張插圖，畫面有兩位學生在圖書館看書和做筆記，人物放左側、右側留白；不要校名、校徽、姓名、品牌或文字，輸出一張橫式 16:9 圖。下面將這些已知條件放進四欄；沒有指定的學校和人物身分仍保留為未提供。

~~~text
【背景／資料】這張圖要放在「大學讀書會準備」投影片。畫面主體是兩位大學生在圖書館桌邊看書和做筆記；沒有指定學校、科系或真實人物。

【任務】生成一張安靜、自然的讀書會準備情境插圖。

【限制與缺資訊處理】兩位學生和桌上的書本都要清楚。人物安排在畫面左側，右側保留空間供投影片標題使用。只依上述條件創作，不推測學校、科系或人物身分，也不加入校名、校徽、姓名、品牌或可辨識文字。若你無法設定 16:9 比例，請說明可用的替代比例。

【輸出格式】輸出一張橫式 16:9 插圖；畫面不含文字。
~~~

這份提示詞同時說清楚用途、要畫的內容、位置限制和輸出比例。若工具不提供比例設定，限制欄已要求回報可用選項；學員不必把不存在的設定當成已完成。

### 用圖像提示詞檢核器直接找缺漏

你可以把任務簡述和完成的圖像提示詞一併交給文字型 LLM，請它只比對要求是否有寫入，不請它替你猜風格或補造校園資料。這個檢核器檢查提示詞是否完整，不判定最後生成的圖像是否真的符合要求。

~~~text
請比對「圖像任務簡述」與「圖像提示詞」。

逐項檢查：
1. 主體和場景是否明確。
2. 任務用途是否說明。
3. 重要構圖或位置要求是否寫入。
4. 不可新增的內容是否寫清楚。
5. 輸出方向或比例是否交代；若工具可能不支援，是否要求回報限制。

每項只回覆「已寫清楚／缺少／與簡述矛盾」，附上提示詞中的原句作依據。缺少時只列出要補的條件，不猜測答案。最後提供一份可直接複製的整理版；簡述沒有交代的資料保留為「未提供」。

圖像任務簡述：
[貼上任務簡述]

圖像提示詞：
[貼上你的提示詞]
~~~

若把最初那句「做一張讀書會準備的圖」和完整任務簡述一起交給檢核器，示意結果會指出：主體和場景缺少「兩位學生在圖書館」；構圖缺少左右位置；比例缺少 16:9。上方完成版已補入這些原始條件，並把學校、科系和人物身分留作未提供。這是作者編寫的檢核結果示意，沒有由實際模型執行。檢核器只幫你定位缺漏，最終仍要看提示詞是否忠實保留原始需求。

現在換一份需求練習：系學會要在 16:9 活動簡報放一張「環保市集」情境圖。畫面有重複使用的水杯和便當盒，主體在右側，左側留空給標題；不用校徽、品牌或文字。請用四欄寫出一則圖像提示詞，再貼上面的檢核器。完成時應看到一則可直接複製的圖像提示詞；如果檢核器要求你補上校名或顏色等原需求未提供的細節，保留「未提供」，不要照猜測補入。

參考完成版：

~~~text
【背景／資料】這張圖要放在系學會的 16:9 環保市集活動簡報。已知畫面有可重複使用的水杯和便當盒；沒有提供學校、品牌或指定色彩。

【任務】生成一張介紹環保市集的情境插圖。

【限制與缺資訊處理】讓水杯和便當盒成為主要物件，放在畫面右側，左側保留標題空間。不加入校徽、品牌或文字；未提供的校園細節和色彩不要自行指定。若工具不支援 16:9，請回報可用比例。

【輸出格式】輸出一張橫式 16:9 插圖。
~~~

比對時，確認原需求中的物件、左右配置、禁用內容與比例都留在提示詞裡；學校和色彩維持「未提供」。

## 音訊與影片摘要：說明模型能依據哪個通道

音訊進入工具後，可能只提供逐字稿，也可能保留工具可辨識的聲音資訊；影片可能同時提供說話內容、畫面事件和畫面上的文字。不同工具取得的資料不一樣，所以提示詞要指定你需要的資訊，並要求模型把無法讀取、未提供或彼此衝突的內容分開標示。

以下是一段虛構的社團講座籌備逐字稿。它讓你練習如何整理文字依據；因為沒有附上實際錄音或影片，你不能用它驗證工具的轉錄或畫面辨識能力。

~~~text
[00:00] 林：系上講座海報星期五要定稿。
[00:06] 佳：我星期三下班前可以先排版。講者介紹已收到，講題還沒拿到。
[00:13] 明：場地是 E201 嗎？報名表寫 E202。
[00:20] 林：我手上的場地單也寫 E202，但還沒跟總務確認。我今天去問，確認後再改。
[00:29] 佳：我先用「場地待確認」排版，收到講題和場地資訊後再送定稿。
~~~

把這段逐字稿貼到文字型 LLM，使用下面的提示詞。若使用音訊或影片功能，附件要由目前工具實際支援的方式提供；影片版本還要指出你需要它依據說話內容、畫面事件或畫面文字，不能把逐字稿當成畫面證據。

~~~text
【背景／資料】以下內容是[音訊逐字稿／影片逐字稿／工具可讀取的音訊或影片]。本次實際提供的資料是：[說話內容／時間標記／畫面資訊，按實際輸入填寫]。若你不確定工具取得了哪些通道，填「未確認」，不要先宣稱它已讀取。
[貼上逐字稿，或依工具支援方式提供附件。]

【任務】整理這段材料中的主旨、已確認的決定、待辦事項和仍待確認的資訊。

【限制與缺資訊處理】只依本次實際提供的內容回答。保留材料中的時間標記；每個決定和待辦都附上相關時間與原文片段。沒有說明負責人或期限時標「未提供」；前後不一致或尚未確認時標「待確認」。只有逐字稿時，不描述未提供的畫面、人物表情或語氣。若你無法讀取附件，請明說並請我貼上逐字稿，不要猜測。

【輸出格式】
一、主旨：一至兩句。
二、決定：內容｜依據時間與原文。
三、待辦：負責人｜要做的事｜期限（未提供則照標）｜依據時間與原文。
四、待確認：問題｜目前已知內容｜還缺什麼。
~~~

### 示範結果與理由

下面是依逐字稿整理的教學示意，並非實際模型執行結果。

| 項目 | 示意輸出 | 逐字稿依據 |
|---|---|---|
| 主旨 | 系上講座海報預計星期五定稿，送出前仍需確認講題和場地。 | [00:00]、[00:29] |
| 決定 | 佳先排版，講題和場地資訊到齊後再送定稿。 | [00:29] |
| 待辦 | 佳｜先排版｜星期三下班前｜「我星期三下班前可以先排版」[00:06] | [00:06] |
| 待辦 | 林｜向總務確認場地｜今天（日期未提供）｜「我今天去問」[00:20] | [00:20] |
| 待確認 | 場地是 E201 還是 E202；目前林手上的場地單和報名表都寫 E202，但仍待總務確認。 | [00:13]–[00:20] |
| 待確認 | 講座講題尚未收到；負責人與期限未提供。 | [00:06] |

這份結果把「場地單和報名表都寫 E202」保留下來，也保留尚未確認的狀態，沒有直接把 E202 當成最後答案。相對地，如果工具只拿到逐字稿，問它「影片裡投影片用了什麼顏色」時，提示詞應讓它回答「畫面資訊未提供」，不能由對話內容猜出顏色。

### 用媒介來源檢核器檢查摘要

摘要完成後，再用專門檢查影音摘要的提示詞核對時間、通道和文字依據。它要求模型提供原文片段，讓你能回到逐字稿定位；這項檢核仍可能漏掉錯誤，也不代表逐字稿本身正確。

~~~text
請檢查「影音摘要」是否超出「本次提供的材料」。

逐項核對主旨、決定、待辦和待確認事項，回覆：
- 摘要中的主張
- 狀態：逐字稿明確／逐字稿前後不一致／逐字稿未提供／需要畫面確認（本次未提供畫面）
- 可定位的時間標記及原文片段；沒有依據就寫「找不到」
- 建議處理：保留／改標待確認／刪除

如果材料只有逐字稿，不得推論畫面、表情或語氣。不要判斷材料外的事實真偽，也不要把「未提及」當成「錯誤」。

本次提供的材料：
[貼上逐字稿，或說明實際附件可提供的通道]

影音摘要：
[貼上待檢查的摘要]
~~~

用這個檢核器看上方示意輸出，預期海報定稿期限、排版期限、場地狀態和講題缺漏都有時間或原文依據；「影片投影片顏色」在只有逐字稿時會標為「需要畫面確認（本次未提供畫面）」。檢核器提供的是可追溯線索，不會替你確認場地真實狀況。

## 把同一架構改用在影片

如果你收到的只有一份影片逐字稿，就把背景欄寫成「本次只提供逐字稿」，限制欄保留「不描述未提供的畫面」。如果工具能讀取影片，再明確寫出要整理口語、畫面事件、畫面文字中的哪些項目，以及希望保留的時間標記。這是在提示詞中說清楚資料來源，不能靠一句「請看影片」保證工具真的取得全部通道。

現在把上方社團逐字稿當作「影片轉出的逐字稿」，再問「影片中講者指著哪一個教室？」。直接使用媒介來源檢核器，預期會看到「需要畫面確認（本次未提供畫面）」，不會從 E201 或 E202 的口頭討論推定影片畫面。若你用的工具能讀影片，仍須另外提供影片並實測後，才能把畫面辨識結果當成已驗證。

## 帶走兩份提示詞

離開本課前，保留一則完成的圖像提示詞和一則音訊／影片摘要提示詞。圖像提示詞要清楚寫出主體、用途、構圖限制與輸出形式；影音提示詞則要限定實際可取得的通道，並讓每項主張能回到時間標記或原文。

你之後可把這兩份架構換成自己的生活或課程任務。使用前先確認工具這次收到什麼資料；如果工具讀不到附件，改貼逐字稿或其他可用輸入，再沿用相同提示詞架構。提示詞會留下本次任務的明確條件；每次使用仍要依當次輸入確認模型能處理的內容。
