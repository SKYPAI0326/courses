# 掌握時間軸基本操作

一段影片中間有3秒不需要的內容。刪掉後，後面的影片應留在原地，還是立刻接上來？兩種結果都可能合理：配合既定時間的作品可能要保留空位，連續短片則通常要接起來。工具的差別，就在它會怎樣處理刪除範圍與後方內容。

我們用燈塔、城市、工作坊三段素材建立36秒序列，先比較刪除與補位，再處理影音連結、插入與範圍移除。完成後輸出 `practice-cut-v1.mp4`，檢查時間軸上的決定是否真的出現在成片中。

開啟上一單元的專案，先確認燈塔序列仍為12秒。以下以正文的起點與數值操作；[時間軸練習卡](../../courses/acp-pr/assets/ai-short-video-editing/foundation-practice-card-v1.md) 可供查閱，[復原卡](../../courses/acp-pr/assets/ai-short-video-editing/foundation-recovery-card-v1.md) 說明找回面板、序列與離線媒體的方法。

## 先建立並核對 36 秒起始序列

開啟 `foundation-main-v1`。若序列中目前只有 CH0-1 建立的 `clip-01-lighthouse.mp4`，依序把 `clip-02-city.mp4`、`clip-03-workshop.mp4` 接到後方，三段之間不要留 gap。三段順序與原始長度應為 12 秒、10 秒、14 秒，序列總長為 36 秒。

快速檢查：Timeline 由左到右是 clip-01、clip-02、clip-03，播放頭移到結尾時顯示 `00:00:36:00`。若不符，先依練習卡的起始狀態修正，再建立副本。

## 先做安全副本

在 Project 對 `foundation-main-v1` 按右鍵選 **Duplicate（複製）**，再將副本改名為 `foundation-practice-v1`。雙擊副本開啟時間軸。副本與原序列共用來源檔案，卻各自保存剪輯安排；因此試錯時可以回到保留的36秒版本。

快速檢查：Project 面板同時看得到原序列與副本；Timeline 分頁目前開啟的是副本。

## 看懂時間碼與軌道

時間碼 `00:00:03:20` 依序代表時、分、秒、影格。最後兩位不是百分之一秒；每秒有幾格取決於序列幀率。

- V1、V2、V3 是影像軌；A1、A2、A3 是音訊軌。
- 軌道上的上下位置不等於先後時間；左右位置才表示時間。
- 播放頭決定目前預覽位置。
- Snapping（磁吸）讓片段邊緣靠近剪接點時自動對齊。
- Track Mute 的 M 影響整條音訊軌；停用單一 clip 是另一件事。

點 Timeline 的時間碼欄，輸入 `00:00:03:20` 並按 Enter。在本課25 fps序列中，這是3秒又20格，即3.8秒；`00:00:04:00` 才是4秒。按左右方向鍵可逐格移動，觀察最後兩位如何從24回到00，秒數跟著增加。若變動的是來源預覽，先點回 Timeline 再輸入。

## 四種改變要分清楚

先比較各動作究竟改變位置、長度、速度或後方內容，再開始操作。

| 動作 | 主要改變 | 常見風險 |
|---|---|---|
| 移動整個片段 | 起訖位置一起改變，長度不變 | 可能留下 gap 或覆蓋別的片段 |
| 拖曳片段邊緣 | 使用範圍與長度改變 | 可能切掉句尾；後方不一定補位 |
| Ripple Edit | 改變邊緣並讓後方內容跟著移動 | 選錯剪接點會影響整條時間軸 |
| Rate Stretch | 改變速度來符合長度 | 題目沒要求速度時通常不該使用 |

## 練習一：切開、刪除與 Ripple 補位

這個練習用同一段素材比較一般刪除與自動補位的結果。

1. 開啟 Linked Selection（連結選取）與 Snapping（磁吸），把播放頭定位在 `00:00:04:00`。按 `C` 使用 Razor（剃刀），沿播放頭切開 V1／A1；再到 `00:00:07:00` 切一次。確認影像與音訊都在兩個位置分段，只有其中一條切開時先復原並重做。
2. 按 `V` 回 Selection Tool。
3. 選取中間不需要的 linked clip，按 Delete。
4. 觀察是否留下 gap；先按 `Ctrl+Z`。
5. Undo 後中段應回來。對選取的中間影音片段按右鍵，選 **Ripple Delete（漣漪刪除）**，讓後方內容一起往前補位。這次不再另刪空隙。

**驗證**：一般刪除留下3秒 gap，Ripple Delete 讓序列由36秒變成33秒。城市的起點應由12秒前移到9秒，城市本身仍是10秒。這說明補位改變的是後方位置，沒有加速或拉長城市素材。若總長仍36秒，檢查是否只刪掉影音其中一條，或其他軌仍有片段延伸。

**自己試一次**：從原本36秒序列另複製 `foundation-ripple-check`，刪去燈塔第2秒到第4秒，要求後方補位、城市長度不變。這次自行選刪除方式。

## 練習二：Link、Unlink 與只動一個 component

影音連結讓你選取或移動其中一部分時，另一部分可以一起跟隨。把聲音換到另一條軌道，則只改變它上下的位置；只要左右起訖不變，就能保留同步。先做一次 Unlink 觀察，再復原關係並練習只移動聲音。

1. 選取 `clip-02-city.mp4` 的 linked video／audio，使用 `Clip > Unlink`。
2. 點空白處取消選取，再單點影像，確認音訊不會一起被選取。
3. 按 `Ctrl+Z` 回到 linked 狀態。
4. 按住 `Alt` 單獨選音訊 component，將它移到 A2，但保持左右時間位置不變。
5. Alt 單選只暫時選到一個 component，不會自動解除連結。放開 Alt，再點選城市影像，檢查 A2 音訊是否一起亮起；只有確實已解除連結時，才同時選取對應影音並使用 `Clip > Link`。

**驗證**：城市音訊位於 A2、仍從9秒開始，到19秒結束。試移影音後立即 Undo。Link 保存影音配對；Group 是讓多個選取物件一起操作的群組，不能以分組代替影音關係。核對後復原這組試驗，讓城市音訊回 A1、仍保持連結，A2 留空，才做後面的插入比較。

## 練習三：Insert 與 Overwrite

在 Source Monitor 開啟 `clip-03-workshop.mp4`，設定 In `00:00:02:00`、Out `00:00:05:00`，把 Timeline 播放頭放在 `00:00:10:00`。來源時間碼決定「拿哪段」，序列播放頭決定「放哪裡」，兩者可以不同。

在 Timeline 左側確認來源修補 **Source Patching** 的 V1／A1 啟用並對到目標 V1／A1；兩軌都未鎖定。這組開關控制 Source Monitor 的內容送到哪裡，旁邊的軌道目標 **Track Targeting** 則供時間軸命令使用。若只插入影像，先 Undo，檢查來源 A1 的修補狀態，不要另拖一份聲音來猜位置。

- **Insert**：把新內容插入，後方內容往右移；既有畫格不被覆蓋。
- **Overwrite**：在目前位置蓋上新內容；序列總長可能不變。

先在副本中使用 Overwrite，記錄 `00:00:10:00` 起被取代的 `00:00:03:01`，再 Undo；改用 Insert，確認後方內容整體右移 `00:00:03:01`。Premiere 的 Out point 包含最後一格，因此 25 fps 下 `02:00–05:00` 共 76 格，也就是 3 秒 1 格。兩次都沿用相同 In／Out，每次只改一個變因。從33秒起點計算，Overwrite 後仍33秒；Undo 後改用 Insert，應變成 `00:00:36:01`。核對後 Undo 這次 Insert，回到33秒、A2空白的狀態，再練習範圍移除。

## 練習四：軌道控制與範圍移除

前面以已切開的片段做 Ripple Delete；現在用序列的 In／Out 指定一段範圍，即使範圍跨過片段邊界，也能處理。先加上獨立語音，觀察整軌靜音與刪除資料的差別。

1. 把 `audio-01-voice.wav` 放到 A2，起點對齊序列起點。
2. 在 A1 軌道標頭按 M，確認 A1 靜音、A2 仍可聽見。
3. 確認 V1、A1、A2 未鎖定，三軌的 Track Targeting 與 Sync Lock 都啟用，其他空軌不選。點 Timeline，定位 `00:00:14:00` 按 `I`，到 `00:00:16:00` 按 `O`；這次標記的是序列範圍。
4. 使用 **Sequence > Lift**，觀察指定範圍留下 gap，總長仍33秒；Undo 後確認內容與 In／Out 回到原狀，再使用 **Sequence > Extract**。若版本只在 Program Monitor 顯示按鈕，可依滑鼠提示找 Lift／Extract。
5. Undo 後以 Extract 作為最後狀態：指定 `00:00:02:01` 消失、後方內容前移且不留 gap。25 fps 下 `14:00–16:00` 因包含 Out point，共 51 格，也就是 2 秒 1 格。從33秒減去51格，應剩 `00:00:30:24`。若影音錯開，Undo 後先檢查鎖定、目標軌與同步鎖定，不能用拖曳片段掩蓋不同軌處理範圍不一致。

## 從結果選工具

同樣要「拿掉內容」，選定中間片段後可用 Ripple Delete；已標記序列範圍時可用 Extract。兩者都能讓後方補位，但起始選取不同。看到題目先找它指定的物件，才知道該選片段或設序列範圍。

移動片段保留長度；拖曳邊緣改變使用範圍；Ripple Edit 在修剪邊緣時連動後方；Rate Stretch 改變播放速度。這些工具有時都能讓兩個邊緣看起來對齊，只有核對位置、長度與速度，才能知道是否符合要求。

## 輸出測試片

確認 `foundation-practice-v1` 是作用中的序列，開啟 Export：

- Format：H.264
- File Name：`practice-cut-v1.mp4`
- Location：自己的作業資料夾
- Range：Entire Source／整個目前序列

輸出後到 Windows 資料夾雙擊 MP4。不能只在 Premiere 內看；要確認檔案真的可播放、有畫面、有聲音、內容是練習副本。

## 完成檢查

交付前核對保留的36秒原序列、34秒獨立練習，以及練習副本的輸出。副本依上述各次復原點完成後為 `00:00:30:24`；若你刻意保留其他比較結果，先回到指定起點再重做受影響的那組操作。

- [ ] 原始 `foundation-main-v1` 仍保留。
- [ ] 能說出移動、裁切、Ripple、Rate Stretch 的差別。
- [ ] 能分辨 Link 與 Group、Mute Track 與停用 clip。
- [ ] 能說出 Insert／Overwrite、Lift／Extract 的差別。
- [ ] `practice-cut-v1.mp4` 可在 Premiere 外播放。

完成後休息 10 分鐘。下一單元不再逐項練工具，而是把功能放進一張可找路的地圖。
