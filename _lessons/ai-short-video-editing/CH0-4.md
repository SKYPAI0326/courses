# 把題目翻成操作路徑

「把來源片段放進第10秒」還不足以決定操作。如果題目要求保留原有畫格，要用 Insert；如果要求取代該位置的內容，才考慮 Overwrite。同一個時間與素材，因限制不同，就需要不同的處理方式。

這25分鐘把已經做過的操作轉成讀題方法。先從句子找出要改變與必須保留的狀態，再選工具，最後寫出能證明兩者的觀察。四題紀錄存成 `foundation-check-v1.md`，進入後續題庫時可沿用。

本單元使用 [question-decoding-card-v1.md](../../courses/acp-pr/assets/ai-short-video-editing/question-decoding-card-v1.md)。練習時先遮住「答案與判分依據」，完成六格後再比對；另把四題結果抄入 [foundation-check-v1.md](../../courses/acp-pr/assets/ai-short-video-editing/foundation-check-v1.md) 作為交付紀錄。

## 六格題幹拆解卡

每格先寫出可檢查的答案，再決定要用哪個選單或工具。

| 欄位 | 要回答的問題 |
|---|---|
| 作用物件 | 是 Project item、source clip、timeline clip、sequence、track、marker、caption 還是輸出檔？ |
| 動作 | 建立、移動、修剪、刪除、改名、連結、套用、設定或輸出？ |
| 功能位置 | 最可能在哪個面板、選單、工具或工作區？ |
| 目標狀態 | 名稱、位置、數值、時間、軌道或格式最後要是什麼？ |
| 限制 | 不能改什麼、必須保留什麼、是否不可留 gap？ |
| 驗證 | 哪一個畫面或數值能證明真的完成？ |

## 教師示範：只改 Scale，不改中心位置

代表題幹：「將指定 video clip 的 Scale 設為 200%，並維持中心位置。」

- 作用物件：序列中的指定 video clip。
- 動作：修改 Scale。
- 功能位置：選取 timeline clip 後的 Effect Controls > Motion > Scale（2024）；不另套 Transform 效果。
- 目標狀態：Scale = 200%。
- 限制：Position 與 Anchor Point 不變。
- 驗證：面板數值為 200%，Position 保持原值；不能只靠肉眼看起來有放大。

假設原 Position 為960、540，Anchor Point 為960、540，完成後這兩組數值都應維持原值，只有 Scale 變成200%。這些座標只是本例；換素材時必須先記錄該片段自己的原值。只看畫面變大，無法證明位置與錨點都沒改。

## 跟著做：Insert 而不是 Overwrite

代表題幹：「在指定時間把來源片段放入相同軌道，使用既有 In／Out，不刪除原有片段的任何畫格。」

先自己填卡，尤其寫出哪個詞讓你排除 Overwrite，再展開比對。

<details>
<summary>核對插入題的六格</summary>


- 作用物件：Source Monitor 中已有 In／Out 的 source clip，加上目標 sequence。
- 功能位置：Source Monitor、Source Patching、Timeline。
- 目標狀態：片段出現在指定時間與軌道。
- 限制：既有畫格不能被覆蓋，In／Out 不重設。
- 合理動作：Insert；若用 Overwrite，會違反保留既有畫格的限制。
- 驗證：序列總長增加、既有片段仍完整。

在本課單一連續V1／A1序列的條件下，長度增加是線索；仍須確認原內容被移到後方，不能只看總秒數。

</details>

## 自己完成兩題

### 題 A

「刪除指定時間範圍，後方內容往前補位，不留下 gap，也不延長任何片段。」

在六格中寫下作用範圍、選擇的命令，以及你要檢查哪兩個不同結果。

### 題 B

「將序列改名，刪除所有空軌，並把 A1 整條音訊軌靜音。」

題目包含三個動作。請分別寫出作用物件、入口與驗證，並說明刪空軌時要保護什麼。

<details>
<summary>兩題完成後核對</summary>

題A：作用物件為sequence In／Out範圍，使用Extract，檢查範圍消失、後方補位；同時檢查相鄰片段沒有被拉長。Lift留下gap，拉長片段補洞則違反長度限制。

題B：Project 的sequence item改名；Sequence > Delete Tracks只處理空軌；A1標頭M控制整軌靜音。核對新名稱、剩餘軌道與原內容都在，以及A1的M啟用。這題是讀題練習，未提供新名稱時不能自行捏造考題要求；實際操作須回到題目指定值。

</details>

上面的示範、跟做、題A與題B依序就是拆解卡Q1～Q4；將四題答案整理進紀錄，不必再重做一輪。Q1、Q2 對應前面的教師示範與跟做；Q3、Q4 必須獨立填寫。四題都要同時寫出正確作用物件、限制與可觀察驗證，才進入下一段。

## 考試操作前的 20 秒自問

按下按鈕前快速回答四題，可以攔住多數改錯物件與漏看限制的失誤。

1. 我現在選到的是題目指定物件嗎？
2. 這個操作會不會順便改到題目沒要求的數值？
3. 題目禁止的結果有哪些？
4. 做完後要在哪裡看證據？

若不確定，先不要連續嘗試多個工具。回到拆解卡，找出唯一必須改變的狀態。

## 完成檢查

以拆解品質判斷是否通過，不以背出完整滑鼠路徑作為唯一標準。

- [ ] 四張代表題全部完成六格拆解並通過。
- [ ] 每張都寫出一個可觀察的驗證，而不是「看起來完成」。
- [ ] 能說出 Insert／Overwrite、Lift／Extract、track mute／clip disable 的差異。
- [ ] 知道詳細題庫條件將在後續 4 小時逐題練習，本單元只建立讀題方法。

完成後休息 10 分鐘。接下來進入 AI 輔助剪輯，但仍沿用相同方法：先確認輸入與作用物件，再看產出、限制與驗證。

## 講師授課筆記（不進講義）

- **時間配置**：六格卡 4 分鐘；教師示範 6 分鐘；跟做 5 分鐘；獨立兩題 7 分鐘；20 秒自問與收束 3 分鐘。
- **評量方式**：先看物件與限制是否正確，再看路徑。路徑名稱因版本不同可微調，但作用層級錯誤不能放行。
- **轉場**：明確告知學員：180 分鐘的目的不是教完題庫，而是讓明天每題都有可以掛靠的介面與概念。
