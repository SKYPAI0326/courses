# 看懂 Premiere 的工作流程

你有一支12秒的燈塔影片，想把結尾剪短，之後又可能想用回完整版本。剪輯時需要保留的有兩件事：拍到的原始內容，以及這次決定怎麼使用它。Premiere 把這兩件事分開保存，讓你可以重新選段，而不用每試一種剪法就複製一支影片。

我們先開啟素材，再建立用來保存剪輯安排的專案，最後實際裁短片段，比較來源是否改變。這個比較會幫你分清楚：螢幕上看見同一個畫面，背後可能正在查看不同的物件。

這一課留下 `ACP-PR-你的座號-v1.prproj`，其中的 `foundation-main-v1` 序列會交給下一課繼續使用。操作以 Windows Premiere Pro 2024 為準；選單採英文名稱，中文介面可依括號中的用途對照。

## 原始影片放在哪裡，專案就到哪裡找它

下載 [Premiere 基礎練習素材包](../../courses/acp-pr/assets/ai-short-video-editing/premiere-foundation-starter.zip)，在自己的作業資料夾解壓縮。保留 `premiere-foundation-starter` 資料夾，打開裡面的 `media`，應看到三支 MP4、一個 WAV、三張 PNG，以及一份文字檔。詳見 [素材內容說明](../../courses/acp-pr/assets/ai-short-video-editing/premiere-foundation-starter/README.md)。

先用 Windows 播放器開啟 `clip-01-lighthouse.mp4`，確認能看到燈塔畫面並聽到聲音，片長為12秒。如果播放器也無法開啟，先重新解壓縮素材包；仍無法播放就請教師檢查檔案，不要帶著損壞的素材往下做。

專案檔會記錄素材位置、片段排列及編輯設定，影片仍放在原來的資料夾。後續請保持這個資料夾的位置與檔名；只帶走 `.prproj`，不會一併帶走影片。

## 讓專案認識素材，還不等於開始剪輯

影片可以直接用播放器打開，但播放器不會替你保存片段排列。Premiere 的 Project（專案）會記錄這些編輯資料，以及使用了哪些媒體檔。先建立專案，之後每次儲存，就能保存當下的剪輯安排。

開啟 Premiere，選 **New Project（新增專案）**。Project Name 輸入 `ACP-PR-你的座號-v1`，Location 選剛才的作業資料夾，與素材包放在一起，方便日後搬移整份作業。

這次先建立空專案：新建畫面先不要勾選媒體，按 **Create（建立）**，進入編輯工作區。若畫面已有素材勾選，先取消選取，避免提前建立與本課不同的序列。建立後按 `Ctrl+S`，到作業資料夾確認出現 `.prproj`；找不到時，回 Premiere 使用 **File > Save As（另存新檔）** 指定位置。

現在按 `Ctrl+I` 開啟匯入視窗，進入 `media` 資料夾，按住 Ctrl 選取三支 MP4、一個 WAV 與三張 PNG，再按 Open。`title-text-v1.txt` 是文字參考，不納入這次媒體匯入。

在 **Project（專案素材區）** 找到這七個媒體項目。此時還沒建立序列，**Timeline（時間軸）** 沒有片段是正常的；匯入只讓專案認識檔案，還沒有決定如何排列它們。

若面板不見，選 **Window > Workspaces > Editing（編輯工作區）**，或從 Window 選單開啟 Project、Source Monitor、Program Monitor、Timeline。可另開 [工作區概念圖](../../courses/acp-pr/assets/ai-short-video-editing/print/premiere-workspace-map-v2.svg) 對照位置；圖是示意，實際版面不一定相同。本課不需要尋找 Properties 面板，2024 的片段效果控制使用 **Effect Controls**。

## 用序列保存一種剪法

先在 Project 雙擊 `clip-01-lighthouse.mp4`。它會開在 **Source Monitor（來源預覽）**。點一下這個面板，再按空白鍵播放、再按一次暫停，確認目前查看的是燈塔來源。

Source Monitor 讓你看完整來源。要決定先播哪一段、後面接什麼、聲音從哪裡開始，還需要一個保存排列的地方。Premiere 用 **Sequence（序列）** 保存這些安排，**Timeline（時間軸）** 則讓你看見並修改安排。

回 Project，對同一個 MP4 按右鍵，選 **New Sequence From Clip（從片段建立序列）**。Premiere 會依來源設定建立序列，並把這支影片放入時間軸。

Project 現在多出一個序列項目。選取新序列，按右鍵選 **Rename（重新命名）**，改為 `foundation-main-v1`；保留原本 MP4 的名稱。序列分頁應同步顯示新名稱。

在 Timeline 應看到 V1 上的影像與 A1 上的音訊。點時間軸上方的時間尺移動播放頭，**Program Monitor（序列預覽）** 會顯示該位置的畫面。這個序列使用完整12秒影片，設定隨素材為1920×1080、每秒25格。

如果只看到素材、沒有序列，先確認剛才是在 Project 的 MP4 上執行 New Sequence From Clip。若序列已存在但時間軸關閉，雙擊 `foundation-main-v1` 重新開啟即可，不必再建一個。

## 同一個燈塔畫面，為什麼要有兩個預覽？

此時 Source 與 Program 都可能顯示燈塔，因為序列正好用了整支影片。兩個面板的用途，要看它們正在顯示的對象。

| 名稱 | 在這份專案中指什麼 | 如何找到 |
| --- | --- | --- |
| 原始媒體 | 硬碟上的 `clip-01-lighthouse.mp4` | Windows 的 `media` 資料夾 |
| Project item（專案項目） | Project 裡的一個項目；來源素材、序列都屬於專案項目 | Project 中的 MP4 或序列項目 |
| Source clip（來源素材） | 匯入後、連到原始影片的素材，可在不同序列重複使用 | 在 Project 雙擊 MP4，用 Source Monitor 查看 |
| Sequence（序列） | 包含軌道、片段排列、畫面尺寸與幀率的剪輯內容 | 在 Project 雙擊 `foundation-main-v1` |
| Timeline clip（時間軸片段） | 來源素材在序列中的一次使用，可調整使用範圍 | Timeline 中 V1／A1 上的片段 |

Source Monitor 是查看來源的面板，並不是多產生了一份影片。這裡的 MP4 項目同時是 Project item 與 source clip；序列也在 Project 裡，但它負責記錄怎麼剪輯。分辨名稱，是為了選對操作對象。

## 剪掉的尾段還找得回來嗎？

回到 `foundation-main-v1`，做一次可復原的小裁切。這裡只觀察使用範圍，不要求精準剪到某個影格。

1. 點 Timeline，按 `V` 切回 **Selection Tool（選取工具）**。點選燈塔片段，確認 V1 影像與 A1 音訊都被選取；若只有一條亮起，先確認時間軸的 **Linked Selection（連結選取）** 已開啟。
2. 將滑鼠移到片段最右邊的邊緣，向左拖短約2秒。拖的是邊緣；若整段被搬走，立即 `Ctrl+Z`，重新對準右緣。
3. 看 V1、A1 的右緣是否一起向左縮短。兩條都縮短後，這個單片段序列才會從12秒變成約10秒。若聲音仍延伸到12秒，先復原這次動作，確認影音都有被選取，再裁一次。
4. 回 Project 雙擊原本的 MP4，在 Source Monitor 查看完整來源，或用 Windows 播放器重新開啟同一檔案。來源仍是12秒，裁掉的尾段仍在。
5. 點回 Timeline，按 `Ctrl+Z` 復原裁切，確認兩條片段回到完整12秒，再按 `Ctrl+S`。

你改的是序列採用的範圍，原始媒體沒有被重新寫入。若預覽看起來也少了尾段，先核對 Source 面板標題是否為原始 MP4、是否誤開序列或設了 In／Out 範圍；不要單憑預覽範圍就判定來源被剪壞。無法確認時，用 Windows 播放器檢查原檔，保留專案讓教師協助。

## 換一支素材，自己決定要改哪個物件

保留目前12秒的 `foundation-main-v1`。接下來要另外查看城市影片，不能把它接到燈塔後面，也不能用城市素材蓋掉燈塔。

請用 `clip-02-city.mp4` 建立另一個序列，命名為 `foundation-city-check`。先判斷要在 Project 選哪個項目，再使用剛才學過的方法。完成後，分別開啟兩個序列播放，確認它們使用各自的來源。

<details>
<summary>完成後核對：城市與燈塔各自在哪裡？</summary>

Project 裡的燈塔與城市 MP4 都保留，另有兩個序列。`foundation-city-check` 只有城市片段，長度10秒；`foundation-main-v1` 只有燈塔片段，長度12秒。

若燈塔與城市接在同一條時間軸，表示把素材加到既有序列。先復原剛才的加入動作，回 Project 選取城市 MP4，再執行 New Sequence From Clip。若新序列仍是燈塔，先核對選到的是城市 MP4，不能只看目前開著哪個時間軸分頁。

這次要留下的是兩個可各自開啟、播放的序列，不必另寫名詞解釋。

</details>

## 關閉再重開：專案究竟保存了什麼？

按 `Ctrl+S`，再選 **File > Close Project（關閉專案）**。用 **File > Open Project（開啟專案）** 選取剛才儲存的 `ACP-PR-你的座號-v1.prproj`。

重開後，在 Project 分別雙擊兩個序列，播放確認影像與聲音都有。最後切回 `foundation-main-v1`：V1／A1 應保留完整燈塔片段，共12秒。下一課會在這個起點加入另外兩支影片，再建立練習副本。

若出現 **Media Offline（媒體離線）**，先到 Windows 確認影片是否仍在原資料夾。專案記錄的是位置，搬動資料夾、改檔名或拔除外接磁碟，都可能讓它找不到來源。

檔案仍在時，在 Project 對離線素材按右鍵，選 **Link Media（連結媒體）**；在對話框選 **Locate（定位）**，找到同名 MP4，核對名稱後確認。若開專案時已出現連結視窗，可直接從 Locate 開始。重新播放畫面與聲音，確認找回的是正確素材，再儲存。原檔確實找不到時，先停止這筆重新連結並請教師協助，不能任選另一支影片湊成可播放。

交付整個作業資料夾，包含 `.prproj` 與原素材資料夾。能重新開啟、找回來源並播放兩個序列，才是這一課的操作結果；這份專案還不是輸出的成片 MP4。
