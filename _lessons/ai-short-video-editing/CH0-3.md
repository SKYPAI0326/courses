# 建立題庫功能地圖

你把圖片放大，卻發現旁邊影片沒有一起放大；把序列改成直式，所有片段的顯示範圍卻都受到影響。差別來自改動的層級：片段參數只作用於那次使用，序列設定則決定整份剪輯的畫布。

這裡會在一個練習序列中整理素材、放大圖片、做淡入並切換音訊軌。你會看見同一個作品裡，不同改動各自屬於哪個物件，再把功能整理成可查閱的地圖。七個家族用來查找，不需要逐項背誦。

先開啟已有素材的專案與 [功能地圖 PDF](../../courses/acp-pr/assets/ai-short-video-editing/object-panel-function-map-v1.pdf)。[五題定位練習](../../courses/acp-pr/assets/ai-short-video-editing/function-map-check-v1.md) 留到結尾作答後核對。操作以本頁明列參數為準，地圖內較新版的 Properties 名稱，在2024使用 Effect Controls 查看片段參數。

## 先做一份可以比較的練習序列

在 Project 對 `clip-01-lighthouse.mp4` 選 New Sequence From Clip，新序列改名為 `map-practice`。它應有12秒燈塔影音，1920×1080、25 fps。使用 **Sequence > Add Tracks／Delete Tracks**，將軌道整理為3條影像軌、3條音訊軌；只刪除空軌，保留 V1／A1 的燈塔。再刪除空的 V3，留下 V1、V2 與 A1、A2、A3。畫面及總長應都未變；若素材消失，Undo 並核對刪除的是哪條軌。

這個動作改的是序列容納片段的軌道數，沒有改變燈塔來源。在後面的圖片與語音練習，我們會繼續使用這個序列。

## 地圖入口：先判斷改的是哪一層

先把題目放進四個作用層級，便能排除多數不相關面板與工具。

1. **專案層**：素材、bin、sequence item、未使用項目、媒體連結。
2. **序列層**：畫面尺寸、幀率、軌道數、In／Out、sequence marker。
3. **片段層**：位置、長度、速度、連結、效果、音量、clip marker。
4. **輸出層**：格式、尺寸、範圍、檔名與儲存位置。

同一個動詞在不同層級可能是不同操作。「改名」可以改 Project item，不一定是磁碟檔名；「marker」可能是 source clip marker，也可能是 sequence marker。

## 完整示範：先判斷物件，再選功能家族

題目：「將選定的 timeline clip 解除影音連結，保留 video 與 audio 的原時間位置。」

1. **作用物件**：timeline clip 的 video／audio components，不是磁碟檔，也不是整條 track。
2. **功能家族**：家族三「時間軸剪輯與片段關係」與家族五「音訊、連結與軌道狀態」都合理。
3. **最可能入口**：Timeline 選取片段後使用 `Clip > Unlink`。
4. **目標狀態**：video 與 audio 可以分別選取。
5. **限制**：兩個 component 的起訖與時間位置不變，不能順手移動或刪除。
6. **驗證**：點空白處取消選取後，分別單點 video 與 audio；比較 Unlink 前後的起訖位置。

影音可以分開選取且時間仍相同，便能同時證明「關係改了」與「位置沒改」。功能入口與驗證結果因此要一起記。

## 家族一：專案與素材管理

常見任務：建立 bin、移動 sequences、重新命名、處理 Media Offline、移除未使用項目、封存或 Project Manager。

- **主要位置**：Project panel、Link Media／Locate、Project Manager。
- **代表物件**：Project item、bin、sequence item、媒體連結。
- **核心差異**：從專案移除未使用項目，不等於刪除硬碟來源檔。
- **驗證方式**：看 Project panel 階層、Type／Usage 欄位、序列能否播放、磁碟來源是否仍存在。

在 Project 根層的空白處按右鍵，選 **New Bin** 建立 `sequences`。Bin 是專案內的分類資料夾；將 `map-practice` 序列項目拖入即可。若目前身處另一個 bin，先回根層再新增。確認序列現在位於 `sequences` 裡，Windows 的媒體仍在原處。保留 `foundation-main-v1` 的名稱與內容，之後仍可回查36秒起點。

## 家族二：序列、時間碼與軌道

常見任務：依素材建立序列、使用 preset 建立空序列、設定畫面尺寸與幀率、增加或刪除軌道、靜音、In／Out、sequence marker、Auto Reframe。

- **主要位置**：New Sequence、Sequence Settings、Timeline track headers、Markers、Auto Reframe Sequence。
- **代表物件**：sequence、video／audio track、sequence marker。
- **核心差異**：改 Sequence Settings 與建立 Auto Reframed Sequence 的結果不同；後者通常建立新序列並保留原版。
- **驗證方式**：Project panel 是否有正確名稱；Sequence Settings 數值；Timeline 的 V／A 軌數；marker 起點與 duration。

回看 `map-practice` 的 V1、V2 與 A1、A2、A3。剛才減少空軌後，燈塔仍12秒；這就是以序列層操作改變容量、保留內容的例子。

## 家族三：時間軸剪輯與片段關係

常見任務：Razor、Ripple、Rolling、Rate Stretch、Insert、Overwrite、Lift、Extract、移動、修剪、Link／Unlink、Nest、Freeze Frame。

- **主要位置**：Timeline、Tools、Clip 選單、Source Monitor、Program Monitor。
- **代表物件**：timeline clip、edit point、linked components、nested sequence。
- **核心差異**：位置、duration、speed、後方內容是否移動，是四個不同結果。
- **驗證方式**：看片段 In／Out、序列總長、gap、Speed、影音同步與 nest 內容。

代表問答：題目要求「刪除區段且不留 gap」時，Extract／Ripple 路徑比 Lift 更符合；要求「不改 duration」時，不應拖片段邊緣。

## 家族四：Properties／Effect Controls 與關鍵影格

常見任務：Scale、Position、Opacity、淡入淡出、效果參數、Track Matte Key、遮罩與 keyframes。

- **主要位置**：選取 timeline clip 後的 Properties 或 Effect Controls；效果本身從 Effects panel 套用。
- **代表物件**：被選取的 timeline clip、effect、property、keyframe。
- **核心差異**：套用效果與調整效果參數是兩個步驟；沒有選對片段時，面板可能顯示錯誤內容。
- **驗證方式**：核對數值、keyframe 數量與時間、未被要求的 Position／Anchor Point 是否保持原值。

把 Project 中的 `still-01-lighthouse.png` 拖到 `map-practice` 的 V2 起點；選圖片右鍵 **Speed/Duration**，把 Duration 設為 `00:00:05:00`，確認起點仍為0秒、終點5秒。先選取圖片，再開 **Window > Effect Controls**，展開 Motion，記下 Position 與 Anchor Point 原值，只把 Scale 設為50%。Program Monitor 應顯示縮小的圖片疊在底下影片上；若整個畫布變小，先確認是否誤改 Sequence Settings。

Scale 控制大小；Opacity 控制透明程度。固定 Opacity 50% 會讓整段都半透明，淡入則需要隨時間改變數值。**Keyframe（關鍵影格）** 就是在指定時間記下一個值，讓 Premiere 計算兩點之間的變化。

保持選取同一圖片，在序列0秒將 Opacity 設為0%，確認碼錶 **Toggle Animation** 已啟用、此處有一顆菱形關鍵影格。若已啟用不要再關掉；若有意外多出的點，先復原。移到序列 `00:00:01:00`，把 Opacity 改成100%，應新增第二個點。播放0至2秒：縮小圖片逐漸出現，1秒後保持可見；底下V1仍播放。若整段都透明，檢查兩個點是否設在不同時間，以及目前選到的是V2圖片。

## 家族五：音訊、連結與軌道狀態

常見任務：把音訊移到指定軌、Link、Unlink、Mute／Solo、音量 keyframes、Audio Transition、Gain、聲道或同步。

- **主要位置**：Timeline、track headers、Effect Controls、Essential Sound／Audio Track Mixer（依題目）。
- **代表物件**：audio component、audio clip、audio track、音量屬性。
- **核心差異**：Clip Volume、Audio Gain、Track Mute 與停用 clip 不是同一個設定。
- **驗證方式**：軌道位置、M／S 狀態、音量數值、淡出 duration、影音是否仍同步。

Project 的 `audio-01-voice.wav` 是20秒語音。拖到空的 A2 起點，將尾端修剪到燈塔結尾12秒，確認起點0秒、終點12秒。開啟 Snapping 可讓尾端對齊V1結尾；若序列仍20秒，表示A2還有尾段。

先播放，再按 A1 軌道標頭的 **M（Mute，靜音）** 重播同一段。A1的聲音停止，A2的語音仍在。再取消 M，原聲立即回來，片段都沒被刪除。這個可逆的比較說明靜音控制播放狀態，刪除則移除時間軸內容。

**自己完成**：保留A1原聲可聽，暫時停止A2語音，兩條音訊都要留在原位置。先完成再核對。

<details>
<summary>核對音訊狀態</summary>

A1的M關閉、A2的M開啟，兩軌片段起訖不變，A3仍空白；所有Solo（S）關閉。若完全沒聲音，先檢查兩條是否都Mute，或有空軌Solo；不能刪除語音後聲稱完成。

</details>

## 家族六：文字、字幕、轉錄與可存取性

常見任務：建立或修改文字、Leading／Kerning／Tracking、caption、SRT、Text-Based Editing、停頓偵測與刪除。

- **主要位置**：Text panel、Properties／Essential Graphics、Captions、Transcript。
- **代表物件**：graphic text、caption segment、sequence transcript、pause range。
- **核心差異**：畫面文字、字幕與逐字稿是相關但不同的物件；更改 transcript 不一定等於畫面已產生 captions。
- **驗證方式**：Program Monitor 的可讀性、Text／Captions 中的內容、時間範圍、刪除停頓後是否留下 gap。

代表問答：Text-Based Editing 刪除 pauses 時，如果結果留 gap，表示使用 Lift；題目要求連續時間軸時需選 Extract。

## 家族七：影像規格、效果與輸出

常見任務：aspect ratio、resolution、frame rate、codec／container、轉場、Lumetri、Auto Reframe、H.264 輸出與 Source Range。

- **主要位置**：Sequence Settings、Effects、Lumetri Color、Export。
- **代表物件**：sequence、effect、export file。
- **核心差異**：MP4 是 container，H.264 是常見 codec；序列尺寸與輸出尺寸可能不同，必須分別核對。
- **驗證方式**：Export Summary、檔案副檔名、Frame Size、Frame Rate、Range，並在 Premiere 外播放成品。

判讀案例：Entire Source輸出目前序列全長，Source In／Out只輸出已標記範圍。這裡先辨認Range與片長的關係，實際輸出沿用CH0-2；不另外要求執行未指定範圍的新任務。

## 三個容易改錯物件的反例

以下三個結果都可能看起來「有做事」，但改錯了物件。請先判斷哪裡看得出差別，再展開解答。

1. 題目要 sequence marker，卻在 Source Monitor 建成 clip marker。
2. 題目要把 A1 track 靜音，卻只停用一個 audio clip。
3. 題目要改 timeline clip 的 Scale，卻改到 sequence settings 或用滑鼠移動 Position。

<details>
<summary>核對三個錯誤的修正方向</summary>

Sequence marker 應出現在序列時間尺，只有 Source 裡有標記時，先Undo錯誤標記、點回Timeline並取消片段選取，再定位建立。A1整軌靜音看軌道標頭M，單一clip停用看該片段的Enabled狀態；先恢復片段，再改軌道M。Scale 題應選指定timeline clip，到 Effect Controls > Motion 看Scale；先復原誤改的序列尺寸或Position，再只調Scale。

</details>

## 完成檢查

使用 `function-map-check-v1.md` 的五個固定任務。先自行讀題，遮住答案，逐題寫下：

- 它屬於哪個功能家族？
- 作用物件是什麼？
- 最可能先開哪個面板或選單？
- 完成後看哪個狀態驗證？

五題固定範圍是：Unlink 且位置不變、建立 9:16 Auto Reframed Sequence 且保留原序列、Extract 且不留 gap、A1 整軌 Mute、Remove Unused 且保留磁碟來源。至少四題須同時說對作用物件、入口與驗證；家族名稱可有合理重疊。

答錯時不背正確路徑，先回到物件層級重新判斷。下一單元會把這套方法套到完整題幹。
