# make-ai-workflow Style Guide 覆寫

## 語氣與用詞

- 以「你」稱呼讀者，使用直接、技術友善、可跟做的語氣。
- 不使用行銷式誇飾，不用「簡單」「容易」預設學員已懂。
- 工作流一律譯為「流程」；scenario 譯為「情境流程」；credential 譯為「連線設定」。
- 依課程定位使用「資料來源、資料映射、資料契約、控制模組、後續動作」等通用詞，再補充 Make 模組名稱。

## 案例與素材

- 主角：阿凱（27 歲，行銷專員）。
- 公司：弄一下行銷工作室（10 人小公司）。
- 同一單元固定一個 POV，不切換多個角色。
- Gmail、Google Sheets、Webhook 與逐字稿均為可替換練習素材，不得寫成唯一正解。

## 安全與免費工具前提

- 不把付費連接器、固定帳號或含 credential 的藍圖列為學習門檻。
- JSON 範例必須去除 credential、token、固定帳號、資料夾 ID 與個資。
- 實際連線不可用時，提供去敏 JSON、測試資料與固定輸出替代路徑。
