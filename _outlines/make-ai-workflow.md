## 課程定位

教初學者使用 Make 與 Gemini，從拆解工作流、建立資料契約，到讓 LLM 協助設計、修改與除錯，完成一條可測試、可還原、可交接的自動化工作流。課程同時提供 Make 實作路徑與離線模擬路徑；兩者成果與證據不可互稱。

本課程不把 Gmail、Google Sheets 或任何單一輸入方式設定為主軸。案例是教學素材；真正的學習目標是學員能辨識可替換的資料來源、穩定的資料契約，以及可驗證的模組與測試。

## 受眾畫像

- **職業**：行政、行銷、專案、教學工作者，或需要處理重複資料工作的知識工作者
- **技術底子**：會使用瀏覽器與基本雲端文件；不要求程式設計、API 或 JSON 先備知識
- **痛點**：不知道如何拆解自動化需求、不知道模組與欄位怎麼接、擔心 LLM 產出的 JSON 無法驗證

## 單元矩陣

### Part 1：先看懂：工作流與資料結構（100 分鐘）

- CH1-1：看懂一條 Make 流程：從資料進來到通知送出 — 完成一張能說明 4 個模組輸入、輸出、欄位映射與失敗影響的工作流地圖，並做一次 Gmail 來源替換註記（40 分鐘）
- CH1-2：資料契約：讓模組彼此聽得懂 — 完成資料契約與欄位映射表（60 分鐘）

### Part 2：再做出來：流程與 LLM 協作（120 分鐘）

- CH1-3：建立一條可執行的範例流程 — Make 路徑完成一條可執行的 Make＋Gemini 流程；離線路徑完成同流程的映射與 `SIMULATED` 模擬紀錄（60 分鐘）
- CH1-4：讓 LLM 協同設計：從需求到模組規格 — 使用 CH1-3 的 `scenario-v1`（Make）或 `scenario-v1-offline-map`（離線）完成可檢查的工作流設計規格（60 分鐘）

### Part 3：最後能轉用：修改、除錯與交接（140 分鐘）

- CH1-5：讓 LLM 修改與除錯 JSON — 完成最小變更紀錄與測試案例（60 分鐘）
- CH1-6：變體專題與交接 — Make 路徑提交實際測試證據；離線路徑提交固定輸出、預期路由與 `SIMULATED` 交接包（80 分鐘）

## 學習成果

1. 能用資料來源、資料映射、處理、控制與後續動作五個角度讀懂 Make 工作流。
2. 能建立資料契約與欄位映射，讓不同資料來源共用同一 AI 任務。
3. 能在 Make 路徑完成一條可執行的 Make＋Gemini 範例流程，或在離線路徑完成同流程的映射與模擬測試；能說明兩者證據差異。
4. 能要求 LLM 產生模組清單、欄位映射、限制條件與測試案例。
5. 能在移除憑證後，讓 LLM 協助提出 JSON 最小修改並進行測試與還原。
6. 能完成一個工作流變體與交接紀錄。
