# Canva 教學短片文案規範

## 本課覆寫

- 受眾為影音零基礎教師。只假設可使用筆電；登入、複製文字與檔案下載均提供起始指引。
- 學員正文禁用二元對比修辭。直接交代情境、動作及結果。必要的錯誤診斷使用現象與處理方法。
- 無職場人物設定。主案例固定為虛構校園圖書館；轉用練習使用電腦教室。
- 學員視角「你」指參與工作坊的教師。引用學生任務時明確寫「給學生的任務」，其中「你」才指學生。
- 工具為 Canva；外部素材入口與 WhisperDesktop 放課後資源。AI 腳本和付費素材不列核心。
- 橫式 16:9、三場景、30–45 秒為主規格；36 秒為時間配置示例。
- 主範例 v1 為畫面版，v2 為有聲字幕版。第一場無聲成品符合該場完成要求。
- 先用整頁文字與圖形完成最低成果，圖片與短片來源依可取得性替換。
- 術語以繁中先行，首次括註畫面英文；後文沿用同一名稱。

## 術語與第一次使用

| 名詞 | 白話說明 | 首次單元 |
|---|---|---|
| 專案 | 可持續編輯的 Canva 設計 | CH1-1 |
| 場景 | 影片中傳達一個重點的一段畫面 | CH1-3 |
| 時間軸 | 依播放先後排列畫面與聲音的位置 | CH1-4 |
| 播放頭 | 標示現在播放到哪一刻的直線 | CH1-4 |
| 匯出 | 將設計製作成可下載播放的檔案 | CH1-6 |
| MP4 | 本課使用的影片檔案格式 | CH1-6 |
| 旁白 | 配合畫面播放的講解聲音 | CH2-2 |
| 裁短／分割 | 移除片頭片尾／從指定位置切成片段 | CH2-3 |
| 字幕 | 依說話時間顯示的文字 | CH2-4 |
| SRT | 記錄字幕文字及起訖時間的檔案 | EXT1 |
| 燒錄字幕 | 將字幕固定做進影片畫面 | EXT1 |
