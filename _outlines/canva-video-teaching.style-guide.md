# Canva 影片快速上手文案規範

## 本課覆寫

- 受眾為影音零基礎教師。只假設可使用筆電；登入、複製文字與檔案下載均提供起始指引。
- 學員正文禁用二元對比修辭。直接交代情境、動作及結果。必要的錯誤診斷使用現象與處理方法。
- 無職場人物設定。主案例是虛構學生的成果報告簡報；老師自己的用途（課前預習、補課、操作教學）用「換你用」帶出。
- 學員視角「你」指教師。學生版流程卡中的「你」指學生，頁面上明確標示「學生版」。
- 工具為 Canva 免費版；主線只用免費功能。付費功能（魔法尺寸調整、強化人聲、背景移除）每個只在相關頁寫一句。WhisperDesktop 放資源頁。
- 每頁一條成功路徑：看完整示範 → 照步驟做 → 一句話提醒；不講剪輯原理、不要求分鏡或預先規劃。替代路徑放「卡住時」。
- 頁首放三行版（整個流程濃縮成三行）與完成物。
- 術語以繁中先行，首次括註畫面英文；後文沿用同一名稱。

## 術語與第一次使用

| 名詞 | 白話說明 | 首次單元 |
|---|---|---|
| 簡報並錄製 | 自己邊講邊翻頁，Canva 同時錄下投影片畫面、聲音與鏡頭 | CH1-1 |
| 影片設計 | 有時間軸、可以上字幕的 Canva 設計 | CH1-2 |
| 時間軸 | 編輯器底部依播放先後排列畫面與聲音的位置 | CH1-2 |
| 輔助字幕 | Canva 依說話自動產生、可修改的字幕 | CH1-3 |
| MP4 | 下載後可直接播放的影片檔 | CH1-3 |
| 記錄自己 | 在設計裡直接錄鏡頭或螢幕的功能 | CH1-4 |
| 範本 | Canva 做好版面的影片，換素材與文字即可用 | CH2-1 |
| 裁短／分割 | 拖邊緣去掉頭尾／從播放頭位置切成兩段 | CH2-2 |
| 檢視連結 | 對方只能觀看、不能修改的分享連結 | CH3-1 |
