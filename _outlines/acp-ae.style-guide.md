# ACP After Effects Style Guide 覆寫

## 教學口吻

- 使用繁體中文，介面名稱保留 Adobe 英文原詞。
- 第一次出現時寫成「Composition 合成」、「Timeline 時間軸」；後續依介面標籤保留英文。
- 直接說明作用對象、設定值與結果。避免「簡單」「只要按一下」等弱化操作難度的措詞。
- 每段操作先指出目前應選取的圖層、面板或 Composition。

## 核心術語

| 英文介面或概念 | 講義用語 | 說明 |
|---|---|---|
| Project | Project 面板／專案 | `Project` 作面板名稱，`專案` 作整體工程概念 |
| Composition | Composition／合成 | 不縮寫為 Comp，除非引用介面命令 |
| Layer | 圖層 | 介面欄位或選單可保留 Layer |
| Timeline | Timeline／時間軸 | 第一次並列，後續依畫面脈絡使用 |
| Current Time Indicator | CTI／目前時間指示器 | 第一次完整說明 |
| Keyframe | Keyframe／關鍵影格 | 不譯成關鍵幀 |
| Work Area | Work Area／工作區段 | 避免與 Workspace 工作區混淆 |
| Workspace | Workspace／面板配置 | 說明它是介面配置 |
| Mask | Mask／遮罩 | 說明作用於同一圖層 |
| Track Matte | Track Matte／軌道遮罩 | 說明使用另一圖層控制可見範圍 |
| Blending Mode | Blending Mode／混合模式 | 作用於像素混合 |
| Adjustment Layer | Adjustment Layer／調整圖層 | 影響下方圖層 |
| Render Settings | Render Settings／渲染設定 | 品質、解析度與時間範圍 |
| Output Module | Output Module／輸出模組 | 格式、通道與輸出相關設定 |

## 題目卡格式

每張操作題卡依序呈現題目要求、作用對象與層級、指定值與時間、不得改動項目、起始與完成狀態、操作位置、完成檢查、復原位置及版本備註。

題號只作索引。正文要指出同一能力可遷移到哪些新名稱、數值或工程狀態。

## 畫面與截圖

- 一張圖只標示當下要看的面板、圖層、屬性或數值。
- 先提供全畫面定位圖，再提供必要的局部放大；局部圖須標明所在面板。
- 文字要指出讀者應比較的值或狀態，不單獨使用「如下圖」。
- 題目原圖與自製操作圖使用不同標籤。
- 現行介面截圖記錄 AE 完整版本、作業系統與擷取日期。

## 版本標記

- `已驗證`：在指定 AE 版本與作業系統實際重跑。
- `舊版參考`：來源為 2022–2024 題目，尚未在授課版本核對。
- `替代路徑`：現行版本位置不同，但能力與完成狀態相同。
- 未重跑的步驟不得使用「現行介面相同」或「已可授課」。

## 學員版與教師版界線

- 學員版保留任務、完整示範、練習、答案、驗收與修復。
- 教師版另記授課時間、示範順序、舊版題目對照與授權限制。
- 未確認授權的完整原題與原書截圖只留在教師研究資料，不進學員下載檔。
