# CCS 認證研習 Style Guide

本檔列出 CCS 認證研習 9 小時主線的專屬規則；其餘遵循 [_style_guide_template.md](_style_guide_template.md) 與課程共通規範。單元內容依大綱逐一製作與審查；未完成的單元不視為已通過。既有 HTML 舊頁先保留，須在新單元內容確認後再安排轉製。

## 語言與教學密度

- 使用繁體中文、直接稱呼「你」。每個概念先說明它是什麼，再交代成立條件、常見誤解及可採取的下一步。
- 解釋要讓初次接觸者能照著判讀；同一判斷只完整解釋一次，後續以新例子或不同判準推進，不用換句話反覆重述。
- 範例提供完整輸入、示意輸出、依據與修復方式。示意輸出要標明是教學編寫或實際執行結果，不能混淆。
- 提示詞以可直接複製使用為主。CH1-2 起的共用架構包含四個必要欄位：背景／資料、任務、限制與缺資訊處理、輸出格式；受眾／角色、範例、驗證及任務拆解依情境選用。
- 各單元按任務提供相應架構；需要檢核時，使用與待查問題相符的檢核提示詞，不要求學員以紙本記錄表反覆自評。
- 初階主線教學員如何直接選用並填妥提示詞架構。反覆迭代可作為遇到明確缺口時的補救選項，不列為所有新手都必須完成的核心流程。

## LLM 敘述邊界

- 工具中立，不預設任何單一廠牌、付費方案或帳號。用「模型依本次可用輸入產生文字」描述生成，不把流暢文字當成理解、意圖或事實正確的證據。
- 說明「記憶」時，明確區分模型訓練所得的一般模式與人對個人的主動、共同記憶。模型可使用本次運算收到的前文、摘要、檢索資料或其他輸入；資料由應用程式／服務管理並提供，方式依產品而異。
- 可以說明模型依明示條件分類、比較或整理；同時交代這些輸出不代表人的主觀經驗、獨立判斷或責任承擔。
- 教學檢核聚焦於可定位的輸入、引用片段、標籤及下一步。若檢核結果只是模型生成的結論，須說明它不是正確保證。

## 工具示範

- Gemini Notebook（原 NotebookLM）僅作講師可選的來源檢索示範，用來說明應用程式如何把外部資料帶入當次作答；不要求學員登入或操作，也不稱為模型的個人記憶。
- Google 已公告產品更名；講師介面與功能在 G3 前重新查證。未查證前使用概念圖或預備範例，不描述為已驗證的現行介面。
