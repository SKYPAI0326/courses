# Mission: SQL Server Instructor

## Why

在三個月內準備好教授 SQL Server 資料庫基礎 28 小時、資料庫管理與維護 35 小時，以及 Cloud Data／Modern Data Stack 簡介 7 小時。目標包括講解、實際操作、依據證據診斷問題，以及帶學員完成可檢查的成果。

## Success looks like

- 在受支援的 SQL Server 環境完成資料庫設計、T-SQL、檢視表、索引與課綱涵蓋的管理操作，留下可重現結果。
- 面對未背過的問題，先蒐證，再解釋判斷、採取安全處置並確認結果；無法判定時明確說明。
- 完成一場 30–45 分鐘試教，並取得另一位真人學員對理解程度與提問處理的回饋。
- 留存教材、操作步驟、本人實作結果及錯誤修復證據。

## Constraints

- 截止日：2027-01-02。起始能力、每週可投入時間及真人試教對象尚待確認；使用者回報另有 ASUS G14（AMD CPU、NVIDIA 獨顯），但其 OS 與 SQL Server 實驗可用性待查。
- 不捏造真實事故、產品行為、學習成果或使用者實作證據。受控實驗需明確標記為實驗。
- 未經本人操作、診斷或授課驗證的能力不標記為已掌握。

## Out of scope

- 三個月內成為大型企業資深 DBA、重大事故指揮者，或所有雲端資料平台的生產專家。
