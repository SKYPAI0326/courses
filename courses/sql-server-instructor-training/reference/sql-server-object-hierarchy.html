SQL Server 講師訓練 · 速查 01

先分清楚物件在哪一層

連線、資料庫物件和查詢錯誤常落在不同層。能說清楚層級，是學習 SQL Server 的第一個定位工具。

主機執行作業系統與 SQL Server 服務的電腦或 VM。
Database Engine 執行個體（instance）一個執行中的資料庫引擎服務；應用程式連線到執行個體。
資料庫（database）執行個體管理的一組資料與資料庫物件。
結構描述（schema）資料庫內用來組織及管理物件的命名空間。
資料表（table）以資料列（rows）與資料欄（columns）組織資料。

把連線路徑講完整

用戶端先向 Database Engine 執行個體提出連線，接著送出 T-SQL。執行個體依目前資料庫與物件名稱處理要求，並檢查登入身分是否有相應權限。執行個體、資料庫、結構描述和資料表因此不能混稱為「資料庫」。

關鍵區辨
執行個體管理一個或多個資料庫；資料庫包含結構描述與物件；資料表由資料列和資料欄組成。結構描述不是資料庫，也不是資料表。
