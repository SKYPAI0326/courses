# 12 週訓練路線（初稿）

狀態：起點、每週時數、G14 上的 SQL Server 實驗可用性與真人試教對象待確認。使用者回報該筆電有 AMD CPU 和 NVIDIA 獨顯；週次順序先固定，個人節奏依診斷調整。

## 課程時數

| 週次 | 正式內容 | 時數 | 可驗收成果 |
|---|---|---:|---|
| 1–4 | SQL Server 資料庫基礎 | 28 | ERD／正規化決策、資料庫與資料表設計、建置腳本、口頭講解 |
| 5–9 | 資料庫管理與維護 | 35 | DML 與查詢、View、索引與執行計畫、整合專題；另補最低限度的備份還原、權限、監控與 SQL Agent |
| 10 | Cloud Data／Modern Data Stack 簡介 | 7 | ETL／ELT 流程圖、平台差異說明、單一平台小型實作（須先確認帳號及費用） |
| 11–12 | 複習、陌生題診斷、真人試教 | 額外 12–16 | 30–45 分鐘教學、可檢查教材、另一位真人學員的回饋 |

### SQL Server 資料庫管理與維護（35 小時）

| 單元 | 時數 |
|---|---:|
| 基本查詢與 DML：新增、更新、刪除及安全交易 | 11 |
| 進階查詢與結果驗證 | 8 |
| 檢視表 | 3 |
| 索引規劃、執行計畫與效能觀察 | 6 |

其中只有 4 小時正式內容涵蓋傳統 DBA 管理操作；獨立實作時數必須用於反覆練習和復原驗證。若需要教授深入備份策略、效能診斷或高可用架構，現有 35 小時配置不夠，需增加課時或調整原課綱。

### Cloud Data／Modern Data Stack 簡介（7 小時）

| 單元 | 時數 |
|---|---:|
| 雲端資料倉儲、資料湖及架構概念 | 2 |
| ETL／ELT、批次／增量載入與流程編排 | 2 |
| 維度模型、資料品質、治理與成本基本概念 | 1.5 |

建議每週另安排 4–6 小時實作與回憶練習；70 小時正式內容平均每週約 7 小時，連同練習約需每週 11–13 小時。若可用時間較少，需延後或縮小驗收目標，不能把未做的實作算作完成。

## 週次能力進展

| 週 | 焦點 | 必須留下的證據 |
|---|---|---|
| 1 | 資料庫系統、RDBMS、執行個體／資料庫／結構描述／資料表 | 不看筆記講清物件層級；本週先做起點診斷 |
| 2 | 關聯模型、ERD、鍵與關係 | 一份 ERD，能說明主鍵、外鍵與基數 |
| 3 | 正規化與資料完整性 | 展示一次設計拆分並解釋避免的異常 |
| 4 | SQL Server 與建立資料庫、資料表 | 在 SQL Server 上執行建立腳本並查核結構 |
| 5 | DML 安全操作與基本查詢 | 執行 SELECT／INSERT／UPDATE／DELETE，展示修改前後結果 |
| 6 | JOIN、彙總、子查詢／CTE 等進階查詢 | 根據題目寫查詢並解釋結果基數 |
| 7 | 交易、View 與可維護查詢 | 建立並驗證 View；說清楚交易提交／回復邊界 |
| 8 | 索引、執行計畫與效能觀察 | 以實際查詢計畫比較索引前後；不只憑感覺宣稱變快 |
| 9 | 基礎管理與維護：權限、備份還原、SQL Agent、監控 | 在 x64 實驗主機完成至少一次備份還原及一次工作／權限診斷 |
| 10 | Cloud Data、ETL／ELT、倉儲與平台定位 | 架構圖、資料品質檢查與平台取捨口頭說明 |
| 11 | 綜合專題與未背過的問題 | 先蒐集實際輸出／錯誤，再寫判斷與復原步驟 |
| 12 | 真人試教與能力補洞 | 真人學員回饋、試教錄影或觀察紀錄、修訂清單 |

## 必須坦白的範圍風險

提供的大綱在「管理與維護」明列 DML、View、Index、專題；這些內容本身不足以代表完整 DBA 管理與維護。為達到「能解決相關問題」，路線會補入權限、備份還原、SQL Agent 與監控，但 35 小時只能訓練常見基礎處理，不能涵蓋所有企業級管理、HA／DR 架構及重大事故指揮。若授課單位不允許補充範疇，授課能力也必須依原大綱收窄。

Cloud Data 範疇也要區分產品類型：BigQuery 與 Snowflake 可作雲端分析／倉儲例子；Azure SQL Database 是受管理的關聯式資料庫，不能直接當成等同型態的倉儲產品。Microsoft 生態系的倉儲例子應另看 Fabric Warehouse 或 Synapse。7 小時只能教核心概念、架構選擇與單一平台導覽，不足以培養多平台工程能力。

## 驗收閘門

- 第 1 週：起點、工時與可用環境確認；若沒有 x64 SQL Server，管理維護實作不進入「已驗證」狀態。
- 第 4 週：能獨立說明資料模型並在實機建置資料庫與資料表。
- 第 8 週：能獨立完成常用查詢、View、索引並解讀實際執行計畫。
- 第 10 週：能講授指定平台的入門資料流程，並明示未操作過的平台與限制。
- 第 12 週：需有真人學員參加試教。若沒有真人，只能記為個人試講，不能宣稱已驗證教學互動能力。
