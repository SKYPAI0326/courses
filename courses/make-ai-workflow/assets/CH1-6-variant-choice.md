# CH1-6 變體選擇單

先選一個變因，再開始寫規格。正式的 `scenario-v1` 只讀、不覆寫；本單可直接複製為 `variant-v1/choice.md`。

## A：批次彙整

| 項目 | 內容 |
|---|---|
| 新需求 | 每週將多筆回饋整理成一份摘要文件 |
| 唯一變因 | 從一次處理一筆改為一次處理一批 |
| 保持不變 | 每筆輸入契約、Gemini 三個輸出欄位、`needs_review` 安全出口、Docs 交付 |
| 必須重驗 | 批次收集／Iterator、任一筆需人工時的整批處理、三筆測試 |
| 不在本次範圍 | 換資料來源、改提示詞、增加通知模組 |

## B：Gmail 來源

| 項目 | 內容 |
|---|---|
| 新需求 | 用信件資料取代 Sheet 列作為回饋來源 |
| 唯一變因 | 來源欄位映射改為 sender、subject、body |
| 保持不變 | Gemini 輸出契約、Filter、Docs、待人工確認出口 |
| 必須重驗 | sender／subject／body 映射、空白 body、三筆測試 |
| 不在本次範圍 | 批次彙整、改提示詞、增加 Email 回覆動作 |

**我的選擇：** □ A 批次彙整　□ B Gmail 來源
