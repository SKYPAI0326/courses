# Microsoft AI-901 認證準備課程

## 目前狀態

- **slug**：`ai-901-exam-prep`
- **課程定位**：AI-901 模擬試題導向的認證準備課程
- **目前階段**：來源建檔完成，課程大綱、教案與 learner-facing HTML 尚未建立
- **來源語言**：繁體中文為主，部分題目附英文原文

## 來源文件確認

兩份來源皆以相同的 AI-901 能力範圍為核心：

1. 識別 AI 概念與能力（40–45%）
2. 使用 Microsoft Foundry 實作 AI 解決方案（55–60%）

題庫涵蓋是非、單選、多選、情境配對與完成句子等形式，主要主題包括：

- Microsoft 負責任 AI 原則
- 生成式 AI、提示、Token、Temperature、嵌入與多模態模型
- Microsoft Foundry 模型部署、遊樂場、SDK、Agent 與 Evaluators
- Azure Language、Speech、Vision 與 Content Understanding
- OCR、語音辨識／合成／翻譯、實體與情感分析

來源文件已放在本機 `_sources/`；此目錄依專案規則不進 Git。版本、頁數與雜湊值記錄於 [`SOURCE-NOTES.md`](SOURCE-NOTES.md)。

## 使用邊界

- 來源明確標示為模擬試題，不是真實認證試題。
- 題目與答案目前只作為課程需求分析與練習素材來源，尚未完成逐題事實查核。
- Microsoft Foundry 與 Azure 服務介面可能變動；進入教案製作前，需用 Microsoft 官方 AI-901 study guide 與產品文件核對現行考試範圍、術語及操作流程。
- 本資料夾目前不代表課程已可授課或可發布。
