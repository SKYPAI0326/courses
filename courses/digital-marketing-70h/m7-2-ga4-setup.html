單元 7-2

安裝 Google 代碼並用預覽模式驗證

把自己的 GTM 容器接上 GA4，再用練習頁留下網站、GTM、GA4 三層驗證紀錄。

學習目標
能在 GTM 建立網頁容器與 Google 代碼，連到自己的 GA4 評估 ID
能用 Tag Assistant 預覽練習頁，核對容器、資料層事件與參數，並做應出現與不應出現的測試
能依「網站推送、GTM 看到、GA4 收到」三層證據排查看不到事件的原因
本節完成物
預覽模式驗證紀錄
01

預覽模式要證明三層訊號確實接通

這一節把自己的 GTM 容器載入山徑咖啡預約練習頁，留下網站、GTM、GA4 三層正反例紀錄。

資料層（dataLayer）是網站把事件與參數交給 GTM 的資料佇列。Tag Assistant 預覽模式顯示容器收到的事件、變數與代碼觸發結果。GA4 DebugView 顯示開啟除錯模式裝置的事件，位置是「管理 → 資料顯示 → DebugView」；即時報表查看最近活動。Monitor events in DebugView（2026-11 查證）。

右下角（手機版在上方）的監看區列出最近 5 筆網站事件、參數與序號；Tag Assistant 證明 GTM 看見；DebugView 或即時報表證明 GA4 收到。一層通過不代表另外兩層通過。

02

先建立 GA4 資源與網頁資料串流

GA4 資源是練習資料的收件位置；GA4 官方示範帳戶（數據分析模組用過的那個）只能查看既有示範資料，不能接收這張練習頁的事件。完成本步會取得 G- 開頭的評估 ID，再交給 GTM 的 Google 代碼使用。

  1. 到 GA4「管理 → 建立 → 資源」，填資源名稱、報表時區與幣別，再選產業類別和企業規模。Set up Analytics for a website and/or app（2026-11 查證）。
  2. 進入新資源的「管理 → 資料收集和修改 → 資料串流 → 新增串流 → 網頁」。網站網址填 skypai0326.github.io，串流名稱自訂，加強型評估保持開啟。
  3. 加強型評估會自動收集 page_view、scroll、外連 click、站內搜尋、影片、file_download、form_start、form_submit。本頁的 comparison_open 等是另外定義的自訂事件；要避免和自動事件重複，重要表單也要自行驗證，因為 form_submit 不一定適用所有表單。
  4. 複製網頁串流中的 G- 評估 ID。再到「管理」的資源欄，按「資料設定 → 資料保留」（畫面以實際為準），把事件資料保留設為 14 個月；一般資源只能選 2 個月或 14 個月，選短的會讓之後的探索報表看不到較早的資料。Data retention（2026-11 查證）。
03

建立容器與 Google 代碼

先把自己的 GTM、GA4 與練習頁連在一起。完成時應有 GTM- 容器 ID、G- Google 代碼 ID，以及使用 Initialization - All Pages 觸發的 Google 代碼。

  1. 到 Google Tag Manager 建立帳戶，容器平台選「網頁」，複製 GTM- ID。Get started with Tag Manager（2026-11 查證）。
  2. 在 GTM 按「代碼 → 新增 → 代碼設定 → Google 代碼」，貼上自己的 G- ID。舊的 GA4 設定代碼已由 Google 代碼取代。GA4 Configuration tag 改為 Google 代碼（2026-11 查證）。
  3. 觸發條件選 Initialization - All Pages，命名後儲存。正式網站的同意預設要比 Google 代碼更早載入，觸發條件用 Consent Initialization - All Pages；練習頁已經內建，本頁只需按接受，完整設定在本模組最後一節。
  4. 練習頁線上網址是 https://skypai0326.github.io/courses/courses/digital-marketing-70h/assets/practice/booking-practice.html；網址後加 ?gtm=GTM-自己的ID。頁面上方應顯示自己的容器 ID，範例 GTM-XXXXXXX 會被擋下。

自有網站要把第一段容器程式碼放在 <head> 越前面越好，第二段放在 <body> 開頭；有外掛或設定欄位時依平台說明。Install the Google Tag Manager container snippet（2026-11 查證）。本頁只用練習頁的 ?gtm= 參數。

04

接受同意後連上 Tag Assistant 與 GA4

接著驗證容器連線、Google 代碼觸發與 GA4 的 page_view 收件，對象是練習頁、Tag Assistant 與自己的 GA4 資源。

  1. 在 GTM 右上按「預覽」，貼上含 ?gtm= 的完整網址並按 Connect。系統會開一個新分頁載入練習頁；在新分頁操作，回 Tag Assistant 視窗看事件，成功時顯示 Connected。
  2. 練習頁四項同意預設為「拒絕」。先在左下橫幅按「接受全部」；分析儲存被拒絕時，GA4 資料可能看不到或不完整。Consent settings in Tag Manager（2026-11 查證）。
  3. 在 Tag Assistant 確認 Google 代碼只觸發一次，代碼 ID 等於自己的 G- ID。
  4. 到 GA4 DebugView 或「報表 → 即時」核對 page_view；DebugView 只顯示開啟除錯模式的裝置事件。驗證紀錄另列「頁面載入」一列，專門記 page_view 的 GA4 收件結果。
05

山徑咖啡示範：三個資料層事件的正反例

練習頁有四個自訂互動：三個預約事件供示範，line_join 留給練習。示範確認網站與 GTM 的事件、參數及反例；GA4 先用 page_view 驗證收件，自訂事件待下一節建代碼後再驗證。

每列記錄：操作、預期事件與參數、頁面監看序號、Tag Assistant、GA4、反例、證據備註；另加「頁面載入」一列記 page_view。

  1. 開啟比較表：展開時應多一筆 comparison_open，參數 page_type=booking_practice、product_count=3。做反例前記下最後一筆序號，收合後沒有新增就是通過。
  2. 開始預約：booking_start 只在姓名欄第一次取得焦點時推送，參數 form_id=trial_booking、page_type=booking_practice；先點 Email 欄不會觸發。做反例前記序號，同一次填表再切換其他欄位，沒有新增就是通過。
  3. 完成預約：填妥姓名、Email、時段並送出，應多一筆 booking_complete，參數 form_id=trial_booking、preferred_slot。preferred_slot 記的是選項英文代碼，例如選「平日晚上」會得到 weekday-evening。反例先記序號，缺任一必填欄位送出後沒有新增就是通過。

GA4 欄中，page_view 寫實際收件結果；三個自訂事件寫「待下一節建立事件代碼」，以免把 GTM 看見誤當 GA4 收到。

06

看不到事件時依網站、GTM、GA4 三層排查

排查要找出訊號在哪一層中斷，再到對應位置修正。

  • 網站推送：看最近 5 筆事件的序號與參數；沒有新增就查操作與必填欄位，有事件但參數錯就查頁面推送。
  • GTM 看到：網站有事件而 Tag Assistant 沒有，就查容器 ID、Connected 狀態與分頁；事件有而代碼未觸發，就查代碼或觸發條件。
  • GA4 收到：代碼已觸發而 page_view 不見，就查 G- ID、預覽連線、同意與資料篩選。

兩個 page_view 常表示 GTM 與網站原生程式碼都裝了 Google 代碼。即時報表與 DebugView 幾乎即時；一般資源的當日資料約需 2～6 小時、每日資料約 12 小時。Data freshness（2026-11 查證）。

07

用 line_join 完成可重跑的驗證紀錄

練習改測 line_join，欄位與示範相同。先重新整理、確認容器 ID、連上預覽並按「接受全部」。

  1. 正例：按「推送加入 LINE 事件」，預期頁面與 Tag Assistant 各出現 line_join，參數 placement=booking_practice_bottom、page_type=booking_practice。
  2. 反例：先記下監看區最後一筆序號，只捲動到 LINE 區塊但不按按鈕；序號沒有新增就是通過，證明觸發時機是點擊，不是看見區塊。
  3. GA4 欄：本頁先記 page_view 的實際收件；line_join 寫「待下一節建立自訂事件代碼」，不能把資料層事件當成 GA4 已收到。
  4. 重新整理後重做正例，確認事件與參數一致，備註測試時間、容器 ID 後四碼、截圖編號。

完成欄位後，再展開參考方向核對證據完整性。

做完再展開：參考方向

合格紀錄會保留正例新增的序號、事件與參數，也記下反例操作前後序號沒有增加；網站與 Tag Assistant 分欄，GA4 尚未建立 line_join 事件代碼時如實標示。page_view 則在「頁面載入」列記下 GA4 收件結果。
