## 2. 站外信任資料（示範用）

對象：`https://example.com/products/riverline-700` 溪線 700 商品頁。資料整理日期：2026-11-05。

### 頁面信任訊號現況

| 觀察項目 | 頁面或網站上看到的內容 |
|---|---|
| 內容負責人 | 商品頁未顯示具名作者或內容負責人。 |
| 更新日期 | 頁尾顯示「更新：2026-10-20」。 |
| 關於頁 | 頁尾連到「關於山徑咖啡」，內容寫明為台北在地咖啡器具選品店。 |
| 聯絡資訊 | 頁尾顯示客服 Email 與門市電話。 |
| 隱私政策 | 頁尾有隱私政策連結。 |
| HTTPS | 網址列顯示 `https://`。 |
| 合作揭露 | 商品頁未顯示贊助、合作或聯盟連結說明。 |
| 出水影片拍攝條件 | 影片文字寫「700 ml 壺、500 ml 水量」，未顯示拍攝日期與操作者。 |

|---|---|---|---|

## 3. 站外信任資料（練習用）

| 觀察項目 | 頁面或網站上看到的內容 |
|---|---|
| 內容負責人 | 頁面標示「門市服務團隊整理」，沒有個人姓名。 |
| 更新日期 | 頁面未顯示更新日期。 |
| 關於頁 | 頁尾有「關於山徑咖啡」連結。 |
