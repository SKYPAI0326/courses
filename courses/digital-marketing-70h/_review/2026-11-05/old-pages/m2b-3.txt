學習目標 OUTCOMES
能直接套用文案、企劃、競品、受眾四類 Prompt 模板，完成當日行銷工作
能根據模板結構自行修改填入品牌變數，不需要每次從零寫 Prompt
能建立個人的 Prompt 庫管理系統，持續累積有效的模板
CONCEPT · 為什麼要建庫
### 每次從零開始，是在浪費你最有價值的資源
如果你每次需要 AI 協助時，都重新思考怎麼寫 Prompt，你就是在用「思考 Prompt」的時間替代本應「思考行銷策略」的時間。這不是提升效率，是換了一個不同的低效率。
Prompt 庫的概念很簡單：把那些「你曾經試過、有效的 Prompt」儲存起來，填入變數後直接使用。時間久了，你的庫會越來越精準，越來越符合你的品牌和工作場景——這是一個會增值的工作資產。
類比
就像好的設計師不每次都重新建立色彩系統和元件庫，好的行銷人也不每次都重新寫同類型的文案。Prompt 庫是你的 AI 工作的「設計系統」——一致、可複用、可迭代優化。

你是一位擅長社群文案的品牌寫手，熟悉 [目標受眾] 的語言和生活情境。

本次訴求重點：[主打什麼價值或情境]
格式：繁體中文台灣用語，[字數] 字以內，三段式（場景開場 → 核心訊息 → CTA），末尾附 5 個 hashtag。
限制：不使用 [禁忌詞]；語氣不過度促銷；不捏造數字。

      廣告標題批量生成（A/B 測試用）
你是資深廣告文案師，熟悉數位廣告的點擊率優化邏輯。
請為以下廣告生成 10 個不同切角的標題：

      企劃
      行銷活動企劃框架

### 分析 Prompt 模板
      競品
      競品定位分析
你是品牌策略顧問，擅長競品分析與市場定位。
請分析以下 [N] 個競品在 [市場/產業] 的定位：
競品：[品牌A、品牌B、品牌C]
請依序完成：
步驟1：各品牌的核心定位訴求（各 2-3 句）
步驟2：三品牌的共同點（市場共識是什麼）
步驟3：三品牌各自的差異化角度
步驟4：市場空缺分析（哪個受眾或訴求目前沒有人在做？）
步驟5：對我方品牌的策略建議方向
⚠ 請注意：以下分析僅基於公開資訊推斷，請不要捏造具體數字或未公開的市場份額。
使用場景：品牌策略規劃前的市場掃描，注意驗證 AI 輸出的事實內容

      Persona 生成器

BUILD YOUR OWN · 建庫方法
### 如何打造你自己的 Prompt 庫
1
        選定工具：Notion / Google Docs / Obsidian 任一皆可
        重點是分類清楚且隨時能找到。建議用「任務類型」分類（文案/企劃/分析/研究），而不是按時間排列。
2
        每個 Prompt 存三個欄位
        ① Prompt 模板本身（含 [變數] 標記）② 適用場景說明 ③ 上次產出的滿意輸出範例。有了例子，下次一眼就知道這個模板適不適合。
3
        只儲存用過且有效的
        「聽說這個 Prompt 很厲害」不算。必須是你親自測試、調整、得到滿意輸出的版本。收藏太多沒用的 Prompt 比沒有庫還糟——你不會用到它們的。
4
        定期更新：每個月整理一次
        AI 工具在進化，你對 Prompt 的理解也在進化。每個月花 15 分鐘回顧庫——刪掉不再有效的模板，把近期迭代出的更好版本替換進去。
5
        品牌化：填入你的固定變數
        把你品牌的常用資訊（受眾描述、品牌語氣、禁忌詞）直接填入模板，建立「品牌版 Prompt」——這樣每次使用時只需要填入任務相關的變數，不需要每次重新描述品牌背景。

AI 接口 · Prompt 庫填好一格長怎樣
### 不是收藏 prompt，是建立可重用模板
「Prompt 庫」聽起來抽象，下面示範一個「Email 主旨改寫」模板從建立到使用的完整流程。看完你會理解：好的 Prompt 庫格子 = 一個能換 placeholder 重複用的模板 + 使用紀錄。
Prompt 庫一格的完整內容（存到 Notion / Google Keep / Apple 備忘錄）
P-EDM-001 · Email 主旨 A/B 變體生成
場景：發 EDM 前要做 A/B 測試，需要 5 個不同心理觸發角度的主旨備選工具：ChatGPT 或 Claude建立日期：2026-05-22效果評分：★（建立後使用 3 次，每次都拿到至少 2 個可用版本）
Prompt 內容：
你是專寫 EDM 主旨的文案編輯。我需要為以下 EDM 寫 5 個 A/B 測試主旨備選：
      ・產品/活動：[填入]
      ・目標受眾：[填入。如「過去半年買過的老客戶」]
      ・核心 benefit：[填入。如「限時 8 折」]
      請給 5 個不同心理觸發角度的版本：
      1. 急迫型（時間/數量限制）
      2. 好奇型（疑問 / 反直覺開頭）
      3. 利益型（直接強調好處）
      4. 個人化型（提及對方過去行為）
      5. 社會證明型（提及人數 / 評價）
      每個版本：≤ 20 字、避免「驚喜」「不容錯過」這類陳腔濫調。
使用紀錄：
2026-05-22 · 春季新品上市 EDM · 採用第 3 版（利益型）→ 開信率 28%（基線 18%）2026-04-10 · 會員續訂提醒 EDM · 採用第 4 版（個人化）→ 開信率 32%2026-03-15 · 線上活動報名 EDM · 採用第 1 版（急迫型）→ 報名率比上次高 15%
注意 5 個要素：(1) 編號 + 名稱、(2) 場景定義、(3) Prompt 含 placeholder、(4) 效果評分追蹤、(5) 使用紀錄。建議從 5 個你最常重複的任務開始建模板，3 個月後自然累積到 20+ 格。填空式重用、不是收藏式囤積。
Prompt 庫的判準：「下次遇到同類任務，能不能 60 秒內找到這格、改 placeholder、貼進 AI？」答得出來 = 好模板。答不出來 = 那只是筆記不是庫。建議用 Notion table 或 Apple 備忘錄資料夾分類，避免存進「ChatGPT 對話歷史」裡（搜不到 = 等於沒存）。
