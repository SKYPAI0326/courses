# 注意力：前三秒與 Hook
把核心訊息改成可兌現、可測試的觀看理由，再從留存資料找下一版要改的地方。
學習目標：能說明前三秒檢查窗的用途與限制，以及開場三段各自的任務｜能依受眾問題與可用事實，用不同 Hook 類型寫出可兌現的開場｜能讀觀看曲線找出停滯點，提出一個原因假設並只改一個變因
本節完成物：三個不同類型的 Hook（都引用核心訊息）、一段前三秒設計與一份觀看曲線判讀

## Hook 先回答觀眾為什麼值得繼續看

社群開場要解決的問題，是觀眾還沒理解內容之前，如何快速辨認「這和我有關」。Hook（開場鉤子）是開場提出的觀看理由，會留下一個尚未回答、但後段確實能回答的問題。完成 Hook 後，你應能說出三件事：這是誰的問題、為什麼現在要看、接下來會得到什麼。

觀看承諾是 Hook 對後段內容作出的具體預告。例如「看完知道三個比較欄位」就要真的提供三個欄位；手上只有價格與服務資料時，承諾也停在這個範圍。吸睛字眼若沒有受眾問題與可用事實，只會把錯的人帶進來，或在內容還沒兌現前失去信任。

Hook 是自然社群內容的測試變因。測試變因指一輪比較中刻意更動的單一條件；開頭改了，後段內容、片長、行動呼籲與發布條件盡量固定，才有機會判斷差異是否與開場有關。付費廣告的正式 A／B 測試會在廣告課處理，本節先練自然內容的開場假設。

## 前三秒是共同檢查窗，不是演算法門檻

前三秒檢查窗是本課用來核對畫面、字幕與口白是否指向同一問題的共同窗口。它屬於教學設定，各平台的報表窗口與名稱不同；發布後要回到自己的帳號資料調整。YouTube 續看報表把「開頭」定義為前 30 秒仍在觀看的比例；Instagram API 則有前 3 秒略過率，官方標示為估計值且仍在開發中。[YouTube 觀眾續看說明](https://support.google.com/youtube/answer/9314415)、[Instagram Insights API](https://developers.facebook.com/documentation/instagram-platform/reference/instagram-media/insights)（2026-11 查證）。

三秒內的三段各有一個任務：

1. **0～1 秒，畫面讓人停下**：第一個畫面先讓目標受眾辨認主題，例如商品並排、使用情境或問題結果。
2. **1～2 秒，第一句提出問題**：口白或字幕指出觀眾正在做的決定，不用空泛懸念代替內容。
3. **2～3 秒，承諾接下來的收穫**：預告後段會提供的比較、步驟、答案或示範。

檢查時把第一個畫面、畫面字幕、第一句口白分列。三者若各講不同事情，先縮成同一個問題；三者一致後，再看發布資料是否支持原本假設。Instagram 專業帳號可用官方稱為「試驗 Reel」的功能測試內容，資格、位置與分享條件以帳號當日畫面為準。[Instagram 試驗 Reel 說明](https://www.facebook.com/help/instagram/1013292530224018)（2026-11 查證）。

## 六種 Hook 提供不同的觀看理由

同一個核心訊息可以從六種角度進場。分類的用途是迫使寫作者改變觀看理由，而非替六種效果排名。

| 類型 | 定義與通用例句 | 適用情境與可能留下的原因 |
|---|---|---|
| 衝突 | 把兩個互相拉扯的條件放在一起。「功能更多，操作卻不一定更簡單。」 | 受眾正面臨取捨；預期被打破後想看如何解釋。 |
| 痛點 | 直接說出正在發生的不便。「規格看完，還是選不出適合自己的款式？」 | 痛點已有訪談依據；觀眾可能覺得說的是自己。 |
| 數字 | 用已有數字界定範圍。「三個欄位，先排除不合適的選項。」 | 數字可由來源回查；範圍具體，收穫較易預期。 |
| 故事 | 先交代一個尚未結束的情境。「她收藏了五支影片，最後仍沒有下單。」 | 材料中有真實或核准故事；觀眾想知道後來如何處理。 |
| 反直覺 | 提出與常見想法相反、後段能證明的觀點。「選項更多，決定可能更慢。」 | 有比較材料可解釋矛盾；與常識不同而值得查證。 |
| 共鳴 | 重述受眾心裡會說的話。「我只是想買對，不想再研究一整晚。」 | 原話或行為反覆出現；觀眾可能感到被理解。 |

數字型只引用現有事實；故事型也要能追到材料。選型後先填「受眾問題／可用事實與來源／觀看承諾」，再寫句子與選型理由。這三欄能提早看出一句話是否只是語氣漂亮，卻沒有內容可接。

## 山徑咖啡示範：三句 Hook 與觀看曲線判讀

示範用[山徑咖啡品牌包](assets/datasets/simulated-brand-pack.md)的阿傑訪談、核心訊息、商品頁與服務摘要，以及[社群內容練習資料](assets/datasets/social-content-practice.md)的既有沖煮影片觀看紀錄。

| 受眾問題 | 可用事實與來源 | 觀看承諾 |
|---|---|---|
| 已有入門壺，規格看得懂，仍怕升級選錯 | 三款商品、價格 NT$1,680～3,280；商品頁共同欄位不完整 | 看見先用共同欄位比較的順序 |
| 想親手確認壺嘴與重量是否適合 | 門市提供 20 分鐘試握與注水體驗 | 知道線上比較後還能怎麼確認 |
| 評測方法不同，很難放在一起看 | 三份訪談都提到比較或試用需求 | 知道為何要固定比較條件 |

三個 Hook 分別是：

1. **痛點**：「三款手沖壺都有規格，為什麼還是選不出下一把？」引用阿傑的障礙，適合讓升級使用者先辨認自己。
2. **數字**：「三款壺、同一組欄位，先看差異再決定是否升級。」引用商品數量與核心訊息，具體預告比較方式。
3. **衝突**：「規格都看完了，真正讓人不敢升級的差異還沒說清楚。」把資料存在與決策仍卡住並列，後段要解釋缺少的共同使用情境。

優先測試痛點型，理由是它直接接住「規格看不出差別」，且後段能用共同欄位與試握服務回答。前三秒設計：第一個畫面為三款壺與三張不同格式的商品資訊；字幕是「規格都有，為什麼還選不出來？」；第一句口白沿用優先 Hook。

觀看曲線（留存曲線）是影片各時間點仍在觀看的比例；停滯點（Drop-off Point）是曲線上觀眾明顯離開的時間。示範紀錄從 0 秒 100% 降到 3 秒 63%，當時畫面仍是咖啡粉與第一款壺，字幕只說「今天來沖一杯咖啡」。原因假設是開場沒有交代升級者的比較問題。下一版只改開頭：換成上述三款並排的畫面與痛點句，後段、片長與 CTA 保持一致。曲線指出要查的位置，尚無法單獨證明原因；流量來源與受眾差異也要一起查看。

## 用入門者資料完成同欄位練習

練習改用[受眾研究練習資料](assets/datasets/audience-practice.md)的筱晴、冠廷，以及[社群內容練習資料](assets/datasets/social-content-practice.md)的入門者訊息摘要與另一條觀看紀錄。兩位都使用入門壺約半年、預算有限，希望先看價格與一致比較。

交出和示範相同的欄位：

1. 三欄表：受眾問題、可用事實與來源、觀看承諾。
2. 三個 Hook：從六型選三種；每句標類型、引用的核心訊息或事實、選型理由。
3. 優先測試的一句與理由。
4. 前三秒設計：第一個畫面、畫面字幕、第一句口白。
5. 觀看曲線判讀：停滯點秒數、當下畫面／口白／字幕、原因假設、下一版只改的一個變因。

先把曲線數字對回畫面，再提出一項能由下一版驗證的原因。完成後帶著優先 Hook 進入平台選擇。

> 參考方向：練習曲線在 12～15 秒從 79% 降到 54%，同時口白承諾比較使用差異，畫面卻停在沒有手沖壺的空景；可把原因寫成「畫面未兌現比較承諾」的假設，下一版只替換這三秒畫面，其他條件固定。

## 用 AI 加速：擴充類型並稽核承諾

學員完成三句後，AI 可依另外三種 Hook 類型擴充候選，並逐句核對材料。觀看曲線仍由學員讀取，避免模型把同時發生的變化說成原因。

```text
擴充下列短影音 Hook，使用尚未使用的三種類型。
每句標示類型、引用的原句或事實，以及後段必須兌現的內容。
列出最多三句沒有來源、超出可用事實或影片無法兌現的文字。
保留優先測試決定給我，不預測觸及、留存或轉換。
[貼上受眾摘要、核心訊息、可用事實、影片內容與我寫的三句 Hook]
```

採用候選時記下人工修改與理由。下一步會把三句 Hook 放進受眾、內容能力、轉換路徑與產能的比較，選出第一個主測試平台。

## 自我檢查

1. 必教內容：Hook、觀看承諾、三題判準與測試變因在第 1 節；前三秒檢查窗與三段任務在第 2 節；六種 Hook 在第 3 節；觀看曲線與停滯點在示範節。
2. 山徑咖啡第一次出現在第 4 個正文小節。
3. 規則 1：做到，Hook、觀看曲線、停滯點首次出現均定義。
4. 規則 2：做到，平台時間窗與試驗 Reel 只用設計卡來源並標示 2026-11 查證。
5. 規則 3：做到，案例用內容稱呼，素材連結使用課程根相對路徑。
6. 規則 4：做到，未套固定轉場句，未使用「上一頁／上一節」。
7. 規則 5：做到，小節標題描述內容，練習參考方向位於練習末段。
8. 規則 6：做到，練習先列完成物，再提供參考方向。
9. 規則 6a：做到，示範用阿傑與既有沖煮影片；練習用筱晴、冠廷與另一支影片。兩者欄位同為三欄表、三句 Hook、優先句、前三秒設計、曲線判讀。
10. 規則 7：做到，各正文小節限制語不超過一句。
11. 規則 8：做到，人物、價格、商品數與服務均取自指定材料。
12. 規則 9：做到，AI 位於學員練習後，只擴充候選與稽核來源。
13. 規則 10：做到，只使用核准的 Markdown 元件。
14. 規則 12：做到，各節第一段先交代方法、用途、對象與成果。
15. 規則 13：做到，第一個二級標題前只有四行。
16. 型態與順序：方法型；先教問題、方法與判準，再示範、練習及 AI 稽核。
17. 示範與練習資料：示範用品牌包阿傑線與示範曲線；練習用入門者線與練習曲線。
