- 2026-11-01 改寫過一次（以下稱「現稿」），使用者審核後退件。退件原因與已確認的問題類型見 `_review/2026-11-05/diagnosis.md` 第 1～3 節，以及 `_review/2026-11-05/PM檢查-P1-M1.md`。
- 消費者心理模組（m1-*）已重寫並通過人工審核，可以當作「概念型」頁面的參考：`_lessons/digital-marketing-70h/m1-1.md`～`m1-4.md`。

## 教學型態（每頁判定一種主型態；混合時寫主／次）

| 型態 | 學員要帶走 | 講授順序 |
|---|---|---|
| 概念型 | 能說明一個理論或原理，並用它判斷情境 | 要回答的問題 → 理論名稱與出處 → 定義與特徵 → 生活例子 → 常見誤解 → 放到工作上 → 案例示範 → 練習 |
| 方法型 | 能用一套框架或步驟完成分析 | 要解決的問題 → 方法是什麼、為什麼有效 → 步驟 → 案例示範 → 練習 |
| 操作型 | 能在工具或平台完成一件任務 | 工作情境與任務 → 完成後長什麼樣 → 步驟 → 驗證結果 → 常見錯誤 |
| 整合型 | 能把前面的成果組成一份決策或企劃 | 回顧手上的成果 → 決策框架 → 示範 → 作業 |

判定依據是「學員離開這一頁時要會什麼」，不是頁面現在怎麼寫。四種都不合就寫「不合：理由」。

## 每頁輸出（照這個格式）

```text
### <單元>｜<現稿標題>
- 型態：<主型態>（次：<若有>）。理由：<一句，學員要帶走什麼>
- 學習目標草案：<1～3 條，用「能說明／能判斷／能操作／能完成」開頭>
- 保留清單（改寫前頁面中正確、應保留的概念、定義、術語、方法步驟、例子）：
  | 項目 | 改寫前怎麼教（一句） | 現稿狀態：保留／弱化／遺失 |
- 現稿問題（只列下列類型，每條附現稿原句；沒有就寫「無」，不要硬找）：
  - A 案例先上：概念或方法還沒教，就先進山徑咖啡、品牌包、企劃書
  - B 沒引入就使用：方法、步驟、名詞第一次出現時，沒說是什麼、為什麼現在做、做完得到什麼
  - C 練習等於示範：練習用的資料和示範相同，照抄示範就能交
  - D 判準不一致：頁面教的判準、示範的判斷、參考寫法三者說法不同
  - E 疑似錯誤或過時：平台功能、數字、時程看起來有問題（只標出，不用查證）
- 備註：<跨頁依賴、和其他頁重複、你判斷不了要問負責人的事>
```

「保留清單」特別注意：上一輪改寫常把專業術語（例：System 1、JTBD、CPC、ROAS、E-E-A-T）當成噪音刪掉，把定義與特徵表換成案例。改寫前頁面裡正確的概念與術語都要列出來。改寫前頁面若有錯誤或過時說法，不列入保留，寫進 E。
