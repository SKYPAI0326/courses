### m2c-1｜用 AI 寫初稿：從來源到定稿
- 型態：方法型（次：操作型）。理由：學員要帶走一套「AI 起草、人查核定稿」的分工流程，能套到任何文字任務，不綁定單一工具。
- 學習目標草案：
  1. 能說明 AI 起草與人工判斷的分工：哪些交給 AI，哪些必須由人確認。
  2. 能用可用事實表與四輪流程（選料、起草、查核、定稿）完成一篇逐句可回指來源的初稿。
  3. 能判斷草稿裡的事實句、判斷句與行動句，刪除來源外的承諾並記錄修訂理由。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | AI 與人的分工 | 列出 AI 擅長（結構初稿、批量變體、填格式、改語氣、翻譯）與人負責（品牌觀點、市場情境、驗證數字、判斷受眾、品牌聲音校準） | 弱化（只剩副標一句「由你守住來源、語氣與最後決定」，兩份清單不見） |
  | 品牌卡 | 對話開頭先貼一段固定品牌描述（受眾、語氣、禁忌詞），後續指令可精簡 | 遺失（可用事實表管事實，不管語氣與禁忌詞） |
  | 五步文案工作流 | 投料 → 初稿 → 挑選 → 潤稿 → 存檔 | 弱化（改成四輪：選料、起草、查核、定稿） |
  | 接受「夠好」的初稿 | 第一輪不求完美，先評估方向再迭代 | 弱化（只剩「不追求華麗」） |
  | 多切角再挑選、精確修改指令 | 一次要 3 個切角，選最對的一版，下具體修改指令而不是整篇重生 | 遺失 |
  | 有效 Prompt 存入 Prompt 庫 | 好結果的 Prompt 組合存起來，下次同任務直接套用 | 弱化（定稿紀錄保留原始指令，但沒有「存庫重用」） |
  | 系列貼文一致性 | 先讓 AI 設計系列骨架，再逐篇生成並交代前後篇關係；同一對話內完成 | 遺失（大綱移出） |
  | Email 冷／熱／沉睡受眾分層 | 三種受眾溫度的目標、語氣與 CTA 不同，要在 Prompt 寫明 | 遺失（大綱移出） |
  | 發布前核查清單 | 數字來源、品牌聲音、AI 口頭禪、時效、CTA 與受眾溫度、爭議表達；可讓 AI 先做第一輪自查 | 弱化（來源查核保留；口頭禪剩「空話」一句；時效、CTA 溫度、AI 自查遺失） |
  | 渠道分裝 | 同一來源改寫成 FB／IG／LINE：事實層一致、語氣層分裝 | 遺失（大綱只寫拿掉 IG 系列與 Email 分群，沒寫拿掉渠道分裝） |
  | 逐句回指來源、不可補寫清單 | 列出來源沒有的時間、價格、優惠、成效等不得補寫，三版逐句回指 | 保留 |
  | 修訂紀錄 | 保存 brief、原始 Prompt、AI 初稿、人工修訂、採納理由 | 保留 |

- 現稿問題：
  - A 案例先上：L9「本頁第一次使用[山徑咖啡品牌包]……先認識會用到的資料」，在第一個 `##`、四輪流程（L20 起）還沒教之前就打開品牌包並列出資料表。
  - B 沒引入就使用：
    1. L16「核心訊息｜校準『先比較使用差異，再決定是否升級』」：「核心訊息」沒有定義，且它屬於 M3 的 Message Brief，學員此時還沒學過。
    2. L13～14「商品頁摘要」「服務摘要」：品牌包沒有這兩個名稱（對應的是 WEB-01「首頁與產品頁摘要」、WEB-02「轉換與服務摘要」），學員找不到。
  - C 練習等於示範：L61「請使用同一份山徑咖啡資料，完成以下內容」；L47 示範已給出修正版，L69 參考寫法「應只談三款壺、比較需求與 20 分鐘試握；行動可寫『前往門市體驗頁了解預約』」，照抄示範就能交。
  - D 判準不一致：L13 說商品頁摘要用來「確認三款手沖壺、價格區間」，但 L69 參考寫法「應只談三款壺、比較需求與 20 分鐘試握」，價格區間是品牌包有的事實，寫進去算不算錯，兩處說法不同（輕微）。
  - E 疑似錯誤或過時：改寫前頁面「AI 在 10 秒內給你一個 80 分的初稿……用 5 分鐘的潤稿把它推到 95 分」，數字沒有來源，不列入保留。
- 備註：
  - L9「本頁第一次使用山徑咖啡品牌包」與現況不符：M1 四頁重寫後已經用過品牌包。
  - 示範只修了一句話（L45～47），練習要交 180～220 字初稿、逐句對照、三處修訂與定稿；示範沒有走完練習要交的完整成品，不符規則 6a「示範是練習的完整範本」。
  - 需要負責人決定：品牌卡、多切角挑選、渠道分裝屬通用 AI 用法，是否該留在本頁。`grep` 現稿：「沉睡」「系列貼文」在全課 0 頁；「冷受眾」只在 m8-4（廣告受眾，不是 Email）。Email 分層若移到 M9，要確認 M9 有接住。

### m2c-2｜用 AI 生圖：描述畫面、維持品牌一致
- 型態：方法型（次：操作型）。理由：學員要帶走把 brief 寫成圖像提示詞、再用同一判準比較候選的方法，工具可替換。
- 學習目標草案：
  1. 能說明圖像提示詞的構成元素（主體、風格、光線、氛圍、構圖與留白、負向提示）。
  2. 能把 brief 轉成可重現、可沿用到系列圖的品牌視覺提示詞卡。
  3. 能依 brief 條件逐項比較候選圖，判斷採用、修正或退回，並記錄權利與來源。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 圖像提示詞元素與術語 | 主體（Subject）、風格（Style）、光線（Lighting）、情緒（Mood）、負向提示（Negative），附帶標注的完整範例 | 弱化（改成六件事；「視覺風格」一項與英文術語、「負向提示」一詞都不見，改稱「排除元素」） |
  | 中英提示要實測 | 不預設英文較好，同內容測中英兩版，留下能穩定重現的版本 | 遺失 |
  | 品牌一致性要素 | 色調、光線風格、拍攝風格、人物特徵、排除元素，各給設定法與範例 | 弱化（標題有「維持品牌一致」，但沒有教怎麼讓系列圖一致；拍攝風格、人物特徵不見） |
  | 品牌視覺 Prompt 串（style block） | 把品牌固定視覺參數存成一段，每次生圖先貼，再加本次主體 | 遺失 |
  | 只給主題 vs 加品牌參數對照 | A 版只給主題會像圖庫照；B 版加材質、色溫、鏡頭、氛圍、品牌標籤；附一致性公式 | 遺失（現稿的 A／B 是同一提示詞的兩張候選，不是提示詞對照；鏡頭語彙如 50mm、景深、底片顆粒都不見） |
  | 工具選用方法 | 同一 brief 交 2～3 個工具，依品牌一致性、文字正確性、權利紀錄、修正時間評分，開課日重查 | 保留（工具改為三種產品形態並更新版本；Ideogram「文字入圖」用例拿掉） |
  | 圖內文字人工排版 | 價格、日期、法規文字不用生成圖當定稿，在設計工具人工排版 | 保留 |
  | 版位、安全區與裁切 | 依實際 placement 查規格，不同版位分別檢查安全區、裁切與主角構圖，不硬改尺寸 | 遺失（只剩「任務與版位」與 4:5） |
  | 候選比較再迭代、生成隨機性 | 生成一組候選比較後才調整；prompt 長、加參數都不保證改善 | 保留 |
  | 權利與來源紀錄 | 記錄工具、日期、提示、參考素材來源與授權；商標、肖像、受保護角色未釐清不發布 | 保留 |
  | 三種狀態區分 | 提示詞通過、素材已審查、發布核准是三件事 | 弱化（L48 分「提示詞符合／圖像符合」，「已審查不等於可發布」沒講） |
  | 效率要實測 | 生圖可能省找圖時間，也可能增加挑選、修圖、權利查核；用真實任務記錄總工時、費用、返工 | 弱化（只剩比較「修正時間」） |

- 現稿問題：
  - A 案例先上：L9「打開[內容產製共同練習包]……第一次使用山徑咖啡視覺資料時，先整理成小表」，提示詞卡的構成（L19）與工具選用（L21）都還沒教，就先列山徑咖啡視覺資料表。

    2. L26「Edit Model 已取代舊參考工具」：「舊參考工具」與 Edit Model 都沒有說明是什麼。
  - C 練習等於示範：L59「把練習包裡的六類視覺條件完整放進提示詞卡」，L35～42 示範已寫出完整提示詞；L66 參考判斷列的條件就是示範那幾項，照抄示範就能交。
  - D 判準不一致：
    1. 卡片內容三種說法：L19「六件事：任務與版位、主體、場景、色彩與光線、構圖與留白、排除元素」；L59「練習包裡的六類視覺條件」（練習包實際有主體、場景、色彩、氛圍、構圖、排除、後製文字七列）；L66 參考「必須有黃銅壺、米白濾杯、橡木吧台、左側晨光、暖色調與右上留白」（沒有氛圍與排除）。L11～17 小表也漏了氛圍。
    2. 比較判準三套：L23 工具選用看「符合條件的比例、修正時間、來源紀錄與使用權利」；L44 示範「逐項核對」brief 條件；L61 練習改用「構圖、品牌一致性、文字風險、人物與商標、來源紀錄」。
    3. L3 完成物「品牌視覺提示詞卡與 2 張圖」，L60 練習「沒有工具時，保留兩個待生成位置」，沒有圖也算完成，與完成物不符。

### m2c-3｜用 AI 處理影音：字幕、剪輯與生成影片
- 型態：操作型（次：方法型）。理由：學員要能用字幕、剪輯工具完成一段口白的字幕與剪輯點，並用「錯字／事實錯誤分開」的校對法驗證結果。
- 學習目標草案：
  1. 能說明字幕、剪輯、生成影片三類工具各接手哪一段，原始輸出與人工修訂要分開保存。
  2. 能對照來源口白校對字幕，分辨辨識錯字與事實錯誤，並留下修訂理由。
  3. 能標出剪輯點，說明保留或刪除的原因。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 三段式腳本 Hook → 核心價值 → CTA | 前 3 秒提出問題，中段給有來源的內容，結尾 CTA 要與影片任務一致 | 遺失（大綱移出；m4-2、m4-3 有 Hook） |
  | 腳本生成 Prompt 模板 | 時間點｜口白｜視覺提示，產 2 個 Hook 版本並標來源句 | 遺失（大綱移出） |

  - A 案例先上：L9「打開[內容產製共同練習包]，複製 Part 2A 與 2B 全部文字貼進新對話」，三種影音任務的定義（L17）還沒講就先打開練習資料（判為操作型時，情境先行可接受，但這裡在任務定義之前就要求貼資料，見備註）。

### m2d-1｜深度研究：先審研究計畫，再查出處
- 型態：方法型（次：操作型）。理由：學員要帶走「先寫計畫、再搜尋、逐筆開原頁核對、主張與推論分開」的研究方法，深度研究工具只是執行載體。
- 學習目標草案：
  1. 能寫出可審的研究計畫：決策用途、子問題、地區與期間、接受與排除的來源、停止條件。
  2. 能在深度研究工具執行前審改計畫，執行後開啟原頁核對引用。
  3. 能把主張、出處、推論與限制分開，完成附出處的研究摘要與未找到清單。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 研究的 AI 分工 | AI 負責掃描整理，人負責開原始來源判斷；AI 輸出常把來源內容與推測混在一起 | 保留 |
