### m3-1｜環境分析：從 3C、SWOT 到策略方向
- 型態：方法型。理由：學員要能用 3C 與 SWOT（含交叉推導）完成一次環境分析，推出有依據的策略方向。
- 學習目標草案：
  1. 能說明 3C（Customer、Competitor、Company）各自要回答的問題，以及「交叉點」為何是策略機會。
  2. 能判斷一項條件屬於 SWOT 的哪一格（內部 S／W、外部 O／T）。
  3. 能用 SO／ST／WO／WT 交叉推導，寫出附證據與反證條件的策略方向。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 3C 分析：Company／Competitor／Customer | 同時分析公司、競品、顧客三個維度 | 保留 |
  | 3C 提出者：大前研一 | 「3C 分析由管理顧問大前研一提出」 | 遺失 |
  | 每個 C 的檢核問題 | Company 問核心能力、資源限制、認知定位；Competitor 問定位、受眾、弱點、新進者；Customer 問核心需求、決策觸發點、未滿足痛點、選競品原因 | 弱化（每個 C 只剩一句欄位說明） |
  | 直接競品 vs 間接競品 | Competitor 檢核問題「直接 vs 間接？」 | 遺失 |
  | 3C 交叉點即策略機會 | 顧客需要、競品沒做到、我們做得到的事 | 保留 |
  | SWOT 四格名稱（Strengths／Weaknesses／Opportunities／Threats） | 中英對照列出四格與例子 | 弱化（只有中文表頭，沒有英文原名，也沒有定義段） |
  | SWOT 不停在列表，要交叉推導 | 「大多數 SWOT 分析停在列表階段」，填完要轉策略 | 保留 |
  | SO／ST／WO／WT 四類策略（攻勢／競爭／改善／防禦） | 四格交叉各寫一條策略並命名 | 弱化（只示範 SO、WO 兩種交叉，沒有四類名稱，ST、WT 不見） |
  | 證據標籤：有來源／品牌自述／評論觀察／推斷／待查 | AI 整理競品資料時每條結論要標證據類型 | 弱化（只剩「來源」「待補」，五種標籤不見） |
  | 品牌官網只能證明品牌怎麼說自己 | 官網不能單獨證明市佔或顧客認同 | 弱化（改成「競品欄只寫資料表能支持的公開主張」） |
  | Company 由學員補入，AI 不推定 | Company 維度靠 AI 推斷等於沒有分析 | 保留 |
  | 交叉洞察不能是「加強社群行銷」空話 | 沒有針對性的建議要回頭補具體資料 | 保留 |

- 現稿問題：
  - A 案例先上：第一節第二段就開品牌包，3C 還沒定義。原句：「第一次使用[山徑咖啡品牌包]，先辨認資料與角色：」（表格在 3C 定義段「3C 依序整理 Customer 顧客……」之前）。
  - B 沒引入就使用：
    - 第一段就用「3C 與 SWOT」，到第二節才說明 3C 是什麼。原句：「這一頁要把它放進 3C 與 SWOT，和自己的能力、顧客需求一起看。」
    - SWOT 全頁沒有定義或展開，直接用「四格」。原句：「若一開始就填四格，常會把想做的行動寫成機會」。
  - C 練習等於示範：練習用同一個品牌、同一批資料，示範已給出完整 SWOT 與兩條方向。原句：「換你做時，先用山徑咖啡完成一張 3C 表，再填 SWOT 四格，最後寫兩條方向。先完成自己的版本，再對照上方示範」。
  - D 判準不一致：
    - 頁面判準說機會／威脅來自外部、要問「對目標問題是幫助還是阻礙」，示範卻把資料缺口填進威脅。原句：「威脅｜公開競品資料仍不足，無法判定差異是否獨有」。
    - 頁面說競品欄只寫有來源的公開主張，但品牌包沒有任何山徑咖啡的競品資料；「小組競品資料表」是 m2d-3 各組替自己產品做的表，不是山徑咖啡的。原句：「小組競品資料表｜競品公開主張與資料缺口」、「競品欄要用前一份作業的真實公開來源補入」。
  - E 疑似錯誤或過時：無。
- 備註：
  - 跨頁依賴：m2d-3 模組作業的競品資料表是「自己組產品」的競品；m3-1、m3-4 把它當成山徑咖啡的競品來源。要請負責人決定：品牌包補一份模擬競品資料，還是 3C 示範的競品欄只示範「待補」。
  - 現稿新增的「內外部判準」「證據鏈」「反證條件」是好的補充，不在改寫前頁面裡，屬新增內容。

### m3-2｜受眾研究：STP、Persona 與信任關係圖
- 型態：方法型（次：概念型）。理由：學員要能用 STP 切分並選定受眾、把研究線索整理成 Persona，並畫出影響這次決策的信任路徑。
- 學習目標草案：
  1. 能說明 STP 三步（Segmentation、Targeting、Positioning）各自做什麼，以及區隔的四種常用維度。
  2. 能依證據完成 Persona，分清已知事實、研究假設與待補資料。
  3. 能完成一張信任關係圖，分出發起者、建議者、出資者、使用者，並依證據選一條優先路徑。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | STP 三步：Segmentation／Targeting／Positioning | 先切市場、選目標、再決定位置，中英對照 | 弱化（只講前兩步，沒有英文原名；P 推到「模組最後」） |
  | 區隔四維度：人口、地理、心理、行為 | Segmentation 依四類維度切分 | 遺失（只剩「使用經驗、購買情境、需求或行為」，沒有四維度架構） |
  | Targeting 評估：規模、成長、競爭、能力 | 評估區隔吸引力，選 1～2 個主力目標 | 弱化（改成需求明確度、品牌能力、可接觸程度） |
  | Positioning 定義與三特質（有意義、有差異、可信） | 「定位不是你說什麼，是他們記住什麼」 | 遺失（本頁不教；m3-4 有相關性／差異性／可信度三題，但沒有連回 STP 的 P） |
  | 世代只能當抽樣線索，不能直接下結論 | 把世代說法改寫成研究問題，資料有差異才按年齡分群 | 弱化（只剩「而不是只看年齡」一句） |
  | Persona 是基於研究資料的代表性工作模型 | 名字與人物設定只是方便討論，決策靠原話、行為、來源 | 保留 |
  | Persona 三欄：輸入已知事實／研究假設／還需要的資料 | AI 生成的 Persona 要分欄標示 | 保留（改成「保留原話、行為與未知」） |
  | 合成 Persona 不是研究證據 | 「課堂合成人物誌 · 尚未經訪談驗證」 | 保留（現稿另引 NN/g Synthetic Users） |
  | 決策四角色：發起者、建議者、出資者、使用者 | 四角色各有定義，一次購買可能分屬不同人 | 弱化（四角色沒有定義；練習寫「本人、建議者、可能的出資者與使用者」，發起者消失） |
  | 三種信任網絡：個人人際／樞紐傳播／興趣同好 | 各自的關係形狀、先問的問題、可查證線索 | 保留（改名「樞紐人物」「同好社群」，先問問題與可查證線索弱化） |
  | 三網絡對照表：信任基礎、常見角色、行銷任務、常見誤判 | 四個維度比較三種網絡 | 遺失 |
  | 三網絡是本課分析框架，非學術分類 | 明說不是有固定邊界的學術分類 | 弱化（只剩「本課用三種關係」） |
  | 優先路徑選擇準則：證據清楚度 × 受眾相關性 × 可接觸程度 | 依三項選一條優先路徑，附第一個驗證動作 | 遺失（本頁沒有選路徑；三準則搬到 m3-4 模組作業） |
  | 同一人可跨兩種網絡，關係分開判斷 | 卡住時的修復 | 保留 |
  | 出資者未知就寫未知，不自行填入 | 新增訪談題「上一次是誰付款？」 | 保留 |
  | audience brief（主 Persona、原話痛點、行為證據、常用平台、決策障礙） | 本頁完成後存成共同來源，M3-4 與 M4～M9 引用 | 遺失（現稿沒有提到要整理成受眾 brief；品牌包第 6 節有鎖版） |

- 現稿問題：
  - A 案例先上：STP 只給一句定義，下一段就打開品牌包。原句：「STP 的前兩步是市場區隔與目標選擇：……定位句留到模組最後完成。」接著：「本頁直接使用[山徑咖啡品牌包]三份訪談：」。
  - B 沒引入就使用：
    - 「出資者」「使用者」「建議者」三個角色全頁沒有定義，第一次出現就在練習指令裡。原句：「標出本人、建議者、可能的出資者與使用者」。
    - 「定位」第一次出現時沒說是什麼。原句：「定位句留到模組最後完成。」
  - C 練習等於示範：示範已用三份訪談寫出阿傑 Persona 與三人的關係連線，練習用同一批訪談做同一件事。原句：「請先完成三份 Persona，再畫一張圖……先完成自己的版本，再對照：品牌包沒有說誰替三人付款，因此出資者應標未知；阿傑看評測、麗芬問社團、柏翰做筆記都有訪談依據。」
  - D 判準不一致：
    - 頁面要求節點是人、平台只是接觸位置，示範的節點卻是平台、服務與自己的筆記。判準原句：「信任關係圖只有 YouTube、Facebook、門市：補上節點中的人、扮演角色、信任理由與來源」；示範原句：「阿傑連到 YouTube 評測者與大型電商評論……柏翰連到多支實測影片與自己的比較筆記；三人再連到門市試握。」
    - 示範寫阿傑連到「大型電商評論」，品牌包 INT-01 只寫「再到大型電商比價」，沒有提到評論。
  - E 疑似錯誤或過時：
    - 改寫前（不列入保留）：「最有力的區隔是『行為』和『心理』維度，不是人口學」說得太絕對；「比空白簡報開始快十倍」沒有出處。
- 備註：
  - 現稿把三位受訪者各寫成一份 Persona；改寫前與品牌包第 6 節都把 Persona 當成「代表性模型」（「阿傑型」）。一人一份 Persona 和 Persona 的定義是否衝突，請負責人決定。
  - Positioning 在 m3-2 不教、m3-4 才教；重寫時要決定 STP 的 P 放哪一頁，避免兩頁都沒交代 P 與定位三測試的關係。
  - 優先路徑的選擇在本頁消失，卻出現在 m3-4 模組作業，m3-3 開頭又說「上一頁若選同好社群為優先路徑」。三頁的依賴要對齊。

### m3-3｜消費者旅程：接觸點與缺口
- 型態：方法型。理由：學員要能畫出旅程地圖、辨認缺口，並依證據排出修補優先順序。
- 學習目標草案：
  1. 能說明旅程各階段顧客的狀態、核心問題與行銷任務。
  2. 能用「顧客需要什麼、我們給了什麼、差距是什麼」找出旅程缺口。
  3. 能依證據、影響與修補成本選出最大缺口並寫出第一個修補動作。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 旅程不是線性，但可用階段理解 | 「消費者旅程不是線性的，但我們可以用……階段來理解」 | 保留 |
  | 旅程階段（認知／考慮／決策／購買後／擁護） | 五階段表；prompt 另用六階段 | 保留（現稿統一為六階段，與品牌包第 8 節一致） |
  | 每階段的顧客核心問題 | 「我有這個問題嗎？」「哪個選項最適合我？」等 | 保留 |
  | 每階段的顧客狀態 | 第一次聽說、主動研究、縮小選擇、形成評價、主動推薦 | 遺失 |
  | 每階段的行銷任務 | 建立知名度、提供比較、降低風險、兌現承諾、讓分享容易 | 遺失 |
  | 每階段的典型接觸點 | SEO 內容、評測、比較頁、Email 序列、會員計劃等 | 弱化（只列山徑咖啡的現況接觸點） |
  | 有接觸點但沒完成任務，比空著更危險 | 用「行銷任務」逐格檢查現有活動 | 遺失 |
  | 缺口定義：顧客期待與實際體驗的落差 | 缺口的定義句 | 遺失（全頁沒有定義「缺口」） |
  | 找缺口的三問：需要什麼、給了什麼、差距是什麼 | 每個接觸點問同一組問題 | 遺失 |
  | 常見缺口類型：信任、購後沉默期、比較內容、分享機制 | 四個缺口寫法示例與優先級 | 遺失（只剩山徑咖啡的比較與購後教學） |
  | 排序準則：缺口影響力 × 填補難度（頻率、嚴重度、修補成本） | 依影響與難度推薦優先處理的階段 | 弱化（改成證據筆數、阻礙哪個問題、品牌能否修補） |
  | 沒被記錄不等於品牌沒有：寫「本批資料未觀察到」 | 先回查流程再判定 | 保留 |
  | 缺口證據表：來源編號、原句、日期、階段、情緒、是否重複 | 先做證據表再判斷缺口 | 弱化（示範一列旅程表有來源，但沒有證據表欄位） |
  | 建議附待測指標，未測前不寫成成效 | 例如表單完成率、客服重複詢問數 | 保留（「預期觀察的行為」） |

- 現稿問題：
  - A 案例先上：第一節在缺口、接觸點還沒定義前就打開品牌包。原句：「本頁使用[山徑咖啡品牌包]：」與「上一頁若選同好社群為優先路徑，就把社團討論放在考慮階段」。
  - B 沒引入就使用：「缺口」「接觸點」第一段就使用，全頁沒有定義。原句：「每格寫顧客問題、現有接觸點、可見證據與缺口，不能只列品牌正在做的渠道。」
  - C 練習等於示範：示範已畫出六階段並選出最大缺口，練習用同一份資料，而且品牌包第 8 節就是答案。原句：「換你做時，先完成六階段地圖……再列三個缺口候選並選一個。先完成自己的版本，再對照品牌包旅程」。
  - D 判準不一致：頁面要求不把猜測畫成事實，示範旅程表卻把不存在的東西寫成信任來源。判準原句：「旅程表應分別寫成已有證據與待觀察，不把合理猜測畫成已發生事實」；示範原句：「信任來源：評測者與一致實測」（品牌包 INT-03 說現有影片沒有一致條件，一致實測是需求，不是已存在的來源）。
  - E 疑似錯誤或過時：
    - 現稿：「ChatGPT 購物研究會追問需求、跨網站研究並產出買家指南」，平台功能有時效，上課前要再確認。
    - 改寫前（不列入保留）：「顧客在等待商品時是最脆弱的——他們可能後悔或感到被忽視」沒有出處；五階段表與 prompt 的六階段說法不一致。
- 備註：
  - 依賴 m3-2 的「優先路徑」，但現稿 m3-2 沒有選優先路徑這一步（見 m3-2 備註）。
  - 品牌包第 8 節「顧客旅程 v1」已是完整答案，練習若只用山徑咖啡，學員可直接抄。是否改用其他資料，請負責人決定。

### m3-4｜品牌定位：USP 與價值主張
- 型態：方法型（次：整合型）。理由：學員要能用 USP 與定位三測試寫出可證明的定位聲明與核心訊息，並把 M3 成果整合成模組作業。
- 學習目標草案：
  1. 能說明 4P 與 4C 的對應，找出企業視角與顧客視角的落差。
  2. 能說明 USP 的定義，並用差異化、相關性、可信度三測試篩選候選。
  3. 能完成定位聲明、核心訊息、可信證據與禁用空話，作為後續渠道共用的來源。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 4P：Product／Price／Place／Promotion（企業視角） | 4P 是企業的行銷組合工具 | 遺失 |
  | 4C：Customer Value／Cost／Convenience／Communication（顧客視角） | 4C 逐項對應 4P | 遺失 |
  | 4P vs 4C 找落差 | 「你以為在做的事」和「顧客實際感受到的事」之間的落差 | 遺失 |
  | 顧客成本不只金錢（時間、學習成本、風險感） | 4C 的 Cost 說明 | 遺失 |
  | USP（Unique Selling Proposition）定義 | 顧客為什麼選你，是一個最有力的理由，不是優點清單 | 弱化（只寫「USP 是獨特銷售主張」，沒有英文原名；「不是優點清單」改到標題） |
  | 定位三測試：差異化／相關性／可信度 | 三個問題驗證 USP | 保留 |
  | 差異化測試做法：把 USP 換成競品名字仍成立就不夠獨特 | 具體的替換測試 | 遺失 |
  | 相關性測試：必須是目標受眾的核心決策標準 | 「獲獎無數」顧客不在乎就沒意義 | 弱化 |
  | 可信度測試：需要可驗證支撐（標籤、認證、見證、數字） | 說不出證據，受眾不會信 | 保留 |
  | 定位陳述句式 | 「對 [目標受眾]，[品牌] 是 [類別] 中 [差異化] 的選擇，因為 [理由]」 | 保留 |
  | USP 候選三切入角度：功能／情感／場景 | 用不同角度產生候選 | 遺失 |
  | USP 證據狀態：最完整的候選、待驗證、護城河標未知 | 候選逐項對證據 ID，不宣稱最有效 | 保留 |
  | message brief 內容：主 Persona、定位句、核心訊息、3 項可信證據、不可使用的空話 | M3 收尾建立共同來源，M4～M9 引用 | 保留（不用 message-brief 名稱） |
  | M3 四單元構成策略底盤 | 環境、受眾、旅程、定位合起來 | 保留 |
  | 定位評議會：相關性、可證明、競品難複製各 0～2 分；必須排除一個替代案 | 小組只能選一個 USP 進 brief | 遺失（模組作業改成信任關係圖與推廣方向） |

- 現稿問題：
  - A 案例先上：USP 只給一句定義、三測試還沒教，就打開品牌包。原句：「本頁使用[山徑咖啡品牌包]：」（表格在第一節，三測試第一次出現在第二節示範裡）。
  - B 沒引入就使用：
    - 三測試第一次出現就在示範中直接使用，前面沒有教每一題怎麼判斷。原句：「用相關性、差異性、可信度三題檢查：受眾是否在乎？競品資料能否支持差異？品牌是否有證據做到？」
    - 模組作業的「購買心理地圖」在本頁沒有說明是什麼（來自 m1-4 作業）。原句：「每人帶小組產品的購買心理地圖、競品資料表，以及自己畫的一版信任關係草圖。」
  - C 練習等於示範：示範已列出三個候選、選定結果與定位句，練習用同一份資料做同一件事。原句：「換你做時，先用山徑咖啡資料寫三個 USP 候選，再用三題刪到一個，接著完成定位聲明、核心訊息、三項證據與禁用空話。先完成自己的版本，再對照示範」。
  - D 判準不一致：
    - 頁面說差異性要用競品資料檢查，示範卻在沒有競品資料的情況下通過差異性。判準原句：「相關性由訪談支持，差異性仍要用競品資料檢查，兩者分開記錄。」示範原句：「目前『比較＋試握』同時有網站、服務、訪談與評論支持，最適合進入定位聲明。」（四項都不是競品資料，品牌包也沒有競品資料）
    - 頁面給的定位句式有「因為〔可信證據〕」，示範定位句沒有這一格。句式原句：「對於〔目標受眾〕，〔品牌〕提供〔品類與差異〕，讓他能〔顧客價值〕，因為〔可信證據〕。」示範原句：「對已使用入門壺、想升級但怕買錯的手沖使用者，山徑咖啡提供可比較、可試握的手沖壺選擇，讓他依自己的控流習慣決定下一把壺。」
    - 本頁教定位三測試，模組作業的回饋判準卻是信任路徑的選擇準則。原句：「講師依證據清楚度、受眾相關性、可接觸程度講評」。
  - E 疑似錯誤或過時：
    - 現稿：無。
    - 改寫前（不列入保留）：USP 公式「我們是唯一能夠……的品牌」會引導寫出無證據的「唯一」宣稱；範例是保養品，與課程案例無關。
- 備註：
  - 模組作業（個人準備、小組討論、上台分享）的主體是信任關係圖與優先路徑，和 m3-2 內容重疊，定位只在最後一步帶過。作業主軸應該是定位還是信任路徑，請負責人決定。
  - 差異性測試需要競品資料，與 m3-1 備註的競品資料缺口是同一個問題。
  - 4P／4C 是否要回到本頁，或已在其他模組教過，我判斷不了，請負責人確認全課是否還有地方教行銷組合。

### m4-1｜注意力：前三秒與 Hook
- 型態：方法型。理由：學員要能用 Hook 類型與前三秒結構寫出開場，並用觀看曲線找出停滯點、提出可測試的修改。
- 學習目標草案：
  1. 能說明前三秒檢查窗的用途與限制，以及開場三段（視覺、第一句、承諾）各自的任務。
  2. 能依受眾問題與可用事實，用不同 Hook 類型寫出可測試的開場。
  3. 能讀觀看曲線找出停滯點，提出一個原因假設並只改一個變因。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 前三秒是教學用的共同檢查窗，不是演算法門檻 | 方便比較的教學設定，要依自己帳號資料調整 | 保留 |
  | 開場三段：0–1s 視覺抓取、1–2s 認知啟動、2–3s 決策點 | 每一秒的任務不同 | 弱化（只剩練習裡「第一個畫面、畫面字幕、第一句口白」） |
  | Hook 要創造「未解答的問題」 | 第一句話讓人想繼續找答案 | 保留（「未解問題」「觀看理由」） |
  | 六種 Hook 類型：衝突、痛點、數字、故事、反直覺、共鳴 | 每型有例句與適用目標 | 遺失（換成問題型、反差型、行動型三種） |
  | 各 Hook 的作用原理（預期違反、代入感、未完成敘事、認知不協調） | 每型附一句為什麼有效 | 遺失 |
  | 停滯點（Drop-off Point）定義 | 觀看者離開的時間點，IG、TikTok 提供觀看曲線 | 弱化（有讀法，沒有「停滯點」名稱與定義） |
  | 停滯點讀法：找最明顯下降→對回畫面口白字幕→只改一個變因 | 觀看曲線指出哪裡要查，不能單獨證明原因 | 保留 |
  | Hook 必須對應 Persona 痛點與核心訊息 | 承接 M3 的受眾與訊息 brief | 保留 |
  | Hook 是測試變因：只改開頭，其他條件固定 | 觀察期與成功指標發布前寫好 | 保留 |
  | 前三秒留存指標要事先鎖定 | 產出 Hook 假設與要觀察的前三秒留存指標 | 弱化（改成「哪個訊號會推翻假設」，沒有指名留存指標） |
  | AI 候選逐句回指「可用事實」，不補資料 | 沒有來源的折扣、人物、成效要刪除 | 保留 |
  | 自然社群 vs 付費廣告分工 | 本節只處理自然內容，M8 才做廣告 A/B | 遺失 |

- 現稿問題：
  - A 案例先上：Hook 只有一句定義，三種結構還沒教，就打開品牌包。原句：「第一次使用[山徑咖啡品牌包]，先分清楚資料與用途：」（位於第一節，三種結構在第二節）。
  - B 沒引入就使用：「觀看曲線」第一次出現在練習段，前文沒說是什麼、在哪裡看。原句：「觀看曲線只能指出哪裡值得檢查，不能單獨證明原因」。
  - C 練習等於示範：練習可以選示範用的阿傑與同一批事實，三種結構也和示範相同，照抄示範三句就能交。原句：「先用山徑咖啡完成一張三欄表，從阿傑、麗芬或柏翰選一人……接著各寫一個問題型、反差型與行動型 Hook」。
  - D 判準不一致：頁面說觀看承諾只能預告內容確實會回答的事，示範反差型卻承諾品牌包沒有的「同一方式比較」。判準原句：「觀看承諾只能預告內容確實會回答的事」「若字幕承諾『實測』，後段就要真的用同一條件呈現比較方法」；示範原句：「反差型：『先別只看材質；同一個方式比較，才看得出使用差異。』」（品牌包 WEB-01：只有一款有出水影片）。
  - E 疑似錯誤或過時：
    - 現稿：試播 Reels「可設定在 72 小時內表現良好時自動分享給所有人」，平台功能與時限需上課前確認。
    - 改寫前（不列入保留）：「大腦優先處理視覺信號」「預期違反是最強的注意力觸發之一」「高共鳴率帶來高儲存率」都沒有出處；例句「三個讓 IG 觸及翻倍的細節」本身是無來源的成效承諾。
- 備註：
  - 現稿把六種 Hook 換成三種自創結構。改寫前的六型是業界常見分類，要恢復六型、保留三型，還是兩者對照，請負責人決定。
  - m4-5 模組作業回饋判準「有受眾的問題、有觀看理由、有事實依據」與本頁的三題（誰的問題、為什麼現在看、接下來得到什麼）說法不同，重寫時要對齊。

### m4-2｜平台策略：IG、Threads、Facebook、YouTube、TikTok 怎麼選
- 型態：方法型。理由：學員要能用受眾證據、內容能力、轉換路徑與產能四項選出第一個測試平台，並設計有停止條件的測試。
- 學習目標草案：
  1. 能分辨平台官方說明、自家帳號資料與尚未驗證的假設。
  2. 能說明五個平台各自要看的資料，以及哪些結論不能直接推論。
  3. 能用四份證據選出主測試平台，並寫出含指標、觀察期與停止條件的 30 天測試。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 不用單一人格或人口印象概括平台 | 同一平台有不同版位、格式與受眾 | 保留 |
  | 三類證據：官方訊號／自家帳號觀察／未驗證假設 | 先查官方說明，再看自己的 Insights | 弱化（只剩「先填事實，再寫判斷」） |
  | 五平台各自「先查什麼」 | IG 分版位、YouTube 看流量來源與留存、FB 粉專社團 Reels 分開、Threads 看回覆與發現位置、TikTok 看 For You／搜尋／追蹤來源 | 弱化（第二節保留重點，Threads、TikTok 縮成一兩句） |
  | YouTube 官方把表現分成吸引、互動、滿意度 | 官方的三類訊號 | 遺失 |
  | CTR 要和曝光來源、留存、滿意度一起讀 | 不能單獨看 CTR | 遺失 |
  | 推薦會依個人觀看與搜尋紀錄個人化 | 不同使用者看到的結果不同 | 遺失 |
  | 平台未公開固定權重，單一互動沒有通用權重 | 問句、高頻發布都要自己驗證 | 遺失 |
  | 證據矩陣「不可直接推論」欄 | 例：收藏一定比按讚重要、社團一定比粉專觸及高 | 遺失 |
  | 平台選擇四份證據：受眾證據、內容能力、轉換路徑、測試容量 | 四項都能回答才進入測試 | 保留 |
  | 自然觸及與付費結果不可混比 | Facebook 盤點時的提醒 | 遺失 |
  | 30 天測試：假設、CTA、指標、觀察期、停止條件、回顧問題 | 第一個決策要寫測試期間與停止條件 | 弱化（現稿「測試界線」只有固定什麼、觀察什麼、何時回看，沒有停止條件） |
  | 觀察期要配合發布節奏與轉換延遲 | 不預設固定三個月 | 遺失 |
  | 平台決策只適用於目前輸入 | 不能延伸成某平台對此類品牌普遍較好 | 保留 |

- 現稿問題：
  - A 案例先上：第一節第二段就是山徑咖啡的平台判斷，五個平台要看什麼在第二節才教。原句：「山徑咖啡的品牌包顯示，阿傑型受眾會看 YouTube、Instagram 與 Facebook 咖啡社團……因此後兩者先標為待補證據，不直接排除。」
  - B 沒引入就使用：
    - 「30 天測試界線」第一次出現在練習，頁面沒有教測試怎麼設計。原句：「完成物包含：五平台證據表、主平台、補測平台、兩項待補資料，以及一個 30 天測試界線。」
    - 示範表的「60 秒比較短片」在本頁沒有說明（是下一頁的內容）。原句：「三個 Hook、60 秒比較短片」。
  - C 練習等於示範：練習用同一批資料填同一張五列表，只遮住一欄。原句：「先用山徑咖啡填完五列，不看示範的『初步角色』欄，自行寫主平台與一個補測平台。」
  - D 判準不一致：
    - 頁面規定選擇表六欄含「每週產能」「下一步行動」，示範表五欄沒有這兩欄。規定原句：「平台選擇表至少有六欄：平台、受眾證據、適合承接的 Hook、現有素材、下一步行動、每週產能。」示範表頭：「平台｜現有證據｜可承接內容｜待補資料｜初步角色」。
    - 練習要求引用四項中至少三項，示範選 Instagram 的理由沒有產能。原句：「每個選擇都要引用受眾、內容、承接與產能中的至少三項」；示範：「理由是有可用影片、歷史摘要與明確的預約承接」。
    - 示範說 Instagram 有品牌既有貼文與「明確的預約承接」，品牌包 SOCIAL-01 沒寫是哪個平台，且只有門市活動貼文有預約連結。原句：「Instagram｜有既有貼文與沖煮影片摘要」。
  - E 疑似錯誤或過時：
    - 現稿：Threads 台灣在地化社群標籤、Threads 廣告擴大到全球（引 TechCrunch 2026-01-21）、Facebook 影片統一為 Reels，三項平台功能有時效，上課前要再確認。
    - 改寫前（不列入保留）：平台卡標題「中高齡受眾」「娛樂優先」等標籤，和同頁「不能用單一人格概括」矛盾。
- 備註：
  - 品牌包沒有產能資料，四份證據中的「測試容量」無法用山徑咖啡示範。要不要在品牌包補上團隊每週產能，請負責人決定。
  - 品牌包 SOCIAL-01 沒標平台；示範把它當成 Instagram 帳號資料，需要負責人決定品牌包要不要寫明平台。

### m4-3｜短影音腳本：情緒弧線與行動呼籲
- 型態：方法型。理由：學員要能用四段結構、情緒弧線與 CTA 策略寫出一支 60 秒短影音腳本。
- 學習目標草案：
  1. 能說明四段腳本（Hook、衝突、解決、CTA）各自的任務與段落之間的因果。
  2. 能在腳本中安排情緒弧線的高低點。
  3. 能依行銷目標選擇對應的 CTA，並讓 CTA 接住影片內容。
- 保留清單：

  | 項目 | 改寫前怎麼教（一句） | 現稿狀態 |
  |---|---|---|
  | 四段腳本：Hook（0–5s）→衝突（5–20s）→解決（20–50s）→CTA（50–60s） | 每段任務與常用技巧 | 保留（改名障礙、解法、行動呼籲；常用技巧欄不見） |
  | 腳本先行：先寫四段文字，再考慮鏡頭剪輯 | 很多人拍了才發現沒有中心 | 保留 |
  | 情緒弧線五段：緊張→共鳴→期待→滿足→行動 | 每段的情緒任務與秒數 | 弱化（只剩「我也卡在這裡→原來可以這樣判斷→我知道下一步」三步） |
  | 步步揭露：用「第一點、第二點」製造連續小期待 | 解決段不要一次說完 | 遺失 |
  | CTA 要回答「我為什麼要做這個動作」 | CTA 是設計，不是請求 | 弱化（只剩「和影片內容相連的下一步」） |
  | 六種目標對應 CTA：收藏、留言、分享、訂閱、導購、重播 | 每種目標一句寫法與原理 | 遺失 |
  | 六種短影音格式：教學、反直覺、Before／After、Vlog、問答、清單 | 每種格式適用情境 | 遺失 |
  | 秒數是剪輯規格，實拍後依口白調整 | 不是平台規則 | 保留 |
