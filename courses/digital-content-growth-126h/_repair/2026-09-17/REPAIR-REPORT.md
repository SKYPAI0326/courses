# 學員資產可用性修復報告

日期：2026-09-17
課程：數位內容與成長行銷人才培訓（126 小時）

## 修復前的確定問題

- 126 份 `*-工作版.html` 與閱讀版正文相同。
- 原有工作版沒有文字輸入欄位；只有部分頁面保留 checkbox。
- 40 個主課頁把主要完成路徑交給 Word、記事本或其他外部工具。
- 參考案例、答案與示例沿用「工作版」命名，學員無法先判斷是否需要填寫。
- 原有靜態檢查沒有驗證輸入、保存、匯出或本機連結，因此可能在綠燈下交付不可用頁面。

## 本輪的生成機制修復

1. 新增 `_tools/asset-contracts.json`，集中定義工作表、參考資產與固定參考頁的分類規則及例外。
2. 工作表生成 `*-工作版.html`；參考資產生成 `*-參考版.html`，下載名稱同步反映用途。
3. 工作表保留提示與示範內容，只把空白欄位或明確回答欄轉為 textarea；完成檢查中的 checkbox 也可保存。
4. 工作版加入本機草稿保存、清除、完成版 HTML 匯出；匯出檔保留學員輸入並移除工作控制列。
5. 獨立下載版內嵌 CSS、favicon 與操作腳本；不再放置會把學員帶回錯誤遠端版本的自我下載連結。
6. CH1-1 的學員指引改為以可填寫工作版為主要路徑，Word／記事本降為瀏覽器保存失敗時的備援。
7. 新增資產契約、欄位唯一性與全課本機連結解析測試，避免只檢查外觀。

## 冷跟做證據

在本機 Windows 路徑等價的瀏覽器流程中，以 CH1-1 工作版完成：

1. 看見可輸入欄位與完成檢查 checkbox。
2. 填入測試答案後按「儲存草稿」，畫面顯示「草稿已儲存到這台電腦」。
3. 重新載入後，畫面顯示「已載入本機草稿」，輸入內容仍存在。
4. 按「下載完成版 HTML」後產生 `CH1-1-完成版.html`。
5. 匯出檔保留填入文字，移除 textarea、工作控制列與 runtime。
6. 實際按閱讀版的下載連結，產生 `CH1-1-可填寫工作版-獨立版.html`；檔案包含內嵌 CSS、欄位與 runtime，沒有相對 CSS 依賴。
7. 參考版顯示「資產用途：HTML 參考版」，沒有輸入欄位、保存按鈕或匯出按鈕。
