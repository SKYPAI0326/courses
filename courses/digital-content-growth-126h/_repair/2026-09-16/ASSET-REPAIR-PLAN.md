# 附件可用性修復計畫：digital-content-growth-126h

## 問題

- 40 份學員模板只以 `.md` 連結出現在講義中，點擊後會離開目前頁面。
- Markdown 原始格式不適合作為一般學員的第一閱讀入口。
- 目前附件連結沒有明確的單檔下載行為。
- UTF-8 檔案在部分 Windows 編輯器／舊版工具中可能出現亂碼。

## 修復範圍

1. 每份模板保留原始 `.md`，加入 UTF-8 BOM，並透過 `download` 屬性提供單檔下載。
2. 每份模板產生同名 `.html` 閱讀版，使用明確的 UTF-8 宣告與課程一致的閱讀樣式。
3. 講義中的模板連結改為「開啟閱讀版（新分頁）」＋「下載原始模板（UTF-8）」；原講義頁不被取代。
4. CSV 合成資料也加入單檔下載行為與 UTF-8 BOM，避免 Windows 開啟時欄位文字亂碼。
5. 將資產產生與連結改寫納入課程產生器，後續重建頁面不會退回 Markdown 直連。

## 不改動

- 不重寫 47 頁教學正文。
- 不把 Markdown 原始模板刪除或改成只能閱讀的檔案。
- 不新增外部平台、登入或上傳要求。

## 驗收

- 40 個 `.html` 閱讀版與 40 個 `.md` 下載來源一一對應。
- 47 個講義頁面中的資產連結皆指向存在的目標。
- 模板連結具有 `target="_blank"`、`rel="noopener"` 與 `download` 對應入口。
- 40 份 Markdown 與 3 份 CSV 均以 UTF-8 BOM 儲存。
- `docs/lint-page.py`、連結存在性檢查、HTML 結構檢查與公開頁面試開完成。
