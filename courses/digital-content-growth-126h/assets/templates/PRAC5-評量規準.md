# 國際廣告投放包評量規準 v1

| 面向 | 通過條件 | BLOCK 條件 |
|---|---|---|
| 市場與受眾 | 能回到能力、需求訊號、語言與測試成本 | 市場過大或只靠想像選擇 |
| 渠道分工 | Google、Meta、LINE 各有任務、受眾、素材與限制 | 所有渠道都寫增加曝光 |
| 投放企劃 | 文案／素材、落地頁、CTA、追蹤與否定／停止條件相連 | 只有平台欄位，沒有判斷 |
| 預算模擬 | 輸入假設、公式、結果與護欄分開 | 把預估當成實際績效 |
| 兩輪決策 | 固定條件、只改主要變因，能決定 Pause／Iterate／Scale | 同時改很多變因或無停止條件 |
| 權限與交接 | 不含付款資料，README、版本、來源與 BLOCK 齊全 | 依賴真實帳號或口頭說明 |
