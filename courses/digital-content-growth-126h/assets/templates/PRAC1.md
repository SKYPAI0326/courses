# PRAC1｜共同專案 Brief v1

## 使用方式

整合 CH1-1、CH1-2、CH1-3 的三張卡，保留一個主要對象、一個主要問題與一個主要行動。這份 Brief 是後續五科共用的起點；各科可以增加專業判斷，但要能回到本文件的共同核心。

## 2. 八個必要欄位

| Brief 欄位 | 填寫內容 | 來源或證據 |
|---|---|---|
| 應用情境 | 這組能力先拿去哪裡使用？ | CH1-1 |
| 主要對象 | 誰會閱讀、使用或做決定？ | CH1-1／CH1-2 |
| 問題與後果 | 對象在哪個情況卡住？造成什麼影響？ | CH1-2 |
| 需求與任務 | 對象現在需要理解、判斷或完成什麼？ | CH1-2 |
| 價值主張 | 我們替對象處理什麼，讓哪個判斷更容易？ | CH1-3 |
| 證據 | 哪些材料支持這個承諾？ | 檔案、案例、資料或待補 |
| 主要行動 | 對方看完後採取哪個下一步？ | CH1-3 |
| 限制與待驗證 | 不能做什麼？還不知道什麼？ | 環境、權限、成本與資料 |
