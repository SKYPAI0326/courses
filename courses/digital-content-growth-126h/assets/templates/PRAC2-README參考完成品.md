# 可行銷內容組 README 參考完成品 v1

以下是一份結構參考。學員要換成自己的檔名、版本、受眾與來源，不能只複製文字。

## 專案摘要

- 專案名稱：弄一下工作室內容整理服務
- 主要受眾：第一次接觸服務、需要整理內容的小型團隊負責人
- 核心問題：有零散材料，卻無法形成可持續發布的內容
- 核心訊息：先整理受眾、問題、證據與 CTA，再製作可交接的圖文與影片
- 主要 CTA：查看服務說明並確認需求條件

## 行銷判斷說明

- 圖卡主要處理：受眾理解。它把零散材料到內容主題的流程具體化。
- 短影音主要處理：受眾理解與信任建立。它展示工作步驟與可交付欄位，不把模擬案例寫成客戶成果。
- 兩種資產共用：受眾、服務範圍、核心訊息、證據限制與 CTA。
- 平台差異：圖卡可快速掃讀；短影音以開頭問題、流程與單一 CTA 安排節奏。

## 限制與恢復

- 尚未確認的素材、AI 示意與工具條件要列在待確認清單。
- 影片無法開啟時，先保留專案檔與素材索引，依 CH2-7 前測路徑修復。
- 來源不明的圖片不進入公開版本，改用自製或已確認來源素材。
- 任何未測量的成果不寫成成效承諾。

## 接手任務

另一位同學只看本資料夾，應能在 3 分鐘內找到主版、圖卡、CTA、來源紀錄與待修正項目。接手結果記錄在 `05-verification/同儕驗收-v1.md`。
