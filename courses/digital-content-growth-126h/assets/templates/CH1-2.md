# CH1-2｜問題—受眾—需求卡 v1

## 使用方式

沿用 CH1-1 的暫定情境，只處理一個主要對象與一個主要問題。這張卡用來區分「誰卡住」「卡在哪裡」「需要完成什麼」，避免把工具、願望或結果保證誤寫成需求。

至少填兩筆線索。線索可以來自既有檔案、公開資料、模擬訪談摘要、工作現場觀察或課程提供的案例；沒有真實資料時，請標記為 `synthetic` 或「待驗證」。

## 3. 需求與任務

| 欄位 | 填寫內容 |
|---|---|
| 需要理解的事 | 例如：知道服務如何處理自己的問題 |
| 需要判斷的事 | 例如：判斷方案是否符合目前範圍 |
| 需要完成的事 | 例如：查看案例並提交一項需求 |
| 目前最重要的需求 | 只選一項，並說明選擇理由 |
| 不在本次處理的事 | 清楚寫出排除範圍 |

## 完成檢查

- [ ] 主要對象不是「大家」或「所有人」。
- [ ] 至少有兩筆線索，並標記來源狀態。
- [ ] 問題描述了障礙與影響，沒有只寫情緒或願望。
- [ ] 主要需求和問題前後一致。
- [ ] 已把不能推論或尚未確認的部分列出。
- [ ] CH1-3 可以直接用這張卡寫價值主張，不必重新猜測對象。
