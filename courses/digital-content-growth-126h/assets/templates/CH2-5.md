# CH2-5｜視覺資產組 v1

## 使用方式

使用 CH2-3 的分鏡與 CH2-4 的來源紀錄，建立一組可被修改、輸出與接手的視覺資產。Affinity 是工具選項；先完成訊息、版面、來源與輸出條件，再操作軟體。

## 1. 交付資料夾

```text
視覺資產組-v1/
├── README.md
├── source/          # 可編輯來源檔；圖層與文字可理解
├── vector/          # 向量資產輸出
├── raster/          # 影像或社群圖卡輸出
├── preview/         # 預覽圖
└── 來源與限制.md
```

## 5. 輸出檢查

- [ ] source 檔案可以重新開啟，圖層與檔名可理解。
- [ ] 向量資產可在指定尺寸閱讀，沒有不必要的點陣化。
- [ ] 社群圖卡有正確格式、版本與預覽。
- [ ] 來源、授權、AI 標示與待確認事項跟著交付。
- [ ] 接手者不需要口頭補充就知道如何修改與輸出。
