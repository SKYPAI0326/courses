# 專題素材入口｜門市新人訓練簡報

全部是虛構教材資料，日期無年份。素材含委託、名單狀態、政策兩版、會議紀錄、完整示範、測試證據與答案鍵。先按講義要求讀指定檔案；做完任務後才開 `answer-key.md`。

| 檔案 | 用途 | 核對方式 |
|---|---|---|
| [request.md](request.md) | 委託與交付對象 | 確認讀者、用途、完成物及限制 |
| [project-status.csv](project-status.csv) | 截止日前的名單狀態 | 不把待回覆者算成已報名 |
| [policy-v1.md](policy-v1.md) | 舊版排程政策 | 保留版號，不和新版混用 |
| [policy-v2.md](policy-v2.md) | 已核准的新版本 | 只更新明示被取代的截止日和場地 |
| [meeting-notes.md](meeting-notes.md) | 討論、建議與待辦 | 區分核准和建議 |
| [worked-example.md](worked-example.md) | 文件型完整示範 | 做完 CH7-2 初稿後逐段比對 |
| [test-evidence.md](test-evidence.md) | 測試案例與人工觀察 | 分清教師示例結果和自己的實測 |
| [answer-key.md](answer-key.md) | 教師核對答案 | 完成獨立任務再看 |

作品可用一般文件完成；不要求網站或平台部署。必要時在紙上畫來源關係、手動核對；實際平台未跑就標 `NOT_RUN`。
