從完整回應取得可重開的 HTML

用於 CH4-1 首次操作，之後三課沿用。同一工具每改一次另存版本，原版保留。

1. 先給完整要求

在文字 AI 新對話貼下方要求。這是講師示範；學員隨後用工作／休息條件改造。

請給我一個可離線開啟的單檔 HTML 計時器，CSS、JavaScript 都在檔內，不使用外部套件。
初始顯示 03:00；有開始、暫停、重設三個按鈕。
開始後每秒倒數；重複開始不加速；暫停不扣秒；再開始從原剩餘時間繼續。
重設停止並回到 03:00；到零停止，不出現負數，不自動開始另一輪。
請提供從 <!doctype html> 到 </html> 的完整檔案，說明如何測以上行為。

2. 保存完整檔案

若回應有下載 HTML，下載到「AI課程練習／Part4」，命名 timer-v1.html。若只有程式碼，使用該程式碼區的複製功能，取得從 <!doctype html> 到 </html> 的全部內容；不複製前後解說或三個反引號。

Windows 可開記事本，貼上後另存新檔，檔名 timer-v1.html、檔案類型選所有檔案、編碼 UTF-8。Mac 可開文字編輯，先轉成純文字再貼上，另存 .html；若詢問副檔名，選保留 .html。不確定編輯器選項時，使用工具的 HTML 下載或下方參考檔作恢復點。

在檔案管理員檢查實際副檔名，應是 .html 而非 .html.txt、.rtf 或 .docx。看不到副檔名時打開檔案資訊查看完整名稱。

3. 開啟與留下第一筆證據

用瀏覽器開檔，看到 03:00 和三個按鈕。按開始，約三秒後應約 02:57；按暫停、等待三秒，時間不動；按重設回 03:00。把實際結果記下：

版本 操作 預期 實際 結果
timer-v1.html 開始約三秒→暫停三秒→重設 倒數→暫停不動→03:00 由自己操作後填 通過／待修／未跑

若看到整頁程式碼，檢查副檔名與純文字格式；空白或無按鈕則檢查是否漏了程式碼尾部。若按鈕壞掉，保留檔案，向 AI 提供「輸入／操作／預期／實際」並要求修正後完整 HTML，另存 timer-v2.html，重跑相同測試。

4. 下一版與交接

CH4-1 再加工作／休息設定。可用參考工具測相同規則，但註明是參考檔操作；參考檔已包含雙階段，不是剛才三分鐘示範的模型實際輸出。

CH4-2 先使用報價參考檔覈算，想生成自己的版本時，將報價規則和測試 CSV 交給 AI，要求完整 HTML，重做本頁步驟 2–3。CH4-3 先用參考檔載入 CSV，改造時把完整舊 HTML、資料字典和單一新要求一併交給 AI。輸出只有片段時要求整份檔案，避免初學者猜插入位置。

README 可複製這份最小成品，再換成自己的實際檔名：

工具：工作／休息計時器；檔案 timer-v2.html。
開啟：將 HTML 下載後用瀏覽器開啟，不需登入、不需 CSV。
操作：工作設 25、休息設 5，選工作後開始；暫停保留秒數，重設回設定值。
已測：請附自己的正常、邊界及保存重開結果。
未測：跨裝置背景計時；未公開部署。
恢復：改壞時回到 timer-v1.html；保留 v2 錯誤紀錄，不覆寫唯一成功版本。

JSON 工具卡不會備份這些 HTML 檔；交付資料夾要另含主檔、輸入資料與 README。
