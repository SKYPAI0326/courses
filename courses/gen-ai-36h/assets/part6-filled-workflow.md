# 一張完整七欄流程卡與通知草稿
基準使用 WF-01 的 10/02 會議及 10/03 場地回覆；10/22 改期是下一段的測試，不覆寫這張卡。先看示範，再依自己的保存位置填卡。

## 完整卡片
| 表單實際欄名 | 填寫範例 |
|---|---|
| 名稱 | 課程安排內部核對與通知草稿 |
| 何時用 | 收到會議紀錄或場地回覆時；任何日期或場地變更後重查 |
| 輸入 | part6-workflow-case.md：10/02 會議、10/03 09:20 場地回覆；不含 12 位學員個資 |
| 輸出 | WF-通知-v1.txt 與來源對照；內部草稿，待主管核准外發 |
| 怎麼檢查／驗證證據 | 先查會議沿用 10/21，再查場地確認 A201 14:00–16:00；逐一核日期、地點、教材待確認及外發狀態；未知不補決策 |
| 失敗時重做哪一步 | 來源缺失回原檔；日期或場地衝突先停發並列追問；草稿錯回來源對照改受影響句，另存 v2 再核對，不覆寫 v1 |
| 成果位置／狀態 | AI課程練習/Part6/WF-通知-v1.txt；來源表同資料夾；已人工核對來源，待主管核准，未寄出 |

## 下游通知 v1 範例
```text
內部審核草稿｜課程安排
內部規劃日期：10/21，14:00–16:00；場地 A201 已由 10/03 回覆確認。
10/22 是會議提案，目前沒有可用場地，不寫成已確定改期。
教材要求為開課前兩日完成；實際交付日與負責人待確認。
請主管確認是否核准這份安排及對外通知；確認前不寄出。
本稿不含學員個人名單。
```

## 三種工作各選什麼方式
- 比較來源中的 10/21／10/22：來源筆記或手動對照表；必須能回到原句。
- 把已核對事實寫成通知：文字 AI 或一般文件；完成後逐句校對。
- 核准改期／決定是否外發：交主管；工具可列問題，不能代替主管核准。
只查一個日期時，直接開原文往往已足夠，不需要再建自動化。把你選的方式與理由記在「怎麼檢查」內。

JSON 只含卡片文字。另存 WF-通知-v1.txt、後續 v2 和來源表，才有真正可恢復成果。
