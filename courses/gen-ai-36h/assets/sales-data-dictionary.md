# 交易資料字典與清理規則

來源：虛構門市 2026-04 交易匯出，13 列（含重複列）；金額為新台幣元。

| 欄位 | 意義 | 規則 |
|---|---|---|
| transaction_id | 來源交易識別碼 | 重複 ID 只保留第一筆；把重複列另記在清理紀錄，不加總 |
| date | 交易日 YYYY-MM-DD | 空白日期不得猜補；先放入待查，不列入按日期趨勢 |
| region | 區域 | 依原值分組，不自行合併 |
| amount | 淨額 | 退款為負數，納入淨營收；不可改成正數 |
| status | SALE／REFUND／CANCELLED | 取消不計營收；退款納入負值；SALE 納入 |

本練習的彙總口徑：排除第二筆重複 TX-003；排除 CANCELLED TX-009；將無日期的 TX-006 留在待查表，暫不計入；保留退款 TX-007 的 -200。不要把「排除」和「退款」混為一種處理。
