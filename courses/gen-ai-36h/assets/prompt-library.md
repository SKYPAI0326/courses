# 20項文字任務查詢庫｜同一案例的輸出參考

這20項不是20種工作案例，而是同一個「新生工作坊」虛構素材的不同輸出形式。每次只選一項，先按讀者與用途挑選；不要把多項全部跑一遍當成實作深度。若要練多來源、版本變更與待決策，請改用[門市退貨表單試辦工作包](workplace-cases/part2/START-HERE.md)。換成自己的工作前先補足資料並移除教材日期。

## 01 三點摘要

```text
任務：整理成三點，保留日期、時間與未知事項。
資料：11月3日14:00辦新生工作坊，預計90分鐘。小安準備投影片，交付期限未提供。場地及插座供應尚未確認。學員需帶筆電。
限制：只使用以上資料；未知資訊保留待確認。
請附上需要人工核對的日期、數字與承諾。
```
