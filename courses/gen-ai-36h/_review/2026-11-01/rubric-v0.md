# gen-ai-36h 講義審查評分尺

課程定位：「生成式 AI 工作應用班（36h）」，對象是零基礎上班族，核心是讓學員從 0 開始把生成式 AI 用進日常工作。
評審三個問題：(一) 不說人話：像待辦清單，突然開始、突然結束、段落沒有銜接；(二) 偏離主題：多數時間在做人工閱讀、人工審核、人工作業，而非學用生成式 AI；(三) 編號複雜：長編號充斥、以編號取代說明。

## 計分說明
- 每個細項 0～3 分：0＝完全沒做到／嚴重，1＝偶爾做到，2＝大致做到、個別段落缺，3＝全頁做到。每個分數必附原文引句（逐字，不改寫）。
- 計數型細項同時填數字：2-1 填「AI 產出 a 步／AI 協助判斷 b 步／純人工 c 步」與比例；3-1 填識別碼總數與種類；3-2、3-3 填出現處數。再依下表換算 0～3 分：
  - 2-1：(a+b)/(a+b+c) ≥ 70% 且每段純人工 ≤1 步 → 3；≥ 70% 但有段落純人工 ≥2 → 2；50–69% → 1；< 50% → 0。
  - 3-1：每千字 ≤2 且種類 ≤3 → 3；每千字 ≤5 → 2；≤10 → 1；> 10 → 0。
  - 3-2、3-3：0 處 → 3；1 處 → 2；2–3 處 → 1；≥4 處 → 0。
- 「學員動作」指正文要學員親自去做的一件事（讀、算、比對、貼給 AI、記錄、測試…）。同一動作在一段內重述不重複計。
- 2-5 為選評：有自動化流程的頁面才填，不影響通過；其他頁填 N/A。
- 頁面判定：三套標準各自「通過／不通過」，依各標準的通過門檻。

## 3. 審查標準

每頁三個問題各自評分。每個細項 0～3 分：0＝完全沒有／嚴重，1＝偶爾做到，2＝大致做到、有個別段落缺，3＝全頁做到。每個分數都要附原文引句。

### 標準一：說人話（敘事與銜接）

| 細項 | 檢查內容 | 3 分的樣子 |
|---|---|---|
| 1-1 開場情境 | 頁首是否說明誰、遇到什麼事、這節做完能得到什麼 | 工作情境＋風險＋本節目的 |
| 1-2 段落銜接 | 每段第一句是否接住上一段的結果，而非直接下指令 | 「剛才整理好的三點摘要，現在拿去…」 |
| 1-3 指令附理由 | 要學員做的動作，是否說明為什麼這樣做 | 每個關鍵步驟都有一句「因為…／這樣…」 |
| 1-4 收尾回扣 | 頁末是否收回本節成果，並說明下一節會用到什麼 | 有「你現在有了 X，下一節會拿它做 Y」 |
| 1-5 一句話複述 | 冷讀者讀完能否用一句話說出這頁在教什麼 | 冷讀者的複述與頁面目標一致 |
| 1-6 句子負荷 | 單句是否塞超過兩個動作或兩個對象 | 一句一事，長清單改成段落敘述或表格 |

通過門檻：沒有任何 0 分，平均 ≥ 2。

### 標準二：扣緊生成式 AI 主題

先把頁面中每個學員動作分成三類，再評分：

- **AI 產出**：學員給資料與要求，讓 AI 寫、整理、分類、做工具。
- **AI 協助判斷**：核對工作交給 AI 做（要 AI 標出處、換模型交叉檢查、用 NotebookLM 引用），學員只做最後決定。
- **純人工**：學員自己逐筆讀、算、比對、測工程案例，AI 不在場或只是附帶。

| 細項 | 檢查內容 | 通過條件 |
|---|---|---|
| 2-1 動作配比 | 三類動作的步數比例 | AI 產出＋AI 協助判斷 ≥ 70%；純人工每段最多 1 步 |
| 2-2 完成物 | 本節完成物是不是一個用 AI 做出來的成果 | 完成物寫的是「用 AI 做好的 X」，不是「核對紀錄、人工決定、證據」 |
| 2-3 核對方式 | 驗證是否教學員用 AI 幫忙驗證，且份量相稱 | 核對有教 AI 做法；不出現逐欄、逐句的純人工比對作業 |
| 2-4 限制語密度 | 「不能／不要／仍須人工／不代表」等警語 | 每段最多 1 句，集中放在必要處 |
| 2-5 自動化含 AI（選評） | 自動化單元的流程中有沒有生成式 AI 步驟 | 只記錄、不計入通過門檻（已裁決，見第 7 節） |
| 2-6 標題主軸 | Part 名、單元標題、副標講的是 AI 能力還是人工防錯 | 標題說的是「用 AI 完成什麼」 |

通過門檻：2-1、2-2 必須通過；2-3、2-4、2-6 不得有 0 分；2-5 為選評，不影響通過。

### 標準三：編號不取代說明

| 細項 | 檢查內容 | 通過條件 |
|---|---|---|
| 3-1 識別碼密度 | 每千字識別碼數、全頁識別碼種類 | 每千字 ≤ 2 個；學員需要記住的代碼 ≤ 3 種 |
| 3-2 工程碼外露 | T01–T07、NOT_RUN、PENDING、S3、A102 等製作或測試用代碼 | 學員正文 0 個 |
| 3-3 編號當主詞 | 句子是否用代碼當主角，沒有說明它是什麼 | 0 處；案例一律用內容稱呼，如「那封問營業時間的信」 |
| 3-4 跨頁引用 | 引用其他單元時用章節碼還是用內容 | 用「上一節的分類提示詞」，不用「沿用 CH5-3 提示詞」 |
| 3-5 英文欄位名 | source_key、review_status 等是否有中文說明 | 正文用中文名；英文欄名只出現在必須照填的表格內 |
| 3-6 檔名代稱 | 是否用 attachment-case.md 這類檔名代替說明 | 連結文字寫用途（「附件案例」），不寫檔名 |

通過門檻：3-2、3-3 必須為 0 處；其餘不得有 0 分。
