# gen-ai-36h 講義審查評分尺 v1.1

版本：v1.1（2026-11-01，補齊逐頁評分時回報的 7 項邊界規則，見 `spot-check.md`）。v1 見 `rubric-v1.md`，v0 見 `rubric-v0.md`。現況基準（`scores.csv`）用 v1 評；改寫驗收用 v1.1，比較前後時要用 v1.1 重評基準頁。

課程定位：「生成式 AI 工作應用班（36h）」，對象是零基礎上班族，核心是讓學員從 0 開始把生成式 AI 用進日常工作。
評審三個問題：(一) 不說人話：像待辦清單，突然開始、突然結束、段落沒有銜接；(二) 偏離主題：多數時間在做人工閱讀、人工審核、人工作業，而非學用生成式 AI；(三) 編號複雜：長編號充斥、以編號取代說明。

## 通用規則

- 每個細項 0～3 分：0＝完全沒做到／嚴重，1＝偶爾做到，2＝大致做到、個別段落缺，3＝全頁做到。每個分數必附原文引句（逐字）。
- 「段」＝頁面上以 `##` 開頭的小節；「自然段」才指單一段落。
- 頁面判定：三套標準各自「通過／不通過」，依各標準的通過門檻。門檻沒有另外寫明時，細項「通過」指 ≥ 2 分。
- 不適用的細項填 N/A，不計入平均。

## 標準一：說人話（敘事與銜接）

| 細項 | 檢查內容 | 3 分的樣子 |
|---|---|---|
| 1-1 開場情境 | 第一段是否說明誰、遇到什麼事、這節做完能得到什麼 | 工作情境＋風險＋本節目的 |
| 1-2 段落銜接 | 每段第一句是否接住上一段的結果，而非直接下指令 | 「剛才整理好的三點摘要，現在拿去…」 |
| 1-3 指令附理由 | 要學員做的動作，是否說明為什麼這樣做 | 每個關鍵步驟都有一句「因為…／這樣…」 |
| 1-4 收尾回扣 | 最後一段（或最後兩個自然段）是否收回本節成果，並說明接下來會用到什麼 | CH 頁：「你現在有了 X，下一節會拿它做 Y」。PRAC 頁：收回本 Part 學會的能力，並說明下一個 Part 會延伸到哪裡。全課最後一頁（PRAC7）：收回全課學會的能力與之後怎麼用 |
| 1-5 一句話複述 | 讀完能否用一句話說出這頁在教什麼；對照對象是頁面標題＋本節完成物 | 複述與標題、完成物一致 |
| 1-6 句子負荷 | 單句是否塞超過兩個動作或兩個對象 | 一句一事。資料規格（如報價參數）只在同一句還附帶動作、且列了 4 個以上值時才算超載 |

通過門檻：沒有任何 0 分，平均 ≥ 2。

## 標準二：扣緊生成式 AI 主題

### 動作分類（2-1 用）

「學員動作」＝正文主線要學員親自做的一件事。選做步驟、條件式排錯（「如果沒送出…」）不列入。同一動作在同一段內重述只計一次；在不同段再做一次，另計。

v1.1 補充：
- 以條件句寫成、但其實是本頁預設工具的步驟（「用 NotebookLM 時…」），列入主線。
- 交給 AI 前的短讀（讀一段 ≤ 5 行的輸入資料）歸工具操作，不計；讀多份資料、自己整理或分辨內容，歸純人工。
- 學員對 AI 產出做簡短判斷（看 ≤ 3 處、或比較兩版 AI 輸出差在哪），歸 AI 協助判斷；逐句、逐欄、逐筆比對，歸純人工。
- 學員不用 AI、自己寫卡片、提案、README、表單內容或交接說明，歸純人工。
- 測 AI 做出的工具：點按確認功能能用（單一功能、不逐案記錄）歸工具操作；準備 ≥ 3 組輸入並記錄預期與實際，歸純人工（測試矩陣）。

| 類別 | 定義 | 例 |
|---|---|---|
| AI 產出 | 學員給資料與要求，讓 AI 寫、整理、分類、改寫、做工具 | 貼提示詞請 AI 整理摘要；請 AI 依新需求改工具 |
| AI 協助判斷 | 檢查工作由 AI 做（標出處、列依據、比對差異、換模型交叉檢查、NotebookLM 引用），學員只抽看 AI 指出的 ≤ 3 處並做決定 | AI 列出每點依據的行號，學員核對其中三處 |
| 純人工 | 學員不靠 AI 自己讀原始資料、手算、逐句／逐欄／逐筆比對、設計並執行多案例測試矩陣 | 先手算報價再比對；逐欄核對九欄；跑 7 組測試案例並逐一查表 |
| 工具操作（不計） | 帳號準備、開關檔、存檔、命名、重開確認、看操作指南、建置與執行 Make 流程、點按 AI 做出的工具確認能用 | 「複製到文件、命名、放進資料夾」；在 Make 加模組並執行一次 |

依 2026-11-01 使用者裁決（Make 流程沒有生成式 AI 步驟不算偏題），建置與執行 Make 列為工具操作、不計入比例；但多案例測試矩陣（如一次準備 7 組測試列逐一驗收）屬純人工。

比例＝(AI 產出＋AI 協助判斷) ÷ (AI 產出＋AI 協助判斷＋純人工)。分母為 0（整頁都是工具操作）時，2-1 填 N/A。

### 細項

| 細項 | 檢查內容 | 計分 |
|---|---|---|
| 2-1 動作配比 | 依上表分類並計算比例 | ≥ 70% 且每段純人工 ≤ 1 步 → 3；≥ 70% 但有段落純人工 ≥ 2 步 → 2；50–69% → 1；< 50% → 0 |
| 2-2 完成物 | 「本節完成物」是不是用 AI 做出來的成果 | 全部是 AI 做出的成果（摘要、信、工具…）→ 3；主項是 AI 成果，另附核對紀錄 → 2；有提到 AI 成果但主項是核對、證據、測試紀錄 → 1；完全沒有 AI 成果 → 0。主要完成物是 Make 流程的頁面：看流程是否接上前面用 AI 做出的成果（接上 → 2 以上），不因流程本身沒有 AI 扣分 |
| 2-3 核對方式 | 驗證是否教學員用 AI 幫忙驗證，且份量相稱 | 核對都有 AI 協助做法、沒有純人工逐筆比對作業 → 3；有 AI 協助做法但仍有 1 處純人工逐筆比對 → 2；以純人工核對為主 → 1；只有純人工核對且佔大半篇幅 → 0。頁面沒有核對 → N/A |
| 2-4 限制語密度 | 對學員的警語、禁止、條件限制（不能／不要／不可／不代表／仍須人工／才能…） | 只算正文（含表格），不算提示詞框與標題；一句含多個限制語算 1 句；陳述事實的否定句（「原文沒有確認發布日」）、放寬語（不需要、不必）、表目的的「才能」（「這樣才能找回」）不算。每段 ≤ 1 句 → 3；有 1 段超過 → 2；2～3 段超過 → 1；4 段以上或全頁 ≥ 10 句 → 0 |
| 2-5 自動化含 AI（選評） | 自動化流程中有沒有生成式 AI 步驟 | 只記錄有／無，不給分、不影響通過。非自動化頁填 N/A |
| 2-6 標題主軸 | 頁面標題、副標、段落小標講的是 AI 能力還是人工防錯 | 標題與多數小標講「用 AI 完成什麼」→ 3；標題講 AI、小標多為防錯 → 2；標題中性或混合 → 1；標題以人工防錯為主軸 → 0 |

通過門檻：2-1 必須 3 分（即 ≥ 70% 且每段純人工 ≤ 1 步，沿用已核定的執行表條件；N/A 時只看 2-2）；2-2 必須 ≥ 2；2-3、2-4、2-6 不得 0 分；2-5 不影響通過。

## 標準三：編號不取代說明

### 名詞定義

- **識別碼**：案例碼（Q01、N01、U07、MSG-01）、測試碼（T01）、階段碼（S1、S3）、狀態碼（NOT_RUN、PENDING）、正文裡的章節碼（「沿用 CH5-3 提示詞」）、英文表名與欄位名（ReviewedQueue、source_key）、檔名。不算：頁首麥包屑的章節標示、資料裡的數字（12 件）、「步驟 4」「第 2 行」。
- **工程碼**：給製作者或測試記帳用、學員不需要理解就能完成學習的代碼：測試碼、階段碼、狀態碼、內部批次碼、版本標籤（v3-test）。學員練習用的案例碼（Q01、N01、U07、MSG-01）不算工程碼，改由 3-1、3-3 評。判斷方式：學員要靠這個代碼找到或辨認一份練習材料 → 案例碼；只用來記帳、標版本或區分測試批次 → 工程碼。
- **處**：每出現一次算一處；範圍寫法（T01–T07）算一處。
- 同一個代碼可能同時影響 3-1、3-2、3-3，這是刻意的：三項分別看密度、類型、用法。例外：檔名只在 3-6 計，不再計入 3-3。

| 細項 | 檢查內容 | 計分 |
|---|---|---|
| 3-1 識別碼密度 | 每千字識別碼數**直接採用 `baseline.csv` 的 `codes_per_k`**（機器計數，分母為頁面正文全部非空白字元）；另由評分者數「學員需要記住意思的代碼」種類 | 每千字 ≤ 2 且種類 ≤ 3 → 3；每千字 ≤ 5 → 2；≤ 10 → 1；> 10 → 0 |
| 3-2 工程碼外露 | 正文中的工程碼 | 0 處 → 3；1 處 → 2；2～3 處 → 1；≥ 4 處 → 0 |
| 3-3 編號當主詞 | 代碼當句子主詞或受詞，同一句沒有說明它是什麼內容 | 同一句已附內容說明（「問營業時間的 U07」）或同句謂語說明內容（「POL-02 把截止改成 11/09」）不算；只接類型名詞（「PRAC4 工具」「WF-02 新更新」）仍算未說明。前文解釋過、後文單獨出現時，每段第一次出現要再說明。0 處 → 3；1 處 → 2；2～3 處 → 1；≥ 4 處 → 0 |
| 3-4 跨頁引用 | 引用其他單元時用章節碼還是用內容 | 全用內容或「上一節」→ 3；1 處用章節碼 → 2；2～3 處 → 1；≥ 4 處 → 0。沒有跨頁引用 → 3 |
| 3-5 英文欄位名 | source_key、review_status 等是否有中文說明 | 正文都用中文名，英文欄名只在必須照填的表格內 → 3；1～2 個沒說明 → 2；3～5 個 → 1；> 5 個 → 0。沒有英文欄名 → 3 |
| 3-6 檔名代稱 | 是否用 attachment-case.md 這類檔名代替說明 | 指示學員存檔命名（「保存為 quote-v1.html」）不算。0 處 → 3；1 處 → 2；2～3 處 → 1；≥ 4 處 → 0 |

通過門檻：3-2、3-3 必須 3 分（0 處，沿用已核定的執行表條件）；其餘不得 0 分。
