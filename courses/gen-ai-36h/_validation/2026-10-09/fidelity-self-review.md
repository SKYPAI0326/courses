# 教案至 HTML 保真自審

日期：2026-10-09。審查者：教材修訂者（author-self-check）。範圍：全部 28 份正式 `_lessons` 來源及對應 Part 1–7 HTML；保留原課程頁殼、導覽與密碼關卡。

方法：以 `_tools/verify-course.py` 對每份來源正文的段落、清單、表格與程式區塊逐項比對學員可見 HTML 正文；逐頁驗本地連結；將原頁與新頁的關卡腳本與前後導覽比對；核對 28 張課程卡標題。轉製器只替換既有 `.lesson-body` 與指定標題欄位，保留 HTML 包裝層。對 Part 1、Part 5、Part 7 的實際 HTML 結構另行查看示範／練習與素材連結位置。

結果：28 頁來源內容可在 HTML 正文找到，原關卡腳本與導覽路徑一致，站內連結有實檔，來源與頁面對應。機器比對與作者抽查不能證明 CSS 呈現、鍵盤操作或小螢幕可讀；這些保留瀏覽器待驗。
