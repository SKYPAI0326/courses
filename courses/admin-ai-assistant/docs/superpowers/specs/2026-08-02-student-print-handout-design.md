# 行政 AI 虛擬助理實戰：學員版印刷講義設計規格

## 目標

將 `admin-ai-assistant` 現有課程內容製作成易讀、可雙面列印、可搜尋複製，且適合匯入 NotebookLM 的學員版 PDF。

## 產物

- 6 份章節分冊 PDF：CH1 至 CH6。
- 1 份全課合併版 PDF。
- 1 份 NotebookLM 索引：列出 PDF、章節、來源 HTML 與建議提問方式。
- 1 份 JSON manifest：保存產物、章節與來源對照。
- 可重跑建置腳本；不修改既有課程 HTML。

## 收錄範圍

- 章節正文：`CH1.html` 至 `CH6.html`。
- 課程資產庫：`prompt-library.html` 與其可列印文字資產，納入全課合併版附錄。
- 保留學習目標、案例、提示詞、步驟、預期輸出、練習與檢核題。
- 練習題保留作答空間；答案從章節正文抽離，集中放在各分冊末尾與合併版答案附錄。
- 移除密碼關卡、網站導覽、複製按鈕、下載按鈕、頁尾及純網頁互動控制。
- 所有 `details` 的非答案內容展開；答案內容移至答案附錄。

## 輸出結構

### 章節分冊

1. 章節封面
2. 本章學習內容與來源
3. 章節正文
4. 練習與作答空間
5. 本章答案

### 全課合併版

1. 全課封面
2. 課程目錄
3. CH1 至 CH6
4. 課程資產庫附錄
5. 集中答案附錄

## 印刷規格

- A4 直式。
- 上 16 mm、下 18 mm、內側 18 mm、外側 16 mm，適合雙面列印與裝訂。
- 正文約 10.2 pt，行高至少 1.65；標題避免孤行，正文設定 widows/orphans。
- 每章另起新頁；短卡片與表格列避免跨頁，長 Prompt 與長表格允許自然分頁。
- 保留低飽和品牌色；深底區塊轉為淺底深字，灰階列印仍可辨識。
- 頁尾顯示課程名、章節與連續頁碼。
- 移除只有頁尾的空白頁與不必要的目錄溢頁。

## NotebookLM 可用性

- PDF 必須保留文字層，不輸出為掃描圖片。
- 分冊檔名使用 `ADMIN-AI-CH01` 至 `ADMIN-AI-CH06`，確保排序穩定。
- 每章與附錄保留清楚標題、來源 HTML 檔名與 PDF 書籤。
- PDF metadata 包含課程名、章節、學員版與 NotebookLM 關鍵字。
- README 索引說明分冊與合併版內容重複，避免 NotebookLM 重複引用。

## 建置方式

- 從既有 HTML 抽取教學正文與資產庫內容。
- 注入專用 print CSS，使用 Chromium 產生帶文字層 PDF。
- 使用 pypdf 移除空白頁、重建 metadata／書籤，並合併全課版。
- 產物寫入 `output/pdf/admin-ai-assistant/`，暫存檔放在 `admin-ai-assistant/tmp/pdfs/`。

## 驗收標準

- 6 份分冊、1 份全課版、README 與 manifest 全部存在。
- CH1 至 CH6 與資產庫來源均可從 PDF 文字層搜尋。
- 分冊頁數總和加上全課專屬附錄頁，等於全課合併版頁數。
- 每頁為 A4，metadata 與章節書籤存在。
- 全部分冊逐頁轉成 PNG；零空白頁、零裁切、零重疊、零黑方塊、無不可讀文字。
- 人工抽查全部縮圖，以及封面、目錄、Prompt、表格、練習與答案頁的原尺寸畫面。
