# Folder Classification Policy

- `course-html`: contains learner-facing HTML and course/page signals.
- `source-only`: contains course sources but no learner-facing HTML.
- `no-handout-project`: independent project without web handouts.
- `support`: backup, repair, tools, validation, assets, output, or shared documents.
- `management`: Course Manager itself and its generated artifacts.
- `unknown`: evidence is insufficient; require inspection.

Classification is evidence-based and must preserve a human-readable reason.
