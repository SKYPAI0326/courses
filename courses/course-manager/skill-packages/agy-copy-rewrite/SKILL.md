# agy 文案改寫

這是直接改寫文字的獨立入口。使用者指定檔案及改寫範圍後，agy 自行閱讀原檔，負責文案分析與可讀性改寫；Codex 負責備份、指派、資訊正確性與檔案邊界核對、溝通。不啟動課程迭代控制器、評分、作者比較或第二位模型覆核。明確使用「文案迭代」或「文案迭代改」時，依專案 AGENTS.md 的既有入口處理。

## 執行

1. 確認來源檔與使用者指定的段落、章節或文字範圍。若只有檔案，範圍就是該檔的可見文案。Codex 只定位檔案與授權範圍，不預先抽取、切段或改寫文字；範圍無法唯一定位時，指出歧義並請使用者選定。
2. 在不會發布的持久工作目錄建立本次資料夾，另建 `workspace/` 子目錄，裡面只放逐位元複製的原檔 `original<原副檔名>` 和候選 `candidate-v1<原副檔名>`。將原檔絕對路徑與 SHA-256 記在 `workspace/` 外。原檔此時不變。若要定點修訂，從前版候選另複製新版本，建立新的 `workspace-vN/`，其中只放本次必要的參照檔與候選檔；不覆寫舊候選或 agy 回答。設定檔、模型回答、標準錯誤和紀錄都放在工作目錄之外。
3. 以只含本次參照檔與候選檔的 `workspace/` 為工作目錄，讓 agy CLI 在單次 `--sandbox --disable-slash-commands --output-format json --print` 回合自行讀取原稿副本，只編輯候選副本。使用工作目錄外的一次性 JSON 設定檔搭配 `--settings`，以複數鍵名 `permissions` 僅授權 `read_file(original 的絕對路徑)` 與 `write_file(candidate-v1 的絕對路徑)`；設定檔不放進 workspace，不修改全域設定，也不用 `--dangerously-skip-permissions`。Codex 傳入實際檔名、使用者指定的範圍與下列要求，不把檔案內容轉成純文字或拼進提示詞；原始回答及標準錯誤另存於 workspace 之外。沿用使用者指定的 agy 模型；未指定時用 `gemini-3.8-flash-low` 與 `--effort low`，不可用就回報，不自動換模型。不另呼叫模型做評分。

   > 請直接閱讀 `original` 的原始檔案，先判斷指定範圍有哪些文法、用詞、指涉、句子承接或前因後果問題，再把必要修訂寫入 `candidate-v1`，最後簡短說明實際修改。使用臺灣繁體中文，只整理原文已提供的關係；保留事實、數字、案例、專有名稱、介面設定名稱、操作步驟、條件中的「或／且」關係與結論，不新增情境、理由、條件或建議。清楚的句子不必改。若資訊不足，維持原意並指出缺口，不要猜。HTML 須依原有標籤、換行、強調、章節編號與上下文閱讀；只改指定範圍內的可見文字，不重新序列化 HTML，不動標籤、屬性、圖片、連結、CSS、JS 或互動。只讀寫這兩個指定檔案，不使用終端命令、子代理或其他工作區檔案。

4. Codex 先查 JSON 的 `denied_actions` 與標準錯誤；即使 `status` 是 `SUCCESS`，有拒寫就視為未完成。再核對候選與原稿的差異：修改須在授權範圍內，HTML 標籤與屬性、CSS、JS 等非文案內容須與原稿一致；數字、專名、介面設定名稱、事實、邏輯條件及操作不得無依據改變。Codex 對可精確定位的越界或資訊變動，從原稿還原該片段至新版候選，不為可讀性重寫句子；無法精確還原就停止。若 agy 明確判斷無須修改，候選可與原稿相同。只有還原後留下可定位的文案問題時，Codex 才指出具體差異，讓 agy 在新候選上定點修正一次，不重啟整套流程；再次不符就保留紀錄並回報。
5. 交付候選檔與簡短差異說明，請使用者閱讀並決定是否取代原檔。未獲明確接受時，停在隔離候選。接受後，先確認原檔 SHA-256 仍與起始版本相同，再另存一份替換前備份；用已接受的候選替換原檔並核對內容一致。若原檔已變更，停止覆寫並請使用者重新確認差異。
6. 使用者要求還原時，先核對目前原檔仍是本次套用的版本，再以替換前備份還原；若已有後續修改，保留現況並列出差異，避免覆蓋新工作。

## 本機啟動權限

這臺電腦的 Codex 受限命令環境已實測阻擋 agy 寫入 `~/.gemini` 與綁定 localhost；一般權限下先試一次只會重現啟動失敗。使用 `exec_command` 呼叫 agy 時，首輪即對**該次命令**設定 `sandbox_permissions: "require_escalated"`，不設定永久 `prefix_rule`，也不修改 Codex 或 agy 的全域權限。保留 agy 的 `--sandbox`，讓它之後的終端工具仍受限制。若單次權限遭自動審核拒絕，保留紀錄並停止，不在受限環境重送模型呼叫。

## 交付界線

回報候選、原檔是否已替換、備份位置及還原方式。原則上一次 agy 回合完成；只有具體文案錯誤可定點回修一次。Codex 核對資訊並還原可精確定位的非文案或資訊變動，不代寫可讀性文案，也不為了報告格式反覆重送。若 agy 無法執行或未產生可用候選，保留備份與原始紀錄，停止並回報原因，不改用其他模型或自行補寫。
