# Lesson Type Contract

正式 `course_type` 只有四種：`concept`、`skill-operation`、`programming`、`integration-capstone`。舊的 Concept／Skill-operation／Integration / Capstone 顯示名稱讀入時分別正規化為上述值。課型控制證據，不控制卡片、段落或題數。複合單元選主要成果對應的課型，補充實際需要的證據。

## concept

學員學會解釋、分類、推導、比較或判斷。正文提供白話意義、適用條件、必要推理與完整例子；對易混淆處提供非例或錯誤分析。練習須有理由與可核對的答案或評判依據。分類、口語說明、推導與作品表現均可驗收；不要求工具步驟或職場決策。

## skill-operation

學員完成具體技能或操作。提供環境與起始材料、完成結果、最短成功路徑，以及關鍵動作的輸入、理由與可觀察結果。於重要決策及狀態變化安排檢查與適用的修復。示範覆蓋不能自行推得的方法，練習依內容實質契約安排支援遞減與條件變化。技能可以是工具、手作或表現，不限定檔案格式。

## programming

學員將需求轉成可執行程式。除 skill-operation 適用證據外，提供執行環境、完整可執行的核心程式、輸入與預期輸出、設計理由、必要邊界測試及排錯起點。提供可複製程式仍要解釋資料和控制流程；一個程式區塊不等於已教會。依授權實際執行，未跑不得聲稱成功。

## integration-capstone

學員選擇並整合前課能力，完成合理任務或作品。提供任務背景、受眾或用途、真實限制、必要的上游能力及材料、中間成果、取捨理由、完整參考成果、驗收判準與修訂路徑。截止日、客戶、交接格式只有在任務需要時提供；學術推導或創作不虛構公司。無外部帳號／真實資料時提供能驗收核心能力的備援並說明限制。

## 共通判斷

解釋、示範、練習、重複的充分性依 `$BASE/_規範/course-content-substance.md`；方法與版本證據依 quality-gate.md。所有課型都可用自然段落、表格、對話或程式呈現。標題不能代替內容，也不要求每個證據各占一張卡片。
