# course-manager 專案入口

## 接續課程 skill 改善

使用者說「接續課程 skill 改善」時，先讀取本目錄下的 [課程設計 skill 修正紀錄](operations/skill-improvement-2026-10-26/課程設計skill修正紀錄.md)，再依當次指定的問題與範圍接續工作。先辨認已套用修正、人工回饋及尚未驗證的結論，並讀取本次涉及的現行 skill；不可只憑歷史紀錄覆寫現行檔案。

若只有啟動詞，先簡述目前狀態與待續項目，詢問本次要處理的問題，不自行啟動所有待辦。完成實質修正後，將原因、變更位置、實際結果與限制追加至同一份修正紀錄。沿用既有規範，不另建檢查表，也不把參考課程固化為通用章節模板。
