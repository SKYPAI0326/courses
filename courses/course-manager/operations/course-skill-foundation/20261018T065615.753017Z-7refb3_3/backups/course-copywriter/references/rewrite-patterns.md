# 課程文案連貫化範例

## 從片段到教學段落

### 片段寫法

```text
### 資料映射
- 把欄位放入下一個模組。
- 檢查名稱。
```

### 連貫寫法

```text
上一個模組已經產生三個欄位，下一步要把它們交給 AI；如果欄位名稱對不上，後面的摘要就會是空白。因此先確認每個輸入欄位要放進哪個位置。

學員操作：把 `feedback` 放入提示詞的回饋欄位，並保留 `customer_name` 作為後續文件標題。
快速檢查：送出前能指出每個欄位的來源與目標位置。
```

## 從示範到跟做

不要只寫「請依照上方示範操作」。要說明哪些判斷已經示範、哪些部分由學員重新完成：

```text
示範中我們已確認 `needs_review = true` 時資料不會直接寄出。現在沿用相同的判斷，重新製作你的地圖；這次只改變資料來源，Filter 與寄信條件保持不變。
```

## 從跟做到遷移

替換案例時，明確分出不變與改變：

```text
把 Sheets 換成 Gmail 不代表整條流程重做。Gemini 的處理、人工確認條件與文件輸出仍然相同；真正需要重映射的是 `feedback` 改成郵件 `body`，以及通知對象改由寄件人欄位取得。
```

## 段落自問

每次改寫後問三句：

1. 這段承接了前一段哪個可觀察結果？
2. 學員讀完後，知道下一步的目的嗎？
3. 如果刪掉這段，操作或判斷會變得不可能嗎？
