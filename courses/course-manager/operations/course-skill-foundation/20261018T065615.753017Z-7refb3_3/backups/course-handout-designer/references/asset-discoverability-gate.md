# Asset Discoverability Gate

## 核心原則

資產「存在」不等於學員「找得到、拿得到、知道何時使用」。只要講義提到範例檔、附件、測試資料、Blueprint、模板、圖片或完成品，就必須讓零基礎學員不靠講師口頭補充即可取得並辨認它。

## 每項核心資產的必要資訊

| 欄位 | 必須回答 |
|---|---|
| 身分 | 顯示檔名、格式，以及必要的版本／去敏狀態 |
| 取得方式 | HTML 提供可點擊的相對連結（可開啟或下載）；Markdown 提供可解析路徑或可複製內容 |
| 使用時機 | 在學員第一次需要它之前說明「現在拿哪一份、稍後用在哪一步」 |
| 用途 | 說明資產提供什麼輸入，以及會產生哪個完成物 |
| 備援 | 無權限、格式不支援或連線不可用時，提供可執行的替代路徑與能力差異 |
| 完整性 | 實際檔案存在、連結從目前頁面可解析、內容與示範／映射一致 |

## 放置規則

1. 資產必須在第一次操作前出現在「起始材料」或示範說明中；頁尾資產清單只能補充，不能是唯一入口。
2. 只有裸檔名、只寫「課程資產中／附件內」、或只提供教師端路徑，都不算學員可取得方式。
3. 學員要匯入或複製的檔案，需同時提供檔案用途、使用步驟與預期結果；去敏 Blueprint 要明示哪些連線／目的地需在工作區重綁。
4. 產頁前逐一驗證檔案與 `href` 目標；檔案不存在、連結斷掉或只能靠講師轉交時，狀態為 `BLOCK`，不得以文字敘述補洞。

## 審查判定

任一核心資產缺少身分、取得方式、第一次使用時機或備援，判定為 `BLOCKER`。若資產可取得但講義未說明它與輸入／輸出的關係，判定至少為 `MAJOR`，退回補寫教學脈絡。
