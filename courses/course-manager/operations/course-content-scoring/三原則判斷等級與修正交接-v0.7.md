# 三原則判斷等級與修正交接 v0.7

日期：2026-10-27。狀態：可供試用的判斷與交接規則；尚未驗證跨評估者一致性。

承接[三原則架構 v0.5](三大原則與彈性評估架構-v0.5.md)、[正確性與價值基準 v0.6](正確性與價值判斷基準-v0.6.md)及[三案例校準](三份教材案例校準-v0.6.md)。本版定義如何形成品質結論，以及如何把結論交給修正工作。不設計修復循環、停止條件、重試次數或自動發布。

## 一、判斷前固定用途與證據範圍

每次評估先記錄教材路徑與版本、評估層級（單元／模組／整課）、目標學員及先備、應解決的問題、本單元承擔的理解或能力、必要支援的承擔位置。用途需由教材或課程承諾支持；無法確認時標示定位待確認，不替作者發明較容易通過的目的。

同時寫清楚檢查方式：文本審讀、來源查證、作者操作、目標學員閱讀或實作觀察。文本審讀可以判斷教材是否提供必要解釋，不能證明學員已學會。每個等級只適用於所記錄的範圍，不把單章結論推成整課結論。

## 二、共同等級：四級，不加總

| 等級 | 意義 | 與相鄰等級的分界 |
| --- | --- | --- |
| L0．未成立 | 已有證據顯示，本原則在主要用途上沒有可用的內容基礎，或內容與主要用途根本矛盾 | 不是資料沒拿到，也不是發現一處嚴重錯誤就直接給 L0；須指出主要基礎缺失或根本矛盾 |
| L1．核心需修正 | 有可保留的內容，但至少一個已確認缺口阻礙主要理解、關鍵行動或必要價值 | L1 與 L2 看影響，不看問題字數；一句錯誤若改變主要判斷仍是 L1 |
| L2．局部需修正 | 主要用途已獲內容支撐，仍有已確認、應處理的局部問題；不須學員自行補出核心知識或另找關鍵操作路徑 | 若必須靠講師臨場補核心理由或關鍵步驟，不能給 L2；純風格偏好也不構成降級 |
| L3．符合用途 | 必要主張與支援已有相應證據，未發現影響該用途的實質缺口 | 不是完美、最長、最難或涵蓋最多；可有不影響用途的編輯建議 |

L0–L3 是有順序的判斷代碼，不是等距分數。不加總、平均、轉成百分制或跨用途排名。A、B、C 分別呈現；一項優點不能抵銷另一項核心缺口。三項皆 L3 也只表示本次範圍符合用途，不代表整課驗收或學習成效已被證明。

## 三、三原則各自的明確錨點

| 等級 | A．資訊正確 | B．學員理解 | C．內容價值 |
| --- | --- | --- | --- |
| L0 | 主要解釋、方法或示範的基礎不成立，無法提供可信的主要認識或行動依據 | 主要內容只有標籤、指令或互相矛盾的片段，無法辨認所教的意思與必要關係 | 在已確認的學員與用途下，內容沒有可辨認的必要貢獻，或主要內容與需求相反 |
| L1 | 有正確內容，但核心事實、推論或適用條件出錯，使主要認識或關鍵行動受到誤導 | 有局部解釋，但背景、材料、理由、段落關係或必要使用支援有核心斷裂，學員須自行補出 | 選材可能值得教，也有部分增益，但缺少支撐主要價值的深度、判斷或內容；主要承諾未被教材承載 |
| L2 | 核心主張及條件已成立，仍有不改變主要判斷的局部措辭、例子一致性或條件表達需修正 | 核心意思、主要推理與必要使用路徑已可理解，局部用詞、轉段或非關鍵說明仍需修正 | 主要貢獻與必要深度已成立，但局部重複、支線負擔或次要內容不足影響投入效益 |
| L3 | 用途所需事實、方法、條件與材料推論一致；會影響結論的變動主張有適切查證，沒有過度保證 | 指定先備的學員可由教材理解問題、材料與方法，依用途讀懂結論或使用內容；必要支援明確，無須評估者代補 | 能指出內容帶來的必要理解、判斷、能力或查閱支援；深度、分工與負擔在本次證據範圍內符合用途 |

「正確但沒有價值」「有價值但難懂」都可成立。C 另記兩句：選材值得教的是什麼，以及正文是否足以承載它。不能只因題目有用就給 C L3，也不能只因文案失敗就把應保留的教學核心抹掉。

對同一問題若要影響兩項等級，必須各自說明後果。例如來源核對步驟不解釋用途，可能使 B 無法理解；若也沒有教出課程承諾的判斷能力，才另影響 C。不得把同一句「不好讀」複製成三項判斷。

## 四、防止片段講義得到高等級

完整教學正文沿用[文案基準 v0.3](講義文案撰寫基準-v0.3.md)及[v0.4 六項診斷](文案評分規則-v0.4.md)：問題建立、材料意義、段落發展、段落關係、範例說明力及學習收束。

- 已確認有影響主要理解的背景、解釋、銜接或收束斷裂，B 最高 L1；若主要解釋基礎不存在，判 L0。資料齊全、步驟完整、成品存在與版面漂亮都不能解除這項限制。
- 以 v0.4 檢查同一版本完整正文時，任一核心項低於 3，B 不得高於 L1。材料或範例未達基本要求，B 不得為 L3；是否為 L1 或 L2，依其對主要理解的影響判斷。
- v0.4 六項皆達 3，只能支持正文脈絡條件；B 還需檢查本單元承擔的必要使用支援。不能把舊文案分數直接換成 B 等級。
- 速查表、練習頁等依用途檢查可理解性，不強制補長篇故事。速查表仍須讓讀者知道查什麼、如何解讀及適用條件；練習頁仍須有可取得的先備與必要任務說明。

核心與局部的判別必須寫出「學員因而無法理解／完成什麼」。原本只稱「局部」的舊問題不能直接對應 L2。例如保存方式只缺一句，但若阻斷本章承諾的重新開啟文件，就按關鍵行動缺口處理；若僅影響非必要的另一種格式，才可能屬 L2。

## 五、證據不足另列，不當成等級

每個具體主張仍記「有證據支持／已確認缺口／待確認」。這是證據狀態，與 L0–L3 的品質等級分開。

| 證據情況 | 應如何呈現 |
| --- | --- |
| 必要材料與證據足以區分等級 | 給 A／B／C 各自等級，附正面證據、缺口及影響 |
| 缺少會改變該原則等級的證據，且無法確定缺口 | 該原則標「待判定」，列出缺什麼、補到後能判斷什麼；不給 L0 或暫填 L3 |
| 已確認核心缺口，同時還缺其他必要證據 | 呈現「待判定；已知最高 L1」，保留已知問題與未確認範圍。不能用未知掩蓋已知，也不能假裝已完成全項判斷 |
| 未檢查的內容不屬本次用途或範圍 | 說明未涵蓋的範圍，可對已界定範圍判級；不能事後刪去必要責任以取得 L3 |

A、B、C 三原則本身不標不適用；可以不適用的是下層形式，如概念導入章不必有軟體操作。若用途本身待確認，受影響的整項先待判定，但可確定的事實錯誤與脈絡缺口照常交接。

## 六、評估結果交接格式

交接是一份可供修正者直接工作的說明，可用以下模板，不必另建資料庫。教材正文不得被改成這份表格的欄位順序。

```markdown
# 評估與修正交接

## 評估對象
教材路徑與版本：
評估層級、學員與先備：
本單元用途、承諾與相鄰支援：
檢查方式與未涵蓋範圍：

## 三原則結論
| 原則 | 等級或待判定／已知上限 | 支持證據與缺口編號 | 結論適用範圍 |
| --- | --- | --- | --- |
| A 正確 | | | |
| B 理解 | | | |
| C 價值 | | | |

## 問題 P01（同一根因合併，跨原則另述影響）
原文位置與短引文：
已確認的問題、依據與學員影響：
受影響原則與核心／局部的理由：
修正後應出現的具體改變：
必須保留的事實、教學用途與既有優點：
可修改範圍、相關依賴與交付位置：
確認改變的方法與所需證據：

## 待確認 Q01
目前不知道什麼、為何影響判斷：
最小補證動作與來源／環境：
哪些修改依賴此結果、哪些已確認問題可先處理：

## 修正者回交
完整候選稿位置與來源版本：
對應各問題實際改了什麼、保留了什麼：
實際核對結果與依據：
未處理、無法確認或需改變用途／範圍的事項：
```

等級負責說明品質狀態，問題說明負責指引修正。不得只交「提升到 L3」「增加脈絡」「補更多案例」等抽象指令；應指出缺少的關係與預期讀者能理解的內容。目標可寫希望符合 L3，但不能取代具體改變及其證據。

修正範圍以解決問題所需為準，可以跨相鄰段落補回完整敘事，不限於改一個詞；同時不得擅自增加工具、降低承諾、改變主要例子或刪除必要內容。若根因是素材或環境，交接要指出這項依賴，不交給文案改寫來掩蓋。

修正者交付完整、可直接閱讀的候選稿與簡短變更對照；不能只回傳零散修補句。實際查證、操作、人工回饋分開記錄，未執行不填成功。本階段沿用現有試驗方式保留原稿、另存候選稿，不自行覆蓋正式講義；這是交付範圍，並非另設核准關卡。

## 七、把既有案例轉成可用的交接示例

以下沿用 v0.6 的原文版本與查核，不是本輪重新評完三份教材。等級只示範如何套用已知證據；不為尚未檢查的面向補級。

### P-GTM-01：保留導入敘事，修正自主部署的界線

原文為 GTM CH1-1 第 239 行「任何追蹤碼……都不需要再去動網站的原始碼」，連同 296–304 行的自主部署結論。v0.6 已依 Google 資料層文件指出過度概括：所需事件或資料仍可能要由網站提供。這會讓初學行銷學員錯估工程協作責任，是 A 的核心缺口；就此已知證據，A 不得高於 L1，仍須配合其他必要主張的證據才能給完整等級。

交給修正者的要求：讓讀者能分辨可在 GTM 介面調整的設定，與仍需網站資料或工程協作的情境；同步調整前後對照與結尾。保留原先工程排程痛點、容器比喻及概念導入用途，不加入與本章無關的部署作業。以原官方來源核對條件，完整閱讀修改前後段落，確認技術限制不再被比喻與結論推翻。交付獨立候選稿，不改正式檔。

### P-36-01：材料有價值，仍需完整解釋

36 小時原稿第 208 行快速串接「告訴主管」「完成物」「準備帳號」，218 行定義提示詞後立刻要求貼上。v0.4 的核心脈絡診斷與使用者回饋已指出：學員須自行補出材料用途、要求理由與段落關係。原稿有局部解釋，不能判完全沒有基礎；但 B 不得高於 L1。C 應保留「核對來源與未知資訊值得教」的正面證據，再判承載是否足夠，不直接給高等級。

交給修正者的要求：在完整正文中建立向主管報告的問題，解釋五行紀錄如何對應進度、後續工作與待確認事項，再交代三點摘要、追問與改數字練習的理由。保留原始五行、完整提示詞、12 改 8、發布日期未定及保存任務，不能用增加任務清單替代解釋。以 v0.3 六項功能核對整篇，逐項指出原本缺少的關係在哪裡補上。現有改寫稿是已完成的示例，使用者閱讀回饋可引用但不可擴大為所有學員的理解證明；本示例不要求再重寫一次。

### P-36-02 與 Q-36-01：保存路徑須由操作證據解決

改寫稿第 81 行讓學員使用「平常用來寫文字的文件工具」，接著要求存入本機資料夾。已知問題是工具選擇與保存路徑的適用條件沒有交代；尚未知的是指定學員實際使用什麼工具、是否因此無法完成。v0.6 稱它為局部缺口，不表示可直接給 B L2。若目標學員包括使用雲端文件且無本機匯出先備者，這會阻斷本章承諾的保存任務，B 最高 L1；未確認學員環境前，受影響判斷先待判定，不能假設已有能力。

先補證目標環境或依課程既有設定選定最小可用路徑，不必盤點所有文件工具。修正時說清楚這條路徑如何保存並重新開啟，保留第 79 行的保存理由、83 行的核對方式及已獲認可的敘事。確認方法是實際建立、儲存、關閉與重新開啟文件，並核對內容；只看文字不能填「操作通過」。已確定的語意與適用範圍問題可先整理，具體操作說明依所選環境產出。

## 八、規則核對與本版界線

| 邊界案例 | 規則應產生的結果 |
| --- | --- |
| 資料齊全、步驟完整，但主要段落靠讀者自行拼接 | B 最高 L1，不被 A 或 C 的優點抵銷 |
| 主要正文根本只有任務標籤，沒有可辨認的解釋基礎 | B L0；不是因為任務列表這種形式本身被禁止 |
| 主要理解成立，只有不影響意思的用詞偏好 | 不因此降到 L2；記可選編輯意見 |
| 有一處確定核心錯誤，其餘重要主張未查 | 待判定，已知最高 L1；同時交出已確認問題及待補證 |
| 概念導入沒有操作，但用途與所需解釋均已成立 | 不因缺操作降級；按概念用途判斷 |
| 改寫更流暢，卻把「要補附件」改成保證「補齊」 | B 的改善不能免除 A 的一致性問題，回交須列出該變更影響 |
| 只有單章文本與相鄰單元資料 | 可判單章內容，不能宣稱整課不重複或學員已學會 |

上述為本次作者的規則一致性核對，不是新一次教材評分或獨立審查。新增等級需在後續實際交接中觀察是否足以區分問題；本版未規定何時進入下一輪、何時停止、何時回復或如何自動執行。
