# 單章課程改善流程 v0.10

日期：2026-10-28。狀態：依使用者同意的[GTM三次試作回顧](GTM三次試作回顧與v0.9調整建議.md)整合，可供後續指定的單章作業使用；尚未以本版啟動修復，未實作自動化。

本版取代v0.9作為後續新作業的流程入口，保留[v0.9](單章課程改善流程-v0.9.md)及舊試作紀錄。判級沿用[v0.7](三原則判斷等級與修正交接-v0.7.md)，循環與人工確認沿用[v0.8](修復循環與停止條件-v0.8.md)；本版明確化證據分類、補證與定稿順序、多個停止原因並存時的回報方式。新採本版時，這三處以本版為執行細則，沒有放寬判級、兩版上限或失敗補救限制。

**既有試作不自動遷移、不重評、不重置版本額度。CH1-3仍依原紀錄等待補證，保留v2、2／2及H3未確認；本次不下載、不匯入、不登入，也不產新稿。**

## 一、範圍與輸入

一次只處理使用者指定的一個章節，讀取判斷必要的相鄰單元與附件。先固定學員、先備與本章承諾，再決定哪些證據必要；不能發現實作缺口後把用途改成概念介紹，也不要求概念章額外完成部署才能達標。不按主章、補充章或練習章名稱預設不同分數。

預設單一執行者完成評估、修改與作者自查，不宣稱獨立審查。保留正式來源與候選歷史，不自行覆蓋正式講義、發布或擴大修復。已有授權且資料充分的工作直接執行，不在每步增加核准。

| 輸入 | 應記內容 | 不足時處理 |
| --- | --- | --- |
| 教材版本 | 正式來源、教案／HTML關係、原稿快照與SHA-256 | 查指定課程現有檔案；版本歧義會改變成果時才詢問 |
| 學員與用途 | 對象、先備、本章承諾、後續依賴、須保留的事實與閱讀優點 | 讀大綱與正文；仍有重要歧義時走H1，不另造較低標準 |
| 材料與來源 | 已查的講義／附件／課程入口、材料位置與版本、官方依據、已有實測或回饋 | 記搜尋範圍及未知；找不到不直接宣稱不存在 |
| 授權與歷史 | 修改範圍、規則版本、候選用量、同一失敗補救次數、使用者限制 | 接續沿用歷史；換規則版本不會自動增加候選額度或解除暫停決定 |

## 二、先分清楚教材缺失與證據不足

每個判斷都記「查了什麼、實際觀察、仍未知什麼、是否影響本章承諾」。以下分類放在既有評估與交接紀錄，不另建一套評分表。

| 類別 | 記法與處理 | 不可推論 |
| --- | --- | --- |
| 已確認的錯誤或教學缺口 | 列P，附原文位置、證據、學員受到的影響、預期修改及保留內容 | 不能只有「不夠好」或「還沒測」 |
| 已確認的支援入口缺口 | 列P，限定所查講義與入口。例如要求ZIP卻未提供取得方式；其他位置是否已有材料另列Q | 不可擴大成整門課沒有材料、老師沒提供帳密；若其他入口有支援，優先補引用 |
| 材料內容／適用性未知 | 列Q，說明需取得什麼才能回答哪個問題；查到檔名或權限只解除相應未知 | 素材存在不等於內容完整、可匯入或適合本章 |
| 尚未實測 | 列Q，指定版本、操作、預期觀察及其對本章判斷的影響 | 未測不是失敗，不直接列P、給L0或以L1封頂 |
| 已觀察到實測問題 | 記版本、環境、動作、實際結果與預期差異；原因已指向教材時列P，原因不明時保留Q供診斷 | 一次錯誤不必然證明教材錯；不得把環境或執行工具問題歸給教材 |
| 工具限制／使用者決定 | 記執行限制與停止原因，例如工具斷線或使用者暫不下載 | 不轉成品質扣級，也不稱學員一定無法操作 |
| 人工閱讀未確認 | 記H3待確認及對應版本／段落 | 不當成已證實難讀；人工認可也不取代技術實測 |

P與Q可以描述同一環節的不同面向。例如「講義未說明如何取得登入資訊」是P；「指定網站能否以提供的方式登入」是Q。補到資訊後分別更新，不以一項解除另一項。

### A／B／C如何使用這些證據

- A正確性、B理解與必要使用支援、C內容價值分別判斷，不平均、不加總。沿用v0.7的L0–L3及文案核心脈絡限制。
- 每個已知封頂須對應已確認的核心P；每個「待判定」須對應會改變該項等級的Q，指出受影響的具體主張。無關未知不阻擋該項判斷。
- 已有核心P且仍缺必要證據，記「待判定；已知最高L1」。只有未測、尚無已知核心缺口時，不加L1上限。
- C不能只因沒有實測而降級。應判斷教材是否承載本章承諾的必要深度、判斷與成果支援；若尚無法知道，就列待判定。若已確認缺少必要登入支援，才以該缺口及其影響支持等級。
- A的一般工具主張已有來源支持時，保留該部分結論；指定素材仍待驗證時，清楚限定待判定範圍，不稱整章所有事實未知。
- 同一根因可能影響多原則，但須各寫其後果，不能複製相同扣級理由。補齊文件、列滿步驟或把Q寫清楚，都不等於P已修復。

## 三、補證先於依賴它的定稿

先取得會改變主要修法的必要材料，再產出供比較的候選稿。已有材料可直接查，不要求使用者重填表格；資訊缺口會改變成果時，提一個必要問題，等待期間繼續與該資料無關的查核與修改準備。未回覆不能當作材料不存在、同意某個假設或授權繼續。

操作章只按本章需要檢查以下環節；不把每個概念章都強制套用整條路徑：

| 環節 | 可支持的觀察 |
| --- | --- |
| 入口 | 學員從教材哪裡找到材料；連結指向、檔名、權限設定與實際可達頁面 |
| 取得 | 是否真的取得指定檔案或存取所需環境；記版本及必要識別資訊 |
| 內容 | 實際內容是否包含本章需要的材料，能否辨認用途；檔名不代替內容檢查 |
| 操作 | 依候選步驟在指定環境實際做到哪裡，遇到什麼結果 |
| 結果 | 是否得到本章承諾的產物或狀態、如何辨認，以及是否具必要後續支援 |

每段分別記「已確認／未確認／觀察到問題」及證據位置，不換算總分。前一段通過不能外推後一段；已有同版本相關證據可沿用，不為紀錄更新重跑。

補證應針對會改變判斷的最小範圍。改操作路徑須有相應實際路徑驗證才能宣稱完成；尚不能驗證則如實停於補證。不能以官方一般流程、已有同名網站或另一章的人工認可，替代指定材料的測試。遵守使用者停止、權限及環境限制，不以補證之名擴大工作。

## 四、交接與候選稿產出

沿用單章資料夾：保存原稿快照、一份可追加的評估／交接／比較紀錄、必要的候選稿及開發進度連結。不為每個流程步驟另造文件。

每個P的交接包含：原文與位置、已確認的影響、具體修法、須保留內容、修改範圍、確認方法。每個Q包含：已查範圍、未知問題、需要的最小證據、影響哪個P或原則、下一動作及其限制。「提高到L3」不是有效交接。

### 候選稿何時產出

1. **材料足以支持本輪修改：**完成有依據的修正後，另存可連續閱讀的全文候選稿；局部問題只改必要位置，全文供前後比較。預設Markdown，HTML依明確需求另做呈現核對。
2. **必要補證仍待回覆或可繼續取得：**先完成查核與交接，不搶先把依賴未知的文字定稿。確定且無相依的問題可實質修正，但不把未成立的完整成果寫成已完成。
3. **必要證據暫時拿不到：**交付已完成的交接與獨立可用修正；若需提供全文比較，標為「審閱草稿／待補證」，明示適用範圍，不稱可獨立完成的講義。不得編造素材、帳密、成功畫面或恢復步驟。
4. **沒有實質缺口：**交付評估與不需修改的理由，不強制產候選稿。

候選正文應服務學員理解。查核進度、Q編號、版本限制與編輯待辦集中於交接紀錄；草稿可在開頭集中說明未完成範圍，正文只保留會影響學員當下選擇或行動的必要限制，不在各段反覆插入「本稿尚待查核」。減少這些提示不能用來隱藏缺少的操作支援。

### 版本用量

預設最多兩個候選版本；同一失敗最多一次自動補救，補救仍占候選額度。實際產出並用於評估或交付比較的內容版本都計入，審閱草稿也不例外；不能用改名或「仍是草稿」規避上限。

原稿備份、未改內容的複本、單純更新證據紀錄不增加候選用量；根據新證據修改候選正文、刪除退步內容或產出修訂版則計入。先把必要補證做完再定稿，以減少無效版本，不能以補證為由無限擴充上限。保留所有已供比較的版本及其問題歷史。

## 五、執行順序與比較

| 步驟 | 動作與產出 |
| --- | --- |
| 1 固定範圍 | 記學員、用途、來源版本、授權、保留內容與既有用量；保存原稿。用途有重大歧義走H1 |
| 2 評估原稿 | 按第二節區分P／Q／執行限制；判A／B／C，將缺口與未知綁到證據 |
| 3 補證與交接 | 按第三節完成能做的必要查核，明確哪些修正可進行、哪些仍依賴Q；形成可執行交接 |
| 4 產出候選 | 依第四節判斷可定稿、可提供有限草稿或應停在交接；記改動與用量 |
| 5 比較與退步檢查 | 對照原稿、前版及人工認可版，逐項確認P已解／部分改善／未解，Q已確認／仍未知；分別更新A／B／C |
| 6 決策與停止 | 依第六節判斷能否續修、應補證、等待人工或完成；不因低等級自動回到改寫 |
| 7 接收回饋 | 綁定版本與段落，區分閱讀認可、修正指示與正式採用；更新紀錄，不把沉默當確認 |

比較須保留原有背景、例子、必要條件、段落發展及收束；新增問題先定位根因，不把退步稿升為基準。能局部修正時保留已修好的事實，只修退步處；不整份退回含核心錯誤的原稿再宣稱安全。閱讀感受與同版型呈現、平台實測分別陳述，未檢查者不宣稱無退步。

## 六、續修限制與停止狀態

先判斷**哪些動作仍可做**，再決定**目前主要狀態**。狀態名稱不會解除版本上限、使用者限制或待確認事項。

### 動作界線

- 來源或授權改變時，先辨認影響；重大用途變更走H1。使用者要求停止的動作立即停止，其他已授權且無相依的工作可完成。
- 同一失敗補救後再失敗、加刪反覆或相同證據下評級來回，停止相關自主修改並走H2。
- 兩版用完不得再產內容修訂版；仍可在授權範圍內核對既有稿、記錄證據或接收回饋。使用者暫不補證時，不因仍可記錄而繼續操作。
- 續修須同時具備具體未解P、有依據且不同於失敗作法的修法、必要材料、明確範圍與剩餘額度。若只剩風格偏好就停改；若等級低卻說不出缺口，先澄清理由，不為追分改寫。

### 主要狀態的選擇

先確認是否仍有影響本章用途的P／Q、必要H3或其他待決事項。若已無必要缺口、證據足夠且無實質退步，可完成，不因剛好用滿兩版而改稱受限。

其餘情形依下列順序選一個主要狀態，並在同一筆紀錄列出所有並存限制：

| 優先順序與狀態 | 條件及下一動作 |
| --- | --- |
| 1 等待人工確認（H1／H2） | 下一步取決於用途或取捨決定；交出具體問題與已有成果。其他Q、用量及禁止動作仍保留 |
| 2 等待補證 | 有會改變本章判斷的必要Q，且本輪暫時不能取得；記缺什麼、由誰或何條件恢復。若使用者選擇暫不補證，明記其決定，不重複索求 |
| 3 受限停止 | 仍有需要修改的已知P，但受版本／資源／授權限制且不屬前兩項，不得自主續修；說明最小下一決策 |
| 4 等待人工確認（H3） | 必要P／Q已處理，目前只有閱讀確認未完成；停止潤稿，交人工比較 |
| 5 本輪修正完成 | 本章必要判斷A／B／C均L3、無實質退步，適用的人工確認已完成或不需觸發；無缺口原稿也可直接結束，不必修稿 |

有必要Q時，H3可另記未確認，甚至先取得閱讀回饋，但不以此解除Q；有版本限制時，補證完成也不會自動開放第三版。需新增修稿額度或改變用途時，先取得明確的新工作授權，記承接原因、範圍與額度，保留先前失敗及版本歷史，不假稱重新從零開始。

例：CH1-3仍為「等待補證；用量2／2；H3未確認；使用者暫不下載」。它不是已修復，也不是已證實匯入失敗；即使未來收到材料，仍須遵守剩餘動作限制。只有用量耗盡、但最後一版已達完成條件的案件，可正常完成，不為額度本身加新門檻。

## 七、人工確認的位置

| 位置 | 觸發條件 | 交付與界線 |
| --- | --- | --- |
| H1 範圍 | 用途有重要歧義，或必須改學員、主要成果或必要教學 | 交已知問題、最小方案及影響；已有授權且範圍清楚不重問 |
| H2 取捨與反覆失敗 | 正確性與閱讀難兼顧、重複退步／失敗、使用者指出改稿更難讀 | 交完整上下文、版本、已試方法及具體疑問；不因有回覆自動重置額度 |
| H3 閱讀 | 整篇敘事、閱讀節奏或重要解釋有變動，成效只有作者自評 | 交原稿、候選、保留優點與限定段落的閱讀問題。純局部修改若不涉及未確認的整篇稿，可依既有授權完成，不強加核准 |

課程設計者確認閱讀、內容專家判技術與用途、學員提供理解或操作觀察，均須寫明回饋範圍。讀得順不等於能做完；一位使用者認可不代表全體學員成效。先前整篇稿的H3未完成時，不能用本輪只改兩句跳過。正式採用與發布不包含在以上確認內。

## 九、本版依據與一致性核對

CH1-1支持局部修正及保留優點，但屬本流程制定前案例；CH1-2支持概念章從交接到H3結案；CH1-3支持缺口辨認與補證停止，尚未支持完整操作修復。H1／H2反覆失敗處理、跨評估者一致性與全課循環仍未充分驗證，不能因新增規則就宣稱有效。

本版已用以下情境進行作者規則核對，並非新教材試跑：

| 情境 | 本版要求 |
