# 完成品驗收規則

摘要符合下列條件才算完成：

1. 三個活動都有 CTR、CVR、平均 CPC、CPA 與 ROAS，百分比與比率保留兩位小數，金額取到元。
2. 公式一致：CTR = clicks ÷ impressions；CVR = conversions ÷ clicks；平均 CPC = cost ÷ clicks；CPA = cost ÷ conversions；ROAS = conversion value ÷ cost。
3. 明確指出 Prospecting Social 的 CPA 為 NT$1,000、ROAS 為 2.00，因此未達 CPA ≤ NT$500 且 ROAS ≥ 4.00 的雙重門檻。
4. 判讀至少引用一個實際數字，也說明彙總資料不能單獨證明素材、受眾或版位造成結果。
5. 建議包含一個可執行的下一步與後續要觀察的指標，不直接宣稱因果。
