單元二

把點擊接到轉換與價值

現在補上 CVR、CPA 與 ROAS，讓同一張表從媒體互動延伸到商業結果。

先固定這份資料的口徑

這份簡化資料把 clicks 當成可追蹤的 eligible interactions。CVR 是 conversions 除以 clicks；CPA 是 cost 除以 conversions；ROAS 在這裡使用 conversion value 除以 cost。不同平台的互動與歸因口徑可能不同，所以跨平台比較前必須先確認定義一致。

CVR = conversions ÷ clicks × 100%
CPA = cost ÷ conversions
ROAS = conversion value ÷ cost

完整示範：Retargeting Display

它有 500 clicks、50 conversions、NT$20,000 cost 與 NT$125,000 conversion value。CVR 是 50 ÷ 500 = 10.00%；CPA 是 20,000 ÷ 50 = NT$400；ROAS 是 125,000 ÷ 20,000 = 6.25。

這三個數字的意思不同：CVR 描述點擊後轉換的比例，CPA 描述平均一筆轉換成本，ROAS 描述每一元廣告花費對應多少轉換價值。不要只挑最好看的數字下結論。

完成三個活動

把 Brand Search 與 Prospecting Social 的三個指標算出來，再補到上一單元的表。Prospecting Social 是這一單元的重要檢查點：它的 CPA 應為 NT$1,000，ROAS 應為 2.00。

卡住時：conversions 為 0 時，CPA 不能除以 0，應標成「無法計算」並另外呈現花費與零轉換；cost 為 0 時，ROAS 同樣不能硬填無限大。

交接到摘要

確認每列都有五個指標，並保留兩位小數。下一單元會用同一張表對照門檻：CPA 不高於 NT$500，而且 ROAS 不低於 4.00。兩項都符合才算本次達標。
