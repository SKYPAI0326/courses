# 補充講義撰寫規劃

建立日期：2026-10-26  
主題：使用開源與 AI 影音工具完成獨立剪輯工作流  
目前階段：已依 2026-10-26 後續要求完成官方文件導引版內文；待實機試跑，尚未選定正式教學工具。

講義正文：[用開源與 AI 工具完成一支可修改的短片](補充講義-開源AI影音工作流.md)。已涵蓋七款原始工具、Kdenlive 與 Shotcut，並提供練習材料與修改任務；實機操作、中文生成品質及原生專案交接仍待確認。以下保留原規劃作為後續試跑與修訂依據，不因先完成內文而視為試跑通過。

## 一、已確認的方向

本補充內容獨立評估自身可用性，不預設必須回到 Premiere，也不受原課 5 小時配置限制。是否採用工具，應取決於學員能否完成作品、修正結果與繼續編輯。

不將七款工具全部列為必學。先以最少工具完成完整流程，出現具體缺口才增加工具。講義依工作任務組織，不以逐款安裝介紹作為主體。

使用者已同意先以 Concat 試跑完整工作流，將 Kdenlive 列為補強核心候選；其餘工具依需求加入。本次僅建立規劃，尚未執行安裝、模型下載、付費服務設定或作品試跑。

## 二、成果與工作流範圍

初期以一般教學短片、口播、訪談精華與社群影片為範圍，不先擴張至專業長片、多機位或複雜視覺特效製作。

完整工作流包含：

素材準備 → 選段與排序 → 精剪與補畫面 → 旁白與配樂 → 字幕校正 → 畫面與音量調整 → 輸出 → 重開專案修改。

學員最終應保留：

- 一支可在剪輯軟體外播放的短片。
- 可重新開啟、繼續修改的專案與所需素材。
- 工作流需要的獨立字幕、音檔或其他中間素材。
- 一份簡短修改紀錄，說明 AI 結果中採納、修正或拒絕的內容。

自動產出 MP4 不等於完整工作流成立；必須確認字幕、聲音與畫面能依修改要求處理。

## 三、工具初評與採用順序

下表為官方文件支持的能力與本次規劃判斷，並非實機驗收結果。

| 工具 | 文件支持的角色 | 規劃位置 | 優先確認事項 |
|---|---|---|---|
| Concat | 多軌剪輯、標題、特效、字幕、語音、專案自動儲存與輸出 | 第一個試跑的剪輯核心 | 安裝、中文字幕與字型、手機素材相容性、精準修改、專案重開 |
| Kdenlive（新增候選） | 多軌後製、字幕／逐字稿、專案與素材封存 | Concat 有具體缺口時的補強或替代核心 | 同一作品能否完成，以及新增的操作與模型設定成本 |
| Shotcut（備選） | 多軌剪輯與混音、字幕交換、代理剪輯、專案儲存 | Kdenlive 不適合目標環境時再比較 | 不預先增加第三套剪輯軟體教學 |
| AutoClip | 既有長影片選段、取景、字幕與發布包 | 長片再製的選修路線 | 選段原意、細部修改能力、原始時間碼與可編輯素材交接 |
| MoneyPrinterTurbo | 主題、腳本、配音、素材、字幕、配樂與合成 | 主題成片的進階路線 | 服務設定、費用、局部替換與重新生成成本、素材交接 |
| yovoice | 語音生成、聲音設計、角色配音與音樂 | 內建聲音功能不足時的配音候選 | 臺灣中文表現、指定模型、生成速度、音檔輸出 |
| VoiceStudio | 語音生成、聲音複製、影片配音與轉錄 | 與 yovoice 比較後擇一主教 | 中文效果、設定成本、音檔交接與模型使用條件 |
| ArtCraft | 圖像、構圖、2D／3D 場景與影片素材生成 | 有補鏡頭需求時才加入 | 費用、生成結果可用率、下載格式與剪輯軟體匯入 |
| FilmCraft | 時間軸剪輯、調色、混音、字幕、專案與輸出 | 暫列觀察候選 | 官方仍標示 Alpha，真實素材及平台相容性需實測 |

### 預計比較的組合

1. **最少工具方案：Concat。**優先使用現有素材與內建功能完成作品；有配音缺口才補 yovoice 或 VoiceStudio。
2. **可擴充方案：Kdenlive 加任務工具。**Kdenlive 負責精剪、字幕、聲音與輸出；AutoClip、MoneyPrinterTurbo、配音工具或 ArtCraft 依素材需求加入。

不預設第二種方案較好，也不預設所有工具能交換完整可編輯時間軸。

## 四、第一輪實機試跑

### 4.1 試跑前確認

- 確認實際教學平台、作業系統、記憶體、GPU、可用空間與安裝權限。
- 選定工具版本與官方下載來源，記錄版本及日期。
- 選定一組有使用權的中文口播、手機影片、圖片與背景音樂；沿用同一組素材比較工具。
- 本輪以約 60 秒作品為試跑規格，並非已決定的正式課程作業長度。
- 若需模型，記錄模型名稱、版本或識別資訊、下載量與用途；不可只寫「下載 AI 模型」。
- Concat 官方目前說明桌面安裝檔尚未簽章；先確認目標電腦能否依管理政策安裝，不將解除安全限制寫成全體學員預設步驟。

目前未指定試跑主機；不因本規劃自行跨主機派送。

### 4.2 基本製作任務

以 Concat 完成以下操作：

1. 建立專案，設定畫面比例、解析度與幀率。
2. 匯入素材，選段、排序、裁切並加入補充畫面。
3. 保留口播，加入配樂，調整相對音量與必要淡入淡出。
4. 產生或匯入字幕，修正中文錯字、斷句及時間。
5. 檢查畫面裁切、字型、字幕可讀性與聲畫同步。
6. 輸出影片，在剪輯軟體外播放檢查。
7. 儲存並關閉軟體，重新開啟專案。

### 4.3 修改任務

在同一專案完成三項修改，再次輸出：

- 修改一處字幕錯字與斷句。
- 替換中間一個鏡頭，保留原有旁白。
- 降低配樂音量，確認旁白仍清楚且時間未錯位。

確認修改是否可直接完成，或必須回原生成工具重新產製。不可用播放最初成片取代修改能力檢查。

### 4.4 記錄與決策

| 項目 | 要記錄的實際結果 |
|---|---|
| 環境 | 平台、硬體、工具版本、模型與測試日期 |
| 初次設定 | 安裝與模型下載時間、所需空間、權限及登入要求 |
| 製作效率 | 轉錄、生成、輸出及人工校正的時間 |
| 中文品質 | 辨識錯字、繁簡體、斷句、字型及配音問題 |
| 可修改性 | 三項修改能否完成，以及是否需要重新生成 |
| 可恢復性 | 關閉重開後是否保留編輯、素材是否能正確定位 |
| 實際成本 | 是否使用付費服務、實際用量與費用；未量測不填估計值 |
| 交付物 | 成片、專案、素材與字幕的實際位置 |
| 結論 | 可作主線／需補強／暫不採用，附具體原因 |

若 Concat 能完成基本製作與修改，先保留單工具主線，不因工具清單較長而增加依賴。若出現直接影響完成作品的缺口，再以同一素材與修改任務測試 Kdenlive；只比較受影響的能力。

## 五、跨工具交接檢查

加入任何生成工具前，先確認它提供什麼輸出，以及剪輯核心能否實際匯入。

| 交接內容 | 必須確認的問題 |
|---|---|
| 影片 | 是原始片段、無字幕版本，還是已燒字幕的成片？實際編碼能否匯入？ |
| 聲音 | 旁白與音樂能否分開取得？是否只能取得混合音軌？ |
| 字幕 | 能否輸出 SRT？時間碼對應原片還是成片？中文編碼與斷行是否正確？ |
| 剪輯決策 | 能否保留來源與起訖時間，讓學員回到原始片段修改？ |
| 專案 | 能否在原工具重開？跨工具交換是否保留軌道、字幕與效果？ |

如果只能交接合成 MP4，應將該路線定位為「生成成片後有限修改」，明確交代限制；不可宣稱保留完整分軌或可編輯時間軸。

## 六、試跑通過後的講義架構草案

章節暫名：**用開源與 AI 工具完成一支可修改的短片**。

| 單元 | 學員任務 | 撰寫前需要的依據 |
|---|---|---|
| 1. 準備工作環境與素材 | 完成安裝、開啟專案並匯入素材 | 指定版本、實際安裝路徑、設備條件與素材包 |
| 2. 完成第一版剪輯 | 選段、排序、裁切並加入補畫面 | 已試跑的主工具流程與示範專案 |
| 3. 整理聲音與字幕 | 調整口播、配樂，修正中文字幕 | 指定模型或字幕來源、常見錯誤與修正示範 |
| 4. 輸出與接收修改 | 播放檢查，完成三項修改並再次輸出 | 成片、修改前後專案與可重現操作 |
| 5. 選修：長片再製 | 利用 AutoClip 產生候選並檢查原意 | 可用的選段案例與交接方法 |
| 6. 選修：從主題產生初稿 | 利用 MoneyPrinterTurbo 產生、檢查及修改影片 | 已完成的服務設定、費用與局部修改實測 |
| 7. 選修：補配音或畫面 | 依作品缺口產生聲音或視覺素材 | 擇定的工具、中文品質與匯入結果 |

單元 1–4 為獨立完成作品的核心。單元 5–7 視實測結果與教學需求取捨，不承諾全部製作。正式時數依初次設定、操作及修正時間決定，目前不沿用先前估計的 60–80 分鐘。

## 七、講義撰寫原則

- 先呈現要完成的作品與任務，再介紹必要工具。
- 步驟使用實際驗證的版本、介面文字及中文素材，不從功能清單推測操作。
- 每段練習提供可觀察的完成結果與對應的修復方法。
- 原始影片、字幕、音檔與專案須能讓學員取得；不能只有教師成片。
- 如提供預先生成素材作為備援，須區分「完成後製」與「完成 AI 生成操作」。
- 功能重複的工具擇一主教，其他僅列差異與適用情境。
- 免費軟體、本機運算、模型下載與雲端費用分開說明。
- 聲音、模型及素材的使用條件放在實際需要做決定的位置。
- 未完成的測試標示待確認，不以官方行銷文字或安裝難度評分代替實測。

## 八、目前尚待確認

1. 目標學員的設備與實際試跑環境。
2. Concat 能否通過中文素材、三項修改與重開專案的測試。
3. 是否確有必要增加 Kdenlive 或獨立配音工具。
4. AutoClip、MoneyPrinterTurbo 的輸出是否足以支撐預定修改方式。
5. 選修路線的服務、模型、費用及素材條件。
6. 根據上述結果決定正式工具組合、單元取捨與時數。

後續接續順序：**讀取本規劃 → 確認試跑環境 → 試跑 Concat → 判斷補強需求 → 選定工具組合 → 撰寫核心講義 → 視需求增加選修路線。**
