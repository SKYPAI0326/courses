# ACP Premiere Pro 模擬試題版面規格

- 版本：v0.1（草案，待使用者確認）
- 日期：2026-11-03
- 適用：重製 `output/ACP_PR_模擬試題.pptx` 與 `output/pdf/ACP PR 模擬試題.pdf`
- 範圍：學科 A01–A38、術科 B01–B42（現行版漏掉的 B19 補回）

## 1. 這版要修的問題

| 問題 | 現行版狀況 | 本規格對應 |
|---|---|---|
| 沒有原始題目 | 79 張投影片 0 張題圖；選項全數未列 | §4 題圖規則、§3 題目區必含選項 |
| 摘要取代原文 | 英文題幹被縮寫（A18、A33、A34、B28 等） | §5 轉錄規則：逐字轉錄 |
| 字太小 | 英文原題 9.4–9.75pt，正文 8–10pt | §6 字級下限 |
| 不能當模擬考 | 題目與正解在同一頁 | §2 題本與解答本分開 |

## 2. 交付形式

- 主要交付：A4 直式 PDF，給學員閱讀、列印、作答。
- 結構分兩部分，同一份 PDF 前後排列，或拆成兩檔：
  1. **題本**：只有題目、題圖、選項、作答欄。不出現正解、解析、核實狀態。
  2. **解答本**：依題號對應，含正解、解題步驟、錯誤選項說明。
- 頁面內不放製作用的 metadata（「題庫定位」「核實狀態」「獨立核實版」）。來源對照另存成 `MOCK-EXAM-SOURCE-MAP.md`，給製作與驗收使用。

## 3. 題本頁面結構

### 3.1 學科題（A 類）

由上到下：

1. **題頭列**：題號（A19）＋題型標籤＋作答方式。
   - 題型標籤固定用這 6 種：單選、複選（選 N 項）、配對、下拉填空、是非（True／False）、點選介面。
2. **英文原題**：逐字轉錄，含情境句與提問句，段落照原題。
3. **題圖**：原題有圖就放，位置在原題文字下、選項上，與考試畫面順序一致。
4. **選項**：
   - 單選／複選：A–E 標號，英文原文一行一項；中文對照接在同一行後方，或放下一行縮排。
   - 配對：左欄項目、右欄描述，兩欄表格，右欄順序照原題。
   - 下拉填空：句子保留空格 `_____`，每個空格下方列出原題所有選項。
   - 點選介面：題圖放大到欄寬，按鈕可加編號圈（①②③），選項列出編號。
5. **中文翻譯**：放在英文原題下方，字級較小、灰色。翻譯只做輔助，不取代英文，也不補充原題沒有的條件。
6. **作答欄**：一行「我的答案：＿＿＿」。

分頁：一題不跨頁。無圖短題一頁可排 2 題，有圖題一頁 1 題。

### 3.2 術科題（B 類）

由上到下：

1. **題頭列**：題號（B35）＋專案名稱（Pizza Time）＋任務名稱（Remove section）。
2. **英文原題**：逐字轉錄 Certification Test 面板的任務文字，保留條列、粗斜體強調、表格、時間碼格式。
3. **參考圖**：原題寫「should look like the following image」等字樣時一定要附；沒寫就不放。
4. **中文翻譯**：與學科相同規則。
5. **完成檢核欄**：把原題每一條要求拆成一個 ☐，文字直接取自原題條件，不另加條件。

分頁：一個任務不跨頁。短任務一頁可排 2 個。

## 4. 題圖規則

| 來源 | 用法 |
|---|---|
| 主檔 PPT 內嵌圖（`ACP PR CC 2024.pptx` S46–S99） | 直接抽出原圖使用，不重繪 |
| 追加題庫 PNG（33 張螢幕擷取） | 裁切題目內容區後使用 |
| 補充題庫 JPEG（75 張手機翻拍） | 只裁出答題需要的圖片區；文字部分用轉錄，不貼整張翻拍 |

- 題圖寬度：至少 120mm；比較圖、按鈕列、介面圖放滿欄寬（180mm）。
- 解析度：輸出時至少 150 dpi。原圖不夠大時照原尺寸放，不用 AI 放大或重繪。
- 手機翻拍可以做透視校正、裁切、調亮度；不可修改內容。
- 題本內不放整張考試介面截圖當題幹，因為列印後字太小，翻拍也有摩爾紋。

## 5. 轉錄規則

- 英文題幹、選項、任務條件**逐字轉錄**，來源優先序：考試截圖 > 主檔 PPT 文字。
- 不摘要、不合併句子、不刪情境句、不改寫條件。
- 主檔 PPT 的明顯打字錯誤（如 `DONOT`、`exiting footage`、`the name it`），以考試截圖為準修正；沒有截圖可對照時保留原字，並在來源對照表註記。
- 選項順序照原題；原題無字母標號時，依序加 A–E 方便作答與對答案。
- 時間碼照原題寫法，不自行補成 `hh:mm:ss:ff`；需要補時寫在中文翻譯裡。

## 6. 字級與版面

| 元素 | 字級 | 備註 |
|---|---:|---|
| 題號／題型標籤 | 13pt 粗 | |
| 英文原題 | 12pt | 行高 1.5 |
| 選項（英文） | 11.5pt | 行高 1.45，項目間距 2mm |
| 中文翻譯 | 10.5pt | 灰色 #555 |
| 解答本正解 | 13pt 粗 | |
| 解答本解析 | 10.5pt | 行高 1.6 |
| 頁首頁尾 | 9pt | 全文件最小字級 |

- 紙張 A4 直式，邊界上下 16mm、左右 15mm，版心寬 180mm。
- 英文字型：Arial／Helvetica（接近考試介面）；中文字型：蘋方／微軟正黑體。
- 單欄排版。題本不用卡片式雙欄，避免字被擠小。

## 7. 解答本結構

每題：題號＋題目第一句（英文，辨識用）→ 正解（字母＋原文）→ 解題步驟 → 其他選項為何不對。術科：正解改為操作步驟，步驟中的面板與選單名稱用英文原名。

- [ ] 每題題圖數與原題一致；需要看圖作答的題都有圖
- [ ] 每題選項數與原題一致
