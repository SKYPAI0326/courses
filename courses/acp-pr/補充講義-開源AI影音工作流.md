# 用開源與 AI 工具完成一支可修改的短片

資料查核日期：2026-10-26  
適用對象：能使用資料夾、下載檔案，想獨立完成短片製作的初學者。  
閱讀方式：先讀導讀，了解工具能幫你完成什麼，再完成第 1–5 節的共同基礎。其餘工具依作品需求選讀，不需要全部安裝，也不需要 Premiere。第 6–11 節先作工具探索；只有決定使用哪一條路線後，才準備該節帳號、模型與環境。

> **本版的使用範圍**：操作依官方文件整理，搭配可取得的課程素材與作者設計練習。尚未逐款在教室電腦完成實機試跑；下文的「應看到」是檢查目標，不代表作者已觀察到成功結果。工具介面與模型會更新，找不到所述功能時，先核對版本與該節官方文件，保留現有作品。

## 導讀｜這些工具能幫你做出什麼？

一場活動結束後，你手上有幾段手機錄影、照片和一份介紹文字，想讓沒參加的人也能看懂活動。要做成影片，還得挑出值得留下的內容、安排先後順序、補上解說，讓文字和聲音對齊。即使素材齊全，這些整理與製作工作仍會讓人遲遲無法開始。

這批工具提供幾種切入方式：讓 AI 提出候選片段、把文字讀成旁白、產生缺少的畫面，或先組出一版影片。你可以從初稿開始判斷與修改，逐步完成作品。是否真的省時，取決於素材、電腦和生成結果；本講義會帶你看懂工具負責的工作，以及你仍需做的選擇。

### 從三種作品，想像自己的用途

| 想完成的作品 | 原本容易卡住的地方 | 工具可以協助的工作 |
|---|---|---|
| 活動精華或訪談短片 | 原片很長，不確定哪些段落能獨立成篇 | AutoClip 提出候選；你回聽前後文，決定保留與修正 |
| 有解說的教學短片 | 已有圖片與文字，缺少旁白及畫面安排 | 配音工具產生聲音；剪輯工具讓圖片、字幕與解說對齊 |
| 從主題開始的知識短片 | 不知道如何把腳本、素材、聲音組成第一版 | MoneyPrinterTurbo 協助合成初稿；你核對內容並調整畫面 |

這些是可嘗試的作品方向，不是工具保證自動完成的成果。第一次先挑一個最接近自己需求的方向，會比同時學會所有工具更容易看見用途。

### 先分清楚四種工作，再認識工具名稱

**剪輯工具負責把作品組起來。** 它讓你決定哪一段先出現、哪張圖片蓋在哪裡、字幕停留多久，以及音樂是否蓋過人聲。Concat 是本講義首先使用的整合工具；Kdenlive、Shotcut 與 FilmCraft 是其他剪輯環境，不必四套一起學。

**自動成片工具負責先整理一版。** AutoClip 從現有影片找片段，MoneyPrinterTurbo 從主題或腳本組合內容。兩者的起始材料不同，選錯工具就可能花時間準備不需要的東西。

**配音工具負責把文字變成聲音。** yovoice 與 VoiceStudio 可用來補解說，讓沒有錄製口播的作品也有旁白。你仍要試聽發音、停頓與語氣，並依實際聲音長度安排畫面。

**視覺生成工具負責補素材。** ArtCraft 適合在缺少某個畫面時製作圖片或影片片段。產生的畫面要回到作品裡接受檢查：它是否說明了正在講的內容，而不只是看起來漂亮。

| 工具 | 在這份講義中的角色 | 什麼時候值得打開它？ |
|---|---|---|
| Concat | 第一套剪輯核心 | 想把現有影片、圖片、聲音與字幕組成完整短片 |
| AutoClip | 既有影片的選段助手 | 想把口播、訪談或課程重新製作成較短內容 |
| MoneyPrinterTurbo | 從腳本到成片的初稿工具 | 已有主題或文字，希望先組出一版解說影片 |
| yovoice | 本機語音與音樂製作工具 | 想先嘗試中文旁白，並保留獨立音檔供剪輯 |
| VoiceStudio | 聲音設計與配音工具 | 有聲音設計、授權聲音複製或影片配音需求 |
| ArtCraft | 視覺素材生成與構圖工具 | 腳本已清楚，但缺少能表達某句話的畫面 |
| Kdenlive | 可承接後製與專案封存的剪輯核心 | 需要另一套環境來整理多軌內容與後續交接 |
| Shotcut | 另一套剪輯核心 | 想比較操作方式，或原先工具不適合自己的環境 |
| FilmCraft | 試用中的剪輯環境 | 願意用小作品探索新工具；目前不作唯一正式工作環境 |

以上角色整理自各工具官方說明；功能與使用限制的來源放在後面的對應操作章節。Kdenlive 與 Shotcut 是補強選項，FilmCraft 仍在 Alpha 階段。

### 為什麼這裡選擇開源工具？

開源工具讓你能查閱專案文件、功能與授權，也提供自行管理工作環境的選擇。對想持續製作影片的人，值得學的是如何保存素材、字幕與專案，讓作品可以繼續修改，不必每次都從頭開始。

不過，開源不代表每種 AI 功能都免費，也不代表安裝後一定能流暢執行。本機模型會使用運算資源，雲端服務可能另外計費，模型與素材也有各自的使用條件。後文會在需要下載、選模型或生成時說明，第一次不需要把所有選項準備齊全。

### 第一次投入後，你會留下什麼？

共同練習會提供一支兩分鐘中文影片、圖片、字幕與配樂，讓你用 Concat 做出約一分鐘的短片，再親手改字幕、替換畫面與調低音樂。完成後，你會留下可播放的影片，以及能重新開啟修改的專案與素材。

這個起點能讓你先理解影片如何組成，也能辨認自己真正需要哪種 AI 協助。若現有聲音已足夠，就不用另學配音；若沒有長片要挑選，就先跳過 AutoClip。等作品出現明確缺口，再加入對應工具，學到的每一步都會用在自己的影片上。

## 1. 從作品需求決定工作流程

你收到一段兩分鐘的中文介紹，希望做成一分鐘短片。第一次輸出後，還要改一個字幕錯字、換掉中間的畫面，以及降低配樂音量。如果只留下最後的 MP4，這些修改會變得困難：畫面上的字幕可能已經與影片合成，旁白也可能已和音樂混在一起。

因此，本講義同時照顧兩件事：完成可播放的影片，以及保留日後能修改的材料。AI 可以提供選段、旁白或畫面，你仍要決定內容是否正確、片段如何銜接，以及哪些素材應分開保存。

### 1.1 三種起點，三條路線

| 你手上的材料 | 建議起點 | 完成方式 |
|---|---|---|
| 已有影片、照片與聲音，想自己安排內容 | Concat；需要替代剪輯環境時用 Kdenlive 或 Shotcut | 匯入 → 精剪 → 字幕與混音 → 輸出與修改 |
| 已有訪談、課程或口播，想找出精華 | AutoClip | 分析與選段 → 人工核對 → 在原工具修正，必要時交剪輯軟體後製 |
| 只有主題與腳本，希望產出初稿 | MoneyPrinterTurbo | 核對腳本 → 配音與素材 → 自動合成 → 檢查與修改 |

另外三種需求可在途中補入：yovoice 或 VoiceStudio 製作旁白，ArtCraft 製作視覺素材，FilmCraft 則提供另一套仍需審慎試用的剪輯環境。這些工具的官方用途見各節來源；路線安排是本講義的教學選擇。

### 1.2 看懂四種檔案，才能正確交接

**原始素材**是影片、圖片、聲音的來源。**專案**記錄使用哪些素材、擺放位置、裁切與效果。**字幕檔**保存文字與時間碼。**輸出影片**是把這些安排算成可播放的畫面與聲音。

專案通常仍需要原始素材。把專案寄出去，對方未必就能開啟完整影片；把 MP4 寄出去，對方也不會因此取得你的分軌與字幕編輯能力。保留專案、素材與字幕，才有機會在下次修改時只處理受影響的部分。

字幕也有兩種交付方式。燒入字幕已成為畫面的一部分，播放器不用另外載入字幕就能看見；獨立 SRT 可改字與時間，但不承諾保留原剪輯軟體的字型、動畫或所有樣式。本講義會保留 SRT，再依使用目的決定影片是否燒入字幕。

### 1.3 軟體、模型與服務分開準備

下載軟體後，AI 功能未必立即可用。本機模型需要下載檔案並使用電腦資源；雲端模型需要可用帳號、模型權限與連線，部分服務另有 API 費用。聊天產品的訂閱不應直接視為 API 額度。

第一次操作只準備當下會使用的模型。例如先做字幕，就先處理語音辨識；不要同時下載歌曲生成、聲音複製與視覺分析模型。先用一句話或一小段素材確認可用，再處理整支影片。這能讓失敗原因較容易定位，也避免尚未確認設定就消耗大量時間與費用。

原片是課程製作的靜態示意影像與合成中文旁白，不是工作坊現場紀錄。圖片亦為生成式示意素材。新增配樂是本講義以程式合成的簡單和弦，供混音操作使用，並非任何一款 AI 音樂工具的成果。字幕參考依原始字幕與指定剪輯順序換算，沒有代替剪輯軟體的實測。既有素材來源可查閱[素材清冊](assets/ai-short-video-editing/asset-manifest.json)。

新增的材料判斷圖卡是作者繪製的文字圖解；練習字幕只將第 2 句「材質」改成「材貭」，其他文字與時間碼均與答案相同。這個錯字供重開後的修改練習使用，含錯字的第一版只留在練習資料夾，不對外發布。

建議建立以下資料夾；名稱是整理建議，不是軟體的強制規定：

```text
video-practice/
  source/       原片與圖片
  audio/        原旁白、生成旁白與配樂
  subtitles/    原片字幕與成片字幕，分開命名
  project/      剪輯專案
  exports/      輸出的影片
```

將素材放到固定位置後才匯入軟體。進行中不要任意搬動或重新命名來源檔；若要換電腦，先確認專案是否有封存功能，或連同素材一起搬移並重新開啟檢查。

### 2.2 第一次作品的內容安排

本練習製作約 60 秒的「社區工作坊：先判斷，再利用」。以下時間以秒為單位，右端為剪輯邊界，不重複包含下一段的第一格。原片是 25 fps，先沿用相同幀率，減少不必要的轉換。

| 成片位置 | 原片取用範圍 | 內容用途 |
|---|---|---|
| 00–10 秒 | 00–10 秒 | 介紹工作坊 |
| 10–20 秒 | 20–30 秒 | 先分類與檢查 |
| 20–30 秒 | 30–40 秒 | 區分可用與有疑慮的材料 |
| 30–40 秒 | 50–60 秒 | 說明再利用例子 |
| 40–50 秒 | 70–80 秒 | 保留「只追求速度」的提醒 |
| 50–60 秒 | 110–120 秒 | 邀請觀眾思考下一步 |

這是作者提供的剪輯方案，不是 AI 分析結果。各段包含完整句子與停頓，方便第一次定位。熟悉後可縮短停頓，但字幕也必須一起調整，不能繼續套用未更新的參考 SRT。

## 3. 用 Concat 完成第一版剪輯

Concat 在本講義負責整合工作。你會先讓原片形成有順序的一分鐘，再補圖片、配樂與字幕。這個順序能避免剛做好的字幕因後續大幅換段而全面錯位。

### 3.1 安裝與建立專案

本次文字跟做先固定為 **Windows 11、Intel／AMD x64 電腦、Concat 0.2.8 桌面版**，使用既有字幕，不下載 AI 模型。這是教材選定的路線，尚未代表已在教室電腦試跑成功。Mac 與其他平台先參考官方安裝說明，不套用 Windows 安裝檔。

1. 在 Windows「設定 → 系統 → 系統資訊」確認處理器與系統類型；若是 ARM 電腦，先停在這一步，官方目前沒有可沿用的 Windows ARM 路線。
2. 到 [Concat 下載頁](https://concatenate.pages.dev/download/)選 Windows x64，核對版本與平台，下載安裝程式或 MSI；不要選 Source code 原始碼壓縮檔。
3. 執行下載檔，依安裝精靈完成安裝，再由開始功能表開啟 Concat。官方說明安裝檔尚未簽章；若遇到 SmartScreen 或 Smart App Control 攔截，保留畫面交由管理者依組織政策處理，不要求學員關閉全機安全防護。
4. 成功開啟時，首頁上方應有 **New project** 與 **Open project**；本機剪輯不需先登入帳號。若尚未看到首頁，不要繼續猜後面的按鈕位置。

官方最低列出 4 GB 記憶體；程式及最小字幕模型約需 500 MB，素材、快取與輸出另占空間。這些是最低條件，不保證播放流暢。無法安裝時，第 9 節提供 Kdenlive 的另一條探索路線，仍需先確認它能在自己的電腦啟動。[安裝與首次啟動](https://concatenate.pages.dev/guides/install/)、[系統需求](https://concatenate.pages.dev/guides/system-requirements/)

在首頁按 **New project**，名稱輸入 `workshop-60s`，位置選剛建立的 `project/`，畫幅選 **16:9、1080p、25 fps**，再按 **Create**。Concat 的專案是資料夾，會自動儲存；記下實際建立的完整路徑，後面重開要選這個專案資料夾。[建立專案](https://concatenate.pages.dev/guides/first-edit/)

### 3.1.1 先認識四個區域，再匯入

以下依官方桌面預設配置描述；若曾自行搬動面板，位置可能不同，請以面板名稱辨識。

| 區域 | 預設位置與用途 | 第一次要做的事 |
|---|---|---|
| Library／素材庫 | 左上方，保存匯入素材 | 按 Import，選原片、工作坊圖片與配樂；All media 應出現三個素材 |
| Preview／預覽 | 素材庫旁，顯示畫面 | 單擊素材卡會看來源；回到時間軸點選後才看剪輯結果 |
| Timeline／時間軸 | 下方，一條條橫列稱為軌道 | 拖曳原片素材卡到最左側 0 秒；只有時間軸上的內容會參與作品 |
| Inspector／屬性 | 右側，依選取物件改變 | 先單擊要修改的片段，再看屬性；沒選物件時顯示專案資料 |

時間軸上的直線是播放頭，表示目前播放位置。按空白鍵可播放／暫停；要剪某段，先單擊該片段，避免誤切其他軌。拖曳片段中間會移動整段，拖曳左右邊緣才是改長度。先把原片放到 0 秒，播放確認有聲音，再繼續。若預覽仍顯示來源素材，點回時間軸確認。[官方介面導覽](https://concatenate.pages.dev/guides/the-window/)

### 3.2 分割與刪除：先保留來源時間，最後才補空隙

將原片拖到空白時間軸的起點，播放確認有聲音。先不要放配樂或字幕，避免分割時誤選其他物件。

1. 關閉工具列的 **Magnetic timeline**。這樣刪除片段時先留下空隙，後面的片段不會提前移動。
2. 點擊預覽下方的時間碼定位；依序在 10、20、30、40、50、60、70、80、110 秒建立切點。使用 **Edit → Split at playhead**，每次先選取要分割的影片片段。
3. 刪除原片 10–20、40–50、60–70、80–110 秒的片段。此時保留六段，但時間軸仍有空隙。
4. 按第 2.2 節順序，將六段依次移到成片的 0、10、20、30、40、50 秒，開啟吸附可協助邊界貼齊。
5. 播放每個接點，確認沒有黑畫面、重複字或只剩半句的旁白。

先切完再搬動，是為了讓表中的「原片時間」一直可用。若提前啟用連動刪除，後面片段位置改變，再跳到同一時間就可能切到不同句子。切錯時立即 Undo，回到最近一個正確切點，不必重新匯入整支影片。[Concat 時間軸操作](https://concatenate.pages.dev/guides/cut-on-the-timeline/)

### 3.3 覆蓋畫面，保留原本的解說

成片 20–25 秒正在說明材料判斷。現在用圖片覆蓋這五秒，底下原片與聲音都保留。

1. 在時間軸上方工具列的最左側按 **Add track（＋）→ Add to top**，新增位於原片上方的空軌。
2. 確認 **Magnetic timeline** 關閉、**Snap to edges** 開啟。點預覽下方的時間碼，把播放頭定位到 20 秒。
3. 從 Library 拖曳工作坊圖片到新軌，讓左邊緣吸附播放頭。不要把圖片拖到原片所在的軌道。
4. 將播放頭定位到 25 秒，拖曳圖片的右邊緣至播放頭，得到 20–25 秒的五秒圖片；不是拖曳圖片中間。
5. 若邊界太密看不清，用 **View → Zoom in** 放大；核對原片仍是六段、總長仍為 60 秒。圖片和旁白可同時播放，是因為它們在不同軌道。

播放 19–26 秒，應看到畫面進入圖片再回到原片，旁白連續。若聽不到聲音，先確認你是否刪掉了底下原片；若圖片沒有蓋住畫面，檢查軌道上下順序、可見性與圖片是否位於正確時間。這種補充畫面常稱為 B-roll，可以用來呈現解說提到的事物，也能讓畫面切換更自然。

初次練習不必加轉場。先把句子與畫面對齊，之後再判斷轉場是否真的幫助理解。

## 4. 把字幕與聲音做成可修改的內容

### 4.1 字幕應跟著哪一條時間軸

原片第 8 句在 70.5–78.8 秒，指定剪法把原片 70–80 秒移到成片 40–50 秒。因此該句字幕的新時間為：

```text
新開始時間 = 40 + (70.5 - 70) = 40.5 秒
新結束時間 = 40 + (78.8 - 70) = 48.8 秒
```

若把原片 SRT 原封不動放到一分鐘成片，這句字幕會出現在成片結束後。字幕文字正確，仍可能因時間軸不同而無法使用。

跟做時使用含一處故意錯字的 `workshop-60s-practice.srt`，正確的 `workshop-60s-reference.srt` 留作答案；不要兩份都匯入，否則會重複字幕。

1. 按時間軸工具列上的 **Generate Captions（T）**，在面板選 **Import SRT…**，選練習版字幕。這條匯入路線不需下載 Whisper。
2. 匯入後應有六個文字片段。它們必須位於圖片與影片的上方；若圖片蓋住字幕，先 Undo 這次匯入，以 **Add track → Add to top** 增加空軌，再匯入一次並檢查。
3. 將播放頭移到 12 秒，單擊該處字幕片段；右側 **Inspector → Text → Content** 應顯示第二句。先確認能找到「材貭」這個練習錯字，留到第 5.2 節重開後再改。
4. 其餘五句照正確稿回聽；文字與時間都要吻合。文字在 Content 修正；時間在時間軸拖曳字幕片段左右邊界修正。

字幕匯入後會成為文字物件。需要另外保存 SRT 時，先選一個字幕片段，再用 Captions 面板的 **Export SRT…** 匯出該軌；檢查提示指向的是字幕軌。[Concat 字幕指南](https://concatenate.pages.dev/guides/auto-captions/)

想練習 AI 轉錄時，先在 **Settings → Transcriber** 下載多語言 Whisper 模型。中文版不要選名稱含 **English** 或 `.en` 的英語專用模型。選取要辨識的有聲片段，再使用 **Generate Captions**；它針對所選聲音產生字幕，不能假設按一次就已處理所有剪過的片段。逐段完成後，回聽檢查重複、漏句與時間位置。

本例尤其要保留「如果只追求速度，很容易做出沒有人需要的物品」中的條件與否定。少了「沒有人需要」，影片的意思就變了。繁體字、專有名詞與標點也應人工檢查；字幕模型能辨識中文，不等於一定輸出適合臺灣讀者的用字。

### 4.2 讓配樂襯托旁白

按 **Add track → Add to bottom** 增加下方空軌，將 `practice-bed-60s.wav` 從 Library 拖到這條軌的 0 秒；它長 60 秒，應與原片剪輯結尾對齊。單擊配樂片段，按 **M** 暫時靜音，先聽旁白，再按 M 恢復配樂比較；目標是在一般播放音量下，每句話都聽得清楚。按 M 前確認選的是配樂，不是原片。

Concat 的聲音片段上有音量線，可拖曳調整；需要把影片聲音單獨處理時，片段右鍵的 **Detach audio** 會將聲音拆出。先確認拆出的聲音與影像沒有錯位，再進行修改。[聲音與軌道操作](https://concatenate.pages.dev/guides/cut-on-the-timeline/)

本練習先單擊配樂，在片段內找到橫向細線並向下拖曳，讓音樂明顯變小；不要拖到片段邊緣。與原設定來回試聽，再決定是否需要更低。這是比較練習，不是所有影片通用的混音標準。片段音量相同，聽起來也可能不同；要在旁白最小聲與音樂較明顯的位置檢查，而非只聽開頭。

若原片聲音與另一份旁白同時播放，會聽到雙重人聲。先暫時靜音其中一軌確認來源，再保留真正要使用的聲音，不要直接把所有軌道一起降低。

### 4.3 需要補一句旁白時，先試內建語音

例如片尾想補上：「先確認需求，再決定材料的下一個用途。」先在 **Settings → Speech** 下載支援中文的模型；官方文件將 Kokoro 列為支援中文的內建聲音選項。不要因另一個模型能複製聲音，就推定它同樣支援中文。

移動播放頭至預定位置，開啟 **Text to Speech**，在 Script 貼上上述句子，選模型與中文聲音，再執行 **Generate speech**。官方說明生成音訊會加入時間軸，並以 WAV 保存在專案音訊資料夾。試聽後再安排片尾長度；若超出原本 60 秒，就縮短文字或調整剪輯，不能只把最後幾個字裁掉。[Concat 語音生成指南](https://concatenate.pages.dev/guides/text-to-speech/)

這是額外練習，加入後須更新字幕與總長度。若內建聲音不適合，再選讀第 7 節的專門配音工具。

## 5. 輸出後，再完成一次修改

### 5.1 匯出可播放的影片

本次交付選擇「**畫面內可直接看到字幕的 MP4，另附可修改的 SRT**」。匯入的字幕是時間軸文字物件；先在預覽確認它們可見、字幕軌未隱藏，且位於圖片上方。這條路線讓文字隨畫面輸出，不把另外儲存 SRT 誤認為已完成影片字幕。[字幕物件說明](https://concatenate.pages.dev/guides/auto-captions/)

先確認目前啟用的是要輸出的時間軸，再按視窗右上方 **Export**（或 **File → Export**）。第一次使用 H.264，保持專案的 1920 × 1080、25 fps，在輸出面板的 Name 填 `workshop-v1`，以 Browse 選 `exports/`，確認路徑為 `exports/workshop-v1.mp4`，再按 Export。本例是一般 SDR 練習素材，不需要額外啟用 HDR 或 10-bit。HEVC、AV1 等選項是否可用還與裝置編碼能力有關，先以能完成交付的設定為主。[Concat 輸出指南](https://concatenate.pages.dev/guides/export/)

等待輸出完成後，使用系統播放器從頭看完；不要另外載入 SRT，確認 12 秒仍看得到練習錯字、22 秒圖片上仍看得到字幕。若只看到圖片沒有字幕，回專案核對字幕軌可見性與上下順序，再輸出；這是結果檢查，不是假定已在本機驗證。檢查片頭、每個切點與片尾，確認聲音沒有突然消失、字幕沒有掉出畫面、最後一句沒有被截斷。輸出完成但檔案無法播放時，保留專案，先重試短段 H.264 輸出，確認是整個輸出流程還是特定素材出錯。

### 5.2 交付前的修改練習

先確認視窗頂端專案名稱旁顯示 **saved**，再關閉軟體。重新啟動 Concat，首頁按 **Open project**，選第 3.1 節記下的 `workshop-60s` 專案資料夾；不要選 MP4 或單一素材。也可以在已有編輯視窗中用 **File → Open project** 開啟。最近專案清單可作捷徑，但這次練習請確實找到資料夾。[專案開啟方式](https://concatenate.pages.dev/guides/first-edit/)、[儲存狀態與選單](https://concatenate.pages.dev/guides/the-window/)

重開後，先核對專案名稱、六段原片、20–25 秒工作坊圖片、六句字幕及 0–60 秒配樂都在；播放 12 秒與 22 秒確認聲畫。若看到空白新專案，回 Open project 重選原資料夾，不要重新匯入素材冒充恢復成功。

接著完成三項真實修改：

1. **修正錯字。** 將播放頭移到 12 秒，單擊第二句字幕，在 **Inspector → Text → Content** 將「材貭」改成「材質」。正確整句是「志工先依材質分類，再檢查每一件物品是否乾淨完整。」只改文字，保留 10.5–18.8 秒。可另加換行改善閱讀，但不能以換行取代改字。
2. **替換畫面。** 在 Library 按 Import 匯入 `materials-check.png`。關閉 Magnetic timeline；只單擊 20–25 秒的工作坊圖片，確認選到圖片後按 Delete。將新圖拖到同一上方軌的 20 秒，再把右邊緣修到 25 秒。不要刪底下原片，也不要移動字幕。這是用刪除後補入來替換，不假設工具另有 Replace 按鈕。
3. **調低配樂。** 選配樂片段，將音量線再向下調整，保持開始與結束時間不動。在相同播放器音量下比較，確認旁白比配樂清楚。

先播放 19–29 秒：新圖應在 20 秒出現、25 秒消失，旁白不中斷，字幕仍在原位。這張圖卡把「可用／有疑慮」的判斷寫出來，比原來的工作坊場景更直接對應解說；替換不只是把畫面換成另一張漂亮圖片。

等待 saved 後另輸出 `workshop-v2.mp4`。選一個字幕片段，再用 **Export SRT…** 匯出字幕；將結果保存在 `subtitles/workshop-v2.srt`，原檔只改名稱、不改副檔名。檢查第二句是「材質」、時間仍為 10.5–18.8 秒，其餘五句與正確稿一致。保留 v1 供比較，但只把已修正的 v2 當交付版本。

| 比較位置 | v1 練習版 | v2 完成版 |
|---|---|---|
| 12 秒字幕 | 材貭（故意錯字） | 材質 |
| 22 秒畫面 | 工作坊示意圖片 | 材料判斷圖卡；字幕仍可見 |
| 相同旁白段落 | 原配樂音量 | 配樂較低，旁白仍完整 |
| 總長與句子順序 | 六段、60 秒 | 不變 |

重新開啟時找不到素材，先確認來源檔是否被搬動或改名，將它們恢復至原本位置與名稱後重開專案。若仍缺檔，記下缺少的檔案與實際路徑，保留專案請教師協助；本文尚未核實各版本的重新連結介面，不猜測按鈕。不要把 MP4 當成原生專案的完整替代品。

### 5.3 自己決定一支 30 秒版本

回到原片與原始 SRT，另做約 30 秒的「材料再利用注意事項」。自行選句，需包含一項實際判斷與一項限制；不要沿用六段表直接刪掉後半段。重新安排字幕、配樂與結尾。

可接受的答案不只一種。例如保留「分類與檢查」、「有安全疑慮的材料另外處理」、「只追求速度的風險」，就能形成注意事項；只留下「布料做提袋、玻璃罐做收納」則偏向用途介紹，尚未完成這次任務。核對依據是內容是否符合目的、語句是否完整，以及修改後字幕與聲音是否同步。

## 6. AutoClip：從既有影片挑出精華

當素材長到不容易逐段瀏覽，AutoClip 可協助找候選片段。它的預設路線以字幕分析為主，適合訪談與口播。輸出前仍需判斷片段是否獨立成立；吸引人的一句話若拿掉前面的條件，可能會改變原意。[AutoClip 官方說明](https://github.com/zhouxiaoka/autoclip)

### 6.1 安裝與模型設定

從 [官方 Releases](https://github.com/zhouxiaoka/autoclip/releases)選擇對應平台。官方安裝指南提供 Apple Silicon macOS 與 Windows x64 桌面路線；Intel Mac、Linux 另有 Docker／CLI，本文不把它們視為相同安裝難度。桌面包內含 Python、FFmpeg，語音辨識與分析模型仍需準備。

在設定選擇分析服務商，填入自己的 API Key 與可用模型，測試連線後儲存。若採本機模型，先在 Ollama 或 LM Studio 啟動服務並載入模型，再回 AutoClip 連線。能開啟 AutoClip 不代表本機模型已啟動。

本節先用第 2 節的影片與原片 SRT，不啟用額外視覺分析或生圖。這可將「字幕是否可用」與「AI 是否選得好」分開觀察。官方安裝指南仍記載特定版本的 Windows 實機驗收待完成，因此下載到安裝包不能當作教室已可用的證據。[安裝與第一次出片](https://github.com/zhouxiaoka/autoclip/blob/main/docs/USER_INSTALLATION_GUIDE.md)

### 6.2 從匯入到人工修正

1. 使用檔案匯入，選擇兩分鐘影片及其原片 SRT；確認字幕時間仍對應 120 秒原片。
2. 確認製作類型與目標平台，再開始分析。這支短素材只用來熟悉流程，不代表長影片效能測試。
3. 打開候選片段，回到原片聽取前後文。記下來源起訖與片段主旨。
4. 在編輯器檢查片段邊界、標題與文案，修正斷句或誤導描述；依實際可用功能調整。
5. 匯出後檢查字幕語言、人物取景與片尾。官方說明不同平台預設包裝可能不同，不要只看輸出比例就認定設定符合需求。

假設候選片段只有「很容易做出沒有人需要的物品」，你應回聽前一句。補回「如果只追求速度」才能保留條件。若工具無法調整到需要的範圍，保留來源時間碼，用原始影片在剪輯核心重建這段。

下載發布包後，逐一確認是否真的含有獨立字幕、音檔或來源資訊。沒有看到的檔案不要假設存在。只有燒字幕 MP4 時，可作觀看或有限後製；若要精準改字，應回原工具，或以原始片段重新建立字幕。

**本節練習**：選一段你願意採用的候選，再找一段需要修改的候選。提交兩段的來源時間與理由。沒有產生合適候選也可記錄原因，不必為了交作業接受失去原意的片段。

模型連線失敗時先處理連線測試；字幕錯誤時先修 SRT 再分析；只有輸出失敗時，不要先重做全部轉錄。雲端分析可能傳送字幕，雲端轉寫會使用音訊，其他功能也可能傳送畫面；先確認你選的實際路線。[模型與資料說明](https://github.com/zhouxiaoka/autoclip#模型与数据由你选择)

## 7. yovoice 與 VoiceStudio：製作能放回剪輯軟體的旁白

本節用同一段文字比較聲音，避免把不同文案造成的差異誤認為工具能力。先完成一套工具即可。

```text
整理材料之前，先確認它是否乾淨、完整，也適合接下來的用途。
玻璃罐可以用來收納，但有裂痕的材料應另外處理。
先想清楚需求，再決定留下什麼。
```

這段是作者撰寫的練習旁白，不是原片逐字稿。生成後請依它的實際長度安排新片段；原片 SRT 不會自動對齊這份新錄音。

### 7.1 yovoice：先用內建聲音完成一段中文

從 [yovoice Releases](https://github.com/leemysw/yovoice/releases)下載。官方列出的桌面條件包含 Windows 10/11 x64、macOS 14 以上 Apple Silicon，另提供 Linux 安裝方式。Windows 的一般與 CUDA 安裝包需依硬體選擇；沒有 NVIDIA GPU 不必選 CUDA 包。[平台與安裝說明](https://github.com/leemysw/yovoice#installation)

在 Settings 的模型列表選擇所需模型，先下載輕量的官方 Kokoro 版本。依官方模型文件，`kokoro-82m-q8` 的中文聲音可選 `zf_xiaobei`；實驗性的 `kokoro-1.1-zh-q8` 使用另一套代碼，例如 `zf_001`。兩者不要混用。介面若顯示聲音名稱而非代碼，以模型聲音列表對照。

進入語音生成工作區，選剛下載的模型與中文聲音，貼上上面的三句旁白，執行生成。先聽「乾淨、完整」、「有裂痕」與句尾，確認沒有漏字、重複或不自然停頓；需要修正時，先把句子縮短或改成較容易朗讀的標點，再重新生成。

保存並匯出音檔，命名為 `narration-yovoice-v1`，保留工具實際提供的副檔名；不要只改副檔名冒充格式轉換。匯入剪輯軟體後，將它放在獨立聲音軌，以這份聲音的長度安排圖片與字幕。

Kokoro 使用內建聲音，不支援聲音複製。要複製聲音，需另選支援的模型與參考錄音；部分模型還需要逐字一致的參考文字。模型檔案大小也不等於執行時的總記憶體需求。[模型、中文聲音與輸入要求](https://github.com/leemysw/yovoice/blob/main/docs/models.md)

**本節練習**：以相同模型生成兩版，只改變一句話的斷句方式，選出較容易理解的一版。比較發音與停頓，不以「有繁體中文介面」判定口音品質。音樂與歌曲生成需另下載模型，本練習已有配樂，不需為完成旁白再安裝音樂模型。

### 7.2 VoiceStudio：從聲音選擇到匯出

VoiceStudio 提供聲音複製、設計與影片配音等工作區。請從 [官方 Releases](https://github.com/debpalash/VoiceStudio/releases)選擇平台安裝檔，依首次啟動引導完成本機環境與模型準備。官方 README 說明 Intel Mac 目前僅支援 App 介面、需要遠端後端；因此 Intel Mac 不能直接沿用「全部本機完成」的假設。[安裝與硬體條件](https://github.com/debpalash/VoiceStudio#get-started)

1. 開啟 **Voice cloning**，先選可用聲音；需要參考錄音時，使用本人或已明確獲授權的單人乾淨錄音。
2. 選擇引擎，依提示安裝模型。不同引擎對語言、硬體及參考文字的要求不同。
3. 貼上本節共同旁白，先生成第一句，確認發音與速度可接受後再處理其餘內容。
4. 保留不同 take，試聽後選定版本，再匯出音檔。官方文件說明 Clone／Design 的一般預設輸出為 16-bit WAV，實際選項仍受引擎限制。
5. 匯入剪輯軟體，確認長度、音量與接點，再製作對應字幕。

調整 Audio quality 是影響下一次生成，並不會回頭提升已產生的檔案品質。發音錯誤應回文字、參考錄音或引擎處理，單純提高輸出位元深度無法修正念錯的字。[引擎與功能](https://github.com/debpalash/VoiceStudio/blob/main/docs/feature-catalog.md)、[音質與輸出說明](https://github.com/debpalash/VoiceStudio/blob/main/docs/audio-quality.md)

**本節練習**：使用與 yovoice 相同的文字，檢查哪一版較少需要後製。若沒有做兩套工具，也可比較同一工具的兩個 take。評估依據是字詞正確、停頓、聲音穩定與生成時間，不是工具聲稱支援多少語言。

軟體授權與模型條件應分開閱讀。yovoice 模型文件特別列出部分權重或生成內容的非商業限制；商用前需回到所選模型發布者的條款確認，不將「開源軟體」當作所有輸出的商用許可。[模型條件入口](https://github.com/leemysw/yovoice/blob/main/docs/models.md#licenses)

## 8. MoneyPrinterTurbo 與 ArtCraft：從文字補出影片素材

### 8.1 MoneyPrinterTurbo：把腳本做成初稿

MoneyPrinterTurbo 能串接文案、配音、素材與合成。為了看清楚每個步驟，第一次先提供已核對的腳本與本機素材，暫不要求它同時搜尋素材、生成新畫面與自動發布。

Windows 可從 [官方 Releases](https://github.com/harry0703/MoneyPrinterTurbo/releases)的 Assets 下載一鍵啟動 `.7z` 包，解壓至不含中文、空白與特殊字元的路徑。GitHub 自動提供的 Source code 壓縮檔不是同一套啟動包。官方建議以 `update.bat` 更新，再用 `start.bat` 啟動；若教師已固定教學版本，課前確認版本後不要在課堂臨時更新。

macOS／Linux 或已有 Python 環境者可採官方套件路線；目前官方 PyPI 套件名稱是 **`mpt`**，不是名稱相近的第三方套件。下列命令供有 Python 3.11 以上環境者使用，Windows 初學者優先使用上述啟動包：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install mpt
mpt webui
```

這組啟用命令適用 macOS／Linux shell。建立虛擬環境可把套件與其他專案分開；瀏覽器開啟 WebUI 後才進入服務設定。本文未執行這些安裝命令。[官方安裝與套件說明](https://github.com/harry0703/MoneyPrinterTurbo#快速开始-)

第一次作品使用第 7 節三句旁白作為自訂腳本，目標為「介紹材料再利用前的判斷」。依 WebUI 的基本設定與製作欄位完成：

1. 確認文案服務與其他會使用的服務已設定；API Key 只填入工具設定，不放進腳本或交作業的截圖。
2. 輸入主題並使用自訂腳本，逐句核對，避免自動改寫添加原文沒有的保證或數據。
3. 素材來源先選本機上傳，加入工作坊圖片或自備有權使用的影片。
4. 配音先選可用服務試聽，或上傳第 7 節生成的旁白，避免同時排查兩個語音流程。
5. 選擇影片比例、字幕與配樂，先生成一支；檢查文字對應的畫面、音量與字幕後，再修改不適合的環節。

例如「有裂痕的材料應另外處理」若配上完整玻璃罐的漂亮展示，畫面未必幫助觀眾理解。可改用明確的文字提示或自行拍攝的例子，不必不斷重生整支影片。輸出格式與中間檔依版本實際提供者為準；拿到 MP4 後仍需確認能否另外取得旁白、字幕與素材。[工作流與素材功能](https://github.com/harry0703/MoneyPrinterTurbo#功能特性-)

**本節練習**：產出一版初稿，找出一個「腳本與畫面不匹配」或「配音與字幕不同步」的位置，修正後再輸出。保留所改的腳本或素材，讓下一次修改不必重新猜設定。

### 8.2 ArtCraft：先做一個有用途的補充鏡頭

當剪輯進行到某句話卻沒有畫面，才需要補素材。ArtCraft 可用文字生圖、圖像編輯與圖生影片，也提供 2D／3D 構圖工具。本練習只處理一個鏡頭，不要求先學 3D 建模。[官方功能說明](https://github.com/storytold/artcraft)

從 [ArtCraft 官網](https://getartcraft.com/)進入網頁版或下載桌面版，依服務要求登入。選擇目前帳號可使用的生圖模型，先確認點數與輸出條件。免費下載軟體不等於所有生成免費；價格頁也區分訂閱與點數購買，不以年繳平均月價當作月繳費用。[定價與點數](https://getartcraft.com/pricing)

先生成一張用於「分類材料」的畫面。以下提示詞是本講義撰寫的輸入範例，沒有宣稱已用 ArtCraft 生成：

```text
一張用於材料再利用教學影片的寫實示意圖。
木桌上分開擺放乾淨布料、完整空玻璃罐與紙盒，三組物品彼此清楚分離。
室內自然光，略微俯視，橫式 16:9，主體集中在中央，底部保留字幕空間。
不要加入文字、商標或人物臉孔，不要表現成真實活動新聞照片。
```

在結果中檢查物件是否合理、玻璃是否變形，以及是否留出字幕空間。需要修正時，可用圖像編輯或畫布工具處理指定區域；只有構圖確實需要前後景或攝影機位置時，才轉入 3D 工作方式。官方教學入口提供 2D 與 3D 編輯示範。[ArtCraft 教學入口](https://getartcraft.com/tutorials)

若仍圖已能說明內容，下載實際圖片即可。需要動態時，再選圖生影片，要求緩慢推近或輕微鏡頭移動，避免同時要求複雜動作。確定可接受費用後才生成。下載完成的檔案，保留實際副檔名，先在播放器或圖片檢視器開啟，再匯入剪輯軟體。

**本節練習**：把素材放在一句話對應的位置，檢查它是否確實增加資訊。若只是漂亮但與內容無關，回到提示詞或改用第 2 節既有圖片。使用既有圖片可以完成後製，但不代表完成了本節的生成操作。

## 9. Kdenlive：需要另一套剪輯核心時

Kdenlive 可承接影片、圖片、音訊與字幕，但不應假設能開啟 Concat 的原生專案。換工具時，先用原始素材與剪輯表重建；跨工具交換專案需另行確認相容性。

從 [Kdenlive 官網](https://kdenlive.org/)下載符合平台的版本。本節依 26.08 手冊整理。使用 **File → New** 建立專案，設定資料夾與符合來源的 1080p／25 fps；以 **Add Clip or Folder** 把原片、圖片、配樂加入 Project Bin，再拖至時間軸。Clip Monitor 看來源，Project Monitor 看目前組合的結果。[Kdenlive 入門](https://docs.kdenlive.org/en/getting_started/quickstart.html)

依第 2.2 節的來源範圍修剪片段：在時間軸以剪刀／分割工具建立邊界，刪除不用的部分，再依序放到指定成片位置。將圖片放在上方影像軌、配樂放獨立音訊軌。選取聲音片段後，以音量效果調整配樂，播放確認旁白未受影響。不要把「刪除影片片段」和「只覆蓋上方畫面」混為同一種操作。

已完成六段排列時，使用 **Sequence → Subtitles → Import Subtitle File** 匯入成片參考 SRT，選取字幕修改文字與起訖。若要重新辨識，先在 **Settings → Configure Kdenlive → Speech to Text** 準備引擎與模型，再執行語音辨識。中文稿不要勾選翻譯成英文。[字幕匯入與編輯](https://docs.kdenlive.org/en/effects_and_filters/subtitles.html)、[語音轉文字設定與使用](https://docs.kdenlive.org/en/effects_and_filters/speech_to_text.html)

用 **File → Save** 保存專案，以 **Render** 產出影片；兩者用途不同。輸出後播放檢查，再執行第 5.2 節三項修改。如果要交接整個作品，使用 **File → Archive Project** 將所需素材與專案一起封存，從封存結果重新開啟確認。[專案封存](https://docs.kdenlive.org/en/project_and_asset_management/file_management/archiving.html)

**本節練習**：沿用相同素材重建一個 20 秒片段，加入字幕與配樂，保存、關閉、重開、修改、輸出。先確認最小流程能完成，再決定是否遷移整支作品。若字幕模型無法設定，可先匯入既有 SRT 完成剪輯；語音辨識能力仍另外記為待完成。

## 10. Shotcut：用另一種介面完成相同剪輯任務

Shotcut 同樣可作剪輯核心。從 [官方網站](https://shotcut.org/)下載，先在 **New Project** 填寫 Projects Folder、Project Name 與 Video Mode，再開始匯入。手動選定幀率與解析度，可避免第一個加入的素材讓專案採用不符合目的的設定。[專案建立說明](https://forum.shotcut.org/pub/new-project)

開啟原片後，把它加入 Timeline；在播放頭位置分割，修掉不用的部分，再排列片段。需要補畫面與配樂時增加影像軌、音訊軌，分開擺放。Shotcut 支援多軌、音訊濾鏡、字幕與代理剪輯；代理檔主要改善編輯預覽負擔，不會替你修正原本的字幕或剪輯決策。[功能與編輯能力](https://shotcut.org/features/)

初次練習先做前兩段，共 20 秒。加上一行標題與配樂，使用音量濾鏡調低配樂。保存為 `.mlt` 專案，再從 **Export** 面板選輸出來源為 Timeline，使用基本預設與 **Export File** 產生影片。若誤選 Source，可能只輸出原始來源，而沒有輸出你的剪輯。[輸出基本操作](https://forum.shotcut.org/pub/export-basics)

`.mlt` 記錄編輯安排，不包含全部原始媒體。把來源檔與專案放在固定位置，關閉後重新開啟，確認圖片、音樂及片段沒有遺失。需要更深入的文字、字幕、轉場與代理操作，可由[官方教學索引](https://shotcut.org/tutorials/)選取對應主題；索引中的第三方教材不能一概當作已由團隊驗證的操作證據。

**本節練習**：只替換上方圖片而保留旁白，另輸出第二版。如果你已能在 Concat 或 Kdenlive 完成作品，不需要為了工具數量再做一套；本節供環境或操作偏好不合時選用。

## 11. FilmCraft：以小作品試用新剪輯環境

FilmCraft 官方列出剪輯、調色、混音、字幕與輸出能力，同時明確標示 Alpha，並指出真實素材與部分平台測試仍有限。因此本節以副本、小片段與可回復的練習為範圍，不先把唯一正式專案交給它。[官方狀態與限制](https://github.com/storytold/filmcraft#status)

從 [官方 Releases](https://github.com/storytold/filmcraft/releases)選擇實際提供的安裝檔。進入後建立新專案，匯入原片與圖片，把原片前 20 秒放到時間軸，再於上方加一張 5 秒圖片。基本流程依官方能力整理；本版未逐一核對每個桌面版本的選單位置，找不到對應入口時請查該版文件，不用猜測快捷鍵。

FilmCraft 的原生專案副檔名為 `.fcproj`。先保存專案，再加入字幕：官方文件說明 **File → Import** 或拖入 SRT 可建立字幕軌，**Text** 面板可修改文字及時間；**File → Export → Captions…** 可輸出字幕。若使用第 2 節原片 SRT，只留下前 20 秒會用到的字幕，不能讓後面原片字幕延長輸出範圍。[專案格式](https://github.com/storytold/filmcraft/blob/main/docs/project-files.md)、[字幕操作](https://github.com/storytold/filmcraft/blob/main/docs/captions.md)

接著輸出 H.264 MP4，關閉軟體，再重開 `.fcproj` 修改一行字幕並重新輸出。若畫面或聲音異常，先保留原始素材與錯誤現象，再以較短片段定位問題。這個結果只代表你測試的版本、平台與素材，不推論所有手機影片都能順利處理。

官方提供多種時間軸交換格式，但不同軟體對效果、字型與音訊處理的解讀仍需實際確認。本課不把「可匯出 XML／AAF／OTIO」寫成跨軟體無損交換保證。

## 12. 把工具串起來時，保留修改的入口

### 12.1 最少工具的交付方案

已有素材時，先在 Concat 完成第 3–5 節。中文配音若不合需要，才用 yovoice 或 VoiceStudio 生成獨立音檔；畫面不足時，才由 ArtCraft 補充。每加一個工具，都說清楚它要補什麼，以及交回哪一個檔案。

| 交接來源 | 優先保留 | 接收端的第一個檢查 |
|---|---|---|
| 配音工具 | 獨立旁白音檔、文字與模型／聲音資訊 | 試聽發音與時長，再安排字幕 |
| ArtCraft | 下載的原始圖／影片與提示詞 | 實際檔案可開啟、比例適用、內容合理 |
| AutoClip | 候選片段、來源起訖、實際提供的字幕 | 是否保留原意，字幕時間對應哪支片 |
| MoneyPrinterTurbo | 腳本、使用素材、可取得的聲音與字幕 | 能否局部修改，還是只有合成 MP4 |
| 剪輯核心 | 原生專案、來源素材、成片 SRT 與 MP4 | 重開後可定位素材，輸出可播放 |

這是交接時應爭取的材料，不保證每款工具都會輸出全部項目。若只能取得合成影片，先確認修改需求是否仍做得到，再決定繼續後製或回來源重建。

### 12.2 常見問題，分別回到正確位置

| 現象 | 先檢查 | 修正後從哪裡繼續 |
|---|---|---|
| 字幕全部晚了十秒 | 是否套到原片 SRT，或少算刪除片段的時間 | 修正成片時間碼，再匯入字幕 |
| 配樂降了，旁白也一起變小 | 是否只有混合音軌，或同時選取多個聲音物件 | 找回獨立旁白／配樂，再混音 |
| 換圖片後旁白不見 | 是否刪掉底下含聲音的影片 | Undo，保留底層聲音，改用上方覆蓋 |
| 雲端工具開始就失敗 | 模型權限、連線測試、額度與輸入格式 | 從失敗的服務設定處理，不先重裝剪輯軟體 |
| 輸出成功但朋友看不到字幕 | 是否只附 SRT，播放器未載入 | 明確選擇燒入字幕或教對方載入字幕 |
| 重開專案顯示素材遺失 | 原檔位置與名稱是否改變 | 恢復原路徑或重新定位，確認後再輸出 |

### 12.3 完成作品與完成工具操作分開核對

交付時至少檢查：影片可以從頭播放、語句完整、字幕可讀、旁白清楚，以及專案重開後能完成一次局部修改。若某個 AI 功能無法使用，利用既有素材仍能完成後製，但應如實記錄該 AI 操作尚未完成。

本講義最終要留下的能力，是能從需求選工具、看出生成結果的問題，並保留足以修正作品的材料。當你收到「改一句字幕、換一個鏡頭、降低音樂」的要求時，應能找到該改的物件，而不用把整支影片從零重做。
