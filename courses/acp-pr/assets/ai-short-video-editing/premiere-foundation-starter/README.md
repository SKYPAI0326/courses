## 使用方式

CH0-1 從空白 Premiere 專案匯入全部檔案，以 `clip-01-lighthouse.mp4` 建立第一個序列。CH0-2 依 `../foundation-practice-card-v1.md` 建立副本並操作。

## 備援

若 MP4 無法播放，先用 Windows 播放器確認檔案，再檢查 Premiere 的 H.264 解碼環境。PNG 與 WAV 可分別用來驗證影像與音訊匯入，避免把單一 codec 問題誤判為整包素材損壞。
