先分四個作用層級

專案層Project item、bin、sequence item、媒體連結、未使用項目。

常看：Project panel、Usage、Link Media、Project Manager。
序列層畫面尺寸、幀率、軌道、In／Out、sequence marker、Auto Reframed Sequence。

常看：Sequence Settings、Timeline、Markers。
片段層位置、長度、速度、連結、效果、音量、clip marker。

常看：Timeline、Properties／Effect Controls、Source Monitor。
輸出層格式、codec、尺寸、範圍、檔名與儲存位置。

常看：Export、Export Summary、輸出後檔案。
先看物件，再看動詞。「改名」可能作用在 Project item，不代表改磁碟檔名；「marker」可能屬於 source clip 或 sequence；「靜音」可能作用在 audio clip 或整條 audio track。
分類規則：功能家族可以重疊。只要理由能對應作用物件、功能入口與驗證方式，可回答一個或多個家族，不因家族不同就直接判錯。

七個功能家族

家族代表物件常見入口先分清楚完成證據
1. 專案與素材管理Project item、bin、sequence item、媒體連結Project panel、Link Media／Locate、Project Manager移除 Project item 不等於刪除磁碟來源階層、名稱、Usage、序列可播放、來源檔仍存在
2. 序列、時間碼與軌道sequence、video／audio track、sequence markerNew Sequence、Sequence Settings、track headers、Markers、Auto Reframe修改原序列設定與建立新 Auto Reframed Sequence 的結果不同序列名稱、尺寸、幀率、軌道數、marker 起點與長度
3. 時間軸剪輯與片段關係timeline clip、edit point、linked components、nested sequenceTimeline、Tools、Clip、Source Monitor、Program Monitor位置、duration、speed、後方內容是否移動是不同結果In／Out、序列總長、gap、Speed、影音同步、nest 內容
4. Properties／Effect Controlstimeline clip、effect、property、keyframeProperties／Effect Controls、Effects panel套用效果與調整參數是兩個步驟；必須先選對片段數值、keyframe 時間、未要求的 Position／Anchor Point 保持原值
5. 音訊、連結與軌道狀態audio component、audio clip、audio track、音量屬性Timeline、track headers、Effect Controls、Audio Track MixerClip Volume、Audio Gain、Track Mute、Clip Enable 不相同軌道位置、M／S、音量、淡出長度、影音同步
6. 文字、字幕與轉錄graphic text、caption segment、sequence transcript、pause rangeText、Properties／Essential Graphics、Captions、Transcript畫面文字、caption、transcript 是相關但不同的物件Program Monitor 可讀性、文字內容、時間範圍、刪除後有無 gap
7. 影像規格、效果與輸出sequence、effect、export fileSequence Settings、Effects、Lumetri Color、Exportcontainer 與 codec 不同；序列尺寸與輸出尺寸要分開核對Export Summary、副檔名、Frame Size、Frame Rate、Range、外部播放
三組重疊案例：Mute 可歸家族 2／5；Link／Unlink 可歸家族 3／5；Auto Reframe 可歸家族 2／7。判分看理由與驗證，不看是否只寫唯一家族。
