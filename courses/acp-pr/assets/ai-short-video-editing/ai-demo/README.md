# AI 短影音固定示範素材 v1

## 核心檔案

- `ai-short-video-demo-01.mp4`：120 秒、1920 × 1080、25 fps，中文語音。
- `ai-short-video-demo-01-raw-practice.srt`：含三個刻意錯誤的練習版。
- `ai-short-video-demo-01-v1.srt`：教師答案與工具不可用時的正確版。
- `ai-short-video-demo-script-v1.txt`：逐句時間碼與原文。
- `ai-mini-cut-reference.mp4`：24.9 秒、1080 × 1920 的固定參考成片。
- `ai-mini-cut-caption-fallback-v1.srt`：參考成片字幕。

## 課堂路徑

1. 轉錄工具可用：用 MP4 轉錄，輸出候選 SRT，再與 v1 核對。
2. 轉錄工具不可用：從 raw practice SRT 開始修正，另存 v1。
3. 生成式 AI 可用：使用 `../prompt-card.md` 取得候選。
4. 生成式 AI 不可用：使用 `../decision-table-fixed-output-v1.md`，仍完成回聽、取捨與 Premiere 執行。

## 版本限制

現場使用的 AI 服務、登入方式、隱私政策與方案仍須填入服務卡。固定素材只解除內容與網路依賴，不代表任何外部服務已核准。
