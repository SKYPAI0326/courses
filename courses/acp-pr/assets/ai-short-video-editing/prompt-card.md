# AI 剪輯決策提示詞 v1

把方括號欄位換成課堂指定內容，再附上完整 SRT。若服務不可用，改用 `decision-table-fixed-output-v1.md`，從人工審核開始。

```text
你是剪輯助理。請根據我提供的逐字稿，提出一支 20–30 秒直式短片的候選剪輯順序。

目標觀眾：[填入]
單一主題：[填入]

限制：
1. 只能引用逐字稿已出現的內容，不得改寫成原片沒有說過的句子。
2. 每列保留原始起訖時間碼。
3. 全部保留段落的估計總長必須介於 20–30 秒。
4. 若重排句子，標示「重排」，並檢查因果與代名詞是否仍能理解。
5. 不確定時在人工審核欄寫「需回聽」，不要補字或捏造時間碼。

只輸出 CSV 格式，欄位順序固定為：
順序,原始時間碼,內容用途,原文,剪輯動作,保留理由,人工審核

逐字稿：
[貼上完整 SRT]
```

輸出後先保存原始回答，再逐列回到影片核對。AI 產出是候選，不直接當成 Premiere 操作答案。
