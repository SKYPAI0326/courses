看懂 Premiere 的工作流程

能建立並重開 Premiere 專案、匯入固定素材、建立序列，並用自己的話區分原始媒體、Project item、source clip、sequence 與 timeline clip。

本單元完成證據
保存 ACP-PR-你的座號-v1.prproj，並能指出原始媒體、Project item、Source clip、Sequence 與 Timeline clip 的差異。

故事起點：你剛收到一包 Premiere 練習素材，任務是把它整理成之後每一個剪輯練習都能重開的工作專案。先把檔案、專案項目、來源檢視器與時間軸中的片段分清楚，後面才知道自己改到哪一層。

Premiere 不會把所有影片「裝進」專案檔。專案檔比較像工作紀錄：它記得素材放在哪裡、時間軸怎麼排、效果改了什麼。先理解這個關係，後面遇到改名、離線素材、序列或片段題目時，才不會改錯對象。

本單元完成後，你會留下 ACP-PR-你的座號-v1.prproj，並能指出一段影片從硬碟進入 Premiere 到成為時間軸片段的路徑。

先認識五個不同物件

先用這張表分辨硬碟來源、專案引用與時間軸實例，避免後面改錯層級。

名稱 白話意思 改動時會影響什麼
原始媒體 Windows 資料夾裡的 MP4、WAV、JPG 真正的來源檔；移動或刪除可能讓專案離線
Project item Project 面板中的素材項目 專案如何引用素材；改名通常不會改磁碟檔名
Source clip 在 Source Monitor 開啟的來源 設 In／Out、看來源內容、加 clip marker
Sequence 一套時間軸設定與剪輯結果 畫面尺寸、幀率、軌道與排列
Timeline clip 素材放入序列後的一個實例 可裁切、移動、套效果；不會直接剪壞原始媒體

先記住一句話：同一支原始影片可以在 Project 面板出現一次，卻在不同序列或同一序列中成為多個 timeline clips。

建立可重開的專案

先固定資料夾、專案名稱與儲存位置，讓後續每個操作都有可回復起點。

  1. 下載 premiere-foundation-starter.zip，解壓縮到自己的作業資料夾；確認看得到 premiere-foundation-starter/media/。
  2. 在 Windows 先播放其中一支 MP4，確認有畫面與聲音。
  3. 開啟 Premiere Pro 2024，選 New Project。
  4. 名稱輸入 ACP-PR-你的座號-v1；Location 指向自己的作業資料夾。
  5. 建立後立即按 Ctrl+S。

快速檢查：Windows 作業資料夾中看得到 .prproj。若沒有，使用 File > Save As 重新指定位置。

匯入素材並找到核心面板

按 Ctrl+I 匯入練習包中的影片、音訊與圖片。先只找六個位置：

  • Project（專案素材區）：找素材與序列。
  • Source Monitor（來源預覽區）：查看原始素材與來源時間碼。
  • Program Monitor（成片預覽區）：查看目前序列在播放頭位置的結果。
  • Timeline（時間軸）：排列與修改 timeline clips。
  • Properties／Effect Controls（屬性／效果控制）：修改被選取片段的數值。
  • Tools（工具列）：選取、Razor、Ripple 等時間軸工具。

如果畫面與教師不同，先選 Window > Workspaces > Editing。若某面板仍不見，到 Window 選單依名稱打開；不要亂拖全部面板重排。

從素材建立第一個序列

在 Project 面板選一支指定 MP4，右鍵選 New Sequence From Clip，再把新序列改名為 foundation-main-v1。

這個動作同時建立：

  1. 一個跟隨素材設定的 sequence。
  2. 一個放在該 sequence 中的 timeline clip。

雙擊 Project 面板中的原始 MP4，Source Monitor 顯示來源；再點 Timeline 中的片段，Program Monitor 顯示序列結果。兩個 Monitor 看起來可能相同，但代表的物件不同。

完整示範：同一個檔案如何變成五種可辨認狀態

請依照下面五個步驟，把同一支影片從電腦上的檔案帶進 Premiere， 再放進序列中。每完成一個步驟，先核對列出的結果，再進入下一步； 這樣你會看見「同一支影片」在不同位置代表不同物件。

  1. 確認原始媒體：在 Windows 檔案總管開啟 starter 的 media 資料夾，雙擊 clip-01-lighthouse.mp4。確認播放器能開啟影片，畫面與聲音都正常， 而且影片長度約 12 秒。這一步確認的是電腦上的原始檔案，不是 Premiere 裡的項目。
  2. 建立 Project item：回到 Premiere，按 Ctrl+I 匯入同一個 MP4。確認 Project 面板出現 clip-01-lighthouse.mp4。這表示專案記住了該檔案的位置與使用關係； 原始影片仍留在 Windows 的 media 資料夾，沒有被複製進 .prproj 檔，也沒有另外產生一份影片副本。
  3. 查看 Source clip：在 Project 面板雙擊剛匯入的項目， 讓它出現在 Source Monitor。把播放頭拖到開頭與結尾各查看一次，確認這裡顯示的是 完整原始影片，而不是時間軸目前使用的片段範圍。你不需要等待影片從頭播到尾。
  4. 建立 Sequence：在 Project 面板選取該 MP4，右鍵選 New Sequence From Clip。確認新序列出現在 Project 面板， 並將它改名為 foundation-main-v1。這個序列會依素材設定建立時間軸。
  5. 確認 Timeline clip：開啟 foundation-main-v1，確認 V1 與 A1 各出現一段片段。點選時間軸上的片段， 再看 Program Monitor；這裡顯示的是該片段在此序列中的使用範圍。你現在選到的是 時間軸實例，後續裁切只會改變這個序列，不會改掉 Source Monitor 的原始影片。

最後把 timeline clip 結尾縮短約兩秒，再回到 Source Monitor 播放來源結尾。預期結果是 Program Monitor 的序列變短，但 Source Monitor 仍看得到完整來源。若兩者都變短，先停止操作並用復原卡回到安全狀態。

跟著做：證明原始素材沒有被剪壞

用一次可復原的小裁切，觀察 timeline clip 與 source clip 的差別。

  1. 在 Timeline 選取片段，將結尾向內拖短約兩秒。
  2. 播放 Program Monitor，確認序列結果變短。
  3. 雙擊 Project 面板中的原始 MP4，在 Source Monitor 拖到原本結尾。
  4. 確認來源仍完整。
  5. 按 Ctrl+Z 回復，並儲存專案。

你應該看到：Timeline 的操作只改 sequence 中的片段使用範圍；Source Monitor 仍可看到完整來源。

專案檔與媒體檔為什麼要放固定位置

關閉 Premiere，把練習 MP4 暫時移到同一資料夾內的 temp 子資料夾，再重開專案。若看到 Media Offline，代表專案記錄的素材位置失效；這不是影片被刪掉，也不是時間軸內容消失。

使用 Locate／Link Media 指向新位置後，再把檔案放回正式素材資料夾並重新連結。請只做有明確回復步驟的版本，完成後用復原卡回到原始狀態。

自己完成：五物件定位

不看前表，依序指出：

  1. Windows 中的原始 MP4。
  2. Project 面板中的同名項目。
  3. Source Monitor 顯示的來源。
  4. Project 面板中的 foundation-main-v1。
  5. Timeline 中被選取的片段。

對每一項說出「它是什麼」與「改它可能影響哪裡」。答不出時，重新用雙擊素材、雙擊序列與選取 timeline clip 比較。

完成檢查

交付前確認：五項都成立，代表你已建立可重開的專案，也知道後續操作會改到來源、序列或時間軸中的哪一層。

交給下一章：保留 foundation-main-v1 作為安全原版。下一章會複製這個序列，再用副本比較不同時間軸工具造成的結果。
