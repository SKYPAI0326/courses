## 與題庫的邊界

Premiere Pro 認證題庫及其簡報維持獨立。5 小時模組只建立理解題庫所需的功能地圖與讀題方法；指定專案、逐題操作與評分條件留在後續 4 小時題庫講解。本課修改不會自動重建題庫簡報。
