# Adobe ACP After Effects 課程網站

這是可獨立開啟的靜態課程網站。從 `index.html` 開始，無需安裝套件或執行建置工具；首頁列出看懂介面、完成六秒標題動畫與熟悉基本題型三項完成標準。

## 專案內容

- 課程首頁與 Part 1–3 單元總覽
- 介面與功能補充講義
- `part1`、`part2`、`part3` 課程頁面
- `assets/handout.css`、`assets/handout.js` 共用資源
- `assets/downloads/` 講義下載教材與補充講義使用的獨立六秒標題動畫 `.aep` 練習專案；不接續正課的 `ACP-AE-Lab` 連續工程
- `assets/screenshots/` AE 2026 實際工作區與動畫中段截圖；舊版 CC 2019 局部圖保留但已不在講義引用

## 開啟方式

在瀏覽器開啟 `index.html`。頁面字型會嘗試載入 Google Fonts；沒有網路時會使用系統備援字型。

## 專案範圍

本資料夾整理課程網站與其頁面資源。AE 練習工作包保留在上層資料夾；網站下載區另附一個補充講義用的獨立練習專案，不取代正課的 `ACP-AE-Lab` 連續工程。
