# ACP After Effects 單元講義規格

本文件定義每個單元要寫入正式學員正文的任務、方法、示範、練習與驗收。時間與講師調度只留在本設計文件，後續學員頁不顯示授課排程。

## 共用頁面結構

每個 skill-operation 單元使用以下內容順序，但標題依實際內容命名：

1. 問題與本單元完成物。
2. 起始材料與取得方式。
3. 完成畫面或設定的預覽。
4. 必要概念與作用層級。
5. 完整示範，包括輸入、操作、中間狀態與最後結果。
6. 引導練習，撤除部分步驟提示。
7. 獨立或條件變化練習。
8. 完成檢查與錯誤修復。
9. 對應題號與課後使用方式。

操作題卡統一顯示：任務動詞、作用對象、作用層級、指定值或時間、不得改動項目、完成證據、復原位置與版本備註。

## CH1-1 介面 Project 與 Composition 規格

**時數與課型**：45 分鐘，`skill-operation`<br>
**任務**：依規格建立 `Square_Practice` Composition，並指出 Project、Composition、Timeline 與目前選取的 Layer。<br>
**完成物**：一個 1080 × 1080、29.97 fps、10 秒、名稱正確的 Composition，以及設定截圖。

### 任務契約

| 欄位 | 設計內容 |
|---|---|
| 起始材料 | 可啟動的 AE、空白 Project、規格卡 |
| 第一個動作 | 建立新 Project 並立即另存到個人練習資料夾 |
| 第一個結果 | 視窗標題顯示已儲存的工程名稱，Project 面板可見 |
| 核心方法 | 分辨素材容器、畫面容器、時間容器與圖層實例；以單位判讀尺寸、fps 與 duration |
| 完成檢查 | 名稱、寬高、fps、duration、背景設定逐項相符 |
| 修復位置 | Composition Settings；工作區混亂時使用 Workspace Reset |

### 教學證據

- Demo：由一張完成畫面反推 Composition 尺寸與影格率，再完整建立。
- Together：依第二張規格卡建立橫式 Composition，學員自行輸入尺寸與時間。
- Solo：只提供目標規格，建立直式 Composition 並截取設定證據。
- 題目銜接：操作題 1、2、7、11、13、28、35。

## CH1-2 素材圖層 Timeline 與 Transform

**時數與課型**：60 分鐘，`skill-operation`<br>
**任務**：建立文字、Shape 與 Solid，整理圖層名稱、順序、顯示、鎖定及 Label，將標題移到指定位置。<br>
**完成物**：Timeline 結構清楚的練習 Composition，另一位學員能依名稱找到目標圖層。

### 任務契約

| 欄位 | 設計內容 |
|---|---|
| 起始材料 | CH1-1 工程、自製背景圖、授權字型或系統替代字型 |
| 第一個動作 | 將素材匯入 Project 面板並放入 `Assets` 資料夾 |
| 第一個結果 | Project 面板出現素材縮圖，沒有 Missing Footage |
| 核心方法 | 同一素材可在 Composition 中成為多個 Layer；Timeline 上方圖層覆蓋下方圖層；Transform 修改選取圖層 |
| 完成檢查 | 名稱、順序、眼睛、鎖定、Label、Position、Scale 與 Anchor Point 符合規格 |
| 修復位置 | 先核對選取圖層，再檢查 Timeline 開關欄與 Transform 屬性 |

### 教學證據

- Demo：拆解完成畫面的前後層次與 Transform，重建三層標題卡。
- Together：保留相同素材，撤除圖層排序提示，要求依完成畫面重排。
- Solo：更換文字與圖片，自行建立可辨識的圖層結構。
- 題目銜接：操作題 3、6、9、10、15、17、20、22–26、30–32、36、37。

## CH1-3 Keyframe 時間控制與動畫節奏

**時數與課型**：75 分鐘，`skill-operation`<br>
**任務**：讓標題在 0–2 秒移入、2–4 秒縮放、4–6 秒淡出，並把移動段落設為 Easy Ease。<br>
**完成物**：6 秒動畫片段，時間與屬性變化均可在 Timeline 核對。

### 任務契約

| 欄位 | 設計內容 |
|---|---|
| 起始材料 | CH1-2 工程、動畫時間表、完成預覽 |
| 第一個動作 | 把 CTI 移到 0 秒，展開目標圖層 Transform |
| 第一個結果 | Timeline 顯示 Position、Scale、Opacity，可辨認目前時間 |
| 核心方法 | Keyframe 記錄屬性在特定時間的值；CTI、屬性秒錶與菱形按鈕各有不同作用 |
| 完成檢查 | 指定時間到達指定值，無多餘 Keyframe，Easy Ease 套在正確區段 |
| 修復位置 | 先停在指定時間核對屬性值，再處理多餘 Keyframe 或插值 |

### 教學證據

- Demo：由完成動畫反推三段時間與屬性，再完整重建。
- Together：保留動作，改成新的開始與結束位置，學員自行建立 Keyframe。
- Solo：將 6 秒節奏改為 5 秒，說明哪些 Keyframe 需要移動及原因。
- 補充操作：Work Area、In／Out Point、Time-Reverse Layer、Time Remapping 與 Freeze Frame。
- 題目銜接：操作題 4、5、7、14、27、33、36、38。

## CH1-4 Mask Matte Blending Effects 與色彩

**時數與課型**：45 分鐘，`skill-operation`<br>
**任務**：使用同一組素材比較 Mask、Track Matte、Blending Mode 與 Adjustment Layer 的作用結果，完成一個文字揭露。<br>
**完成物**：四個可切換比較的 Composition，標示每種方法控制哪個範圍。

### 任務契約

| 欄位 | 設計內容 |
|---|---|
| 起始材料 | 自製文字、光束、材質與背景圖層 |
| 第一個動作 | 複製基準 Composition，保留一份未修改版本 |
| 第一個結果 | Project 面板有可比較的基準版與操作版 |
| 核心方法 | Mask 修改單一圖層可見區域；Matte 使用另一圖層的 Alpha 或亮度；Blending 改變像素混合；Adjustment Layer 影響下方圖層 |
| 完成檢查 | 操作對象、作用範圍、數值與完成畫面相符 |
| 修復位置 | 先關閉效果或模式回到基準，再核對圖層順序、Matte 來源與 Effect Controls |

### 教學證據

- Demo：使用同一畫面逐一比較四種方法，說明選擇理由。
- Together：指定要「只顯示圓形範圍」，學員判斷使用 Mask 並調整 Feather。
- Solo：指定「用另一個圖層控制光束顯示」，學員選擇 Matte 並核對來源。
- 題目銜接：非操作題 11、12；操作題 3、6、12、19、27、32–34、39、40。

## CH1-5 3D Camera 音訊 Render Queue 與輸出

**時數與課型**：45 分鐘，`skill-operation`<br>
**任務**：辨認 3D Layer 與 Camera 的用途，設定音訊，將指定 Work Area 加入 Render Queue 並核對輸出設定。<br>
**完成物**：Render Queue 設定證據與短測試輸出。

### 任務契約

| 欄位 | 設計內容 |
|---|---|
| 起始材料 | 前課工程、短音訊、輸出規格卡 |
| 第一個動作 | 播放工程並確認 Work Area、畫面與音訊存在 |
| 第一個結果 | Preview 可播放指定區段，Audio Meter 有反應 |
| 核心方法 | Composition Settings 定義工作畫布；Render Settings 決定渲染品質與範圍；Output Module 決定格式與通道 |
| 完成檢查 | Quality、Resolution、Time Span、音訊、格式與輸出位置符合規格 |
| 修復位置 | 看到格式時在 Output Module；看到品質與範圍時在 Render Settings |

### 教學證據

- Demo：比較 Composition Settings、Render Settings 與 Output Module。
- Together：依第一張交付規格設定短輸出。
- Solo：更換 Resolution 與輸出範圍，留下設定截圖。
- 3D 與 Camera 以辨識與短示範為主，不在本時數要求獨立攝影機動畫。
- 題目銜接：非操作題 4、5；操作題 8、16、18、21、29、31。

## PRAC1 六秒標題動畫整合

**時數與課型**：30 分鐘，`integration-capstone`<br>
**任務**：依完成預覽、素材包與驗收表，完成一段 6 秒標題動畫。<br>
**完成物**：可重開的 `.aep`、6 秒預覽檔、設定檢核表。

### 整合條件

- 由學員自行決定圖層建立與動畫安排順序。
- 必須使用文字或 Shape、至少兩種 Transform Keyframe、Easy Ease、Mask 或 Matte、一項 Effect。
- 輸出前核對 Work Area、圖層顯示、音訊、Resolution 與輸出位置。
- 完成版與起始版分開保存，素材不得離線。

### 驗收與修訂

- 畫面：指定元素在指定時間出現，沒有意外遮擋。
- 工程：圖層名稱清楚，無多餘空白圖層或失效效果。
- 動畫：時間與完成預覽一致，無多餘 Keyframe。
- 輸出：長度 6 秒，Resolution 與格式符合規格。
- 修訂：依檢核表只修改不合格項目，再重新輸出。

## CH2-1 十三題概念判斷

**時數與課型**：60 分鐘，`concept`<br>
**任務**：完成 13 題解析表，每題寫出答案、題幹線索、判斷依據與排除理由。<br>
**完成物**：個人解析表與易混淆清單。

### 三組判斷方法

1. 視覺與製作流程：以畫面位置、製作階段、動態變化或色彩目的判斷。
2. 權利與無障礙：先確認權利主體、使用條件與使用者能觀察到的輔助功能。
3. 媒體與 AE 概念：先看單位、圖層作用範圍、堆疊關係與時間狀態。

### 練習設計

- Demo：完整解析一題，示範如何從題幹找到線索並排除干擾項。
- Together：每組共同完成一題，必須說明排除理由。
- Solo：完成其餘題目並標記最不確定的三題。
- 訂正：答案字母不計入完整證據；訂正必須補理由。

## CH3-1 操作題 1–13

**時數與課型**：60 分鐘，`skill-operation`<br>
**同步實作**：題 1 建立 Composition、題 7 Work Area 與 Trim、題 10 Timeline 圖層管理。<br>
**路徑解析**：題 2–6、8–9、11–13。

### 能力增量

- 把題目拆成對象、數值、時間、指令與不得改動項目。
- 先判斷操作作用於 Composition、圖層或檢視狀態。
- 完成後逐項核對，不以畫面「看起來差不多」取代規格。

### 支援遞減

- 題 1 提供完整任務卡與示範。
- 題 7 只提供操作入口與完成證據。
- 題 10 只提供題目與驗收清單，學員自行安排順序。

## CH3-2 操作題 14–27

**時數與課型**：60 分鐘，`skill-operation`<br>
**同步實作**：題 14 Time Remapping、題 17 Parenting、題 27 Radial Blur 動畫。<br>
**路徑解析**：題 15–16、18–26。

### 能力增量

- 分辨素材解讀、Layer 屬性、Effect 與時間屬性的操作位置。
- 保留既有 Keyframe 或既有圖層狀態，只修改題目指定部分。
- 用時間和值的前後狀態驗證動畫效果。

### 支援遞減

- 題 14 提供時間示意圖與完整復原點。
- 題 17 提供目標 Parent 關係，學員自行定位欄位。
- 題 27 只提供起訖時間、效果值與驗收條件。

## CH3-3 操作題 28–40

**時數與課型**：60 分鐘，`skill-operation`<br>
**同步實作**：題 29 Photoshop Sequence 輸出、題 38 Transform 與 Easy Ease、題 40 Beams Matte。<br>
**路徑解析**：題 28、30–37、39。

### 能力增量

- 在多條件任務中安排安全順序，避免前一個操作破壞後一個條件。
- 分辨 Render Settings 與 Output Module。
- 完成後檢查輸出、可見性、圖層狀態與指定動畫。

### 支援遞減

- 題 29 使用兩個對話框的比較圖與完整示範。
- 題 38 只提供時間和值，學員自行建立 Keyframe 與 Ease。
- 題 40 只提供完成畫面與遮蔽條件，學員自行決定 Shape 位置與大小。

## 講師授課筆記 不進講義

- 每個 60 分鐘操作題單元先用 10 分鐘掃描全組題目，集中時間完成 3 題代表題，最後用路徑表收束其餘題目。
- 代表題必須使用已驗證起始工程。缺少工程時，只能完成讀題與路徑分析，不能記錄實作通過。
- 學員同時卡住時，先要求指出目前作用層級與選取對象，再提供下一個介面位置。
- 每完成一題立即另存復原點，避免後續題目污染原始狀態。
