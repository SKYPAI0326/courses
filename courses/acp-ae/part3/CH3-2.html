(01)

Step by Step：先判斷作用層級

第一個動作
另存 ACP-AE-Q14-27.aep。每題先完成六步定位，再動手修改。
01
圈出動詞與完整對象
例如「修改 footage 影格率」，不要只抄「影格率」。
02
寫下層級字母
標記 P（Project）、C（Composition）、L（Layer）、E（Effect）或 T（Time）。
03
寫出進入點
指出第一個要開啟的面板，例如 Project、Timeline 或 Effect Controls。
04
抄下條件
記錄數值、時間與不得改動的項目。
05
寫出完成畫面
先決定最後要看到哪個屬性、畫面或檔案。
06
寫復原位置
在操作前寫下 Undo、Reset、None 或題組副本。說不出第一個選取對象時先停下。

(03)

Step by Step：三題代表題

Q14
Time Remap 停格
  1. 複製 PRAC1_Title_6s 為 Q14_Freeze，放進測試 Composition。
  2. 選圖層後執行 Layer > Time > Enable Time Remapping。
  3. 3 秒建立 Keyframe，把同一時間值複製到 5 秒。
  4. 播放 3–5 秒，確認保持同一內容時間。
  5. 卡住時：停用 Time Remapping 或從副本重開。
Q17
Parenting
  1. 建立 Shape Layer 並命名 CTRL_Parent。
  2. 記錄 Title_Text 與 Accent_Shape 的 Position。
  3. 把兩層 Parent 設為 CTRL_Parent。
  4. 只移動 Parent，確認兩層保持相對距離。
  5. 卡住時：跳位就 Undo，Parent 設回 None。
Q27
Effect Keyframe
  1. 複製 FX_Adjust 為 Q27_Blur。
  2. 套用 Radial Blur，在 Effect Controls 找 Amount。
  3. 設 0 秒 = 0、2 秒 = 35、4 秒 = 0。
  4. 關閉 Effect 做 A/B 比較並留下三個時間點證據。
  5. 卡住時：確認 Keyframe 在 Effect 下，不在 Transform 下。
(04)

Step by Step：變式與修復

變式練習
  1. 從題 15–16、18–26 選三題。
  2. 每題只改一個名稱或數值。
  3. 先標 P、C、L、E 或 T，並寫第一個選取對象。
  4. 完成後核對是否仍在相同層級。
  5. 通過標準：三題都有路徑、證據與復原位置。
修復
Interpret Footage 與 Composition fps 混淆
回 Project 面板的 footage，不用 Composition Settings 代替。
Parent 後跳移
Undo，核對父層與其初始位置，再重設關係。
Effect 動畫沒變
查兩個以上不同數值、CTI 時間與 Effect 開關。
