(08)

操作題 1–13：Composition、圖層與介面狀態

先讀題定位，再在 ACP-AE-Q01-13.aep 實作題 1、7、10；其餘完成作用層級、路徑、證據與復原卡。

學習成果
完成 13 張操作路徑卡。
實作 Composition 建立、Work Area/Trim、Timeline 圖層管理。
每題用數值、開關或畫面狀態驗收。
(01)

Step by Step：先讀懂每一張操作題

第一個動作
將 ACP-AE-Lab-PRAC1.aep 另存為 ACP-AE-Q01-13.aep。進入 AE 前先完成下列六步，不要用滑鼠猜功能。
01
找動詞
圈出建立、修改、刪除、修剪或檢視。動詞決定你要做的動作。
02
找完整對象
抄下完整名稱，例如 Title_Text，不要只寫「圖層」。
03
判斷作用層級
確認要在 Project、Composition、Timeline、View 或 Render Queue 操作。
04
抄下數值與時間
逐項記錄寬高、fps、duration、Position 或 Work Area。
05
圈出不能改的項目
例如「不改 Composition」或「保留原 Keyframe」，都要另行標記。
06
先寫證據與復原位置
知道完成後要拍哪裡、出錯要回哪裡，才開始操作。任何一欄不確定就先停下。
(02)

十三張路徑卡

Q01

依規格建新 Composition

實作

層級 Composition　路徑 Composition > New Composition　證據 名稱、寬高、fps、duration　復原 Composition Settings

Q02

檢查 Action Safe 與越界元素

層級 View + Layer　路徑 開 Safe Margins，再移動或刪指定層　證據 指定區不再越界　復原 Undo/Position

Q03

紋理圖層混合

層級 Layer Mode　路徑 Timeline Modes 欄　證據 Mode 名與前後差異　復原 Normal

Q04

圖層反向播放

層級 Layer Time　路徑 Layer > Time > Time-Reverse Layer　證據 起訖畫面交換，層長不變　復原 Undo

Q05

階段式 Position 動畫

層級 Transform Keyframe　路徑 起終時點設 Position　證據 指定時間的值　復原 Position Keyframe

Q06

椭圓 Mask 可見區

層級 Mask　路徑 選層後用 Ellipse Tool　證據 Masks > Mask 1　復原 Mask Path/Feather

Q07

Work Area 與 Trim Composition

實作

層級 Composition Time　路徑 設 Work Area，再 Trim Comp to Work Area　證據 duration 與原 Work Area 一致　復原 立即 Undo/前一版

Q08

自訂 Render Settings

層級 Render Queue　路徑 Add to Render Queue > Render Settings　證據 Quality、Resolution、Time Span　復原 刪 render item 重加

Q09

修改現有文字

層級 Text Layer　路徑 Type Tool/Text 屬性　證據 畫面文字正確　復原 Undo/原文

Q10

Timeline 圖層管理

實作

層級 Timeline　順序 先建層，再命名與排序，最後設定 Label 與 Lock　證據 Timeline 全圖　復原 副本或 Undo

Q11

Composition 視圖與 Resolution

層級 View　路徑 Composition 面板下方 View Layout/Resolution　證據 介面值　復原 1 View/Auto

Q12

亮部圖層 Blending Mode

層級 Layer Mode　路徑 Timeline Modes　證據 Mode 欄與畫面亮部　復原 Normal

Q13

橫式 Logo Composition

層級 Composition　路徑 New Composition　證據 名稱、寬高、fps、duration　復原 Composition Settings

(03)

Step by Step：三題代表題

Q01
新建 Composition
  1. 在路徑卡寫 Q01_Square、1080 × 1080、29.97 fps、10 秒。
  2. 選 Composition > New Composition 並逐欄輸入。
  3. 關閉後重開 Composition Settings 核對五欄。
  4. 擷取 Settings，另存 Q01-done.aep。
  5. 卡住時：只修正錯誤欄；若改到原工程，停止保存。
Q07
Work Area 與 Trim
  1. 複製 PRAC1_Title_6s 為 Q07_Trim。
  2. 把 Work Area 設為 1–5 秒並先留證。
  3. 選 Composition > Trim Comp to Work Area。
  4. 確認 duration = 4 秒。
  5. 卡住時：若做在原版，立刻 Undo 或關閉不保存。
Q10
Timeline 管理
  1. 複製為 Q10_Layers。
  2. 建立並命名 Guide_Top、Title_Main、Accent_Bar、BG_Locked。
  3. 先排上下順序，再設定 Label、眼睛與 Lock。
  4. 確認所有狀態能同時在 Timeline 看見。
  5. 卡住時：Undo 最近一步，一次只重做一類修改。
(04)

Step by Step：變式與修復

變式練習
  1. 從題 2–6、8–9、11–13 選三題。
  2. 每題只替換圖層名或一個數值，不改作用層級。
  3. 先寫預測結果，再依六步路徑卡操作。
  4. 通過標準：結果與預測一致；若不同，能指出錯在對象、層級或數值。
修復
改到原始 Composition
停止操作，不再保存，從題組副本重開。
選錯層
Undo，在 Timeline 重新點名目標圖層。
View 與工程值混淆
先問這是 View 還是 Composition 本身，再選入口。
