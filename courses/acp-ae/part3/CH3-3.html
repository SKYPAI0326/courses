操作題 28–40：輸出、動畫、色彩與 Matte

先把多條件排成不破壞現有狀態的安全順序，再實作 Photoshop Sequence、Transform + Easy Ease 與光束 Track Matte。

學習成果
完成題 28–40 的 13 張路徑卡。
分辨 Render Settings、Output Module 與 Output To。
實作三題並建立個人錯題與復原清單。
(01)

Step by Step：替多條件題目排安全順序

第一個動作
另存 ACP-AE-Q28-40.aep。遇到一題有很多條件時，先拆成六步再操作。
01
拆成 checkbox
把每個要求分成一列，不在腦中同時記全部條件。
02
標出作用層級
分別標示 Composition、Layer、Effect、Render Settings、Output Module 或 Output To。
03
建立可回復副本
先另存題組工程或複製 Composition，保留未修改版本。
04
先做安全操作
先完成命名、選取與檢查，再修改數值或輸出設定。
05
逐條核對並留證
每完成一個 checkbox 就檢查，不到最後才一起回想。
06
重開後重新驗收
重開工程，從題目第一條再核對一次。不知道在哪個對話框驗收時先停下。
(02)

十三張路徑卡

Q28

修改現有 Composition 規格

層級 Composition　路徑 Composition Settings，只改指定欄　證據 修改後 Settings 與排版　復原 Undo/原值記錄

Q29

Photoshop 影像序列輸出

實作

層級 Render Queue / Output Module　路徑 Format = Photoshop Sequence　證據 格式、資料夾、連續編號檔　復原 刪 render item/測試副本

Q30

指定圖層 Transform

層級 Layer　路徑 選對層，只改指定 Position/Scale/Rotation　證據 層名 + 屬性 + 值　復原 Undo/Reset

Q31

輸出前圖層顯示狀態

層級 Timeline　路徑 副本中使用眼睛或 Solo，不刪層　證據 開關 + 輸出畫面　復原 關 Solo/復原眼睛

Q32

Overlay 與 Logo 可見性

層級 Layer Mode/Visibility　順序 先設 overlay Mode，再關 logo　證據 Mode + 眼睛 + 畫面　復原 Normal/開 logo

Q33

Text Animation Preset

層級 Text Layer　路徑 Animation > Apply Animation Preset　證據 Text Animator 屬性 + 預覽　復原 Undo/刪 Animator

Q34

Lumetri Creative Look

層級 Effect　路徑 Lumetri Color > Creative > Look；　證據 Look 名 + 前後比較　復原 None/Reset

Q35

直式廣告 Composition

層級 Composition　路徑 New Composition，先輸入 1080 × 1920　證據 名稱、寬高、fps、duration　復原 Settings

Q36

圖層 In/Out Point

層級 Layer Time　路徑 CTI 對齊後修剪圖層邊緣　證據 圖層條起訖 + 時間　復原 Undo/拖回

Q37

多圖層名稱、Label 與順序

層級 Timeline　順序 確認 Composition，再先命名，再調整順序，最後設定 Label　證據 Timeline 全圖　復原 副本/Undo

Q38

Transform 與 Easy Ease

實作

層級 Layer Keyframe　順序 設起訖值與 Keyframe，再選正確菱形套 Ease　證據 時間 + 值 + 圖示　復原 Undo/復原屬性

Q39

Shape Twist

層級 Shape Contents　路徑 Contents > Add > Twist；　證據 Twist、Angle/Center + 畫面　復原 刪 Twist/Reset

Q40

光束 Track Matte

實作

層級 Layer Matte　路徑 光束為 fill，Shape 為 Matte 來源　證據 Matte 來源、Alpha/Luma + 畫面　復原 None/順序

(03)

Step by Step：三題代表題

Q29
Photoshop Sequence
  1. 複製為 Q29_PS_Sequence，Work Area 設 0–1 秒。
  2. 加入 Render Queue，先核對 Render Settings 的範圍。
  3. 在 Output Module 選 Photoshop Sequence。
  4. 在 Output To 指定新資料夾後 Render。
  5. 應看到：多個連續編號 PSD，不是單一影片。
  6. 卡住時：位置錯回 Output To；檔案太多回 Time Span。
Q38
Transform + Easy Ease
  1. 複製為 Q38_Ease，只選 Accent_Shape。
  2. Position：0 秒在畫面外，1.5 秒到中央。
  3. Scale：1.5 秒 = 85%，3 秒 = 110%。
  4. 只選兩個 Position Keyframe，套 Easy Ease。
  5. 應看到：Position 有 Ease，Scale 保持一般 Keyframe。
  6. 卡住時：Undo，收起 Scale 後再選 Position 菱形。
Q40
光束 Track Matte
  1. 複製 FX_Matte 為 Q40_Beams_Matte，建立 Beam_Fill 與 Beam_Matte。
  2. 分別單獨顯示兩層，確認兩層都有可見內容。
  3. 在 Beam_Fill 指定 Beam_Matte 為 Alpha Matte。
  4. 應看到：光束只保留在 Matte 範圍。
  5. 結果相反就切 Inverted。
  6. 卡住時：全透明先設 None，再重做單層檢查。
(04)

Step by Step：變式、完成檢查與修復

變式練習
  1. 從題 28、30–37、39 選三題。
  2. 每題只改名稱、時間或一個數值，不改作用層級。
  3. 把新條件拆成 checkbox，寫出安全順序與復原位置。
  4. 使用題組副本，每完成一條就核對。
  5. 通過標準：每題都有數值、開關或檔案證據。
完成檢查
13 張卡均有安全順序、完成證據與復原位置；三題實作保留設定圖、畫面圖與副本工程；輸出檔實際開啟重驗。
修復
格式對、位置錯
回 Output To，不在 Output Module 找資料夾。
只改 View Resolution
回 Render Queue > Render Settings 核對該 render item。
Matte 全透明
設 None，分別檢查 fill 與 matte，再查來源、Alpha/Luma 與 Inverted。
