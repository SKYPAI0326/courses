# Certiport Adobe ACP After Effects 認證：初始範圍整理

> 研究日期：2026-10-05<br>
> 文件狀態：初始範圍，供課程設計與學習規劃使用<br>
> 認證正式名稱：Adobe Certified Professional in Visual Effects & Motion Graphics Using Adobe After Effects

## 一、先確定的認證定位

目前 Adobe 官方公開的 After Effects Exam Guide 以 **2025 版、After Effects v25.x** 為基準。這份整理先以該版本作為主要範圍；報名或排考前，仍需到 Certiport 的現行考試清單確認實際可考版本、語言與考場供應狀態。

Adobe Certified Professional（ACP）不是只考軟體名詞。官方說明的考試包含兩個部分：

1. **Questions**：選擇題或選答題。
2. **Tasks**：在實際 Adobe 軟體中完成操作的 live-in-the-app 任務。

官方列出的考試時間為 **50 分鐘**。官方對目標考生的描述，是約有 **150 小時的 After Effects 教學與實作經驗**，能獨立完成核心工作，僅在少數情況需要同儕、文件或支援協助，並能回答常見的概念與應用問題。150 小時是目標考生基準，不是保證通過的最低時數。

## 二、官方公開的六大範圍

官方 Exam Guide 說明，列出的項目是考試主題範例，並非完整題庫。因此下表適合當作「範圍地圖」，不能解讀成逐題預測或考題清單。

| 領域 | 官方範圍重點 | 應形成的能力 |
|---|---|---|
| 1. 視覺特效與動態圖像產業工作 | 客戶與受眾、交付需求、無障礙、前期規劃、專案管理、授權與著作權、動態設計與動畫原理 | 能讀懂製作需求，判斷素材與輸出條件，使用正確的視覺與製作術語 |
| 2. 專案設定與介面 | Project、Composition、效能與播放設定、偏好設定、工作區、面板、Timeline、Markers、Guides、Grids | 能建立符合交付要求的專案，快速找到並操作必要介面 |
| 3. Composition 組織 | 匯入與管理素材、PSD/AI、影像序列、離線素材、各類 Layer、Timeline 管理、Pre-compose、Parenting、Null、Anchor Point | 能維持可理解、可修改、可重新連結的專案結構 |
| 4. 建立與修改視覺元素 | Solid、Shape、Pen、Mask、Track Matte、文字、MOGRT、圖層變形、追蹤、穩定、時間調整、3D 空間、Effects 與 Presets | 能建立基本動態圖像與合成效果，並依需求調整素材 |
| 5. 動畫視覺元素 | Keyframes、Interpolation、Graph Editor、Motion Blur、Effects 動畫、Expressions、Mask Path、Track Matte、Text Animators | 能製作可控制、可修正的物件、遮罩與文字動畫 |
| 6. 發布數位媒體 | 發布前檢查、規格確認、Collect Files、單格與影像序列輸出、Render Queue、Adobe Media Encoder、Codec、Alpha Channel、多種輸出尺寸 | 能交付可播放、規格正確、素材完整且可存檔的成果 |

目前沒有在公開官方指引中找到各領域的明確配分比例，因此本文件不自行推估權重。

## 三、功能與應用範圍

### 1. 專案、Composition 與交付規格

需要熟悉：

- 建立與修改 Project、Composition。
- 設定 frame rate、frame size、resolution、duration、pixel aspect ratio。
- 設定 work area、背景色、Composition 名稱與由 footage 建立 Composition。
- 了解 GPU rendering/effects、Preview、Memory、Media & Disk Cache、Auto-Save 等設定的基本用途。
- 依交付平台或播放設備選擇畫面比例、尺寸、格式與 Codec。

常見應用：建立短影音、社群影片、片頭、字幕動畫或品牌動態圖像時，先依交付規格設定 Composition，再開始製作。

### 2. 介面、工作區與 Timeline

需要熟悉：

- Project、Timeline、Composition、Preview、Effects & Presets、Effect Controls、Layer、Properties 等面板。
- 切換、排列、顯示與隱藏工作區面板。
- Timeline 的縮放、播放、時間碼、Current Time Indicator、Work Area Bar。
- Composition Marker 與 Layer Marker。
- Title/Action Safe、Proportional Grid、Rulers、Guides、Snap 與 Align。

常見應用：在時間有限的實機任務中，快速定位圖層、效果、時間點與交付安全區域。

### 3. 素材匯入與專案管理

需要熟悉：

- 匯入影片、音訊、圖片、影像序列與其他相容素材。
- 匯入 Photoshop（PSD）與 Illustrator（AI）圖層。
- 處理 offline media，尋找、替換、Relink、Reload、Interpret footage。
- 用資料夾整理素材，管理名稱、Placeholder 與 Metadata。
- 使用 Collect Files 整理專案相依檔案、字型與素材位置。

常見應用：接手他人專案、替換客戶素材、修復遺失連結，或將專案交給下一位製作者。

### 4. Layer、合成結構與可見性

需要熟悉：

- Footage、Text、Solid、Shape、Camera、Adjustment、Light、Null、Audio、Content-Aware Fill 與 Pre-comp 等 Layer 類型。
- Layer 的新增、刪除、命名、排序、鎖定、標籤、顯示與隱藏。
- Quality、Sampling、Motion Blur、Continuous Rasterize、Blending Modes、Track Matte、Mute、Solo 等開關或模式。
- Pre-compose、Nesting、Parenting、Null Object 與 Layer Linking。
- 用 Pan Behind（Anchor Point）工具或座標調整 Anchor Point。
- 用 Opacity 控制圖層可見度。

常見應用：把多個素材組合成有清楚層級的畫面，讓父子圖層共同移動，或用 Null Object 控制一組元素。

### 5. Shape、Pen、Mask 與 Track Matte

需要熟悉：

- 建立 Solid、Shape Layer 與由 Vector Layer 建立形狀。
- 使用 Shape Tool 與 Pen Tool，新增、刪除與轉換頂點。
- 建立、複製、貼上與修改 Mask Path。
- 調整 Mask 的 Feather、Expansion、Opacity、Interpolation，以及 Add/Subtract 等模式。
- 使用 Alpha Matte、Luma Matte 與反轉 Matte。
- 了解 Layer Mask 與 Track Matte 的用途差異。

常見應用：製作遮罩轉場、局部顯示、文字揭露、物件合成、畫面修補與簡單 Rotoscoping。

### 6. 文字與 Motion Graphics

需要熟悉：

- 建立 Point Text、Paragraph Text 與 Text on a Path。
- 使用 Type、Character、Paragraph 與 Properties 相關工具或面板。
- 設定字型、Adobe Fonts、字級、樣式、Kerning、Tracking、Leading、縮放、對齊、段落間距與文字方向。
- 使用 Text Animation Presets。
- 使用 Text Animators，例如 Position、Fill Color、Tracking。
- 設定 Text Animator 的 Based On 與 Shape。
- 建立不使用 Expressions 的 MOGRT，使用 Essential Graphics 支援的屬性並命名、輸出。

常見應用：製作標題、字幕、片頭、社群短片文字動態與可重複使用的文字模板。

### 7. 圖層變形、時間與影片處理

需要熟悉：

- 在 Timeline 移動、排序、Trim、Split Layer。
- 設定 In Point、Out Point。
- 調整 Position、Scale、Rotation、Flip、Fit to 等 Transform 操作。
- 使用 Tracker Panel、Stabilize Motion 與 Warp Stabilizer。
- 使用 Time Stretch、Time Remapping、Freeze Frame、變速與倒放。
- 啟用 3D Layer，理解 X、Y、Z 軸、2.5D 深度、3D Rotation 與 3D Transform Gizmo。

常見應用：穩定手持畫面、做速度變化、建立簡單景深或視差、把圖像放入移動畫面，以及讓圖層跟隨素材運動。

### 8. Effects、Presets 與 Adjustment Layer

需要熟悉：

- 從 Effects & Presets 套用效果或 Preset。
- 在 Effect Controls、Timeline 或 Properties 調整效果參數。
- 對單一或多個圖層套用效果。
- 使用 Adjustment Layer 讓效果影響下方圖層。
- 了解效果參數也可以被 Keyframe 動畫化。

常見應用：快速建立色彩、模糊、修飾、轉場或視覺強化效果，並保持效果結構可修改。

### 9. Keyframe、Interpolation 與 Expressions

需要熟悉：

- 對 Position、Scale、Rotation、Opacity、Anchor Point 等 Transform 屬性建立與修改 Keyframe。
- Linear、Bezier、Hold Keyframe。
- 複製、貼上、反轉 Keyframe。
- Spatial Interpolation 與 Temporal Interpolation。
- Easy Ease、Easy Ease In、Easy Ease Out。
- Graph Editor 的 Speed Graph 與 Value Graph。
- Separate Dimensions、Constrain Proportions 與 Motion Blur。
- 用 Keyframe 動畫化 Effect Properties。
- 使用 Expression Editor 的基礎 Expressions：`wiggle`、Pick Whip 連結屬性、`loop` 重複動作。
- 了解 Puppet Tool、Wiggler Panel、Motion Sketch 被列為自動建立動畫的工具範例。

常見應用：製作有節奏的物件移動、彈性或重複動畫，並在畫面上修正速度、路徑與時間感。

### 10. 輸出、檢查與封存

需要熟悉：

- 發布前檢查隱藏圖層、動畫時間、音訊音量、resolution、Title Safe、frame rate、work area 與 frame size。
- 匯出單格、連續影像序列與分層 Photoshop 檔案。
- 使用 Render Queue 與 Adobe Media Encoder。
- 選擇檔案格式、Video Codec、輸出位置與 Preset。
- 依不同畫面尺寸或播放設備輸出多個版本。
- 輸出包含 Alpha Channel 的素材。
- 交付前確認所有相依檔案、字型、檔名與檔案位置。

常見應用：輸出透明背景 Logo 動畫、社群影片、廣告素材、影片片段或可交接的完整專案。

## 四、應學習到的程度

### 基礎門檻：概念能判斷

學習者應能解釋或辨識：

- Composition、Layer、Pre-comp、Mask、Matte、Keyframe、Codec、Frame Rate、Resolution、Render 等術語。
- 何時使用 Layer Mask、Track Matte、Adjustment Layer、Null Object 或 Pre-compose。
- 不同交付目的對尺寸、比例、Frame Rate、Codec 與 Alpha Channel 的影響。
- 基本的動態設計、動畫十二原則、構圖、色彩、可讀性與無障礙概念。
- 素材授權、著作權、人物肖像或場地權限的基本風險。

### 操作門檻：能不看教學完成核心任務

學習者應能獨立完成：

- 建立正確 Composition 並匯入、整理素材。
- 建立文字、Shape、Mask、Track Matte 與基本合成。
- 使用 Transform、Keyframe、Easy Ease、Graph Editor 與 Motion Blur 完成基本動畫。
- 使用 Effects、Presets、Adjustment Layer、Tracker 或 Warp Stabilizer 完成指定效果。
- 做基本的 2.5D Layer、時間重映射與簡單文字動畫。
- 檢查、輸出與封存一個可交付的專案。

### 認證門檻：能在時間限制內完成並修正

由於考試含有實機任務，實際準備不能只靠觀看教學。學習者還需要：

- 看懂任務要求後，選擇正確工具與工作流程。
- 在不依賴逐步指示的情況下完成操作。
- 遇到素材離線、圖層順序錯誤、遮罩不顯示、動畫速度不自然或輸出規格不符時，能自行定位問題。
- 在 50 分鐘考試情境中，兼顧選答題、實機操作與成果檢查。

### 目前不應過度推定的範圍

官方公開目標有列出 Expressions、3D、Tracking、MOGRT 與各種效果，但列出的項目是範例，不能據此推定會考所有進階功能。初始準備可先不把以下內容當成核心必考：

- 複雜 JavaScript Expressions 或完整腳本開發。
- 高階角色 Rigging、完整 Character Animation。
- 需要外掛的特效流程。
- 完整 Cinema 4D 或高階 3D 建模流程。
- 電影級 Rotoscoping、Keying 或複雜 Compositing。

這些內容可作為進階課程延伸，但必須先完成官方六大領域的核心操作能力。

## 五、建議用來驗證學習成效的實作成果

以下成果可對應多個官方範圍，適合作為初步能力檢核：

| 實作成果 | 主要驗證能力 |
|---|---|
| 10–15 秒動態標題片頭 | Composition、文字、Text Animator、Keyframe、Ease、輸出 |
| 一段帶透明背景的品牌 Logo 動畫 | Shape/Vector、Anchor Point、Keyframe、Alpha Channel、Render Queue |
| 一段手持影片的穩定與標題疊加 | Footage、Tracker、Warp Stabilizer、Mask、文字與音訊同步 |
| 一段以素材遮罩完成的文字揭露動畫 | Mask、Track Matte、Mask Path、Feather、Expansion、Text Animation |
| 一個可交接的完整專案資料夾 | 素材整理、Relink、命名、Collect Files、字型與輸出管理 |
| 一個不使用 Expressions 的簡單 MOGRT | Text/Shape、Essential Graphics、支援屬性、命名與輸出 |

驗收時應保留可檢查的成果檔、輸出檔、專案檔與簡短操作紀錄；只完成畫面、不檢查可編輯性與交付規格，不能視為完整掌握。

1. 本整理依 Adobe 官方 After Effects Exam Guide、Certiport 官方 Exam Objectives 與 ACP 官方說明製作。
2. 官方公開指引明確說明，Key Terms、Key Tools、Key Concepts 與 Key Settings 是範例，不是完整清單。
3. 本次沒有使用洩漏考題或非法題庫，也不把第三方題庫內容當作官方考試範圍。
4. 公開資料目前足以建立能力範圍，但沒有提供每個領域的固定配分比例；課程時數不應只按推定配分安排。
5. 2026 年實際考試版本、可考語言、考場與遠端考試供應狀態，應在排考前再以 Certiport 現行系統確認。
6. 若要進一步製作課程，下一階段應把本文件轉成「單元—示範—學員實作—驗收證據」矩陣，並為每一項核心功能準備可重現的練習素材。
