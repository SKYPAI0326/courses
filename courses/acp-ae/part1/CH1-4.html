(04)

專案四：3D 開場與成果展總片

最後一個專案把前面的成品收成一支總片。總片前面想要一段有空間感的開場，所以先學 3D：圖層多了前後距離，畫面改由一台攝影機來拍。三張作品卡片在空間裡前後排開，鏡頭往前推。接著把這段 3D 開場和專案一的 Logo 串起來，處理主辦單位臨時改日期，再一次輸出所有成品、打包交件。

四個專案用過的功能，最後整理成一張表，依「在哪裡操作」分類。Part 2、Part 3 講題庫時，可以對著這張表找到你做過的那一步。

打開 EXPO-03.aep，另存為 EXPO-04.aep。

(01)

三張卡片

新建 Composition Intro_3D：1920 × 1080、30 fps、5 秒。這是第四次建 Composition，規格你應該已經不用看了。

建三個 Solid，名稱 Card_1、Card_2、Card_3，不按 Make Comp Size，直接輸入 500 × 700（如果 Lock Aspect Ratio 有勾，先取消，否則寬高會等比例連動），顏色各不同。每張加 Effect > Generate > Gradient Ramp，讓它像作品圖（專案二做照片時用過）。

(02)

打開第三個維度

三張卡片現在疊在同一個平面上。要讓它們前後排開，得先把圖層變成 3D。

Timeline 開關欄有一個立方體圖示的欄位，就是 3D Layer 開關。看不到這一欄時，按 Timeline 面板底部的 Toggle Switches / Modes 按鈕（專案二用它切到 Mode 欄，這次切回開關欄）。把三張卡片的 3D 開關都打開。

展開 Card_1 的 Transform：Position 從兩個數值變成三個，第三個是 Z，代表前後距離，數字越大越遠。分別設定：

  • Card_1：X 600，Z 0
  • Card_2：X 960，Z 600
  • Card_3：X 1320，Z 1200

越遠的卡片看起來越小，這是 3D 圖層的透視。

Rotation 也從一個變成 X Rotation、Y Rotation、Z Rotation 三個（另外還有 Orientation）。把三張的 Y Rotation 都設 25，卡片像側身站著。

(03)

用一個 Null 轉動整組

想讓三張卡片整組慢慢轉。專案二用 Null 帶三行字一起移動，這次同樣做：

  1. Layer > New > Null Object，改名 Cards_CTRL，也要打開 3D 開關。2D 的 Null 沒有 Y Rotation 和 Z 方向的屬性，下一步的轉動做不了。
  2. 三張卡片的 Parent & Link 都拖到 Cards_CTRL。
  3. 展開 Cards_CTRL 的 Transform：0 秒 Y Rotation 設 -15 並按碼錶，5 秒設 15。框選兩個菱形套用 Easy Ease。

播放：整組卡片慢慢轉向。

(04)

架一台攝影機

選 Layer > New > Camera。Type 選 Two-Node Camera，Preset 選 35mm，按 OK。

Two-Node 的意思是這台攝影機有兩個點：攝影機本身的位置，和它看著的 Point of Interest（目標點），攝影機永遠對著目標點。

只看一個畫面很難知道攝影機在哪。Composition 面板下方有一個 View Layout 選單（預設 1 View），改成 2 Views。點其中一個畫面，在面板下方的 3D View 選單選 Top（從上往下看）；再點另一個畫面，確認它的 3D View 是 Active Camera。現在一邊看得到攝影機的位置和它的視線，另一邊是攝影機實際拍到的畫面。

讓鏡頭往前推：

  1. 展開 Camera 圖層的 Transform。攝影機的 Transform 和一般圖層不一樣：沒有 Anchor Point 和 Scale，多了 Point of Interest。這次用 Position 和 Point of Interest。
  2. 0 秒：兩個屬性都按碼錶記下目前數值。
  3. 4 秒：Position 的 Z 增加 800，攝影機往前走；Point of Interest 的 X 改成 600，目標轉向 Card_1。
  4. 框選四個菱形，套用 Easy Ease。

播放時看 Active Camera 那一邊，鏡頭邊推近邊轉向第一張卡片。看完把 View Layout 改回 1 View。

(05)

背景：扭曲的星形

先點 Timeline 空白處取消選取。這是第四次在畫形狀前取消選取，原因一直一樣：不取消，形狀會被畫成選取圖層的遮罩，或加進選取的形狀圖層裡，而不是新的一層。

在矩形工具群組裡選 Star Tool，Fill 選淡藍、Stroke 選 None，在畫面中央拖出一個大星形，改名 Swirl，拖到最底層。

形狀圖層可以在內部加修改器。展開 Swirl，在 Contents 那一列右邊找到 Add 選單，選 Twist。Contents 底下多了 Twist 1，展開後把 Angle 設成 180，星形的尖角被扭成螺旋。

讓它慢慢轉：Angle 在 0 秒設 0 並按碼錶，5 秒設 180。

注意 Swirl 沒有打開 3D 開關，所以攝影機移動時它不動，像固定的背景。3D 開關決定這一層受不受攝影機影響。

(06)

選做：立體文字

這一步需要切換 3D 算圖方式，電腦較慢可以跳過，題庫有一題概念題會用到這裡的結果。

  1. 選 Composition > Composition Settings，切到 3D Renderer 分頁，Renderer 選 Advanced 3D。
  2. 用 Type Tool 打 EXPO 2026，打開它的 3D 開關。
  3. 展開文字圖層，找到 Geometry Options，把 Extrusion Depth 設成 50。
  4. 展開文字層的 Transform，把 Y Rotation 改成 30，從側面看得到文字有厚度了。

Extrusion Depth 就是沿 Z 方向長出厚度。

(07)

選做：把向量圖轉成形狀

如果講師有提供 Illustrator（.ai）的 Logo 檔：用 File > Import > File 匯入，拖進 Intro_3D，選它，選 Layer > Create > Create Shapes from Vector Layer。Timeline 多出一個可以編輯路徑、改填色的 Shape Layer，原本的 .ai 圖層自動關閉顯示。

沒有 .ai 檔的話，也可以選一個文字圖層試同一個選單裡的 Create Shapes from Text，結果類似：文字變成可以編輯的形狀。

(08)

串成總片：Logo 怎麼變成黑底了

新建 Composition Expo_Final：1920 × 1080、30 fps、10 秒。

從 Project 面板把 Intro_3D 和 Logo_Open 都拖進來。Logo_Open 要接在 3D 開場後面：CTI 移到 5 秒，拖住 Logo_Open 色條的中段往右移，色條左端靠近 CTI 時按住 Shift，會吸附上去。專案二、三拖的是色條的端點，那是剪掉一段；拖中段是搬移，長度不變。

播放到 5 秒後，Logo 是黑底。原因在專案二第 2 步：為了直式廣告，我們在 Logo_Open 裡關掉了 BG 的眼睛。巢狀 Composition 改一處、處處跟著變，這次反過來吃到這個結果。

不要回 Logo_Open 打開 BG，否則直式廣告又會出現橫帶。在 Expo_Final 裡自己補背景：新建 Solid（Make Comp Size、深藍），拖到 Logo_Open 下面，把它色條的左端拖到 5 秒，剪掉前面一段。

總長度是 5 + 6 = 11 秒，Logo_Open 最後 1 秒被切掉了。打開 Composition > Composition Settings，把 Duration 改成 0:00:11:00。四個專案都用過 Composition Settings，每次改的理由都不同。

整理一下 Timeline：每層取好名字、設 Label 顏色、背景鎖起來，順序是上面先播的開場、下面是 Logo 和背景。

(09)

臨時改日期

主辦單位通知：展期改成 12.19 – 12.21。日期在直式廣告裡。

在 Project 面板雙擊 Story_Ad 打開它。用 Type Tool 在畫面上的日期文字裡點一下，選取原本的文字，改成 12.19 – 12.21，再點工具列上的選取工具結束編輯。

既然要重做，順便讓日期用打字機效果出現。打開 Effects & Presets 面板（Window > Effects & Presets），搜尋 Typewriter，在 Animation Presets 裡找到它，拖到日期圖層上。

預設集其實就是一組做好的 Keyframe。展開日期層，Text 底下多了一組 Animator，一路展開到有菱形的那一列（通常是 Range Selector 1 底下的 Start），看到兩個菱形；把它們拖到 5 秒 15 格附近（和三行字滑上來的時間配合），兩個菱形距離越近，字打得越快。

(10)

一次輸出全部

Render Queue 可以排好幾個再一起算：

  1. 選 Expo_Final，選 Composition > Add to Render Queue。
  2. 再選 Story_Ad，做一次同樣的動作。
  3. 兩列都把 Render Settings 確認是 Full、整段長度，Output Module 選 H.264，Output To 各自取名 Expo_Final.mp4、Story_Ad_v2.mp4。
  4. 按 Render，兩個會依序算完。
(11)

交件前打包

要把工程交給別人，或換電腦繼續做，只拷貝 .aep 不夠：工程裡匯入的影片、音效、圖檔都是外部檔案，對方開啟時會顯示找不到素材。

選 File > Dependencies > Collect Files，Collect Source Files 選 All，按 Collect，選一個新資料夾。AE 會把 .aep 和所有用到的素材複製到同一個資料夾，並產生一份報告。

自己做一次

  1. 在 Intro_3D 加第四張卡片 Card_4（Z 1800），讓它也跟著 Cards_CTRL 轉。
  2. 讓攝影機在 4 秒後再往右平移，最後停在 Card_4 前面。
  3. Expo_Final 最後加一段 2 秒的 Replay 片段，總長度跟著調整。

完成後檢查：

  • 第四張卡片跟著整組轉，Swirl 不受攝影機影響。
  • Expo_Final 每一秒都有背景，沒有黑畫面。
  • 直式廣告的日期是新的，而且以打字機效果出現。
