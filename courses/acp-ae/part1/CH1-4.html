四種方法都會改變畫面。你會用同一張標題卡做四個版本，直接看懂「改哪一層」與「哪些內容會跟著改」。

本課英文名詞

這幾種功能都會改變畫面，但控制位置不同。記住每個名詞控制哪一層，比只背中文翻譯更有用。

Mask
遮罩。直接在同一圖層畫出要顯示或隱藏的範圍。
Mask Path / Mask Feather
遮罩路徑／羽化。前者控制形狀，後者讓邊緣變柔和。
Track Matte
軌道遮罩。使用另一個圖層的形狀或亮度控制目前圖層的透明範圍。
Alpha / Luma
透明資訊／亮度資訊。決定 Track Matte 依透明度還是明暗建立可見範圍。
Blending Mode
混合模式。決定目前圖層的像素如何和下方圖層混合。
Adjustment Layer
調整圖層。把效果套用到它下方的多個圖層。
Effect
效果。改變圖層的顏色、模糊、扭曲或其他外觀。
Effect Controls
效果控制面板。查看並修改目前圖層已套用效果的參數。
Ellipse Tool
橢圓工具。在選取圖層時可畫 Mask；未選圖層時會建立 Shape Layer。
Alpha Matte
透明度軌道遮罩。使用來源圖層的透明區域控制下方圖層是否可見。
Mode / Modes
模式／模式欄。在 Timeline 顯示 Blending Mode 與 Track Matte 的選項。
None / Normal
無／正常。前者取消 Matte 來源，後者是一般的圖層混合方式。

(03)

Step by Step：用同一畫面比較四種方法

01
建立不修改的基準版
操作：複製 Square_Practice，改名 FX_Base；再複製四份，命名 FX_Mask、FX_Matte、FX_Blend、FX_Adjust。
應看到：Project 面板有五個內容相同、名稱清楚的 Composition。
如果沒有：先整理名稱，不要在分不清版本時繼續。
02
在 FX_Mask 建立同圖層遮罩
操作：選取 Accent_Shape，用 Ellipse Tool 畫圓形 Mask，再調整 Mask Feather。
應看到：只有這一層的可見範圍改變，圖層下出現 Masks > Mask 1。
如果沒有：若產生新 Shape Layer，Undo，選取 Accent_Shape 後重畫。
03
在 FX_Matte 用另一層控制文字
操作：建立圓形 Shape 並命名 Matte_Circle；在 Title_Text 指定它為 Alpha Matte 來源。
應看到：文字只在圓形範圍內顯示，Modes 欄看得到來源名稱。
如果沒有：先設回 None，分別確認文字與圓形都能單獨看見，再重新指定。
04
在 FX_Blend 比較像素混合
操作：複製 Accent_Shape 為 Light_Blend，把 Mode 從 Normal 改成能看出差異的模式。
應看到：重疊區的亮度或顏色改變。
如果沒有：先切回 Normal，再選一個差異較明顯的模式。
05
在 FX_Adjust 同時調整下方圖層
操作：選 Layer > New > Adjustment Layer，命名 Color_Adjust，放在要受影響圖層上方，再加入一個色彩 Effect。
應看到：它下方的圖層一起改變；關閉眼睛後恢復原畫面。
如果沒有：檢查圖層上下順序與時間長度，先不要加入第二個 Effect。
06
逐一比較作用對象
操作：依序開啟五個版本，每次只比較一個版本，說出被改圖層與控制來源。
應看到：四種方法都有可辨認差異，FX_Base 保持原樣。
如果沒有：用圖層眼睛或 Effect 開關做一次一項的 A/B 比較。
07
另存新版
操作：另存 ACP-AE-Lab-v04.aep。
應看到：重開後五個 Composition 都存在。
如果沒有：回到存檔步驟確認新檔，再關閉工程。
(04)

Step by Step：練習、驗收與修復

同步練習：調整既有 Mask
  1. 開啟 FX_Mask，選取 Accent_Shape。
  2. 展開 Masks > Mask 1，不要再畫第二個 Mask。
  3. 調整 Mask Path 位置，再小幅增加 Mask Feather。
  4. 通過標準：橘色圖層只顯示於圓形內，邊緣輕微柔化。
變式練習：改變 Matte 形狀
  1. 開啟 FX_Matte，選取 Matte_Circle。
  2. 把 Shape 改成橫向矩形。
  3. 不更換 Title_Text，也不改 Alpha Matte 類型。
  4. 通過標準：文字可見範圍跟著變成矩形，來源仍是同一層。
完成檢查
五個 Composition 都存在；基準版未改；Mask 是圖層屬性；Matte 有來源層；關閉目標開關可看前後差異。
修復
畫 Shape 卻成為 Mask
Undo；要建新 Shape Layer 時先取消所有圖層選取。
Matte 後整層消失
設回 None，確認來源有可見區域，再重設 Alpha/Luma。
作用範圍錯誤
核對 Adjustment Layer 順序與受影響圖層。
