3D、Camera、音訊、Render Queue 與輸出

先用短練習看懂 3D Layer 與 Camera，再把六秒動畫加入 Render Queue。你會逐項檢查，最後打開輸出檔確認結果。

學習成果
分辨 3D Layer、Camera 與 2D Layer 的關係。
區分 Composition Settings、Render Settings 與 Output Module。
產出可開啟的六秒測試檔並留下設定證據。
第一次看到先讀

本課英文名詞

輸出時會連續看到多個設定名稱。先分清楚每一層負責的事，再依序檢查。

3D Layer
3D 圖層。啟用後可使用 Z 軸、方向與材質等立體屬性。
Camera
攝影機。控制 3D 圖層的觀看位置與視角。
Render Queue
渲染佇列。集中放置等待輸出的 Composition 與輸出設定。
Render Settings
渲染設定。決定輸出範圍、品質、解析度與影格率。
Output Module
輸出模組。決定檔案格式、通道、壓縮與音訊。
Output To
輸出至。指定輸出檔的資料夾與檔名。
Time Span
時間範圍。決定這次實際要輸出哪一段時間。
Needs Output
尚未指定輸出位置。看到這個狀態時，先設定 Output To 才能輸出。
Preview
預覽。輸出前先播放工作區段，檢查畫面、長度與音訊。
File > Export > Add to Render Queue
加入渲染佇列。把目前 Composition 送到 Render Queue 準備輸出。
Quality / Resolution
品質／解析度。在 Render Settings 中控制渲染品質與輸出尺寸比例。
Format / Audio Output
格式／音訊輸出。在 Output Module 中選擇檔案格式並決定是否輸出聲音。
Audio Layer / Audio Meter
音訊圖層／音量表。前者放置聲音素材，後者顯示播放時的音量變化。
Summary / Render
摘要／渲染。先用摘要核對設定，再按 Render 開始輸出。

(02)

三層輸出模型

層級負責什麼不負責什麼
Composition Settings畫布尺寸、fps、duration最後檔案格式與輸出位置
Render SettingsQuality、Resolution、Time Span、frame rate容器、編碼、音訊開關
Output ModuleFormat、壓縮、通道、Audio OutputComposition 本身的編輯長度

Adobe 區分 Render Settings 與 Output Module：前者決定渲染方式，後者決定格式、壓縮與輸出後處理。查看 Adobe 輸出說明。

(03)

Step by Step：辨識 3D Layer 與 Camera

01
建立安全副本
操作：複製 Composition，改名 3D_Check；選取 Title_Text 並開啟 3D Layer 開關。
應看到：Transform 出現 Z 軸與方向相關屬性。
如果沒有：確認開啟的是立方體圖示，而且選到 Title_Text。
02
加入 Camera 並觀察差異
操作：選 Layer > New > Camera，建立 Camera 並輕微改變視角。
應看到：3D 圖層受視角影響；2D 圖層不會自動有深度。
如果沒有：先不要做 Camera 動畫，檢查文字層的 3D 開關與目前視圖。
03
回到正式輸出 Composition
操作：回到 Square_Practice。
應看到：正式 Composition 沒有因 3D 練習而被修改。
如果沒有：關閉目前分頁，從 Project 面板重新開啟 Square_Practice。
(04)

Step by Step：建立可核對的輸出

01
確認六秒預覽範圍
操作：將 Work Area 設為 0–6 秒，從頭播放一次。
應看到：畫面完整，沒有意外黑幀。
如果沒有：先修正 Work Area 或圖層眼睛，不要加入 Render Queue。
02
決定是否加入音訊
操作：有合法音訊就匯入 Assets 並放進 Timeline；沒有就採無音訊版本。
應看到：有聲版看得到 Audio Layer；無聲版不需 Audio Meter 證據。
如果沒有：素材無法取得時改走無音訊備援。
03
加入 Render Queue
操作：選取 Square_Practice，選 File > Export > Add to Render Queue。
應看到：Render Queue 出現同名 render item。
如果沒有：確認選到 Composition，不是資料夾或素材。
04
檢查 Render Settings
操作：點 Render Settings，核對 Quality、Resolution、Time Span；時間應是 0–6 秒。
應看到：設定與練習要求相同。
如果沒有：取消輸出，修正 Work Area 後重新加入 render item。
05
檢查 Output Module
操作：點 Output Module，選授課電腦可用的格式；有音訊時開 Audio Output。
應看到：Summary 顯示格式、通道與音訊狀態。
如果沒有：先記錄目前設定，不要連續亂切格式。
06
指定輸出位置
操作：點 Output To，指定 Exports/Square_Practice-test，使用不覆蓋舊檔的名稱。
應看到：顯示可寫入路徑，不再是 Needs Output。
如果沒有：建立 Exports 或改選可寫入位置。
07
留下設定證據並輸出
操作：先擷取 Render Settings、Output Module、Output To，再按 Render。
應看到：狀態完成，指定資料夾出現檔案。
如果沒有：保留錯誤訊息，檢查輸出位置與磁碟空間。
08
開啟輸出檔並另存工程
操作：打開輸出檔，核對長度、畫面、解析度與音訊；另存 ACP-AE-Lab-v05.aep。
應看到：檔案可播放且符合規格，新工程可重開。
如果沒有：依問題回到步驟 4、5 或 6，不要重複 Render 錯誤設定。
(05)

Step by Step：練習、驗收與修復

同步練習：只輸出前三秒
  1. 保持 Composition Settings 不變。
  2. 建立新的 Render Queue 項目。
  3. 將 Time Span 設為 0–3 秒。
  4. 使用新檔名輸出。
  5. 通過標準：檔案為三秒，且你能指出改的是 Render Settings。
變式練習：不同 Resolution
  1. 再建立一個 Render Queue 項目。
  2. 只修改 Render Settings > Resolution。
  3. 使用不同檔名輸出。
  4. 通過標準：兩項 Resolution 不同，但 Composition 尺寸不變。
完成檢查
Work Area 與 Time Span 相符；Format、Audio Output、Output To 正確；輸出檔可開；證據同時看得到三個設定層級。
修復
Needs Output
在 Output To 指定現有資料夾與新檔名。
輸出長度不對
回 Render Settings > Time Span，不用 Composition duration 當替代。
檔案無聲
先 Preview 確認有聲，再檢查 Output Module > Audio Output。
