(06)

六秒標題動畫整合檢核

你會把前五課合在同一個作品中。依照五個階段操作，每一階段檢查通過後再繼續。

學習成果
完成可重開的 ACP-AE-Lab-PRAC1.aep。
依時間表整合 Transform、Easy Ease、Mask/Matte 與 Effect。
產出六秒預覽檔與完整證據清單。
操作前快速複習

整合練習會用到的英文名詞

這一頁不增加新工具。開始前先確認你看到英文名稱時，能說出它控制什麼。

Composition
合成。本次六秒作品的工作畫布。
Transform
變形屬性。控制 Position、Scale、Rotation 與 Opacity。
Keyframe
關鍵影格。記錄屬性在指定時間的數值。
Mask / Track Matte
遮罩／軌道遮罩。建立文字或圖形的揭露範圍。
Effect
效果。改變指定圖層的外觀。
Render Queue
渲染佇列。檢查設定並輸出最後的六秒檔案。
(01)

任務契約

欄位內容
輸入ACP-AE-Lab-v05.aep、本頁任務簡報、系統字型與 AE 內建 Shape/Solid。
完成物PRAC1_Title_6s、ACP-AE-Lab-PRAC1.aep、預覽檔、證據清單。
第一個動作先另存 ACP-AE-Lab-PRAC1.aep，再建立新 Composition。
成功訊號PRAC1_Title_6s = 1080 × 1080、29.97 fps、6 秒，Timeline 初始空白。
交接Part 2 用此工程解釋概念；Part 3 用其副本練代表題。
(02)

任務簡報

製作「FOCUS / FRAME / FINISH」三詞標題動畫。

時段畫面任務技術條件
0–2 秒主標題移入並減速停下Position + Easy Ease
2–4 秒標題或強調形狀進行第二組變化Scale、Rotation 或 Opacity
4–6 秒用 Mask 或 Track Matte 揭露，最後一秒淡出Mask/Matte + Opacity
✓
至少一項 Effect，並能說明它作用於哪個圖層。只使用系統字型與 AE 內建素材，避免 Missing Footage。
(03)

Step by Step：完成六秒整合作品

S0
另存工程並建立 Composition
操作：另存 ACP-AE-Lab-PRAC1.aep，再建立 PRAC1_Title_6s：1080 × 1080、29.97 fps、6 秒。
應看到：新 Timeline 是空白，舊 Composition 仍在 Project 面板。
Checkpoint：重新開啟 Composition Settings，規格全對才繼續。
卡住時：工程尚未另存就先停止。
S1
先完成靜態畫面
操作：建立 Text、Shape 與背景層，命名每層並排好順序；先不要加 Keyframe。
應看到：FOCUS / FRAME / FINISH 清楚可讀，沒有 Missing Footage。
Checkpoint：Timeline 不應出現未命名圖層。
卡住時：先修正命名、順序與眼睛開關。
S2
建立 0–4 秒 Transform 動畫
操作：寫下 0、2、4、6 秒時間表；0–2 秒做 Position 移入與 Easy Ease，2–4 秒再做第二種 Transform。
應看到：兩段變化清楚，至少使用兩種 Transform 屬性。
Checkpoint：停在 0、2、4 秒逐點檢查，再播放 0–4 秒。
卡住時：刪除多餘 Keyframe，只保留時間表需要的時點。
S3
加入揭露、Effect 與淡出
操作：4–6 秒用 Mask 或 Track Matte 揭露；加入一項 Effect，最後一秒以 Opacity 淡出。
應看到：控制位置清楚，Effect Controls 看得到效果，6 秒時標題不可見。
Checkpoint：關閉再開啟 Mask／Matte 或 Effect，能說明哪裡改變。
卡住時：Matte 全透明時先設回 None，分別檢查 fill 與 matte。
S4
預覽、輸出並整理證據
操作：把 Work Area 設為 0–6 秒並播放；加入 Render Queue，依序核對 Render Settings、Output Module、Output To 後輸出。
應看到：預覽與輸出都是六秒，檔案可開啟，證據齊全。
Checkpoint：依完成檢查表逐列打勾。
卡住時：黑幕或太短時先檢查 Preview、Work Area 與 Time Span，不要重複 Render。
(04)

驗收、變式與修復

類別通過標準證據
畫面文字可讀、時間正確、無意外遮擋0、2、4、6 秒擷圖
工程圖層名清楚，無離線素材或多餘層Timeline 全圖
動畫兩種以上 Transform、Easy Ease、Mask/Matte，無多餘 Keyframe展開屬性圖
效果至少一項 Effect，作用層級可說明Effect Controls
輸出6 秒，尺寸與格式符合規格Render Queue 與可開啟檔案
Step by Step：變式練習
  1. 複製 Composition，改名 PRAC1_Variant_5s。
  2. 改為 1080 × 1920、5 秒，不修改六秒原版。
  3. 重新安排文字與 Shape，讓直式畫面可讀。
  4. 重新計算進場、變化、離場時間。
  5. 將 Work Area 改為 0–5 秒並輸出不同檔名。
  6. 通過標準：五秒直式版保留三段邏輯，六秒原版仍可重開。
修復
無法重開
停止製作，修正 Save As 路徑與權限，以空白 Composition 可重開為安全點。
畫面對、動畫亂
回時間表，只保留規格時點 Keyframe。
Matte 後消失
設 None，確認來源可見，再檢查 Alpha/Luma 與圖層順序。
