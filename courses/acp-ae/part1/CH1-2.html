(02)

專案二：直式限時動態廣告

專案一的 Logo 開場是橫的，成果展還需要一支給 IG、FB 限時動態用的直式廣告。這個專案把專案一做好的 Logo 直接放進直式畫面，再加上一道光掃過的大標題、一張彈出的作品照，以及最後滑上來的日期地點。

專案一裡每一層都是各做各的。這次會碰到圖層之間的關係：用一層的形狀決定另一層哪裡看得到、用一層帶著其他幾層一起動、把一段做好的動畫整包放進另一個畫面。題庫裡混合模式、Track Matte、Mask、Parent 這幾類題目，問的都是這種關係。

打開專案一的 EXPO.aep，先另存為 EXPO-02.aep，萬一做壞還能回到專案一的版本。

(01)

直式畫布

選 Composition > New Composition：名稱 Story_Ad，Width 1080、Height 1920，30 fps，Duration 0:00:08:00，按 OK。

Composition 面板應該是直長的。如果是橫的，寬高打反了，選 Composition > Composition Settings 改回來。橫式 1920 × 1080、直式 1080 × 1920，題庫常考這組數字。

在 Project 面板把 Story_Ad 拖進 Comps 資料夾。

(02)

把專案一的 Logo 放進來

從 Project 面板把 Logo_Open 拖進 Story_Ad 的 Timeline。

一整段 Logo 動畫變成一列圖層。Composition 可以像素材一樣放進另一個 Composition，裡面有幾層、幾個 Keyframe 都包在這一列裡。

問題是 Logo 原本是 1920 寬，直式畫面只有 1080 寬，左右被切掉了。展開這一列的 Transform，Scale 改成 56%（1080 ÷ 1920 約 0.56），整段 Logo 一起縮小。再把 Position 的 Y 調小，讓 Logo 移到畫面上方。

現在看起來是一條深藍色橫帶。我們希望只要 Logo，不要專案一的背景。在 Timeline 雙擊這一列，會打開 Logo_Open 本身；把 BG 列最左邊的眼睛（Video 開關）點掉，再點 Timeline 上方的 Story_Ad 分頁回來。

橫帶不見了。你在 Logo_Open 裡改的東西，所有放了它的地方都會跟著變。專案一已經輸出的 mp4 不受影響，那是另一個檔案。

還有一點：Logo_Open 只有 6 秒，放進 8 秒的 Story_Ad 後，色條在 6 秒結束，最後 2 秒 Logo 會消失。這支廣告最後 2 秒是日期地點，先接受這個結果；專案三會學到讓畫面停住的方法。

(03)

背景加質感：第一個 Effect 與混合模式

建背景：Layer > New > Solid，名稱 BG_Story，按 Make Comp Size。這次它自動變成 1080 × 1920，因為 Make Comp Size 跟著目前開著的 Composition。顏色選深藍，拖到最底層並鎖上。

想加一點紙張般的雜訊質感。再建一個 Solid，名稱 Texture，放在 BG_Story 上面。選 Effect > Noise & Grain > Fractal Noise。

兩件事會同時發生：

  • 畫面變成整片灰色雲霧，深藍完全被蓋住。
  • 左上角多了一個 Effect Controls 分頁，裡面是 Fractal Noise 的所有參數。效果套在哪一層，參數就在這裡調。

要讓雲霧「疊」在深藍上，而不是蓋住，要改圖層的 Blending Mode（混合模式）。Timeline 圖層列右側找 Mode 欄位；看不到的話，按 Timeline 面板底部的 Toggle Switches / Modes 按鈕（在開關欄正下方），它會在開關欄和模式欄之間切換。

把 Texture 的 Mode 從 Normal 改成 Overlay：深藍回來了，上面多了深淺紋理。再試 Screen：只有亮的部分疊上去，整體變亮。比較完選 Overlay，並把 Texture 的 Opacity（T）降到 40%。

Mode 欄改的是「這一層的像素怎麼和下面混在一起」。題庫裡的「紋理圖層混合」「亮部混合」都在這一欄。

(04)

大標題加掃光：Track Matte

用 Type Tool 打 畢業成果展（中文字型），白色、大小約 150，用 Align 面板水平置中，放在 Logo 下方。改名 Headline。

接著做一道光：先點 Timeline 空白處取消選取（專案一學到的，不然會畫成遮罩），用 Rectangle Tool 畫一條比標題高的黃色長條，改名 Light。展開它的 Transform，Rotation（旋轉）輸入 20，讓它斜一點。

讓光從左掃到右，用的是同一個 Transform 裡的 Position。CTI 到 1 秒，把它拖到標題左邊外側，按 Position 碼錶；CTI 到 2 秒，拖到標題右邊外側。框選兩個菱形，選 Animation > Keyframe Assistant > Easy Ease。

現在光掃過整個畫面。我們要它只在字裡面出現，這就是 Track Matte（軌道遮罩）：讓一層的可見範圍，由另一層的形狀決定。

在 Light 那一列找 Track Matte 欄位（在 Mode 欄旁邊，看不到就按 Toggle Switches / Modes），用旁邊的螺旋圖示（pick whip）拖到 Headline 那一列放開。

播放看看，會發生兩件事：光只在字裡出現，但白色的字本身也不見了，只有光掃過時才看得到字。因為 Headline 被拿去當形狀來源後，AE 把它的顯示關掉了。

解法是多一份字：選 Headline，選 Edit > Duplicate 複製，把複製出來的那一份改名 Headline_White，拖到 Light 下面，確認它的眼睛是開著的。現在是白字當底、光在字裡掃過。

Track Matte 欄位右邊有兩個小圖示，可以切換用來源層的 Alpha（透明度）或 Luma（亮度）當形狀，還能反轉。文字的形狀來自透明度，所以用 Alpha。

(05)

圓形作品照：這次刻意用 Mask

還沒有作品照片，先用色塊代替。建一個 Solid，名稱 Photo，這次不按 Make Comp Size，直接在 Width、Height 輸入 600 × 600，任意顏色。選 Effect > Generate > Gradient Ramp，讓它變成漸層，比較像一張圖。

要把它裁成圓形。專案一不小心做出來的遮罩，這次是我們要的：保持 Photo 在選取狀態，用 Ellipse Tool 按住 Shift 在它上面拖一個圓。

方形變圓形了。展開 Photo，多了一組 Masks > Mask 1，和 Transform 並排。展開 Mask 1 可以調：

  • Mask Feather：邊緣柔化，設 10。
  • Mask Expansion：圓往外擴或往內縮。

Mask 和 Track Matte 的差別：Mask 是畫在圖層自己身上；Track Matte 是借用另一層的形狀。

(06)

讓照片晚一點出現：In Point

照片不該一開始就在畫面上，要在 3 秒才出現。

Timeline 右側每一列有一條色條，代表這一層在哪段時間存在。把 CTI 移到 3 秒，把 Photo 色條的左端往右拖到 CTI 的位置（拖到附近時按住 Shift，會吸附上去），開頭就剪在 3 秒。色條的開頭叫 In Point，結尾叫 Out Point，拖右端就是剪結尾。

(07)

照片要彈出：Pre-compose

照片下方想加一行小字 作品搶先看，兩個一起從底部彈出。

先用 Type Tool 打字，改名 Caption，放在照片下方，把 In Point 一樣剪到 3 秒。

如果分別替 Photo 和 Caption 做縮放，兩個會各自朝自己的中心縮，彈出時會分開。我們要它們是一個東西。

同時選取 Photo 和 Caption，選 Layer > Pre-compose。名稱填 Photo_Card，選 Move all attributes into the new composition（選了兩層時只有這個選項），Open New Composition 不要勾，按 OK。

兩層變成一列 Photo_Card，Project 面板也多了一個同名 Composition。這和第 2 步把 Logo_Open 放進來是同一件事，只是方向相反：第 2 步是把現成的 Composition 放進來，這裡是把幾層打包成新的 Composition。

接著做彈出，這裡會用到專案一的兩個做法：

  1. 用工具列上的 Pan Behind Tool，把 Photo_Card 的錨點拖到照片的底部中央，讓它從底部往上長。
  2. 展開 Photo_Card 的 Transform，用 Scale。CTI 到 3 秒 15 格，按碼錶記下 100%；CTI 到 3 秒，改成 0%；CTI 到 3 秒 10 格，改成 110%，讓它稍微衝過頭再回來。框選三個菱形套用 Easy Ease。

播放：照片連同小字一起從底部彈出。

Photo_Card 的色條可能從 0 秒開始，也可能從 3 秒開始，看對話框裡 Adjust composition duration to the time span of the selected layers 有沒有勾。兩種都不影響畫面：裡面的兩層本來就從 3 秒才出現。

(08)

日期地點：靠近邊緣就要看安全框

用 Type Tool 打三行，各自一層：12.18 – 12.20、教育館 B1 展廳、免費入場。放在畫面下方。

手機限動的上下邊緣常被介面蓋住，所以要確認文字不要太靠邊。Composition 面板下方有一個像井字的按鈕（Choose grid and guide options），選 Title/Action Safe。畫面出現兩個框：外框是 Action Safe（重要動作要在框內），內框是 Title Safe（文字要在框內）。

三行字如果超出內框，往上移。再選這三層，用 Align 面板做 Align Horizontal Center（專案一用過）。

想讓最下面一行剛好離底部 300 像素：選它，展開 Transform，直接在 Position 的 Y 數值輸入 1620（1920 − 300）。用數值輸入，比拖曳準確。

看完把 Title/Action Safe 關掉（同一個按鈕再選一次）。

(09)

三行一起滑上來：Null 與 Parent

三行字要一起從畫面外滑上來。分別做三組 Position Keyframe 很麻煩，而且很難對齊。

選 Layer > New > Null Object。Timeline 多一列 Null 1，畫面上只有一個小方框。Null 是沒有畫面的圖層，有位置、縮放、旋轉，但不會被看到，專門拿來帶動別的圖層。改名 Info_CTRL。

在三行字的 Parent & Link 欄位（Timeline 中間偏右，顯示 None），用螺旋圖示一一拖到 Info_CTRL。欄位會顯示 Info_CTRL。

試試看：拖動 Info_CTRL，三行字一起移動。這就是 Parenting（父子關係），子層跟著父層移動、縮放、旋轉。

做動畫只要動 Info_CTRL：展開它的 Transform，CTI 到 5 秒 15 格按 Position 的碼錶；CTI 到 5 秒，Y 加 500，讓三行字在畫面下方外面。最後套用 Easy Ease。

(10)

先輸出一版快速檢查

做到這裡，先輸出一版低解析度的看整體節奏，比每次在 AE 裡預覽快。

選 Composition > Add to Render Queue，這次多改一個地方：點 Render Settings 右邊的藍字，Resolution 選 Half（寬高各一半），Time Span 確認是整段 8 秒，按 OK。Output Module 一樣選 H.264，檔名 Story_Ad_draft.mp4，Render。

在手機或電腦上看一遍。要改就回 Timeline 改；最後再輸出一次 Resolution 選 Full、檔名 Story_Ad.mp4 的正式版。

Render Settings 管「怎麼算」（品質、解析度、哪一段時間）；Output Module 管「存成什麼檔」（格式、編碼）。專案一只改了後者，這次兩個都用到了。

自己做一次

  1. 把 Light 的掃光改成從右上往左下，並在 5 秒再掃一次。
  2. 讓 Photo_Card 在 7 秒縮回 0。
  3. 把 Info_CTRL 的 Scale 改成 90%，確認三行字一起變小。

完成後檢查：

  • 白字一直看得到，光只出現在字裡。
  • 照片和小字一起彈出、一起縮回。
  • 三行字的 Parent 欄位都是 Info_CTRL。
  • Story_Ad.mp4 是直式 8 秒。

這個專案用到的功能在哪裡

標「再次」的是專案一用過、這次換了理由又用一次的功能。

  • Project：Composition 放進 Composition、Pre-compose 產生的新 Composition、再次用資料夾整理。
  • Composition：直式 New Composition、再次用 Composition Settings 改寬高、Title/Action Safe。
  • Layer：Solid 尺寸手動輸入、Null Object、Pre-compose、In Point／Out Point、再次取消選取後畫形狀。
  • Timeline 欄位：Mode（Blending Mode）、Track Matte（Alpha／Luma）、Parent & Link、眼睛開關。
  • Timeline 屬性：Rotation、Mask Feather／Mask Expansion、再次用 Anchor Point、Keyframe、Easy Ease。
  • Effect：Fractal Noise、Gradient Ramp，參數都在 Effect Controls。
  • Render Queue：Render Settings 的 Resolution、Time Span；再次用 Output Module。
