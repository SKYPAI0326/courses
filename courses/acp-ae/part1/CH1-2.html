素材、圖層、Timeline 與 Transform

在上一課的 Square_Practice 放入背景、橘色強調帶與文字。每次修改前，先在 Timeline 點選正確圖層。

學習成果
用 Project 資料夾整理 Composition 與素材。
建立、命名、排序、鎖定與標示圖層。
在正確圖層修改 Position 與 Scale。
第一次看到先讀

本課英文名詞

這一課的英文多半是圖層種類與基本變形。先看中文意思，再到 Timeline 找相同名稱。

Solid
純色圖層。建立滿版背景或單一色塊。
Shape Layer
形狀圖層。製作矩形、圓形等可縮放的向量圖形。
Text Layer
文字圖層。輸入並排版標題或內文。
Transform
變形屬性群組。集中控制圖層的位置、大小、旋轉與透明度。
Position / Scale
位置／縮放。前者移動圖層，後者放大或縮小圖層。
Rotation / Opacity
旋轉／不透明度。前者改角度，後者控制顯示或淡出。
Anchor Point
錨點。圖層縮放與旋轉時使用的中心點。
CTI
目前時間指示器。Timeline 上可拖曳的藍色時間線，決定你正在查看哪一刻。
Make Comp Size
符合合成尺寸。建立 Solid 時讓它直接填滿目前 Composition。
Rectangle Tool / Type Tool
矩形工具／文字工具。分別用來畫 Shape 與建立文字。
Shape Path
形狀路徑。控制 Shape 本身的寬、高與輪廓。
Label
色彩標籤。用顏色區分 Timeline 中不同用途的圖層。
Undo
復原。操作結果不對時退回上一步，避免在錯誤狀態繼續。

(02)

先看懂 Project 與 Layer

Project 面板像檔案清單，放的是可使用的項目；把項目放進 Composition 後，才會在下方 Timeline 變成一列 Layer 圖層。

✓
操作前先看兩件事：Timeline 哪一列被選取，以及 CTI 現在停在哪個時間。Transform 只會改目前選取的圖層。
想改什麼先選哪裡完成證據
文字位置Title_TextPosition 值與畫面位置同時變化
強調帶大小Accent_ShapeScale 或 Shape Path 尺寸變化
背景顯示BG_Solid 眼睛關閉後出現透明格
前後疊放Timeline 圖層列上層遮住下層重疊區
(03)

Step by Step：建立三層標題卡

從整理檔案開始，一次只做一種修改。每一步先完成「應看到」的結果，再繼續下一步。

01
整理 Project 面板
操作：在 Project 面板建立 Comps、Assets、Exports，把 Square_Practice 拖進 Comps。
應看到：展開 Comps 可以找到 Square_Practice。
如果沒有：確認拖曳的是 Project 面板中的 Composition，不是 Timeline 圖層。
02
建立背景 Solid
操作：開啟 Square_Practice，選 Layer > New > Solid，名稱輸入 BG_Solid，選 Make Comp Size，顏色設深灰。
應看到：Timeline 出現 BG_Solid，中央畫面全部變成深灰。
如果沒有：確認目前開啟的是 Square_Practice，尺寸不滿版時重新建立並選 Make Comp Size。
03
建立橘色強調帶
操作：先按 Timeline 空白處取消選取，再用 Rectangle Tool 畫橘色矩形，命名 Accent_Shape。
應看到：Timeline 多一層，畫面出現橘色矩形。
如果沒有：若矩形變成 BG_Solid 的 Mask，立刻 Undo，取消圖層選取後重畫。
04
建立標題文字
操作：用 Type Tool 輸入 MOTION STARTS HERE，使用電腦現有無襯線字型，命名 Title_Text。
應看到：Timeline 多出 Title_Text，完整文字清楚可讀。
如果沒有：確認文字顏色與背景不同；缺字型就改用電腦已有字型。
05
排序、標示並鎖定
操作：由上到下排成 Title_Text、Accent_Shape、BG_Solid，替三層設定不同 Label，鎖定背景。
應看到：文字在最上方、橘色矩形在中間、背景在最下方，背景列顯示鎖頭。
如果沒有：先只修正圖層順序，不要同時改 Position。
06
調整文字位置
操作：只選 Title_Text，展開 Transform，修改 Position 到中央偏上，Scale 保持 100%。
應看到：只有文字移動。
如果沒有：Undo，確認 Timeline 藍色選取列是 Title_Text。
07
調整強調帶
操作：改選 Accent_Shape，調整 Position 與 Scale，讓矩形位於文字後方。
應看到：只有橘色矩形改變。
如果沒有：先把 Scale 還原 100%，一次只改一項。
08
另存新版
操作：另存為 ACP-AE-Lab-v02.aep。
應看到：視窗標題顯示新檔名，重開後三層仍存在。
如果沒有：先確認新檔確實出現在指定資料夾，再進下一課。
(04)

Step by Step：練習、驗收與修復

同步練習
  1. 保留三層，不新增素材。
  2. 選 Accent_Shape，把強調帶移到文字左側。
  3. 選 Title_Text，把文字移回中央。
  4. 通過：名稱與順序不變，只有兩層 Transform 改變。
變式練習
  1. 複製為 Square_Variant。
  2. 文字改成自己的課程名。
  3. 把強調帶改成細線，不改順序。
  4. 通過：原版不變，變式有新文字與細線。
完成檢查
Comps、Assets、Exports 資料夾存在；圖層名稱清楚；背景已鎖定；選任一層都能在畫面指出對應物件；工程可重開。
修復
改到錯物件
Undo，在 Timeline 選對圖層再改。
文字被遮住
把 Title_Text 移到 Accent_Shape 上方。
背景被拖移
Undo 後鎖定 BG_Solid。
