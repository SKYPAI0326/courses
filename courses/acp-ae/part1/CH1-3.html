Keyframe、時間控制與動畫節奏

把上一課的靜態標題卡變成六秒動畫。每次改數值前，先把 CTI 移到正確時間。

學習成果
分辨 CTI、Stopwatch、Keyframe 與 Work Area。
依時間表建立 Position、Scale、Opacity 動畫。
找出多餘 Keyframe，並在正確區段套用 Easy Ease。
第一次看到先讀

本課英文名詞

這一課要控制「何時改變」。先判斷名稱是在設定時間、動畫開關，還是某一個時間點的數值。

Keyframe
關鍵影格。記錄某個屬性在特定時間的數值，Timeline 上會顯示菱形。
Stopwatch
碼錶開關。開啟某項屬性的動畫；關閉時可能清除既有 Keyframe。
Easy Ease
緩入緩出。讓動作在起點與終點自然加速或減速。
Work Area
工作區段。指定預覽或輸出要使用的時間範圍。
In Point / Out Point
圖層進點／出點。決定一個圖層從何時開始、到何時停止顯示。
Time Remapping
時間重映射。用 Keyframe 改變素材的播放速度或播放位置。
Keyframe Assistant
關鍵影格輔助。包含 Easy Ease 等常用的 Keyframe 時間調整指令。
Time-Reverse Layer
圖層時間反轉。把整個圖層的播放方向前後顛倒。

(02)

四個不能混用的控制

CTI
Timeline 上方可左右拖曳的目前時間指示器；它決定你正在看哪個時間。
Stopwatch
啟用或停用該屬性動畫；停用可能清除已有 Keyframe。
Keyframe
某一個屬性在某一個時間的記錄值。
Work Area
預覽或指定輸出的區間，不會自動刪除外側圖層。

Adobe 官方說明指出，用 Keyframe 建立時間變化通常至少需要起點與終點兩個 Keyframe。查看 Adobe 說明。

(03)

Step by Step：建立三段式動畫

時間PositionScaleOpacity預期
0:00畫面左外80%100%尚未進畫
2:00畫面中央80%100%完成移入
4:00畫面中央110%100%完成放大
6:00畫面中央110%0%完成淡出
01
準備 Position 起點
操作：選 Title_Text，CTI 移到 0 秒，Position 放到畫面左外，再按 Position Stopwatch。
應看到：0 秒出現第一個 Position Keyframe，畫面中暫時看不到標題。
如果沒有：確認選對圖層、CTI 在 0 秒，而且按的是 Position Stopwatch。
02
建立 Position 終點
操作：CTI 移到 2 秒，把文字移到中央。
應看到：2 秒自動出現第二個 Position Keyframe。
如果沒有：不要重按 Stopwatch；回到步驟 1 確認 Position 動畫已啟用。
03
只替 Position 加 Easy Ease
操作：只選兩個 Position Keyframe，右鍵選 Keyframe Assistant > Easy Ease。
應看到：Keyframe 圖示改變，0–2 秒移入有減速感。
如果沒有：Undo，確認沒有同時選到 Scale 或 Opacity。
04
建立 2–4 秒 Scale
操作：2 秒 Scale = 80% 並啟用 Stopwatch；4 秒 Scale = 110%。
應看到：Scale 在 2、4 秒各有一個 Keyframe，文字逐漸放大。
如果沒有：核對 CTI 時間，不要用 Position 模擬放大。
05
建立 4–6 秒淡出
操作：4 秒 Opacity = 100% 並啟用 Stopwatch；6 秒 Opacity = 0%。
應看到：4 秒完整可見，6 秒完全透明。
如果沒有：確認改的是 Opacity，不是圖層眼睛。
06
設定 Work Area 並逐點檢查
操作：Work Area 設 0–6 秒，依序停在 0、2、4、6 秒對照時間表，再播放。
應看到：移入、放大、淡出三段完整。
如果沒有：先停在出錯時段，只修該屬性的時間或數值。
07
另存新版
操作：另存 ACP-AE-Lab-v03.aep。
應看到：重開後三組 Keyframe 都存在。
如果沒有：確認新檔存在再關閉工程。

(05)

Step by Step：練習、驗收與修復

同步練習
  1. 複製為 Subtitle_Text。
  2. 刪除副標原有 Position Keyframe。
  3. 0 秒放右外，2 秒放中央偏下。
  4. 只替 Position 套 Easy Ease。
  5. 通過：主標從左、副標從右進入。
變式練習
  1. 先複製 Composition。
  2. Position 終點移到 1.5 秒。
  3. Scale 改為 1.5–3.5 秒。
  4. Opacity 改為 3.5–5 秒。
  5. 通過：只移時間，不改起訖值。
完成檢查
0、2、4、6 秒值符合時間表；每屬性只留必要 Keyframe；Easy Ease 只套移入 Position；Work Area = 0–6 秒；工程可重開播放。
修復
值對、時間錯
刪多餘 Keyframe，只移動正確菱形。
Keyframe 全消失
Undo，不要再點已啟用的 Stopwatch。
預覽不是 6 秒
重設 Work Area 起點 0、終點 6。
