(03)

專案三：精華重播片段

前兩個專案的東西都是在 AE 裡畫出來的。實際工作更常處理拍好的影片：放慢、停格、倒放、調色。這個專案把專案一輸出的 Logo_Open.mp4 當成拍好的影片，做一段精華重播：慢動作播放，在 Logo 完整出現時停一秒，再快速倒帶，整體調成暖色，最後輸出一組圖檔給設計組挑一格做海報。

處理影片時有兩種改法：改素材本身，所有用到它的地方會一起變；或只改某一層怎麼播放，其他地方不受影響。題庫裡 Interpret Footage、Time Remapping、Time-Reverse 這幾題，差別就在這裡。

打開 EXPO-02.aep，另存為 EXPO-03.aep。

(01)

匯入影片，用它建 Composition

選 File > Import > File，選 EDTECH-EXPO/Logo_Open.mp4。它出現在 Project 面板，圖示和 Composition 不同，這是素材（Footage）。

在 Project 面板建一個資料夾 Assets，把它拖進去。專案一建資料夾時還看不出用處，現在 Project 裡已經有 Composition、Solids、Pre-comp 和影片，分開放才找得到。

把 Logo_Open.mp4 拖到 Project 面板底部的 Create a new Composition 圖示上放開（Project 面板底部那排小按鈕之一，滑鼠停在上面會顯示名稱）。AE 會用影片本身的尺寸、影格率、長度建一個 Composition，並把影片放進去。

新的 Composition 名稱和影片一樣，容易和專案一的 Logo_Open 搞混。選 Composition > Composition Settings：

  • 名稱改成 Replay。
  • Duration 從 6 秒改成 0:00:08:00。

專案一用 Composition Settings 確認長度，專案二用它修正寬高，這次用它改名稱、延長時間。把 Replay 拖進 Comps。

(02)

先用標記把節奏排好

動手前先決定時間點，等於在時間軸上寫分鏡：

  • 0–3 秒：慢動作播放
  • 3–4 秒：停格
  • 4 秒起：倒帶

點 Timeline 空白處取消所有圖層選取，把 CTI 移到 3 秒，選 Layer > Add Marker（有些版本放在 Layer > Markers 底下）。時間尺上出現一個標記。沒有選取圖層時加的是 Composition Marker，標在整個 Composition 上；選取圖層時加的會是那一層的 Layer Marker。

雙擊這個標記，Comment 輸入 Hold。再到 4 秒加一個，Comment 輸入 Rewind。

之後拖曳色條或 Keyframe 時按住 Shift，會自動吸附到這些標記。

(03)

慢動作：改影片的影格率解讀

影片每秒 30 格。如果讓 AE 把它當成每秒 15 格播放，同樣的畫面就要播兩倍久，等於慢動作。

在 Project 面板對 Logo_Open.mp4 按右鍵，選 Interpret Footage > Main。在 Frame Rate 區選 Conform to frame rate，輸入 15，按 OK。

原本 6 秒的影片，現在要播 12 秒，Project 面板上方的素材資訊也會顯示新的長度。看 Timeline：如果這一層的色條沒有跟著變長、仍停在 6 秒，把這一層刪掉，從 Project 面板重新拖一次進來，色條就會延伸到 8 秒之後。

注意改的位置：這是在 Project 面板對素材本身改，所有用到這支影片的 Composition 都會一起變慢，不只是這一個。題庫的「修改 Footage 解讀影格率」就是這個位置。

(04)

停格：Time Remapping 與 Hold Keyframe

播放確認 Logo 大約在 3 秒時完整出現（原本 1.5 秒，慢了一倍）。要從這裡停住。

選這一層，選 Layer > Time > Enable Time Remapping。圖層下出現 Time Remap 屬性，頭尾已經各有一個 Keyframe。Time Remap 的數值意思是「這一刻要顯示影片的第幾秒」。

  1. CTI 移到 3 秒（按住 Shift 拖會吸到 Hold 標記）。
  2. 按 Time Remap 左邊的菱形按鈕（Add or remove keyframe at current time），在 3 秒加一個 Keyframe。這裡不是按碼錶：碼錶已經開著，再按會把 Time Remapping 整個關掉，和專案一第 8 步按錯碼錶是同一類狀況。
  3. 對這個新 Keyframe 按右鍵，選 Toggle Hold Keyframe，菱形的右半邊變成方形。Hold 的意思是數值停在這裡，不往下一個 Keyframe 變化。

播放：3 秒後畫面停住。

這一層只需要播到 4 秒。CTI 移到 4 秒，把色條的右端往左拖到 CTI（按住 Shift 會吸附），Out Point 就剪在 4 秒（專案二剪照片時拖的是左端）。改名為 Play。

(05)

倒帶：Time-Reverse Layer

從 Project 面板再把 Logo_Open.mp4 拖一次進 Timeline，放在 Play 上面，改名 Rewind。這是一份沒有 Time Remap 的乾淨副本。

選它，選 Layer > Time > Time-Reverse Layer。整層變成倒著播。

播放會發現：倒帶一開始是一長段靜止畫面。原因是影片後半本來就是 Logo 停著不動，倒過來就跑到前面了。我們要的是 4 秒時剛好開始「動」。

把 CTI 停在 4 秒，左右拖動 Rewind 的色條中段（不是兩端），一邊看畫面：拖到 4 秒那格是 Logo 完整、下一格就開始縮回的位置。播放確認 4 秒起開始倒退。

這時 Rewind 的色條可能從 4 秒之前就開始，會蓋住 Play。CTI 在 4 秒，把 Rewind 色條的左端拖到 CTI（按住 Shift 吸附），In Point 就剪在 4 秒。

(06)

倒帶加速感：替 Effect 數值做動畫

選 Rewind，選 Effect > Blur & Sharpen > Radial Blur。Effect Controls 裡把 Type 改成 Zoom（從中心往外的放射狀）。

模糊的 Amount 也能做 Keyframe，做法和 Scale、Position 一樣，只是碼錶在 Effect Controls 裡：

  1. CTI 到 4 秒，Amount 設 0，按 Amount 左邊的碼錶。
  2. CTI 到 4 秒 15 格，Amount 設 60。
  3. CTI 到 5 秒 15 格，Amount 設 0。
  4. 展開 Rewind，這次除了 Transform，還多了一組 Effects；展開 Effects > Radial Blur，Amount 旁邊就是剛做的三個菱形。框選它們，套用 Easy Ease。

預覽時可能變得很卡，因為放射模糊每一格都要重算。Composition 面板下方有一個解析度選單（顯示 Full 或 Auto），改成 Half，預覽只算一半解析度，會順很多。這只影響預覽，不影響輸出。

(07)

整體調暖：Adjustment Layer

兩層影片要一起變暖色。分別套效果要做兩次，之後改也要改兩次。

選 Layer > New > Adjustment Layer，放在最上面，改名 Color。Adjustment Layer 本身沒有畫面，套在它身上的效果會作用在它下面所有圖層。

選 Color，選 Effect > Color Correction > Photo Filter，Filter 選一個 Warming Filter，Density 調到 40。Play 和 Rewind 都變暖了。點掉 Color 的眼睛比較前後，再打開。

再加一個 Effect > Color Correction > Lumetri Color。在 Effect Controls 展開 Creative，Look 下拉選單裡選一個預設風格，看畫面變化。

順帶分辨兩種調色目的：把偏色、曝光不一致修回正常，叫色彩校正；在正常的基礎上做出風格，叫風格調色。Lumetri 的 Creative Look 屬於後者。

(08)

加音效（有音效檔再做）

影片素材沒有聲音。如果你手邊有一個短音效檔（mp3、wav），用 File > Import > File 匯入，拖進 Timeline，In Point 放在 4 秒。

展開這一層，聲音圖層主要的屬性在 Audio 底下；展開 Audio，找到 Audio Levels，改成 -15 dB，聲音小一些。圖層左側的喇叭圖示是 Audio 開關，點掉就靜音，不必刪圖層。

(09)

單獨檢查一層：Solo

想只看倒帶那一層的效果，點 Rewind 左側的 Solo 開關（小圓點）。畫面上只剩開 Solo 的圖層。

看完一定要關掉。Solo 開著時輸出，也只會算出開 Solo 的那幾層。

(10)

輸出一組 Photoshop 圖檔

設計組要從 3 到 5 秒之間挑一格做海報。

  1. 把 Work Area 的左端拖到 3 秒、右端拖到 5 秒（先把 CTI 放在該時間，拖到附近時按住 Shift 會吸附上去）。專案一用 Work Area 剪長度，這次用來選範圍。
  2. 選 Composition > Add to Render Queue。
  3. Render Settings：Time Span 選 Work Area Only。
  4. Output Module：Format 選 Photoshop Sequence。
  5. Output To：先在 EDTECH-EXPO 裡建一個新資料夾 Replay_PSD，存到裡面。
  6. Render。

打開資料夾，會看到一串連號的 psd 檔，每一格一張。2 秒 × 30 格，大約 60 張，所以一定要放在獨立資料夾。

只想要一張的話，CTI 停在那一格，選 Composition > Save Frame As > File。

自己做一次

  1. 把停格從 1 秒延長到 1.5 秒：移動 Rewind 標記，再讓 Play 的 Out Point、Rewind 的 In Point 對齊新位置（按住 Shift 拖會吸附）。
  2. Lumetri 換另一個 Look，再把 Photo Filter 關掉（Effect Controls 裡效果名稱左邊的 fx 開關），比較差異。
  3. 輸出整段 8 秒的 mp4，記得先把 Work Area 拉回 0–8 秒，或在 Render Settings 選 Length of Comp。

完成後檢查：

  • 慢動作、停格、倒帶三段清楚，倒帶時有放射模糊。
  • 所有 Solo 都關閉。
  • Replay_PSD 裡是連號的 psd 檔。

這個專案用到的功能在哪裡

  • Project：匯入素材、用素材建 Composition、Interpret Footage（影格率解讀）、再次用資料夾整理。
  • Composition：再次用 Composition Settings（改名、延長）、Composition Marker、預覽解析度、Save Frame As。
  • Layer：Time Remapping、Hold Keyframe、Time-Reverse Layer、Adjustment Layer、再次剪 In／Out Point。
  • Timeline 開關：Solo、Audio 開關、Audio Levels、再次用眼睛開關。
  • Effect：Radial Blur（Keyframe 在 Effect Controls）、Photo Filter、Lumetri Color 的 Creative Look。
  • Render Queue：Time Span 選 Work Area Only、Photoshop Sequence；再次用 Render Settings 與 Output Module。
