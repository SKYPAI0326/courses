(01)

專案一：成果展 Logo 開場

接下來的四個專案，要替一場畢業成果展做一套宣傳影片：開場 Logo、限時動態廣告、精華重播，最後串成一支總片。每個專案都會用到前一個的成品，前面學過的操作也會在不同情況下再出現。做完四個專案，到 Part 2、Part 3 講題庫時，題目裡提到的功能你都親手用過，知道它在哪裡、做什麼用。

第一個專案先做 Logo 開場。AE 的每一個操作，都發生在幾個固定的地方：放材料的清單、觀眾看到的畫面、排圖層和時間的時間軸，以及最後輸出的地方。題庫的操作題，第一步常常就是判斷該去哪裡改。這個專案從空白工程開始，把這幾個地方各用一次，做出深藍背景、橘色圓形彈出、標題浮現的開場，再輸出成影片檔；專案三會把這個影片檔當素材再用一次。

(01)

先存檔，再開始

打開 After Effects，畫面中央通常是 Home 畫面，按 New Project。接著馬上選 File > Save As > Save As，在桌面建一個資料夾 EDTECH-EXPO，檔名存成 EXPO.aep。

先存檔的原因很實際：AE 當掉時，沒存過的工程什麼都不會留下。存好後，視窗最上方的標題會出現 EXPO.aep。之後每做完一段就存一次（File > Save）。

(02)

建立畫布：Composition

AE 裡真正會被播放、輸出的東西叫 Composition（合成），可以把它想成一張有長度的畫布。選 Composition > New Composition，跳出設定視窗：

  • Composition Name：Logo_Open
  • Width 1920、Height 1080（如果 Lock Aspect Ratio 有勾，先取消，免得改一個另一個跟著變）
  • Pixel Aspect Ratio：Square Pixels
  • Frame Rate：30，也就是每秒 30 張畫面
  • Duration：0:00:10:00，10 秒。最後只要 6 秒，但動畫還沒做，先留多一點
  • Background Color：黑色

按 OK 之後，畫面上會同時出現三塊你整堂課都會用到的區域：

  • 左上的 Project 面板多了一個 Logo_Open，這裡是工程裡所有材料的清單。
  • 中間的 Composition 面板是一塊黑色畫布，就是觀眾會看到的畫面。
  • 下方的 Timeline 面板有一個 Logo_Open 分頁，左邊放圖層，右邊是時間。現在是空的。
(03)

鋪背景：Solid

選 Layer > New > Solid。名稱打 BG，按 Make Comp Size 讓尺寸自動等於這個 Composition，顏色選深藍，按 OK。

畫面變成整片深藍，Timeline 出現第一列圖層 BG。順便看一下 Project 面板：AE 自動多了一個 Solids 資料夾，你建的每個 Solid 都會收在裡面。

(04)

畫圓形：第一次會遇到的狀況

在上方工具列找到矩形工具，按住它不放，選 Ellipse Tool（橢圓工具）。工具列右側點 Fill 旁的色塊，選橘色；再點 Stroke 這個字（不是它旁邊的色塊），在跳出的選項裡選 None，不要外框。

現在按住 Shift 在畫面中央拖出一個圓。

多數人第一次會看到：深藍背景不見了，只剩一個圓形範圍是深藍，其餘變黑。原因是 BG 還在選取狀態，選取著 Solid、文字這類圖層時畫形狀，AE 會在那個圖層上畫遮罩（Mask），只留下形狀內的部分。（選取的如果是形狀圖層，新畫的形狀會加進那個形狀圖層裡，也不是新的一層。）專案二會刻意用這個功能，現在先不要它。

選 Edit > Undo 復原，接著點 Timeline 圖層列下方的空白處，取消所有選取（也可以選 Edit > Deselect All），再畫一次圓。這次 Timeline 會多一列 Shape Layer 1，畫面上出現橘色圓形。

選取這一列，按 Enter，改名為 Circle，再按 Enter 確認。

(05)

打標題

選工具列上的 Type Tool（T 字圖示），在圓形下方點一下，輸入 EDTECH EXPO。字型、大小、顏色在右側的 Character 面板設定（沒看到就選 Window > Character），顏色用白色，大小約 120。打完用滑鼠點工具列上的選取工具（箭頭圖示）離開打字狀態。

Timeline 多了一列文字圖層，名稱自動等於文字內容。

(06)

對齊到正中

圓和文字大概是手拖的，不會剛好置中。選 Window > Align 打開 Align 面板，把 Align Layers to 設成 Composition。

先只選 Circle，按 Align Horizontal Center（水平置中），圓就移到畫面左右正中。再選文字層做一次。選取的圖層不同，被移動的就不同，這是 AE 最常見的規則：改之前先看 Timeline 選了哪一列。

(07)

整理圖層：順序、名稱、顏色、鎖

Timeline 的圖層由上往下疊，上面的會蓋住下面的。現在三層應該是文字、Circle、BG。如果順序不對，直接上下拖曳圖層列。

再做三件小事：

  • 每一列眼睛、鎖頭那幾個開關的右邊，有一個小色塊，這是 Label，點開改顏色。建議背景用灰、形狀用橘、文字用黃，之後一眼就分得出來。
  • 背景不會再動，點 BG 列左側鎖頭欄位（Lock），鎖上後在畫面上點不到它，不會誤拖。
  • 文字層改名為 Title（選取後按 Enter）。
(08)

讓圓形彈出來：第一個關鍵影格

動畫在 AE 的做法是：在某個時間點記下一個數值，在另一個時間點記下另一個數值，中間由 AE 自動補。被記下的點叫 Keyframe（關鍵影格）。

  1. 點 Circle 圖層名稱左邊的小三角形展開，再展開裡面的 Transform。Transform 底下有五個屬性：Anchor Point（錨點）、Position（位置）、Scale（縮放）、Rotation（旋轉）、Opacity（不透明度）。圖層的移動、縮放、旋轉、淡入淡出，都在這裡做動畫。這次用 Scale。
  2. 把 Timeline 上方藍色的時間指示線（CTI，目前時間）拖到 0:00:00:15，也就是半秒。也可以直接點左上角的時間碼輸入 15。
  3. 按 Scale 左邊的碼錶圖示（Stopwatch）。時間軸上半秒的位置出現一個菱形，這是第一個 Keyframe，記下了 100%。
  4. 把 CTI 拉回 0:00:00:00，把 Scale 數值改成 0。這裡不必再按碼錶：碼錶開著時，在新時間改數值會自動新增 Keyframe。
  5. 按 Preview 面板的播放鍵（空白鍵也可以），圓會從無到有放大。再按一次停止。

如果在第 4 步又按了一次碼錶，菱形會全部消失，因為碼錶是整個屬性動畫的開關。選 Edit > Undo 復原即可。

(09)

底線從左邊長出來：認識錨點

先點 Timeline 空白處取消選取，再用 Rectangle Tool 在標題下方畫一條細長的白色橫條，改名 Underline。你會發現這次已經記得先取消選取了，這就是第 4 步的狀況。

讓它從 0 長到全寬：

  1. 展開 Underline 的 Transform，找到 Scale。數值左邊有一個鍊條圖示，點一下解除等比例，這樣寬、高可以分開改。
  2. CTI 到 0:00:01:00，按碼錶記下 100%, 100%。
  3. CTI 到 0:00:00:15，把第一個數值（寬）改成 0。
  4. 播放。

底線是從中間往兩邊長，不是從左邊。原因是縮放以 Anchor Point（錨點）為中心，而錨點現在在橫條中央，畫面上那個小十字就是它。

選工具列上的 Pan Behind Tool（像十字加圓圈的圖示），把 Underline 的錨點拖到橫條最左端。這個工具只搬錨點，橫條本身不會移動。再播放一次，底線就從左往右長了。

錨點在後面每個專案都會再用到：旋轉繞著它轉、縮放朝它縮，想改變「從哪裡動」，就是搬錨點。

(10)

標題浮上來：一次動兩個屬性

展開 Title 的 Transform，這次同時用 Position 和 Opacity 兩個屬性。

  1. CTI 到 0:00:01:10：Position 和 Opacity 各按一次碼錶，記下目前位置和 100%。
  2. CTI 到 0:00:00:20：Opacity 改 0；Position 的第二個數值（Y）加 60，讓文字往下 60 像素。
  3. 播放：標題一邊淡入、一邊往上浮。
(11)

動作太死板：Easy Ease

播放時仔細看，三個動作都是等速開始、等速停下，像機器。真實物體會慢慢起步、慢慢停下。

在 Timeline 右側用滑鼠框選全部菱形（三層都要），選 Animation > Keyframe Assistant > Easy Ease（也可以在菱形上按右鍵，選同一個指令）。菱形變成沙漏形狀。再播放一次，動作明顯柔和。

(12)

把長度剪成 6 秒

動畫在 1.5 秒左右就做完了，Composition 卻有 10 秒。我們要 6 秒：前面動畫、後面停住讓觀眾看清楚。

Timeline 上方灰色的長條是 Work Area（工作區段），決定預覽播哪一段。先把 CTI 移到 0:00:06:00，再把 Work Area 的右端往左拖到 CTI 的位置（拖到附近時按住 Shift，會吸附上去），結尾就停在 6 秒。

Work Area 只決定預覽範圍，Composition 還是 10 秒。要真的剪短，選 Composition > Trim Comp to Work Area。

確認方式：選 Composition > Composition Settings，Duration 應該顯示 0:00:06:00。之後要改尺寸、長度、影格率，都回這個視窗。

(13)

整理 Project 面板

在 Project 面板空白處按右鍵 New Folder，建兩個資料夾：Comps 和 Renders。把 Logo_Open 拖進 Comps。

現在材料少，看不出差別。專案二、三會在這個 Project 裡放進更多 Composition 和素材，有資料夾才找得到。

(14)

輸出成 mp4

選 Composition > Add to Render Queue。下方 Timeline 位置多了一個 Render Queue 分頁，裡面有一列 Logo_Open。

  • Output Module 右邊的藍字點開，Format 選 H.264，按 OK。
  • Output To 右邊的藍字點開，存到 EDTECH-EXPO 資料夾，檔名 Logo_Open.mp4。
  • 按右上角 Render。

進度條跑完會有提示音。到資料夾雙擊 Logo_Open.mp4，應該能用一般播放器播放，長度 6 秒。這個檔案專案三會用到，不要刪。

最後存檔（File > Save）。

自己做一次

在 Project 面板選 Logo_Open，選 Edit > Duplicate 複製一份，改名 Logo_Open_Green。雙擊打開它，把背景改綠色（選 BG 後選 Layer > Solid Settings；BG 鎖著時先解鎖。兩個 Composition 用的是同一個 Solid，視窗下方的 Affect all layers that use this solid 不要勾，否則原本的背景也會一起變綠）、標題改成你自己的名字，再讓圓形改成從 1 秒才開始彈出。

完成後檢查：

  • 原本的 Logo_Open 沒有被改到。
  • 圓形從 1 秒開始彈出，所有動作都是柔和停下。
  • Composition Settings 顯示 6 秒、30 fps、1920 × 1080。

這個專案用到的功能在哪裡

講解題庫時，題目常會說「在某某層級操作」。今天碰到的功能分別在：

  • Project（材料清單）：Composition、Solids 資料夾、自建資料夾、複製 Composition。
  • Composition（畫布設定）：New Composition、Composition Settings、Work Area、Trim Comp to Work Area。
  • Layer（圖層）：New Solid、Solid Settings、Shape、Text、命名、順序、Label、Lock。
  • Timeline 屬性：Scale、Position、Opacity 的 Keyframe 與碼錶、Easy Ease、Anchor Point。
  • Render Queue（輸出）：Output Module 的格式、Output To 的位置。
