(01)

介面、Project 與 Composition 規格

從 AE 空白畫面開始：先存檔，再建立符合名稱、寬高、影格率與長度規格的 Composition。

學習成果
分辨 Project、Composition、Layer 與 Timeline 的層級。
依單位正確輸入尺寸、fps 與 duration。
用 Composition Settings 留下可核對的完成證據。
第一次看到先讀

本課英文名詞

先把英文介面名稱和用途連起來。操作時看到這些字，就知道該看哪裡、能改什麼。

Project
工程檔。保存素材、Composition 與各項設定；副檔名是 .aep。
Project panel
專案面板。管理素材、Composition 與資料夾，通常位於畫面左側。
Composition
合成。一段動畫的工作畫布，決定尺寸、影格率與長度。
Composition panel
合成預覽面板。顯示目前時間點的畫面，通常位於中央。
Timeline
時間軸。排列 Layer、查看時間並設定動畫，通常位於畫面下方。
Layer
圖層。放進 Composition 的文字、圖形、圖片、影片或音訊。
Composition Settings
合成設定。修改合成名稱、寬高、影格率與總長度。
fps / Duration
每秒影格數／總長度。前者控制每秒畫面張數，後者控制合成可使用多久。
File > Save As
檔案 > 另存新檔。先替 Project 指定資料夾與檔名，避免做到一半找不到工程。
New Composition
新增合成。開啟建立新 Composition 的設定視窗。
Name / Width / Height
名稱／寬度／高度。設定合成名稱與畫布尺寸。
Frame Rate
影格率。設定每秒播放多少格；題目寫 fps 時就核對這一欄。
Pixel Aspect Ratio
像素長寬比。一般螢幕練習選 Square Pixels（方形像素）。
Background Color
背景顏色。設定合成預覽的底色；它不會自動建立一個背景 Layer。
Workspace
工作區。控制各面板的排列方式；面板不見時可用它恢復配置。
(01)

今天要交付什麼

為什麼這很重要
認證任務常把尺寸、fps、長度與輸出條件寫在同一句。如果先選錯層級，後面的數值全對也不能過關。
欄位內容
輸入可啟動的 AE、可寫入的 ACP-AE-Practice 資料夾、本頁規格卡。
完成物ACP-AE-Lab.aep，內含 Square_Practice Composition。
第一個動作建立空白 Project，立即另存為 ACP-AE-Practice/ACP-AE-Lab.aep。
成功訊號視窗標題顯示檔名，Project 面板可見，工程可重新開啟。
交接保留 Square_Practice，下一課在其中建立圖層。
ⓘ
本頁使用 Adobe After Effects 2025 的功能與介面名稱。若使用不同版本或語系，選單名稱與位置可能略有差異；請以功能名稱、設定值與「應看到」的結果核對。
(02)

Step by Step：建立 Square_Practice

每一步都先確認「應看到」的結果；畫面不同時先修正，不要帶著錯誤繼續。

01
建立空白工程並先存檔
操作：開啟 AE，建立新 Project，選 File > Save As > Save As，存成 ACP-AE-Practice/ACP-AE-Lab.aep。
應看到：AE 視窗標題出現檔名。
如果沒有：確認資料夾可寫入；未存檔前不要繼續。
02
打開 Composition 設定
操作：選 Composition > New Composition。
應看到：New Composition Settings 對話框。
如果沒有：先點 AE 視窗，再重新選一次。
03
輸入名稱與尺寸
操作：Name = Square_Practice；Width = 1080；Height = 1080；Pixel Aspect Ratio = Square Pixels。
應看到：寬、高相同，畫布比例為正方形。
如果沒有：檢查寬高是否輸入反，也不要加入 px。
04
輸入時間規格
操作：Frame Rate = 29.97；Duration = 00:00:10:00。
應看到：時間碼代表 10 秒 0 格。
如果沒有：輸入完整時間碼，不要只輸入 10。
05
完成 Composition
操作：Background Color 設深灰，按 OK。
應看到：Project 有 Square_Practice，中央為深灰正方形，Timeline 尚無圖層。
如果沒有：在 Project 連按兩下 Square_Practice；找不到時回到步驟 2 重建。
06
重新打開設定並留證
操作：選 Composition > Composition Settings，逐欄核對五項規格並擷圖。
應看到：名稱、寬、高、fps、duration 都和規格相同。
如果沒有：在 Settings 修正錯誤欄位，再重新開啟並擷圖。
中間狀態
Project 面板有一個 Composition；Composition 面板是深灰正方形；Timeline 尚無圖層。
(03)

Step by Step：同步練習與變式

同步練習
  1. 選 Composition > New Composition。
  2. 建立 Wide_Practice：1920 × 1080、24 fps、8 秒。
  3. 重新開啟 Settings 核對五項。
  4. 通過：Project 可見新 Composition，五項規格正確。
變式練習
  1. 建立 Vertical_Check：1080 × 1920、30 fps、6 秒。
  2. 關閉再重開 Settings。
  3. 不看規格卡，口述五個核對欄位。
  4. 通過：畫布為直式，五項都正確。
(04)

完成檢查與修復

完成檢查
  • Square_Practice = 1080 × 1080、29.97 fps、10 秒。
  • Wide_Practice = 1920 × 1080、24 fps、8 秒。
  • Vertical_Check = 1080 × 1920、30 fps、6 秒。
  • Project 已儲存，關閉後能重新開啟。
  • 證據圖可同時看到 Composition 名稱與全部規格。
修復路徑
寬高相反
回 Composition Settings 更正 Width / Height，然後重新擷圖。
播放速度不對
核對 Frame Rate，不以預覽感覺判定。
面板排列不同
由 Window > Workspace 重設，找回 Project、Composition、Timeline。
尚未儲存
停止繼續操作，先 Save As 到指定資料夾。
