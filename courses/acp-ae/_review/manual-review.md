# ACP-AE 人工審核紀錄

開始日期：2026-10-16

## 審核原則

- 學員頁只呈現學習範圍、操作方法、完成結果與必要版本差異。
- 本機環境、製作進度、機器驗證狀態與內部 Gate 只記錄在 `_review`、`_validation` 或 `_repair`。
- 每次修正後重新執行文字掃描、結構檢查與頁面抽查。

## 回饋紀錄

### MR-001 製作端環境寫入學員講義

- **回饋**：不能將「本機沒有 After Effects」等本機狀況視為結果寫入講義。
- **範圍**：首頁、CH1-1、Part 3 說明、所有頁尾版本文字與 10 份正式教案 front matter。
- **修正**：移除本機、待實測、靜態驗證與內部驗收狀態；改為穩定的課程版本說明及學員可採用的版本差異處理方式。
- **驗證**：學員 HTML 與正式教案的內部狀態關鍵字掃描均無命中；`validate-handout.py` 通過；全課 lint 為 0／0／0。
- **狀態**：已修正並驗證。

### MR-002 首頁文案偏向製作說明，未直接服務學習

- **回饋**：來源範圍、原題收錄與版本說明對學員沒有直接幫助；課程文案應聚焦基礎操作與通過考試。
- **範圍**：課程首頁、Part 3 入口、Part 2 頁面標題與說明。
- **修正**：首頁改為「從基礎操作到概念題、操作題、代表實作」的學習結果；「這門課怎麼學」直接說明 Part 1–3 的順序與每題檢查方法；Part 3 改為操作題解題順序；移除自製、原題、下載包與不承諾等製作端用語。
- **驗證**：相關關鍵字在學員 HTML 無命中；全課 lint 0／0／0；首頁、Part 3 與概念題頁 copy audit 均為 0 warning。
- **狀態**：已修正並驗證。

### MR-003 Markdown 下載與低價值跳轉中斷學習

- **回饋**：Markdown 不適合一般學員閱讀；從講義跳到只有少量說明的檔案，沒有足夠學習價值。
- **範圍**：首頁三個資源按鈕、首頁導覽列、PRAC1、CH3-1。
- **判斷**：讀題卡內容已在 Part 3 六步讀題法中呈現；證據清單已在 PRAC1 與各課完成檢查中呈現；官方目標 PDF 屬課程設計參考，不是學員主流程。
- **修正**：移除所有學員 HTML 對 Markdown 檔案的連結、重複下載按鈕及首頁官方目標文件跳轉；必要內容保留在使用當下的講義頁內。
- **驗證**：14 個學員 HTML 已無 `.md` 連結、資源按鈕或官方目標按鈕；全課 lint 0／0／0；相關三頁 copy audit 0 warning。
- **狀態**：已修正並驗證。

### MR-004 英文介面名詞缺少初學者解釋

- **回饋**：軟體介面使用英文沒有問題，但第一次接觸 AE 的學員難以記住陌生名詞。
- **範圍**：Part 1 的 CH1-1～CH1-5、PRAC1，以及六份正式教案來源。
- **修正**：每課開頭加入「本課英文名詞」，以英文介面名稱、中文理解與實際用途建立對照；各課只新增該課首次引入的核心名詞。PRAC1 改為整合前快速複習，不再引入新工具。
- **驗證**：六頁各有一個可存取的名詞區塊，共 68 張名詞卡；HTML 名詞與說明成對、ID 無重複，手機版改為單欄。`validate-handout.py` 通過；全課 lint 0／0／0；Part 1 copy audit 無 BLOCK；課程內容檢查 10 頁均為 machine checked、0 block。
- **狀態**：已修正並完成機器驗證，等待人工逐頁確認閱讀感受。
