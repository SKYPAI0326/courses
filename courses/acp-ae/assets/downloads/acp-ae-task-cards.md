# ACP After Effects 讀題與操作卡

## 使用方法

每次進入 AE 前先寫完以下內容：

1. 任務動詞：建立、修改、套用、關閉、輸出或其他。
2. 作用對象：Project item、Composition、Layer、屬性、Effect、Render item。
3. 作用層級：Project / Composition / Layer / Effect / Time / Render。
4. 指定值與時間：單位、起訖、數值、格式。
5. 不得改動項目：題幹沒要求的層、Keyframe、圖層順序或輸出條件。
6. 完成證據：會在哪個面板、數值、開關或畫面看到。
7. 復原位置：Undo、Reset、None、前一版工程或題組副本。
