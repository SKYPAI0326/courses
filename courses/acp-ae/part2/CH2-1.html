十三題概念判斷與排除

每一題都照四步作答：找線索、說考點、選答案、排除錯項。這樣題目換一種說法時，你仍能自己判斷。

學習成果
完成 13 題四欄解析與三項易混淆清單。
用作用範圍、單位、時間與權利條件排除干擾項。
把 AE 概念對應到 PRAC1 工程的真實結構。
(01)

Step by Step：每一題都用四步作答

第一個動作
在第 1 題先圈出「指定線交點」與「畫面右上」，再看選項。能先說出題目在考什麼，就是第一個成功訊號。
01
圈出題幹線索
只圈會改變答案的字詞，例如「右上交點」「每秒」「下方圖層」。先不要猜答案字母。
02
說出題目在考什麼
判斷它屬於視覺與流程、權利與無障礙，或媒體與 AE 概念。
03
選答案並寫依據
用完整句子寫：「因為題幹出現＿＿，所以答案是＿＿。」只寫 A、B、C、D 不算完成。
04
排除最容易混淆的選項
寫出錯項屬於什麼概念，以及它為什麼不符合本題條件。

完整示範：第 1 題

欄位示範內容
題幹線索「指定線交點」「畫面右上」
考點構圖參考線與交點
答案與依據A。三分法網格會產生可供對齊的交點。
排除理由B 是畫面中心；C 是畫布邊角；D 是時間範圍。
Checkpoint
第 1 題四欄都有文字後才進入第 2 題。若只有答案字母，回到步驟 1。
(02)

十三題概念練習

1. 主體要對齊畫面右上的「指定線交點」，最合理的參考是？
A 三分法網格交點　B 正中心點　C 畫布邊角　D Work Area 終點
展開答案與理由
A。「指定線交點」對應三分法網格；B/C 不是同一構圖依據，D 是時間區間。
2. 尚未拍攝，要先確定鏡頭、動作與畫面順序，最直接的文件是？
A Storyboard　B Render Queue　C Output Module　D Proxy
展開答案與理由
A。Storyboard 屬前期；B/C 是輸出，D 是媒體替代物。
3. 員工在工作範圍內為雇主製作動畫，判斷權利歸屬的第一步是？
A 查雇用／委任合約與適用法規　B 查分辨率　C 查 Blending Mode　D 查 Keyframe
展開答案與理由
A。權利不由技術設定決定；實際案例依當地法規與專業意見。
4. 29.97 fps 中的 fps 代表？
A 每秒影格數　B 每影格像素　C 音訊採樣　D 品質等級
展開答案與理由
A。fps 描述每秒影格數，不是空間解析度或音訊採樣。
5. 文字圖層增加 Extrusion Depth，最直接的結果是？
A 沿 Z 軸增加厚度　B 增加時間長度　C 加音訊　D 轉為影像序列
展開答案與理由
A。Extrusion 是空間深度，與時間、音訊或輸出格式無關。
6. 不考慮混合、透明與 Matte，上方不透明圖層與下方圖層重疊時會？
A 上層遮住下層　B 下層永遠在前　C 自動平均混合　D 順序不影響
展開答案與理由
A。題幹已排除透明與混合的例外。
7. Position 要在 0–2 秒從左移到右，最少需要？
A 起點與終點的兩個 Position Keyframe　B 一個 Opacity Keyframe　C 一個 Marker　D 一個 Mask
展開答案與理由
A。單一值無法定義改變的起訖。
8. 影片主要資訊來自口述，要協助不便聽取聲音的觀眾，最直接的做法是？
A 同步且經校對的字幕　B Motion Blur　C 提高 fps　D 背景變黑
展開答案與理由
A。字幕把語音資訊轉為可讀文字；其他選項不會。
9. 把 Work Area 改為 0–6 秒，對 8 秒圖層的直接影響是？
A 圖層仍可保留 8 秒，預覽／指定輸出可用 0–6 秒　B 後兩秒永久刪除　C 自動變速　D 自動加 Time Remap
展開答案與理由
A。Work Area 是區間指定，不等於 Trim Layer 或 Time Stretch。
10. 圖層從快速移動逐漸減速停下，對應的動畫原理是？
A Slow In / Slow Out　B 對稱構圖　C 白平衡　D 影像序列
展開答案與理由
A。線索是速度在終點前改變。
11. Adjustment Layer 上套色彩效果且沒有 Mask，通常影響？
A 時間與空間範圍內的下方圖層　B 只影響上方　C 只影響 Project　D 所有關閉的 Composition
展開答案與理由
A。作用範圍由圖層堆疊、時間與自身透明度共同決定。
12. 先修正影像偏藍與曝光不一，這一階段較接近？
A Color Correction　B 風格化 Color Grading　C Motion Tracking　D Rotoscoping
展開答案與理由
A。修正技術問題與不一致性是校正；風格化通常在正確基礎上進行。
13. 使用 Creative Commons 素材前，最完整的第一步是？
A 辨識授權元素與版本，查原始授權頁的姓名標示、改作與商業條件　B 下載就自由用　C 改色就可用　D 只看檔名
展開答案與理由
A。CC 不是單一條件，必須回原始授權頁查證。
(03)

Step by Step：變式、完成檢查與修復

變式練習
  1. 從 13 題挑三題，抄下原本關鍵條件。
  2. 每題只改一個條件，例如把第 11 題的 Adjustment Layer 改成一般 Solid。
  3. 遮住原答案，重新執行上方步驟 1–4。
  4. 寫出答案是否改變，以及造成改變的那一個條件。
  5. 通過標準：三題都有條件、答案與理由。
完成檢查
13 題都有答案、線索、依據、排除理由；至少三題能指出「條件一改，答案就可能改變」；權利題保留合約與原始授權頁查證。
修復
只記字母
遮住選項，先說題目在測哪個關係。
排除理由空白
對每個干擾項寫出它的作用層級與題幹差異。
授權不確定
保留原始連結與授權頁擷圖，無法確認時不使用。
