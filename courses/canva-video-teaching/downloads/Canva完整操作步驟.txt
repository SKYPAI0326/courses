CH1-1
建立你的第一個影片專案
這門課要練習的是 Canva 影片製作。你會先用一套完整的校園介紹素材操作，讓每個人都能用相同檔案核對結果；英文與圖書館只是本次示範內容，之後可以換成中文或其他學科題材。第一場將實拍片段剪成可播放的畫面版，加入位置圖、活動標籤與動態提示；第二場在同一作品加入自己的講解與字幕。

練習選取與復原
這一段確認你能移動、復原並再次開啟專案，之後操作失誤或離開頁面時才找得回工作。
將標題拖到畫面上方。若位置偏離，用工具列的「復原」回到前一個狀態。Mac 可用 Command + Z，Windows 可用 Ctrl + Z。
複製案例文字時，先拖曳選取文字，再用 Command + C 或 Ctrl + C；回到 Canva 點進文字框，用 Command + V 或 Ctrl + V 貼上。

匯入，讓影片成為主要畫面
在左側「上傳 → 上傳檔案」選
stock-library-walk.mp4

新版多軌
：將影片拖到下方較粗的主軌。主軌的片段會依序播放；不要拖到文字所在的上層軌。若原有空白主軌片段仍在，選它按 Delete，保留走道片段。
既有頁面
：將影片加入第一頁並選取影片。點上方素材工具列右端的「更多」（三個點），開啟「位置」，切換到「圖層」，再點影片旁的三個點，選「設為背景」。影片應填滿畫布。若它另建一頁，將起初的標題複製到影片頁，刪掉多餘空白頁。
把播放頭拉到片段中間，按播放。確認看到會移動的實拍畫面。若只有小影片浮在白底上，先將影片移到主軌／設為背景。
影片作背景時可覆蓋文字；先不要反覆新增標題，稍後用圖層把已有文字帶回前方。
分清楚「裁短」和「裁切」
裁短會改變保留的時間；裁切會改變可見畫面範圍。例如把原片中約第 2–12 秒留下來，是十秒裁短。保留這十秒、只把構圖移向人物，屬於裁切。

調整構圖
在畫布上選影片，開啟工具列「裁切」，或點兩下影片進入裁切。拖曳畫面內的影像調整可見範圍，按「完成」／點外側結束。保留人物與書架，避免為了填滿畫面將主體切掉。不要把裁切框當成時間裁剪。
沒有明顯裁切工具時，先確認選到影片而非文字，再看「更多」；影片原本就是 16:9，主流程可先沿用完整畫面，另練習縮放與人物位置。

把教材整理成第一段畫面
你的專案已有標題。現在要讓學生看到圖書館的位置，請使用
案例原文

The library is next to the cafeteria.
這句話回答「圖書館在哪裡」。原文中的閱讀、自習與音量提醒各有不同用途；本段先呈現位置，下一段再介紹活動。
把一句話放進畫面
點標題文字框外框。上方會出現字型與字級工具列；點字級數字，輸入 64，按 Enter。拖曳文字框到畫面上方，四周留下空間。

It's next to the cafeteria.

另外加入兩個文字框，分別輸入
Library
、
Cafeteria
，放在對應矩形內。將文字設為 36。
在兩個矩形之間加入
next to
。讓文字與矩形之間保持間距。
你會看到一個問題、一句回答及兩個相鄰地點。圖形提供位置線索，句子提供學生可以說出口的表達。
檢查文字能否讀完
將畫面縮放到整頁可見，讀出問題和答案。若文字超出邊界，先把文字框拉寬；仍太擠時，將長句分成兩行。標題與內文分開調整，保留 Library 和 Cafeteria 的辨識空間。
如果文字被矩形蓋住，選取該文字框，在「位置」調整前後順序，移到矩形前方。若無法選到文字，可先移開矩形，修改後再放回。

複製、排序與群組的用途
複製文字可保留字型與底色，但新文字也會繼承原來的顯示時間；一定要移到新片段的位置。拖主軌片段可改順序；拖上層標籤只改標籤時間。群組用來一起移動相關物件，不能替你判斷它們應在哪一段出現。
自己完成：找出第二個標籤最適合放置的位置，不遮住手上的書或筆電。用時間軸核對四個片段總長為 36 秒，三個教學重點仍為位置、活動、提問。保存 v1，休息後再調整文字出現方式。

處理播放問題
如果改完後全片明顯變長，逐頁查看長度，確認只有預定場景被修改。如果畫面只停在一頁，先查看你啟動的是單頁預覽還是整支影片播放，回到完整時間軸再播放。
本例用直接換頁呈現順序。想提醒觀眾注意位置時，先用框線或顏色標示 next to，再播放確認提示與閱讀時間相容。

選已下載的模型；依錄音設定語言。中英混合內容轉錄後逐句核對兩種語言。
在 Whisper task 選轉錄原語言（Transcribe），保留原本中英文內容。先在「Settings → Outputs」勾選 SRT 與 TXT，確認輸出資料夾；預設會放在母片旁。回到轉錄頁開始處理。
完成後開啟輸出資料夾，找到與母片對應的檔案。
一邊播放母片，一邊檢查字幕文字；把修訂結果另存為
姓名_主題_校訂.srt
，保留原始輸出。
下面是本課參考母片前兩句的字幕格式。請播放母片核對這兩段時間：
1
00:00:01,000 --> 00:00:02,291
Where is the library?

2
00:00:04,291 --> 00:00:06,064
It's next to the cafeteria.
序號下方是開始與結束時間，最後一行是顯示文字。你的字幕時間必須對應自己的錄音。若某句提早出現，回到該字幕片段修正時間，再重播確認。

製作字幕影片
開啟 Hardsub Studio，分別在影片欄位選
姓名_主題_母片.mp4
，在字幕欄位選
姓名_主題_校訂.srt
。影片預覽旁應出現字幕句子清單；點一句會跳到相應時間。選支援繁體中文的字型，位置選底部中央，先用白字、深色外框及適合影片的字級。預覽第一句、中央場景及最後一句。確認字幕能顯示中英文且沒有遮住教學內容，在輸出設定選 MP4、H.264 及保留原尺寸，指定另存的檔名
姓名_主題_字幕版.mp4
，開始輸出。完成後按「Play Exported Video」或到輸出資料夾開啟 MP4，核對開頭、中間及結尾，確認聲音與字幕都有保存。
若作業系統阻止開啟程式，先停在提示畫面，請裝置管理人員確認官方來源與可用方式。若找不到模型，回 Model Hub 查看下載是否完成。轉錄太慢時，可依官方硬體說明改用較小模型；結果仍需人工校訂。字幕顯示方框時，更換支援該語言的字型再輸出。
程式的轉錄與影片編碼在本機進行；額外 AI 翻譯使用自行設定的服務，費用和傳送內容依該服務而定。本練習使用本機轉錄與字幕輸出。
