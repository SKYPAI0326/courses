# 操作時的技巧與修復

先找到你目前遇到的情況，再開啟對應單元。返回作品前，確認開的是自己的 Canva 專案。

| 目前的任務或問題 | 先做的處理 | 完整操作 | 修復後檢查 |
|---|---|---|---|
| 要把一段教材做成影片 | 寫出學生看完要做的一件事，選出必要句子 | [開一支新影片，認識 Canva 的剪輯桌面](../../../_lessons/canva-video-teaching/CH1-1.md) | 每個場景都支援同一個教學重點 |
| 文字被影片或圖形蓋住 | 選取文字調整圖層順序，或先移開圖形 | [把走道影片放上主軌，做出第一個場景](../../../_lessons/canva-video-teaching/CH1-2.md) | 所有文字完整可見 |
| 片段畫面不是想要的那一段 | 選主軌片段用滑移換一段原片，片長不變 | [接上閱讀與自習，排出三個場景](../../../_lessons/canva-video-teaching/CH1-3.md) | 人物動作完整，片段仍是六秒 |
| 答案太早出現，或還沒讀完就換片段 | 拖上方文字條邊緣調整元素時間；動畫太長就縮短 | [讓文字準時出現，再加一點動態](../../../_lessons/canva-video-teaching/CH1-4.md) | 語句讀完才換片段，答案第 2 秒才出現 |
| 換題目後畫面與文字對不上 | 用「取代」換影片，再改活動句；逐段播放 | [換一個主題，用同一套方法再做一次](../../../_lessons/canva-video-teaching/CH1-5.md) | 名稱、活動、畫面和問題一致 |
| 下載出現付費提示 | 找出有皇冠標示的素材或效果，換成免費項目 | [下載畫面版，留好下次的入口](../../../_lessons/canva-video-teaching/CH1-6.md) | 下載的影片可正常播放 |
| 錄製沒有聲音 | 查看瀏覽器網站權限與麥克風，錄一句測試 | [錄下自己的講解，再用 AI 語音做英文示範](../../../_lessons/canva-video-teaching/CH2-2.md) | 聽得到完整測試句 |
| AI 語音額度用完 | 改用自己錄音，或用課程 WAV 先完成對齊 | [配音與聲音製作](配音與聲音製作.md) | 每段畫面都有一份清楚的講解 |
| 剪輯後少了一個字 | 復原，保留語句前後空間再分割 | [剪掉停頓、配上音樂](../../../_lessons/canva-video-teaching/CH2-3.md) | 接合處能完整聽懂 |
| 配樂蓋過講解 | 選配樂，把音量調到 10–20，再試「全部平衡」 | [剪掉停頓、配上音樂](../../../_lessons/canva-video-teaching/CH2-3.md) | 戴耳機每一句都聽得清楚 |
| 字幕有錯字或不同步 | 在輔助字幕面板改字，拖字幕邊緣對齊說話時間 | [自動上字幕，再校正與翻譯](../../../_lessons/canva-video-teaching/CH2-4.md) | 文字及出現時間對應聲音 |
| 英文字幕辨識成中文，或反過來 | 刪掉這次字幕，重開面板只勾同一種語言的音訊，口說語言按「編輯」選對 | [自動上字幕，再校正與翻譯](../../../_lessons/canva-video-teaching/CH2-4.md) | 英文語音配英文字幕，中文講解配中文字幕 |
| 學生打不開觀看連結 | 確認建立的是可供檢視連結，用無痕視窗重開 | [下載有聲字幕版，分享給學生觀看](../../../_lessons/canva-video-teaching/CH2-6.md) | 無痕視窗不登入也能播放 |

修復時先處理一個問題，確認結果後再做下一項修改。作品要大幅改題材時，先建立複本。

## 時間軸常見狀況

| 現象 | 先查什麼 | 修復後確認 |
|---|---|---|
| 主要影像變成小視窗 | 影片是否放在上方軌 | 移回主軌，畫面填滿 |
| 背景擋住標題 | 圖層前後順序 | 文字在前、底板在中、影片在下 |
| 活動句跨到錯誤片段 | 複製文字後的起訖 | 拖上方文字條，只在對應片段顯示 |
| 時間軸只有一頁頁縮圖 | 是否開到舊設計 | 改看[舊專案相容處理](舊專案相容處理.md)，或新建影片 |
| 聲音重疊 | 背景原音、重複旁白 | 靜音背景或刪掉重複的錄音，再回聽 |
| 下載的影片沒有字幕 | 是否只開了 Canva 播放器的顯示字幕 | 改用輔助字幕或[手動補字幕](時間軸與字幕實作.md)，重新下載 MP4 |

完整功能與延伸見[Canva 功能與技巧](Canva功能與技巧.md)。

## 配音怪、兩種語言搶話或字幕對不上

先關配樂，確認音訊軌只留一份旁白。AI 語音的中文選台灣中文、英文選對應英文語言，各產生完整短句；先聽同稿短樣再決定聲線。剪接點保留字音，換語言時留理解時間。換聲音後重新產生並校正字幕。詳細入口、同稿短樣與分句檔見[配音與聲音製作](配音與聲音製作.md)。
