# 操作時的技巧與修復

先找到你目前遇到的情況，再開啟對應操作。返回作品前，確認使用自己的 Canva 專案。

| 目前的任務或問題 | 先做的處理 | 完整操作 | 修復後檢查 |
|---|---|---|---|
| 要把一段教材做成影片 | 寫出學生看完要做的一件事，選出必要句子 | [教材取捨](../../../_lessons/canva-video-teaching/CH1-2.md) | 每個場景都支援同一個教學重點 |
| 換題目後畫面放不下 | 拉寬文字框或換行，重新朗讀與播放 | [替換教材](../../../_lessons/canva-video-teaching/CH1-5.md) | 名稱、活動、畫面和問題一致 |
| 文字被蓋住 | 選取文字調整前後順序，或先移開圖形 | [文字與圖形](../../../_lessons/canva-video-teaching/CH1-2.md) | 所有文字完整可見 |
| 還沒讀完就換頁 | 選取該頁延長時間，再從前一頁開始播放 | [播放節奏](../../../_lessons/canva-video-teaching/CH1-4.md) | 語句讀完且有必要停頓 |
| 錄製沒有聲音 | 查看網站權限與麥克風，錄一句測試 | [錄製講解](../../../_lessons/canva-video-teaching/CH2-2.md) | 能聽到完整測試句 |
| 只說錯其中一段 | 重錄該段，確認新錄影後移除頁面舊片段 | [分段錄製](../../../_lessons/canva-video-teaching/CH2-2.md) | 只有預定講解出聲 |
| 剪輯後少了一個字 | 復原，保留語句前後空間再裁剪 | [裁短與分割](../../../_lessons/canva-video-teaching/CH2-3.md) | 接合處能完整聽懂 |
| 字幕有錯字或不同步 | 回聽對應片段；重剪後重新核對字幕 | [字幕校訂](../../../_lessons/canva-video-teaching/CH2-4.md) | 文字及出現時間對應錄音 |
| 下載出現付費提示 | 找出標示付費的素材，改用自製圖形或已確認免費素材 | [匯出影片](../../../_lessons/canva-video-teaching/CH1-6.md) | 下載影片可正常播放 |
| 接收者無法開啟連結 | 檢查分享接收者與檢視權限 | [分享與交付](../../../_lessons/canva-video-teaching/CH2-6.md) | 對方從自己的帳號能開啟 |

修復時先處理一個問題，確認結果後再做下一項修改。作品要大幅改題材時，先保存副本。


## 實拍與新版時間軸的修復

| 現象 | 先查什麼 | 修復後確認 |
|---|---|---|
| 主要影像變小視窗 | 影片是否放上層軌 | 移回主軌，畫面填滿 |
| 背景擋住標題 | 圖層前後順序 | 文字在前、底板在中、影片在下 |
| 標籤跨到錯誤活動 | 複製文字的起訖 | 修正文字軌，只在對應片段顯示 |
| 沒有時長／剪刀 | 是否新版多軌 | 直接拖片段邊緣裁短 |
| 聲音重疊 | 背景原音／重複旁白 | 靜音背景或刪重複錄音，再回聽 |
| 下載影片沒有字幕 | 是否只有觀看字幕 | 改用可匯出字幕／定時文字，重下 MP4 |

完整功能與延伸見[Canva 功能與技巧](Canva功能與技巧.md)。


## 配音怪、兩種語言搶話或字幕對不上

先關配樂，確認音訊軌只留一份旁白。中文選台灣中文、英文選對應英文語言，各生成完整短句；先聽同稿樣本再決定聲線。剪接點保留字音，換語言時留理解時間。換聲音後按新母片重新校訂字幕；舊十秒分割練習的切點不套在新版。詳細入口、同稿短樣與分句檔見[配音與聲音製作](配音與聲音製作.md)。
