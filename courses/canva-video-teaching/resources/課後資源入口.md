# 製作下一支教學短片

準備一個教學重點，從你已完成的 Canva 作品建立複本，再替換文字、畫面與講解。每次改題材都重新播放，檢查聲音與字幕是否仍對應新內容。

先完成[時間軸與字幕實作](時間軸與字幕實作.md)，確認你能獨立選取背景、文字與聲音；想換教材用途時，用[概念比較完整案例](案例與腳本.md)重排資訊，再依[個人操作紀錄](../downloads/個人Canva操作紀錄.txt)留下可重現的修改。

## 先選需要的材料

| 目前要做的事 | 開啟的資源 | 會得到什麼 |
|---|---|---|
| 將教材安排成三段 | [案例與腳本](案例與腳本.md) | 完整例句、講解及轉用方法 |
| 配音聽不清或想換聲線 | [配音與聲音製作](配音與聲音製作.md) | Canva 免費聲線短樣、分語言生成、接句與字幕換版 |
| 帶學生做影片 | [學生製作任務](學生製作任務.md) | 可修改的任務、繳交內容與規準 |
| 忘記操作或遇到問題 | [技巧與修復卡](技巧與修復卡.md) | 返回原教案的操作入口與修復方式 |
| 找圖片及短影片 | [Pexels](https://www.pexels.com/) | 可挑選的素材；使用前閱讀[授權](https://www.pexels.com/license/) |
| 找配樂或音效 | [YouTube Audio Library 說明](https://support.google.com/youtube/answer/3376882?hl=zh-Hant) | 素材下載與署名方法；逐曲確認使用條件 |
| 將錄音轉成文字或 SRT | [WhisperDesktop 延伸教案](../../../_lessons/canva-video-teaching/EXT1.md) | 本機轉錄、字幕校訂及輸出方法 |

使用外部素材時，把原頁網址與需要的署名文字存進專案紀錄。錄到人物前先取得同意；畫面避免出現學生姓名、帳號及個人資料。

## 起始設計與操作技術

作品找不到時，從[三頁起始檔](三頁起始檔.md)在自己的帳號恢復。文字檔、SRT 保存與素材上傳方法請查[操作與檔案技術卡](操作與檔案技術卡.md)。

## 保存作品

把相關檔案放進同一個資料夾，使用能辨識內容的名稱：

- `姓名_圖書館_v1.mp4`：第一場的畫面版。
- `姓名_圖書館_母片.mp4`：第二場字幕前的有聲版本。
- `姓名_圖書館_v2.mp4`：完成字幕的版本。
- `姓名_圖書館_專案紀錄.txt`：Canva 連結與素材來源。

使用 WhisperDesktop 時，再保存原始與校訂後的 SRT。SRT 記錄文字與顯示時間，需要搭配影片使用。

## 專案紀錄範例

```text
主題：圖書館
教學重點：介紹位置及一項活動
v1 專案網址：貼上第一場畫面版設計的編輯網址
v2 專案網址：貼上第二場複本的編輯網址
分享檢視網址：貼上設定可供檢視後複製的網址
第一場檔案：姓名_圖書館_v1.mp4
母片檔案：姓名_圖書館_母片.mp4
第二場檔案：姓名_圖書館_v2.mp4
素材來源：文字與校園設定取自本課案例；位置圖自行繪製
下次修改：替換成實際校園照片並核對地點關係
```

## 下載帶回去的檔案

開啟[素材與成品](素材與成品.md)，下載文字工作包與影音練習包。文字工作包包含腳本表、學生任務、專案紀錄與修復卡；影音包包含畫面版、有聲母片、字幕版、練習片段及 SRT。

[免費素材](免費素材.md)列出本課自製圖形、外部圖片及配樂入口，使用前先記下每份素材的來源與條件。

## 保存整份網頁講義

下載[離線講義包](../downloads/canva-handouts-offline.zip)，解壓縮後開啟 `index.html`。保留資料夾中的檔案位置，單元連結、參考影片與文字材料即可一起使用。Canva 操作與外部網站需要網路。


## 下次做實拍短片

先打開[Canva 功能與技巧](Canva功能與技巧.md)，依需求選模板替換、速度、自訂動畫、畫中畫或直式重排。再由[素材取得頁](免費素材.md)找影片，把新原片加入專案副本。課堂實拍 ZIP、來源紀錄和自製配樂可保留供下一次練習。
