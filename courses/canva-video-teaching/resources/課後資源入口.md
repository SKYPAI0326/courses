# 製作下一支教學短片

準備一個教學重點，從你已完成的有聲字幕版建立複本，再替換畫面、文字、旁白、字幕與最後的提問。每次改題材都重新播放，檢查聲音與字幕是否仍對應新內容。

想多練時間軸與字幕，先看[時間軸與字幕實作](時間軸與字幕實作.md)的時間實驗、十秒分割與手動補字幕；想換教材用途時，用[概念比較完整案例](案例與腳本.md)重排資訊，再依[個人操作紀錄](../downloads/個人Canva操作紀錄.txt)留下可重現的修改。

## 先選需要的材料

| 目前要做的事 | 開啟的資源 | 會得到什麼 |
|---|---|---|
| 將教材安排成三段 | [案例與腳本](案例與腳本.md) | 完整例句、講解及轉用方法 |
| 配音聽不清或想換聲線 | [配音與聲音製作](配音與聲音製作.md) | Canva 免費聲線短樣、分語言產生、接句與字幕換版 |
| 帶學生做影片 | [學生製作任務](學生製作任務.md) | 可修改的任務、要用到的 Canva 功能、繳交內容與規準 |
| 忘記操作或遇到問題 | [技巧與修復卡](技巧與修復卡.md) | 回到對應單元的入口與修復方式 |
| 找影片、圖片與配樂 | [找到下一支影片需要的素材](免費素材.md) | Canva 圖庫影片、音樂庫與外部素材的使用方式 |
| 找 Canva 以外的圖片及短影片 | [Pexels](https://www.pexels.com/) | 可挑選的素材；使用前閱讀[授權](https://www.pexels.com/license/) |
| 找 Canva 以外的配樂或音效 | [YouTube Audio Library 說明](https://support.google.com/youtube/answer/3376882?hl=zh-Hant) | 素材下載與署名方法；逐曲確認使用條件 |
| 將錄音轉成文字或 SRT | [WhisperDesktop 延伸教案](../../../_lessons/canva-video-teaching/EXT1.md) | 本機轉錄、字幕校訂及輸出方法 |

使用外部素材時，把原頁網址與需要的署名文字存進專案紀錄。錄到人物前先取得同意；畫面避免出現學生姓名、帳號及個人資料。

## 起始設計與操作技術

作品找不到時，從[三頁起始檔](三頁起始檔.md)在自己的帳號恢復。文字檔、SRT 保存與素材上傳方法請查[操作與檔案技術卡](操作與檔案技術卡.md)。

## 保存作品

把相關檔案放進同一個資料夾，使用能辨識內容的名稱：

- `姓名_圖書館_畫面版.mp4`：第一場的無聲畫面版。
- `姓名_圖書館_有聲字幕版.mp4`：第二場加上講解、配樂與字幕的版本。
- `姓名_圖書館_專案紀錄.txt`：兩份 Canva 專案網址、檢視連結與素材來源。

使用 WhisperDesktop 時，再保存原始與校訂後的 SRT。SRT 記錄文字與顯示時間，需要搭配影片使用。

## 專案紀錄範例

```text
主題：圖書館
教學重點：介紹位置及一項活動
畫面版專案網址：貼上第一場畫面版設計的編輯網址
畫面版 MP4 檔名：姓名_圖書館_畫面版.mp4
有聲字幕版專案網址：貼上第二場複本的編輯網址
有聲字幕版 MP4 檔名：姓名_圖書館_有聲字幕版.mp4
檢視連結：貼上在無痕視窗確認過的觀看網址
素材來源：走道、閱讀、自習取自 Pexels；提問背景與配樂取自 Canva 圖庫與音樂庫
下次修改：替換成實際校園影片並核對地點關係
```

## 下載帶回去的檔案

開啟[素材與成品](素材與成品.md)，下載文字工作包與影音練習包。文字工作包包含腳本表、學生製作任務、專案紀錄與修復卡；影音包包含畫面版、有聲版、有聲字幕版、練習片段及 SRT。

## 保存整份網頁講義

下載[離線講義包](../downloads/canva-handouts-offline.zip)，解壓縮後開啟 `index.html`。保留資料夾中的檔案位置，單元連結、參考影片與文字材料即可一起使用。Canva 操作與外部網站需要網路。

## 下次做實拍短片

先打開[Canva 功能與技巧](Canva功能與技巧.md)，依需求選模板替換、速度、自訂動畫、畫中畫或直式重排。新影片可以先在 Canva 圖庫影片搜尋，或由[素材取得頁](免費素材.md)從 Pexels 下載，再加入專案複本。課堂實拍 ZIP 與來源紀錄可保留供下一次練習。
