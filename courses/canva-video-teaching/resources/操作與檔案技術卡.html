操作與檔案技術卡

完成這一頁
開啟與另存 TXT、SRT，修正字幕並上傳素材。
本頁操作
  1. 準備開始
  2. 開啟、修改與保存文字檔
  3. 修改一份 SRT 字幕
  4. 上傳素材到指定頁面
  5. 下次修改與學生分組
  6. 改片長與獨立音訊的交接
(01)

準備開始

先下載現成紀錄或字幕練習檔，在電腦上開啟，再修改內容。把課程檔案集中在一個資料夾，方便下一次接續製作。

(02)

開啟、修改與保存文字檔

Windows

  1. 下載專案紀錄.txt，在檔案總管「下載」找到它。按右鍵，選「開啟方式 → 記事本」。
  2. 點要填寫的欄位後方，輸入文字或貼上網址，按 Ctrl+S 儲存。
  3. 要換檔名或另存位置時，按 Ctrl+Shift+S。檔名輸入 王老師_圖書館_專案紀錄.txt，將名字換成自己的名字。
  4. 選保存資料夾，編碼選 UTF-8，再按「儲存」。回資料夾重新開啟，確認中文字和網址完整。

Mac

  1. 在 Finder 的「下載」找到紀錄檔，按右鍵選「打開方式 → 文字編輯」。
  2. 編輯欄位後按 Command+S 儲存。若視窗上方有字型排版工具列，開啟「格式 → 製作純文字」，確認以純文字保存。
  3. 要另存一份時，在「檔案」選「製作複本」，再按 Command+S，輸入 王老師_圖書館_專案紀錄.txt，指定資料夾。
  4. 保存時使用純文字及 UTF-8 編碼。回 Finder 再開啟，確認內容完整。

若文字編輯器在檔名後加上 .txt，保留文字紀錄的副檔名即可。副檔名是檔名最後的 .txt、.srt、.mp4，用來辨認檔案種類。

(03)

修改一份 SRT 字幕

下載字幕校訂練習.srt，使用上方的文字編輯器開啟。若直接開成播放器，改用右鍵「開啟方式」選記事本或文字編輯。旁邊開啟參考母片，回聽前十秒。

練習檔的問題 修正方式 核對結果
第 2 句 coffee area 改成 cafeteria 與錄音中的地點名稱一致
第 3 句簡體字 改成「圖書館在餐廳旁邊。」 文字與講解意思一致
第 3 句從 7 秒開始，9 秒結束 改成 00:00:06,364 --> 00:00:08,715 對應本課母片這句話的時間

第三段修正後應是：

3
00:00:06,364 --> 00:00:08,715
圖書館在餐廳旁邊。

每段包含序號、起訖時間和文字，段與段之間保留空白行。00:00:06,364 表示 6 秒又 364 毫秒；保留英文逗號與箭頭 -->。

將結果另存為 圖書館_校訂.srt，保留原練習檔。Windows 在另存視窗將檔案類型選「所有檔案」，檔名輸入 .srt 結尾，編碼選 UTF-8。Mac 以純文字另存，若詢問是否使用 .srt，選使用 .srt。回資料夾確認檔名沒有變成 .srt.txt，再開啟核對時間。

與完整參考字幕比較前三段。修改自己的字幕時，時間必須依自己的錄音回聽確認。接著在 WhisperDesktop 延伸練習使用校訂檔製作字幕影片。

(04)

上傳素材到指定頁面

  1. 先下載素材，在 Canva 開啟自己的作品，再選左側「上傳 → 上傳檔案」。
  2. 選圖片、音訊或 MP4，等待上傳縮圖出現。
  3. 點要放素材的頁面縮圖，將播放頭移到該頁起點。影片縮圖拖進目前畫面，確認出現可移動的物件外框；直接點影片縮圖可能增加新頁，遇到這種情況先復原，再拖入。圖片點一下加入，檢查它出現在目前頁面。
  4. 圖片或影片用四角縮放並移到預留空間；音訊用時間條定位開始時間。回放前後兩頁，確認文字可讀、聲音只有一份。

影片難以拖到預留位置時，選影片物件，開啟「位置 → 排列 → 進階」。先將「比率」鎖定，再將寬度改為 320，讓高度自動配合。X=1500、Y=60 可作為本課 1920 × 1080 畫面右上方的起始位置。每次點數字欄位先全選舊值，再輸入新值並按 Enter。確認小窗保留完整畫面；若影像被裁掉，復原後用四角等比例縮放，再定位。

拖入的影片會從目前播放頭開始。展開所有素材音軌，將整條影片移到對應頁的起點，再從前一頁播放，確認只有預定的一份講解。

替換錄音時，先確認新檔能播，再選舊錄影或舊音訊條刪除，回聽確認。配樂也會佔一條音軌；先把講解音量調清楚，再降低配樂音量，試聽仍可辨認每一句話。

(05)

下次修改與學生分組

先在「檔案 → 建立複本」保存新版本，改好名稱再編輯。學生取得三頁起始檔後，先各自匯入帳號並改名，確認能修改第一句，再依學生製作任務分工。

小組共編時指定目前負責操作的人，其餘同學核對腳本、回聽聲音或檢查字幕。每完成一段，記下目前版本網址和待改事項，再交接給下一位同學。

(06)

改片長與獨立音訊的交接

先更新片段與聲音時間表，音訊按目前場景起點放置。整條 36 秒 WAV 只適用原版；改某一段長度時用分句檔重排或重錄。時間軸與字幕實作有選取「所有音訊」、校訂清單及下載的實測畫面。
