# 素材與成品

先選你目前需要的檔案。檔案下載後放進同一個資料夾，保留你自己的專案與錄音。

## 實拍主案例與素材

[下載實拍練習包](../downloads/canva-stock-practice.zip)。先用 [走道](../assets/media/stock-library-walk.mp4)、[閱讀](../assets/media/stock-reading.mp4)、[自習](../assets/media/stock-study.mp4) 三支原片，在 Canva 中裁短、裁切、排序與加入前景文字。完整取得方式與來源見[免費素材](免費素材.md)。

<video controls preload="metadata" poster="../assets/media/footage-poster.png" aria-label="實拍主案例字幕版成果對照"><source src="../assets/media/footage-v2.mp4" type="video/mp4"></video>

| 成果 | 用途 |
|---|---|
| [實拍畫面版 v1](../assets/media/footage-v1.mp4) | 36 秒無聲剪接：走道十秒、閱讀六秒、自習六秒、提問十四秒 |
| [實拍有聲母片](../assets/media/footage-master.mp4) | 對照畫面與講解；尚無字幕 |
| [實拍字幕版 v2](../assets/media/footage-v2.mp4) | 完整成果對照，底部字幕已合成進影片 |
| [新版配音 SRT](../assets/media/footage-corrected.srt) | 九句字幕對應 Lisa 英文＋子晴台灣中文；自己錄音時另校訂 |
| [新版文字稿](../assets/media/footage-transcript.txt) | 閱讀、自習各有一組雙語講解 |

以上三支是本課本機合成的成果對照，包含 Pexels 活動影像、自製文字與 Canva AI 語音講解（英文 Lisa、台灣中文子晴），用來比較製作前後。Canva 操作請在自己的設計裡依講義完成；直接上傳已合成成品不能再分別修改它的原文字與字幕。生成語音已在 Canva 匯出，再於本機擷取、分段並合成到實拍畫面，整支成果不是 Canva 匯出。下面原文字版媒體保留舊聲音和時點，作排版、分割與補句練習。

## Canva 實際匯出的四片段示範

這支 [36 秒操作示範 MP4](../assets/media/canva-footage-demo.mp4)在 Canva 裁短三支原片、排成四片段，加入可編輯前景文字、SVG 位置圖及獨立 WAV；字幕由 Canva 生成，再校訂繁體字與英文空格。由 Canva 直接匯出 1080p MP4。可對照[時間軸與字幕實作](時間軸與字幕實作.md)的真實中間畫面，重新完成自己的可修改版本。

## 配音短樣與分句檔

開啟[配音與聲音製作](配音與聲音製作.md)，直接播放子晴、彥廷同稿短樣，查看真人錄製、Canva AI 語音和外部 TTS 的使用方法。[36 秒旁白 WAV](../assets/media/reference-narration.wav)對齊原實拍圖書館版；資源頁另提供九個分句 WAV，轉用時可只替換活動句。

## 文字工作包

[下載文字工作包](../downloads/canva-text-pack.zip)。解壓縮後可開啟文字檔與 CSV 表格，替換成你的教材。

| 檔案 | 使用方法 |
|---|---|
| 校園案例與腳本.txt | 複製例句與講解文字到自己的作品 |
| 三場景腳本表.csv | 用試算表開啟，填入每段畫面、講解、材料及時間 |
| 學生製作任務.txt | 改成班級主題後交給學生，附上起始資料 |
| 專案紀錄.txt | 記下 Canva 專案網址、下載檔案與素材來源 |
| Canva完整操作步驟.txt | 依單元編號查閱完整文字步驟，包含字幕修復與課後轉錄 |
| 操作與檔案技術卡.txt | 查文字檔、SRT、素材上傳及學生交接步驟 |
| 三頁起始檔操作.txt | 先用四片段 PPTX 補實拍及時間，再恢復第二場起點；附舊三頁練習 |
| 時間軸與字幕實作.txt | 選對物件、重排時間、選獨立音訊生成字幕 |
| 片段與聲音時間表.csv | 保存實際片段起訖，讓錄音和字幕接續同一版本 |
| 個人Canva操作紀錄.txt | 記下選取、數值、修復與個人完成證據 |
| 配音與聲音製作.txt | 查語言、免費聲線、生成入口、接句與字幕換版 |
| 技巧與修復卡.txt | 依目前的問題找到修復步驟 |
| 作品檢查.txt | 匯出前與交付前逐項確認 |

## 可修改的四片段文字底稿

[下載圖書館_四片段文字底稿.pptx](../downloads/圖書館_四片段文字底稿.pptx)，依[底稿接續操作](三頁起始檔.md)匯入 Canva、轉為影片格式、替換實拍背景及設定 10／6／6／14 秒。它只提供可修改的文字，還需要加入原片、位置圖並調元素起訖，才是第二場可接續的 v1。

原[圖書館_三頁起始設計.pptx](../downloads/圖書館_三頁起始設計.pptx)保留作圖形版練習；同一操作頁附完整轉回四片段步驟。
