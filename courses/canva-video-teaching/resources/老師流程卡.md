# 老師流程卡
列印這一頁，依你要交付的影片類型選一條流程；遇到畫面或權限問題時查[卡住時](卡住時.md)。

## 成果報告影片

1. 把 PPTX 拖進 Canva 首頁，開啟後按「展示簡報」旁下拉箭頭→「展示並錄製」。
2. 按「前往錄製工作室」，允許麥克風後按「開始錄製」，邊講邊翻頁。
3. 按「結束錄製」，回放確認後按「下載」，把 MP4 存到電腦。
4. 回首頁按「建立」→「影片」，把 MP4 拖進左側「上傳」，再拖到下方時間軸。
5. 點影片→「字幕」→確認「套用輔助字幕至」→「產生輔助字幕」，改正錯字。
6. 按「分享」→「下載」→「MP4 影片」→「下載」，用電腦播放器確認字幕仍在。

## 操作教學影片

1. 先開好要示範的網站分頁或視窗，再回 Canva 按「建立」→「影片」。
2. 按「上傳」→「記錄自己」→「螢幕」，想露臉時選「相機與螢幕」。
3. 選要分享的分頁或視窗，邊操作邊說明，完成後按「儲存並結束」。
4. 點時間軸上的錄影→「字幕」→「產生輔助字幕」，從頭播放並改錯字。
5. 按「分享」→「下載」→「MP4 影片」→「下載」，用播放器看一次操作與字幕。

## 輪播影片

1. 把 PPTX 拖進 Canva 首頁，或直接開啟自己的簡報設計。
2. 逐頁設定停留秒數，設定位置畫面以實際為準。
3. 從第一頁預覽，依讀完主要文字所需時間調整各頁秒數。
4. 按「分享」→「下載」→「MP4 影片」，畫質維持預設後下載。
5. 用電腦播放器從頭看到最後，確認每頁自動切換且沒有旁白聲音。

## 範本短片

1. 按「建立」→「影片」→左側「範本」，搜尋主題並選沒有皇冠的範本。
2. 把 MP4 拖進左側「上傳」，再拖到範本原有影片或照片上完成取代。
3. 點兩下改文字，刪掉用不到的頁或片段，從頭播放確認內容。
4. 拖片段邊緣裁短；播放頭移到切點按 S，選不要的段落按 Delete。
5. 從「新增音訊」或左側「音訊」加入無皇冠音樂，有人聲時把音量調低。
6. 按「分享」→「下載」→「MP4 影片」→「下載」，用電腦播放器完整看一次。
