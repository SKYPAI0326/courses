# 老師流程卡
列印這一頁，依你要交付的影片類型選一條流程；遇到畫面或權限問題時查[卡住時](卡住時.md)。

## 成果報告影片

1. 首頁按「建立」→「上傳」→「上傳檔案」選 PPTX，開啟後按「展示簡報」旁下拉箭頭→「展示並錄製」。
2. 按「前往錄製工作室」，選好相機與麥克風後按「開始錄製」，看講稿邊講，按右方向鍵翻頁。
3. 按「結束錄製」，在「你的錄製內容已準備就緒！」按「下載」，把 MP4 存到電腦。
4. 回首頁按「建立」→「影片」→「橫式影片」，把 MP4 拖進左側「上傳」，再拖到下方時間軸。
5. 點影片→「字幕」→「產生輔助字幕」；字幕是簡體字，對照講稿整句貼上繁體。
6. 按「分享」→「下載」→「MP4 影片」→「下載」，用電腦播放器確認字幕仍在。

## 操作教學影片

1. 先開好要示範的網站分頁，再回 Canva 按「建立」→「影片」→「橫式影片」。
2. 按「上傳」→「錄製自己」→「錄製半身說話影片」，模式選「螢幕」，想露臉選「攝影機和螢幕」。
3. Chrome 跳出視窗時選分頁並按「分享」，按「記錄」邊操作邊說明，完成後按「儲存並退出」。
4. 點時間軸上的錄影→「字幕」→「產生輔助字幕」，把簡體字改成繁體。
5. 按「分享」→「下載」→「MP4 影片」→「下載」，用播放器看一次操作與字幕。

## 輪播影片

1. 開啟自己的簡報設計，或從首頁「建立」→「上傳」匯入 PPTX。
2. 點頁面縮圖，按上方工具列的時鐘「5.0秒」輸入秒數；全部相同就按「套用至所有頁面」。
3. 按「展示簡報」旁的下拉箭頭 →「自動播放」看一輪，依讀完主要文字所需時間調整秒數。
4. 按「分享」→「下載」→「MP4 影片」，畫質維持預設後下載。
5. 用電腦播放器從頭看到最後，確認每頁自動切換且沒有旁白聲音。

## 範本短片

1. 按「建立」→「影片」→「橫式影片」→左側「範本」，搜尋主題並選沒有皇冠的範本。
2. 把 MP4 拖進左側「上傳」，再拖到範本原有影片或照片上完成取代。
3. 點兩下改文字，刪掉用不到的頁或片段，從頭播放確認內容。
4. 拖片段邊緣裁短；播放頭移到切點按 S，選不要的段落按 Delete。
5. 從「新增音訊」或左側「音訊」加入無皇冠音樂，有人聲時把音量調低。
6. 按「分享」→「下載」→「MP4 影片」→「下載」，用電腦播放器完整看一次。

## 發給學生與收件

1. 打開學生版流程卡，填好繳交期限、繳交方式與影片長度上限。
2. 示範影片按「分享」→「公開檢視連結」建立並複製連結，用無痕視窗開一次。
3. 「應用程式」搜尋 QR，開「Dynamic QR Codes」，貼上連結按「儲存」，用手機掃一次。
4. 把連結與 QR 碼貼在流程卡開頭，發到班級平台或列印。
5. 收件時用收件檢查表：能播放、字幕是繁體且正確、長度在上限內、檔名有組別與題目。

## 發表會影片

1. 按「建立」→「影片」→「橫式影片」，把通過檢查的 MP4 都放進左側「上傳」。
2. 在第一頁打上活動名稱當片頭。
3. 每組先按時間軸最右邊的「＋」做字卡，再把該組影片拖到時間軸最後面。
4. 從頭播放確認順序，再按「分享」→「下載」→「MP4 影片」→「下載」。
