# Canva 影音剪輯改善提案

日期：2026-10-27

檢視範圍：正式大綱、CH1-1～CH2-6、EXT1、Canva 功能資源頁、時間軸與字幕資源頁、既有真人跟做紀錄及目前 Gate

檢視方法：以 `course-designer` 檢查能力進展、完整示範、操作證據與案例整合；以 `course-copywriter` 檢查學員閱讀主線、承接與文案自然度。這份文件只提出改善方案，不直接改寫教案或 HTML，也不宣稱完成正式驗收。

## 一、結論先行

本課已具備完整的素材、可播放成品、操作步驟、修復提示與學生任務，功能範圍也已涵蓋建立專案、匯入、裁短、裁切、圖層、物件起訖、動畫、轉場、錄製、旁白、配樂、字幕、匯出與分享。問題不是功能太少，而是教學主線被多個介面與版本分支切散。

目前不宜再增加更多 Canva 功能。優先改善以下三件事，會比擴充功能清單更能讓學員熟悉完整剪輯流程：

1. **固定一條新版多軌主線。** 新建影片統一用新版時間軸；舊頁面式編輯器改放相容性附錄，不在每個步驟與新版並列。
2. **固定一支 36 秒作品走完全流程。** 34／38 秒版本改為副本中的延伸實驗，不再讓後續錄音、字幕與配樂都同時處理多種時間狀態。
3. **把介面教學從「按鈕名稱」改成「選取對象—可見控制—操作結果」。** 學員先看懂自己選到主片段、文字、音訊或字幕，才執行裁短、移動、分割與校訂。

若完成上述調整，現有校園短片案例可以支撐零基礎學員走完一輪 Canva 剪輯流程；目前則較接近「功能都教到了，但學員需要在多條路徑中自行拼出完整工作流」。

## 二、目前內容的優勢

### 1. 完成物與跨堂承接清楚

正式大綱已定義 v1 畫面版與 v2 有聲字幕版，並把六項學習成果對應到單元。主案例由素材整理、粗剪、文字與時間、聲音、字幕一路走到 MP4 與可編輯專案，基本骨架正確。

### 2. 已把相近功能說出差異

CH1-2 明確區分裁短與裁切，CH1-4 區分物件起訖與動畫速度，CH2-4 區分觀看字幕與下載後仍存在的成片字幕。這些都是零基礎剪輯最容易混淆的概念，應保留。

### 3. 素材與修復資訊充足

實拍練習包、位置圖、旁白、字幕、配樂、完成影片、專案紀錄與學生任務都有實檔。多數關鍵步驟也提供「做完看到什麼」與「沒看到回哪裡」，具備可操作基礎。

### 4. 已要求學員留下 Canva 操作證據

CH2-5 不只驗收英語或影片內容，也要求裁短、構圖、文字起訖、聲音／字幕及個人操作紀錄。這個設計能避免小組只交出成品，卻無法證明每位學員操作過 Canva，應完整保留。

## 三、層面一：文案自然度改善

### A. 目前主要問題

#### 1. 主線常被例外路徑打斷

學員在尚未完成第一輪成功操作前，就反覆遇到新版／舊版、36／38／34 秒、真人／AI、可編輯專案／平面備援、主專案／獨立練習專案等分支。每個分支各自合理，但連續閱讀時會讓正文像操作規格，而不像帶人完成作品的教學。

影響最明顯的位置：

- CH1-1 先要求學員判斷新版多軌或既有頁面。
- CH1-2、CH1-4 在核心操作中並列兩套介面。
- CH1-4 允許保留 36 或 38 秒，CH1-5 又產生約 34 秒版本。
- CH2-2 同時處理真人錄影、AI 語音、獨立 WAV 與舊三頁 MP4。
- CH2-3、CH2-4 各自切到另一個練習專案，再要求學員回主專案。

#### 2. 「用途／完成檢查／卡住時／判斷方式」標籤密度偏高

這些內容本身必要，但 CH1-1、CH1-2、CH1-4 特別容易形成「步驟卡—標籤—步驟卡—標籤」的節奏。閱讀者知道每一小段要做什麼，卻不一定抓得到作品如何一步步成形。

#### 3. 課程的故事是作品流程，正文卻常以功能切段

大綱的真實主線是「把三支素材剪成一支能給學生看的短片」，但部分段落改由 Canva 功能名帶路，例如動畫、轉場、字幕面板、備援入口。功能應服務作品問題；若功能名稱成為段落主角，學員容易記住按鈕，卻無法在換素材後重建判斷。

#### 4. 正文保留過多歷史版本說明

「原文字與圖形版」「舊三頁版」「頁面式四片段版本」具有維護價值，但不應大量留在第一次學習的主線。這些內容適合放到「舊專案相容處理」資源頁，由需要者查閱。

### B. 改寫原則

#### 1. 每個單元先回答作品問題，再引入功能

建議正文以作品狀態推進：

```text
目前作品缺少什麼
→ 這次要改哪個物件
→ 為什麼選這個操作
→ 做完畫面／聲音如何改變
→ 如何確認沒有破壞下一段
```

例如 CH1-4 不以「設定時間、動畫與轉場」作為閱讀主線，而是從「答案一開始就出現，觀眾沒有先思考」展開，再教文字起訖；動畫與轉場只在能改善觀看理解時加入。

#### 2. 一段成功路徑只保留一套操作語句

新版多軌作為正文；舊頁面式、帳號沒有入口、素材遺失等狀況放在成功路徑之後的短型修復區。學員先完成一次，再決定是否需要備援。

#### 3. 將檢查語句寫進操作因果，不機械加標籤

需要立即阻止錯誤的檢查仍留在步驟旁；只負責收束的「用途」可併入前後段落。例如：

> 把走道影片拖到主軌。放開後，畫布應由影片填滿；若只看到一個可縮放的小視窗，影片仍在上層軌，將它拖回最下方主軌。

這一句同時包含動作、結果與修復，不需再拆成「用途」「完成檢查」兩張卡。

#### 4. 保留兩個版本名稱，不保留多個進行中狀態

- `v1`：36 秒畫面版。
- `v2`：在同一支 36 秒作品加入旁白、聲音與字幕。
- 34／38 秒與題材替換：只在副本中試驗，完成後回到標準 36 秒專案繼續主課。

這可大幅減少 CH2-2～CH2-4 對不同起點、終點及配樂長度的重複說明。

### C. 期望語氣：友善、手把手，並善用比喻

整體聲音應像一位坐在學員旁邊的剪輯教練：熟悉 Canva，也記得第一次面對時間軸時容易看錯物件、拖錯軌道或找不到按鈕。文字不催促、不居高臨下，先讓學員看清目前畫面，再陪他完成一個動作，最後把判斷交還給他。

#### 1. 友善不等於熱鬧，而是降低犯錯壓力

- 對學員使用「你」，用具體、平穩的語句帶路。
- 將常見錯誤寫成可修復的正常狀況，例如「如果影片變成小視窗，通常是放到上層軌了」。
- 避免「這很簡單」「只要按一下」「顯然」「你應該已經會了」等可能讓初學者更挫折的說法。
- 不靠驚嘆號、鼓勵口號或頻繁稱讚製造親切感；完成後直接指出學員現在多會了哪一件事。

#### 2. 手把手要呈現畫面狀態，不是把每個點擊拆得更碎

每個新操作採用以下節奏：

```text
先看目前畫面
→ 一起完成第一個例子
→ 說明為什麼這樣做
→ 學員自行完成相似操作
→ 播放或回聽結果
→ 出錯時回到明確位置
```

例如不只寫「拖曳文字軌左邊緣」，而要先讓學員確認文字條已亮起、左右把手可見，再拖到第 2 秒，最後把播放頭停在第 1 秒與第 3 秒比較結果。這才是手把手；增加更多沒有畫面狀態的點擊步驟，只會讓篇幅變長。

#### 3. 比喻只用來解釋看不見的關係

適合本課的比喻包括：

| 概念 | 可用比喻 | 比喻後必須接回的 Canva 物件 |
|---|---|---|
| 主軌與上層軌 | 主軌像影片的骨架；上層軌像疊在畫面上的透明片 | 指出主片段、文字條、圖形或畫中畫實際位在哪一軌 |
| 播放頭與時間 | 播放頭像時間尺上的指針，停在哪裡就看到那一刻 | 指出播放頭、時間讀值與目前畫面 |
| 裁短與裁切 | 裁短像剪掉錄影帶的頭尾；裁切像移動一扇窗，只改變看見的範圍 | 回到時間軸把手與畫布裁切框，分別核對片長與構圖 |
| 圖層 | 圖層像疊放的透明紙，上面的物件會蓋住下面的物件 | 回到「位置／圖層」或上層軌，確認文字、底板與影片順序 |
| 聲畫對齊 | 畫面與旁白像兩條並排的刻度，起點錯開就會提早或延後說話 | 回到音訊條、片段起點與接點前一秒回聽 |

每個難點只選一個最短、最貼近畫面的比喻。比喻說完立即使用正式介面名稱與實際操作；不能用「骨架」「透明片」取代主軌、上層軌、播放頭或裁切框，也不為每個按鈕硬加故事。

#### 4. 建議的句子質感

偏規格式的寫法：

> 新版在上層軌選取答案文字，把左邊緣拖到第 2 秒，右邊緣拖到第 10 秒。

建議改成：

> 先在上層軌點一下答案文字。看到文字條亮起、左右兩端出現把手後，我們先把左端拖到第 2 秒，右端留在第 10 秒。播放頭停在第 1 秒時只會看到問題；移到第 3 秒，答案才出現。你可以把播放頭想成時間尺上的指針，用它檢查文字是否在正確時刻進場。

偏命令式的修復寫法：

> 若只有小影片浮在白底上，回到主軌設定。

建議改成：

> 如果畫面上只出現一個可以縮放的小影片，先別重傳素材。這通常表示影片被放到上層軌了；把它拖回最下方主軌，看到影片重新填滿畫布後再繼續。

這種語氣同時保留準確指令、可觀察結果與修復位置，也讓學員感覺有人陪著排除問題。

### D. 各單元的文案調整方向

| 單元 | 目前閱讀負擔 | 建議主句與推進方式 |
|---|---|---|
| CH1-1 | 一開始同時介紹成品、素材、專案、五個介面區域與新舊版本 | 以「把三支原片整理成可續編專案」為主句；只教當下看得到的畫布、上傳、主軌、播放頭與復原 |
| CH1-2 | 新舊介面雙路徑與文字版補充同時出現 | 先完成新版主軌匯入、裁短、裁切、圖層；舊頁面式改為附錄連結 |
| CH1-3 | 三場景／四片段與頁面數並列 | 先說清楚「場景是教學功能，片段是剪輯素材」；只用主軌片段名稱定位 |
| CH1-4 | 功能密度高，且中途產生 38 秒分支 | 由觀眾閱讀問題帶出物件起訖；動畫與轉場各只做一次有理由的選擇；延長兩秒改在副本中測試後復原 |
| CH1-5 | 轉用版會成為另一條可接第二場的主線 | 保留轉用練習，但明示為副本；第二場一律回到標準 36 秒 v1 |
| CH2-2 | 真人錄影、AI 語音、WAV、舊三頁 MP4 平行展開 | 確定一條聲音主路徑；其他做成「設備或帳號無法使用時」的分流卡 |
| CH2-3 | 主作品與獨立十秒專案往返 | 讓主作品至少實際完成一次分割／接合；獨立素材只作重練，不承擔唯一分割證據 |
| CH2-4 | 多個字幕來源與補句專案切換 | 先在主 v2 完成生成、校訂與匯出檢查；手動補句只處理主專案的一個真實漏句 |
| CH2-5～6 | 已接近自然工作流程 | 保留觀看者回饋、學生任務、交付與保存；縮短重複的完成聲明 |

## 四、層面二：介面介紹豐富度改善

### A. 平台現況帶來的必要調整

Canva 官方目前說明：2025 年 10 月以前建立的舊影片設計仍保留頁面式結構；所有新影片設計已使用新版多軌時間軸。新版也已把物件起訖、分割、主軌／上層軌與背景附著列為標準操作。來源：

- [Canva：建立與編輯影片](https://www.canva.com/help/creating-and-editing-videos/)
- [Canva：在編輯器中錄製影片](https://www.canva.com/help/recording-videos/)
- [Canva：錄製旁白](https://www.canva.com/help/record-voiceover/)
- [Canva：自動字幕](https://www.canva.com/features/auto-caption/)

因此，從 CH1-1 新建影片開始的學員，正常情況應走新版多軌。舊頁面式步驟仍有價值，但用途應改為：

- 開啟 2025 年 10 月以前建立的舊專案。
- 匯入或續編歷史頁面式教材。
- 教師需要維護既有成品時查閱。

### B. 介面介紹不是多放截圖，而是補齊四種線索

每個第一次使用的功能，至少應同時讓學員看見：

1. **目前選到什麼物件。** 主軌影片、上層文字、音訊、字幕或畫布物件。
2. **選對後會出現什麼控制。** 例如裁短把手、裁切、音量、字幕、動畫。
3. **操作後哪個狀態改變。** 長度、起點、可見範圍、音量或字幕內容。
4. **選錯時畫面會有什麼差異。** 例如影片變成小視窗、整個背景跟著移動、主軌長度被誤改。

### C. 建議建立八張「主線錨點圖」

不需要每一步截圖。建議只補下列能支撐整條主線的介面圖，每張以實際帳號、同一語言介面及同一 36 秒專案擷取：

| 錨點圖 | 放置位置 | 必須標出的介面關係 |
|---|---|---|
| 1. 空白影片全貌 | CH1-1 | 上傳區、畫布、主軌、播放頭、預覽、分享／下載 |
| 2. 影片在主軌與上層軌的差別 | CH1-2 | 背景填滿與小視窗兩種結果；如何拖回主軌 |
| 3. 裁短與裁切的選取狀態 | CH1-2 | 時間軸把手對照畫布裁切框 |
| 4. 四片段粗剪完成 | CH1-3 | 10／6／6／14 秒主軌與三個教學場景的關係 |
| 5. 文字起訖與動畫控制 | CH1-4 | 文字條左右把手、整段移動、動畫面板各改什麼 |
| 6. 旁白／錄影／配樂軌 | CH2-2～3 | 主畫面、講師影片、旁白、配樂的分軌與音量 |
| 7. 分割前後 | CH2-3 | 播放頭、分割點、被刪停頓及接合後結果 |
| 8. 字幕來源與校訂 | CH2-4 | 選中的有聲物件、字幕清單、畫面字幕及匯出結果 |

現有素材可沿用 CH1-2 裁短圖、圖層圖、文字選取圖、音訊字幕圖與字幕校訂圖；缺口主要在 CH1-1 的新版全貌、CH1-3 的完整粗剪、CH2-2～3 的新版聲音軌與新版分割。

### D. 介面圖的製作規則

- 所有主線截圖都來自新版多軌與同一 36 秒作品。
- 圖上只標示當下需要的 2～4 個區域，不把整個介面變成密集地圖。
- 截圖下方直接附「選對時看到什麼」與「選錯時如何判斷」。
- 同一功能若有中文／英文標籤差異，以位置與圖示輔助，不把翻譯名稱當唯一辨識方式。
- 按鈕或面板名稱在正式改寫前，用目前授課帳號實際核對；官方文件只證明功能存在，不代替帳號介面實測。
- 歷史頁面式截圖移到一份「舊專案相容處理」頁，避免與新版主線混用。

## 五、整合案例能否讓學員熟悉完整剪輯流程

### A. 目前判斷

**功能覆蓋：高。** 現有案例已涵蓋一支教學短片從素材到交付的主要工作。

**主線整合：中。** 粗剪、圖層、聲音、字幕與匯出確實互相承接，但學員可能在中途改成 34 或 38 秒、切到平面備援、使用獨立剪輯專案、再切到字幕專案。學到的功能未必都作用在同一支作品上。

**獨立遷移：尚待真人驗證。** 目前 Gate 已明示真人冷讀、連續跟做、計時、理解與轉用仍待完成。現有內容可以支持機器與作者檢查，不能直接推論零基礎學員已熟悉整個流程。

### B. 建議的標準整合案例

整門課只追蹤一支 `姓名_圖書館_v1／v2`：

| 里程碑 | 學員在同一專案完成的工作 | 可觀察產物 |
|---|---|---|
| M1 建立工作區 | 新建 16:9、命名、上傳三支影片與位置圖 | 可重開的空白專案與素材區 |
| M2 完成粗剪 | 主軌排成 10／6／6／14 秒，裁短並調整構圖 | 36 秒四片段畫面版 |
| M3 完成圖層與節奏 | 加入問答、位置圖、文字起訖及一個有理由的動畫／轉場 | 可理解的 v1 |
| M4 完成聲音剪輯 | 錄製或錄旁白、裁短、分割一次停頓、調整配樂 | 聲畫對齊的 v2 |
| M5 完成字幕 | 生成、校訂、補一個漏句並檢查明暗背景 | 有聲字幕版 v2 |
| M6 交付與回修 | 匯出 MP4、取得觀看者回答、修正一處、設定檢視連結 | 可播放檔、可編輯專案與交付紀錄 |

### C. 支援遞減方式

1. **講師示範：** 用第一個走道片段完整示範選取主軌、裁短、裁切與文字層。
2. **同步操作：** 學員依相同步驟完成閱讀片段，講義提供起點與結果。
3. **半獨立操作：** 自習片段只提供成果條件，學員自行選六秒內容、構圖與標籤位置。
4. **整合操作：** 提問片段由學員完成時間、文字起訖及觀看測試。
5. **轉用：** 完成 v2 後，再用副本換題材；須同步改素材、文字、時間、旁白與字幕，不能只改標題。

這樣可以把「熟悉功能」改成可觀察的能力：學員能辨認物件、選擇操作、預測影響、檢查結果並修正錯位。

### D. 分割與字幕不應只存在於獨立練習

CH2-3 目前把移除中間停頓放在另一個十秒專案，主 v2 主要做頭尾裁短。建議在標準 v2 安排一個真實停頓，讓學員至少一次在自己的作品中完成：

```text
聽出停頓 → 放置播放頭 → 分割前後兩端 → 刪除中段 → 接合 → 回聽字音
```

獨立十秒素材可保留為第一次示範或補做，但不能成為整門課唯一的分割證據。字幕亦同：主 v2 至少要完成一個真實錯字校訂與一個起訖修正，十秒補句專案只作重練。

## 八、完成判準

改善後應能從正式內容中直接證明：

- 學員只靠一條新版主線就能完成 36 秒 v1 與 v2。
- 每個第一次出現的 Canva 功能都有選取對象、操作入口、可觀察結果與修復提示。
- 裁短、裁切、移動、分割、圖層、物件起訖、音量與字幕不再因介面分支混在一起。
- 分割、字幕校訂與匯出都實際作用在標準主作品，不只存在於獨立練習。
- 轉用新題材時，學員能同步處理素材、文字、時間、聲音與字幕。
- 正文讀起來是一支作品逐步完成的過程，舊版、備援與課後延伸不打斷第一次成功路徑。
- 語氣像一位耐心坐在旁邊帶做的剪輯教練；不以命令、口號或「很簡單」壓縮初學者的困難。
- 比喻能幫助學員指出實際 Canva 物件與關係；移除比喻後，操作名稱、步驟、結果與修復仍然完整。
- 真人連續跟做可以完成，且需提示的位置能回扣到明確正文或介面圖，而非由講師臨場補充。
