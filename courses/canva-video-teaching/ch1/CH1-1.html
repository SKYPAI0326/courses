CH1-1 · 15 分鐘

建立你的第一個影片專案

完成這一頁
建立橫式影片專案，辨認素材區、畫布與時間軸，保存可重新開啟的設計。
本頁操作
  1. 準備開始
  2. 先看這次要做的影片
  3. 先登入並建立影片專案
  4. 輸入標題並認識編輯器
  5. 練習選取與復原
  6. 確認本單元成果，進入下一單元
(01)

準備開始

這門課要練習的是 Canva 影片製作。你會先用一套完整的校園介紹素材操作，讓每個人都能用相同檔案核對結果；英文與圖書館只是本次示範內容，之後可以換成中文或其他學科題材。第一場將實拍片段剪成可播放的畫面版，加入位置圖、活動標籤與動態提示；第二場在同一作品加入自己的講解與字幕。

檔名中的 v1 表示「第 1 版」，用來保存第一場做好的畫面；v2 表示「第 2 版」，用來保存加入聲音與字幕的作品。這兩份作品會由你在自己的 Canva 帳號建立。

先開啟示範素材：腳本與操作對照。這份資料提供可直接使用的文字與片段配置，目的是讓你練習 Canva 的文字、圖層、時間、聲音與字幕功能。示範成品依序顯示「位置」「活動」「觀眾練習」，全片預計 30–45 秒。

(02)

先看這次要做的影片

播放 36 秒實拍字幕版成果對照，再看第一場的無聲剪接版。留意走道、閱讀與自習的活動影像，以及配合內容出現的文字。兩支都是本課本機合成的成果對照；你會依後續步驟在自己的 Canva 專案重建，第二場改用自己的講解。

先下載實拍練習包 ZIP，解壓縮後確認有 stock-library-walk.mp4、stock-reading.mp4、stock-study.mp4 與 library-map.svg。用電腦播放器開啟任一支 MP4，人物或鏡頭應隨播放改變；SVG 會在下一單元疊加到影片上。來源、作者與用途可在素材取得頁查閱；不必從搜尋結果自行猜選哪支影片。

(03)

先登入並建立影片專案

Canva 專案是你可以持續編輯的設計。完成後會把設計下載成影片檔，專案仍留在帳號中，供下次修改。

  1. 使用筆電開啟 Canva，登入自己的帳號。出現帳號首頁後再繼續。
  2. 選「建立設計」，搜尋「橫式影片」，建立空白影片。尺寸若以像素顯示，使用 1920 × 1080。
  3. 點選設計名稱，改為 姓名_圖書館_v1，將「姓名」換成你的名字。

此時應看到橫向空白畫布。先完成這個起始狀態，再辨認編輯器中的工具。

(04)

輸入標題並認識編輯器

畫面中央是畫布。開啟左側「文字」，按「新增文字方塊」，輸入 Where is the library?。選取文字框後，上方會出現字型、字級與其他文字工具；下方時間軸會在後續單元用來調整影片與物件的播放時間。

接著練習修改已建立的文字框，之後換教材時就能更新標題。點兩下標題，將 library 暫時改成 classroom，再點文字框外的空白處。看到 Where is the classroom?，表示文字已修改；最後用相同方法改回 library，接續本課示範。

以下對照表供後續單元查閱。本頁實際用到中央畫布、左側文字入口與選取後工具列；上傳、時間軸與下載會在第一次使用時再操作。

區域 用途 這次會操作什麼
上傳／元素 放入自己的 MP4，或查找平台素材 上傳三個練習片段；確認付費標示
中央畫布 排列影片、文字、圖形，調整構圖 拖曳、縮放、裁切與前後順序
下方時間軸 決定片段順序、長度與物件起訖 裁短片段；讓標籤只在需要時出現
選取後的工具列 顯示所選物件可用的功能 影片的音量／裁切；文字的字型／動畫
分享 → 下載 保存可播放影片 選 MP4，檢查實際下載檔

若下方有分層的影片、文字與音訊軌，後續使用「新版多軌」路徑。若下方主要是一頁頁縮圖與頁面秒數，使用「既有頁面」路徑。新舊介面的裁短和分割入口不同；功能與技巧頁有辨識方式。本頁只要辨認自己的介面，下一單元才開始匯入與剪輯。

(05)

練習選取與復原

這一段確認你能移動、復原並再次開啟專案，之後操作失誤或離開頁面時才找得回工作。

將標題拖到畫面上方。若位置偏離，用工具列的「復原」回到前一個狀態。Mac 可用 Command + Z，Windows 可用 Ctrl + Z。

複製案例文字時，先拖曳選取文字，再用 Command + C 或 Ctrl + C；回到 Canva 點進文字框，用 Command + V 或 Ctrl + V 貼上。

完成後點左上角首頁圖示，回到 Canva 首頁。從「繼續設計」找到剛命名的作品並點開；未出現時，開啟「專案」，搜尋你輸入的名稱。從最近的設計開啟 姓名_圖書館_v1。標題仍在，便能接著完成畫面。

如果文字無法修改，先確認是否進入自己的帳號，以及目前是否有編輯權限。開啟別人的檢視連結時，回到自己的首頁建立空白影片，再輸入標題。

(06)

確認本單元成果，進入下一單元

原本的 36 秒文字與圖形版 可作排版底稿對照，不是本頁必做操作。

本單元完成後，你應有一份已命名、可再次開啟的橫式影片專案，並能修改其中的標題。點頁尾「下一單元」進入 CH1-2「匯入影片，完成第一個場景」；影片匯入會在下一單元逐步完成。
