(03) · CH 4.3

同款品牌、3 張系列也像同個牌子

3 張廣告放在一起，看起來像同一個品牌出的——這就是系列感。不靠設計師、不靠天生美感，靠一份品牌小卡（3 件事）+ AI 執行 + 3 個問題做跨張檢查。時間：45 分鐘

學習成果
能填寫一份品牌小卡（顏色 / 字體 / 風格詞），讓 AI 每次都吃同份規格
能用同款線稿 + 品牌小卡產出 3 張看起來像同品牌的系列完稿
能用系列檢查 3 問（顏色對 / 字體對 / 看起來像同品牌嗎）跨張驗收
今天結束時，你會交出
  1. 1 份品牌小卡（顏色 hex + 字體名稱 + 風格詞 3-5 個）
  2. 3 張系列完稿（共享同份品牌小卡 + 同骨架）
  3. 1 份系列檢查 3 問結果（顏色對 / 字體對 / 像同品牌嗎）

完成這 3 件就算過關。系列感不靠美感、靠 3 件事鎖死。

(01)

看 — 有品牌小卡 vs 沒品牌小卡

為什麼這很重要
你在 CH4-1 學會了跨產業套用、CH4-2 學會了多變體——你現在能跑很多張了。問題是：多張放在一起，它們看起來像「同一個品牌」嗎？本段讓你先感受有沒有品牌小卡的差異，再教你怎麼填、怎麼用。

弄一下咖啡工作室老闆準備做春夏秋冬 4 季 × 3 張新品廣告 = 12 張的年度行銷系列。他已經在 CH4-1 學會跨業種套用、CH4-2 學會多變體，覺得自己準備好了——但跑出 3 張之後，老闆自己的朋友問：「這 3 張是 3 個不同品牌嗎？」

沒有品牌小卡（各張自由發揮）
春抹茶拿鐵 · 鼠尾草綠 + 奶油白 · 明朝體 · 療癒、手作
夏柚子氣泡 · 黃橘 + 天藍 · 黑體 · 清爽、活力
秋焙茶拿鐵 · 深棕 + 米色 · 手寫感 · 沉穩、職人
3 張放一起像 3 個咖啡店的廣告——綠的、黃的、棕的，每張一個世界。
有品牌小卡（所有張共用一份規格）
春抹茶拿鐵 · 鼠尾草綠 + 奶茶棕 + 奶油白 · 明朝體 + 黑體 · 手作、職人
夏柚子氣泡 · 鼠尾草綠 + 奶茶棕 + 奶油白 · 明朝體 + 黑體 · 手作、職人
秋焙茶拿鐵 · 鼠尾草綠 + 奶茶棕 + 奶油白 · 明朝體 + 黑體 · 手作、職人
3 張放一起像同一個咖啡店 3 個季節新品——配色、字體、語氣全一致，只有商品換。
→
決定性的 3 項一致變量：配色 + 字體 + 道具類型。商品換，但視覺規格不換。

沒有品牌小卡 = 每張都重新決定 = 看起來像不同品牌
有品牌小卡 = 每張吃同份規格 = 看起來像同品牌

(02)

學 — Brand DNA：五段都能驗收

品牌小卡是什麼
品牌小卡是版本化的品牌規格：同時給生成工具、後製者與驗收者使用。它要寫清楚任務、不可變項、可變項、禁止帶入與系列檢查；模型輸出仍須由人與工具驗證。
第 1 件事
先寫用途
先定義交付用途、受眾、第一眼與下一步；沒有任務條件，風格描述再完整也無法判定是否適用。
第 2 件事
分開不變與可變
色彩、光線、材質、構圖、商品或角色、後製字體寫成不可變項；每輪只指定一個主要變因。
第 3 件事
用證據放行
禁止帶入第三方識別與正式敏感文字；系列完成後用取色、來源紀錄、並排比較與第三人盲評放行。

以下五段與下載的 Brand DNA 模板完全同名；學員可逐段對照，不需轉譯另一套 schema。

品牌小卡 5 段詳解

第 1 段
任務與受眾
填品牌／專案代稱、交付用途、受眾情境、希望觀眾先看到與感受到什麼，以及下一步行動。
驗收：第三人只讀這段，也能說出成品要解決的任務與使用情境。
第 2 段
不可變項
逐項寫主色與容差、accent 的位置與面積、光線方向與軟硬、材質、構圖安全區、商品／角色外觀，以及正式後製字體與層級。可從 7 組可觀測品牌風格系統取屬性，不用品牌名稱當捷徑。
驗收：每項都要有方法，例如取色器、陰影方向、reference 前後對照、安全區模板或字型清單。
第 3 段
可變項
列出允許改變的場景、配件、季節色與鏡位；每一輪只指定一個主要變因，其餘條件固定。
驗收：旁觀者能指出本輪只改了哪一項；若同時改商品、季節、徽章、價格與道具，就不能判斷差異來源。
第 4 段
禁止帶入
列出第三方 logo、包裝、角色與 trade dress；reference 僅供示意、不可複製的元素；不必要敏感屬性；正式價格、日期、法規與合約文字。
驗收：逐項對候選圖與文字檢查；任何來源或權利不明的元素都先停止，不以相似度猜測放行。
第 5 段
系列檢查
並排檢查主色、光向、材質、商品／角色、用途與安全區；正式文字完成後製與逐字校稿，並記錄 reference、prompt、模型／版本、日期與人工修改。
驗收：第三人不看 prompt，也能說出三張屬於同一品牌並指出各張用途；缺證據就標 REVISE。
💡
品牌小卡維護建議：保存版本號、適用用途與修改理由；每次品牌或平台條件變更後重驗，不假設一份規格永久有效。
(03)

學 — 品牌繼承 prompt 和系列檢查 3 問

品牌繼承 prompt（5 min）

品牌小卡填好之後，每次跑新廣告都引用同一版本；本輪只改第 3 段指定的一個主要變因：

品牌繼承 prompt 模板（可直接複製）
吃下以下品牌規格： [貼整份品牌小卡] --- 骨架沿用：{骨架代號，例：骨架 4 商品中心 · 道具環繞} 本輪唯一主要變因：{例：商品從春季抹茶換成夏季柚子；其餘條件固定} 固定條件：{列出骨架、場景、徽章、價格、道具與安全區} 請依以上規格 + 骨架 + 主題產出完稿。 【待查線索】 產完請列出需由人核對的位置，不要替使用者宣告通過： 1. 顏色哪些區域可能偏離規格？（AI 只列位置；人用取色器記錄實際 hex） 2. 字形哪些區域可能偏離規格？（AI 只列位置；實際字型以後製設計檔為準） 3. 禁用清單是否全部遵守？（逐條比對） 若任一項可能不符，只列待查位置與修正建議；由人判定後再決定是否重跑。
→
3 個關鍵鎖定
整份品牌小卡貼上去（不是摘要，是五段完整 schema）
AI 只列待查線索；你用取色工具、字型來源與三張並排結果判定
每輪只有第 3 段指定的一個主要變因，其他全吃品牌小卡並列為固定條件

系列檢查 3 問（5 min）

3 張都跑完後，請 AI 先列跨張差異；再由你用取色、後製字型來源與第三人盲評做一致性驗收：

系列檢查 3 問（可直接複製）
請對剛才產出的 3 張系列（A / B / C）盤點可能的品牌一致性差異，對照以下規格： [貼品牌小卡] 逐項比對 3 張： 1. 顏色可能偏離嗎？指出待查區域；實際 hex 由人用取色工具記錄。 2. 字形可能偏離嗎？指出待查文字；實際字型名稱以後製設計檔與字型清單為準。 3. 看起來像同一個品牌嗎？（對照品牌小卡的禁用清單 + 風格詞，逐張比對） 不要替作品判定通過。只列出待查位置、可能差異與你無法從影像確認的資訊，交由人用工具與來源紀錄核對。

AI 的 hex 與字型名稱可能是推測，不能直接當證據。色彩用取色工具，文字用實際後製字型，系列辨識用三張並排與第三人盲評；三項必要條件全過才收。

PM 判定標準
三項必要條件全過
由人簽核後收為系列資產，進 PRAC4 / CH5-1 反覆使用
任一必要條件未過
迭代不符那張，保留已確認部分、只修缺口，再重新人工核對
規格無法判定
補齊色票、字型來源、禁用清單或 reference，再重新產出；不要猜測
(04)

做 — 填品牌小卡 + 跑 3 張系列 + 驗收

15 分鐘，3 個階段
為自家品牌（或假想品牌）建立完整的品牌小卡，跑 3 張系列，做跨張一致性驗收。完成後你就有第一份可以長期重複使用的品牌視覺規格。
階段 1 · 5 min
填品牌小卡
打開品牌小卡填空範本，填自家品牌（或假想品牌）：
  • 第 1 段：任務、受眾、第一眼與下一步
  • 第 2 段：不可變項（色彩、光線、材質、構圖、商品／角色、後製字體）
  • 第 3 段：可變項與本輪唯一主要變因
  • 第 4 段：禁止帶入（第三方識別、敏感屬性、正式價格與法規文字）
  • 第 5 段：系列檢查與來源紀錄

若 5 分鐘填不完：先填第 1 / 2 / 4 段；第 3 段只寫一個主要變因，第 5 段沿用檢查清單。

階段 2 · 7 min
跑 3 張系列
用品牌繼承 prompt 模板，跑 3 張系列：
  • 3 張共用同一個骨架 + 同一份品牌小卡
  • 本輪只換一個主要變因；骨架、場景、徽章、價格、道具與安全區固定
  • 範例：只換商品為春抹茶 / 夏柚子 / 秋焙茶，其他條件完全相同

先以第一張實際記錄組 prompt、排隊、生成、校稿與驗收時間，再估後兩張；平台不可用時改走 OFFLINE-01，不承諾固定秒數。

展開品牌繼承 prompt 模板（複製即用） 
吃下以下品牌小卡：

[貼入完整品牌小卡]

---

結構沿用：{骨架代號，例：骨架 4 商品中心・道具環繞}

本輪唯一主要變因：{例：商品名稱與商品外觀}
固定條件：{骨架、場景、徽章、價格、道具、安全區}

請依以上品牌小卡 + 骨架 + 主題產出 1:1 完稿。

【AI 差異盤點】
產完請列出待查線索，不要替作品判定通過：
1. 色票是否符合本系列的色彩角色與比例？（由人用取色工具記錄）
2. 後製字型與層級是否有來源紀錄？（不要從像素猜字型）
3. 禁止帶入清單是否全部遵守？（逐條比對）
4. 除唯一主要變因外，是否還有其他條件被改動？
階段 3 · 3 min
系列檢查 3 問
3 張都跑完後，先讓 AI 列差異線索；你再用取色工具、實際後製字型來源、三張並排與第三人盲評逐項核對。

判定：顏色、字型與品牌辨識三項必要條件由人確認全過，才存檔；任一項未過就只改缺口並重驗；缺證據時先補證據，不猜測。
展開系列檢查 3 問（複製貼回同對話） 
請拿這 3 張（A / B / C）盤點品牌系列差異，對照以下品牌小卡：

[貼品牌小卡]

檢核項：
1. 3 張的配色是否符合品牌小卡的色彩角色與容差？（由人取色記錄，不採 AI 猜測）
2. 3 張的字族是否符合品牌小卡指定？
3. 3 張是否都遵守禁用清單？（逐條比對、逐張比對）
4. 3 張的結構骨架是否一致？（例：都是骨架 4）
5. 3 張的語氣調性是否一致？（對照品牌小卡「示範句對比」）

若任一張可能偏離，指出「第 {A/B/C} 張在第 {1-5} 項的待查位置與理由」。不要宣稱實際 hex、字型名稱或最終通過；這些由人用工具與來源紀錄確認。

完成標準（self-check）

  • 填完品牌小卡（至少第 1 / 2 / 4 段，第 3 / 5 可簡化）
  • 跑出 3 張系列（同骨架 + 同品牌小卡 + 每輪只有一個主要變因）
  • 做過 AI 差異盤點，並完成取色、字型來源與第三人盲評
  • 顏色、字型來源與品牌辨識三項必要條件由人確認全過；任一項未過則留下迭代紀錄
  • 存檔 3 張系列 + 品牌小卡（PRAC4 會用到）
→
預期差異提醒：你的品牌小卡與 3 張系列會和同學不同。品牌小卡可以持續迭代，但收進資產庫前，顏色、字型來源與品牌辨識三項必要條件都要由人留下可追溯證據。

(07)

常見錯誤 3 條

錯誤 01
品牌小卡填得太抽象（只寫「日系風」）
現象
第 1 段只寫「做廣告」、第 2 段只寫「日系清新」、第 3 段沒有指定唯一變因。看似有填，實際上無法驗收。
原因
抽象詞 = AI 的猜謎題。日系風的配色有 10 種可能、字體有 20 種可能——AI 只能猜一個組合。下次跑新系列時 AI 又猜一個，兩次結果不一致。
解法
每段都要具體到「可執行」的程度：
抽象（錯誤）具體（正確）
日系風低彩度、大片留白、自然紙材、襯線標題、無促銷爆炸貼
清新色調鼠尾草綠 #5a7a5a + 奶茶棕 #8a6a4a + 奶油白 #f5efe3
好看的字體Shippori Mincho 700 / Noto Sans JP 400
親切手作、職人、季節感、療癒（4 詞）

檢查方法：填完每段，換隔壁同學看——他能不能照你的描述重現同樣的視覺？若他說「我要猜什麼顏色才對」——你的描述不夠具體。

錯誤 02
3 張系列跑完沒做系列檢查 3 問
現象
學員跑 3 張系列，每張個別看都還 OK，存檔。沒跑系列檢查 3 問。兩週後要做第 4 張，打開前 3 張才發現——第 1 張鼠尾草綠主導、第 2 張不小心用了橄欖綠（跟鼠尾草綠不同 hex）、第 3 張徽章形狀變了——3 張已經偏離品牌小卡。
原因
人眼比對跨張偏離容易漏判，特別是顏色相近時（鼠尾草綠 vs 橄欖綠）。系列檢查 3 問專門為了抓跨張微偏離設計的。
解法
3 張系列跑完後，必跑系列檢查 3 問。AI 只負責指出可能偏色與待查位置；實際色碼用取色工具量測，字型用後製檔與來源紀錄確認，最後再做第三人盲評。任一必要條件未過就迭代，不存檔。

紀律：人工證據才是最後守門員；AI 不能替自己的輸出簽核。
錯誤 03
品牌小卡的禁用清單沒填
現象
第 4 段禁用清單留空或只寫「沒特別禁用」。結果 AI 產系列時，自己加了漸層背景、多了裝飾邊框、用了額外的亮橘色點綴——這些品牌小卡沒禁，AI 合法加上，但跟品牌調性不符。
原因
AI 預設從訓練資料平均值取用（訓練資料裡充滿漸層、多色、裝飾邊框）。沒有禁用清單 = AI 自由發揮。
解法
第 4 段「禁止帶入」是必填。至少核對四類：
  • 第三方識別：logo、包裝、角色、trade dress
  • reference 邊界：只供示意、不得複製的元素
  • 人物與敏感屬性：沒有任務必要性就不加入
  • 正式文字：價格、日期、法規與合約文字交由可控工具後製

每項都要能逐項核對；權利、來源或正式文字不明時先停止，不以模型自述代替證據。

檢核題

Q1｜概念驗證 — 品牌小卡的 5 段是什麼？為什麼禁用清單是必填而非選填？
看答案要點

5 段：第 1 段任務與受眾、第 2 段不可變項、第 3 段可變項與本輪唯一主要變因、第 4 段禁止帶入、第 5 段系列檢查。

禁止帶入必填的理由：它界定第三方識別、reference、人物與正式文字的邊界；缺少這段就無法證明輸入與交付物可用。

不及格答案：只列 5 段沒說為什麼重要 ‧「禁用清單看情況」（錯誤，必填）‧「品牌小卡就是品牌風格」（太空泛）

Q2｜應用驗證 — 為弄一下咖啡工作室填品牌小卡前 3 段，並組成一個品牌繼承 prompt（跑「夏季柚子美式」新品廣告）。
品牌背景：台北單店手沖咖啡，走職人、手作、季節限定，客群 25–35 歲女性
看答案要點

品牌小卡前 3 段：

  • 第 1 段：官網新品首圖；25–35 歲咖啡客；先看到新品，再進商品頁
  • 第 2 段：鼠尾草綠主色、暖側光、紙與陶材質、骨架 4、安全區、後製字型與來源
  • 第 3 段：本輪只換商品；季節、場景、徽章、價格、道具與骨架固定

品牌繼承 prompt 必要元素：

  • 完整貼上品牌小卡（不是摘要）
  • 骨架：骨架 4 商品中心 × 道具環繞
  • 本次主題：商品夏季柚子氣泡美式 ‧ 季節夏季限定 6/1–7/31 ‧ 道具柚子切片、冰塊、氣泡水玻璃杯
  • 含【AI 差異盤點】並由人完成第 5 段系列檢查

不及格答案：用途只寫「做廣告」‧ 不可變項沒有驗收方法 ‧ 同時改多個主要變因 ‧ 沒有人工與工具證據
