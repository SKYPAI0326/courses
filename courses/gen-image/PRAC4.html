(12) · PRAC 4

品牌系列演練

你是確認系列像同品牌的人。這是 M4 最後一輪演練：從三種組合挑一組，填完五段 Brand DNA，建立三張每輪只改一個主要變因的候選，再用工具、來源與第三人證據完成跨張驗收。通過的資產才進 CH5-1。

學習成果
能為自選品牌填完整五段 Brand DNA，並為不可變項指定驗收方法
能從三種演練組合挑一組、建立三張共享同一 DNA 與骨架、每輪只換一個主要變因的候選
能用 AI 差異盤點、取色、字型來源與第三人盲評完成跨張人工驗收，留下可追溯證據
(01)

熱身 — 快速決策：選演練組合 + 品牌

定位提醒
你是確認系列像同品牌的人——這是 M4 最後一輪演練，為自己建立完整品牌資產（品牌小卡 + 3 張系列）。5 分鐘內決定好「演練組合 + 品牌」，後面 20 分鐘的演練才能順跑。

步驟 1｜挑 1 個品牌（2 min）

三選一：

  • A 自家品牌：你實際經營或服務的品牌（最有商業價值）
  • B 客戶品牌：你最近接案的客戶品牌（最接近實戰）
  • C 主線 A 弄一下咖啡工作室：課程預設範例（若 A/B 不適用）

步驟 2｜從 3 種演練組合挑 1 組（3 min）

組合情境本輪唯一主要變因適合誰
I 跨季節年度行銷規劃春 / 夏 / 秋 新品（同類商品、換季節）快消品 / 餐飲 / 美妝
II 跨產品線品牌陣列展示主打 A / B / C 3 款不同產品有多產品線品牌 / 手作店
III 跨活動週期行銷日曆新品上市 / 週年慶 / 會員專屬 3 個活動電商 / 服務業 / SaaS

快速判斷：

  • 手上業務一年會跑 4 季行銷 → 選組合 I
  • 品牌有 3+ 核心產品 → 選組合 II
  • 每月都有不同行銷主題 → 選組合 III
  • 都不太符合 → 預設用組合 I（最通用）

預期差異：你挑的組合 + 品牌跟同學不會一樣——這是設計。每個人跑自己業務情境才有帶走價值。

(02)

演練 — 3 個階段，20 分鐘跑完

節奏說明
20 分鐘分 3 階段：階段 1 填五段 Brand DNA → 階段 2 取得三張單一變因候選 → 階段 3 差異盤點與人工驗收。平台等待時間依當日實況記錄；時間不足改用 OFFLINE-01，不能跳過證據。

階段 1｜填五段 Brand DNA（8 min）

打開 Brand DNA 模板，依同一套五段 schema 填寫：

段內容硬性要求
1任務與受眾用途、受眾、第一眼、感受與下一步
2不可變項色彩、光向、材質、構圖、商品／角色、後製字體；每項有驗收方式
3可變項列出允許範圍，指定本輪唯一主要變因
4禁止帶入第三方識別、reference 邊界、敏感屬性、正式文字
5系列檢查工具、來源、並排與第三人證據清單

若真的來不及：第 1／2／4 段不可省略；第 3 段只寫一個主要變因，第 5 段沿用範本清單。

填完立刻自查：

  • 第 1 段：第三人能說出用途與受眾
  • 第 2 段：每個不可變項都有驗收方式
  • 第 3／4 段：本輪只有一個主要變因，權利與正式文字邊界已寫清楚

階段 2｜取得 3 張系列候選（10 min）

依你選的演練組合（I / II / III）跑 3 張系列：

組合第 1 張第 2 張第 3 張
I 跨季節{品牌}春季限定 {新品 A}{品牌}夏季限定 {新品 B}{品牌}秋季限定 {新品 C}
II 跨產品線{品牌}主打 {產品 A}{品牌}主打 {產品 B}{品牌}主打 {產品 C}
III 跨活動週期{品牌}新品上市{品牌}週年慶優惠{品牌}會員專屬活動

每張流程：貼模板 F → 取得候選 → AI 列差異線索 → 人工檢查。記錄實際耗時，不預設平台速度。

1
貼品牌繼承 prompt（30 秒）

用以下模板（見 prompt-templates.md 模板 F），填入當張主題：

依以下品牌小卡執行：
[貼完整品牌小卡]

---

結構沿用：{固定骨架}
本輪唯一主要變因：{例：商品從抹茶換成柚子}
Reference 角色：{商品／構圖／品牌，各自只負責什麼}
必須保留：{不可變項：骨架、商品／角色、色彩、光向、材質、安全區}
可以改變：{第 3 段允許範圍；本輪只啟用一項}
禁止帶入：{第三方識別、未授權元素、正式價格與法規文字}
正式文字：保留乾淨文字區，交由後製加入。

請依以上品牌小卡 + 骨架 + 主題產出 1:1 完稿。

【待查線索】產完請指出需由人核對的位置，不要替使用者宣告通過：
1. 哪些位置可能偏離「必須保留」？
2. 哪些位置可能超出「可以改變」或違反「禁止帶入」？
3. 哪些資訊無法從像素證明，必須由人或工具確認？
2
取得候選並記錄實際耗時

把 prompt 送出；平台不可用時，改用 OFFLINE-01 實際候選面板完成同一份驗收。

3
初步檢查

拿到圖後逐項人工確認：色彩用取色工具、商品／角色用 reference 前後對照、文字用實際後製字型與來源、第 4 段逐條核對；AI 回答只作為待查線索。

i
核心紀律：3 張都用同一份 Brand DNA + 同一個骨架，每輪只換一個主要變因。其餘條件若也改變，先標 REVISE，不做歸因結論。

階段 3｜系列差異 5 項 跨張一致性檢核（2 min）

3 張跑完後，同對話內貼系列差異盤點（見 prompt-templates.md 模板 G）：

請列出剛才 3 張系列（A / B / C）的跨張差異，對照以下品牌小卡；不要替使用者宣告通過：
[貼品牌小卡]

逐項跨張比對：
1. 色彩與光向：指出可能偏離 Brand DNA 的區域。
2. 商品／角色：指出外觀、比例或材質可能漂移的位置。
3. 構圖：指出主體占比、留白與視線路徑差異。
4. 禁止清單：逐張列出可能違規的元素。
5. 正式文字：列出必須人工後製與校稿的位置。

最後輸出待查清單；實際通過與否由人類與工具證據決定。另確認 3 張只有指定的主要變因改變，並列出每一項要由取色、reference、來源紀錄、後製檔、並排或第三人盲評補足的證據。
所有必要條件全過且有證據 → 存檔進個人品牌資產庫
任一項不符 → 迭代不符那張，只修偏離項後重驗
無法證明 → 標記 REVISE，不進品牌資產庫
(03)

分享 — 互相展示，外部視角驗系列感

互相展示（3 min）

2-3 人一組，每人快速展示：

  • 自家品牌小卡（口述 5 段要點，30 秒）
  • 3 張系列（並排展示，30 秒）
  • 系列差異盤點與證據（待查位置、人工判定與來源，30 秒）
  • 最滿意的 1 張 + 最卡關的 1 張（30 秒）

同學回饋（互相給 30 秒）：

  • 你的 3 張看起來像同品牌嗎？（外部視角檢驗）
  • 品牌小卡有沒有什麼段落可以更具體？
  • 若要再做第 4 張，你建議什麼主題？

老師總結 + M5 預告（2 min）

  • 統計全班三項必要條件皆有人工證據且全過的人數
  • 挑 2-3 個最完整的品牌小卡範例當全班示範
  • CH5-1 預告：下個單元 30 分鐘跑完一次完整閉環——今天產出的品牌小卡 + 3 張系列就是 CH5-1 的起點。全部存檔備份。
(04)

動手練習 — 30 分鐘完整流程

PRAC 4 演練題目

在 30 分鐘內完成完整品牌系列演練：

  • 熱身（5 min）：挑 1 個品牌（A/B/C 三選一）+ 1 個演練組合（I/II/III 三選一）
  • 演練（20 min）：填五段 Brand DNA（8 min）→ 取得 3 張單一變因候選（10 min）→ 系列差異盤點與人工驗收（2 min）
  • 分享（5 min）：互相展示 + 同學回饋
預期成果
  • 1 份完整五段 Brand DNA
  • 3 張系列完稿（共享同品牌小卡 + 同骨架）
  • 1 份系列差異線索 + 工具、來源與第三人證據記錄
  • 1 個外部驗證結果（同學能否辨認為「同品牌」）
  • 1 組可進 CH5-1 整合實戰的品牌資產雛形
完成標準（self-check）
  • 品牌明確（自家 / 客戶 / 假想皆可）
  • 演練組合明確（I / II / III 選 1）
  • Brand DNA 五段完成，第 2 段每個不可變項都有驗收方式
  • 跑出 3 張系列（共享同一 DNA + 同骨架、每輪只換一個主要變因）
  • 第 4／5 段與工具、來源、第三人證據皆由人核對全過
  • 至少 1 位同學確認「看起來像同品牌」
  • 品牌小卡 + 3 張系列獨立備份（CH5-1 會用）
i
預期差異提醒：你的品牌、組合、Brand DNA 與系列會和同學不同。重點是三張並排時能被辨認為同品牌，而且不可變項、禁止帶入與系列檢查都有人工證據。今天產出是個人品牌資產庫的雛形。

  • 五段 DNA 填不完 → 第 1／2／4 段不可省略；第 3 段只寫一個主要變因，第 5 段沿用範本清單
  • 3 張系列看起來不像同品牌 → 查 CH5-1 troubleshooting 表症狀 ⑧「系列 3 張不像同品牌」、貼修正話術

  • 沒同學可以辨認 → 給家人 / 朋友看也算（重點是「外人看得出像同品牌」）
(05)

常見錯誤 3 條

01
熱身花 10 分鐘決定演練組合（選擇癱瘓）
錯誤現象

學員看到 3 種組合（跨季節 / 跨產品線 / 跨活動週期），開始糾結「我到底該選哪個？」「跨季節會不會太簡單？」「跨產品線我只有 2 款產品怎麼辦？」——結果 10 分鐘過去了，還沒開始填品牌小卡。

原因

選擇癱瘓。演練的重點是「跑通流程」，不是「選最完美組合」。對初學者來說 3 選 1 已經足夠，糾結組合不會讓成果更好。

解法

5 分鐘強制決策：一年做 4 季行銷 → 選 I；品牌有 3+ 產品 → 選 II；每月不同行銷主題 → 選 III；都不符合或選不定 → 預設 I（最通用）。

心法：選哪個都會有收穫——重點是跑完完整流程，體驗 M4 所有技能的整合。

02
跳過第 4 段「禁止帶入」
錯誤現象

學員覺得時間不夠，沒有寫第三方識別、reference 邊界、人物與正式文字限制就開始生成。候選可能帶入未授權 logo、包裝、人物特徵或不可控價格日期，整組不能放行。

原因

第 4 段是權利與正式文字的停止條件。缺少它，就無法證明輸入與交付物可用。

解法

第 4 段必填：逐項寫第三方識別、reference 中不得複製的元素、不必要人物與敏感屬性、正式價格日期及法規文字。任何來源或權利不明就停止。

03
3 張系列主題變量設太多（變量失控）
錯誤現象

學員挑組合 I 跨季節，卻同時改商品型態、場景、徽章、價格與道具。多個條件一起變動後，無法判斷差異來自哪一項，應直接標 REVISE。

原因

變量失控。系列演練的核心是控制變量、換單一維度：組合 I 跨季節 → 商品類別保持一致，只換季節主題（都是飲品類，或都是甜點類）。

解法

3 張主題的商品型態必須相近：

組合 I 範例（飲品）：春抹茶拿鐵 / 夏柚子拿鐵 / 秋焙茶拿鐵（都是拿鐵類）
組合 II 範例（皂類）：玫瑰皂 / 薰衣草皂 / 檜木皂（都是單塊皂）
組合 III 範例（App）：新品上市 / 週年慶 / 會員方案（都是同 App 不同訊息）

心法：演練是控制變量測技能，不是炫技。變量多 = 看不出品牌小卡效果，失去演練意義。

  • 有必要門檻未過 → 停止收件，補權利／來源證據或重跑不合格作品
Q2｜反思：品牌小卡的長期價值

請回答以下 3 個問題：

  1. 你今天產出的品牌小卡 + 3 張系列，在哪些實際任務中可以重用？每次重用前要重查哪些變動條件？
  2. 若下個月要做第 4 張，哪些條件可以沿用？哪些品牌、平台或用途變更會觸發更新與重驗？
  3. 品牌小卡作為可版本化規格，跟你之前做行銷物料的模式相比，在哪些步驟可能節省時間？請用一次實測記錄回答。
預期答案要點（至少命中 3 點算通過）
  1. 重複使用範圍：列出同品牌、同渠道且權利條件未變的實際任務；每次仍核對品牌版本、平台規範、素材來源與商品事實
  2. 下個月做第 4 張：先確認品牌小卡仍適用，再只換主題變量；若品牌、渠道或權利條件有變，先更新小卡與來源紀錄再生成
  3. 時間節省來源：配色、字型、語氣、禁用與骨架不用每次從零定義；用實際前後工時記錄估算，不能預設節省比例
  4. 額外價值（加分）：品牌小卡提供共同規格與驗收依據，降低交接遺漏；一致性仍需逐件人工驗收，不會自動保證

不及格的答案：「看情況」／「不確定能不能重複用」／沒算出具體使用次數／「還是要重畫設計」（違反本單元核心）。
