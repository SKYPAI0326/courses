# 8 個可拆解 Prompt 範例

每例都使用六段：用途、場景、主體、構圖、風格光線、限制。把括號中的判斷理由讀懂，再換成自己的 brief。

## 1. 電商商品主圖

```text
用途：1:1 電商主圖，縮成 160px 仍要看出商品。
場景：暖白無縫棚拍背景，只有很淡的接觸陰影。
主體：一個米白色無品牌咖啡袋，正面朝鏡頭，封口與袋底完整。
構圖：置中，商品占畫面約 70%，四周保留一致空間。
風格與光線：真實產品攝影，柔和雙側棚燈，材質紋理清楚。
限制：不要文字、logo、貼紙、道具、人物、浮空或變形包裝。
```

理由：用途與縮圖條件先決定「占比」；背景與限制避免模型擅自加品牌。

## 2. 社群新品圖

```text
用途：4:5 社群新品主圖，上方保留兩行後製標題空間。
場景：淺色石材桌面與柔和午後窗光。
主體：透明杯柚香冷萃、兩片柚子皮、少量冰塊。
構圖：飲品在下方中央，占畫面 55%；上方 25% 保持乾淨。
風格與光線：清爽 editorial food photography，低對比、真實水珠。
限制：不要生成文字、價格、logo、吸管穿透、重複杯緣或多餘水果。
```

## 3. 官網 Hero

```text
用途：16:9 官網 hero，桌機版文字放左側。
場景：安靜的淺木桌與霧藍牆面。
主體：右側一台無品牌筆電、筆記本、鉛筆與小桌燈。
構圖：筆電在右側 45%，左側 40% 保持低細節負空間。
風格與光線：自然窗光、專業但不壓迫、真實工作空間。
限制：螢幕只顯示抽象色塊；不要文字、UI、logo、人物、品牌設備特徵。
```

## 4. 限時動態

```text
用途：9:16 限時動態背景，正式文字後製。
場景：俯拍桃色桌面。
主體：一罐無品牌氣泡飲、檸檬片、薄荷與冰塊。
構圖：主罐位於中段；頂端與底端各留 15% 乾淨安全區。
風格與光線：鮮明 studio flat lay，清脆短陰影。
限制：不要文字、logo、手、第二罐、液體噴濺或平台按鈕。
```

## 5. 節慶禮盒

```text
用途：4:5 禮盒宣傳圖，傳達體面與手作溫度。
場景：深棕木桌、米色布料與少量乾燥果實。
主體：打開的米白無品牌禮盒，內含三格不同形狀餅乾。
構圖：禮盒在下方三分之二，緞帶形成對角引導線，上方留標題區。
風格與光線：溫暖側光、編輯式靜物攝影、克制質感。
限制：不要文字、金色獎章、角色、節慶商標、變形盒角或多餘內容物。
```

## 6. 旅遊橫幅

```text
用途：16:9 旅遊 EDM 橫幅，標題放天空區。
場景：虛構山湖、彎曲湖岸、遠山與大面積天空。
主體：左下湖岸一艘完全無標誌的橘色獨木舟。
構圖：湖岸形成由左下往中央的引導線；右上保留乾淨天空。
風格與光線：真實旅遊攝影、午後光、平靜開闊。
限制：不要真實地標、建築、人物、文字、旗幟、logo 或品牌裝備。
```

## 7. 四步驟資訊圖底圖

```text
用途：4:5 四步驟資訊圖底圖，文字由設計軟體後製。
場景：暖灰純色背景。
主體：四個清楚分隔的圓角區塊，各含一個簡單健身器材圖示位置。
構圖：2×2 網格，左上到右下閱讀；每格保留三行文字空間。
風格與光線：扁平幾何、清楚、低裝飾、對比足夠。
限制：不要生成任何文字、數字、人體前後對照、醫療符號或小型裝飾。
```

## 8. 系列變體

```text
用途：延伸同系列第二張社群圖。
Reference 角色：商品 reference 鎖定瓶身比例與瓶蓋；品牌 reference 鎖定奶油白、深藍與橘色 accent；構圖 reference 只取右主體左留白。
主體：保持同一無品牌保養瓶外觀，改成橫放並加入一片綠葉。
構圖：仍維持右側主體、左側 40% 留白；不得交換文案區。
風格與光線：與第一張相同的柔和側光與低對比石材背景。
限制：不得改瓶蓋、瓶身高寬比、主色或陰影方向；不要帶入 reference 的文字與 logo。
```

## 拆解練習

任選一例，把每一行標成「不可改」「可變」「禁止帶入」。若無法指出證據，先不要生成。
