# 離線候選工作簿

用途：當生圖平台無法登入、額度不足、排隊過久或不允許上傳時，仍完成 PRAC2 → CH3-1 → PRAC3 → CH4-1 → PRAC4 → CH5-1 的核心判讀與證據鏈。這條路徑不證明平台操作熟練，平台實跑仍列為待驗。

使用圖：[OFFLINE-01 六格候選工作表](../reference-pack/course-offline-candidate-sheet.png)

## 面板編號

由左至右、由上至下：

- P1：自然留白咖啡。
- P2：瑞士編輯咖啡。
- P3：美式復古咖啡。
- P4：同骨架灰階線稿。
- P5：同骨架保養品。
- P6：同骨架湖畔旅行。

六格都刻意保留：右側主體、左上標題安全區、左下徽章佔位、由左到右的閱讀方向。

## PRAC2｜同骨架不同 preset

1. 比較 P1／P2／P3，逐格記錄版型、字階預留、配色、必要元素。
2. 圈出保持不變的三個結構項。
3. 寫出至少兩個表象差異，並指出它們來自色彩、材質、光線或圖形語彙哪一類。
4. 三格都要作人工判定；任一必要項未知就標記 REVISE。

完成物：一張 P1–P3 比較表 + 兩個可見差異。不以「只填 brief」代替。

## CH3-1｜完稿轉線稿判讀

1. 將 P1 與 P4 並排。
2. 逐項核對主體位置、占比、標題區、徽章區、閱讀方向與多餘元素。
3. 在 P4 上標示 must keep／can change／forbidden。
4. 留下一項工具或前後對照證據。

完成物：P4 骨架紀錄 + 六項人工判定 + 證據。不要求對話 URL；來源記 `OFFLINE-01 / P1→P4`。

## PRAC3｜五張素材的結構抽取

1. 以 P1、P2、P3、P5、P6 為五張來源，逐張記錄 `OFFLINE-01 / 面板編號`。
2. 對每張手繪或文字描述其線稿：主體框、標題安全區、徽章區、引導線。
3. 逐張標記 READY／REVISE 與原因；至少完成三張，五張為 stretch goal。
4. 選出最高泛用骨架，寫出可套用的三個業種。

完成物：至少三份結構筆記 + 來源 + 人工必要項 + 最高泛用判定。

## CH4-1｜同骨架跨業種反控

1. 以 P4 為骨架，P1／P5／P6 為三張跨業種結果。
2. 檢查三張是否保留右側主體、左上安全區、左下徽章與閱讀方向。
3. 檢查內容是否確實換成咖啡／保養／旅行，而非只換顏色。
4. 至少兩張必要項全過；選一張寫一輪「只改一項、保持其餘不變」回修指令。

完成物：三份驗收 A + 至少兩張 PASS + 一份回修指令。

## PRAC4｜同品牌三張系列驗收

使用下列三張課程專用候選；三張共用同一品牌 DNA 與構圖骨架，只更換季節主題：

- [春季候選 v16](../course-visuals/2026-10/v16-brand-spring-2026-10.png)
- [夏季候選 v17](../course-visuals/2026-10/v17-brand-summer-2026-10.png)
- [冬季候選 v18](../course-visuals/2026-10/v18-brand-winter-2026-10.png)

1. 先抄錄共同 DNA：主色、強調色、背景色、字體後製方向、語氣與禁用項。
2. 逐張記錄唯一允許改變的季節主題；圈出商品、配色、構圖、禁用項與正式文字等五類差異。
3. 由人工逐項判定 PASS／REVISE；AI 只能列待查位置，不能代替放行。
4. 請第三人盲看三張是否像同品牌，記錄人數、原句與判定。
5. 選出系列感最弱的一張，寫一輪「只改一項、其餘不變」的回修指令。

完成物：三張候選編號 + 五段 DNA + 五類差異表 + 第三人盲評 + 一份單變因回修指令。三張不是同一品牌、同一骨架或只改一個主題時不得過關。

## CH5-1｜完整閉環與 Release gate

沿用 PRAC4 的 v16／v17／v18 三張候選，完成：

1. 把 v16 當完稿 A，手繪或文字化反推一張 L2 線稿，標出主體、標題安全區、徽章、CTA 與 must keep／can change／forbidden。
2. 以 L2 線稿逐項核對 v17／v18，證明 B／C 只換季節主題、沒有換骨架或品牌 DNA。
3. 選一張做一次局部修改：在副本上以紙筆或可用的離線編輯工具實際改一個不合格項，保留修改前／後，並核對選區外沒有改動。
4. 對三張系列完稿完成 8 項結構 QA 與 5 項跨張驗收。
5. 完成商用五關；未知項標記 STOP，不自行補資料。
6. 交付三張各自的 alt、完整純文字文案、文字校稿與對比檢查。
7. Provenance manifest 記錄工具、日期、prompt 狀態、v16／v17／v18、人工修改與來源訊號；最後標記 READY／REVISE／STOP。

完成物：3 張系列完稿 + 1 張 L2 線稿 + 1 組局部修改前後對照 + 系列 QA + release gate + alt／copy + manifest。少一項不得過關；離線路徑不證明平台操作熟練。
