## 2. 不可變項

| 類別 | 規則 | 驗收方式 |
| --- | --- | --- |
| 主色 | 色票或容差範圍 | 取色器紀錄 |
| Accent | 出現位置、面積上限 | 面積與位置目視 |
| 光線 | 方向、軟硬、對比 | 陰影方向前後對照 |
| 材質 | 主要表面與紋理 | 放大檢查 |
| 構圖 | 主體占比、固定留白 | 疊安全區模板 |
| 商品／角色 | 不可改外觀 | Reference 前後對照 |
| 字體 | 後製字型與層級 | 設計檔／字型清單 |
