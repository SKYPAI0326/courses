# 生圖 Anti-patterns：看到現象就知道回哪裡修

不要一次重寫整段 prompt。先辨識現象，回到最小責任區，單次只改一個變因。

| 現象 | 常見原因 | 先回哪裡修 | 可觀測證據 | 安全停止條件 |
| --- | --- | --- | --- | --- |
| 主體不明、裝飾搶戲 | 主體占比與數量未定義 | 主體＋構圖 | 縮圖下第一眼指出同一主體 | 兩輪後仍無單一焦點，改用簡化骨架 |
| 留白被填滿 | 未指定安全區用途 | 構圖 | 疊上文案框仍不遮主體 | 平台無法遵守留白，改用後製擴圖或裁切 |
| 商品外觀漂移 | Reference 角色混雜或限制不明 | 商品 reference | 前後對照輪廓、比例、瓶蓋 | 關鍵商品特徵連續兩輪改變，停止生成 |
| 選區外也被改 | 局部修改不支援或描述太廣 | 局部修改指令 | 差異圖只出現在指定區 | 無法限定修改範圍，回到原圖後製 |
| 圖中文字錯誤 | 把正式文案交給圖像模型 | 後製流程 | 逐字校稿與 OCR | 價格、日期、法規文字一律移出生成 |
| 色彩看似接近但不一致 | 只用色名、未取色 | 品牌 DNA | 取色器紀錄 RGB/HEX 與容差 | 精確品牌色無法穩定時改用後製 |
| 系列圖像不同品牌 | 未鎖定不可變項 | 品牌 DNA＋系列檢查 | 連排 3 張仍有相同光向、材質與 accent | 每輪都漂移不同項目，回到一張母版 |
| 多 Reference 汙染 | 未說明每張角色與禁止帶入 | Reference 分工 | 來源圖的文字/logo 未出現在結果 | 權利不明元素被帶入，立即停用該 reference |
| 人物肢體或身份異常 | 姿勢複雜、identity 約束不足 | 主體＋人工 QA | 手指、關節、臉部與配件逐項檢查 | 可辨識人物未同意或身份漂移，停止使用 |
| 畫面帶有刻板印象 | 敏感屬性被當成視覺捷徑 | Brief＋偏誤檢查 | 成對 prompt 只改一項後比較角色與場景 | 無法說明敏感屬性必要性，移除該屬性 |
| 「AI 說通過」但人看出錯 | 把自評當證據 | 人工 QA | 人工、工具、第三人三層紀錄 | 任一必要項失敗即不得放行 |
| 權利或同意不明 | 素材來源缺紀錄 | Release gate | manifest 欄位完整且可追溯 | 任一欄 UNKNOWN，改用課程 pack 或自有素材 |

## 單變因修復句型

```text
目前可觀察到：{錯誤現象}。
這一輪只修改：{一個變因}。
保持不變：{已通過項目}。
通過證據：{人要看什麼、工具要量什麼}。
```
