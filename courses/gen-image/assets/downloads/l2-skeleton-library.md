# L2 線稿骨架庫

L2 只保留主體框、文案區、CTA、留白與視線路徑，不畫材質與裝飾。先判骨架，再決定產業與風格。

## 骨架 1｜主體下置＋上方標題

```text
┌──────────────────┐
│   標題／主張區    │
│                  │
│      主體框       │
│    ┌────────┐    │
│    └────────┘    │
│  輔助資訊   CTA   │
└──────────────────┘
```

- 適合：社群新品、活動海報。
- 先看：上方安全區是否真的空；主體縮小後是否仍清楚。

## 骨架 2｜左文右圖

```text
┌──────────────────┐
│ 文案區 │          │
│ 標題   │  主體框  │
│ 說明   │          │
│ CTA    │          │
└──────────────────┘
```

- 適合：官網 hero、EDM。
- 先看：手機裁切時能否改成上下排列；主體不得壓到文案區。

## 骨架 3｜中心商品＋環繞證據

```text
┌──────────────────┐
│ 證據 A    證據 B │
│      ┌────┐      │
│      │主體│      │
│      └────┘      │
│ 證據 C    CTA    │
└──────────────────┘
```

- 適合：電商賣點、功能介紹。
- 先看：證據不可比商品更搶；正式文字應後製。

## 骨架 4｜對角引導

```text
┌──────────────────┐
│ 標題              │
│       ↘           │
│          主體框   │
│               CTA│
└──────────────────┘
```

- 適合：旅遊、生活情境、動態活動。
- 先看：引導線是否把視線帶向主體，而不是帶出畫面。

## 骨架 5｜模組網格

```text
┌──────────┬───────┐
│ 大主題格 │ 小格 A│
│          ├───────┤
├─────┬────┤ 小格 B│
│小格C│結論│       │
└─────┴────┴───────┘
```

- 適合：資訊圖、系列摘要、品牌 board。
- 先看：每格是否只有一個重點；閱讀順序是否能用箭頭說明。

## 驗收與失敗回修

1. 用 3 秒指出 P1、P2、P3；不同人答案若分散，層級不清。
2. 把畫面縮成手機縮圖，主體仍需可辨識。
3. 疊上安全區，正式文字不得壓到主體。
4. 骨架不穩時回到框線，不要靠增加裝飾補救。
