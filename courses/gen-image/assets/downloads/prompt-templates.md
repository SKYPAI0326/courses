# Prompt 組裝模板

## 模板 A｜從 Brief 到第一版

```text
用途與比例：{交付媒介、比例、觀看尺寸}
目標：{觀眾看完要知道／感受／採取什麼行動}
場景：{環境、背景、時間、必要道具}
主體：{品項、數量、材質、姿態、不可改外觀}
構圖：{主體位置、占比、視線路徑、負空間與安全區}
風格與光線：{媒材、真實度、光向、對比、色彩}
限制：{不要的人物、文字、logo、變形、錯誤物件與權利風險}
```

送出前，把「好看、專業、高級」換成可觀測屬性。例如：

- 高級 → 低飽和、單一主光、材質細節、裝飾不超過兩種。
- 活潑 → 高明度、短陰影、斜向節奏、三個色塊以內。
- 日系 → 大面積留白、自然材質、低對比、細線條；不要用品牌名代替。

## 模板 B｜多 Reference 角色分工

```text
Image 1（商品 reference）：只鎖定 {外觀、比例、材質}。
Image 2（構圖 reference）：只取 {主體位置、視線路徑、留白}；不要帶入 {文字、logo、商品}。
Image 3（品牌 reference）：只取 {色彩、光線、材質語彙}；不要複製特定 trade dress。

產出要求：{新場景與用途}。
必須保留：{可觀測項目}。
可以改變：{可變項目}。
禁止帶入：{來源圖中不屬於本案的元素}。
```

每張 reference 只承擔清楚角色。來源、授權或人物同意不明時，改用課程 reference pack。

## 模板 C｜局部修改

```text
只修改：{指定區域與指定內容}。
保持不變：{主體外觀、構圖、光向、背景、色彩、比例等}。
修改後應看到：{可觀測結果}。
不得改動：{選區外項目清單}。
若無法只改指定區域：停止，不要重畫整張；回報受限位置。
```

## 模板 D｜失敗回修

```text
目前現象：{只描述看得到的錯誤}。
目標差距：{與 brief 哪一項不符}。
這一輪只改：{一個變因}。
必須保持：{已通過項目}。
通過證據：{尺寸、取色、文字校稿、第三人盲評或前後對照}。
```

## 模板 E｜人工驗收紀錄

```text
候選版本：{檔名／版本}
AI 提出的待查項目：{線索，不是結論}
人工目視：{通過／失敗 + 現象}
工具證據：{尺寸、像素、取色、OCR、對比、裁切預覽}
第三人盲評：{任務是否看懂、先看到什麼}
決定：{通過／回修／停止}
回修位置：{prompt 哪一段、reference、後製或 brief}
```

## 模板 F｜品牌繼承系列

```text
依以下 Brand DNA 執行：
{貼完整 Brand DNA}

Reference 角色：{商品／構圖／品牌，各自只負責什麼}
本次唯一主要變因：{季節、產品或活動主題}
必須保留：{不可變項}
可以改變：{可變項}
禁止帶入：{第三方識別、未授權元素、正式價格與法規文字}
正式文字：保留乾淨文字區，交由後製加入。
```

## 模板 G｜系列差異盤點

```text
請列出系列 A／B／C 的待查差異，不要替使用者宣告通過：
1. 色彩與光向：指出可能偏離 Brand DNA 的區域。
2. 商品／角色：指出外觀、比例或材質可能漂移的位置。
3. 構圖：指出主體占比、留白與視線路徑差異。
4. 禁止清單：逐張列出可能違規的元素。
5. 正式文字：列出必須人工後製與校稿的位置。

最後輸出待查清單；實際通過與否由人類與工具證據決定。
```
