## 使用界線

1. Reference pack 僅供本課練習與教學示範，不授權對外商用或轉售。
2. 搜尋網站可以用來觀察市場，但不要下載、截圖或上傳權利不明的第三方圖片。
3. AI 自評只能列出待查項目；是否通過由人依可觀測證據判斷。
4. 權利、同意、平台條款或素材授權任一不明時，停止交付並改用本課 reference pack。
