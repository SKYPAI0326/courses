# 同一素材的 8 種用途版型

這 8 種是「交付用途」，不是 L2 骨架。先決定觀眾在哪裡看到、需要做什麼，再選比例與安全區。

| 版型 | 常用比例 | 畫面優先順序 | 安全區 | 驗收問題 |
| --- | --- | --- | --- | --- |
| A. 電商主圖 | 1:1 | 商品輪廓 → 包裝細節 → 配件 | 四周至少 6% | 縮成 160px 後仍知道賣什麼嗎？ |
| B. 社群主圖 | 4:5 | 主視覺 → 一句主張 → 行動線索 | 上下避開介面遮擋 | 第一秒看到的是主體還是裝飾？ |
| C. 限時動態 | 9:16 | 上段鉤子 → 中段主體 → 下段 CTA | 上下各留約 15% | 按鈕區是否被主體擋住？ |
| D. 官網 Hero | 16:9 / 3:2 | 品牌情緒 → 主體 → 文案 | 依文案位置保留 35–45% 負空間 | 桌機與手機裁切後主體都完整嗎？ |
| E. EDM 橫幅 | 3:1 / 2:1 | 主張 → 商品 → 日期或條件 | 文案與商品分區 | 窄幅下是否仍有單一路徑？ |
| F. 活動海報 | 4:5 / A 系列 | 活動名 → 主視覺 → 日期地點 | 上中下三段 | 文字拿掉後仍有清楚層級嗎？ |
| G. 資訊圖 | 4:5 / 1:1 | 標題 → 區塊順序 → 結論 | 每區可容納後製文字 | 完整文字版是否同步交付？ |
| H. 系列封面 | 1:1 / 4:5 | 固定識別 → 每期主題 → 編號 | 固定模組位置 | 連排 4 張時像同一系列嗎？ |

## 同一張素材如何改版

以「無品牌咖啡袋」為例：

- 電商主圖：商品置中、背景最少、細節可辨識。
- 社群主圖：商品偏下，上方留標題，加入一個季節色塊。
- 限時動態：商品落在中段，下方留 CTA；避免頂端被帳號列遮住。
- Hero：商品落在右側，左側完整保留文案區；另做手機裁切。
- EDM：用更窄的橫向構圖，移除不必要配件。
- 海報：保留上中下三級文字區，不讓模型生成正式文案。
- 資訊圖：商品只作一個區塊，其他區塊承接規格與使用方式。
- 系列封面：鎖定商品大小、背景材質與 accent 位置，只換主題色或配件。

## 選擇規則

1. 先寫交付媒介與實際裁切比例。
2. 再標出不可被平台 UI 或文字覆蓋的位置。
3. 只有在同一比例內才比較構圖版本；不同用途不得只靠自動裁切。
4. 正式文字、價格、日期與法規資訊一律後製並逐字校稿。
