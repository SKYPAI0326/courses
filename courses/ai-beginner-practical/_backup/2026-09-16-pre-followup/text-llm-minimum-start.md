# 可輸入文字的語言模型｜最小啟動卡

這張卡不指定任何聊天平台。課程只要求你找到一個「能輸入文字、送出問題、看到回答、複製並保存文字」的語言模型工具；平台名稱與畫面按鈕可能不同。

## 平台中立的取得路徑

1. 如果是課堂學習，先使用課程提供者給你的課程入口、現場帳號或指定練習環境。
2. 如果是自學者，搜尋「文字型語言模型」或開啟你已合法使用的工具官方入口；選一個能完成本卡四項基本動作的工具即可，課程不要求比較品牌，也不要求購買方案。
3. 看到登入、建立帳號或方案選擇畫面時，依該工具當下提供的流程操作。若必須付費才能開始，回到上一個選擇，改用你已有的工具、課程提供的環境，或先走本頁的離線備援。
4. 成功開啟後，先用「請用一句話說明你能協助哪些文字工作」測試；看得到回答並能複製保存，才算完成工具準備。

這條路徑讓不同地區、組織與裝置的學員都能選擇可用工具；講義中的提示詞、判斷方法與完成物格式保持不變。

## 開始前

- 先準備本單元的工作表或模板，複製一份到自己的文字筆記。
- 準備一個可以保存純文字的地方，之後要留下原始提示詞、第一版回答、修訂指令與修正版。
- 如果工具需要登入，使用你已有的帳號；如果該工具提供免登入或訪客模式，可以依畫面提示進入。課程不要求你為本課程購買方案。

## 你要在畫面上找到的四個位置

1. **文字輸入區**：可以貼上完整提示詞的地方。
2. **送出控制**：送出文字後，回答會出現在同一個對話中。
3. **回答區**：閱讀、複製或重新選取工具回答的地方。
4. **保存位置**：把提示詞與回答貼回工作表或自己的純文字筆記。

## 最小操作

1. 開啟你能使用的文字型語言模型工具，確認看得到文字輸入區。
2. 先貼一個短問題，例如：「請用一句話說明你能協助哪些文字工作。」
3. 送出後，確認回答出現在回答區。
4. 複製回答，貼到工作表的第一版欄位；不要只保存最後修改後的文字。

## 如果無法登入或工具暫時不可用

先不要自行猜測或把課程示範當成自己的完成物。你可以：

- 先用本單元的完整示範，練習標出輸入、輸出、保留條件與待確認事項；
- 在工作表記下「待重跑：工具可用後，從哪一個步驟重新送出」；
- 保存目前已完成的欄位與原始提示詞；
- 工具恢復後，從最近一個未完成步驟重跑，並把自己的實際回答補回。

這條備援路徑能保留學習進度，但不能把頁面示範或預先提供的回答算成你的個人化完成物。
