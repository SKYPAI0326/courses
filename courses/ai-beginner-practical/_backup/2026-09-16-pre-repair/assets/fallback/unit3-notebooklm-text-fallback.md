# 第 3 單元｜純文字備援

如果課堂中暫時無法加入檔案來源，仍可用下列文字完成同一個閱讀任務。請把需要的段落複製到可用的文字對話工具，並在工作表上註明「純文字備援」；這份備援不會產生 NotebookLM 的引用標記，請改以段落編號人工回查。

## 備援操作

1. 先複製一個主題區塊，不要一次貼上全部素材。
2. 在問題中保留段落編號，例如 [N01-P01]。
3. 要求輸出引用段落編號；找不到的內容寫「來源未提及」。
4. 用原始段落逐句核對數字、日期、條件與結論。
5. NotebookLM 恢復後，再用同一份提示詞加入正式來源重做一次。

## 新聞摘要備援

請只根據以下文字，輸出一句話、約 200 字、約 500 字三種摘要。每段保留支持主旨的段落編號；不要把計畫寫成已完成；找不到的資訊寫「來源未提及」。
