# 第一次使用文字對話工具

先完成一次「送出、看到回答、複製、貼回」，再開始本章任務。文字型 LLM 就是能用文字對話完成任務的 AI 工具。

## 先開啟可用入口

1. 課前先和講師確認你能使用的工具入口與帳號。上課時開啟該入口；尚未取得入口，先請講師協助，不需要自行比較品牌。
2. 依畫面登入，確認能看到文字輸入區。若帳號不能使用或要求升級付費，請講師協助改用課前確認的可用環境。
3. 自學時，使用你已能登入的文字對話工具。還沒有可用工具時，先完成工具準備，再進行模型實作；不把閱讀範例當成已完成對話。

不熟悉登入或找不到輸入區時，先把這一步處理好。課程不要求購買方案。

## 做一次小測試

1. 在輸入區貼上：`請用一句話說明你能協助哪些文字工作。`
2. 用畫面的送出控制送出，等待回答。
3. 使用複製功能，或選取回答文字後按複製。
4. 開啟自己的文字筆記，貼上回答。確認最後一句也有貼上。
這次小測試只確認工具能送出與複製，不另交作業。看到貼回的文字後再回講義。

## 第一次保存正式任務

1. 回講義開始自己的任務。任務完成後，將提示詞與回答貼回本頁工作台，按「儲存到本機」。
2. 重新整理頁面，確認剛才內容仍在；按「匯出 Markdown」，到下載資料夾重開。`.md` 是文字檔，不能直接開啟時，用純文字工具開啟即可。

## 看不到回答或不能保存時

- 輸入後沒有回答：檢查是否已送出及登入狀態，請講師協助確認工具。
- 工作台不能暫存：立即匯出或列印，保留已完成內容。
- 工具暫時不可用：先讀完整示範找出錯句，記下「平台待重跑」與續做步驟。工具可用後再產生自己的回答。

要保存第一版與修正版，不能只留最後結果；範例不當成自己產生的回答。
