# 第 3 單元來源包

這 9 份檔案是課堂用的模擬素材，方便全班使用同一批文字練習 NotebookLM 的來源、提問與引用回查。它們不代表即時新聞、實際政府公告或正式法規。

|---|---|---|
| 新聞 | news-community-fridge.txt | 講師 Demo：主張與證據狀態台帳 |
| 新聞 | news-workshop-transcript.txt | 進階摘要選題 |
| 新聞 | news-market-stall.txt | 進階摘要選題 |
| 新聞 | news-library-books.txt | 進階摘要選題 |

| 公告 | notice-tax-filing.txt | Together：影響、期限、下一步 |
| 公告 | notice-labor-insurance.txt | 個人練習選題 |
| 公告 | notice-health-insurance.txt | 個人練習選題 |
| 書籍節錄 | book-excerpt-learning-notes.txt | 5 個重點與 3 個行動 |

檔案中的段落編號（例如 [N01-P03]）是純文字備援與人工回查用的輔助標記；在 NotebookLM 中仍以回答顯示的引用為主要回查入口。
