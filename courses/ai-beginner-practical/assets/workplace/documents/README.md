# CH3同情境工作文件

每位學員獨立選A或B一組，在自己的NotebookLM建立筆記本；每組3份文件都要加入。選FAQ／一頁交接／會議待辦其中一種成果，不需交三種。這些是完整教學模擬文件，不代表現行單位規定。

A教育行政：排課規範、期間性核准公告、容量有矛盾的會議。B服務交接：案件規範、首次回覆試辦公告、C017交接會議。A練版本權威與適用範圍，B練首次回覆與結案的差異、未完成與詢問期限。

先開啟CH3-1.html#workplace-practice的來源複製區，依序加入所選三文件，再選prompts/中的一份成品提示詞。reference成品只在完成自己的版本後對照；手寫DA／DB代號不代表平台引用。

延伸自己的單位：換成可使用的同情境3份文件，保留讀者、文件狀態、版本與期間；沒有資料就先用本包，不需要先完成Gamma。

office-ai-cases的company-sop.md與meeting-notes.md僅參考「規範＋會議→可交接文件」方法；原公司的財務數字、規定與因果敘述沒有移入本包。
