# 看一份實際做過的提案

先看一份 PDF 的封面、方法、時程與核准頁，知道自己會留下什麼。接著回到 [素材入口](../README.md) 選企劃操作，不要求交相同措辭或版型。

實跑使用 Gamma Agent 作文字對話、生成與修訂；其他 LLM、經典生成器及初學者真人跟做尚未實測。初稿保留實際不足，不能直接視為最終正確答案。

A 的初稿把業績與費用放同頁，後續分區標明萬元與元；原大綱漏列費用兩項篩選規則，修訂時回 P03 補回。首次 PDF 的四週表格排壞，第四週擠成窄欄，改為單欄四段後重新匯出檢查。最終 PDF 包含修復結果，初稿文字未覆寫。B 的第8頁將三個角色責任分行，保留時間與成本條件。

兩份最終 PDF 均重新開啟、確認十頁並檢查版面。Gamma 可編輯檔留在製作帳號，未公開分享；學員使用這裡的 PDF 預覽，自己的可編輯版本由自己的帳號製作。
