# PRAC2-1 Gamma 實際試跑紀錄

日期：2026-10-07，Asia/Taipei。執行者：作者以瀏覽器工具操作，不是初學者真人跟做。範圍：兩份完整模擬企劃至 Gamma 修訂與 PDF 匯出。最終結果：此平台路徑 PASS；其他工具分支與授課時間不在通過範圍。

## 實際路徑

兩案分別在授課帳號的 Gamma Agent 輸入共用 outline.txt 提示詞與完整企劃，取得十頁大綱；第二次輸入 gamma-text.txt 提示詞及實際大綱，取得十段文字；貼入生成提示詞與實際十段文字，檢查十張方案後按生成。生成後各自修訂，使用分享 → 匯出 → 所有投影片 → PDF，下載再開啟。

實際發送全文以 case-a／case-b-prompt-sent.txt 保存，材料檢查比對完整來源與提示詞。A 在試跑後修正一個「未解問题」錯字為「未解問題」，實際發送檔未改寫；內容未受影響。B 來源未改。大綱與第二次轉換、生成指令各存獨立檔，沒有用人工參考冒充模型輸出。

A 首次失敗 PDF：case-a-before-table-fix.pdf；第7頁影像：case-a-before-table-fix-page-7.jpg。失敗已由最後匯出版本取代，紀錄保留。修復指令與前後可見畫面存 case-a-table-fix-prompt.txt、case-a-rule-restore-prompt.txt、case-a-final-revision-visible.txt。Gamma 自述版面通過不作為 PDF 驗收依據。

有一次 Agent 送出顯示連線失敗，輸入內容仍在，重新送出後正常處理。B 的 download 事件監聽逾時，但介面顯示匯出完成；實際下載檔從本機 Downloads 取得並以 PDF 內容確認，不將事件逾時視為檔案失敗。

## 最終實檔與檢查

case-a-gamma-export.pdf、case-b-gamma-export.pdf：兩份均十頁、每頁960×540點。使用 pdfplumber 逐頁核對實際第二階段正文，NFKC 正規化、忽略空白與角色分行取代的分號，以 PDF 文字流順序檢查；沒有正文遺漏。另檢查 A 的兩規則及第7頁四週、B 的投入條件。方法與雜湊見 pdf-checks.json。

使用 pdftoppm 渲染全部二十頁，作者查看兩案全部頁面的聯絡表及 A 第5／7頁、B 第8頁大圖。最終無截字、重疊或故障直欄；文字量仍較多，真人可讀性與授課耗時仍需實測。渲染只是把實際 Gamma PDF 轉為檢查影像，沒有重新排版或改寫 PDF。

學員可下載副本在 assets/workplace/gamma/examples/。兩個可編輯 Gamma 文件位置見 live-decks.json，保留在製作帳號；兩案分享介面均顯示連結持有人及工作區成員無存取權限，未公開或修改權限。未付費升級。

## 尚未驗證

其他 LLM、經典生成器、PPTX 匯出、真人初學者操作、90–120分鐘估時、正式 HTML 入口與 CH2 時段整合均未實測。平台 PASS 只涵蓋本次授課帳號 Gamma Agent 路徑，不代表整課已可發布。
