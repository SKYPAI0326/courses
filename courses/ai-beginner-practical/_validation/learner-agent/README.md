# 學員 Agent 驗證包

這是一個給 `ai-beginner-practical` 使用的 L5 冷試跑設計。它模擬三種真實初學者，從課程總覽開始，只使用學員看得到的頁面與素材，判斷能否獨立完成核心任務並帶走可重做的成果。

## 驗證目標

不是檢查作者是否「有寫到」某個概念，而是回答四個問題：

1. 學員從入口能否知道先做什麼？
2. 每一步是否說明操作、預期結果、快速檢查與卡住時的處理？
3. 核心任務是否能在 3 小時內完成，並留下可保存的成果？
4. 一週後，學員是否知道如何替換自己的條件再次使用？

## Agent 可讀範圍

執行前先產生 `evidence-manifest.json`。Agent 只可讀：

- `index.html`
- `module1.html`
- `CH1-1.html`、`CH2-1.html`、`CH3-1.html`、`CH4-1.html`
- manifest 列出的 19 個學員素材

禁止讀取：

- `_validation/`、`_repair/`、`_backup/`、`_review/`、`_tools/`
- `COURSE-OUTLINE.md`、`COURSE-BLUEPRINT.md`、`COVERAGE-LEDGER.md`
- `_gates.md`、`_plan.md`、`STYLE-GUIDE.md`
- 任何既有 review、修復報告或作者摘要

這個邊界避免 Agent 先看到答案、Gate 判定或製作團隊的自我說明。

## 驗證任務矩陣

每個 persona 都要走同一條課程主線，但使用不同的真實情境：

| 階段 | 必做任務 | 必須留下的證據 |
| --- | --- | --- |
| 入口 | 從 `index.html` 找到課程導覽與四個單元 | 第一步、課程定位、工具規則 |
| CH1 | 五個日常問題、五欄輸入、一次缺條件比較與個人任務卡 | 對話紀錄、缺口前後版本與任務卡 |
| CH2 | 1 封 Email、1 則訊息、3 版自我介紹、至少 2 份迭代 | 日常溝通包 |
| CH3 | NotebookLM 實機確認、3 份來源、主張／證據狀態台帳、公告影響卡、書籍三層筆記與跨來源比較 | 證據閱讀包、引用回查結果 |
| CH4 | 五類情境選一類，完成決策問題、標準／優先順序、方案比較、取捨、缺資料與下一步 | 生活決策卡與重做路徑 |
| 課後 | 使用課後整合工作表重做一個自己的需求 | 第一版、缺口／取捨判讀、後續版本與待確認欄位 |

Agent 可因時間停止延伸題，但不能把延伸題當成核心失敗；若核心任務自身無法開始、無法檢查或沒有完成物，必須標記阻斷。

## 三個學員 persona

### A｜剛接手行政工作的怡安

- 29 歲，行政專員，職場 3 年
- 會使用瀏覽器與文件編輯，沒有提示詞經驗
- 想把請假信、會議邀約與週報整理做快
- 在意能不能照著頁面完成，最怕不知道下一步

### B｜重視交付品質的志明

- 43 歲，門市營運主管，職場 15 年
- 熟悉表格與文件，偶爾使用文字型 LLM
- 想比較商品、整理公告，再把結果交給同事
- 在意輸出是否能回到來源或資料，最怕模型自行補資料

### C｜對 AI 沒把握的美玲

- 57 歲，社區服務承辦人，職場 25 年
- 會使用手機與基本文件，不熟悉多步驟網頁操作
- 想處理長公告、家庭規劃與對外訊息
- 在意錯了能不能回復，若第一次失敗就可能放棄

## 輸出判定

每個 persona 都要輸出：

- 第一個實際動作與所需時間
- 第一次卡點：頁面、步驟、時間、看不懂或做不到的原因
- 是否繼續；若繼續，記錄使用了哪個頁面的修復路徑
- 每個核心任務的完成物、缺漏與證據頁面
- 課程體驗分數（10 分）與五項子分數
- 隔週回頭使用率（0–100%）與理由
- 會推薦與不會推薦的對象
- 1–2 個最值得修補的地方

所有判定要區分：

- `observed`：頁面或素材直接支持
- `inferred`：根據頁面合理推論，但沒有直接證據
- `blocked`：因缺頁面、缺素材、缺平台實機或沒有可驗證操作而無法判定

## 通過門檻

- 三 persona 平均至少 7/10
- 隔週回頭使用率平均至少 60%
- 不得有「核心任務沒有完成物」「學員不知道下一步」「沒有快速檢查」「修復只能靠講師口頭補充」等 L5 阻斷
- CH3 的 NotebookLM 實機確認若未真正操作，只能標 `blocked`，不能用文字推論代替 L4b

## 執行限制

這份設計本身不會自動把課程內容傳給外部模型服務。若要用外部 Agent 實際跑，必須由使用者另行授權資料傳輸，並把 Call ID、輸出與分數寫回驗證紀錄；未執行時不得填入 PASS。
