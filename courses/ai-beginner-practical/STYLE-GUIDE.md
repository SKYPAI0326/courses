# ai-beginner-practical Style Guide

## 課程專屬定位

- 讀者是第一次把 LLM 用在日常任務的人，文字要讓他能照著做，不要求先懂技術名詞。
- CH2 的 PRAC2-1 指定 Gamma、CH3 指定 NotebookLM；其他 LLM 只能寫成「你正在使用的 LLM」或「對話工具」，不可出現特定平台的註冊、按鈕或介面教學。
- 每個單元都先展示完成物，再給提示詞與操作。概念解釋控制在能支持下一個動作的程度。
- 不安排資安專題。涉及健康、財經、天氣或公文時，使用「完成前查核」說明資料限制與下一步，不擴寫成資安課。

## 受眾與案例

- 主要讀者稱呼：你
- 示範主角：阿凱，27 歲，在弄一下行銷工作室負責一般文書與生活安排；他的任務只用來讓學員看懂，不要求學員扮演行銷人。
- 個人練習：回到學員自己的工作或生活需求；CH1 先補一個最影響結果的缺少條件，CH4 再比較標準、取捨與缺資料，不把同一種修改流程複製到每個單元。

## 術語覆寫

| 英文 | 本課用語 |
|---|---|
| LLM | 能用文字對話完成任務的語言模型 |
| prompt | 提示詞 |
| source | 提供 AI 的原文與資料；NotebookLM 中為加入的來源 |
| notebook | NotebookLM 筆記本 |
| citation | 回到來源的引用標記 |

## 禁用內容

- ChatGPT、Gemini、Claude 等平台名稱，不得作為學員必須使用的工具。
- 其他 LLM 的註冊、App 安裝、固定按鈕位置與平台比較；Gamma／NotebookLM 可寫完成任務所需操作，提供介面變動的查找與保存備援，不要求付費升級。
- 身分證、銀行帳號、病歷或其他資安紅線清單。

## 網頁版面標準（2026-09-14）

- 入口頁、4 個核心內容頁及 PRAC2-1 補充頁共用 `assets/layout-redesign.css`；頁面本身只保留內容專屬樣式。
- 桌面版內容寬度上限為 1120px。入口頁 hero 使用「課程定位／課程產出」雙欄；內容頁 hero 使用「單元標題／學習成果」雙欄。
- 入口頁以單元編號、時數、任務描述與獨立入口呈現課程路徑；內容頁以左側章節標記、右側教學內容維持閱讀定位。
- 卡片、提示區與主要按鈕使用單一藍灰強調色與細線；不使用漸層、重陰影或厚側邊色條。
- 寬度 760px 以下回到單欄，章節標記取消 sticky，卡片與工具清單垂直排列。

## 2026-10-08 工作實作主線

CH3每人自選同案例三文件與FAQ／交接／待辦其中一種，CH4每人自選完整兩方案brief或生活需求。短獨立示範只觀察，直接操作自己材料，不交全班案例或同桌作業。引用、版本／適用範圍是CH3新增判斷；硬限制、排序、角色工時與單一條件敏感性是CH4新增判斷。來源與brief第一次使用前可展開完整複製、下載；參考答案後看。保存台接真提示詞與版本，舊欄位折疊選做、舊紀錄保留。NotebookLM官方說明已出現Gemini Notebook名稱，以當期帳號功能與實際引用為準，文件查核不冒充平台實測。

## CH1工作主線（2026-10-08）
每人獨立選教育／服務／業務或完整自帶單一原文，只交一份工作短文與8文字＋4檢查；五欄直接在同一prompt、保存首版，只修一項並核對新版。五生活題、拆解表與另一次轉用選做，原46欄與v2值保留，不要求同桌簽核。CH1單來源任務，與CH2讀者轉換／Gamma、CH3多來源引用權威、CH4硬限制取捨分工，單章180分鐘不變。

## 零基礎跟做用語（2026-10-09）

- 開場先寫工作情境、今天的作品與第一步；詳細完成檢查集中頁尾。
- 學員操作用中文具體動詞。「brief」寫「完整案例資料」，「compare／change」寫「比較兩方案／改一項限制」；「主張」首次出現解釋為「一句可以查證的話」。內部階段代碼、暫存版本與平台試跑日期留教案。
- 「每人獨立」開場交代一次；不在每步重複無須同學、全班或同桌的敘述。
- 參考成品標明作者或模型來源；工具不可用的狀態與續做方法留在對應步驟。文字改善不等於真人理解、時數或新提示詞已實跑通過。
- CH2 自我介紹、第二次轉換集中課後區；必答題只使用本章必做文字。補限制試一次仍錯時，可依原文人工完成並保留版本。
- CH4 案例用「補訓案／交接案」，主要說明使用具體方案名稱。450漢字只作模型縮稿參考，不另設逐字計數作業；學員核對一頁列印預覽、算式和待確認。
- Gamma 自帶企劃若沒有P編號，以原文小標題或支持短句對照。頁內文字存檔區只下載貼入全文，學員須重開確認，不宣稱自動暫存。
