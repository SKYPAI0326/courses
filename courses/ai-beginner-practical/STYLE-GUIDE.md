# ai-beginner-practical Style Guide

## 課程專屬定位

- 讀者是第一次把 LLM 用在日常任務的人，文字要讓他能照著做，不要求先懂技術名詞。
- 唯一固定平台是 NotebookLM；其他 LLM 只能寫成「你正在使用的 LLM」或「對話工具」，不可出現特定平台的註冊、按鈕或介面教學。
- 每個單元都先展示完成物，再給提示詞與操作。概念解釋控制在能支持下一個動作的程度。
- 不安排資安專題。涉及健康、財經、天氣或公文時，使用「完成前查核」說明資料限制與下一步，不擴寫成資安課。

## 受眾與案例

- 主要讀者稱呼：你
- 示範主角：阿凱，27 歲，在弄一下行銷工作室負責一般文書與生活安排；他的任務只用來讓學員看懂，不要求學員扮演行銷人。
- 個人練習：回到學員自己的工作或生活需求，保留同一份輸出規格，只改一個情境條件。

## 術語覆寫

| 英文 | 本課用語 |
|---|---|
| LLM | 能用文字對話完成任務的語言模型 |
| prompt | 提示詞 |
| source | NotebookLM 的來源資料 |
| notebook | NotebookLM 筆記本 |
| citation | 回到來源的引用標記 |

## 禁用內容

- ChatGPT、Gemini、Claude 等平台名稱，不得作為學員必須使用的工具。
- 平台註冊、登入、App 安裝、按鈕位置與平台功能比較。
- 身分證、銀行帳號、病歷或其他資安紅線清單。

## 網頁版面標準（2026-09-14）

- 入口頁與 4 個內容頁共用 `assets/layout-redesign.css`；頁面本身只保留內容專屬樣式。
- 桌面版內容寬度上限為 1120px。入口頁 hero 使用「課程定位／課程產出」雙欄；內容頁 hero 使用「單元標題／學習成果」雙欄。
- 入口頁以單元編號、時數、任務描述與獨立入口呈現課程路徑；內容頁以左側章節標記、右側教學內容維持閱讀定位。
- 卡片、提示區與主要按鈕使用單一藍灰強調色與細線；不使用漸層、重陰影或厚側邊色條。
- 寬度 760px 以下回到單欄，章節標記取消 sticky，卡片與工具清單垂直排列。
