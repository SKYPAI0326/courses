# AI 入門即戰力：可見版面重設計計畫

日期：2026-09-14

## 目標

回應入口頁「內容存在，但首屏看不出課程全貌」的問題，讓學員在第一眼知道課程總時數、四個單元、每單元的實務完成物，以及下一步要開啟哪一頁。

## 設計決策

1. 入口頁由寬鬆的單欄段落改成「左側課程定位／右側四單元索引」的首屏；四個單元使用編號、時數、任務描述、完成物與 CTA。
2. 入口頁後續說明改為緊湊的課程路徑區，保留所有原始段落與連結，只改 HTML 分組與視覺呈現。
3. 內容頁保留 editorial 文字風格，但加入固定的章節狀態列、可掃讀的 section header、較緊湊的 hero 與一致的底部導覽；不改變教學內容與操作順序。
4. 桌面版使用兩欄資訊層級，手機版回到單欄；不加入漸層、重陰影或新的平台依賴。

## 驗收

- 五頁 HTML 可正常 lint。
- 所有本地檔案與錨點連結可解析。
- 四個單元的 steps、quiz、details 數量不減少。
- 入口頁首屏可同時看見課程定位與至少兩個單元入口。
- 以本機 HTTP 預覽檢查桌面與手機版基本折行。
