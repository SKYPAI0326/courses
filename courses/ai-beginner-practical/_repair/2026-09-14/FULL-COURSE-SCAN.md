# 全課學員路徑檢視

日期：2026-09-14
範圍：CH1-1、CH2-1、CH3-1、CH4-1、Course Blueprint、各單元教案與課程提供素材
方法：HTML lint、跨檔案契約比對、素材存在性檢查、學員視角冷讀

## 結論

目前全課為 **BLOCK**。版面與靜態結構已通過，但四個單元都存在會阻斷零基礎學員獨立完成的路徑或契約問題：

| 單元 | 主要阻斷點 |
|---|---|
| CH1-1 | 工作表是 Markdown 原檔，頁面要求直接填寫；教案、工作表、HTML 的完成檢查與備援題數不一致；缺少個人變化練習 |
| CH2-1 | 版本紀錄最低要求、完成檔名與實際模板不完全一致；示範改動超過單一變因；部分產出未要求立即保存 |
| CH3-1 | NotebookLM 入口與來源加入缺少可執行起點；備援檔沒有直接入口；公告與書籍練習在 HTML 被壓成情境表；引用與保存欄位不足 |
| CH4-1 | 共同冷氣比較沒有課程素材；轉移練習改動規則與提示詞卡不相容；示範同時改兩個變因；完成檔名與 Blueprint 不一致 |
| 跨單元 | Blueprint 的四份完成物檔名與頁面／教案不一致；通用 LLM 起始檔誤寫成 CH1 工作表 |

## 已通過

- 5 個 HTML 頁面 lint：0 BLOCKER、0 ERROR、0 WARN。
- 內部連結目標存在；現有頁面使用同一套版面 CSS，沒有回退到舊版視覺結構。
- 四個單元都有操作步驟、預期結果、快速檢查與部分恢復路徑。
- CH1 示範、CH2 三類文書、CH3 來源閱讀、CH4 30 張提示詞卡均有可讀的核心內容。

## 修正原則

1. 先讓學員知道「材料在哪裡、要留下什麼、第一步怎麼建立可保存副本」。
2. Demo、Together、Solo 各自保留不同任務；共同練習使用課程提供的同一份素材。
3. 每次只改一個主要變因，並立即保存原始輸入、第一版、修改指令與修正版。
4. 課程固定平台只有 NotebookLM；其餘頁面維持文字型 LLM 通用寫法。
5. 不以 lint PASS 代替零基礎冷跟做；外部平台與課堂真人試跑仍列為後續驗收。

## 驗證限制

專案目前缺少 `_規範/course-content-substance.md`、`_規範/learner-action-contract.md` 與 `docs/audit-course-substance.py`，因此本次以現有 beginner continuity gate、Blueprint、教案、素材與瀏覽器冷讀補足內容檢查；不能宣稱完整官方 substance gate 已執行。
