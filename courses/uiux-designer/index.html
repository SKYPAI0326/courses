99 小時接近零基礎成人學員以實作成果完成每個階段

你會處理什麼工作？

課程從一個小型手機服務任務開始。你會看到需求如何逐步變成畫面規則、互動原型、測試紀錄與交付檔案。

情境：客戶只給你一句「請做一個登入與內容列表」

你要補出色彩、字型、格線、元件與內容狀態。客服把錯誤訊息改長後，版面不能裁切；使用者按下完成後，畫面要在正確時機給出回饋；下一位工作者拿到檔案時，也要知道來源、限制與修改方法。

每個階段都會保留一份看得見的成果，下一階段直接使用它。你會從同一個案例一路做到可測試的手機原型，再整理成可以交接的設計與網站素材。

從哪裡開始？

你會先處理第一個可交付的小成果，再沿著同一個案例往後建立版面、元件、原型與網站。第一堂只需要瀏覽器與 Figma；其他工具會在任務需要時出現。

完成課程後，你會留下什麼？

這些成果會在課程中逐步累積，接著組成一份能說明設計決策、測試結果與版本狀態的交付包。

介面規則色彩角色、Typography scale、格線、間距與 Auto Layout 規則；用長文字、項目增刪與手機寬度變化檢查版面。
Figma 元件與畫面Component、Instance、Variants、Properties、Button、Form、List、Toast、Dialog 與 Navigation，並整理成可維護的手機畫面。
可測試的原型從線框與畫面清單組成 Prototype Flow，加入觸發、轉場、Overlay、Swap、滾動、置頂與漂浮按鈕，再用固定任務留下 Actual／Expected 與修正紀錄。
交付與網站完成 Figma／Photoshop 輸出、Inspect 與 Handoff 清單，再用 HTML、CSS、最小 JavaScript、Git/GitHub 與雲端部署保存可接手的版本。

每個單元怎麼帶你前進？

每次操作都從上一個結果出發：先看一個具體例子，再改一個條件，確認方法能承受新的內容。

  1. 先看工作情境知道誰提出需求、目前的畫面或檔案出了什麼問題，以及修好後誰會使用成果。
  2. 看完成物與示範先看到輸入、操作、中間結果與完成品，再理解這個設定或元件解決哪個問題。
  3. 跟著做一遍沿用示範中的材料與判斷條件，在自己的 Figma 或課程資料夾完成同一份成果。
  4. 改一個條件換入較長文字、另一種狀態或另一個任務，觀察原本的規則是否仍然成立。
  5. 檢查、修復、交接用明確的驗收條件確認結果；若畫面或互動不符合，回到指定位置修正，再把成果交給下一個階段。

工具會在什麼時候出現？

你不需要在第一天先學會整套工具。每種工具都跟著一個工作結果出現，單元頁會在操作前交代檔案、帳號、權限與完成條件。
