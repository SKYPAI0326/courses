第一章｜第 12 份：狀態與邊框

這是第一章的最後一份。這一份我們會在色卡新增五個顏色，並在規則表最下面加一區「狀態與邊框」，放三個樣本：一段紅色的錯誤說明、一個有外框的輸入框、一條分隔線。

開始前

這一份在做什麼、為什麼要做

這一份我們做三件事：

  1. 在色卡新增五個顏色：Error（錯誤）、Warning（警告）、Success（成功）、Control Border（操作邊框）、Border（裝飾線）。
  2. 在規則表最下面加一區「狀態與邊框」：一個小標題和五行說明。
  3. 在這一區做三個樣本：一段錯誤說明、一個輸入框、一條分隔線。

為什麼要做這件事？因為開場的課程順序表寫過，要讓成員「登入打錯知道錯在哪」。登入畫面之後會有輸入帳號的地方，打錯時要有一段說明告訴成員錯在哪裡，這段說明要用一看就知道「出錯了」的顏色。同樣地，之後成員把任務標記完成，要有「成功」的訊息；有需要留意的事，要有「警告」。

邊框也分兩種：輸入框的外框是讓人知道「這裡可以打字」，一定要看得見；卡片之間的分隔線只是裝飾，淡一點反而不搶眼。這兩種用途不同，所以用兩個顏色。

做完這一份，你會有：色卡十四個顏色；規則表最下面一區「狀態與邊框」，有五行說明、一段紅色錯誤說明、一個灰色外框的輸入框、一條淡淡的分隔線。第一章開場說的四樣東西（色卡、文字樣式、登入畫面、規則表）就全部完成了。

需要先有：第 11 份做完的檔案。

先認識一件新的事：邊框的對比門檻

還記得嗎？第 7 份說過，字要過 4.5:1。不是字的東西，例如輸入框的外框、勾選框的框線，W3C 的門檻是 3:1：只要這個框是讓人操作的，它就要至少 3:1，否則使用者找不到可以打字的地方。只是裝飾用的線，沒有這個要求。

顏色用在哪裡白底上的對比
Control Border輸入框外框（讓人操作）3.75:1，過 3:1
Border分隔線（裝飾）1.48:1，只能當裝飾
跟著做

第一段：在色卡新增五個顏色

1新增五個顏色

點最左邊那排圖示的 Variables 打開色卡。下表五個顏色，每一個都照下面的步驟建：

  • 點表格最下面的 Create variable，選單選 Color。
  • 新的一列名字是反白的，直接打名字，按 Enter。
  • 點這一列 Value 欄的 FFFFFF，打色碼，按 Enter。

做完會看到：色卡共十四列，最下面五列是這五個顏色。點色卡右上角的 × 關掉。

第二段：寫「狀態與邊框」的說明

2把規則表加長到 1480

在 Layers 點 Rules，在右邊 Layout 區 Dimensions 的 H 改成 1480，按 Enter。

做完會看到：規則表的白紙往下變長，「可使用工作室帳號登入」那一個樣本下面多出一大塊空白。

3打小標題「狀態與邊框」

  • 點文字工具 T，在新空白處的左上方點一下，打「狀態與邊框」，按 Esc。
  • 點 Typography 的樣式名那一行（或標題列右邊的四點圖示），在清單點 Section title。
  • 點 Fill 右邊的四點圖示，選 Text。
  • Position 填 X 32、Y 1112。
狀態與邊框

4打五行說明

  • 用文字工具在小標題下方點一下，打下面五行，每行結尾按 Enter，打完按 Esc。
  • 點 Typography 的樣式名那一行，在清單點 Body。
  • Fill 選 Text。
  • Position 填 X 32、Y 1148。

做完會看到：小標題下面五行說明，和上面各區的清單一樣大、一樣顏色。

第三段：做三個樣本

5錯誤說明樣本

  • 用文字工具在五行說明下方點一下，打下面這句，按 Esc。
  • 點 Typography 的樣式名那一行，在清單點 Supporting。
  • 點 Fill 右邊的四點圖示，選 Error。
  • Position 填 X 32、Y 1292。
帳號格式不正確，請輸入工作室帳號

做完會看到：一行紅色的小字。

為什麼要寫出原因？因為只把字變紅，成員只知道「錯了」，不知道錯在哪、要怎麼改。說明要寫出原因和怎麼改；而且看不清紅色的人，也能從文字讀懂。

6輸入框樣本：先拉一個框

  • 點下方工具列的 Frame 工具，在錯誤說明下方的空白處拉一個框。
  • 在 Layers 確認它縮排在 Rules 底下；雙擊它的名字，改成 Sample / Input，按 Enter。
  • Position 填 X 32、Y 1330；Layout 區 Dimensions 填 W 322、H 48。
  • Appearance 的 Corner radius 填 8。
  • 點 Fill 右邊的四點圖示，選 Card。

做完會看到：一個和按鈕一樣大的白色圓角框。因為是白底放在白紙上，現在看不出它在哪裡，這是正常的，下一步就會加外框。

7替輸入框加外框

Sample / Input 還選著。

  • 在右邊找到 Stroke（外框），點它右邊的 +。
  • 框加上了一圈黑色外框（000000），同時跳出一個調色盤。點調色盤右上角的 × 關掉它。
  • 點 Stroke 右邊的四點圖示，跳出色卡清單。
  • 在清單上方的搜尋欄打 Control，點 Control Border。點清單右上的 × 關掉。

做完會看到：輸入框有一圈灰色外框，Stroke 顯示 Control Border。

為什麼用搜尋？因為色卡現在有十四個顏色，清單要往下捲才找得到。打幾個字搜尋比較快。

8在輸入框裡放提示字

  • 用文字工具在輸入框裡面點一下，打「工作室帳號」，按 Esc。
  • 在 Layers 確認它縮排在 Sample / Input 底下。
  • 點 Typography 的樣式名那一行，在清單點 Body。
  • 點 Fill 右邊的四點圖示，選 Muted。
  • Position 填 X 16、Y 12（從輸入框左上角量）。
工作室帳號

做完會看到：輸入框裡靠左有一段灰字「工作室帳號」，像還沒打字時的提示。

9分隔線樣本

  • 點 Frame 工具，在輸入框下方的空白處拉一個框。
  • 在 Layers 確認它在 Rules 底下；雙擊名字改成 Sample / Divider，按 Enter。
  • Position 填 X 32、Y 1410；Layout 區 Dimensions 填 W 322、H 1。
  • 點 Fill 右邊的四點圖示，選 Border。

做完會看到：輸入框下方一條很淡的細線。和輸入框的外框比，分隔線淡很多：外框要讓人找得到，分隔線只是把東西隔開。

做完之後

檢查自己做對了沒

  1. 色卡：十四個顏色，最後五個是 Error、Warning、Success、Control Border、Border。
  2. 規則表最下面：小標題「狀態與邊框」、五行說明、紅色錯誤說明、輸入框、分隔線。
  3. 樣本的顏色：錯誤說明 Fill 是 Error；Sample / Input 的 Fill 是 Card、Stroke 是 Control Border；裡面的提示字 Fill 是 Muted；Sample / Divider 的 Fill 是 Border。

對照範例：範例的色卡多了 Focus Ring、Disabled、Disabled Text 三個顏色，那是做表單時才會用到的，第一章先不用管。其他顏色的色碼和對比數字和你的一樣。

打開範例對照

常見問題

點 Stroke 的 + 之後，外框一直是黑色

那個調色盤是直接挑色碼用的。關掉它，改點 Stroke 右邊的四點圖示，從色卡選 Control Border。

提示字「工作室帳號」不在輸入框裡

在 Layers 把它拖到 Sample / Input 那一行上放開，看到縮排後再填 X 16、Y 12。

這一份學到的事

  • 錯誤、警告、成功各有自己的顏色；錯誤說明要寫出原因和怎麼改，不能只靠紅色。
  • 讓人操作的外框至少 3:1；只當裝飾的線可以淡。
  • Stroke 是外框：點 + 加上，再從四點圖示選色卡的顏色。

第一章完成

開場說過，第一章做完你手上會有四樣東西。恭喜，現在全部到齊了：

  1. 一張有名字的色卡（十四個顏色）。
  2. 五種文字樣式。
  3. 一張全部照規則做的登入畫面。
  4. 一張規則表，寫清楚每個顏色和文字用在哪裡、檢查過哪些對比。

第二章開始，我們會用這些規則排版面、做出更多畫面。
