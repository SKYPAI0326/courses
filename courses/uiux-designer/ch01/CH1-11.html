第一章｜第 11 份：主色的四種用法

這一份我們會在色卡新增三個主色的變化，並在規則表加一區「主色的四種用法」，放三個參考樣本：滑鼠移上去的按鈕、按下去的按鈕、淺色的提示區。

開始前

這一份在做什麼、為什麼要做

這一份我們做四件事：

  1. 在色卡新增三個顏色：Primary Hover、Primary Pressed、Primary Soft。
  2. 把規則表下面兩區往下移一點，並把規則表加長，騰出位置。
  3. 在規則表最下面加一區「主色的四種用法」：一個小標題和四行說明。
  4. 複製登入按鈕，貼到這一區，做成三個參考樣本，分別換上三個新顏色。

為什麼要做這件事？因為按鈕被滑鼠移上去、被按下去的時候，如果顏色完全沒變，使用者會不確定「系統到底有沒有收到」。開場的主管說過，有的成員整天坐在電腦前用滑鼠，有的在客戶現場用手機按。滑鼠移上去時按鈕稍微變亮、按下去時變深，他們就知道「這裡可以按」「我按到了」。

這四種顏色都是主色的變化，都只用在最重要的那個動作上（第 9 份的規則）。我們把它們做成參考樣本放在規則表裡，之後做原型時，就照著它們設定按鈕的樣子。

做完這一份，你會有：色卡九個顏色；規則表最下面多一區「主色的四種用法」，下面依序是一顆稍亮的綠按鈕、一顆深綠按鈕、一個淺綠提示區。手機上的登入畫面不變。

需要先有：第 10 份做完的檔案（「登入」的字色是 On Primary）。

先認識一件新的事：狀態

狀態是同一個按鈕在不同時刻的樣子。這一份用到三種：

狀態什麼時候用的顏色
一般按鈕平常的樣子Primary
滑過滑鼠停在按鈕上面Primary Hover（稍亮）
按下手指或滑鼠按下去的那一刻Primary Pressed（較深）

另外一個 Primary Soft 不是按鈕的狀態，是淡淡的主色，用在提示區的底色，讓提示看起來和主色同一家，但不會比按鈕醒目。

跟著做

第一段：在色卡新增三個顏色

1新增 Primary Hover、Primary Pressed、Primary Soft

點最左邊那排圖示的 Variables 打開色卡。下表三個顏色，每一個都照下面的步驟建：點表格最下面的 Create variable，選單選 Color；新的一列名字是反白的，直接打名字，按 Enter；再點這一列 Value 欄的 FFFFFF，打色碼，按 Enter。

做完會看到：色卡共九列，最下面三列是 Primary Hover、Primary Pressed、Primary Soft。點色卡右上角的 × 關掉。

第二段：規則表騰出位置

2把規則表加長到 1112

在 Layers 點 Rules，在右邊 Layout 區 Dimensions 的 H 改成 1112，按 Enter。

做完會看到：規則表的白紙往下變長，最下面多出一大塊空白。這一份的新內容就放在那裡。

3把下面兩區往下移

照下表，在 Layers 一行一行點，每點一行就到右邊 Position 把 Y 改成表裡的數字，按 Enter。X 都不用動。

做完會看到：色彩清單和「文字樣式」之間空出一行的距離，不再擠在一起；下面每一區都往下移了 24。

為什麼要一段一段手動移？因為第 6 份看過，這些字的位置都是固定的，前面的東西變長，後面的不會自己讓開。第三章學 Auto layout 之後，這種事 Figma 會自己處理。

第三段：寫「主色的四種用法」的說明

4打小標題

點文字工具 T，在規則表最下面「主按鈕改 Muted…」那一行下方的空白處點一下，打下面的字，按 Esc。接著：點 Typography 的樣式名那一行（或標題列右邊的四點圖示），在清單點 Section title；點 Fill 右邊的四點圖示，選 Text；Position 填 X 32、Y 740。

主色的四種用法

做完會看到：小標題和上面的「色彩角色」「檢查紀錄」一樣大、一樣粗，對齊左邊。

5打四行說明

一樣用文字工具，在小標題下方點一下，打下面四行，每行結尾按 Enter，四行都打完按 Esc。接著：點 Typography 的樣式名那一行，在清單點 Body；Fill 選 Text；Position 填 X 32、Y 776。

行尾的數字是對比，是用第 7 份同一套公式算的：白字放在 Hover、Pressed 上，深色字 Text 放在 Soft 上，都超過 4.5。

做完會看到：小標題下面四行說明，字的大小和顏色和其他清單一樣。

第四段：複製按鈕，做三個參考樣本

6複製登入按鈕

先在 Layers 展開 Screen / Login、Login / Card，點 Button / Draft。在畫布上的綠色按鈕上按滑鼠右鍵，跳出的選單點 Copy。

做完會看到：選單關掉，畫面沒有變化。不用擔心，按鈕已經複製起來了，下一步才貼上。

7貼到規則表下面的空白處

捲動或縮放畫布，看到規則表最下面那塊空白。在空白處按滑鼠右鍵，選單點 Paste here（貼在這裡）。

做完會看到：你按右鍵的地方出現一顆一模一樣的綠色「登入」按鈕；Layers 裡它在 Rules 底下，名字也是 Button / Draft。

注意：Copy 之後如果重新整理了網頁，複製的內容會不見，Paste here 就貼不出東西。這時不用慌，回第 6 步重新 Copy 就好。

8做成「滑過」的樣本

這顆貼上的按鈕還選著，接著做三件事：

  • Position 填 X 32、Y 904。
  • 在 Layers 雙擊它的名字，改成 Button / Hover，按 Enter。
  • 點 Fill 右邊的四點圖示，選 Primary Hover，點清單右上的 × 關掉。

做完會看到：這顆按鈕比登入畫面上的稍微亮一點。點它裡面的 Label 看看：字色已經是 On Primary，不用再改。這就是第 10 份先修好的好處，複製幾顆都不用一個一個找。

9再貼一顆，做成「按下」的樣本

用同樣的方法，在規則表空白處再按一次右鍵，點 Paste here。新貼上的按鈕：Position 填 X 32、Y 968；在 Layers 改名為 Button / Pressed；Fill 選 Primary Pressed。

做完會看到：一顆比一般按鈕深的綠按鈕，排在滑過樣本的下面。

10再貼一個，做成「淺底提示」的樣本

在規則表空白處再按一次右鍵，點 Paste here。新貼上的這一個：Position 填 X 32、Y 1032；在 Layers 改名為 Hint / Soft；Fill 選 Primary Soft。

接著改裡面的字：

  • 在 Layers 點 Hint / Soft 底下的 Label，Fill 選 Text。
  • 在畫布上這段字上連點兩下，整段反白後打「可使用工作室帳號登入」，按 Esc。
  • 在右邊 Position 上方的 Alignment，點第二個（水平置中），再點第五個（垂直置中）。
可使用工作室帳號登入

做完會看到：最下面是一個淺綠底、深色字的提示區，字在正中間。

為什麼這裡的字要改成 Text？因為 On Primary 是「放在主色上的白字」，淺綠底上放白字，對比只有 1.15，幾乎看不見。淺底上要用深色字 Text。

做完之後

檢查自己做對了沒

  1. 色卡：九個顏色，最後三個是 Primary Hover（2F6E55）、Primary Pressed（1B4535）、Primary Soft（E8F0EC）。
  2. 規則表：最下面有「主色的四種用法」小標題、四行說明，以及三個樣本：Button / Hover、Button / Pressed、Hint / Soft。
  3. 字色：兩顆按鈕的 Label 是 On Primary，Hint / Soft 的 Label 是 Text。
  4. 登入畫面沒變：手機上的按鈕還是 Primary。

對照範例：範例的規則表也有「主色的四種用法」一區，排法不完全一樣（範例多放了一顆一般狀態的按鈕，旁邊有文字標示），顏色和對比數字是一樣的。

常見問題

右鍵選單裡沒有 Paste here，或點了沒有東西出現

回第 6 步，在登入按鈕上按右鍵重新 Copy，不要重新整理網頁，再到規則表空白處按右鍵 Paste here。

貼上的按鈕不在 Rules 底下

按右鍵的位置不在規則表的白紙上。在 Layers 把它拖到 Rules 那一行上放開，看到縮排後再填 X、Y。

改按鈕顏色時，連手機上的登入按鈕也變了

選到的是 Login / Card 底下的 Button / Draft。把它的 Fill 選回 Primary，再到 Layers 的 Rules 底下選剛貼上的那一個。

這一份學到的事

  • 同一個按鈕有不同狀態：一般、滑過、按下，各用主色的一個變化，讓使用者知道「可以按」「按到了」。
  • 淺色的主色（Soft）用在提示區底色，上面放深色字，不放白字。
  • 右鍵選單的 Copy 和 Paste here，可以把東西複製到指定的位置。
  • 字色一開始就用對的顏色，之後複製幾份都不用再改。
