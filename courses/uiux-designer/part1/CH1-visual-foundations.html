01 · 情境與起始材料

先處理「看得到內容，卻不知道先讀哪裡」的畫面

阿凱收到一張登入畫面：標題、說明、錯誤訊息和按鈕都使用相近的深灰色，大小也沒有規則。雯姊要把它交給客戶確認時，客戶無法快速指出主要任務。你會先建立閱讀順序，再把這個順序記成可重複使用的規則。

這一頁是操作講義頁：它會交代情境、示範、Figma 操作與驗收。起始材料頁提供案例文字、固定值與完成條件；讀完後回到本頁「03 · 示範」，先跟著 Figma 工作位置指引建立設計檔和工作頁，再製作視覺規則。真正的成果會留在你的 Figma 設計檔中。

開啟起始材料頁（取得輸入資料）

先取得案例文字、色彩值、文字級距與成果欄位；讀完後回到本頁「03 · 示範」開始操作。

第 01 堂完成檢查表

完成 Figma 操作後，填入 Figma 連結、截圖、樣式名稱與修正紀錄，交給下一堂使用。

Figma 官方操作說明

若畫面名稱或位置不同，再查看官方的管理頁面說明；本頁已列出本堂要用的基本路徑。

本堂環境：使用 Chrome 桌面版與已登入的 Figma 帳號，在自己的 Drafts（個人草稿區）建立可編輯的設計檔。若你無法建立個人檔案，先停在這裡，記下畫面提示再處理帳號或權限。
02 · 先理解兩種規則

色彩回答「這個元素扮演什麼角色」，字型回答「先讀哪一層」

色碼只是顏色的數值。把它命名成角色後，之後換主色時才找得到所有使用位置；文字級距則把標題、說明、錯誤與按鈕排出順序，讓使用者不用猜測。

規則白話意思本例設定看得到的結果
色彩角色用用途命名顏色，不用外觀命名。color-bg、color-text、color-accent按鈕與重要提示使用同一個強調色。
文字級距用固定尺寸區分資訊層級。標題 32、說明 16、錯誤 14、按鈕 16 px標題最大，錯誤輔助文字最小，閱讀順序清楚。
長文字檢查把真實錯誤訊息放進版面，確認大小與行距仍能閱讀。「密碼至少需要包含一個英文大寫字母與一個數字」文字可換行，沒有壓住按鈕或被裁切。
03 · 示範

先準備 Figma 工作頁，再整理視覺規則

阿凱從起始材料帶回四段登入畫面文字、三個色碼和四個文字尺寸。這些固定資料讓我們專心觀察閱讀順序。先在 Figma 建立可放成果的設計檔和工作頁，再把顏色、字級與長錯誤訊息整理成可重用的規則。

先認識三個位置：Drafts 是 Figma 檔案瀏覽器裡的個人草稿區，用來存放你的檔案；Design 是本堂要建立的設計檔，像一份可編輯的文件；Page 是設計檔裡的一張畫布，本堂把視覺規則放在名為 Visual foundations 的頁面。

建立設計檔與工作頁：保留本講義頁，在 Chrome 開新分頁操作 Figma。每一步完成後先比對畫面，再繼續。

  1. 前往 figma.com，使用你的 Figma 帳號登入。登入後應看到檔案瀏覽器；若已登入，直接從檔案瀏覽器開始。
  2. 在檔案瀏覽器左側點 Drafts。它是你的個人草稿區；進入後應看到個人檔案清單與建立檔案的入口。若看不到 Drafts，先確認已登入自己的帳號。
  3. 在 Drafts 檔案頁主區右上方，點直接顯示的 Design 按鈕。若你的介面沒有直接顯示 Design，點右上角 + Create，再選 Design。新設計檔開啟後，中央可看到空白畫布。
  4. 在畫面最左側的導覽列點 File。旁邊的側欄會顯示 Pages（頁面清單）與 Layers（目前畫布上的物件清單）。
  5. 在 Pages 標題旁點 + 新增空白頁。清單多出一個頁面名稱後，在該名稱上連按兩下，輸入 Visual foundations，再點清單空白處套用名稱。
工作頁檢查

左側 Pages 清單看得到 Visual foundations，中央是這一頁的空白畫布。若左側看不到頁面清單，先點最左側的 File；若清單收合，點目前頁面名稱展開。若介面名稱不同，可使用本節「Figma 官方操作說明」核對；目前不要開始建立色票。

先分清楚「工作畫布」和「登入畫面」：Figma 的 Page 是放置設計物件的工作區；Frame 才是本堂要設計的登入介面。空白設計檔右側會顯示 Page 和畫布色碼，左側 Layers 尚無物件；這次驗證的範例色碼是 #1E1E1E，你的檔案若不同就保留原值。底部中央工具列中，移動箭頭右邊的網格／井字形按鈕是 Frame；游標停在按鈕上會顯示工具名稱，也可以按 F。建立登入畫面 Frame 後，才把背景 #F5F3EE 設在該 Frame 的 Fill。

本堂建立的是目前檔案內可重複套用的 local styles；免費方案可以建立樣式，這堂不需要發布團隊素材庫。

在 Figma 哪裡你會看到什麼本堂要做什麼
左側 LayersFrame、文字與矩形的名稱清單。點選要修改的物件，例如 Login screen。
中央畫布Page 工作區和放在上面的登入畫面 Frame。檢查顏色、文字順序與長句是否仍在 Frame 範圍內。
右側 Design目前選取物件的尺寸、Fill 和文字 Typography 設定；未選取物件時顯示 Page。先看面板標題確認選到 Page、Frame、文字或矩形；設定背景時，標題須顯示 Frame 或 Login screen。
  1. 建立登入畫面的 Frame。看畫面底部中央工具列：移動箭頭右邊的網格／井字形按鈕是 Frame。游標停在按鈕上，等工具提示顯示 Frame 後點一下；也可按 F。在中央深色畫布按住滑鼠拖出直式框。框仍被選取時，到右側 Design 面板上方的 W、H 欄位分別輸入 402、874。到左側 Layers 對新框名稱連按兩下，輸入 Login screen 後按 Enter。
    完成畫面：中央出現直式框；右側尺寸是 402 × 874；左側 Layers 有 Login screen。
  2. 選對物件，再設定畫面背景。先看右側 Design 面板標題。若顯示 Page，你選到的是工作畫布；到左側 Layers 點 Login screen，標題應改成 Frame 或顯示該名稱，且上方能看到 W、H。在右側往下找到 Fill；若該列收合，先點列名展開；若沒有色塊，點 Fill 右側的 +。點新增的色塊打開色彩選擇器；若色彩欄顯示 RGB 等格式，點格式選單改成 HEX，輸入 F5F3EE 並按 Enter。
    完成畫面：登入畫面 Frame 內部變成淡米色，右側仍選取該 Frame；Frame 外圍 Page 畫布顏色保持原值。若整片工作畫布變色，表示改到 Page，回 Layers 選 Login screen 再操作。Figma 官方也把 Fill 定義為套用在 Frame、形狀或文字層內部的填色；選到文字時，它只會改字色。
  3. 把這個背景存成可重用的角色。仍在色彩選擇器中點 +，選建立 color style（不要選 variable），在名稱欄輸入 color-bg，按 Create style。
    完成畫面：右側 Fill 仍為淡米色，樣式清單可以找到 color-bg。若右側只顯示 Page 顏色，先取消色彩選擇器，再從 Layers 選回 Frame。
  4. 先做標題，從它建立第一個文字樣式。先在左側 Layers 點 Login screen，再在下方工具列點 Text（或按 T），在 Frame 內點一下，輸入起始材料的標題「登入工作區」。左側新文字列應縮排在 Login screen 之下；若它和 Frame 同層，把文字列拖到 Frame 名稱上。選取文字層後，右側 Design 面板會顯示文字設定；在 Typography 的字級欄輸入 32。點 Typography 的樣式按鈕，選新增樣式，命名 type-title，再按 Create style。
    完成畫面：標題變大；選取標題時，右側 Typography 能看到 32 和 type-title。
  5. 照同一條路徑完成另外三個文字樣式。每建立下一段文字前，先在 Layers 選 Login screen，再按 T 並在 Frame 內點一下。建立「輸入帳號與密碼後開始工作」，字級設為 16，建立 type-body；建立起始材料的短句「登入失敗，請檢查帳號與密碼」，字級設為 14，建立 type-helper；建立「開始登入」，字級設為 16，建立 type-button。確認每個文字列都縮排在 Frame 下方；選取文字層後才改右側 Typography 字級。若樣式已存在，從 Typography 樣式按鈕選它套用，不要建立同名副本。字族和行高沿用 Figma 初始值，本堂固定檢查的是四個字級。
    完成畫面：Layers 清單有四個文字層；分別選取時，右側可核對 32、16、14、16 px 和對應的樣式名稱。
  6. 設定文字色彩。在 Layers 點標題文字層；右側找到文字的 Fill 色塊，點開後若色彩欄顯示 RGB 等其他格式，先在格式選單改成 HEX，再輸入 2C2B28 並按 Enter。點色彩選擇器的 + 建立 color style，命名 color-text。接著逐一選取說明、錯誤與按鈕文字層，在它們的 Fill 樣式清單選 color-text。
    完成畫面：四段文字都變成深色；外層 Frame 的淡米色背景不變。若選字時改到整片背景，先看右側標題，再回 Layers 選對物件。
  7. 替按鈕做一個金色底框。先在左側 Layers 點 Login screen，再在下方工具列點 Rectangle（或按 R），在「開始登入」文字後方拖出橫向矩形。確認新矩形列縮排在 Frame 下方；選取矩形，在右側 Design → Fill 的格式選單選 HEX，輸入 C9963A 並按 Enter，再點色彩選擇器的 + 建立 color-accent。在 Layers 將矩形拖到按鈕文字下方，讓文字可見。這裡的矩形只呈現按鈕外觀，點擊互動會在後面的原型單元製作。
    完成畫面：金色底框與「開始登入」文字都在 Login screen Frame 內，文字沒有被遮住。
  8. 排出閱讀順序，再測試長錯誤訊息。在中央畫布拖曳四段文字，由上到下排列為標題、說明、錯誤訊息、按鈕；左邊緣大致對齊，全部留在 Frame 內。本堂先練閱讀層級，不設定格線或 Auto Layout。先截一張起始短句的畫面。接著在左側 Layers 點錯誤文字列，按 Enter 或連按兩下進入文字編輯；按 ⌘A（Mac）或 Ctrl+A（Windows）選取原句，替換為材料頁的長文字壓力句「密碼至少需要包含一個英文大寫字母與一個數字」。仍選取這個文字層時，到右側 Design 面板上方的 W 欄輸入 200；再向下找到 Layout 區，打開高度模式並選 Auto height。
    完成畫面：長句自動換行且每一行都看得見，文字框隨內容增高，按鈕沒有重疊或移出 Frame；保存長句截圖。
操作時先看右側面板標題：Page 代表你在改工作畫布；Frame 或 Login screen 代表你在改登入畫面背景；Text 代表你在改文字；選到矩形時才是在改按鈕底色。每次輸入色碼前先確認這個標題。

需要對照 Figma 畫面時：可開啟官方的 Frame 建立說明、Fill 設定說明、色彩選擇器與樣式、文字樣式、文字框尺寸與換行。官方頁面含操作畫面；本講義的步驟仍以本堂可直接完成的順序為主。

Checkpoint 1

現在應該看到 402 × 874 的 Login screen Frame，內部是 #F5F3EE；四段文字依序排列，三個色彩角色和四個文字樣式都已建立。選取 Frame 時右側能看到 color-bg，選取文字時能看到各自的樣式。若整張工作區變色，回到 Layers 選 Login screen，將 color-bg 設在 Frame 的 Fill。

04 · 跟著做

用同一組資料建立你的第一份規則表

工作頁已就緒，示範也展示了完整結果。現在沿用固定色碼、文字和四個尺寸，自己安排區塊位置；你要判斷視線先到哪裡、按鈕是否突出，以及長錯誤訊息會不會擠開按鈕。

這次自己做畫面上的位置與動作完成檢查／卡住時
建立登入畫面在底部中央工具列找移動箭頭右邊的網格／井字形 Frame 按鈕（停留確認工具名稱），或按 F；在中央畫布拖出框。右側 Design 的 W、H 輸入 402、874；左側 Layers 將框命名 Login screen。右側顯示 402 × 874；左側有 Login screen。若右側標題是 Page，回 Layers 點 Frame 名稱。
套用背景先看右側標題：若是 Page，到 Layers 點 Login screen；標題應變為 Frame。再於右側 Fill 點 +、色塊、HEX 欄，輸入 F5F3EE；色彩選擇器 + 建立 color-bg。淡米色只出現在 Frame 內，Page 外圍保持原色。若整片工作區變色，回 Layers 選 Login screen 設 Fill；不要改 Page 顏色。
完成字色與按鈕色選文字層，在右側文字 Fill 建立 color-text；選按鈕矩形，在 Fill 建立 color-accent。逐一選 Frame、文字、矩形，對照右側標題與 Fill 色塊。矩形若遮住文字，在 Layers 將矩形排到文字下方。
完成文字樣式下方 Text／按 T 建立文字；右側 Typography 設 32、16、14、16，從樣式按鈕建立或套用對應名稱。每選一個文字層，右側都能看到對應字級與樣式名稱；若看見 Frame 設定，回 Layers 點正確文字層。
替換長錯誤訊息選錯誤文字層，改貼完整長句；右側寬度設 200，Layout 高度模式設 Auto height。文字需換行並完整顯示，按鈕保留在 Frame 內。保存短句、長句兩張截圖。

判斷方法：先在中央畫布追「標題 → 說明 → 錯誤 → 按鈕」，再從 Layers 逐一選取。每次改值前，先用右側面板標題確認目前選到 Page、Frame、文字或矩形。

05 · 自己改一個條件

換成另一段錯誤訊息，確認規則能承受內容變化

把錯誤訊息改成「帳號或密碼不正確，請檢查後再試一次」，保持色彩角色、四個文字尺寸、段落順序與按鈕位置不變。比較兩段文字的行數、可讀性和與按鈕的距離，記錄一個需要修正的地方。

Checkpoint 2

通過條件是兩段錯誤訊息都能閱讀，標題仍是第一個視覺焦點，按鈕仍能被辨識；紀錄中要寫出你改了哪個間距或文字框，以及改動後的畫面結果。

06 · 驗收與下一堂

把視覺規則交給格線與版面基準

完成本堂後，你有一頁可重開的 Figma 視覺規則表。下一堂會沿用同一套色彩與文字樣式，處理手機和桌機的欄、間距與安全邊界；因此請保留檔案名稱、色票名稱、文字樣式與短句／長句兩張畫面截圖。

  • Visual foundations 頁面存在，且包含 3 個色彩角色。
  • 4 個文字樣式的尺寸與用途對得上案例文字。
  • 起始短句與壓力句都能閱讀；長句沒有壓住按鈕。
  • 截圖與 Figma 檔放在同一個課程資料夾。

檢核題 1：為什麼要命名 color-accent，不直接命名「黃色」？

答案方向：名稱記錄用途；日後調整主色時，可以一起找到所有強調元素。

檢核題 2：長錯誤訊息通過文字樣式檢查，但按鈕被推到畫面外，你先查哪三個位置？

答案方向：文字框寬度、行高／高度模式、容器與按鈕的層級與間距。
07 · 卡住時的修復

從畫面現象找到規則位置

現象先查哪裡重跑起點
色票只有「米色」「深灰」等名稱色票／Fill 的用途命名。回「03 · 示範」的建立色彩色票步驟，改成 color-bg 等角色名，再檢查使用處。
四段文字看起來大小相同文字層是否套用 Text style，而非只改單次尺寸。回「03 · 示範」的文字樣式步驟，先確認四個樣式出現在清單。
長錯誤訊息被裁切或壓住按鈕文字框寬度、行高與容器高度。回「03 · 示範」的長文字檢查步驟，用短句與長句各跑一次並保存截圖。

三種現象都要記在完成檢查表；文字描述不能取代畫面證據。
