(A3) · 6 小時

用 Auto Layout 撐住長文字與內容變化

把內容壓力轉成可觀察的寬度、高度、層級與修復判準。

學習成果
固定文字寬度 200，讓長中文換行。
使用 Auto height 讓容器隨內容增高。
區分已驗證的文字壓力與尚未測的 Form／List 行為。
(01)

先讓內容負責版面

阿凱的登入錯誤訊息在短句時整齊，換成較長的客服文字後卻被裁掉。本節不是把字縮小，而是建立一個能在內容變化時保留可讀性的手機區塊。

壓力句：密碼至少需要包含一個英文大寫字母與一個數字。
(02)

三個概念

固定寬度控制行寬；Auto height／Hug讓容器隨換行增高；內容壓力測試先換文字，再觀察容器、按鈕與相鄰元件是否被推開。

(03)

Stage A3-1：完整示範

  1. 建立手機 Frame 與登入區塊，選取文字層。
  2. 將文字寬度設為 200，使用右側 Content 輸入長中文。
  3. 將高度設為 Auto／Hug，觀察換行與容器高度。
  4. 把錯誤輔助文字放在輸入區塊下方，確認它是子層。
  5. 記錄原始短句、壓力文字、尺寸與修復結果。
(04)

同步演練與 Checkpoint

步驟模式期待結果
1Together有可選取的文字與容器。
2Demo固定寬度 200，長句換行。
3Checkpoint高度增加，文字完整可讀。
4Solo只替換另一句長文字，仍能重排。
5Check留下尺寸與截圖證據。
直接在畫布輸入可能造成誤選或文字串接；先在 Layers 選文字層，再用右側 Content。
(05)

變化練習與邊界

把錯誤文字換成更長的版本，只改文字；若裁切，先回到寬度／高度設定。不要把整張手機 Frame 放大，也不要把多列 List 增刪當成已驗證。

  • 已驗證：長中文、Auto height、右側 Content 修復。
  • 待測：Form 多欄位、List 多列增刪、完整手機流程。
(06)

交付檢查

  • 短句與長句都在 200 寬度內完整顯示。
  • Auto height 隨換行增加，不裁切文字。
  • 錯誤輔助文字仍是輸入區塊子層。
  • 我沒有用縮小字級掩蓋內容壓力。
  • 我知道 Form／List 仍要另跑測試。

起始材料：A3 起始頁。機器摘要：Probe A 摘要。完成後，手機 Frame 可交給 B1／B4 作為輸入。
