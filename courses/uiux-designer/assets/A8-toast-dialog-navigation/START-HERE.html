Toast、Dialog 與 Navigation：起始材料

你會接手 A7 的清單畫面，建立短暫回饋、需要決定的內容容器與頁面導覽文字。這頁固定尺寸、命名和未測行為；操作順序請回到 A8 學習頁。

開始前準備

先開啟 A7 的 Figma 檔，確認 Row、Title 與 Empty Message 仍在同一個 Frame。缺少 A7 來源時，先回 A7 重建；不要把沒有來源的畫面當成已交接成果。

固定設定

項目設定
ToastToast / Success，260×48 px，文字「已儲存」。
DialogDialog / Confirm，260×150 px，標題「刪除這筆資料？」與「取消／確認」。
NavigationNavigation / Header，文字「首頁　清單　設定」，放在畫面上方。

你要留下的成果

  1. Toast、Dialog、Navigation 的 Layers 與尺寸截圖。
  2. Dialog 長標題變因的行數、容器高度與修正紀錄。
  3. 三種元素的文字責任表。
  4. 填入A8 完成檢查表，標註出現時機、Overlay、關閉、置頂與 Prototype 尚未測試。
範圍提示

本堂驗收視覺層級、尺寸與命名。自動出現、Overlay、關閉、置頂、滾動與 Prototype 連結要在 Part B 實際操作後才能判定。

資料準備好後回到Toast、Dialog 與 Navigation 學習頁，依示範完成三種畫面材料。
