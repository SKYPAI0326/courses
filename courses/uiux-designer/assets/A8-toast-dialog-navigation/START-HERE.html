設計能讓人知道下一步的回饋、彈窗與導覽：起始材料

本頁提供本堂所需的輸入材料，操作步驟請見講義；請在自己的設計檔中完成，本堂沒有提供預先建立的 Figma 檔案。

本堂完成物是可切換 Success、Warning、Error 的 Toast 元件集、一個 Overlay / Confirm 確認完成彈窗，以及有 Top Bar 返回與 Nav / Bottom 導覽的手機畫面。Screen / List Done、Screen / Detail Warning 與 Screen / Detail Error 皆為 402 × 874；原型階段再連接實際開關與換頁互動。

課前準備與操作速查提供第一次登入、建立設計檔、選圖層及保存方式。本堂沿用前堂完成物；缺少時請依講義的重建路徑補齊。

本堂會使用的規格／資料

元素規格應出現的內容
ToastType=Success／Warning／Error；Message 預設「已完成」且可改；Horizontal、W 354（Fixed）、Fill Card、Control Border 1 px、圓角 8、Gap 8、水平內距 16、垂直內距 12、Hug 高Success「任務已完成，已移到完成清單」；Warning「尚有檔名未核對，請確認後再完成」；Error「無法儲存變更，請檢查網路後再試一次」
Overlay / Confirm寬 320、Gap 16、四邊內距 24、Hug 高、圓角 8標題「確認完成？」、說明「這筆任務將移到已完成清單。」、取消與確認完成
Nav / BottomHorizontal；待處理與已完成各寬 201、高 64，合計寬 402、Gap 0、y 810、Fill Card目前頁同時使用文字色與底線標示，另一個目的地仍可辨認
Top Barx 24、W 354（Fixed）、Horizontal、Hug 高；Button / Back 為 44 × 44，內含 24 × 24 返回圖示標題「任務詳情」，返回按鈕提供返回清單的觸控範圍

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG是示意圖，匯入後不含Auto Layout、主元件或Prototype連線；這些設定請依講義建立。

任務資料 TASK-DATA.csv：十二筆示範任務，用來建立清單、測試長標題與捲動。缺網路時可直接複製講義表格內容。
