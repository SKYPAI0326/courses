第 08 堂 · 起始材料頁

Toast、Dialog 與 Navigation

你會接手第 07 堂的清單畫面，建立短暫回饋、需要決定的內容容器，以及顯示目前位置的導覽文字。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。完成回饋、刪除確認與頁面位置混在一起，後續 Prototype 無法分辨責任。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 07 堂的 Row、Title、Empty Message 與清單 Frame。
第一個動作在清單 Frame 上方建立 Navigation / Header；Layers 應能讀取導覽層。
第一個可觀察結果導覽、短暫回饋與確認容器各自可找到，文字責任不混在一起。
本堂完成物Toast、Dialog、Navigation 視覺層、尺寸／文字責任表與未測邊界。
下一位使用者／用途第 09 堂會將可辨識的介面材料轉成任務卡、畫面清單與手機流程。
失敗時怎麼回復分開回到導覽、Toast、Dialog 三個層級；自動出現、Overlay、關閉與置頂不在本堂假設完成。
