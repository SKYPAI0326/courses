練習素材

練習用圖示包

這個資料夾有 16 個線條圖示，大小都是 24×24，線條粗細 2。做按鈕、清單卡片、提示訊息和底部導覽時可以直接用。

下載全部圖示（icons.zip）

怎麼放進 Figma

  1. 點上方「下載全部圖示（icons.zip）」，再解壓縮：Mac 直接雙擊 zip；Windows 按右鍵選「解壓縮全部」。解壓後會得到一個 icons 資料夾，裡面有 16 個 SVG 檔。只要一兩個圖示時，也可以點下方各圖示的「下載」單獨存檔。
  2. 把 SVG 檔從解壓後的資料夾拖進 Figma 畫布，就會變成可改顏色的向量。
  3. 選取圖示裡的線條，在右側面板的 Stroke 改顏色；放大縮小時線條不會糊掉。
