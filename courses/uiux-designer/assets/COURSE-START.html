課前準備與操作速查

你會在同一份Figma設計檔建立工作室待處理清單，最後完成交付包與對應的靜態網站。課程不要求設計、程式或Git經驗；需要能開瀏覽器、輸入文字、找到下載檔案。

第一次建立設計檔

  1. 開啟Figma並登入自己的帳號。在首頁進入Drafts／草稿，建立New design file。不要選FigJam、Slides或Make。
  2. 將檔名改為「工作室任務清單－姓名」。看到左側Layers、中央畫布及右側Design後，開始第一個Frame。
  3. 按F後在畫布拖出畫板，在右側W與H填402、874；於Layers雙擊名稱改為 Screen / Login。
  4. 按T點在Frame內輸入文字，按Esc結束編輯。從Layers選文字層應看到文字屬性；選Frame應看到尺寸。找不到設定時先確認選到的層。
  5. 拖曳畫布可按住Space；使用縮放控制放大縮小；按Undo（Mac Cmd+Z／Windows Ctrl+Z）回復上一個操作。

圖層與常用設定

父層是包住內容的容器，子層是容器裡的物件；在Layers中子層會縮排。Frame可包含文字、形狀與其他Frame，Rectangle是形狀。Shift+A會對選取物件新增Auto Layout。右側Design改外觀；Prototype設定點選、轉場與滾動；Present／播放入口才是實際預覽。

儲存與復原

Figma有自動儲存，關閉前等同步完成。每堂完成時在檔案選單儲存本機副本（Save local copy，.fig），另保留自己的檔案連結。若沒網路，先保留現有編輯視窗與本機副本，不靠未同步截圖當成已存檔。後續在自己的課程資料夾使用 01-rules、02-layout、03-prototype、04-handoff、05-web 分開儲存成果。

本課SVG是可下載的視覺示意；CSV是示範任務資料，皆由課程製作。SVG匯入Figma後不含Auto Layout／Component／連線；依講義建立設定才能學會這些能力。缺前課檔案時從該堂重建步驟補齊，不能假設有教師提供的Starter檔。

免費方案與原型範圍

Starter可以在同一份檔案設定多個基本互動；本課使用不同按鈕各執行一個動作，把登入、清單、詳情及Overlay串起來。同一個觸發事件堆疊多個動作與條件邏輯屬付費功能，本課不用。Starter沒有Dev Mode；第15堂改用Design面板讀取尺寸、色碼及Export。

原型使用示範帳號文字，不驗證真實密碼、不接資料庫；頁面狀態以不同Frame表現。這個範圍能驗收UI與流程，不能宣稱已完成正式登入系統。
