課前準備與操作速查

你會在同一份Figma設計檔跟著講義做「工作室待處理清單」，同時在預約、點餐、會員三個題目中選一題，每堂把剛學的方法用在自己的題目上，最後交出整合作品、交付包與公開網站。課程不要求設計、程式或Git經驗；你需要能開啟瀏覽器、輸入文字，以及找到下載的檔案。

工具何時使用

工具先準備什麼何時用
Figma Design個人帳號、Starter方案，以及自己的可編輯設計檔；使用桌面瀏覽器或桌面版設計與原型的每一堂；Starter方案就夠用
Photoshop桌面版依Photoshop桌面版準備與啟動取得軟體授權或教室使用資訊，確認本課三層PSD檔能開啟整理交付包那一堂；沒有軟體時先完成Figma部分，取得電腦後再補做Photoshop
VS Code、瀏覽器、Git先從VS Code官方下載選擇適合自己作業系統的macOS或Windows版本並完成安裝。首次啟動看到Welcome後，選File → Open Folder能開啟資料夾才算準備完成；Git依下方「做網站前的準備」安裝做網站那一堂

第一次建立設計檔

  1. 開啟Figma並登入自己的帳號。在檔案首頁進入Drafts（草稿），點右上角那排按鈕中的Design。不要選FigJam、Slides、Sites、Buzz或Make。Starter方案只能同時編輯3個檔案，所以本課所有作品（含流程圖與作品集頁）都放在這一個檔案的同一頁。
  2. 點左上角檔名，改為「工作室任務清單－姓名」。左側若先出現對話面板，點最左邊圖示列的File，就會看到Pages與Layers；中央是畫布，右側是Design與Prototype設定面板。
  3. 先按Shift+S拖出一個約3000×2000的Section（區段），雙擊名稱改為「主線」；之後的手機與桌面畫面都放在裡面。
  4. 按F在Section內拖出畫板，在右側Layout區的W與H填入402、874，Position區的X、Y都填0（放在Section左上角）；於Layers雙擊名稱改為 Screen / Login。
  5. 按T點在Frame內輸入文字，按Esc結束編輯。從Layers選取文字層應看到文字屬性；選取Frame應看到尺寸。找不到設定時先確認選到的圖層。
  6. 拖曳畫布可按住Space；使用縮放控制放大縮小；按Undo（Mac Cmd+Z／Windows Ctrl+Z）回復上一個操作。

圖層與常用設定

父層是包住內容的容器，子層是容器裡的物件；在Layers中子層會縮排。Frame可包含文字、形狀與其他Frame，Rectangle是形狀。Shift+A會對選取物件新增Auto Layout。在右側Design面板可修改外觀；Prototype設定點選、轉場與滾動；按Shift+Space開啟Preview，才是實際預覽。

儲存與復原

Figma會自動儲存。每堂課完成時，從左上Main menu → File → Save local copy儲存本機副本（.fig），另保留自己的檔案連結。若沒有網路，先保留現有編輯視窗，連線恢復後再存本機副本。後續在自己的課程資料夾使用 01-rules、02-layout、03-prototype、04-handoff、05-web 分開儲存成果。

本課SVG是可下載的視覺示意；CSV是示範任務資料，皆由課程製作。SVG匯入Figma後不含Auto Layout／Component／連線；必須依講義建立設定才能學會這些能力。缺少上一堂的成果時，打開上一堂講義的「本堂規格表」照表補做，通常20～30分鐘可以補完。

免費方案與原型範圍

Starter可以在同一份檔案設定多個基本互動；本課使用不同按鈕各執行一個動作，把登入、清單、詳情及Overlay串起來。在同一個觸發事件堆疊多個動作與條件邏輯屬於付費功能，本課不用。Starter沒有Dev Mode，變數也只能有1個模式；量尺寸改用Design面板，給工程師的說明用自己做的標註元件。

原型使用示範帳號文字，不驗證真實密碼、不接資料庫；頁面狀態以不同Frame表現。這個範圍用來驗收介面與流程，正式登入系統屬於工程階段。

做網站前的準備（上課前完成）

做網站那一堂要用Git記錄版本、用GitHub發布網站。下面四件事在家裡就能做，每件大約10～20分鐘；先做完，上課時就能直接開始做網站。

  1. 安裝Git（Windows）：到git-scm.com下載Git for Windows，安裝時一路用預設選項。裝好後重開VS Code，選Terminal → New Terminal，輸入 git --version，看到 git version 開頭的一行就成功了。
  2. 安裝Git（Mac）：打開VS Code，選Terminal → New Terminal，輸入 git --version。沒裝過會跳出安裝開發者工具的視窗，按安裝（也可以輸入 xcode-select --install）。裝完重開終端機再輸入一次，看到版本號就完成了。
  3. 註冊GitHub並驗證Email：到github.com註冊帳號，打開信箱點驗證連結。沒有驗證的帳號可能無法發布網站。
  4. 取得提交用的Email：登入GitHub，右上頭像 → Settings → Emails，勾選「Keep my email addresses private」。畫面會出現一個以 noreply.github.com 結尾的地址，把它記下來，做網站時設定Git會用到。

四件事都做完，就可以在做網站那一堂直接下載網站專案。
