把設計做成網站，留下版本與公開網址：起始材料

本頁整理本堂要下載的網站專案與規格表，操作步驟請見講義。請在自己的電腦上用 VS Code、Git 與 GitHub 完成，不需要開 Figma。

把已整理好的工作室介面交付包轉成能操作的網站，讓接手者從公開網址查看成果，也能從版本紀錄理解每次修改。本堂完成物是一個本機能操作且會因手機寬度重新排列的網站、一段看得出修改順序的版本紀錄，以及一個完成更新確認的公開網址。

本堂會使用上一堂交付包裡的主要色、按鈕規格、透明 PNG 徽章與畫面操作流程。

網站狀態登入、詳情、取消、確認與已完成清單確認只改變當次頁面記憶體；重新整理恢復預設資料

下載網站專案 studio-tasks-web.zip：完整專案含 index.html、styles.css、app.js、README.md、my-screen.html 與 assets 資料夾；解壓後先用瀏覽器走過登入、詳情、取消、確認與已完成清單，再用 VS Code 開啟。網站任務資料寫在 app.js，不會直接讀取 CSV。

完整網站參考：先看做完的樣子；修改請在自己解壓的資料夾進行。

「換你做」要把網站資料換成你題目的資料：預約 BOOKING-DATA.csv、點餐 ORDER-DATA.csv、會員 MEMBER-DATA.csv。
