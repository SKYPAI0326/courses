第 03 堂 · 起始材料頁

Auto Layout 與內容壓力

短文字放得下，不代表畫面能承受真實內容。這堂課用登入錯誤訊息測試固定寬度、換行與容器增高。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。客服把錯誤訊息改長後，文字被裁切，雯姊無法確認表單狀態。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料本頁的短句、壓力句、402×874 Frame 與固定寬度／Auto height 條件。
第一個動作在 Figma 建立 402×874 Frame 與登入區塊；放入壓力句後，文字應換行且容器增高。
第一個可觀察結果按鈕仍留在畫面內，長句沒有被裁切。
本堂完成物能承受長文字的手機登入區塊、短／長句截圖與修正紀錄。
下一位使用者／用途第 04 堂會把穩定的登入區塊抽成主元件。
失敗時怎麼回復回到文字寬度、Auto height／Hug 與父層 Auto Layout，保留短句與長句重新比較。

測試材料

狀態文字用來觀察
短句請輸入密碼初始寬度與位置
壓力句密碼至少需要包含一個英文大寫字母與一個數字換行、Auto height、按鈕是否被推開

通過條件

  1. 兩段文字都能全部讀到。
  2. 文字寬度為 200 px，容器使用 Auto height／Hug。
  3. 錯誤文字仍在登入區塊子層，沒有跑到畫布外。
  4. 保存短句／長句前後截圖與一個修正點。
面板名稱可能不同

若你的 Figma 面板名稱不同，先找 Width、Height、Auto height／Hug 與 Layers；通過條件仍以本頁的可觀察結果為準。
