讓文字變長時，容器與按鈕一起排好：起始材料

本頁提供本堂所需的輸入材料，詳細操作步驟請見講義；各項操作請在自己的設計檔中完成，本堂沒有提供預先建立的 Figma 檔案。

當登入提示文字變長時，下方按鈕也要跟著移動。本堂完成物是一張使用間距變數且能隨內容增高的 Login / Card、一份不改動正式元件的寬度上下限測試紀錄，以及一排空間不足時會自動換行的任務標籤。正式卡片位於 x 24、y 120，寬 354；窄版測試副本 Login / Card 360 寬 312。

課前準備與操作速查提供第一次登入、建立設計檔、選取圖層及保存檔案的方法。本堂需沿用前一堂的完成檔案；若缺少該檔案，請依講義說明的重建路徑補齊。

本堂會使用的規格／資料

設定設在哪裡本例效果
Vertical 垂直排列父 Auto Layout Frame子層由上到下排列
Padding 內距Login / Card 的水平與垂直 Padding套用 Space 16，四邊內距皆為 16
Gap 間距Login / Card 的相鄰子層套用 Space 12，相鄰子層之間留 12
Fixed 固定尺寸Screen / Login 寬 402、Login / Card 寬 354、Button / Draft 寬 322正式畫面、卡片與按鈕維持指定寬度
Hug contents 包住內容卡片高度文字高度增加後，卡片高度跟著增加
Fill container 填滿容器正式卡片的 Message、Hint；窄版副本的按鈕暫時套用正式文字使用卡片扣除內距後的 322；窄版副本隨可用寬度縮放
Auto height 自動高度Message 與 Hint 的文字尺寸模式行數增加時文字框自動變高

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG 為靜態示意圖，匯入後不含 Auto Layout、主元件或 Prototype 連線；這些設定請依照講義步驟建立。

任務資料 TASK-DATA.csv：十二筆示範任務，用來建立清單、測試長標題與捲動。若缺少網路連線，可直接複製講義中的表格內容。
