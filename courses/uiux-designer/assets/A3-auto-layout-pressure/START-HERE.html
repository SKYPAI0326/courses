讓文字變長時，容器與按鈕一起排好：起始材料

這頁提供本堂輸入，操作步驟在講義；請在自己的課程檔完成，沒有預先建立或需要教師轉交的Figma檔。

登入提示一變長，按鈕就被擋住。本堂會真正建立 Auto Layout 容器：讓文字換行、容器增高、按鈕往下移。你還會增刪子層及改畫面寬度，確認版面能跟著內容調整。

課前準備與操作速查提供第一次登入、建立設計檔、選圖層及保存方式。沿用前堂完成物；缺少時依講義的重建路徑補齊。

本堂會使用的規格／資料

設定設在哪裡本例效果
Vertical 垂直排列父 Auto Layout Frame子層由上到下排列
Padding 內距父容器邊界到內容留16
Gap 間距父容器文字與按鈕之間留12
Fixed 固定尺寸402手機Frame、354卡片寬度明確控制畫面或容器寬
Hug contents 包住內容卡片高度文字變高後，卡片變高
Fill container 填滿容器卡片內文字與按鈕寬度使用父容器扣除內距的322
Auto height 自動高度文字層的文字尺寸模式行數增加時文字框變高

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG是示意圖，匯入後不含Auto Layout、主元件或Prototype連線；這些設定依講義建立。

任務資料 TASK-DATA.csv：三筆示範任務，用來建立清單與測試長標題。缺網路時可直接複製講義表格內容。
