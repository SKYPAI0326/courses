讓文字變長時，容器與按鈕一起排好：起始材料

這頁提供本堂所需輸入材料，詳細操作步驟請見操作講義；各項操作請在自己的課程設計檔中完成，課程沒有提供預先建立或需要教師轉交的 Figma 檔案。

當登入提示文字變長時，下方的按鈕會被遮擋。本堂將實際建立 Auto Layout 容器：讓文字自動換行、容器隨內容增高、按鈕順勢下移。你也會透過增刪子圖層與調整畫面寬度，驗證版面能隨內容正常調整。

課前準備與操作速查提供第一次登入、建立設計檔、選取圖層及保存檔案的方法。本堂需沿用前一堂的完成檔案；若缺少該檔案，請依講義說明的重建路徑補齊。

本堂會使用的規格／資料

設定設在哪裡本例效果
Vertical 垂直排列父 Auto Layout Frame子層由上到下排列
Padding 內距父容器邊界到內容留 16
Gap 間距父容器文字與按鈕之間留 12
Fixed 固定尺寸402 手機 Frame、354 卡片寬度明確控制畫面或容器寬度
Hug contents 包住內容卡片高度文字高度增加後，卡片高度跟著增加
Fill container 填滿容器卡片內文字與按鈕寬度使用父容器扣除內距後的 322
Auto height 自動高度文字層的文字尺寸模式行數增加時文字框自動變高

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG 為靜態示意圖，匯入後不含 Auto Layout、主元件或 Prototype 連線；這些設定請依照講義步驟建立。

任務資料 TASK-DATA.csv：內含三筆示範任務，用來建立清單與測試長標題。若缺少網路連線，可直接複製講義中的表格內容。
