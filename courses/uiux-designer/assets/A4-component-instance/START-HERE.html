主元件與 Instance｜起始材料

本頁把 上一堂的登入區塊整理成可重用的主元件，並從 Assets 插入一個 Instance。完成後，下一堂會在這個主元件上加入 Variants 與狀態屬性。

驗證狀態：Component／Instance 已在 Figma Starter／Chrome 實測；本單元仍需真人冷讀與跨帳號重跑。

開啟 Codex Figma Starter Audit｜Probe A

路徑二：自行建立最小起始畫面

  1. 新增一個 Figma Design file。
  2. 建立 Frame，寬 402、高 874，命名 Mobile / Login & List。
  3. 在 Frame 內建立一個垂直 Auto Layout 容器，加入文字 登入。
  4. 確認 Layers 中能選到這個容器；本堂會對容器建立主元件。

  • 主元件：Login / Heading
  • Instance：Instance / Login heading
