第 04 堂 · 起始材料頁

主元件與 Instance

你會把上一堂的登入區塊整理成可重用的主元件，再插入一個 Instance。這份材料讓你知道要選哪個容器、使用哪些名稱，以及沒有編輯權時如何重建。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。重複畫面各自修改，文字與間距逐漸分叉，下一堂找不到共用來源。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 03 堂的手機登入區塊；沒有編輯權時依本頁重建最小畫面。
第一個動作開啟可編輯檔並選取整個登入容器；Assets 應出現主元件。
第一個可觀察結果畫面同時有可辨識的主元件與 Instance，來源關係可追蹤。
