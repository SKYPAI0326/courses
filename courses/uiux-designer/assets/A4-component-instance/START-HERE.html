改一次來源，讓多個按鈕一起更新：起始材料

這頁提供本堂輸入，操作步驟在講義；請在自己的課程檔完成，沒有預先建立或需要教師轉交的Figma檔。

登入、詳情與彈窗都需要相同的按鈕。複製一般Frame只會得到幾個互不相干的物件；本堂建立主元件與兩個Instance，實際驗證共同外觀更新與各自文字覆寫。

課前準備與操作速查提供第一次登入、建立設計檔、選圖層及保存方式。沿用前堂完成物；缺少時依講義的重建路徑補齊。

本堂會使用的規格／資料

物件做什麼檢查線索
主元件 Button / Base儲存共同結構：Label、內距、對齊與填色紫色主元件標記、Assets中可找到
Button / Login Instance登入畫面使用同一套按鈕右側可回到Main component
Button / Complete Instance詳情畫面使用，文字改為標記完成改Label只影響本Instance
一般複製Frame不保留元件來源關係修改原Frame後副本不會跟著變

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG是示意圖，匯入後不含Auto Layout、主元件或Prototype連線；這些設定依講義建立。

任務資料 TASK-DATA.csv：三筆示範任務，用來建立清單與測試長標題。缺網路時可直接複製講義表格內容。
