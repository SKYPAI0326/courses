改一次來源，讓多個按鈕一起更新：起始材料

本頁提供本堂所需的材料與輸入項目，操作步驟請見講義；所有操作請在自己的設計檔中完成，本堂沒有提供預先建立的 Figma 檔案。

登入、詳情與確認畫面都需要共用按鈕。本堂會建立 Components 元件區、Button / Primary 主元件與 Button / Login 使用處，並在 Test Section 以 Test / Complete、Test / Cancel 驗證同步與文字覆寫，測試完成後刪除 Test。完成物另包含 Icon / Check、Plus、Arrow Left、Clock、Alert、Chevron Right 六個可交換的巢狀圖示來源。

課程總目錄提供第一次登入、建立設計檔、選取圖層及保存方式說明。本堂操作沿用前堂完成物；若缺少前堂檔案，請依講義說明的重建路徑補齊。

本堂會使用的規格／資料

物件做什麼檢查線索
主元件 Button / Primary儲存共同結構：高 48、水平內距 16、垂直內距 12、圓角 8、Label、對齊與填色位於 Components，具備紫色主元件標記，可在 Assets 找到
Button / Login 使用處放在登入畫面，Label 為「登入工作室」，寬度 Fill container可回到 Button / Primary，修改 Label 只影響目前使用處
Test / Complete 測試使用處放在 Test Section，Label 為「標記完成」，寬度 Hug contents主元件圓角變更時同步，Label 保留自己的文字；測試結束後隨 Test 刪除
Test / Cancel 測試使用處由 Test / Complete 複製，Label 為「取消」，寬度 Hug contents三個使用處連到同一來源，共同外觀一起更新；測試結束後隨 Test 刪除

畫面視覺參考（SVG）：請先比對內容與閱讀順序。SVG僅為視覺示意圖，匯入後不含Auto Layout、主元件或Prototype連線；上述設定請依講義步驟建立。

任務資料 TASK-DATA.csv：十二筆示範任務，用來建立清單、測試長標題與捲動。若缺少網路連線，可直接複製講義內的表格內容。
