連好登入、清單、詳情與返回：起始材料

這頁提供本堂輸入，操作步驟在講義；請在自己的課程檔完成，沒有預先建立或需要教師轉交的Figma檔。

現在讓畫面能點。你會在同一份Starter檔案，分別為登入Button、任務Row與返回Button建立基本互動，從Login一路到Detail再返回。每個互動先確認選對物件、觸發與目的地，再開啟Preview真點一次。

課前準備與操作速查提供第一次登入、建立設計檔、選圖層及保存方式。沿用前堂完成物；缺少時依講義的重建路徑補齊。

本堂會使用的規格／資料

點選物件TriggerActionDestination預期
Login的 Button / LoginOn clickNavigate toScreen / List看見三筆待處理任務
List的 Row / T01On clickNavigate toScreen / Detail看見T01內容
Detail的「返回清單」物件On clickNavigate toScreen / List回到任務清單

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG是示意圖，匯入後不含Auto Layout、主元件或Prototype連線；這些設定依講義建立。

任務資料 TASK-DATA.csv：三筆示範任務，用來建立清單與測試長標題。缺網路時可直接複製講義表格內容。
