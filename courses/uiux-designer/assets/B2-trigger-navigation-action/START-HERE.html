第 10 堂 · 起始材料頁

觸發事件與互動連結

第 09 堂留下 Login 與 List 兩個手機 Frame。這堂課只建立一條「點擊登入 → 到達清單」的核心連結，讓每個結果都能回到觸發與目的地。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。Login 有按鈕卻沒有到達 List，使用者無法完成登入後查看清單。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 09 堂的 Login／List Frame、起始點與本頁驗收卡。
第一個動作建立獨立測試檔並放入兩個有辨識文字的 Frame；Interaction row 應出現。
第一個可觀察結果在 Chrome Preview 點擊 Login 後能到達 List。
本堂完成物一個 On click → Navigate to → Flow / List、Preview 截圖、Actual／Expected 與 Solo 版本。
下一位使用者／用途第 11 堂會沿用同一條 action 選擇轉場。

操作順序

  1. 建立獨立測試檔，放入兩個有標題與內容的 Frame。
  2. 在 Flow / Login 選取 Button / Login。
  3. Prototype → Add action → On click → Navigate to → Flow / List。
  4. 保留 Instant，從 Login 起始點開 Preview。
  5. 點擊一次，將 Actual／Expected 與三類截圖填入檢查表。
Starter 方案邊界

若第二次新增 action 出現方案提示，截圖並記錄；保留第一條 action，另開測試檔處理其他互動，不按 Upgrade。
