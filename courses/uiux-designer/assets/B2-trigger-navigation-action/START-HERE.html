連好登入、清單、詳情與返回：起始材料

本頁提供本堂課所需的輸入材料，具體操作步驟請參閱講義；所有操作請在您自己的課程檔案中完成，本課程並未預先建立、也不需要教師轉交 Figma 檔案。

現在要讓畫面具備點擊互動功能。您將在同一份 Starter 檔案中，分別為登入 Button、任務 Row 與返回 Button 建立基本互動，完成從 Login 一路前往 Detail 再返回的流程。建立每個互動時，請先確認選取了正確的物件、觸發條件與目的地，接著開啟 Preview 實際點擊測試一次。

課前準備與操作速查提供第一次登入、建立設計檔、選取圖層及保存方式的說明。本堂課請沿用前一堂課的完成成果；若缺少該成果，請依講義說明的重建路徑補齊。
