B2 起始材料：讓一次點擊到達正確畫面

B1 已留下 Login 與 List 兩個手機 Frame。本堂把 Login 的主要按鈕接到 List，並用 Chrome Preview 讀取實際結果。測試檔只保留一條核心 action。

工作情境

按鈕存在，流程仍然沒有走動

使用者在登入畫面按下「登入」，畫面卻沒有前進。你要為這次測試指定 Trigger、Action、Destination，並寫出點擊前後能觀察的結果。

欄位請填入

Figma 操作規格

  1. 建立獨立 B2 測試檔，放入兩個有標題與內容的 Frame。
  2. 在 Flow / Login 選取或建立 Button / Login。
  3. Prototype → Add action → On click → Navigate to → Flow / List。
  4. 保留 Instant，先只回答是否到達正確目的地。
  5. 從指定起始點開啟 Preview，點擊一次並把 Actual／Expected 寫入檢查表。
方案邊界：若第二次新增 action 出現 Starter 方案提示，截圖並記錄。保留第一條 action，另開測試檔處理其他核心互動；不以提示訊息代替通過結果。
