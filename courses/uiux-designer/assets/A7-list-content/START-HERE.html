List 與內容變化：起始材料

你會接手 A6 的 Screen / List Top Frame，在清單區域建立兩列、長標題與空狀態提示。這頁固定尺寸、命名與邊界；操作順序請回到 A7 學習頁。

開始前準備

先開啟 A6 的 Figma 檔，確認 Button／Form 圖層仍在同一個 Frame。缺少 A6 來源時，先回 A6 重建；不要把沒有來源的畫面當成已交接成果。

固定設定

項目設定
Row 01List / Item / Row 01，300×40 px 矩形。
Row 02List / Item / Row 02，由 Row 01 複製。
長標題List / Item / Title，Fixed width 180、Auto height。
空狀態List / Empty / Message，文字「目前沒有清單項目」。

你要留下的成果

  1. 兩個 Row 的 Layers 與尺寸截圖。
  2. 長標題換行前後的 Width／Height 與修正紀錄。
  3. 空狀態提示的 Layers 與文字截圖。
  4. 填入A7 完成檢查表，標註動態增刪、資料切換與多列聯合滾動尚未測試。
範圍提示

本堂驗收視覺列、內容壓力與空狀態圖層。真正的資料增刪、狀態切換與 Prototype 行為要在後續測試階段留下操作證據。

資料準備好後回到List 與內容變化學習頁，依示範完成三種畫面材料。
