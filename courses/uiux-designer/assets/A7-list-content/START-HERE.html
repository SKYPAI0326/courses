第 07 堂 · 起始材料頁

List 與內容變化

你會接手第 06 堂的列表 Frame，建立兩列內容、長標題與空狀態提示，讓下一堂能清楚處理回饋與導覽。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。清單可能有資料、長標題或空狀態；層級不清楚時，使用者與接手者都無法判讀。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 06 堂的 Screen / List Top、Button／Form 圖層、Row 尺寸、長標題與空狀態文字。
第一個動作在 Screen / List Top 建立 Row 01；Layers 應能找到第一列。
第一個可觀察結果兩列、長標題與空狀態文字各自有可辨識的容器。
本堂完成物Row 01／02、固定寬度與 Auto height 的 Title、Empty Message 與內容壓力紀錄。
下一位使用者／用途第 08 堂會用這些狀態建立 Toast、Dialog、Navigation 的視覺材料。
失敗時怎麼回復回到 Row 容器與 Title 寬高；動態增刪與多列滾動保持未測狀態。

固定設定

項目設定
Row 01List / Item / Row 01 · 300×40 px
Row 02List / Item / Row 02 · 由 Row 01 複製
長標題List / Item / Title · Fixed width 180、Auto height
空狀態List / Empty / Message · 目前沒有清單項目

要留下的成果

  1. 兩個 Row 的 Layers 與尺寸截圖。
  2. 長標題換行前後的 Width／Height 與修正紀錄。
  3. 空狀態提示的 Layers 與文字截圖。
  4. 檢查表標註動態增刪、資料切換與多列聯合滾動尚未測試。
