Button 與 Form：起始材料

你會接手 A5 的狀態欄位，建立一個有 Primary／Disabled Value 的 Button component set，再用 Label、Input、Helper 圖層組成表單區塊。這頁列出尺寸、命名和未測試邊界；操作順序請回到 A6 學習頁。

開始前準備

先開啟 A5 的 Figma 檔，在同一個檔案找到 Screen / List Top Frame、A5 的狀態來源與完成檢查表。缺少 A5 來源時，先回 A5 重建；不要在 A6 另建一個無來源的測試檔。

固定設定

項目設定
ButtonButton / Primary，320×48 px，建立 component。
Button ValuePrimary、Disabled，使用 Figma 的 Property 欄。
Form LabelForm / Email / Label，文字「電子郵件」。
Form InputForm / Email / Input，320×48 px 視覺容器。
Form HelperForm / Email / Helper，文字「請輸入有效的電子郵件」。

你要留下的成果

  1. Button component set 的兩個 Value 截圖。
  2. Label、Input、Helper 三個 Form 圖層與相對位置。
  3. Helper 長句的變因練習與修正紀錄。
  4. 填入A6 完成檢查表，註明輸入互動、多欄位與真實錯誤流程尚未測試。
範圍提示

本堂驗收的是視覺元件與 Layers 結構。按鈕點擊、欄位輸入、驗證規則與多欄位資料流要等後續 Prototype／測試階段，不能用畫面名稱代替互動證據。

資料準備好後回到Button 與 Form 學習頁，依示範完成狀態與圖層結構。
