完成表單與錯誤修正：起始材料

本頁提供本堂所需的輸入材料，具體操作步驟請見講義；請在自己的設計檔中完成，本堂沒有提供預先建立的 Figma 檔案。

本堂完成物是含文字屬性的四狀態 Field 元件、一張 Screen / New Task 新增任務表單，以及符合共用規格的 Checkbox、Radio、Toggle、Select 與 Field / Multiline 五種表單控制項。Screen / Login 與 Screen / New Task 起始皆為 402 × 874；Login / Card 位於 x 24、y 120、寬 354，Field / Account 與 Field / Password 寬 322。

課程總目錄提供第一次登入、建立設計檔、選取圖層及保存方式。請沿用前一堂課的完成物；若有所缺少，請依講義說明的重建路徑補齊。
