第 06 堂 · 起始材料頁

Button 與 Form

你會沿用第 05 堂的狀態欄位，建立按鈕的 Primary／Disabled 視覺狀態，再用 Label、Input、Helper 組成可檢查的表單區塊。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。按鈕、欄位與提醒文字沒有清楚責任，下一位工作者無法判斷狀態來源。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 05 堂的狀態來源、Screen / List Top Frame、Button／Form 固定尺寸與命名。
第一個動作在外層 Frame 建立 320×48 Button；畫面應出現可命名的 Button 容器。
第一個可觀察結果Button 與 Form 圖層能被分開找到，Primary／Disabled 的責任可讀。
本堂完成物Button component set、Primary／Disabled、Label／Input／Helper 三層與未測邊界紀錄。
下一位使用者／用途第 07 堂會使用命名與狀態規則整理列表內容。
失敗時怎麼回復回到外層 Frame 與 component set，區分視覺層與尚未測試的互動。
