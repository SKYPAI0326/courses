Overlay 與 Swap

這堂課先完成一條可預覽的「點擊 → 打開 Overlay」互動，再把 Swap 當成獨立變化記錄。免費方案遇到第二條 action 時，安全停止並拆檔。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。按下完成後沒有可確認的回饋，或把 Overlay 與 Swap 混成同一條未驗證流程。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料Screen / Host 402×874、Dialog / Overlay 320×200、指定文字與一條核心 action。
第一個動作建立 Host；畫面應出現 402×874 的可辨識起點。
第一個可觀察結果在 Chrome Preview 點擊 Host 後看見「確認完成」Overlay。
本堂完成物可在 Preview 點擊的 Overlay 測試檔；Swap 另檔記錄來源、目的地與狀態差異。
下一位使用者／用途第 13 堂會把 Host 放入長清單，測試滾動與固定元素。
失敗時怎麼回復回 Host／Overlay 同層與 Prototype 起點；Starter 第二 action 出現方案提示時拆檔。

免費方案邊界

本堂只驗收一條核心 action；第二條 action 出現方案提示時，不按 Upgrade，另建測試檔。
