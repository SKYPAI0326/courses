# B4 Overlay 單一互動試跑包

這份素材包服務 `B4-overlay-single-action.md`。學員第一次操作前，先確認以下檔案都能開啟：

| 檔案 | 格式 | 何時使用 | 用途 |
|---|---|---|---|
| `reference/screen-host-blank.png` | PNG，402×874 | 看完情境、建立 Host Frame 前 | 對照手機主畫面尺寸；它是參考圖，不是可編輯的 Figma 檔 |
| `expected/dialog-overlay.png` | PNG，320×200 | 完成 Overlay 後 | 對照 `確認完成` 文字是否在 Overlay 內 |
| `source/FIGMA-FILE-URL.txt` | TXT | 開始操作前 | 指向實際 Chrome/Figma 測試檔；若網址無權限，依備援路徑新建空白檔 |

## 重要限制

- Figma Starter／Free 同一個原型只以一個核心 action 驗收；本單元使用 `On click → Open overlay`。
- `source/FIGMA-FILE-URL.txt` 是機器測試檔連結，不保證學員帳號有編輯權；無權限時複製畫面名稱與尺寸即可重建，能力差異是沒有預先放好的圖層。
- 這份試跑包沒有要求學員分享檔案、升級方案、輸入付款資料或公開部署。
