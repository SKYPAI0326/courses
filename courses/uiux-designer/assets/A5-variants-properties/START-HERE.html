把主次按鈕與狀態做成可選的元件：起始材料

本頁提供本堂所需的輸入材料，具體操作步驟請見講義；請在自己的設計檔中完成，本堂沒有提供預先建立的 Figma 檔案。

Type 表示按鈕角色，State 表示目前互動狀態或能否操作。本堂完成物是十種角色與狀態組合的 Button 元件集、可開關與交換的按鈕圖示，以及一組符合題目資料的狀態標籤。每個 Button 版本高 48、水平內距 16、圓角 8；既有 Button / Login 維持 Primary／Default。

課前準備與操作速查提供第一次登入、建立設計檔、選取圖層及保存方式。本堂會沿用前一堂的完成檔案；若缺少材料，請依照講義中的重建路徑補齊。
