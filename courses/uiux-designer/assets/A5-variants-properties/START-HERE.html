Variants、Properties 與狀態：起始材料

你會接手 A4 的 Login / Heading 主元件，把「一般標題」與「錯誤提示」收進同一個 component set。這頁列出起始條件、固定文字與成果欄位；操作順序請回到 A5 學習頁。

開始前準備

先開啟 A4 的 Figma 檔與完成檢查表，在同一個檔案選取 Login / Heading 主元件。若沒有可編輯檔案，先依 A4 起始材料建立 402×874 Frame、垂直 Auto Layout、文字 登入 與一個主元件。

本堂固定資料

項目設定
來源主元件Login / Heading
PropertyFigma 預設可能顯示 Property 1；若面板允許，可改名為 State。
Value 1Default：文字「登入」
Value 2Error：文字「帳號或密碼不正確，請檢查後再試一次」
使用處Instance / Login heading，要能切換兩個 Value。

你要留下的成果

  1. 同一個 component set 內有 Default、Error 兩個 Value。
  2. Error Variant 的長錯誤訊息沒有被裁切。
  3. Instance 可在兩個 Value 間切換。
  4. 填入A5 完成檢查表，記錄 Property 名稱、截圖與一個修正點。
面板提示

第一次加入 Variant 時，Figma 會建立 Property。直接把 Layers 名稱改成單一的「Error」可能出現格式警告；請回到 Property 的 Value 欄輸入 Error。

資料準備好後回到Variants、Properties 與狀態學習頁，依示範建立兩個狀態。
