第 05 堂 · 起始材料頁

Variants、Properties 與狀態

你會接手第 04 堂的 Login / Heading 主元件，把一般標題與錯誤提示收進同一組可切換的狀態。

你在這一堂的工作位置

你是阿凱，弄一下行銷工作室的行銷專員。同一位置有一般標題與錯誤提示，分開複製會造成狀態分叉。本堂先處理這個問題，讓雯姊在下一個交接點能使用可檢查的成果。

起始材料第 04 堂的 Login / Heading 主元件與 Instance / Login heading。
第一個動作選取主元件執行 Add variant；畫面應出現第二個 Variant 與可讀的 Property。
第一個可觀察結果同一個 Instance 能在 Default 與 Error 之間切換。
本堂完成物Default／Error component set、可切換 Instance、Property／Value 截圖與修復紀錄。
下一位使用者／用途第 06 堂會沿用狀態欄位建立 Button 與 Form。
失敗時怎麼回復回主元件檢查 Property 名稱與 Value；不要只改 Layers 名稱。

固定資料

欄位本堂值
來源主元件Login / Heading
Property保留 Figma 預設 Property 1，或改名為 State。
Value 1Default · 文字「登入」
Value 2Error · 文字「帳號或密碼不正確，請檢查後再試一次」
使用處Instance / Login heading，能切換兩個 Value。

完成條件

  1. 同一個 component set 內有 Default、Error。
  2. Error 文字換行後沒有被裁切。
  3. Instance 可以在兩個 Value 間切換。
  4. 記錄 Property 名稱、截圖與一個修正點。
常見面板提示

第一次加入 Variant 時，Figma 會建立 Property。狀態名稱要填在 Property 的 Value 欄；不要只把 Layers 名稱改成「Error」。
