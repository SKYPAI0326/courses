A5 完成檢查

請先選取 component set，再選取 Instance 讀取右側 Property。只看到兩個畫面、沒有狀態欄位與值時，先停在未通過。

交付名稱

Figma 元件：Login / Heading component set
完成物：Default／Error 兩個 Value、可切換 Instance、狀態截圖與修復紀錄。

狀態與使用處

項目檢查條件證據位置／備註
Login / Heading 是主元件，兩個 Variant 位於同一個 component set。
面板可讀到 State 或 Property 1，並有 Default、Error 兩個 Value。
Error Variant 顯示「帳號或密碼不正確，請檢查後再試一次」，文字沒有裁切。
Instance / Login heading 可在 Default／Error 間切換，來源關係仍保留。
記錄一個錯誤現象、回修位置與重跑起點。
