B1 起始材料：把一句需求拆成手機流程

今天的任務是為工作室行政人員畫出「登入 → 查看待處理清單 → 選取一筆」的手機介面入口。先寫清楚要完成的工作，再開 Figma 建立兩個 Frame。

使用情境

客戶只給你一句話

「請做一個手機服務，讓使用者登入後查看待處理清單，選一筆資料準備處理。」

這句話還缺少畫面順序、畫面內容與開始位置。你的第一份成果要讓下一位設計者知道：從哪裡開始、會經過哪些畫面、每一頁為何存在。

先填任務卡

欄位請填入
任務 IDTASK-01
角色工作室行政人員
起點尚未登入的手機畫面
目標找到一筆待處理資料，準備查看詳情
限制手機寬 402px；先驗收畫面入口，不加入真實帳密

再填畫面清單

ID畫面名稱進入條件要看見的內容離開條件
SCR-01Flow / Login尚未登入登入標題、帳號、密碼、登入按鈕按下登入後進入清單（B2 建立）
SCR-02Flow / List已登入清單標題、兩列待處理資料、選取線索選取一列查看詳情（後續單元）

Figma 操作規格

  1. 建立一個 402×874 Frame，命名 Flow / Login。
  2. 放入 A6 的 Button／Form 視覺材料；至少看見「登入」、「帳號」、「密碼」。
  3. 複製 Frame，命名 Flow / List，維持同一尺寸。
  4. 把內容換成 A7 的 List／Title 視覺材料，加入兩筆可讀的待處理資料。
  5. 選取 Flow / Login，在 Prototype 面板建立 Flow starting point，名稱可用 TASK-01 Login。
  6. 開啟 Preview，確認第一個畫面是 Login。截圖需同時包含 Frame 名稱、起始標記與 Preview。
方案邊界：這份材料只要求畫面清單、Frame 與起始點。登入按鈕要切換到 List 的行為，留到 B2 的單一 action 測試；畫面上有箭頭不等於 Prototype 已可操作。
