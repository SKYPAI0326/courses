視覺基礎：起始材料

你要在 Figma 建立一頁視覺規則表，讓下一堂的手機格線沿用同一套色彩與文字層級。這頁先給資料與檢查條件；操作順序請回到 A1 學習頁。

開始前準備

使用 Google Chrome 開啟 Figma 網頁版 Starter／Free，在自己的 Drafts 建立空白檔。若沒有可編輯的示範檔，直接依下表重建；不要把本頁當成完成品。

案例文字

用途文字套用規則
頁面標題登入工作區type-title，32 px
說明輸入帳號與密碼後開始工作type-body，16 px
錯誤訊息密碼至少需要包含一個英文大寫字母與一個數字type-helper，14 px
按鈕開始登入type-button，16 px

本例基準值

  • 背景色：#F5F3EE，角色名 color-bg
  • 主要文字：#2C2B28，角色名 color-text
  • 強調色：#C9963A，角色名 color-accent
  • 文字級距：標題 32、內文 16、輔助 14、按鈕 16 px

你要留下的成果

  1. Figma 頁面命名為 Visual foundations。
  2. 三個色彩角色與四個文字樣式能在頁面中找到並再次套用。
  3. 長錯誤訊息換行後每一行都能讀到，按鈕沒有被壓住。
  4. 截圖、Figma 連結與修正紀錄填入完成檢查表。

準備好後回到視覺基礎學習頁，依照示範建立自己的 Figma 檔。
