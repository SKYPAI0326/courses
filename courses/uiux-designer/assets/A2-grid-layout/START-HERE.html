用格線安排手機與桌面版面：起始材料

本頁提供本堂所需的材料與起點，具體操作步驟請見講義；請在自己的設計檔中操作，本堂沒有提供預先建立的 Figma 檔案。

工作室的登入內容要在手機與桌面都能對齊。本堂完成物是一個有共同邊界的手機版面、一個分成清單與提醒區的桌面版面，以及兩種手機寬度的響應式比較。主線將 Screen / Login 從 402 拉寬到 440；自己的題目則依講義比較 360 與 412。

課程總目錄提供第一次登入、建立設計檔、選圖層及保存方式。請沿用前一堂完成物；若缺少，請依講義的重建路徑補齊。
