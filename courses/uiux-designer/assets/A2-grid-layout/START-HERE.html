格線與版面基準：起始材料

你會接手 A1 的色彩與文字樣式，建立手機與桌機的欄、左右邊界與欄間距。這頁提供數值與檢查方式；操作順序請回到 A2 學習頁。

開始前準備

先開啟 A1 的 Figma 檔與完成檢查表，再在同一個檔案新增 Grid foundations 頁面。沒有 A1 檔案時，先依 A1 起始材料重建三個色彩角色與四個文字樣式。

版面基準

設計上把左右邊界稱為 Margin；在 Figma Columns 的 Stretch 模式中，請把它填在 Offset 欄位。

版面Frame 尺寸欄數左右邊界（Offset）欄間距（Gutter）
手機402×874 px416 px16 px
桌機1440×900 px1280 px24 px

畫面內容

  • 手機 Frame：Mobile / Login & List。
  • 桌機 Frame：Desktop / Login & List。
  • 兩個 Frame 都放入 A1 的標題與一個列表區塊，讓兩者左邊落在同一條欄線。
  • 完成後複製手機 Frame，將寬度改成 360 px，保留其他條件，記錄內容是否仍在安全區。

你要留下的成果

  1. Figma 頁面命名為 Grid foundations。
  2. 手機／桌機 Frame 的格線面板截圖，包含 Count、Offset、Gutter。
  3. 標題與列表共享左線的畫面截圖。
  4. 360 px 縮窄前後的觀察紀錄，填入A2 完成檢查表。

資料準備好後回到格線與版面基準學習頁，依示範建立兩種 Frame 的版面基準。
