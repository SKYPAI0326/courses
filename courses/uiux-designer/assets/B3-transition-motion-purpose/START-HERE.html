工作室行政人員進入任務詳情、返回待處理清單與更新狀態時，動畫要幫助理解發生了什麼。本堂完成物是方向一致的主線轉場、一段狀態改變的 Smart Animate、從開頭畫面走到我的紀錄的完整流程，以及動畫版與即時切換版的比較。

課前準備與操作速查提供首次登入、建立設計檔、選取圖層及保存檔案的方式。本堂操作沿用前一堂的完成成果；若缺少前堂檔案，請依講義說明的重建路徑補齊。

本堂會使用的規格／資料

用途本堂設定要觀察的效果
進入整理交付包詳情Row / T01 → Screen / Detail；Move in、從右進入、Ease out、200ms詳情從右進入，表示向內深入
返回待處理清單Button / Back → Screen / List；Move out、往右離開、Ease out、200ms詳情往右離開並顯露清單；方向與進入相反
狀態動畫起訖畫面Motion / Before、Motion / After；兩者皆為 402 × 300Status / Badge 從「待處理」變成「已完成」

畫面視覺參考（SVG）：先比對內容與閱讀順序。SVG是示意圖，匯入後不含Auto Layout、主元件或Prototype連線；這些設定依講義建立。

任務資料 TASK-DATA.csv：12 筆示範任務，用來建立清單、測試長標題與捲動。缺網路時可直接複製講義表格內容。
