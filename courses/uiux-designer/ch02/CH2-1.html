第二章｜第 1 份：替手機畫面加上四欄格線

開場說過，第一章的登入卡片放在 X 24。當時沒說為什麼，答案其實是：24 剛好是邊界的寬度。不過，那是看範例知道的。現在回到你自己的檔案，替手機畫面加上同樣的四欄格線，親眼看看你的卡片落在哪裡。

學完第 1 份，你會：替一張畫面加上欄格線，設定好欄數、邊界和溝槽；再用格線檢查畫面上的東西，有沒有對齊邊界。

為什麼先加格線

接下來幾份要開始移動畫面上的東西：先把「登入工作室」移到卡片外面，之後還要在桌面畫面上排清單和提醒。每移一個東西，你都要知道它該對齊哪裡。開場說過，靠眼睛拖的話，這個離左邊 24、那個離左邊 22，放在一起就歪了。

所以，動手移東西之前，要先在畫面上把線畫好。想想看，這和小時候寫生字簿很像：格子先印好，字寫在格子裡，就算一筆一筆慢慢寫，整頁還是排得整整齊齊。格線，就是 Figma 畫面上的格子。它只是參考線，不會跟著 App 給成員看到。

數字就照開場說的：左右邊界各 24，切成 4 欄，溝槽 12。手機很窄，切 4 欄已經夠用。你看，整排放一個東西，就是跨滿 4 欄；兩個東西對半放，就是各跨 2 欄。這些數字，後面幾份會一直用到。

開始動手

動手之前，先知道三件事。

  • 要選整張手機畫面：格線要畫在整張手機畫面上，所以要點的是 Screen / Login，不是它底下的 Login / Card。要是點到卡片，格線就只會畫在卡片裡。
  • Layout guide：右側設定裡用來加格線的那一區。按下它的 + 之後，Figma 先給的是 Grid，也就是方格，像數學作業用的方格紙；不過我們要的是直條，叫 Columns，就是開場說的「欄」。另外，如果格線原本是關著的，按 + 時 Figma 會把它打開，畫面下方跳出「Layout guides visible」和一個 Hide 按鈕。
  • 要改的三個欄位：選了 Columns 之後，小視窗會多出幾個欄位，我們只改其中三個，它們的名字開場都說過：Count 是要切成幾欄，Margin 是邊界，Gutter 是溝槽。Figma 先放的數字是 5 欄、邊界 0、溝槽 20，所以一開始最左最右沒有留白。Color、Type、Width 則不用動。

選手機畫面 Screen / Login

  • 打開你第一章的檔案。
  • 在左邊 Layers 點 Screen / Login 這一行。

做完會看到：手機畫面外圍出現藍色框，右側設定最上面寫 Frame，W 是 402、H 是 874。

點 Layout guide 的 +

  • 在右側設定的下面找到 Layout guide。看不到的話，把右側往下捲。
  • 點 Layout guide 右邊的 +。
  • 如果畫面下方跳出「Layout guides visible」，不要按旁邊的 Hide，等它自己消失。

做完會看到：手機畫面鋪滿淡紅色的小方格，旁邊跳出一個小視窗，左上角寫著 Grid。

把方格換成直條：選 Columns

  • 點小視窗左上角的 Grid，跳出三個選項：Grid、Columns、Rows。
  • 點 Columns。

做完會看到：方格不見了，手機畫面變成 5 條粉紅色直條，直條之間有比較寬的縫，最左和最右沒有留白。小視窗多了 Count、Margin、Gutter 等欄位。

填入 4、24、12

  • 點 Count 欄位裡的 5，打 4，按 Enter。欄位右邊的小箭頭不用點。
  • 點 Margin 欄位裡的 0，打 24，按 Enter。
  • 點 Gutter 欄位裡的 20，打 12，按 Enter。
  • 點小視窗右上角的 ×，關掉小視窗。

做完會看到：手機畫面上 4 條粉紅色直條，最左和最右各留一條沒有顏色的空白（邊界），直條之間是細細的縫（溝槽）。右側 Layout guide 那一列寫著 4 columns。

檢查：卡片落在哪裡

動手前先知道：放大之後，要看的是卡片的左邊和右邊，各落在哪一條線上。至於卡片裡的字和按鈕，是從卡片的邊往內留一段空白才開始的，所以沒有貼在欄線上。它們是跟著卡片排，不用對齊欄，這是正常的。

放大看卡片的左右兩邊

  • 在 Layers 點 Login / Card。
  • 按 Shift+2，畫面放大到這張卡片。
  • 看卡片的左邊和右邊，各落在哪一條線上。

做完會看到：卡片的左邊剛好貼著第 1 欄的左邊，右邊剛好貼著第 4 欄的右邊。右側 Position 的 X 是 24，Dimensions 的 W 是 354。

用數字對一次：卡片從 24 開始，寬 354，右邊就停在 24 + 354 = 378。再來看手機：寬 402，扣掉右邊界 24，也是 378。所以卡片的左右兩邊，都剛好停在邊界上，中間佔滿 4 欄；用開場的說法，就是跨 4 欄。這樣看下來，第一章那個 24 不是隨便填的，你現在親眼看到它在哪了。

把格線關掉再打開

動手前先知道：Shift+G 只是切換你看不看得到格線，不會改到檔案。格線關掉時你看到的，就是成員在 App 裡會看到的樣子。接下來幾份都要對著欄移東西，所以最後要讓它開著。

用 Shift+G 切換

  • 按 Shift+1，畫面縮回整個作品，和第一章用過的 Zoom to fit 一樣。
  • 點畫布上的空白處，取消選取。
  • 按 Shift+G。粉紅色的直條消失，畫面下方出現「Layout guides hidden」，卡片還在原來的位置。
  • 再按一次 Shift+G。直條回來，畫面下方出現「Layout guides visible」。

做完會看到：格線是開著的，手機畫面上有 4 條粉紅色直條。

做完之後

檢查自己做對了沒

  1. 在 Layers 點 Screen / Login，右側 Layout guide 那一列寫著 4 columns。
  2. 點那一列左邊的小圖示，小視窗打開：類型是 Columns，Count 4、Margin 24、Gutter 12。
  3. 在 Layers 點 Login / Card，右側 Layout guide 那一列是空的，只有一個 +：格線只加在手機畫面上，卡片上沒有。
  4. 格線開著：手機畫面上看得到 4 條粉紅色直條。

常見問題

只有卡片裡出現直條，手機畫面其他地方沒有

這是格線加到卡片上了。在 Layers 點 Login / Card，到右側 Layout guide 那一列，點最右邊的 − 刪掉它，再從第 1 步重新做；這次要點的是 Screen / Login。

按了 + 之後，畫面上看不到方格或直條

這是格線被關掉了。點畫布上的空白處，按 Shift+G，看到「Layout guides visible」就會出現。

小視窗關掉了，想再改數字

在 Layers 點 Screen / Login，點右側 Layout guide 那一列左邊的小圖示，小視窗就會再打開。

不看講義，試著用自己的話回答看看：

  1. 加格線時，為什麼要點 Screen / Login，不是 Login / Card？
  2. 卡片的 X 24 和 W 354，和邊界、四欄有什麼關係？
  3. 按 Shift+G 把格線關掉，會不會改到你的檔案？成員打開 App 時看得到格線嗎？

接下來

第 2 份要把「登入工作室」從卡片裡移出來，讓它變成整個手機畫面的標題。那移出來之後，它要放在哪裡？就靠你剛剛加上的格線來決定。
