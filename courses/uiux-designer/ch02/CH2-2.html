第二章｜第 2 份：把標題移出卡片

上一份你親眼看到了，登入卡片的左右兩邊，剛好停在邊界上。可是卡片裡的「登入工作室」沒有：它是從卡片的邊往內縮了一段才開始的。現在要把它搬到卡片外面，讓它變成整個手機畫面的標題，和卡片站在同一條線上。

學完第 2 份，你會：判斷一樣東西該放進卡片裡，還是放在卡片外面；也會在把它搬到卡片外之後，讓它和卡片對齊同一條邊界，並用一次選兩個的方法檢查有沒有對齊。

為什麼要把標題搬出來

打開手機裡的「設定」看看，最上面是一個大大的「設定」，下面才是一組一組的選項。那兩個字說的是「你現在在哪一頁」，不是其中哪一個選項。很多 App 都是這樣排的：最上面先告訴你這一頁是什麼，下面才是要看、要按的東西。

再換幾個 App 看看，排法都一樣。LINE 點到聊天那一頁，最上面寫「聊天」；購物 App 點進購物車，最上面寫「購物車」；銀行 App 打開轉帳，最上面寫「轉帳」。App 不一樣，內容也不一樣，可是最上面那幾個字，回答的卻是同一個問題：我現在在哪裡？

為什麼每個 App 都要先回答這個問題？因為人很少從第一頁一路點進來。仔細想想，你可能是點了朋友傳來的連結、按了一則通知，或是從別的畫面跳過來，一打開就落在某一頁。這時，最上面那幾個字讓你一眼確認自己沒走錯，接下來才去看下面的內容。而且往下捲了很久、捲回最上面時，看到它，你也就知道自己還在同一頁。

做 iPhone 的 Apple，在寫給設計師的設計規範裡也是這樣說的：標題幫人在 App 裡點來點去時，確認自己在哪裡；大標題在畫面捲回最上面時，提醒他現在的位置。它也建議標題用一個詞或很短的一句話，說出這一頁是做什麼的。

回到工作室的登入畫面來看。「登入工作室」也是這種字：成員打開 App，一眼看到這幾個字，就知道這裡是登入的地方。它說的是這整個畫面在做什麼；至於卡片裡的說明、提示和按鈕，才是成員登入時要看、要按的內容。第一章為了先把卡片做出來，把標題一起放進了卡片；現在畫面要開始照格線排了，就讓它回到該在的位置：卡片外面的上方，屬於整個手機畫面。

搬出來，還有一個好處。標題在卡片裡時，是從卡片的邊往內 16 開始，換算到手機畫面上就是 40；而卡片是從 24 開始。兩個東西的左邊差了 16，不在同一條線上。搬出來之後，把它也放在 24，標題和卡片就從同一條起跑線出發了，這也就是開場範例裡看到的樣子。

標題搬走之後，卡片裡最上面會空出一塊，所以最後還要把卡片裡剩下的三樣東西往上移、把卡片改矮。

第一段：把標題拖出卡片

動手前先知道：Title 現在在卡片裡面，所以它的 X、Y 是從卡片的左上角量的。等一下把它拖出卡片，量的起點就會換成手機畫面的左上角。畫面上的字不會動，右側的數字卻會變。

找到卡片裡的 Title

  • 在 Layers 找到 Login / Card。
  • 如果它底下什麼都沒有，點它左邊的小箭頭展開；已經看得到 Button / Draft、Hint、Message、Title 四樣，就不用點。
  • 點 Title，它就是「登入工作室」這段字。

做完會看到：右側 Position 是 X 16、Y 16，Layout 區的 Resizing 選中的是第一個圖示 Auto width。

拖到 Screen / Login 那一行上

  • 在 Layers 按住 Title 那一行。
  • 往上拖到 Screen / Login 那一行上放開。

做完會看到：Title 跑到 Login / Card 的上面，縮排和 Login / Card 一樣深，表示它現在直接放在手機畫面裡，不在卡片裡了。畫面上的「登入工作室」看起來沒有動，右側卻變成 X 40、Y 136。

字沒動，數字為什麼變了？因為量的起點換了。以前是從卡片的左上角量，現在是從手機畫面的左上角量。卡片本身在 X 24、Y 120，所以 24 + 16 = 40，120 + 16 = 136。你看，這個 40，就是剛才說的標題換算到手機畫面上的位置，和卡片的 24 差了 16。

接著替它改名。Heading，是標題的意思。它已經不在卡片裡了，名字如果還留著 Title，在 Layers 裡就分不出它是卡片裡的字，還是整個畫面的標題；改成 Screen / Heading，看名字就知道它是放在手機畫面上的標題。

改名為 Screen / Heading

  • 在 Layers 雙擊 Title 這個名字，它會變成可以打字的狀態。
  • 打下面的名字，按 Enter。

Screen / Heading

做完會看到：Layers 裡這一行的名字變成 Screen / Heading（太長時後面會被截掉，顯示成 Screen / Headi…，沒有關係）。

再把它放到邊界上。X 24 就是邊界，和卡片一樣。至於 Y 64，是因為手機螢幕最上面那一條，是顯示時間、電量的地方，標題要放在它下面，才不會被蓋到。標題高 32，從 64 排到 96；卡片從 120 開始，中間剛好留 24，和邊界一樣寬。

放到邊界上：X 24、Y 64

  • Screen / Heading 還選著。在右側 Position 把 X 改成 24，按 Enter。
  • 把 Y 改成 64，按 Enter。

做完會看到：「登入工作室」跑到白色卡片上面，左邊和卡片的左邊對齊，貼著第 1 欄的左邊。卡片裡最上面，原本放標題的地方空了一塊。

最後讓標題和卡片一樣寬。第一章的長句測試說過，標題這種短字很適合 Auto width；最後也留了一題：卡片上的 Title 用 Auto width 會不會有問題？那現在什麼變了？標題要和卡片站在同一條線上，左邊從 24 開始，右邊也要停在卡片的右邊，也就是寬度要剛好 354、跨滿 4 欄。Auto width 像一條紙條，寬度由字決定；字只有五個，紙條就只有 120 寬，你沒辦法把它定在 354。

能自己定寬度的，有兩種：Auto height 和 Fixed size。Fixed size 像固定大小的便利貼，寫不下的字會跑到框外；Auto height 則像固定寬度的筆記本，寫到邊就換下一行。標題以後如果變長，換行比跑出框外好，所以選 Auto height。

讓標題和卡片一樣寬：Auto height、W 354

  • Screen / Heading 還選著。在右側 Layout 區的 Resizing 點第二個圖示 Auto height。
  • 把 W 改成 354，按 Enter。

做完會看到：標題的字沒有變，但它外面的框從左邊界一直拉到右邊界，和卡片一樣寬。右側 W 是 354。

第二段：把卡片收緊

動手前先知道：標題本來在卡片裡從 16 排到 48（Y 16、高 32），下一樣東西 Message 從 64 開始。標題搬走後，上面就空出 48，所以剩下的三樣都往上移 48；X 都不用動，維持 16。卡片也跟著改矮 48：原本是 208，少掉 48，就是 160。

卡片裡三樣東西各往上移 48

  • 在 Layers 點 Message，在右側把 Y 從 64 改成 16，按 Enter。
  • 在 Layers 點 Hint，把 Y 從 104 改成 56，按 Enter。
  • 在 Layers 點 Button / Draft，把 Y 從 142 改成 94，按 Enter。

做完會看到：說明、提示和按鈕排在卡片上半部，彼此的距離和原本一樣；換成卡片裡最下面空了一塊。

卡片改矮：H 160

  • 在 Layers 點 Login / Card。
  • 在右側 Layout 區 Dimensions 把 H 改成 160，按 Enter。

做完會看到：白色卡片變矮，下緣在按鈕下面一點點，和原本按鈕到卡片底的距離一樣。右側是 W 354、H 160。

檢查：標題和卡片是不是同一條線

動手前先知道：一次選好幾個東西時，右側只有在大家的數字都一樣時才顯示數字，不一樣就顯示 Mixed。用這個方法，你不用一個一個點開比對，就能確認東西有沒有對齊。

一起選起來，看 X 和 W

  • 在 Layers 點 Screen / Heading。
  • 按住 Shift，再點 Login / Card，兩個會一起被選起來。
  • 按 Shift+2，放大到這兩個東西，看右側的數字。

做完會看到：右側上方寫 2 selected，X 是 24，W 是 354；Y 和 H 顯示 Mixed。畫面上標題和卡片的左邊貼著同一條線，右邊也停在同一個地方。

X 和 W 顯示得出數字，就表示標題和卡片從同一個地方開始，而且一樣寬；至於 Y 和 H，本來就不同，一個在上、一個在下。另外，畫布上藍框下方的 354 × 216，是把兩個東西合起來量的大小：從標題的頂端量到卡片的底端，不是卡片變高了。

看完之後：

  • 按 Shift+1，縮回整個作品。
  • 點畫布上的空白處，取消選取。

做完之後

檢查自己做對了沒

  1. Layers 裡，Screen / Login 底下有兩樣東西：Screen / Heading 和 Login / Card；Login / Card 底下剩三樣：Button / Draft、Hint、Message。
  2. Screen / Heading：X 24、Y 64，Resizing 是 Auto height，W 354。
  3. Login / Card：X 24、Y 120，W 354、H 160。
  4. 卡片裡：Message Y 16、Hint Y 56、Button / Draft Y 94，X 都是 16。

做完的樣子，和開場打開的第二章範例裡的手機畫面一樣。想對照的話，打開範例，在 Layers 點手機畫面裡的 Screen / Heading 和 Login / Card，比右側的 X、Y、W、H。範例打開時格線是關的，想看格線就在畫布上按 Shift+G。

常見問題

拖完之後，Title 還縮排在 Login / Card 底下

這是放開的位置不對。再拖一次，這次放在 Screen / Login 那一行的字上面，看到 Title 和 Login / Card 一樣深，才算成功。

Title 的縮排變得比 Login / Card 還淺，和 Screen / Login 對齊

W 是灰色的，改不了

Resizing 還是 Auto width，寬度由字決定，所以不能填。先點 Resizing 的第二個圖示 Auto height，W 就可以改了。
