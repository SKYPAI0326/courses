第二章｜第 3 節：算出跨欄的寬度

到目前為止，標題和卡片都從左邊界排到右邊界，跨滿 4 欄，寬 354。可是畫面上不會每樣東西都這麼寬。兩個東西要並排、各佔一半時，一半是多寬？現在就要學會用欄把這個數字算出來，再到手機畫面上親手驗證。

學完第 3 節，你會：用欄算出一塊東西跨幾欄時有多寬、從哪裡開始到哪裡結束，再到畫面上驗證算得對不對。

為什麼要算

在手機畫面上並排幾樣東西，不能拿手機的寬度直接除。畫面左右兩邊要各留一段邊界，東西和東西之間也要隔開一段距離。這兩個數字一旦定下來，整個畫面都要照著用，不能這裡留 10、那裡留 15。直接把 402 除以 2 的話，就等於當作邊界和間隔都不存在。

而且，每一塊多寬，也是設計時要做的決定。比方說，手機跳出確認框時，「取消」和「確定」一樣寬，看的人只要讀上面的字就能選。要是「取消」比「確定」寬一截，反而會讓人遲疑，不知道哪一顆才是要按的。反過來，設計的人想讓某一顆比較顯眼，也可以刻意讓它寬一點。不管是一樣寬，還是故意不一樣，都需要一把大家共用的尺來量，不然每次都只能憑感覺拉。

格線，就是這把尺。先從畫面寬度扣掉左右的邊界，剩下的切成幾欄，欄和欄之間隔著固定寬度的溝槽。切成 N 欄，中間就有 N − 1 條溝槽。之後每一塊要多寬，就說它跨幾欄：要一樣寬，就跨一樣多欄；要顯眼的那一塊，就多跨幾欄。現在就用手機的 4 欄，把「跨幾欄」換算成真正的寬度。

先算一欄多寬

先算一欄多寬。手機寬 402，左右邊界各 24，一共扣掉 48。4 欄之間有幾條溝槽？伸出一隻手看看，四根手指之間只有 3 個縫，所以溝槽是 3 條，一共扣掉 36。剩下的 318，就平分給 4 欄：

402 − 24 × 2 − 12 × 3 = 318
318 ÷ 4 = 79.5（每欄的寬）

一欄 79.5 不是整數，這沒有關係。Figma 照這個寬度畫欄，東西只要對齊欄線就好，你不用自己去量 79.5。

有了每欄的寬，跨幾欄就好算了：把那幾欄的寬加起來，再加上它們之間的溝槽。跨 2 欄，是 2 欄加中間 1 條溝槽；跨 4 欄，則是 4 欄加中間 3 條溝槽。

跨 2 欄：79.5 × 2 + 12 = 171
跨 4 欄：79.5 × 4 + 12 × 3 = 354

跨 4 欄算出來是 354，正好就是卡片和標題的寬度。這樣看下來，前兩節一直在用的 354，原來就是「跨滿 4 欄」。

兩塊並排、各跨 2 欄時，位置也算得出來。第一塊從邊界 24 開始，寬 171，就停在 195；再隔一條溝槽 12，第二塊從 207 開始，寬 171，停在 378，剛好是右邊界。

在手機畫面上驗證

算出來的數字對不對，放到畫面上看最清楚。接下來，要在手機畫面裡做兩個暫時的方塊，看看它們是不是剛好落在欄上。這兩個方塊只是用來驗證的，最後會刪掉，所以名字用 Reference / Half：Reference 是「參考」，表示它是對照用的、不是 App 裡真正的東西；Half 是「一半」。

動手之前，先知道兩件事。

  • 位置和大小：X 和 W，就是剛才算出來的；至於 Y 320、H 120，只是把方塊放在卡片下面、讓它夠大看得清楚，沒有特別的意思。第二塊的 X，前面也算過了：第一塊從 24 開始、寬 171，停在 195；再隔一條溝槽 12，就是 207。
  • 顏色：新拉的框沒有顏色，要先點 Fill 的 + 加一個，再換成 Muted。第一章說過，顏色變數的名字寫的是用途，而 Muted 是次要文字的顏色。這兩個方塊做完就刪，所以暫時借用它的灰色，只是為了在淺灰底上看得清楚；至於真正放進畫面的東西，顏色要照用途選。

做第一個方塊：Reference / Half 1

  • 點下方工具列的 Frame 工具。
  • 在手機畫面裡、卡片下面的空白處拉一個框。
  • 在 Layers 確認它縮排在 Screen / Login 底下。
  • 雙擊它的名字，改成下面的名字，按 Enter。
  • 在右側 Position 填 X 24、Y 320。
  • 在 Dimensions 填 W 171、H 120。
  • 點 Fill 右邊的 +。框會變成白色，同時跳出一個調色盤。
  • 點調色盤右上角的 ×，關掉調色盤。
  • 點 Fill 右邊的四點圖示，選 Muted。

Reference / Half 1

做完會看到：卡片下面一塊灰色方塊，左邊貼著第 1 欄的左邊，右邊貼著第 2 欄的右邊，剛好蓋住兩欄和中間那條溝槽。

做第二個方塊：Reference / Half 2

  • 點下方工具列的 Frame 工具。
  • 從第一塊右邊的空白處開始拉一個框。不要從第一塊上面開始拉，不然新的框會跑進第一塊裡面。
  • 在 Layers 確認它縮排在 Screen / Login 底下，和 Reference / Half 1 一樣深。
  • 雙擊它的名字，改成下面的名字，按 Enter。
  • 在右側 Position 填 X 207、Y 320。
  • 在 Dimensions 填 W 171、H 120。
  • 點 Fill 右邊的 +，再點調色盤右上角的 × 關掉調色盤。
  • 點 Fill 右邊的四點圖示，選 Muted。

Reference / Half 2

做完會看到：第二塊灰色方塊蓋住第 3、4 欄，右邊停在右邊界上。兩塊中間留著一條細縫。Layers 裡兩個方塊都縮排在 Screen / Login 底下，深度和 Login / Card 一樣。

接著把兩塊一起選起來檢查。一次選好幾個東西時，Dimensions 下面會多出一個 Spacing，指的就是它們之間的距離。

一起選起來檢查

  • 在 Layers 點 Reference / Half 1。
  • 按住 Shift，再點 Reference / Half 2。

做完會看到：右側最上面寫 Frame（兩個都是 Frame）；W 是 171（兩塊一樣寬，所以顯示數字），X 顯示 Mixed。Dimensions 下面的 Spacing 是 12。畫布上藍框下方寫著 354 × 120。

Spacing 是 12，表示兩塊中間的縫，剛好是一條溝槽。而 354 是兩塊合起來的寬度：171 + 12 + 171 = 354，和卡片一樣寬。你看，兩個半寬並排，加上中間的溝槽，剛好等於跨滿 4 欄。

驗證完，就把它們刪掉。登入畫面現在用不到並排的東西；不過算法學會了，以後真的要並排時，照同樣的方法算就好。

刪掉兩個方塊

  • 兩個方塊還選著，按鍵盤的 Delete（Mac 是 delete 鍵）。

做完會看到：兩塊灰色方塊不見了，Layers 裡 Screen / Login 底下又只剩 Screen / Heading 和 Login / Card。

把數字寫進規則表

第一章把顏色和文字的規則寫進了規則表，格線也一樣：把數字寫下來，之後做新畫面、或是別人接手時，翻開規則表就知道手機切幾欄、一欄多寬。這一章會在規則表最下面加一區「格線與版面」，一共寫五行，現在先寫第 1 行。

動手之前，先知道兩件事。

  • 為什麼一次加長到 1720：先把這一章五行說明的位置留好，之後幾節只要在同一段文字後面加一行，就不用再改規則表的高度。
  • 為什麼第 1 行用 Auto height、W 536：之後幾節會在這一行後面接著打第 2 到第 5 行，有些行比較長。規則表寬 600，左右各留 32，裡面能寫字的寬度就是 536；用 Auto height 把寬度定在 536，字太長就換行，不會超出規則表。這和上一節替標題選 Auto height，是同一個理由。

把規則表加長到 1720

  • 在 Layers 點 Rules。
  • 在右側 Dimensions 把 H 從 1480 改成 1720，按 Enter。
  • 按 Shift+2，畫面會縮放到整張規則表，最下面的空白也看得到。

做完會看到：規則表的白紙往下變長，輸入框和分隔線下面多出一大塊空白。

打小標題「格線與版面」

  • 點文字工具 T。
  • 在新空白處的左上方點一下。
  • 打下面的字，按 Esc。
  • 點 Typography 的樣式名那一行（或標題列右邊的四點圖示），在清單點 Section title。
  • 點 Fill 右邊的四點圖示，選 Text。
  • 在 Position 填 X 32、Y 1444。

格線與版面

做完會看到：分隔線下面一行粗體小標題「格線與版面」，和上面「狀態與邊框」一樣大、一樣顏色。

寫第 1 行：手機格線

  • 點文字工具 T。
  • 在小標題下方點一下。
  • 打下面這一行（直接複製比較不會打錯），按 Esc。
  • 點 Typography 的樣式名那一行（或標題列右邊的四點圖示），在清單點 Body。
  • 點 Fill 右邊的四點圖示，選 Text。
  • 在 Layout 區的 Resizing 點第二個圖示 Auto height。
  • 把 W 填 536，按 Enter。
  • 在 Position 填 X 32、Y 1480。

手機格線　4 欄｜邊界 24｜溝槽 12｜每欄 79.5｜跨 2 欄 171｜跨 4 欄 354

做完會看到：小標題下面一行字，寫著手機格線的六個數字。右側是 X 32、Y 1480，Resizing 是 Auto height，W 536，樣式 Body，Fill 是 Text。

做完之後

檢查自己做對了沒

  1. Screen / Login 底下只有 Screen / Heading 和 Login / Card，兩個方塊已經刪掉。
  2. Rules 的 H 是 1720。
  3. 規則表最下面有小標題「格線與版面」（Section title、Text，X 32、Y 1444）。
  4. 小標題下面一行「手機格線　4 欄｜邊界 24｜溝槽 12｜每欄 79.5｜跨 2 欄 171｜跨 4 欄 354」（Body、Text，Auto height、W 536，X 32、Y 1480）。

常見問題

方塊在 Layers 裡沒有縮排在 Screen / Login 底下

拉框的時候，起點在手機畫面外面，方塊就不會在手機畫面裡，格線也對不到它。在 Layers 按住它，拖到 Screen / Login 那一行上放開，再重新填 X、Y。

第二個方塊縮排在 Reference / Half 1 底下

拉框時是從第一塊上面開始拉的，新的框就被放進第一塊裡。在 Layers 按住它，拖到 Screen / Login 那一行上放開，看到它和 Reference / Half 1 一樣深，再重新填 X 207、Y 320。

方塊是白色的，幾乎看不見

Fill 還停在剛加上時的白色（FFFFFF）。點 Fill 右邊的四點圖示，選 Muted。

小標題或第 1 行不在規則表上，或在 Layers 裡沒有縮排在 Rules 底下

點文字工具時，點到了規則表外面。在 Layers 按住它，拖到 Rules 那一行上放開，再重新填 X、Y。

不看講義，試著用自己的話回答看看：

  1. 手機寬 402，為什麼一半不是 201？
  2. 4 欄之間為什麼只有 3 條溝槽？跨 2 欄的 171 是怎麼來的？
  3. 第二個方塊的 X 為什麼是 207？

到這裡，手機的格線算完了。第 4 節要換到電腦螢幕：做一張寬 1440 的桌面畫面，切成 12 欄，用同樣的方法算出它每欄多寬，以及跨 4 欄和跨 8 欄各是多少，再寫進規則表的第 2 行。
