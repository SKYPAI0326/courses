第二章｜第 5 份：在桌面畫面分出主區和側區

上一份做好了桌面畫面，切成 12 欄，也算出跨 8 欄寬 792、跨 4 欄寬 384。現在用這兩個數字，把桌面畫面分成兩塊：左邊放待處理清單的主區，右邊放今日提醒的側區，再替兩塊各放一個小標題。

學完第 5 份，你會：把一張寬的畫面分成主區和側區，說得出哪一塊該當主區；再用上一份算好的寬度，算出每一區從哪裡開始、到哪裡結束。

主區和側區

用電腦打開很多網站，畫面常常分成一大一小、並排的兩塊。用電腦收信，左邊一窄排是收件匣、寄件備份這些資料夾，右邊一大塊是信件清單。在電腦上看影片，左邊一大塊是正在播的影片，右邊一窄排是接下來可以看的影片。開場提過的購物網站，左邊一窄排是篩選條件，右邊一大塊擺商品。

大的那一塊，放的是你打開這個畫面要做的事：讀信、看影片、挑商品。這一塊叫主區。窄的那一塊在旁邊幫忙：換一個資料夾、找下一部影片、縮小商品的範圍，不看它也能把事情做完。這一塊叫側區。從上面的例子可以看到，側區有時在左、有時在右；決定哪一塊是主區的，是它放什麼，不是它在哪一邊。

為什麼要分清楚？畫面一打開，眼睛通常先落在最大的那一塊。主區放對了，看的人一眼就找到要做的事；放反了，例如信件清單擠在窄窄的一排、資料夾佔掉大半個畫面，他得先在畫面上找一下，才知道從哪裡開始。

工作室的桌面畫面也一樣。開場時主管說，最在意的是「用手機能很快找到待處理的工作」。坐在電腦前的成員也是為了處理工作才打開畫面，所以桌面畫面的主區放待處理清單；今日提醒是當天要記得的短短幾句，在旁邊提醒他別漏掉，放在側區。至於主區為什麼跨 8 欄、側區為什麼跨 4 欄，第 6 份把清單和提醒放進去之後，會把理由寫進規則表。

現在先做兩個空的區，還不放清單和提醒。區是用來排版的：看的人看不到它的框，看到的是裡面的東西排在同一條線上。先把區放在對的欄上，之後放進去的東西只要貼齊區的左邊，就自動對齊格線；整個區要移動時，裡面的東西也會跟著一起走。

算出兩區的位置

在 Figma 做一個框，要填兩種數字：W 是它多寬，X 是它的左邊在哪裡。主區跨 8 欄、寬 792，側區跨 4 欄、寬 384，上一份已經算好，這就是兩區的 W。現在要算的是兩區的 X。

主區最好算。左邊界是從 0 到 120 這一段，左邊界結束的地方，就是第 1 欄開始的地方，所以主區從 120 開始，X 填 120。側區要從主區推過去：主區從 120 開始、寬 792，到 912 結束；中間再隔一條溝槽 24，側區才開始，所以側區的 X 是 936。

主區的 X：120（左邊界結束的地方）
主區結束在：120 + 792 = 912
側區的 X：912 + 24 = 936

最後檢查有沒有排對。側區從 936 開始、寬 384，結束在 936 + 384 = 1320；右邊界從 1440 − 120 = 1320 開始。兩個數字一樣，表示兩區合起來，剛好從左邊界排到右邊界。這也是上一份對過的答案：792 + 24 + 384 = 1200。

上下也要定。兩區的 Y 都是 120，讓上方留的空白和左右的邊界一樣寬。高度先定 540，放得下第 6 份要放的卡片就好；和上一份一樣，這一章在意的是寬度。

做出主區和側區

動手前先知道兩件事。第一是名字。主區叫 Desktop / Main，側區叫 Desktop / Aside。Desktop 表示它在桌面畫面上；Main 是英文「主要」的意思，就是主區；Aside 是英文「在旁邊」的意思，設計上常用它來稱呼側區。

第二是做好之後會看不到框。在桌面畫面裡拉出來的框，Fill 是空的，框裡沒有顏色，所以點畫面其他地方之後，就看不到它了。這是正常的：前面說過，區是用來排版的，看得到的是之後放進去的東西。要再看到它，在 Layers 點它的名字就好。下面填的 X、Y，都是從桌面畫面的左上角量的。

做主區：Desktop / Main

  • 在 Layers 點 Screen / Desktop reference。
  • 按 Shift+2，畫面放大到整張桌面畫面。
  • 點下方工具列的 Frame 工具。
  • 在桌面畫面的左半邊拉一個框。
  • 在 Layers 確認新的框縮排在 Screen / Desktop reference 底下。
  • 雙擊新的框的名字，貼上下面的名字，按 Enter。
  • 在右側 Position 填 X 120、Y 120。
  • 在 Dimensions 填 W 792、H 540。

Desktop / Main

做完會看到：藍色外框的左邊對齊第 1 欄的左邊，右邊對齊第 8 欄的右邊。右側的 Fill 是空的。

做側區：Desktop / Aside

  • 點下方工具列的 Frame 工具。
  • 從第 9 欄裡面開始，往右下拉一個框。起點不要落在主區裡。
  • 在 Layers 確認新的框縮排在 Screen / Desktop reference 底下，和 Desktop / Main 一樣深。
  • 雙擊新的框的名字，貼上下面的名字，按 Enter。
  • 在右側 Position 填 X 936、Y 120。
  • 在 Dimensions 填 W 384、H 540。

Desktop / Aside

做完會看到：藍色外框從第 9 欄的左邊開始，到第 12 欄的右邊結束，右邊貼齊右邊界。Layers 裡 Desktop / Aside 排在 Desktop / Main 上面，兩個一樣深。

替兩區放小標題

兩區各放一個小標題，告訴看的人這一塊放的是什麼。這和第 2 份說的畫面標題是同一個道理，只是範圍小一點：畫面標題說的是現在在哪一頁，小標題說的是這一塊是什麼。小標題用的文字樣式，和規則表每一區的小標題一樣，都是 Section title。

動手前先知道三件事。

  • X 0、Y 16 從哪裡量：小標題放在區裡面，所以 X、Y 是從區的左上角量的；第 2 份說過，量的起點是它所在的那一個框。X 0 就是貼齊區的左邊，主區的左邊就是左邊界，所以主區的小標題不用另外算，自己就對齊了格線。Y 16 和登入卡片裡第一行字離上緣的距離一樣。
  • 名字：字打完，Layers 裡的名字會是那段字本身，例如「待處理清單」。改成 Main / Title、Aside / Title，是寫它的用途：主區的標題、側區的標題。
  • 文字樣式：Figma 會沿用上一次用的文字樣式，所以打完字，Typography 有時已經是 Section title，有時不是。步驟裡會請你先看一眼。

主區的小標題：Main / Title

  • 在 Layers 點 Desktop / Main。
  • 按 Shift+2，畫面放大到主區。
  • 點文字工具 T。
  • 在主區的左上方點一下。
  • 打「待處理清單」，按 Esc。
  • 在 Layers 確認這段字縮排在 Desktop / Main 底下。
  • 看右側 Typography：如果寫的是 Section title，就跳到下一項；如果不是，點樣式名那一行（或標題列右邊的四點圖示），在清單點 Section title。
  • 點 Fill 右邊的四點圖示，選 Text。
  • 在 Position 填 X 0、Y 16。
  • 在 Layers 雙擊這段字的名字，貼上 Main / Title，按 Enter。

待處理清單

Main / Title

做完會看到：「待處理清單」貼在主區的左上角，左邊和第 1 欄的左邊切齊。Layers 裡 Main / Title 縮排在 Desktop / Main 底下。

側區的小標題：Aside / Title

  • 在 Layers 點 Desktop / Aside。
  • 按 Shift+2，畫面放大到側區。
  • 點文字工具 T。
  • 在側區的左上方點一下。
  • 打「今日提醒」，按 Esc。
  • 在 Layers 確認這段字縮排在 Desktop / Aside 底下。
  • 看右側 Typography：如果寫的是 Section title，就跳到下一項；如果不是，點樣式名那一行（或標題列右邊的四點圖示），在清單點 Section title。
  • 點 Fill 右邊的四點圖示，選 Text。
  • 在 Position 填 X 0、Y 16。
  • 在 Layers 雙擊這段字的名字，貼上 Aside / Title，按 Enter。

今日提醒

Aside / Title

做完會看到：「今日提醒」貼在側區的左上角，左邊和第 9 欄的左邊切齊。Layers 裡 Aside / Title 縮排在 Desktop / Aside 底下。

檢查兩區有沒有排好

最後把兩區一起選起來，看右側的數字。第 2 份用過這個方法：兩個東西某一項相同，右側就只顯示一個數字；不同，就顯示 Mixed。兩區應該上緣切齊、一樣高，所以 Y 和 H 要只顯示一個數字；起點和寬度本來就不同，所以 X 和 W 會是 Mixed。Dimensions 下面的 Spacing，是兩個東西之間的距離。

一次選兩區

  • 在 Layers 點 Desktop / Aside。
  • 按住 Shift，再點 Desktop / Main。
  • 按 Shift+2，畫面放大到兩區。

做完會看到：畫布上兩區合起來是 1200 × 540。右側 Y 是 120、H 是 540，X 和 W 是 Mixed，Spacing 是 24，也就是兩區之間的那一條溝槽。

做完之後

檢查自己做對了沒

  1. Screen / Desktop reference 底下有 Desktop / Main（X 120、Y 120，W 792、H 540）和 Desktop / Aside（X 936、Y 120，W 384、H 540），兩個一樣深。
  2. Desktop / Main 底下有 Main / Title「待處理清單」，Desktop / Aside 底下有 Aside / Title「今日提醒」；兩個都是 Section title、Fill 是 Text、X 0、Y 16。
  3. 一次選兩區，Spacing 是 24，畫布上是 1200 × 540。

常見問題

Desktop / Aside 縮排在 Desktop / Main 底下

拉框的時候起點在主區裡面。在 Layers 按住 Desktop / Aside，拖到 Screen / Desktop reference 那一行上放開，看到它和 Desktop / Main 一樣深，再重新填 X 936、Y 120。

小標題跑到桌面畫面的左上角，沒有在區裡

這段字沒有在區裡面，X 0、Y 16 就變成從桌面畫面的左上角量。在 Layers 按住它，拖到 Desktop / Main（側區的標題就拖到 Desktop / Aside）那一行上放開，看到它縮排進去，再重新填 X 0、Y 16。

主區或側區在畫面上看不到

區沒有填顏色，沒選它的時候本來就看不到。在 Layers 點它的名字，就會看到藍色外框。

不看講義，試著用自己的話回答：

  1. 主區和側區差在哪裡？工作室的桌面畫面，為什麼待處理清單放在主區？
  2. 側區的 X 為什麼是 936？
  3. 主區的小標題 X 填 0，為什麼就會對齊左邊界？
