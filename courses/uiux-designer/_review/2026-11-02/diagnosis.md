## 2. 問題一：不說人話（根因在上游，不只在措辭）

1. **寫給稽核者，不是寫給學員**。前幾輪修復（9/16、9/17、10/09、10/22）的主軸是「證據不足就標 PENDING、不得宣稱」，結果大量查核語進了正文：「不能據此寫成他人已理解或真人試跑通過」「不假裝是資料庫同步」「沒有把普通 Navigate 稱為 Swap 測試」「不能換成 PNG 假冒」。學員讀到的是一份防弊清單。
2. **一句塞一個指令＋三個數字＋一個圖層名**。例：「選Value按Shift+A，命名新框 Field / Input ，水平內距16、垂直12、W354、H48、白底、1px #5F6C80 外框、圓角8。」規格值應該放表格，句子負責說為什麼與怎麼看結果。
3. **段落之間沒有接續**。「開始前」一節固定是「在第0X堂檔案找到…能說出…即可開始。缺檔時…」＋每頁相同的樣板句「先開啟本堂起始材料（HTML），讀取輸入與圖層名稱；操作在你的 Figma 檔或本堂指定工具完成」。小節之間沒有「為什麼現在要做這件事」。
4. **跨頁引用靠堂號**。學員要記住第幾堂教了什麼；而頁面檔名（part2/CH4）和堂號（第12堂）又不一致。
5. **雙軌語氣**。「有同學時可請他…；沒有同學時標『他人反饋待補』」在 B1、B2、B4、B6、B7 反覆出現，每次都讓正文分岔。
6. **B8 把完整程式碼貼進講義**（約 100 行），正文變成程式列表；學員真正要做的三個修改與 Git／Pages 流程被擠到後段。

## 3. 問題二：脫離現況

見 `platform-figma-design.md`、`platform-figma-prototype.md`、`platform-git-pages.md`（三份獨立核對，附官方來源 URL）。共通型態：

- 講義用「Layout guides／Layout grid」「Scroll behavior／Overflow」「Flow starting point／流程起始點」這種**新舊名並列＋「若找不到…」備援**的寫法，表示寫作時沒有對照現行介面；學員面對兩個名字反而不知道該找哪個。
- 方案限制（Starter 的原型功能、Dev Mode、草稿與檔案數）是憑記憶寫的，需要以官方定價頁為準。
- 大量「若你的介面沒有…可改用…」備援步驟（A5 的 Text property、B7 的 Export frames to PDF）。

**阻斷學員的 8 處**（照做會做不出來）：

| 頁 | 問題 |
|---|---|
| A4 | 主元件右鍵「Create instance」不存在 |
| A5 | 文字屬性建立路徑錯，連帶 A6～A8 改按鈕文字做不了 |
| B4 | 選單彈層 Manual 位置填畫面座標，實際是相對觸發物件的偏移 |
| B5 | 「Scroll to 第一個 Row」從下拉選不到深層物件 |
| B8 | Mac 推送沒有可走的登入路徑 |
| B8 | `git diff` 進入分頁畫面，沒教按 q 離開 |
| B8 | 「先改標題」寫在命令之後，照做得到空 diff |
| B8 | 三項修改排在建立基準之前，基準被污染 |

誤導約 20 處，最常見：Preview 與 Present 混用（4 頁）、UI3 改名（Text → Typography、Layout grid → Layout guide、Reset overrides → Reset all changes）、新建檔案入口（+ Create → Design）、Figma 自動建立 Flow 卻寫「新增」、Starter 沒有原型分享權限控制。
