# 獨立審查：內容是否足以讓學員做 UI/UX 工作

日期：2026-11-02。三位 fresh-context 審查員（未繼承改寫對話），只拿到 round1 學員正文、課綱、時數帳本與審查問題。本檔為 PM 彙整，保留各自結論與證據要點。

## 審查員 A：UX 實務

**結論：還接不了小案。** 已規定好的手機介面能做到元件化、可預覽、可交付、可部署；缺接案前半段，也沒有從零做一個新產品。

| 項目 | 判定 | 要點 |
|---|---|---|
| 需求理解 | 缺 | 使用者、目標由講義直接給；無訪談、釐清、範圍界定 |
| 資訊架構與流程 | 不足 | 畫面清單預先決定；只有一條主線，無分支／錯誤流程圖 |
| 互動設計原則 | 元件層級大致足夠 | A8、B3～B5 有情境判斷表；缺可帶走的原則清單；缺日期、單選、下拉 |
| 可用性測試 | 不足 | 分級與重測好；只測自己，無測試計畫、帶測引導 |
| 無障礙 | 不足 | 非色彩線索足；4.5:1 門檻、最小觸控尺寸、字級下限未寫進正文 |
| 設計決策與表達 | 不足 | 看圖判斷是二選一；無評論程序、無向客戶／工程師說明 |
| 遷移能力 | 不足 | 練習線與主線同構（清單→詳情→確認），屬近遷移 |
| 職場銜接 | 不足 | 交付包好；無作品集、無給工程師的狀態與響應式標註 |

只碰皮毛的課綱：57-01 線框（事後補畫）、57-08 發布規劃（只 1x PNG）、57-09 網頁設計（只改三處）、42-07 必填、42-09 出現時機、42-11 導覽層級、42-01 色彩系統（配色預先給）。

前五缺口：需求探索（B1 前段，約 4h）、從零做新產品（練習線改自選題，A6 補選擇控制項 1.5h）、資訊架構與流程（B1，3h）、真人測試計畫與帶測（B6，2h）、設計表達與工程交付＋作品集（B7、B8，4h）。

## 審查員 B：UI 技法與 Figma 工作流

**結論：不夠。** 一條任務流程做得扎實；只教課程案例用得到的元件與設定，做得出結構正確的簡單 App，做不到專業水準介面。

| 項目 | 判定 |
|---|---|
| 層級、對齊 | 足夠 |
| 間距系統（4／8 倍數） | 缺 |
| 色彩（深淺階、Hover／Pressed、Color style） | 不足 |
| 字級系統 | 不足 |
| 圖示、圖片 | 缺 |
| 元件化思維 | 足夠 |
| Variants 深度（Boolean、Instance swap、巢狀、互動狀態） | 不足 |
| Styles／Variables、元件庫 | 缺 |
| 尺寸模式、巢狀 | 足夠 |
| 響應式（Constraints、Min/Max、Wrap、斷點） | 缺 |
| 表單元件廣度（Checkbox、Radio、Select、Toggle、Focus） | 不足 |
| 清單、空狀態、錯誤、彈窗 | 足夠 |
| 導覽、卡片、載入 | 不足／缺 |
| 原型 | 測試夠用，展示不足（無 Hover、After delay、Change to） |
| 範例品質 | 不足（對比只有文字，正文僅 3 張示意圖） |
| 練習設計 | 不足（無從空白需求設計新畫面） |
| 業界工作流 | 不足（Pages／Sections、版本歷史、SVG、2x、標註） |

**有效練習時數估算**：Part A 約 27h／帳本 42h，Part B 約 31h／帳本 57h，全課約 58h／99h；B1、B2、B8 落差最大。

前五缺口：Styles／Variables 與 4／8 間距（A1、A3、A4，3h）、元件系統深度與元件庫（A5、A8，4h）、響應式（A2、A3、B8，4h）、UI 模式廣度與圖示圖片（A6、A7、A1／A8，5h）、獨立設計題與交付工作流（A8 後、B6 後、B7，6h）。合計約 22h。

## 審查員 C：學員實作模擬（A1、A5、B4、B6 實走＋全課練習掃描）

**總評 3.5／5。** 主線規格、圖層名、跨堂前置一致，學員做得出東西。

| 單元 | 推估時數 | 帳本 | 主要卡點 |
|---|---|---|---|
| A1 | 4.5～5.5h | 5h | W/H 位置未說；Fill 設成 `Surface` 但沒建顏色樣式；「24／32」未說是字級／行高；卡片與按鈕無尺寸；換你做條件與自我檢查矛盾（主要動作） |
| A5 | 4.5～5.5h | 6h | 規格表「深灰 1 px 外框」對不上 A1 Border 色 |
| B4 | 6～7h | 7h | 換你做要電話與 Email，但 CSV 沒有這兩欄；排序選取狀態沒說怎麼做；B3／B4 沒指定同一筆資料 |
| B6 | 6～7h＋ | 6h | 「隔天」無法在一堂課內做；評分表 F3 文案、C2 Button 四組合在前面練習線都沒要求 |

練習線大致逐堂累積，B6 會有可測試的 App；斷點：A2 桌面雙區、A6 表單之後沒再用；B3、B4 沒指定同一筆；F3 文案與成功結果到 B6 才揭露。

看圖判斷 19 題中 18 題答案是版本二，且都是「明顯壞 vs 好」，沒練到兩案都合理時的取捨。
