# 第二輪練習線：自選題目（三選一）

日期：2026-11-02。取代第一輪的「報名確認 App」。學員在第一堂讀三份需求頁，選一題，之後每堂「換你做」都做自己的題目，整合作品測的就是這個 App。三題同樣是手機 360×800，結構對應如下，讓每堂的練習條件可以用同一張表寫。

## 1. 三個題目

| | 預約 | 點餐 | 會員 |
|---|---|---|---|
| 客戶 | 毛毛巷寵物美容（三位美容師的小店） | 轉角咖啡（外帶為主的街角咖啡店） | 青田書店（獨立書店，有集點卡） |
| 使用者 | 飼主，多半在下班通勤時用手機預約 | 上班族，排隊前先點好、到店取餐 | 熟客，查點數、兌換贈品、看新書活動 |
| 客戶想解決 | 電話預約佔掉美容師時間；時段常重複登記 | 尖峰排隊太長；客製選項口頭溝通常出錯 | 紙本集點卡常遺失；兌換規則常被問 |
| 開頭畫面 | 歡迎頁：店名、一句說明、「開始預約」 | 歡迎頁：店名、營業時間、「開始點餐」 | 登入頁：手機號碼、密碼、「登入」 |
| 清單（12 筆） | 服務項目 | 菜單品項 | 兌換品 |
| 清單卡片內容 | 服務名、所需時間、價格、狀態 | 品名、價格、一句說明、狀態 | 品名、所需點數、狀態 |
| 狀態標籤 | 可預約／本週額滿 | 供應中／售完 | 可兌換／點數不足／已兌完 |
| 長文字那筆 | 「大型犬全套洗澡美容」說明很長 | 「季節限定・柚香蜂蜜冷萃咖啡」名稱很長 | 「青田書店二十週年紀念帆布袋（附手寫書籤）」名稱很長 |
| 詳情 | 服務說明、注意事項、「選擇時段」 | 品項說明、客製選項、「加入訂單」 | 兌換品說明、兌換規則、「兌換」 |
| 表單 | 預約資料：飼主姓名、手機、寵物名字、寵物體型（單選：小／中／大）、日期時段（下拉）、加購（勾選：驅蟲、香氛）、備註、同意注意事項（勾選，必填） | 取餐資料：取餐人姓名、手機、取餐時間（下拉）、付款方式（單選：現場付款／行動支付）、需要統編（開關，打開才出現統編欄）、備註 | 註冊：姓名、手機、Email、生日月份（下拉）、喜歡的書類（勾選，可多選）、訂閱電子報（開關）、同意會員條款（勾選，必填） |
| 主要確認動作 | 送出預約 | 送出訂單 | 確認兌換 |
| 成功／警告／錯誤 | 預約成功／大型犬需多 30 分鐘／網路中斷 | 訂單已送出／取餐時間在尖峰需多等 10 分鐘／網路中斷 | 兌換成功／兌換後點數剩不到 50／網路中斷 |
| 底部面板 | 選擇時段 | 客製選項（冰熱、甜度、加購） | 排序方式（點數低到高、最新上架） |
| 一段狀態動畫 | 時段從「可選」變「已選」 | 「加入訂單」後右上數量徽章 +1 | 「確認兌換」後點數數字減少 |
| 底部導覽 | 首頁／我的預約／會員 | 菜單／訂單／我的 | 首頁／兌換／點數紀錄 |
| 空狀態 | 我的預約：還沒有預約 | 訂單：還沒有訂單 | 點數紀錄：還沒有紀錄 |

## 2. 素材

每題一頁需求說明（含客戶訪談紀錄與 12 筆資料表）＋一個 CSV：

- `assets/shared/practice/BOOKING-BRIEF.html`、`BOOKING-DATA.csv`
- `assets/shared/practice/ORDER-BRIEF.html`、`ORDER-DATA.csv`
- `assets/shared/practice/MEMBER-BRIEF.html`、`MEMBER-DATA.csv`
- `assets/shared/practice/CHOOSE-TOPIC.html`：三題並列比較，幫學員選題

訪談紀錄要真實：客戶會講得模糊、會想要太多功能、有一兩處自相矛盾（例如「什麼都要能線上做」但又「不想讓客人自己取消」），B1 學員要從中整理出目標、範圍（必做／之後再做）、畫面清單與流程。訪談紀錄不能直接寫出畫面清單。

## 3. 每堂「換你做」對應

| 單元 | 條件（三題通用，題目差異看上表） |
|---|---|
| A1 | 讀三份需求頁並選題；建立自己的顏色變數（主色三階：一般、按下、淺底）與三種文字樣式；做開頭畫面並檢查對比 |
| A2 | 為 360 寬設 4 欄格線；規劃桌面雙區（左清單右詳情）；把開頭畫面改成 412 寬，用 Constraints 讓內容跟著調整 |
| A3 | 用間距變數做清單卡片；用長文字那筆測長高；卡片寬設最小與最大寬度；做一排會換行的標籤（Wrap） |
| A4 | 主要確認動作按鈕做成元件，放進自己的元件區；做兩個使用處；按鈕內放圖示使用處並換圖示 |
| A5 | 狀態標籤元件（題目的狀態）；按鈕加 State（Default／Hover／Pressed／Disabled）與「顯示圖示」開關 |
| A6 | 題目的表單，含單選、勾選、下拉或開關；做錯誤與修正後畫面；勾選框與單選做成元件 |
| A7 | 12 筆清單、空狀態、長文字那筆的詳情；卡片加圖示或圖片；做一張載入中畫面 |
| A8 | 成功／警告／錯誤提示；確認彈窗；底部導覽（題目的三個分頁）；檢查觸控尺寸 |
| B1 | 讀訪談紀錄，寫需求摘要（目標、使用者、必做／之後再做）；列畫面清單；在 FigJam 畫流程圖（含錯誤分支）；畫兩張線框並建立流程起點 |
| B2 | 清單 → 詳情 → 返回，至少兩筆；按鈕的 Hover 互動 |
| B3 | 題目的一段狀態動畫 |
| B4 | 確認彈窗三條路徑；題目的底部面板；成功提示自動消失 |
| B5 | 12 筆清單捲動，固定頁首與底部導覽，最後一筆不被遮住 |
| B6 | 整合作品：寫測試計畫，用單人測試方法測自己的 App，修正後重測，填評分表 |
| B7 | 交付資料夾＋標註＋2x 與 SVG 輸出＋一頁作品集案例 |
| B8 | 網站資料換成題目的 3 筆資料；換上自己的徽章；改主色 |
