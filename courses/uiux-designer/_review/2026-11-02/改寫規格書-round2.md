## 0. 為什麼要擴充

三位獨立審查員結論一致：現稿能讓學員把一套**已規定好的**手機介面做到元件化、可預覽、可交付、可上線，但還接不了小案。缺口：

1. 沒有需求理解：使用者、目標、畫面清單全由講義給定。
2. 練習線（報名確認 App）和主線同構，學員沒從零做過一個新產品。
3. UI 技法缺：設計代號（Variables）、4／8 間距、響應式（Constraints、Min／Max、Wrap）、元件狀態（Hover／Pressed／Focus）、顯示開關與換圖示、表單控制項（勾選、單選、下拉、開關）、圖示與圖片、載入狀態、給工程師的標註、2x／SVG 輸出、作品集。
4. 看圖判斷 19 題有 18 題答案是版本二，而且都是一好一壞。
5. 具體缺陷（第 4 節逐條列）。

依活動量估算，現稿全課約 58 小時，時數帳本是 99 小時。本輪每頁增加一到兩個技法小節與更完整的練習，目標每頁正文 7,000～9,500 字（A7、A8 帳本只有 4 小時，6,000～7,500 字；B8 8,000～10,000 字）。

## 2. 練習線：自選題目（取代報名確認 App）

完整定義在 `round2-topics.md`，素材在 `../assets/shared/practice/`（需求頁、CSV）、`../assets/shared/icons/`（16 個 SVG 圖示＋README.html）、`../assets/shared/images/`（3 張範例圖）。動筆前先讀這些檔，資料、店名、狀態值、提示文字一律照素材寫，不要自己編。

「換你做：你的題目」寫法：

1. 第一段一句話說這次要在自己的題目上做什麼。
2. 一張三欄表「預約｜點餐｜會員」，列出這次三題各自要做的具體內容（照 `round2-topics.md` 第 1、3 節）。
3. 「要達成的條件」清單、「合格的結果要能通過的自我檢查」清單（三題通用）。
4. 需要時最後一行放 `<details><summary>真的卡住再看：提示</summary><p>…</p></details>`。
5. 不給步驟、不給數值答案（同第一輪規則 8）。

## 3. 每堂新增與修改

「主線」是工作室待處理清單的示範＋跟著做；「練習」是換你做。介面路徑一律照 `platform-inapp.md`。

### A1 讓畫面看得清楚
- **修缺陷**：第一次開檔就說明 Frame 尺寸在右側 Design 面板的 W、H 欄位改；所有「24／32」這類寫法第一次出現時寫成「字級 24、行高 32」；規格表補上登入卡片與按鈕的寬高（取 A3、A6 第一輪規格表的值，保持一致）；「換你做」的條件與自我檢查不能互相矛盾（第一輪「主要動作」那一條要對齊）。
- **改**：色彩規則表從「抄在旁邊的表」改成 **Variables**。主線示範：左側 Variables → Create → Color，第一個變數建立後把集合改名 `Studio`，依現有色彩規則表建立全部顏色變數（含新增 `Primary Pressed` #1B4535、`Primary Soft` #E8F0EC），再到 Fill 的 styles and variables 圖示 → Libraries 套用。清單下方 Figma 內建的 iOS 變數本課不用。之後全課「設成 Surface」這類說法都是指套用變數。
- **新增觀念**：主色三階（一般、按下、淺底）各用在哪；對比門檻：一般文字 4.5:1、大字（字級 24 以上，或 19 以上粗體）3:1、按鈕外框與圖示 3:1；手機內文字級建議不小於 16、輔助文字不小於 14。
- **Starter 限制**：變數只能有 1 個模式（深色模式之類要付費），本課只用 1 個模式就夠。
- **練習**：選題、讀需求頁、建立自己的顏色變數（主色三階＋文字＋底色＋邊界＋錯誤／成功／警告）與三種文字樣式、做開頭畫面並用對比檢查器檢查。

### A2 用格線安排版面
- **新增技法：響應式與 Constraints**。觀念：同一個畫面要在 360～430 寬的手機上都好看；常見寬度參考（手機 360～430、平板 768、桌面 1280～1440），本課只做手機與桌面兩種。主線示範：在登入畫面裡（非 Auto layout 父層）選標題，Position 區 X／Y 右側小圖示展開 Constraints，標題設 Left + Right、按鈕設 Center；把 Frame 寬度從 402 拉到 440 看誰跟著動、誰沒動；再拉回。說明 Scale 只用在插圖。說明「父層是 Auto layout 時改用 Fill container 與 Min／Max，下一堂教」。
- **練習**：4 欄格線、桌面雙區、開頭畫面從 360 改 412 用 Constraints 調整並截兩張寬度的畫面比對。

### A3 讓文字變長時排好
- **新增技法一：4／8 間距規則與數字變數**。觀念：間距只用 4 的倍數（4、8、12、16、24、32），讓畫面節奏一致、工程師好對照。主線示範：在 Variables 用 Create variable → Number 建 `Space 4`、`Space 8`、`Space 12`、`Space 16`、`Space 24`、`Space 32`；滑鼠移到 Padding／Gap 欄位右端點變數圖示套用到登入卡片。檢查第一輪數值有沒有不是 4 倍數的，有就改並說明。
- **新增技法二：Min／Max 寬度**。登入卡片在桌面寬度不要無限拉長：W 欄下拉 → Add max width…（值自訂並說明理由，例如 480）；按鈕 Add min width…，文字短時也不會太小。
- **新增技法三：Wrap 標籤列**。主線新做一排任務標籤 `Tags`（例如「高優先」「客戶」「本週」「交付」「待確認」），Auto layout 橫向後按 Flow 右邊的 Wrap，把寬度縮窄看標籤自動換行；這排標籤之後做清單時會用到。
- **練習**：用間距變數做題目的清單卡片，長文字那筆測長高，卡片設最小與最大寬度，做一排會換行的標籤。

### A4 改一次來源，多個按鈕一起更新
- **新增技法一：元件區**。用 Section（⇧S）在同一頁開一個 `Components` 區，所有主元件放這裡；命名用斜線分層（`Button / Primary`、`Icon / Check`），Assets 會依斜線分組。
- **新增技法二：圖示元件與巢狀**。把 `../assets/shared/icons/` 裡的 `icon-check.svg`、`icon-plus.svg`、`icon-arrow-left.svg` 從資料夾拖進畫布，各自 Create component、命名 `Icon / Check` 等，圖示的線條顏色套用 `Text` 變數。把 `Icon / Check` 的使用處放進按鈕主元件左側，說明「元件裡面放元件」。選按鈕使用處裡的圖示，在右側元件名稱下拉換成 `Icon / Plus`，觀察只有這個使用處改變。連到 `../assets/shared/icons/README.html`。
- **練習**：主要確認動作按鈕做成元件放進自己的元件區、兩個使用處、按鈕內放圖示並換一個。

### A5 把主次按鈕與狀態做成可選的元件
- **改**：按鈕元件改成 Type（Primary／Secondary）× State（Default／Hover／Pressed／Disabled）共 8 個 Variant；Pressed 套用 `Primary Pressed`，Hover 用 `Primary` 稍亮或加外框（自訂並說明）。第一輪「主次 × 停用」四種組合的內容改寫成這個矩陣。
- **修缺陷**：規格表「深灰 1 px 外框」對不上 A1，改成套用 `Border` 變數（或 Secondary 的外框用 `Primary`，擇一並與 A1 一致）。
- **新增技法：顯示開關與換圖示屬性**。選元件裡的圖示層 → Appearance 標題列 Apply variable/property 圖示 → ＋ → Create property（名稱改 `Show icon`、值 True）；再用 Properties ＋ → Instance swap 建 `Icon` 屬性。選使用處後右側出現 `Show icon` 開關與 `Icon` 下拉。
- **練習**：題目的狀態標籤元件（題目的狀態值），主要確認按鈕加 State 與 `Show icon`。

### A6 完成表單與錯誤修正
- **新增技法：表單控制項**。主線新增 `Screen / New Task`（新增任務）表單：任務名稱（文字欄）、類別（下拉，做收合與展開兩種畫面）、優先順序（單選：高／中／低）、提醒我（開關）、登入畫面加「記住我」（勾選）。每種控制項做成元件：`Checkbox`（Checked true／false）、`Radio`（Selected true／false）、`Toggle`（On true／false）、`Select`（Open true／false）。輸入框元件從一般／錯誤擴成 Default／Focus／Error／Disabled（Focus 用 `Primary` 2 px 外框）。
- **新增觀念**：什麼時候用單選、勾選、下拉、開關（一張比較表：選項數、可複選嗎、要不要立刻生效）；必填標示與說明文字；標籤放欄位上方。勾選框與單選的觸控範圍至少 44×44（點文字也要能選）。
- **練習**：題目的表單（照需求頁欄位），錯誤與修正後畫面，勾選框與單選做成元件。

### A7 把資料做成清單

- **新增技法二：載入中畫面**。`List / Loading`：用灰色矩形排出三列骨架（Skeleton），說明什麼時候給載入畫面、為什麼比轉圈好讀。
- **改**：清單列放入 A3 的 `Tags` 與 A4 的圖示（例如 `Icon / Clock` 放期限前）。
- **練習**：12 筆清單、空狀態、長文字那筆的詳情（含題目的範例圖）、載入中畫面。

### A8 回饋、彈窗與導覽
