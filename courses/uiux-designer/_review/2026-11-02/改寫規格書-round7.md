## 1. 第 4 項：題目配色與共用元件

**問題**：A1 要題目另建顏色集合，評分 V1 也要求題目畫面全用題目變數；但 A6 要題目「沿用同一個 Field」，那個 Field 的顏色綁的是 `Studio`。

**做法（已在 Figma 實機確認）**：選取一個元件集，右側 **Selection colors** 會列出裡面用到的所有顏色；綁了變數的顯示變數名稱，沒綁的顯示色碼。點其中一個變數色塊 → **Libraries** → 選另一個變數，整個元件集裡用到它的地方會一次換掉。截圖：`../assets/shared/ui/figma-selection-colors-swap.webp`（圖說：「選取元件集後，Selection colors 列出用到的變數；點色塊在 Libraries 換成題目的變數（紅框）」）。

- **A1**：題目集合的變數名稱建議和 `Studio` 用同樣的名字（`Primary`、`Text`、`Control Border`…），之後換綁時一眼就對得上。加一句即可。
- **A4**（主教學處）：新增一小節「把主線元件複製給自己的題目」：
  1. 在 `Components / 你的題目` 區，複製主線的按鈕元件集（選取後 Cmd／Ctrl+D 會得到使用處；所以要用 **複製貼上整個元件集**：選取元件集 → Cmd／Ctrl+C → 點題目區 → Cmd／Ctrl+V，貼上的是新的元件集）——此處「複製貼上元件集得到新的元件集」請在自我檢查標記為待 PM 實機確認，正文照寫。
  2. 把新元件集改名（例如 `Button` 改成 `Booking / Button`）。
  3. 選取新元件集，用 Selection colors 把每個 `Studio` 變數換成題目集合裡同名的變數。
  4. 檢查：再看一次 Selection colors，清單裡不應再出現 `Studio` 的變數或裸色碼。

## 2. 第 5 項：讓學員自己做決定

### A8、B4、B5：對應表改成範例
「三個題目的建議對應」表格標題改成「三個題目的範例（可以照做，也可以依你的需求改）」，表格內容保留。條件清單加一條：**「寫一句理由，說明你的做法回應了需求頁裡店主或使用者的哪一句話（引用原句）。」** 自我檢查加一條：「理由引用的原句真的在需求頁裡。」B5 若仍有直接指定分頁的句子，改成「你在需求與流程那一堂決定的分頁」。

### B2：只完整示範一題
- 「三個題目各自最難的那一個畫面」：**預約題保留完整示範**（規格表＋步驟），改名為「完整示範：預約題的選擇時段」。
- 點餐、會員兩段刪掉規格表與步驟，改成「設計問題＋合格標準」：
  - 點餐：設計問題「顧客加入第二杯時，怎麼知道訂單裡現在有幾杯、總共多少錢？售完的品項要在什麼時候讓人知道？」合格標準：數量最少 1、減到 1 時減號停用；徽章數字等於訂單總數量；總計等於各品項單價×數量的和；售完在加入前就看得出來且不能加入。
  - 會員：設計問題「會員在兌換前，怎麼知道自己點數夠不夠、差多少？兌換後去哪裡確認扣了多少？」合格標準：首頁看得到目前點數；點數不足的兌換品在兌換前顯示差多少且不能兌換；點數紀錄的增減與餘額連續正確，最後餘額和首頁一致（資料用 `MEMBER-POINTS.csv`）。
  - 兩段各加一句：「先畫兩種做法的草圖再選一種，把沒選的那種與理由寫進評分表的設計取捨（N5）。」
- 預約題學員：在預約段落最後加一句「你的題目若是預約，這段示範可以照做；但『改時間』『沒到店』等需求頁裡的其他問題，要自己設計（評分表 N4）」。

### B1：店主痛點至少設計一個
B1 練習裡「在需求頁另外找兩個還沒處理的問題」那一條改成：「另外找兩個店主的痛點，**至少一個這次就設計出解法**（之後的堂次做進畫面與原型），另一個可以列入之後再做；兩個都寫理由。」提示 details 可舉方向（預約：改時間；點餐：甜度怎麼選才不會聽錯、怎麼避免重複送出；會員：點數會不會過期），不給答案。

### B6：完成條件
凡寫完成條件的地方改成：總分 80 以上；N1、N2 必過；「解決需求」N1～N5 至少通過四項；沒有做不下去的問題。用一兩句說明為什麼要至少四項（只做功能拿不到這四項）。

### B8：把自己的一張畫面做成網頁（新增一節）
放在「換你做」之前或之內，約 90 分鐘。下載包裡新增 `my-screen.html`（PM 已放進 `web-starter/` 與 `studio-tasks-web.zip`）：一個 360 寬的清單頁，最上面 `:root` 列出顏色與間距變數，下面三張卡片。步驟：
1. 用 VS Code 打開 `my-screen.html`，用瀏覽器開來看。
2. 打開 Figma，選題目的清單畫面，用 Selection colors 和 Design 面板讀出顏色、間距、圓角，把 `:root` 裡的值換成自己的（說明 Figma 的 `Primary` 對應 CSS 的 `--primary`、`Space 16` 對應 `--space-16`）。
3. 把三張卡片的文字換成題目 CSV 的三筆；不能選的那筆在按鈕加上 `disabled`。
4. 把瀏覽器視窗拉到手機寬度，和 Figma 畫面並排比對，至少修一處不一致。
5. `git add`、`git commit`（訊息寫「把我的清單畫面做成網頁」）、`git push`，上線後用 `…/my-screen.html` 打開。
