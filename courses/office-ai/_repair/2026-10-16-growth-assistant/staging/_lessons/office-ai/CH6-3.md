# 用 ta-learning 建立課後數位小老師

課後真正卡住的時刻，通常發生在你獨自面對新資料時。這個總整合會把講師講義變成可查詢的可信核心，再用 `ta-learning` 把濃縮內容展開成白話說明、步驟提示與錯誤診斷。你最後會得到一位能回查講義、誠實標示補充來源、經你同意後才保存新筆記的數位小老師。

## 本節完成後，你能做到什麼

- 用講師講義與課堂材料建立一個 50 筆內可維護的課程 Notebook。
- 以 `ta-core + ta-learning` 完成依據查核、引導式解惑與缺資料測試。
- 把經確認的課後 QA 追加為文字筆記，不覆寫原始講義。
- 將相同機制移植到另一門課、SOP、專案規範或工作知識庫。

## 結訓完成物

**起始材料：**

- [下載 ta-core.md](../../courses/office-ai/assets/skills/ta-core.md)：控制來源邊界、檢索與回寫。
- [下載 ta-learning.md](../../courses/office-ai/assets/skills/ta-learning.md)：控制課後助教的解釋與引導方式。
- [開啟課後指南](../../courses/office-ai/assets/after-class-guide.md)：本次的講師可信核心。
- [下載全課程 Prompt 庫](../../courses/office-ai/assets/datasets/prompts-all.txt)：本次的操作範例來源。
- 你的課堂筆記或一份講義 PDF；內容須可上傳且不含未處理個資或機密。

**第一個動作：**建立或選擇一個課程 Notebook，只加入課後指南、Prompt 庫與一份自己的去識別化課堂筆記。先不要加入網路文章或 AI 自行生成的摘要。

**第一個可觀察結果：**筆記本來源清單顯示 2–3 份可辨識的課程材料，每份都能說明來源者、用途與更新日期。

**完成物：**一個可運作的課後學習助教、一張八項驗收卡、一筆受控沉澱紀錄，以及一份 30 天成長表。

**卡住時：**帳號沒有 Skills 或連接器入口時，沿用 CH6-1 的手動備援；Notebook 無法加入某格式時，把內容轉成可讀文字或改用已提供的 Markdown／TXT 素材。沒有可取得的講義來源時停止，不用模型記憶假裝成課程內容。

## 先建立課程的可信核心

### 來源選擇規則

每一筆來源都要回答三題：

1. 誰提供或核准這份資料？
2. 它用來回答哪類問題？
3. 過期或衝突時，誰負責更新與判斷？

講師講義、正式課後指南、課程 Prompt 庫與已確認的課堂筆記可放入核心區。搜尋到的部落格、論壇貼文與模型生成摘要先放在核心之外；需要補充時，以【最新網路補充】或【模型推論與延伸】標示。

### 50 筆來源配置

免費帳號每本 50 筆來源的建議配置：核心講義不超過 35 筆、輔助資料不超過 10 筆、至少保留 5 筆空間。同一主題的 QA、勘誤與版本更新，追加到一份「課後學習紀錄」文字來源，避免每問一題就新增一筆。

### Checkpoint：可信核心可以開始使用

現在應看到 2–3 筆來源，名稱能分辨內容與版本。若有重複檔、來源不明或無法判斷更新日期，先移除或改名；核心來源通過後才啟用助教。

## 啟用 ta-core 與 ta-learning

帳號有 Skills 入口時，依 CH6-1 的方式新增並啟用 `ta-core` 與 `ta-learning`，確認 Gemini Notebook 連接器可用。帳號沒有入口時，在新對話貼入兩份 Skill 全文，並使用 Notebook 網頁版完成來源查詢。

先執行唯讀確認：

```text
@ta-core @ta-learning
列出目前可用的筆記本與來源數。這一輪只讀，不要新增、修改、重新命名或刪除任何內容。
```

再鎖定你的課程 Notebook：

```text
請鎖定《辦公室 AI 課後助教》。先列出來源名稱與來源數，不要修改資料。
```

**通過訊號：**助理回報正確筆記本、2–3 份課程來源及目前來源數。名稱相近時應請你選擇，不能自行猜測。

## 第一題先驗證講義依據

輸入：

```text
課程為什麼要求把「整理」與「判斷」分開？

請先給結論，再依目前課程 Notebook 回答：
1. 標明講義或課後指南的來源名稱與對應主題。
2. 用一個辦公室例子白話說明。
3. 說明哪個部分仍要由人查核。
4. 如果講義沒有寫到某一點，請明確標成【助教補充】，不要把補充寫成講師原意。
```

**預期結果：**回答先說明 AI 適合重組材料，人要保留數字、事實、承諾與決策查核；接著標出課後指南或 Prompt 庫的依據，再補一個清楚標示的助教例子。

**快速檢查：**點回來源，確認講義真的支持核心結論。例子若不是講義原例，必須標為助教補充。

## 讓助教先診斷再教

輸入：

```text
我常把會議裡的「原則同意」整理成「已決議」。先問我兩個診斷問題，判斷我在哪個步驟混淆；一次只給一個提示。等我回答後，再用講義中的方法帶我修正，最後請我自己重寫一句並檢查。
```

這個任務檢查 `ta-learning` 是否真的扮演助教。合格流程會先了解你的判斷，再逐步提示，最後要求你自己完成。一開始直接丟出答案代表未通過。

### Checkpoint：教學層與來源層都有作用

現在應看到兩種證據：`ta-core` 讓回答標出講義依據與資料缺口；`ta-learning` 讓解惑包含診斷、提示、白話解釋與學員重寫。若只有流暢答案而沒有來源，回到 Notebook 鎖定；若只有引用而沒有引導，檢查 `ta-learning` 是否啟用。

## 再問一題講義沒有的事

輸入一個明顯超出課程的問題，例如：

```text
講師在私人公司實際使用哪一套薪資系統？請只根據課程 Notebook 回答。
```

講義沒有這項私人資訊。回答必須先宣告資料不足，不能假裝自己是講師，也不能虛構講師的經歷。這項測試確認「講義是核心」不會被誤解成「助理能代表講師說任何話」。

## 把高品質 QA 留下來

先建立寫入預覽：

```text
把剛才釐清的「原則同意與正式決議」整理成課後 QA Markdown 預覽，包含：問題、講義依據、常見誤解、修正方法、日期。

請說明預計寫入的筆記本、來源名稱，以及採新建或追加。現在不要寫入。
```

檢查內容正確後，再確認：

```text
確認追加到《辦公室 AI 課後助教》的文字來源〈課後學習紀錄〉文末。保留原始講義不變；完成後回報來源名稱與來源總數。
```

**寫入規則：**

- 同主題 QA、勘誤與學習筆記：追加至既有文字來源。
- 全新主題或需要獨立管理的完整筆記：建立新來源。
- PDF、網頁與外部文件：保持唯讀，修訂內容寫入補充筆記。
- 寫入前：確認筆記本、來源、內容與模式。
- 寫入後：回到來源清單與文字內容查核；追加模式的來源數應保持不變。

## 從學習助教移植到工作助理

同一個底座可用於任何具備可信、可用資料的學習或工作：

| 項目 | 學習助教 | 工作助理 |
|---|---|---|
| 可信核心 | 講師講義、課後指南、課堂筆記 | SOP、專案規格、會議紀錄、正式決策 |
| 上層 Skill | `ta-learning` | 通用或客製化 `ta-work` |
| 常見任務 | 解惑、複習、診斷盲點、出題 | 查制度、規劃、比對規範、草擬文件 |
| 不能污染的內容 | 講師原意、評量標準、課程定義 | 公司制度、內部數字、決策與責任人 |
| 沉澱內容 | 課後 QA、勘誤、版本補充 | 決策紀錄、更新版 SOP、專案 QA |

移植前確認三件事：資料來源可合法使用、內容足以支持任務、結果可由人回查。缺少任一條件時，先整理資料或縮小任務。

## 30 天成長表

每週固定做一次：

| 週次 | 使用任務 | 發現的來源缺口 | 經確認的新增知識 | 新建／追加 | 人工查核結果 |
|---|---|---|---|---|---|
| 第 1 週 | 建立基準，記錄一題課後疑問與處理時間 |  |  |  |  |
| 第 2 週 | 重跑兩題，調整提問與輸出格式 |  |  |  |  |
| 第 3 週 | 加入一題缺資料測試與一筆受控沉澱 |  |  |  |  |
| 第 4 週 | 比較耗時、錯誤與來源數，決定保留或調整 |  |  |  |  |

來源數接近 45 筆時先整理：刪除重複或失效來源，把同主題文字筆記合併追加，保留至少 5 筆空間。不要為了省配額覆寫原始講義或把不同主題硬塞進同一筆。

## 結訓驗收卡

離開本課前逐項確認：

- [ ] 課程 Notebook 有 2–3 份可辨識的可信來源。

- [ ] 助教補充與講義內容有清楚標示。

八項全數有證據，才算完成自己的數位小老師。平台功能受限時，手動備援的截圖、Markdown 與查核紀錄可作完成證據，但要明確標出尚未驗證的自動功能。

## 講師授課筆記（不進講義）

- 示範先用本課課後指南與 Prompt 庫，避免學員上傳不明來源。
- 引導式解惑要讓學員回答診斷題，不用講師代替學員完成。
- 回寫示範先停在預覽；只有全班確認目標與內容後再操作。
- 結尾讓學員口頭說出 `ta-core`、`ta-learning`、`ta-work` 的分工與可移植條件。
