# 可重用工具結構工作表

先說明工具幫使用者完成哪種工作；當次人名、日期和數字在工具生成後填入。

| 設計面向 | 自己的規格 | 排班示例 |
|---|---|---|
| 使用者能輸入什麼 |  | 可新增/刪除/修改的人員、日期、班種、時段與需求 |
| 哪些規則能設定 |  | 可排勾選、總班數上限；新增規則選班種與次數上限 |
| 工具怎麼處理 |  | 先驗證、按限制安排、盡量填滿再平均 |
| 要看到與帶走什麼 |  | 班表、缺額與原因、每人班數、CSV及資料備份 |
| 錯誤如何處理 |  | 缺漏阻擋、無法排滿保留空缺、錯誤還原保留原資料 |
| 支援範圍與交付 |  | 1–8人/1–7日期/1–4班種/每班需1–4人；離線單一HTML |
| 生成後用哪些資料驗收 |  | A四人三日兩班種；B五人兩日三班種，另改需求人數 |

轉移示例：預算工具的輸入改成可新增/刪除的項目、數量與單價；處理由排班改成費用計算，輸出改成各項金額與合計。不能只把排班改名為預算而保留相同資料與處理。

檢查：換一組數量與內容不同的資料，是否仍能在同一工具完成？是否需要改提示詞、改程式或重新生成？需要改時，指出缺少哪個輸入或處理能力，再修規格。
