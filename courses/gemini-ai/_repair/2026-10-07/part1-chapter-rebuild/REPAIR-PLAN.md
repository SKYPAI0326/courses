## 提示詞保真原則

- 不把完整舊提示詞改成短摘要；逐項保留原有功能、邊界、例外、完整檔案輸出與驗收要求。
- 對工具範例明確說明單一 HTML 的交付理由、內嵌 CSS／原生 JavaScript 的關係，以及固定計時不需呼叫 API 或連網的原因；同時說清楚「生成提示詞會送往雲端」的隱私界線。
- 對每項增刪記錄原因。舊版「黃金公式保證欄位／邏輯正確、直接可用」等不實承諾予以更正；移除與本章主線無關或會引入未教技術範圍的變體，不以之替代本章完整案例。
- `<!DOCTYPE html>` 與 `</html>` 顯示在 HTML 程式碼區時必須正確轉義，讓頁面可見文字完整。
- 三頁不提供重複 TXT 或 HTML 下載；提示詞、說明、答案與修復句直接顯示在對應頁面。
