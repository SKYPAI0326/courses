# CH1 learner agent 第二輪冷讀紀錄

- Reviewer kind：independent learner agent
- 範圍：更新後 CH1-1、CH1-2、CH1-3，以及 CH2-1 開頭至預算要求
- 執行方式：只讀冷讀，未修改課程檔案
- 結論：一項重大前提斷裂、三項小型文字／規格不一致；修正後無未解的內容銜接問題。平台路徑和模型實際輸出仍未驗證。

## 發現與修正

| 嚴重度 | 發現 | 修正 |
|---|---|---|
| MAJOR | CH1-2 的「新增練習難度」提示詞要求保留三種難度、暫停、最高分等功能，但首輪經典版沒有這些功能，且 CH1-1 將它們列為自選延伸。 | 改為新增「吃到第 5 個食物完成本局」；明定完成前、碰撞、重開、分數／食物計數歸零及完整 HTML 交付，直接適用首輪版本。 |
| MINOR | CH1-3 把首輪貪食蛇寫成含暫停。 | 改為移動、得分、碰撞和重新開始。 |
| MINOR | CH1-2 黃金公式角色欄和首輪提示詞原句不一致。 | 改為逐字引用首輪角色描述。 |
| MINOR | CH1-1、CH1-3 的技術限制寫「API」，可能被讀成包含瀏覽器內建 API。 | 改成「外部／雲端 API」，並保留 localStorage、Web Audio API 是瀏覽器內建能力的說明。 |

## 冷讀確認項

- CH1-1 首輪提示詞具備開始、桌機／手機控制、食物／計分、碰撞、重新開始及單一 HTML 存檔交付；有 Mac／Windows 存檔操作與生成失敗的修復路徑。
- 三份延伸提示詞可依序接在最新完整 HTML 後，分別補充壽司店視覺、難度／暫停／最高分／觸控滑動、音效／DEMO／代打與視覺效果。
- CH1-3 請款規則把項目名稱列為必填；四組測例與規則相符，空白項目名稱有停止分類的錯誤測例。
- CH1-3 與 CH2-1 共用同一組預算資料及欄位語意；估算 26,000、實支 27,800、較估算多 1,800、核定 30,000 時餘額 2,200 的答案一致，CH2-1 再用核定 27,000 驗證 −800 餘額。
- CH1-1 仍須教師提供已確認的生成平台、登入和免付費路徑；本次冷讀無法驗證模型能否實際生成可玩的檔案。
