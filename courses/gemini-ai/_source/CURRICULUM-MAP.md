# 五章與案例遊樂園地圖

唯一核心路線為CH1→CH2→CH3→CH4→CH5；原Part／PRAC編號保留作網址及來源追溯，學員按章前進。

| 章 | 新增能力 | 往下一章的關係 |
|---|---|---|
| CH1 | 用白話生成、保存、操作及修改小工具 | 提供第二章拆解需求的實際生成經驗 |
| CH2 | 拆需求、分案例，操作固定計算與多條件判斷 | 把需求方法用於第三章排班工具 |
| CH3 | 用A／B及例外核對排班工具，通過後保存為 schedule-v2 | 第四章從通過檢查的 v2 複製，保留原版再追加新規則 |
| CH4 | 從 v2 加入可調規則，查核舊功能與新功能，保存為 schedule-v3 | 將 v3 與 v1、v2 歷史版本交第五章整理、還原及交付 |
| CH5 | 交付 schedule-v3，保留 v1、v2 作為回復版本；另完成CSV清理工具A／B與交付 | 到遊樂園選工作案例，按需求擴展 |

獨立案例遊樂園共29例，23例直接引用既有正文，6例為跨課新素材。按資料整理、計算規則、需求文字、圖表呈現、工作協作選用；案例間沒有必經前後順序。每例正文只存一份。

13份概念、模型及外部部署參考仍在首頁延伸區，平台型教材須另外確認環境和權限。正文目錄及來源分別記在lesson-map.json、playground/catalog.json。
