# Gemini AI 實戰課完整課程地圖

版本：2026-10-07。本表涵蓋 40 個歷史 lesson HTML：新版納入 7 個核心頁與 32 個課後補充頁；`part2/PRAC2-2.html` 不遷入新版課程目錄但保留歷史檔。各頁的內容保真、提示詞完整度及零基礎學習使用情形仍須依頁型試作逐步驗收；路線分流不等於內容完成。

## 全課進程與分流原則

課程對象是程式與 AI 工具零基礎的職場學員。六小時暫以 360 分鐘教學活動、不含休息作規劃估值，尚未真人試教。課程先體驗白話提示生成單一 HTML 網頁應用，再學黃金公式與應用程式提示詞類型，接著以活動預算作唯一工作主案例，最後保存、重開、修改及交付。其他職務案例完整保留於課後補充，供學員依工作選用。

分流總數為核心 7、補充 32（29 頁延伸、3 頁參考）、不遷入新版 1。補充頁仍須有自己的情境、概念、完整可直接使用的提示詞、操作步驟、預期結果、判讀、修正方式和注意事項；本路線同步階段不重寫其正文。每個成果須區分參考品和學員實際生成品，未實測平台生成、匯出、重開或恢復的行為保持未驗證。

## 360 分鐘五階段規劃

| 階段 | 時間 | 單元 | 學習增量 |
|---|---:|---|---|
| 應用生成初體驗 | 50 分鐘 | CH1-1 | 用白話提示生成單檔工具並做一項自選修改；貪食蛇只作趣味小例子。 |
| 應用程式提示詞設計 | 85 分鐘 | CH1-2、CH1-3 | 理解黃金公式，分辨單檔互動、函數計算、多條件判斷各自需要的規格。 |
| 工作情境應用 | 140 分鐘 | CH2-1、PRAC2-1 | 手算預算已知答案，再生成工具並以正常與例外資料核對。 |
| 工具延伸與交付 | 60 分鐘 | CH4-1、PRAC4-3 | 保存重開，沿用同一工具自選修改並完成回歸測試。 |
| 課後補充導覽 | 25 分鐘 | 補充教材目錄 | 依工作選一個後續完整案例，不在課堂快速演練全部案例。 |

時間是設計估值，若六小時含休息或學員平台操作延遲，須試教後調整。

## 已查閱的官方平台依據

- [AI Studio Build mode](https://ai.google.dev/gemini-api/docs/aistudio-build-mode)：Build 以自然語言生成網頁 app，可在 chat panel 迭代；當前網頁 app 預設使用 React 與伺服器端 Node.js runtime；API key 以伺服器端 secret 使用；支援 GitHub 同步與 Cloud Run 部署。頁面於 2026-10-06 查閱。
- [AI Studio deployment](https://ai.google.dev/gemini-api/docs/aistudio-deploying)：頁面標示 2026-09-28 更新；Starter Tier 只對符合資格帳號開放，最多 2 個部署服務；標準部署需要連結 Google Cloud 專案並啟用帳單。
- [AI Studio quickstart](https://ai.google.dev/gemini-api/docs/ai-studio-quickstart)：Chat prompt 可在 Playground 測試及反覆調整；介面位置／按鈕名隨平台改版可能不同。頁面於 2026-10-06 查閱。
- [Gemini API billing](https://ai.google.dev/gemini-api/docs/billing/) 與 [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)：免費層只涵蓋部分模型及各自限制；共享 app 的 API 呼叫計入建立者額度，付費模型可能產生費用。頁面於 2026-10-06 查閱。
- [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=zh-TW)：目前從輸入框下方「新增檔案 → Canvas」建立；13 個原始步驟已依此改寫並連回官方說明。頁面於 2026-10-06 查閱。
- [Railway Trial](https://docs.railway.com/pricing/free-trial) 與 [Plans](https://docs.railway.com/pricing/plans)：核對 Trial 額度／期限、Free 與 Hobby 價格及 Trial volumes 保存規則。頁面於 2026-10-06 查閱。
- [GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)：支援 Actions 建置與發布靜態網站，不支援伺服器端語言。頁面於 2026-10-06 查閱。
