# Gemini AI 實戰課完整課程地圖

版本：2026-10-06。本表依 40 個既有 lesson HTML 的實際正文盤點；原頁內容保留。它用來說明每頁的工作用途、先修能力、產物與證據限制。`核心` 是 10 站有明確必修成果的學習路徑；`延伸` 依工作情境選做；`參考` 是發布、介面或特定領域的補充，不代表已在本輪核心路徑完成或已驗證平台狀態。

## 全課進程與分流原則

全課目標是讓零基礎學員能把一項重複工作說清楚、產生一個可操作成果、用已知答案檢查、修復失敗並保存交付。核心路徑依先備能力排列：Part 1 先認識生成工具並寫出需求與驗收；Part 2 以預算示範固定規則與數值核對；Part 3 選 KPI 練習方向、缺值與資料解讀；接著進 Part 6 處理需要語意判斷的會議交辦；最後回 Part 4 保存、重開並獨立修改。頁碼順序是原始內容分類，不等於必修順序；因此 10 站會從 Part 3 跳到 Part 6，再回 Part 4。Part 5 是依工作選擇的案例庫，未假定每人都要做完 12 個工具。

每個產物都要區分「課程參考品」和「學員自己生成並通過驗收的版本」。生成指令、來源資料、預期答案、觀察結果、修復與重測記錄要能互相對得上。視覺完成、關鍵字評分、已打開頁面或示例答案都不能單獨證明實作成功。

## 已識別的內容銜接與待修缺口

- `part2/PRAC2-1.html` 核心教案處理活動預算，但同頁原始互動示例是專案工時報價計算器。兩者資料欄位及驗收不同；應以清楚標籤分隔，不能讓學員誤以為報價器已證明活動預算正確。
- `part1/CH1-2.html` 與 `part1/CH1-3.html` 需從「拿到整段 Prompt」提升到能逐段讀懂：每段提供什麼資訊、改哪條規則會改變哪個結果，以及如何用測試判斷生成工具是否照做。
- `part1/PRAC1-1.html`、`part1/PRAC1-2.html`、`part1/PRAC1-3.html` 重複提示詞工具練習；放在核心路線之外，學員有工作需要時選做。品質健診的分數只能當提示，不能作通過標準。
- 核心必修從 Part 3 跳 Part 6 再回 Part 4，依序是「資料解讀 → 語意 AI → 保存與交付」。Part 5 的案例及發布兩頁不是完課必要條件。
- AI Studio Build 的生成、GitHub、Cloud Run、Starter Tier 資格、分享程式碼可見性與 API 費用已依 Google 官方文件核對；各帳號是否具備資格仍須當下確認。Canvas 入口、Railway Trial／方案、GitHub Pages 的靜態／伺服器端邊界也已查核並修正。社群平台字數、時區與其他供應商費用仍待選用前查證，不以 lint 代替現行 UI 證據。
- 6 小時安排、學員獨立完成時間、AI Studio 帳號內生成／重開，以及其他平台依賴，仍待真人課程試跑與帳號實測。

## 已查閱的官方平台依據

- [AI Studio Build mode](https://ai.google.dev/gemini-api/docs/aistudio-build-mode)：Build 以自然語言生成網頁 app，可在 chat panel 迭代；當前網頁 app 預設使用 React 與伺服器端 Node.js runtime；API key 以伺服器端 secret 使用；支援 GitHub 同步與 Cloud Run 部署。頁面於 2026-10-06 查閱。
- [AI Studio deployment](https://ai.google.dev/gemini-api/docs/aistudio-deploying)：頁面標示 2026-09-28 更新；Starter Tier 只對符合資格帳號開放，最多 2 個部署服務；標準部署需要連結 Google Cloud 專案並啟用帳單。
- [AI Studio quickstart](https://ai.google.dev/gemini-api/docs/ai-studio-quickstart)：Chat prompt 可在 Playground 測試及反覆調整；介面位置／按鈕名隨平台改版可能不同。頁面於 2026-10-06 查閱。
- [Gemini API billing](https://ai.google.dev/gemini-api/docs/billing/) 與 [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)：免費層只涵蓋部分模型及各自限制；共享 app 的 API 呼叫計入建立者額度，付費模型可能產生費用。頁面於 2026-10-06 查閱。
- [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=zh-TW)：目前從輸入框下方「新增檔案 → Canvas」建立；13 個原始步驟已依此改寫並連回官方說明。頁面於 2026-10-06 查閱。
- [Railway Trial](https://docs.railway.com/pricing/free-trial) 與 [Plans](https://docs.railway.com/pricing/plans)：核對 Trial 額度／期限、Free 與 Hobby 價格及 Trial volumes 保存規則。頁面於 2026-10-06 查閱。
- [GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)：支援 Actions 建置與發布靜態網站，不支援伺服器端語言。頁面於 2026-10-06 查閱。
